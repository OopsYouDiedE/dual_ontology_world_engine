# 正式世界 3D 美术库维护

本目录恢复自提交 `4c64b84a` 的父版本，保留用户指定的 E 方案，以真实三维结构、位图材质与细致家具为基础；但是恢复美术库本身不代表已经替换正式游戏宿主。

人物比例以 E 的统一解剖模板为参考，服装、发型与配件独立制作，动作定位参考《模拟人生4》；但是新动作须在人物与家具的统一尺度下验证，禁止分段拉伸身体凑比例。

装饰纹理使用有来源的原生位图，Shader 可以表现木纹、水面与光照；但是 SVG 纹理及 SVG 转位图的规避方式均禁止。低多边形资源仍保持正确人体与建筑比例；但是粗劣室内外模型与二维贴片不能充当完成的三维替换。

探索显示消费宿主交付的本人认知及最后所见静态状态，当前房间正常显示，探索过的房间显示暗化记忆；但是未知房间保持隐藏，离开房间后的人物和实时变化不冒充已知信息。

区域模型、家具预制件、角色和正式会话分别按职责组织，重复物件复用唯一构造源；但是主体、预约、认知和实时火焰状态保持实例独立。正式移动、门禁与动作完成通过宿主接线；但是作者总览和单场景切换仅用于美术检查。

测试使用根 AGENTS 指定的正式 MCP，单场景入口是 `res://scenes/components/world/library.tscn`；但是旧独立测试工程、回放脚本与采集脚本不随恢复重新启用，清理也始终逐文件进行。

2026-10-27 起室内地毯、长毯和桌旗先使用素色织物，保留既有尺寸、摆放和表面质感；但是花纹制作安排在其他部分处理好之后，当前不新增或恢复地毯纹样。
