# 动物园规则怪谈模拟器

网页与终端现在共同引用 `runtime/ZooSimulator.Runtime.csproj`，使用 `ZooSimulation` 启动同一套模拟。网页发布入口见 `../zoo_web/README.md`。

## Core 能力接入

动物园流程使用实体树与直接引用、身体与心智绑定、客观及已知场景拓扑、文书发布与信念立场、效用决策、声明式事务与资源支付、行动值调度、环境效果变换和因果事件记录。

`ZooWorld.Cognition.cs` 补充有限状态感知、查证取证、Core 对话候选、事件见证、求助后的嵌套回应、情绪与关系反馈、社交态度时效、长期动机及证据反思。反应由 Core 运行时结算，消耗回应者的行动值。查证通过 `observe` 效果提交知识，`NarrativeDynamics` 只对新证据提供反思机会。情绪参与行动评分，并按园区日期结算衰减。

这些能力属于常规模拟流程；具体是否触发取决于现场条件与角色选择。不是每次短推演都会发生全部机制。仪式配方、超自然契约与其他作品专属内容尚未作为动物园机制加入，文书仍不具备直接改写客观世界的权力。

基于本目录《动物园规则怪谈原文.md》的九份文书，共 97 个条目。包含游客、员工、海洋馆门口、馆内、海洋馆员工、游客捡到的纸条、客房遗留纸张、园长文件、保安便签。原文末尾的解析没有作为规则或客观事实导入。宣传性导语不计入编号。

## 运行

在仓库根目录执行：

```powershell
dotnet run --project godot_csharp/examples/zoo_simulator -- --seed 7 --time 180 --rules standard
dotnet run --project godot_csharp/examples/zoo_simulator -- --start-minute 20 --time 360 --verbose --report zoo-run.json
dotnet run --project godot_csharp/examples/zoo_simulator -- --catalog
dotnet run --project godot_csharp/tests/zoo_simulator_audit
```

一个行动值对应一分钟；`--start-minute` 为从第零天午夜起的分钟数，可选择日期、跨午夜以及周日。`--time` 为本次模拟持续时间。`--max-steps` 限制计算量；达到限制且尚有到期任务时返回退出码 2，不报告推演完成。输入错误返回 1。

`standard` 提供岗位和地图知识；`none` 不提供初始文书；`gate` 提供门口告示，兼容旧名称 `corrupted`；`all` 提供全部互相矛盾的文书。它们只改变初始采信内容。`none` 中的人仍能在现场阅读文书，因此它不等同于永久剥夺学习能力。严格的机制对照使用固定行动重放。

## 原生机制与规则

核心引擎提供对象引用、场景拓扑、心智、行动值队列、声明式状态事务和事件记录。本例未修改核心，也没有把文书装进客观规则补丁。

`ZooWorld` 构造游戏层的场景、资源和生物。`ZooAnomalies` 实现这部作品选用的环境暴露、追踪、捕食、时钟和生态过程。它不读取守则对象、条目编号、预设名称或采信状态。生命、侵蚀、关注等数值由实际行动与时间推进演化。移动依赖场景通道；封存依赖物件真实所属容器；制服颜色不提供免疫。

`ZooRules` 保留原文、来源、置信度和采信状态。每个操作性条目解释为行动建议，使用同一套移动、物品操作、求助、巡检等动作。条目函数只能返回评分，不能写世界状态。复杂导航和期限建议在游戏层计算，通过核心的心智效用入口参与选择。原生 `Soul` 保存文书信念；文书载体中的 `Rule` 不带客观执行指令。责任声明 `Inside.8` 仅保存文本，不编造对应的物理惩罚。

`ZooMinds` 生成有位置、身体和物资前提的行动。它不根据守则开关隐藏所谓错误动作。角色会依据自己已采信的文书反思，并形成求助、避难等个人计划；这些计划不改变世界的危险定律。人物可能相信错误信息，也可能在强烈需求下违背建议。

结局由 `ZooWorld.Outcome` 读取：生命耗尽、离开正规出口、进入右街边界、认知同化或仍在园内。右街通向哪里在原文中不确定，所以进入右街边界只报告去向不明。没有“条款完成→生还”或“条款违反→死亡”的结果表。

## 机制假设

原文没有给出唯一的超自然机制、伤害系数或行动时长。本例的数值是可修改的游戏建模选择，不是原文的隐藏标准答案。接触与持续暴露分别结算；暴露以分钟积分，不因行动次数增多而重复收费。未知名称的源只要具备相同属性，就适用相同机制。

白狮分别行动，吼叫影响实际可听见的相邻场景，并且会过期。失去白狮、改变位置或中断吼叫都会改变效果。被捕食者必须与攻击者同处场景，受到实际生命损失；关注度达到某值不会直接使人脱离场景树。

地图虚线是持有作者引用的物件。丢弃不会自动给任何人加上庇护。收到信号需要在场读信，救援需要后续行动。喂纸不会保证产生笑声；笑声来自世界内实际发生的事件。文书中的逃生建议可能无法奏效。

物种认知参照具有范围。读大象标示牌不提供对所有异常的免疫。保持某种解释只影响认知过程，无法阻止食用实体物质造成的接触效应。

封园十分钟、夜间关灯和岗位时间均属于文书约束。门可以提前打开，也不会因为已过十分钟而自动打开；是否操作由角色决定。夜灯在期限之后仍可亮着，只有关灯操作或实际耗尽电量才改变灯的状态。

## 检查与修改记录

- 旧示例只覆盖少量条款，编号和角色流程有错位。现按原文九个连续区段逐条登记，`--catalog` 可查完整文字与声明类型。
- 旧异常代码未直接读取守则预设；这一边界继续保持，并增加同一行动在不同知识条件下的重放验证。
- 旧白狮和保安行为直接写 `protected`，草坪布尔值不能确定投纸者。现移除该状态，使用生物行动、时限场域及实际纸条引用。
- 旧失踪逻辑根据行动前关注值直接移除角色，制服字符串参与免疫判断。现使用持续演化与在场攻击，结果统一从状态读取。
- 旧测试以打印结果为主，不能据此证明完整因果链。现失败会抛出异常并返回非零退出码。

## 验证范围

审计包含文书清点、固定行动重放、服装替换、动作频率变化、未知危险源及其消融、容器隔离、资源竞争、过期命令、信号身份、白狮消融、时间边界、物种参照范围，以及六个种子乘四种初始知识的开放推演。开放推演检查移动合法性、资源非负、状态有限以及事件链能否还原最终状态，不要求某个种子必须生还或死亡。

单个机制实验会控制初始位置和资源以隔离因果变量；它们不被当成整个动物园一定存在某种结局的证据。有限次推演也不能证明所有行动组合的性质。
