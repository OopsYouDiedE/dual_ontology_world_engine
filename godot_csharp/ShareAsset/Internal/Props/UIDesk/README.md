# UIDesk

标题页的桌面、灯光与册子封皮（设计规范第六部分 §4.7 标题页）。全部由 `tools/build_ui_desk.py` 生成，种子固定，可重建。

- `desk.png`：3/4 俯视的木桌与黄铜油灯，灯光七级抖色，原生 640×496 按最近邻放大 2 倍。
- `glow.png`：灯焰光晕（RGBA），标题页以叠加混合显示并轻微闪动（“减少动效”时静止）。
- `book_light.png`：册子表面的乘色光照，屏幕坐标；标题页的册子着色器按屏幕 UV 取样。
- `cloth.png`：册子布面封皮，128 原生像素可平铺，放大 2 倍。

灯光取低饱和暖白，不用琥珀色（恶魔专属）。
