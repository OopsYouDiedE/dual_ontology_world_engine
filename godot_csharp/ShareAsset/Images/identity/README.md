# RPG 48px 动态素材包

当前为网上帧参考重绘版，已替换旧动画。长旌旗参考 Modular_Banner_16x16 的 Quiet 帧表；横旗参考 Screaming Brain Studios 的十六帧正视旗帜序列。原始来源与抽帧方式见 [动作参考.md](动作参考.md)。五方顺序为皇室团龙、皇家科学院、神秘学公会、学院、伯爵个人。

- 上排长旌旗：每帧 **48×96，1 格宽、2 格高**，8 帧轻摆，建议 6 fps。
- 中排横旗：每帧 **48×48，1 格宽、1 格高**，8 帧飘扬，建议 10 fps。
- 下排镂空纹样：每张 **48×48，1 格宽、1 格高**，静态。

长旌旗减少纹章占比和厚重边饰，留出空白旗面及透明摆动余量。横旗重绘为侧面旗面，同一块布的上下边缘随褶皱变化。挂杆和旗杆作为固定层，旗布使用内置 imagegen 绘制的逐帧形变；没有用整张图片平移冒充布料动画。

## 文件

`长旗/`、`横旗/` 中每个阵营均有一张横向八帧 PNG 和 8 张独立帧。横向八帧 PNG 宽均为 384，高分别为 96、48。按从左至右 0–7 循环播放，不追加重复首帧。

`图集/长旗_五方八帧.png` 为 384×480；`图集/横旗_五方八帧.png` 为 384×240。每行一个阵营，每列一帧。长旗每个阵营占两行 48px 格，中排横旗占一行。纹样合图复用 `../flags/five_emblems_48.png`（240×48）。帧尺寸与播放速度记录在 `图集/animations.json`。

源图、预览和打包脚本保留在文档材料目录，不作为 Godot 运行时资源导入。

## 导入

纹理过滤使用 Nearest，关闭 mipmaps。图集无间距和外边距，RGBA 透明背景，Alpha 为 0 或 255。动画必须以整件尺寸取帧；长旌旗若用两个 48px Tile 拼接，上下两格需同步帧号。所有帧使用相同原点，不要按每帧可见边界自动裁剪。碰撞按实际游戏需求单独设置。
