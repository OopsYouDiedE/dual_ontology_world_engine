# 公共研究厅 · 手绘场景素材

本目录保存用户确认的《饥荒：哈姆雷特》式公共研究厅整景与分类绘制源稿。采用粗细不均的墨线、交叉排线、低饱和块面和伪3D平面立牌。此前写实材质图不作为本场景渲染标准。

## 文件

| 文件 | 内容 | 视图 |
|---|---|---|
| `reference/research_hall_approved.png` | 用户已确认的整景，主门、棋桌、推理桌、公告墙、书柜、炉具、三旗与吊灯 | 透视整景 |
| `walls/wall_openings_sheet.png` | 两种墙板、拱形双门、高窗、柱、横饰条、捐建牌 | 平直正视 |
| `floor/floor_rug_topdown_sheet.png` | 方格地面、山海地毯、两种单砖样稿 | 俯视，无整景透视 |
| `hanging/banners_lamp_sheet.png` | 红金科学院旗、黑银学院旗、蓝银公会旗、吊灯 | 平面正视，灯具保留绘画体积 |
| `furniture/furniture_sheet.png` | 书柜、棋桌、椅子正背、推理桌、取暖炉、公告板、盆栽与文具 | 完整2D立牌，画内表现顶面和侧面 |

家具不拆成三维部件。单张图承载体积感，游戏层负责平面位置、朝向和排序。地面由游戏层投影；墙面图不预先画成倾斜侧墙。

## 当前可用范围

这些文件为分类素材板，尚未切成独立透明PNG，也没有制作 Godot 场景节点或修改现有场景引用。平底色属于展示背景，不应作为精灵的一部分导入。地板重复接缝、棋盘格数与棋子位置需要在正式制版时校准，不将生成图直接作为棋局规则数据。

公告板纸张留白，规则文字由游戏另行排版。捐建铭牌的小型狮形只表示贡献来源，正式文字另行排版。徽记小细节允许在当前草稿中概括，后续制版统一轮廓。

`walls/drafts/` 内是有烘焙棋盘底色的旧墙面稿，保留作绘制参考，不是透明贴图。

所有图像通过内置 image_gen 工具绘制，提示词见 `生成记录.md`。主目录内原有墙壁与瓷砖素材未被覆盖。
