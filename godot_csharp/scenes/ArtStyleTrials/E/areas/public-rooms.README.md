# 公共与学术区域 E 家具

`PublicRooms.gd` 提供 `handles(map_id)` 和 `furnish(kit: Node3D, entry: Dictionary)`。主装配器先创建房间地板及朝内墙体，再调用本模块；本模块替代该房间原来的逐项 `_prop` 循环，不应重复调用两者。

范围为 `living_hall`、`central_hall`、`lecture`、`archive`、`resonance`、`counterweight`。保持 `library-layouts.json` 内原家具锚点及房间尺寸。讲堂桌排有独立素木桌、长凳、纸张与墨水；抄写桌有纸张、墨水和单烛；封存架使用独立带黄铜标签的盒匣，图纸柜使用浅抽屉；配重室、调音架和中央传声柱各有专属模型。生活大厅沿用已有细致家具并按其空间增加两块地毯；盥洗室使用三盆洗漱台与管路热水罐。

所有装饰为真实三维几何和现有程序材质；没有 SVG、外墙或门。`vault_door` 条目显式跳过，留给由当前房间认知决定的门系统。纸上短线只表达书写的视觉密度，不增添可读取文字或证据。沉静室维持原始空家具清单。

这是美术装配模块，不修改碰撞、导航、Core 动作或人物知识。没有运行正式会话；最终渲染、家具遮挡及目标画面对照由主代理统一采集后记录。长凳是桌排的视觉组成，尚不构成坐姿或碰撞验收。

已观察主代理首批 10 张对应房间实机图：公告板离墙却没有支架、棋桌/钢琴附带凳与源清单座椅重复、洗衣桶封顶、浴缸缺脚及水龙头、配重横梁遮住滑轮。模块已补支架、移除助手附带重复凳、重建敞口洗衣桶、加浴缸脚与龙头并抬高横梁。修正后仍需主代理重新采集；没有用旧图宣称修正已通过。沉静室保持原始空家具状态。地板密度、墙窗和全房构图范围由主装配器统一处理。
