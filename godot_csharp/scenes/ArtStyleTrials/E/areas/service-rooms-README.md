# E 后勤、诊疗与温室家具

`ServiceRooms.gd` 提供 `static furnish(kit: Node3D, entry: Dictionary) -> void`。`kit` 使用 E `HallCraft` 和 `PublicHallE` 的建模接口，`entry` 使用 `library-layouts.json` 的家具名称、类型及原位置。调用该函数替代通用逐家具 `_prop` 循环；仅用于 `logistics`、`clinic`、`granary`、`greenhouse`。

厨房为铸铁六炉眼灶、独立高位烟罩、开放碗盘架、面板/擀杖/碗的工作桌及手泵；没有沙龙桌旗、书籍、花瓶或烛台。食堂两张 4.8 单位长桌各配八套餐具，沿已有长凳锚点提供 4.5 单位长凳。诊疗采用金属栏杆病床、素色床单、布屏、医用书桌、带空白标签的瓶架和双龙头水槽。粮仓为板缝木粮斗、布袋、木箍桶及木条箱。温室为带土层的长苗床、叶片/茎、育苗盆、工具和阀轮。

所有物件均为程序几何与共享材质，材质按木、布、土、陶、金属分别设置；不生成 SVG，不用低清素材放大。模型不产生剧情事实、库存数值、碰撞或人物动作；餐具只是美术陈设，不代表正式食物状态。没有新增门、门框、墙外面、房间边界或灯光；认知模型、已探索房间暗化及雾由主入口管理。

本模块只做家具，不处理房间地面/墙体材质（厨房与诊所仍需主入口选用相应地砖、墙砖，温室仍需玻璃结构）。未做正式 Core 测试或实机最终视觉验收；由主代理统一采集与对照。未将同名标签写入药瓶表面，避免凭空增加可读证据。

统一采集后的六图观察：服务区家具未见相互穿插或越出房间。按画面修正了高烟罩与灶台前后关系，在保留来源锚点的子节点内向灶台偏移 0.75 并补吊杆；粮面改为细小不规则分布谷粒，布袋压低并补垂绳，苗床增加两层错向叶片和轻微高差。上述修正等待主代理下一次统一采集。碗架、瓶架和叶片上的点状阴影需由公共阴影设置继续核查，不能归为纹样或视作已解决。
