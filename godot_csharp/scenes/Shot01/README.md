# 镜头01：学院中央厅

按 `artifacts/theme-film/scenes/shot-01.png` 拼装的可编辑视觉测试场景。项目主场景 Main2D 已实例化本场景，在 Godot 中按 F5 运行；单独打开 Shot01.tscn 后按 F6 也可运行。

地图32×20格，每格48px，完整画面1536×960；运行脚本为本场景设置同尺寸视口。地形采用学院 A2/A4 重绘版；四门、钟组、窗、雕像、地面罗盘、长凳、侦探背面和音乐家正面由独立图片组成。没有把分镜整图当作背景。家具、旗帜、角色和晨光可分别调整。

中央机械钟与广播喇叭、四座对称拱门、下方入口侦探、左上音乐家、两侧雕像和中央留白对应原分镜。晨光是静态窗格投影，不包含实时光照模拟。人物为静态姿态；本轮测试范围为画面，未加入移动、碰撞或通行交互。

## 旗帜

当前为美术修订第二版。九面旗保留既有五方徽记，重新绘制低饱和布面与细长垂挂轮廓，96×192组件位于 `ShareAsset/rpg2d/shot01/revision2/`，按悬挂位置调整显示比例。此版为静态旗帜，上一版八帧素材保留在 flags 目录但不再用于此场景。中央钟下及入口为黑底银纹学院旗；四门交替悬挂暗红金纹皇家科学院旗和深蓝银纹神秘学公会旗；两端为皇室与伯爵旗。这些旗表示既有权属身份，不将它们虚构为四院院旗。

第二版同时统一了研究桌、植物和烛台风格，减弱钟组亮金与地砖黑缝，补充陈设接触阴影及前景栏柱。建筑纵深、地面材质变化和晨光层次仍与分镜有差距。

## 验证

构建脚本 `res://tools/build_shot01.gd` 保存后重新加载检查838个地图格与9面旗，并通过实际Godot渲染保存1536×960画面。第二版以项目默认入口实际启动120帧，进程正常退出；验证使用 gl_compatibility，避免本环境 Vulkan shader 缓存写入限制。

记录位于 `artifacts/shot01-validation/`：shot01.png 为当前画面，shot01-before-review.png 为本轮修改前画面，validation.txt、revision2.log 和 revision2-main.log 为当前记录。shot01-flags-later.png 与 main-scene.log 保留上一版动画验证结果，不代表当前版本。日志中的系统证书读取提示来自运行环境。

生成入口会覆盖本场景及其派生组件。手工编辑前另存副本；运行游戏无需执行生成入口。补绘组件来源和提示词保存在 `ShareAsset/rpg2d/shot01/`。补绘稿经过最近邻整理到运行尺寸，未宣称为原生逐像素手绘。当前画面保留原分镜的主要构图，家具细节与照明仍有差异。
