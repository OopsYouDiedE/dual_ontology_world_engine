# 三维预制件与当前接线

81 个 `Maps3D/` 文件现已导出为包含相机、环境、空间网格及家具实例的实际节点树，可在 Godot 编辑器中查看组成，家具实例引用 `Generated/` 的共享 `.tscn`；但是它们仍属于待接线的地图美术资源，不能替代正式宿主的门禁、导航与认知投影。导出纹理改为引用原始资源并通过导入设置生成 mipmap，81 个场景文件合计约 22.45 MB；但是此数字只是场景文件大小，不包含引用素材，也不表示内存或帧率改善已经测量。

当前原生公共厅场景已通过正式 Godot 单场景 MCP 会话 `cf4d66971417147d` 检查，观察时宿主错误为空；但是全部地图与动态交互仍未验收。

本轮已将家具缓存导出为 `Generated/` 中的 101 个 `.tscn`，同一几何与配色键复用同一文件，`catalog.json` 保存可读标识映射；但是尚未经过该缓存的装饰、室外贴片与部分录制道具仍需逐项整理，当前数量不代表所有物体已迁移。

每个家具预制件包含 `InteractionSlots/Front`、`Back` 和 `ContactTarget`，站位在几何包围范围外保留 0.45 米距离，并声明 0.3 米净空半径，碰撞采用合并后的网格三角面与单一静态刚体；但是这些站位是几何候选，房间墙体、相邻家具、角色预约和动作权限仍须由正式宿主验证。坐姿位置、手部接触与全部通道尚未逐项验收。

`InteractiveProp.play_visual` 仅在人物距离站位不超过 0.15 米、动画存在且非循环时播放，并在实际动画结束后发出 `visual_completed`；但是该信号是视觉回执，不直接修改 Core 状态。宿主应完成走位、预约与权限校验后调用；但是本轮尚未把正式会话交互替换为该接口。

人物按用户最新要求恢复原有 E 外观，临时分段关节、动作脚本及 16 个生成角色文件已逐文件移除；但是完整连续网格与蒙皮人物仍在筛选，角色动作与物体接触尚未验收。

`tools/ExportWorldPrefabs.gd` 是长期保留的素材制作工具，从现有造型生成家具和 `Maps3D/` 场景入口；但是它不属于测试入口，重新导出会覆盖生成文件，手工修改应先回到对应造型源或另存人工预制件。工具仅逐文件删除旧目录清单中失效的家具资源；但是任何递归删除均禁止。

地图场景入口共 81 个，包含现有 64 个室内空间、6 个室外区、6 个录制布景和5个总览；但是入口覆盖不等于第一、二章正式三维游戏完成，室外仍有贴片、正式宿主仍以二维运动接线。

本轮 C# 编译成功，正式 Godot 单场景会话 `88736eff313e4e64` 已检查公共厅入口，宿主错误为空；但是尚未完成全部地图、角色动作与导航验收。无界面素材导出结束时出现 Godot Dummy 渲染资源释放警告，额外清理诊断曾触发原生崩溃，相关诊断代码已撤回；但是不能把生成文件成功当作导出过程完全无异常。
