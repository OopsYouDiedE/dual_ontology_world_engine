# 第二章室外 E 资源

`Outdoors.build(kit, id)` 为当前已创建的 `kit.content_root` 装配一个区域，返回 `size`、`camera_size`、`camera_target`、`camera_position`、各表现类型实例数及来源。允许 ID 为 `campus_nw`、`campus_n`、`campus_ne`、`campus_sw`、`campus_s`、`harbor`。调用方负责相机、环境、当前区域生命周期与认知可见性；本组件不推进世界、不改变碰撞或通路，不实现门模型。

## 保留数据与新几何

布局来自现役六个地图 TSCN：纹理、物件脚线、显式二维碰撞矩形。源投影为 24px/场景单位，提取器保持该比例。每区背景 PNG 的实际画布尺寸作为地表大小；合同的可行走边界不因地表画布的补齐像素而改变。

仅当建筑原图脚点的 X 和落地 Y 与碰撞矩形中心及南边界相差不超过一个源像素，且碰撞宽度不超过原图宽度时，采用该矩形重建真实三维建筑。高度沿用 `chapter2_art/outdoor.py` 既有模型参数；墙面、基座、角石、窗框、玻璃、檐口、山墙屋顶和部分烟囱为新建几何。窗户不构造新的可通行入口。植被继续使用原位置，体量以保留原图的像素范围为视觉参考，重建树干、树冠及浅色绣球花簇；这不宣称恢复原来的树木实体模型。

源 `CampusSite` 目录已缺失，不能完整恢复全部原模型。中央厅圆顶、复杂门楼、亭廊和低墙等无法与单矩形确认对应的物件保留原 PNG，以 `retained-raster-not-3d` 标记，不能称为新三维成品。原地面 PNG 保留道路、海岸、地形与原烘焙阴影；新建筑和植被关闭动态投影，避免同处双重阴影。这是一套保留已知布局的混合资产库，不是完整真实三维地形重建。

## 重建与依赖

`python mcp/art_style_trials/e_outdoors/extract.py` 只读取现役地图、PNG 尺寸和既有模型参数，生成 `outdoors-data.json` 与 `outdoors-resources.gd`。没有调用旧光栅美术生成器、SVG 或减色转换器。资源清单中的静态 `res://` 字符串使现有闭包复制器收集原 PNG；游戏运行只缓存并加载实际需要的纹理。

提取记录地图与高度参数源 SHA-256。主代理统一进行实际渲染核对，尤其检查新几何与原图混合时的脚点、遮挡、明暗和远景完整性；数据成功生成本身不是视觉验收。

## 本轮实机观察与修正

已查看统一采集的六张 `artifacts/style-e/library-render/outdoor--*.png`。道路、海岸、围墙与物件脚线未见整体平移；新树冠与原有尖柏混合，形状和材质密度仍不统一。复杂原图建筑保留的瓦片与石块细节明显高于新建筑，不能称为全区域美术完成。

首次实机发现新建筑的屋顶斜面遭背面剔除，露出大片箱体顶部。现已反转屋顶三角形绕序、显式设置外法线，并为新屋顶加入按场景尺度连续采样的交错瓦片 Shader。该修正需要下一次统一采集确认；本模块没有自行重跑采集。屋顶纹理来自程序 Shader，不使用 SVG。
