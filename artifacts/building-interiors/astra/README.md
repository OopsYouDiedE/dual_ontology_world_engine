# 建筑室内候选图册

所有逐室分配、平面尺寸及门窗位置是独立候选，未写入设计规范，未改游戏或外部模型。图像先经内置 image_gen 生成并实际审看，随后才制作确定绘图。透视图不能精确量测；图册尺寸是为可建模性提出的数值，不是从图像反推的事实。

主楼外壳采用主代理提供的现有五翼纯几何：南76×12、西12×36、东12×30、北52×12、中联12×24米。局部地下与四层边界按既有模型。图纸使用旋转前的本地主轴坐标；礼仪北轴对应真北顺时针5.73°。未修改外部校园。

`index.html` 为持续更新浏览入口。`COVERAGE.csv` 是全部实例逐层工作清单。`PROMPTS.md` 保存生成提示词及来源。图纸中的房间、门窗、楼梯为候选；仅 R01–R16 是保留的内容房号，其余前缀编号是图纸索引。所有承重、疏散、设备、防水均为方案意图，未经工程验证。

不运行游戏构建、流程回归或正式会话；图册不是游戏验收。四馆馆名和旧模型 R1–R4 对应待外部布局任务确认，不默认为既定方位。

绘图复核中：正门双气闸已经调整为北外墙连续入口；主梯S1全层x17..23，水窖及名录库随之分隔；人物检修梯M1独立于餐梯，5×8m候选双跑。5.8m高差采用34级（每级约170.6mm），每跑17级、16个280mm踏步=4.48m，加1.5m平台可容于8m长度。每跑净宽1.5m，两跑及间隔/墙厚容于5m宽；洞口与栏杆仍需工程深化。
