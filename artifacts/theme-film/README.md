# The Unfallen Duet：角色与主题曲分镜

本目录存放本轮角色像素设计、乐谱分析和主题曲镜头首帧。

## 文件入口

- 当前角色：[32×48正面站立帧](../../godot_csharp/ShareAsset/Images/characters/README-zh.md)。旧角色总图与提示词副本已删除，展示页直接读取唯一新资源。
- `scenes/`：逐镜头独立关键帧，保留用户原编号；没有镜头11。
- `scene-direction-zh.md`：统一美术规范及25个镜头的首帧内容。
- `music-analysis-zh.md`：基于MSCX音符与谱面标记的分析。
- `measure-timing.csv`：逐小节时间，分别列出音乐从0秒开始及外加5秒前导的时间。
- `score-events.json`、`analyze_score.py`：可复核的谱面提取与分析脚本。

## 交付边界

图片使用内置imagegen制作，完整提示词随对应图片保存。48px指地图格子单位；生成图片属于美术设计母版，不能仅凭像素外观视为已经通过48px网格验收的运行时资源。没有修改原始乐谱与人物参考图。

镜头只画一个关键状态。失控与救场、重新推演与重返现实、反制与切黑分别绘制第一个状态，不把多个时刻拼入同一画面。

谱面分析与配器评价来自文件阅读，并非音频试听或录音音色评价。用户提供的数字谱缺少完整节奏、调号与部分八度信息；相关不确定处在报告中保留。
