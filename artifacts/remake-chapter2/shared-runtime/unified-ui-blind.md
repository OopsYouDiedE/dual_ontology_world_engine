## 第一章轨迹与体验

1. 自然阅读 R-05 初醒心声。使用 Space / Enter 或“继续”推进；展开中的文字与完成后的继续按钮可辨认。初醒的硬床、灯油、上船片段与外衣让身份和当前处境足够清楚。
2. seq 4—6 从对白打开回看，滚轮后返回，当前对白保持。seq 16 打开 Q 行动菜单，只有回看与返回现场；通过菜单打开回看，seq 18 对更长记录滚动后看到完整末尾，H 返回现场。
3. 点击附近衣架，走近后出现“侦探的外衣口袋”检视卡：图像、叙述、来源、返回现场分层清楚。Escape 关闭成功。地毯给予底部短句反馈。
4. 点击可见书架并走近，出现“架上的无尘方框”检视卡，同时底部心声仍在。没有遮住关键按钮。选择“请同伴比手”，自然读到四人手都比半枚手印宽的比较过程。结束后回到原检视卡，按钮置灰并出现结果，最后返回现场。

此次推理来自玩家所见的书架灰尘与手印比较，没有预写答案。进展由直接交互获得，未出现为了拿反馈而反复重做一整段的要求。靠近物件的结果异步出现，点击的确认截图有时仍是行走画面，后续截图才呈现卡片；这容易让玩家短暂再点一次，但本轮没有形成阻塞。

## 第二章轨迹与体验

1. 开场先叙述“第1日傍晚”，HUD 是第2日晨，初读有短暂时间疑问；后续自然读到“第2日清晨，铜口召集全体到中央厅”即理解为昨日回顾，没有持续理解阻碍。
2. 对白回看与 H 返回使用同样的位置、颜色与方式。随后读规则和广播说明。长对白在页末把“誓约庭”拆成“誓约”与下一页“庭决定名录库归谁、怎么开”，且回看中也分成两个同名发言段，破坏词语连续性但未阻止理解（seq 9—11、32—33）。
3. Tab 打开笔记本，人物分组、最后位置、当前时间可读，返回现场按钮成功。滚轮对当前尚未溢出的笔记没有视觉变化，符合内容长度。
4. Q 打开长行动菜单，滚轮后下部帮助/回看/命令入口可以看到，固定返回现场仍可用。帮助面板内容多但滚动有效，标题和底部关闭按钮稳定，Escape 返回成功。没有仅靠列表中裁剪外的 controls 点击隐藏选项。
5. R 显示“还没有可以重演的夜。”，但面板标题沿用了先前查看的“帮助”（seq 25）。未解锁说明清楚；标题与操作不对应，是本轮确认的小问题。关闭成功，未为了解锁而推进整章。
6. 点击附近茉拉得到人物行动菜单，含提问、请托、同去、讲规矩、笔记等；菜单说明行动占时段。选择“问茉拉知道什么”后先显示“推演中…”，后显示“人物正在行动…”及人物走入/交谈短句。约20秒后恢复底部对白。期间 H 没有打开回看，HUD 仍显示 H 提示；这是一段有持续更新信息的输入锁定，未观察到死锁。
7. 恢复的对白先给会合关系、巡夜报告及广播，不立即给所选茉拉的回答。本轮读到名录库夜间广播后按任务范围结束；未确认提问回答最终呈现，记录为未覆盖，不认定丢失。

## 局部比较结果与限制

共同对白、回看、米色正文面板、暗化背景、右下返回按钮的视觉与操作习惯一致。第一章附近检视采用图像/文字/来源卡，第二章笔记与帮助采用滚动正文；局部均未出现文字明显被按钮遮盖、无法关闭、返回丢失当前页或输入确认超时。

第二章比第一章信息和选项密度高，帮助存在较长的命令表，需要读滚动内容；人物名字在场景内较小，依靠菜单后名字易辨认。第二章一次行动后的自动人物表现约20秒且不能打开回看，对节奏有实际影响。该观察不是帧率指标；没有采集 FPS，不能据此宣称整体不卡顿。视觉观察未见冻结；每次输入均有会话确认，自动行动有提示且最终恢复。

本轮可感知的统一 UI 优点是两章对白回看和关闭方式保持一致，第二章长菜单与帮助可滚动，第一章检视结果与已执行按钮置灰明确。不掌握此前版本，不作“比旧版改善”的事实断言。

应修正 R 未解锁反馈沿用“帮助”标题；建议以后避免对白分页在专名中间切断，并让人物行动期间的可用快捷键提示反映锁定状态。这三点均来自本轮可见信息，无源码推断。

未覆盖：第一章后续案情、笔记/重演等未在局部自然解锁功能；第二章真实夜间重演、假设选择、跨日剧情、任务承诺与完整提问结果、对质/投票；两章完整体验时长与通关。没有把自动状态推进或这轮短局部比较当作完整游玩验收。
