## 玩家体验与具体问题

### 1. 首次行动的反馈延迟显著，误以为卡住

证据：`0022-input.png` 后至 `0027-snapshot.png` 只见人物轮流进出和动作字幕；`0024-input.png` 的 Tab、`0026-input.png` 的 H 均未打开笔记/回看。状态读取显示 command_running=false，但玩家画面没有说明为何不能操作。约70秒后才进入集中对白，茉拉的答案直到 `0046-snapshot.png` 才出现。

这不是已证实的永久卡死，但反馈等待非常长。询问一句话之后，先看大量人物演出，再听公共集合和采样换药信息，才听自己问的答案，玩家难以判断哪一段是自己的行动后果。建议演出期间显示阶段与操作状态，并尽快给出玩家所选行动的直接反馈；需要保留的群体行动应让观察目的更明确。

### 2. 行动菜单下半部被截掉

证据：`0018-input.png`。屏幕上“查看：同行”只显示上半行，返回按钮占据其下方；状态控件列表中的“查看：证物”“查看：物件”“查看：帮助”“输入命令”在实际截图中不可见。本轮没有利用这些不可见控件 ID 点选它们。

玩家看到开场“输入帮助查看命令”，却没有立即可见的输入入口。菜单需要可辨认的滚动入口或适应高度的布局，返回按钮不能覆盖内容。

### 3. 人物识别负担较高

中央厅像素人物、家具和走动方向可辨认，点击人物能走近并打开其菜单，动作有变化。初次画面一次引入十五个名字，镜头只呈现其中一部分，名字颜色和背景接近，像素文字也较小。人际笔记可查组别，但只有最后位置，尚不足以帮助记住谁是谁。人物菜单每个人显示同样多的操作，当前能做什么不够突出。

### 4. 有推理线索，但本轮尚未形成可检验推断

广播中的白天取回与夜间勿应形成明确的风险；茉拉转述时标注消息来自伊莲娜、赛尔玛，帮助区分亲见与传闻；回避行为给出人际裂痕。这些线索有吸引力。本轮只消耗一个时段，尚未进入讲堂/名录库，也未实验规则、改变关系或到第7日，因此不能评价完整推理闭环和结局。

### 5. 重复与节奏

“采源质样本”“脚踝换药”先作为本人报告出现，之后又由茉拉完整转述。来源标注有用，但多页继续操作降低新信息密度。大部分本轮时间花在开场和第一次询问的演出/对白，只有一次实质行动选择；不能将这段时长当成足够的深度游玩验收。
