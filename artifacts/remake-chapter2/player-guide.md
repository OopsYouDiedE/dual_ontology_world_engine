# 《安眠者有福》第二章《第十一课》文字原型：玩家手册

这份手册只讲怎么启动、有哪些命令、界面上各栏是什么意思。它不讲剧情答案，不讲人物的想法，也不推荐打法。你扮演侦探，和另外十五名学员一起在学园里过五天；第 7 日，大家要议定名录库怎么办。

---

## 1. 启动

需要 .NET 8 SDK。在仓库根目录下执行：

```powershell
cd godot_csharp/scenes/Chapter2/Prototype
dotnet build -c Release
dotnet bin/Release/net8.0/Chapter2Prototype.dll play
```

之后在提示符下一行输入一条命令，按回车。

也可以把命令预先写进一个文本文件，一行一条，`#` 开头的行会被忽略：

```powershell
dotnet bin/Release/net8.0/Chapter2Prototype.dll play 我的命令.txt
```

文件读完游戏就停止。

---

## 2. 时间怎么走

- 游戏从第 2 日清晨开始，到第 6 日夜里结束。第 7 日是名录库之议，你会被问支持哪个方案。
- 每天分六个时段：清晨、上午、午间、下午、傍晚、夜里。
- 白天每个时段只能做一件“占时段”的事。做完，时间就走到下一个时段。
- 夜里只能“睡”或“守夜 某地”。
- 查看类的命令不占时段，随时可用，例如“状态”“笔记”“规矩”“清晨”“重演”。
- 第 4 日清晨是中央厅的公开对质，这个时段只能输入“对质”。
- 口粮在午间和傍晚的配给台领，一天一份。一整天没吃上，第二天下午就什么也做不了。
- 命令没看懂、写错、或者现在不能做，都不会消耗时段。界面会告诉你哪里不对。

## 3. 命令

人名和地点都写中文。“帮助”会随时列出全部命令。

### 3.1 不占时段

| 命令 | 作用 |
| :--- | :--- |
| `帮助` | 列出命令 |
| `状态` | 你的处境：在哪里、饿不饿、学过哪些课、答应过别人什么、打过的赌 |
| `笔记 [某人]` | 人际笔记，见第 4.6 节。不写人名就是所有人的简表 |
| `规矩` | 你知道的规矩，以及你给它们起的称呼（甲、乙、丙……） |
| `传播 [称呼]` | 你写的规矩传到了谁，见第 4.7 节 |
| `清晨 [第N夜]` | 某一夜之后留下的痕迹，默认昨夜，见第 4.4 节 |
| `重演 …` | 对某一夜做假设重演，见第 4.5 节 |
| `消息` | 你听到过的消息，带序号 |
| `公告` | 你看过的公告板上贴着什么 |
| `物件` | 能细看的东西和地点 |
| `同行` | 你见过谁常和谁在一处 |
| `拼规矩` | 拼规矩的五格选项 |
| `打赌 某人 谁 何处 [称呼]` | 和身边的某人打赌“今晚某人会去某处”。说中了，他认你写的那条规矩。每天一次 |

### 3.2 占一个时段（白天）

| 命令 | 作用 |
| :--- | :--- |
| `歇` | 什么也不做 |
| `上课 [话题 精确/含糊]` | 去讲堂上课（上午）。课后可以就一个话题提问，例：`上课 唤名 精确`；不写话题就只听课。话题写错时界面会列出可选话题 |
| `领粮` | 去配给台领口粮 |
| `查 物件或地点` | 细看一处。同一区域里的几处痕迹会一并看到。例：`查 后勤院`、`查 碗` |
| `同去 某人 物件或地点` | 请某人和你一起去看 |
| `请 某人 事` | 请人做事。可请的事：开粮、煮粥、照看病人、修门闩、修温室、上课、领粮、补记台账、挑水、来中央厅、清点、夜巡、守名录库 |
| `问 某人` | 当面问他知道什么。他只说自己看见、听见的 |
| `交钥匙 持钥人 交给谁` | 请拿着粮仓钥匙的人把钥匙交给另一个人 |
| `转告 某人 消息序号` | 把一条消息告诉他，序号见“消息” |
| `讲 某人 [五格]` | 当面对他讲一条规矩，见第 4.3 节 |
| `贴 地点 [五格]` | 把一条规矩贴到某处的公告板 |
| `修温室 甲 乙` | 请两个人下午来温室，一起修 |
| `开库 甲 乙 丙 …` | 请几个人来名录库前厅试开那道门 |
| `帮 某人` | 帮他干一个时段的活，或兑现答应过他的事 |
| `分粮 某人` | 把你今天的口粮给他 |
| `调停` | 第 2 日午间，调停配给台前的争执 |
| `拓碑 [某人]` | 去誓约庭拓印石碑，可以请人同去 |
| `片面告知 某人 关于谁` | 只对他说一半实话。这件事会被记下 |
| `对质` | 第 4 日清晨的公开对质，见第 4.8 节 |
| `重开对质` | 第 4 日以后，把人请回中央厅再对一次，见第 4.8 节 |

### 3.3 夜里

| 命令 | 作用 |
| :--- | :--- |
| `睡` | 睡下 |
| `守夜 地点` | 守在某处一夜，只看得见身影、听得见动静 |

**地点：** 中央厅、讲堂、后勤院、诊疗所、温室、名录库前厅（可简写“前厅”）、誓约庭、生活翼、文契寝区、星仪寝区、后勤寝区。

## 4. 界面上的东西

### 4.1 每个时段的开头和结尾

```
【第3日 · 上午】你在后勤院。
> （你输入的命令）
  （这个时段里你看到、听到的事）
```

时段里出现的几类内容：

| 内容 | 含义 |
| :--- | :--- |
| `【广播】……` | 学园里人人都听得到的广播 |
| `某某说：……` | 别人转述给你的消息。转述可能走样，括号里有时会写“据某某说”。几个人说同一句话时合成一行 |
| `你看见：……` | 和你同在一处的人这个时段做了什么。不在你身边的人做的事，不会出现在这里 |
| `某某在饭桌上说：“……”` | 饭点时，有人顺口复述了某一方对名录库的说法 |
| `某某：“某某跟我说过你那条——「……」。”` | 有人告诉你，你写的规矩是从谁那里传到他耳朵里的，以及他认不认。后面括号写着你给这条规矩的称呼 |
| `你看见某某把你那条……讲给某某听` | 你亲眼看见有人在转述你的规矩 |

### 4.2 规矩的称呼

- 你第一次知道一条规矩时，它会得到一个称呼：甲、乙、丙……按先后排。不论是你自己写的、在板上读到的，还是听人说起的，都按这个顺序。
- “规矩”命令列出所有称呼。
- “重演”“打赌”“传播”里引用规矩，写称呼即可，也可以写规矩里一段独有的文字。

### 4.3 拼一条规矩（五格）

每条规矩由五格组成：

| 格 | 问的是 |
| :--- | :--- |
| 主语 | 谁来做 |
| 条件 | 什么时候 |
| 行为 | 做什么 |
| 例外 | 什么情况不算 |
| 记账 | 怎么留记录 |

两种写法：

1. **一次写完。** 每格写选项文字或序号，用空格隔开：

   ```
   讲 某人 值守者 有人急病时 取一份口粮 次日补记者不算私取 记入台账
   ```

2. **一格一格选。** 只写 `讲 某人` 或 `贴 地点`，界面会逐格列出选项。写“算了”放弃，最后回答“是”才说出口。

主语格也可以直接写一个人名。“拼规矩”列出所有选项。拼好后界面回显整句：`拼成：「……」`。

### 4.4 清晨与痕迹

每天清晨，界面会列出“昨夜之后，这些地方有了变化”，但只说地点，不说是什么变化。如果前一天你得知了自己的规矩在传播，这里也会另起一行列出。

“清晨”命令显示你对那一夜实际读到的内容：

| 显示 | 含义 |
| :--- | :--- |
| `· ……` | 你细看过、守过、问过的地方，写的是全貌 |
| `· ……（路过时一眼看到的；细看才知全貌）` | 你只是之后路过，只记下了明显的变化 |
| `有变化、你还没去看的地方：……` | 只有地点，没有内容 |

痕迹不会随日子消失，除非有人去清理。清理本身也会留下痕迹。

### 4.5 重演

重演是假设某一夜某些人心里或行动上不一样，把那一夜重放一遍，再和你读到的痕迹对照。

- 重演不占时段，也不改变现实。
- 它从那一天的清晨开始重放，你自己当天做过的事也算在里面。

写法：

| 写法 | 作用 |
| :--- | :--- |
| `重演` | 列出可以假设的项目，带序号。项目由“你知道的规矩 × 可能认了它的人”和“某人那一夜在不在某处”组成，并附上那一夜出现过的身量 |
| `重演 1 4` | 选其中几项（最多三项） |
| `重演 某人 认 甲` / `重演 某人 不认 甲` | 假设他认或不认某条规矩 |
| `重演 某人 在 后勤院` / `重演 某人 不在 后勤院` | 假设他那一夜在或不在某处 |
| `重演 第3夜 …` | 重演更早的某一夜 |

结果里的各行：

| 行 | 含义 |
| :--- | :--- |
| `墨影·某人：……　心声：“……”` | 被你假设的那个人在重演里做了什么，以及他自己的理由 |
| `墨影：一个……身影去了……` | 其他人，只有身影 |
| `吻合：……` | 这一处重演和你读到的一样 |
| `冲突：……重演是「……」，现实是「……」` | 这一处对不上 |
| `未查：……` | 那里有变化，但你还没去看，无法对照 |
| 最后一行 | 总结：有没有冲突、还有没有没去看的地方 |

### 4.6 人际笔记

“笔记 某人”把你亲见亲闻的东西分开记：

| 栏 | 记的是 |
| :--- | :--- |
| 规矩 | 他认了或没认你的哪条规矩，是当面说的，还是听谁转述、读板得知的 |
| 立场 | 他在饭桌上复述过谁的说法 |
| 同行 | 你见过他常和谁在一处 |
| 其他 | 你请他做事时他的态度、他当众说过的话、你和他的赌约 |
| 听说/看到 | 只在单看一个人时显示：你知道的、关于他的事 |

笔记只记你看到、听到的，可能不全，也可能有错。

### 4.7 传播

“传播”逐条列出你写过的规矩：

- 当面讲过谁，对方当时点没点头；
- 谁把它讲给了谁：标“你亲眼看见”的是你在场看到的，其余是对方亲口告诉你的。

你不知道的传播，不会出现在这里。

### 4.8 对质与重开对质

输入“对质”或“重开对质”后，界面列出几句陈述和几件证物，并进入一个小提示符：

| 输入 | 作用 |
| :--- | :--- |
| `陈述号 证物号` | 一句陈述配一件证物，例：`1 1`。可以写好几对 |
| `提规 [五格]` | 当众提出一条新规矩，五格的写法同第 4.3 节 |
| `共同` | 提议共同规则“公开指控须附可检查的材料” |
| `完` | 说完，开始对质 |

只有你手里真有、而且真能证明那句话的证物，才有说服力。

“重开对质”在第 4 日清晨以后的任一日可用，每天一次，要占一个时段。

### 4.9 名录库之议（第 7 日）

界面列出几个方案，每个后面写着是谁提出的。写“支持 方案号”或“不表态”。随后每个人表态，结果当场揭晓。

## 5. 小提示（只关于操作）

- 一个时段只做一件事。查看类命令随便用，不花时间。
- 饿着会少一个下午。
- 夜里守在哪里，第二天清晨就读得到哪里。
- 想知道规矩有没有传开，看“传播”和清晨那一行。想知道一个人到底向着谁，看他的“笔记”里“立场”一栏。
