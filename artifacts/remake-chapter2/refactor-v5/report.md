# 第二章宿主重构与双测试记录

本轮把第一章已有的完整界面与交互移入第二章，保留第二章原有地图、角色资源和 C# 世界推演。未改 Core、规则接受公式、回合调度、投票计算或机关判定。工作区原有的角色动画、第一章、主场景、对白主题以及音乐产物均保留。

## 直接复用与最小适配

- `Paper.gd`、`HintOverlay.gd`、`FieldNavigation.gd` 完整复制第一章文件，独立回归核对完整 SHA256 相同。
- `Chapter2Dialogue.tscn` 完整复制第一章对白场景，直接引用同一份 `StoryDialogue.gd`、对白主题、字体、声音与头像资源。
- 第二章场景复制第一章完整 `FieldUI` 节点与渐变资源；纸页、卡片、历史对白、提示、重演控制均沿用原实现。
- `ReplayManuscript.gd`、`ReplayStage.gd` 以完整原文件为起点，只适配第二章假设菜单、结果结构、房间切换和匿名墨影。第二章每次至多三项假设，原引擎决定行动；没有另写重演引擎。
- 行走使用原寻路实现与接近后交互流程，第二章现有地图碰撞体作为导航障碍来源。
- 开场与后续对白都取自真实 `ConsoleUI` 输出，宿主将这些原文分页交给原对白脚本；没有另写图形版剧情。重演文字与画面使用同一次 C# 推演的 `ReplayPresentation`。
- 状态读取只预览规矩称呼，不提前登记；打开规矩选择先执行真实“规矩”读取，避免宿主改变命名顺序。

## 针对盲玩反馈的修复

第二轮独立盲玩能够完成，但体验判定不合格。因此没有把通关当作验收通过。主代理只改已复现的可见问题：对质列出并接受已取得的证物；协商反馈区分帮过与仍未接受；温室区分当前在场者与下午动作，并合并完全重复的输出；侦探支持封闭时留在门外，不自动触物。

CLI 驱动记录真实输入与原始输出，不访问世界状态。`--input-ready` 在实际 `ReadLine` 前提供输入边界标记，驱动吞掉标记，等待下一边界后返回完整输出。Windows 状态文件读取重试仅针对实测的短暂 `PermissionError`，最多五次。

## 实际边界

第二章原型给出房间与动作记录，尚不提供逐家具的历史几何路径；墨影只在明确记录的房间出现，不从最终位置反推历史坐标。第一章结束状态导入、第三章完整存档，以及设计中尚未实现的言灵练习等机制不在本次宿主替换中新增，不能据此宣称整份设计已全部实现。
