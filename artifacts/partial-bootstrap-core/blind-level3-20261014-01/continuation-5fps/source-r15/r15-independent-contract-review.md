## 规划停止与证据范围

- 根层仍完整比较所有通过现有资格和时限检查的动作。`current_action` 只记录净正值的非移动候选，未替换最终 `best`。
- 有当前正值候选且生成了后继时，只有完整比较 depth=1 的全部 frontier 节点后才设置 `positive-current-after-successor-layer`。最终保留所有已比较路径中的最高分首步，可以是移动。
- 每层开始前仍以原预算检查整个 frontier 是否可展开。预算不足沿用 `incomplete-layer-budget`，不会进入该层正文，也不增加 `depth`；因此 `completed_layers` 不把未完成层算入。
- 深度不足及无可预测后继分别记录 `current-affordance-depth-limit` 与 `current-affordance-no-successor`。`root_best` 只在根层完成后写入；`best_after_successor_layer` 只在后继层完成后写入，未执行时保持空集合。
- 满足有限停止条件的 depth=1 仍评分，但不生成下一层 frontier；没有当前正值候选时沿原搜索逻辑运行。预算、深度上限、费用、资格和权威判定未在该差异中改变。
