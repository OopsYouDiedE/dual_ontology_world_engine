# 空间交互、运行时与房间舞台整批实现

来源：用户两份修改附件、2026-10-19的空间交互裁定、“先别验证，执行剩下全部优化”，以及随后明确批准人工轻量认知和阅读期NPC推进。

## 本批源码和资源

- 同房间WASD/鼠标路径由宿主执行，不提交DV、不扣游戏时间或动作数；近距热点及跨房间仍由已准入ID进入Prepare/真实执行/Complete。候选表留在后台，多选在物件旁显示。原生DV提供空间绑定、中文热点标题和本人认识范围内的人名。
- 人物碰撞包含其他人物，路径避让已占位置；接近点排除占用，鼠标路径受阻停止，不传送或移动旁人让路。随身选择也核对其self绑定。HUD框锚点限定在抬头栏，姓名栏不滚动，立绘下不重复姓名。
- 普通游玩事件在冻结前去掉审计专用的before/after大字段，不自动导出重复全量session.json。实际输入、可见信息、分段计时、可恢复存档继续保存，close-result标明策略。完整采集工具显式携带--dv-audit；独立逻辑输出默认仍为完整审计。
- 不能照附件假设无条件删除六类历史字段：正式因子证明仍读取inference心智前后、observation/listener_parse心智后态和factor_prune人物前态。这些实际计算依赖保留。发言预演的来源版本改用source_actor_revision小值，旧事件可回退读取原人物前态。
- 既有Record索引继续使用，小记录第四次文本键查询也可建立索引；冻结新节点时同时缓存值兼容64位哈希，引用相同或兼容哈希不同可短路，同哈希仍深比。存储身份哈希、精确数与浮点数语义保持区分。
- 人工玩家普通回合继续真实收闻、同处感知、基础推理、语用和话题处理，省去全量假说/论证及发言预测。实际成功付费replay后标记下一轮完整刷新。自主AI与NPC仍沿完整共同认知；这是用户批准的控制机制变化。
- 阅读期间从普通dv_next提前运行串行Prepare；仅远处且不进入当前房间的NPC可沿原执行器真实移动或执行并Complete。玩家输入、当前房间行动、新可见对白交给前台。当前阅读正文与HUD保持稳定，后续状态和对白按事件顺序排队，不伪造回执或提前授予玩家观察。
- 室内房间取景、柔和边缘收束、冷灰环境光、暖瓷白/淡玫瑰局部光、冷窗光与有限微尘接入RoomStage。使用实际装修配方生成灯光锚点；减少动态效果关闭微尘并取消缩放动画。普通灯光遵守专属色边界。
- 对白约65%宽度，透明立绘从左侧破框，加入低强度蚀刻滤镜、双线角花、纸面暗角和阴影。纸纹服从辅助设置。研习桌纸页、工作台包纸和长桌器皿细节从原生像素配方生成，保持原尺寸、锚点与碰撞范围。
- 交互按单调微秒记录输入、排队、Prepare、快照、现场执行、Complete、实际首帧与阅读结束；阅读期NPC另有起止标记。工具只读整理缺段，不补猜耗时。
