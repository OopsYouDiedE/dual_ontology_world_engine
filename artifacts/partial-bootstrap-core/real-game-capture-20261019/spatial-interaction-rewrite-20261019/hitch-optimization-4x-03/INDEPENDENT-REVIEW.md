# 独立审查：四倍速实机窗口 03

审查范围仅为本目录内的 `OPERATOR-NOTES.md`、运行与宿主会话记录、性能摘要及其关联 PNG。未读取设计文档、源码或旧试玩材料；未解码巨型 save/session 内容。截图抽查采用说明中列出的剧情对白、卧室/走廊转换、08号门前和末帧。

## 配置与窗口

`launch.json` 和 `run/run.json` 记录本次为新启动的 Godot 玩家会话，`--dv-speed=4.0`，实际时间倍率 4.0，捕获目标 240 秒、5 Hz，并启用 `--dv-audit`。`host-session/inputs.jsonl` 首行记录 `playback_speed: 4.0`、`physics_ticks_per_second: 240`、`max_physics_steps_per_frame: 32`。`result.json` 记录捕获起止为 240001 real_ms，游戏钟从 8:00 到 8:03（480 到 483 分钟）；这些记录支持本轮实际使用 4 倍速、240 Hz 物理 tick、每帧最多 32 步，覆盖约 240 秒的观察窗口。

捕获与封存关闭是两个时间点：`run/capture-close.json` 记捕获在 240001 ms 结束，日志与宿主归档在 244661 ms 完成，相差 4660 ms；归档错误为空。`host-session/close-result.json` 记 `complete: true`、完整审计轨迹、零未处理命令、无 pending action、无错误。宿主 stdout 的末尾仍显示会话在 8:03 处于 active 时由宿主关闭，故关闭完成表示证据封存流程结束，不代表剧情会话自行完成。

.NET CPU sampling 请求时长为 200 秒（`launch.json`、`profiler-stdout.log`），短于 240 秒捕获；`result.json` 也明确注明采样在原生宿主退出前停止、捕获末尾没有 managed profiling。该采样窗口不能代替整段捕获，也不能据此解释最后约 40 秒或归因原生/GPU工作。

## 实际可见行为

`run/input-events.jsonl` 中 14 组按下/释放记录与操作说明列出的已消费输入相符。检查的图像确认：床边 E 打开侦探对白（8:01）；连续 Enter 后回到卧室并显示“床 [E]”；A/D/S 输入使角色在卧室内移动并从门洞进入横向走廊；走廊中 A/W 让角色改变位置和朝向。08号门前向上及 E 后，所查帧没有显示进入房间、对白或可见交互反馈。末帧仍在走廊、角色背向镜头，游戏钟约 8:03。该窗口实际覆盖卧室床边对白、卧室移动及进入乙区走廊；没有到达其他房间，也没有解谜或章节交接证据。

说明中提到的一次写入路径错误没有产生请求。末尾 A 50 ms 请求没有出现在消费日志中，故未执行、效果未知。对门口 E 无反馈只能描述为截图中未见反馈，无法由当前证据判断门的交互规则或阻挡原因。截图是约 5 Hz 的离散采样，不能排除采样帧之间的卡顿或确定逐帧运动质量。

## 绘制间隔与证据边界

`frame-gaps.csv` 与 `hitches.json` 都保留了开局最大绘制间隔 **987.523 ms**，区间从 3.728555 秒到 4.716078 秒。该区间的互斥墙钟分类中 `view_build` 为 902.653 ms；其余包括认知、会话及采集时间。这个开局停顿是本窗口的实际问题，不能概括为全程无卡顿。它是墙钟阶段记录，不证明 CPU 根因，也不单独证明视图构建是根因。

独立从 CSV 以 `begin_us >= 5,000,000` 过滤后，5 秒之后的最大绘制间隔为 **63.471 ms**（起始于 5.123487 秒）；这是有限观测窗口中的最大实测值。不能用它抹去开局 987.523 ms 的间隔。5 秒后个别超过 50 ms 的间隔仍存在，且 CSV 中有未归因墙钟时间；本数据不足以称全程无卡顿或确定因果。

`run/keyframes.jsonl` 所列 21 个关键帧文件均在 `run/` 中找到；目录共保存 1,185 张 PNG。`png-pixel-review.json` 只对 5 张抽样图像做了 RGBA 像素哈希核对且匹配，不是全量 PNG 校验。关键剧情/操作图像和末帧已实际查看。捕获结束时最后保存帧为 `frame-000239919.png`，时间约 239.919 秒。

本次审查的结论限于这些配置记录、离散输入/画面和窗口内测量：游戏确实运行并接受了记录中的玩家输入；玩家走出卧室到达走廊，但未进入 08 号门；开局有明显长绘制间隔，之后观测到的最大绘制间隔较短；封存后台工作晚于捕获终点结束。它不构成全流程完成、无卡顿、根因确认或性能优化幅度的证明。
