## 自动追加的内容

RuntimeDiagnostics在正式宿主的frame_post_draw监测>=50ms绘制间隔，记录实际碰撞体所在房间的变化、初次进入视口的节点。视口包含不代表穿透遮挡可见或被玩家认出。采集器每约200ms追加live-timing；keyframes把新位置/间隔关联至随后实际PNG。这里的关键位置是实际房间变化，不等价于剧情达成；站点交互仍由实际行动/回执确定。

每条命令独立command_id，记录排队、开始、Prepare、Complete、快照和主线程交付；DV内部记录调度、目标刷新、认知和选择起止。引擎本体关闭时保存完整interaction-timing；在线副本由采集器消费。阶段回调不写DV世界/心智/事件。
