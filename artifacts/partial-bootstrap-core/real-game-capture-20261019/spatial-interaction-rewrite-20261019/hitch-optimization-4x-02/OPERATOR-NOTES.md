- 开始画面是一本书样式的标题页，中央有封面插画、标题和“开始阅读”等菜单项。点击屏幕坐标 (866, 537) 后进入卧室。进入时游戏时钟显示 8:00；画面底部出现“床 [E]”提示。
- 卧室可见床、地毯、衣柜、书桌椅、衣帽架及南侧出口。按 S 150 ms 后角色到房间下方，提示变成“风衣 [E]”。再按 S 180 ms 未观察到明显位移或场景变化。按 A 180 ms 后角色移至西南侧桌椅附近；按 D 90 ms 后移向房间中央偏右。按 S 150 ms 后进入横向走廊，游戏时钟显示 8:02。
- 走廊画面可见标号 05、06、07、08 的门洞。按 D 180 ms 后角色沿走廊向右移动，镜头随之滚动。按 A 120 ms 与 A 180 ms 后角色向左移动；按 D 80 ms 与 D 100 ms 后向右移动。短按 50 ms 的 D 也产生可见的小幅右移。移动中没有出现同伴或对话。

- 按 S 100 ms 与 150 ms 后，人物从走廊中央移到下方 07 门洞前，游戏时钟显示 8:04。该处按 E 后，截图仍显示走廊与 07 入口，没有进入新房间或出现文字提示。
