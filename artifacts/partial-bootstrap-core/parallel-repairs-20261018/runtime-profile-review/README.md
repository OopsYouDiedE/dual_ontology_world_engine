## Mechanism-only candidates for later implementation

1. `R.has_value`: for a frozen list containing only strings, cache an ordinal string-membership set by the frozen identity. Mutable lists may reuse such a set only through a valid Backbone. Preserve structural `same_value` fallback for mixed lists, numeric lists and records. This targets the current `dv_has` cost without changing decision calls or results. Test empty lists, duplicates, Unicode strings, failed lookup, mixed exact/floating numbers, nested structural values, and mutable-owner changes after a cached snapshot.
2. `R.record_with_many`: replace repeated `keys.Exists(same_value)` checks for string keys with an ordinal membership set, retaining original output order, duplicate-key update behavior, independent-copy semantics and fallback for non-string keys. The current implementation repeatedly scans all prior keys for every appended update. Test repeated source keys, repeated update keys, append order, absent keys, irregular records' first error, numeric key equality, nested alias mutation and unchanged evidence bytes.
3. `LinkParent`: it linearly scans weak parent lists for every attempted link. A weak parent-membership structure could avoid repeated scans when there are many live shared parents. This is a lower-confidence candidate because the DV profiler does not separately time LinkParent. It must retain propagation from child mutations through all live ancestors; do not skip invalidation merely because the child is already dirty, since newly registered ancestors can still own indexes. Verify nested snapshot/backbone invalidation and multiple independent mutable owners before considering it.

None of these candidates permits returning a frozen child where the current API promises a mutable owner branch. `ReadItem` deliberately thaws through that owner to preserve future mutation semantics. Removing that step from general record lookup is not an equivalent optimization.

## Snapshot and serialization boundary

`snapshot` preserves immutable full logical values with shared frozen branches. `copy_value` creates a distinct mutable root and lazily thaws descendants. `same_value` has a valid shared-Backbone identity shortcut but retains exact/floating semantic comparison; raw structural hashes cannot safely reject numeric equality. Memo reads snapshot keys and owners, return independent mutable copies of cached composite results, and keep frozen values privately. These contracts must survive any cache optimization.

`run_debug` executes full close and writes the entire trace through the existing JSON format. No snapshot suppression, budget increase, skipped cognition or alternative serialization format is proposed. Its final export currently rereads stdout after deriving text to find `debug_end`, and trims two text files by loading them whole; these are possible post-run memory/IO cleanups, but occur after the child finishes or times out and cannot explain progress stopping inside that child. They should not distract from current Runtime hot paths.

The profiler overwrites its own cumulative diagnostic sample intentionally. Copies sealed here preserve sampled bytes. This is separate from the production trace writer's non-overwrite guarantee and does not authorize overwriting original session evidence.
