修复第一章 refresh_until 只有声明却没有实际刷新调用的问题；临时规划视图根据本人已收到的信息刷新。门内操作与实际跨门分别记录。这是行为修复，与等价性能比较分开。

性能
固定同一内容与配置的 64 次实际行动，原版本 43.3509007 秒；复制优化后 22.6257407 秒；同一优化程序集使用默认四堆 server GC 后 6.893638 秒（原速度约 6.29 倍）。八堆试验 6.3666728 秒（约 6.81 倍）。完整 107887588 字节轨迹和原始输出 SHA-256 均一致。
保留全部人物、原行动/推演预算、判答、观察和事件快照。并行仅用于 GC，世界提交与人物决策仍按原顺序。
未达到十倍目标；此证据只覆盖被冻结的有限行动窗口，不代表当前改写内容的整局性能，也不证明 Godot 已启用该回收模式。关闭分层编译的试验变慢，未用于生产默认配置。
改动为合并连续独立字段更新、按更新路径复制、独立暂存事务及观察批次、已经独立构造的事件数据一次转交。相关合同同步 language_core 与 verification 的 AGENTS.md、DESIGN.md。
