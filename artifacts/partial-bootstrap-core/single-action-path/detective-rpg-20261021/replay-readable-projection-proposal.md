`30-session.dv:dvs_sim_compare` 已保存 feature、observation、prediction、result 与 observed_cells。`60-game.dv:dvg_replay` 已取本人付费 simulations，现有文字仅显示比对/矛盾数量。Godot `InvestigationUI.gd:open_manuscript/_supplied_texts` 只渲染 title/lines 等公开字段，因此追加可读行即可接入现有界面，不必改 30 的比较语义或 UI。

补丁修改 40 的 feature 声明，添加内容标签；新增内容白名单函数，对整个 feature 精确比较，禁止仅凭任意 label 字段公开。60 新增只读投影函数，给每个已显示假设追加以下文本：

- 「木楔上的烟灰：已取得对应观察；这项假设的推演与观察相容。」
- 「隔离门内闩：已取得对应观察；这项假设的推演与观察矛盾。」

逐项输出还保存 comparisons 元数据：title、text、result、model_event、source_refs（原假设 basis）和 observation_events（直接感知 dependency 的事件标识）。不把整个 feature、observed_cells、原始预测值或假设值递归输出。来源元数据不由现有 UI 当正文渲染。

## 防越界措施

1. 仅匹配 40 明确声明的七项 feature，完整结构连同公开标签相等；旧记录缺标签不猜测含义，不暴露内部 ID。
2. 每项必须有且仅有对应的 observed_cell；当次 cell 与当前本人 cell 均无争议、有正置信度，且完整 cell 一致。认识更新时即使仍同值但来源变化，也暂不公开旧比较，保持保守。
3. 必须存在本人已 seen 的直接 perception claim，引用对应观察，值与 cell 一致、trust > 0，且有来源事件。仅凭已知布尔值、推理结论、他人认识、初始值或回忆/听闻不公开为直接现场观察。
4. helper 只读 subject.mind 和本人 stored comparison，不读取 state.physical，不执行推演、不写世界/认识，不变更预算、费用、候选顺序或判答。
5. 保留原有 plan_complete 和旧记录状态提示。旧模型还能显示仍相同的单项观察关系，但文字明确来自旧推演，不当作当前整体假设已重新核对。
6. 不改 16 行展示上限、原有整体数量、原有假设标题或行动资格。未能公开任何单项时给出保守提示，缺项不被解读成成立。

## 能做到与仍然缺少的内容

能将“存在 N 个矛盾”定位为“本人已观察的哪条痕迹与这份推演冲突”，以供玩家决定重新检查已有线索；仅呈现已支付计算产生的三态关系。

不能解释冲突的具体因果、事件次序或数值差异：现有七项 feature 只是布尔预测，标签本身不是完整观察叙事。若要显示具体预测内容，必须另在内容声明中为每种可公开谓词/取值给出审核后的自然语言映射，继续绑定本人可知来源，不能通用 dump。

没有本人直接观察的项目完全不显示，因而暂不能列出“尚未调查的具体目标”。不把尚未知痕迹当作待查答案。回忆/听闻项目未纳入此次直接现场白名单；有需要应另定义来源措辞与授权范围。

第二章未找到独立的 replay feature 声明，本补丁未补设。一般单命题假设/未带公开标签的旧模型仍只有保守汇总。组合历史假设若只有内部候选编号标题，仍无法让玩家理解其完整可选内容；本补丁不擅自公开内部 variable_assignments 或 assumptions。原有 16 条上限及筛选顺序也可能使部分记录不在本页，此处不扩范围。

## 手动选择/组合假设接口的后续范围

以下仅为待设计核对的工程范围，尚未实施：

- 内容层声明本人可提出的命题槽、可选公开陈述、对应前提和来源；不把 hidden assumption 或权威变量值列成答案菜单。
- 会话层提供只读本人合法选项查询，以及正式假设选择/组合命令。提交时重新核对本人资格、来源、槽约束与组合条件；自由草稿不进入认识，不等同已采纳命题。
- 选择只生成带来源的待检验假设，沿现有 replay 正式行动报价、支付、Prepare/Complete 与计算预算执行；不能从 UI 免费建模或直接写 simulations。
- 结果以本轮真实 paid model_event 关联每个公开选项、比较和观察来源。预测、已观察事实、未知、过期结果分列；选择本身不授予答案、同伴采信或行动成果。
- UI 保存用户实际选择和可见内容，结果关联来源事件；恢复/关闭按现有二进制合同封存。不因这一接口扩大预算、设定或判答。
- 统一整合后先做必要工程检查，再在主代理授权的新会话中核对本人可知性与显示；UI 需要实际截图验收。不能用本报告代替行为或体验证据。
