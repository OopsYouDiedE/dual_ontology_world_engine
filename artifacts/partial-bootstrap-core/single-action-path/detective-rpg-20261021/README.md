- 接触失败保留尝试与费用，但不消耗“成功一次”的行动资格；仅人工重新接近可取得重试许可，自主主体不能无条件重复失败行动。
- 推演工作台接受玩家明确选择的假设或变量组合，初始不替玩家选择。原动作身份与完整假设封装经宿主传到 Session，再由 DV 重核与正式结算。人工单选仍使用原有付费剪枝、覆盖与证书边界，未扩大预算或模拟其他候选。
- 对比正文只投影本人的已付费结果及仍有效的亲自观察；未知不写作事实。恢复内容声明的认知策略，撤除会话中统一覆盖自主主体规划深度的设置。

- 合入其他 AI 的自然 DV/公式能力、连续门道、共享输入与手柄返回、标题资源准备及揭幕、界面和素材依赖。保留音乐提交 `9f434197`，没有接回第二条启动或执行链。
