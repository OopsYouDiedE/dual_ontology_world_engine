# 主代理设计核对

本报告仅由主代理维护。并行工程与独立审查 Agent 不读取设计正文；盲玩 Agent 不读取本报告、历史包、源码或答案。

依据为当前 `docs/design-standard.md` 的案件循环、空间接近、现场选择、重演手稿、人物独立认知及第一章相关正文；另只读比较 `512f058a8:docs/design-standard.md` 的 Core 前设计。当前用户指令和现设计优先，没有恢复旧 `.story` 执行器或另设第二条生产逻辑。

保留“问题—勘查—试验/协作—假设重演—对照补查—陈述”的循环。玩家明确选择假设，未知检视结果不作为预测中的既得事实。V6 的开放依据仍来自本人实际可知线索；开放前的彼此陌生仅为未查明的推演假设。个人偏好、不同主体采纳和公共结算继续由各自声明决定，未把自主人物统一成同一条正确路线。

本轮工程取舍包括：不放宽物证、模型证书、预算和答辩条件；不凭位置变化冒称观察；不把空候选工作当作已执行模型；不让重复预测任务再次领取同一证据收益；人工接近、过门取消与后续重试须保留真实输入和回执。开放地板边界按现有地图几何处理，没有重画隐藏门或替玩家选择目的地。

主代理保留了其他 AI 已合入的未来纲要有效正文，但未来第三至第六章和离岛执行合同不因此自动成为已实现或已验收能力。人物和结局的多样性仍是设计约束，本轮未验证所有视角与结局。

现设计没有给出连续会话模型余额耗尽后的恢复规则。已向用户请求裁定；在用户答复前保持现有总额及单次上限，不擅加休息、自动补充或新的数值。该问题与同条件算法提速分开，不用修改资源合同制造旧基线更快的结论。
