## E10有限采样的独立问题

现WorldView只取半径46、34.5的八方向点，并先用floor(point/16)查询walkable。旧静态布局中以下两个E10样本通过room与粗格：

- (368,548)，下方向整半径。
- (335.473088,534.526912)，左下整半径。

但二者连续脚位都在Sideboard s141膨胀矩形[333,513]..[435,550]内。格中心合法不能推出格内偏向家具的一点合法；FieldNavigation末尾追加真实destination，后续角色实际碰撞会受阻。搬ToolBench后此终点问题仍存在。

可执行空间中已存在(328,520)：距E10约43.86，真实prep、在半径内，且在s141膨胀左界333以外；它不在当前两圈八方向样本上。候选家具布局下该格从两起点均连通。正当修复是完整枚举现有半径内的合法格中心，再沿现有真实路径与collision执行；不扩大站点、不把到达room替代到达站点、不豁免Sideboard碰撞。若保留任意连续点候选，应另核连续脚位不在任何膨胀障碍中。
