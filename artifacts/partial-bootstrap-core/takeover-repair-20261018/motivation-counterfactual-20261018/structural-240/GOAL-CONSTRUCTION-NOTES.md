# Pure goal-declaration construction split

Implemented in chapter2/dialogue.dv and content.dv only. game/entry.dv is unchanged: there is no whole-goal-refresh guard or actor revision/count certificate. Original c2d dynamic qualification, c2_refresh_content_actions, safety freshness, c2_navigation_goals and c1n_known_future_wait_actor still execute through their existing call chain. Full refresh cost is not solved and no speedup is claimed.

c2d_row_goal caches only c1n_index_goal_window declaration assembly. Its immutable owner is the complete row, and key contains id plus the exact already-qualified when AST. That is the entire constructor input; case/owned/request/advice/safety/manual qualifications are still evaluated in the original order before the call. Row/source/room changes change the owner. Any new input added to this constructor must enter its owner/key. rt_memo_get returns an independent mutable root with existing frozen descendants, preserving caller ownership.

c2m_row_goal caches pure work/travel target assembly by complete row/id/when/completion/travel. Its caller still computes conditions and checks private completion each time; travel is requested only in the original unfinished branch. c2m_observation_goal_templates caches the final static evidence declarations by complete groups/id, and is first accessed only after the original dynamic motive-row loop. Existing c2 personal templates and c2d head/tail caches are preserved. Existing c2i_navigation_input covers its narrower investigation-navigation calculation only; this change does not enlarge that memo's dependency claim or skip local dynamic eligibility.

The new run-goal-construction-engineering.py and goal-construction-probe.dv are PREPARED, NOT EXECUTED. After central authorization, invoke the runner with --out <exclusive-new-directory>. It compares full current c2d/c2m outputs with preserved inline construction, and independently checks exact same-row/different-when/id, changed row, mutable condition, nested aliases and evidence-template owner separation. Existing actual-declaration fixtures cover manipulation permitted, empty actions, owner contexts equal/different; added synthetic private completion true/false fixtures verify the travel branch remains dynamic. These are engineering inputs, not occurred actions or game evidence. The runner preserves source fingerprints, stdout/stderr, full values, first concrete differences and incomplete/error states; no session opens or prepare/complete runs.

The source before each pure constructor is the same existing dynamic function; unknown/malformed dynamic qualifiers therefore retain the original chain. Cache operations freeze values using the existing Runtime ABI. Resource exhaustion and unsupported hostile CLR payloads are not a stronger error-contract promise. No build, probe or formal run has been performed by this subagent after editing.
