## 实际根因与改动

- Record已经具有冻结/可变哈希索引，copy_value也已经采用冻结底本和惰性独立分支，并非所有操作都线性扫描或全树复制。未盲目替换ABI为Dictionary或HAMT。
- 原快照驻留器的弱引用不会自动删除Dictionary键与Queue条目；每1024次公开snapshot仅扫一个桶，而且memo直接进入SnapshotValue绕过这项维护。新维护在Gen2后按有限预算覆盖旧桶，同时保留全部活身份；递归冻结和memo路径也能推进清扫。
- 结构比较复用数值兼容的结构指纹，仅提前排除不等结构。数值跨double/Rational表示仍保持原语义，碰撞回原顺序深比较；不把表示哈希当作逻辑相等。
- 原始DAG每帧新建本机SHA256上下文及前缀数组；现改为同一写入器复用上下文并按帧重置，前缀和结果用栈缓冲。摘要链、节点/事件顺序、Flush和partial边界保持。
- 旧JSON编码按history/simulations以及事件内world/adoptions等名称清空字段，违反现行完整性合同。本轮删除隐式裁剪，保留完整输入；其大小与耗时不能与被删减JSON作为同条件比较。正式窗口使用现有无损DAG，而非关闭快照。
