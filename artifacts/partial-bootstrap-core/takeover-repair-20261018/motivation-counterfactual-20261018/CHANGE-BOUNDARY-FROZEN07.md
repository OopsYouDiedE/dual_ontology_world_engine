# 冻结07修改边界

本轮沿冻结06的内容、预算、规划、执行和证据规则。仅采纳运行时常用数字文本不可变盒复用、冻结容器中新建浅查询临时成员指纹、结构相等内部原生Bool递归。原精确/浮点相等、负零、非法输入、引用短路、原顺序及可变别名合同不变。

未采纳read-fields候选：其额外惰性展开与收益尚未测定。也未采纳Snapshot sweep/ArrayPool候选。中性差分/微基准仅定位工程成本，不推算游戏耗时。

全部改动与文档完成后集中工程检查，随后冻结两个串行server GC4的180秒正式一级标准乙区窗口：默认JIT，以及显式DOTNET_TieredCompilation=0，使用同一formal-model prepare/complete。源指纹、实际配置、原始前缀/终态封存和五日/剧情达成分别记录；与冻结06共同投影按原顺序核对。未达到180秒五日要求时继续保留未完成结论。

run_debug同时记录继承或显式设置的DOTNET_Tiered/COMPlus_Tiered环境项。第二窗口只改变.NET即时编译分层设置，源码及游戏条件不变；实际共同投影与耗时范围分别核对，不预设收益。
