# 第一章与推理证据接线静态审读

日期：2026-10-18。依据：本轮工作区源码与主代理在本线程明确的实施边界。源码仍在整批修订中；本文记录审读时发现与交接情况，不代表冻结后的最终版本。

## 范围与执行边界

审读 `chapter1/content.dv`、`chapter1/opening.dv`，`session/10-subjective.dv` 的个人资格入口及其后续函数，`15-action-planning.dv`、`20-speech.dv`、`25-simulation.dv`，以及 `30-runner.dv` 的人工选项、选择和实际执行接线。为核对调用合同，只读了相应 Core 容器、观察和回应函数。

未读取设计文件或附件；未运行构建、语法检查、内容探针、游戏会话或测试。下述结论来自源码审读，未以实际轨迹验证。

## 已交主代理集中修复的具体缺口

### 同组替代项遗漏自己的正值资格

`10-subjective.dv` 的 `dvp_eligible_after_base` 对当前动作检查 `personal_choice.require_positive`，要求本人价值序中的首个非零净影响为正。同组替代项分支核对了 base、owner、norm、本人解释与 `personal_ready`，但没有重复检查替代项自己的 `require_positive`。

因此，一个自身应被正值门排除的替代项，仍可能因为相对另一个更差动作的序位更高，将该动作排除。当前动作和替代项应共用不递归的个人选择准入检查；完整同组比较不能相互递归调用。此问题已发主代理，并由其交给共同机制代理集中处理。本文未确认其后续修订状态。

### 完成后的匹配行为尚不足以证明建议影响

`30-runner.dv` 的 `dvs_dispatch_due` 在执行已经排队的动作之前排空收闻。`20-speech.dv` 随后可将人工建议记入 `pending_player_influences`。审读时，`dvs_complete_player_influences` 仅检查成功 Complete、匹配的动作 ID 和物理条件从非真变真，没有核对本次行动选择发生于建议的实际理解事件之后。

这使已经选好并排队的动作，也可能被刚在到期前理解的建议记为实际影响。应保留实际 source/parse、选择及执行事件的时序，且不能把纯粹的事后匹配写成已证明的选择因果。该问题已发主代理并交共同机制代理集中处理。本文未确认其后续修订状态。

人工建议的 `manipulation` 声明本身只进入追踪账本；审读到的四种建议没有直接改变目标主体的价值或效用输入。因此，即使相同动作后来真实发生，仍须分别说明“建议意图”“本人实际采纳或选择依据”和“匹配后果”。不能凭声明和先后发生就宣称建议已改变行为。

## 源码中可核对的边界

- 新问句的含意候选只沿实际发言、可听接收和理解入口进入主体。解释资格读取本人的 `interpretations` 和真实来源事件；新同组替代项也补了本人解释资格，缺少该解释的浅表态不应凭价值序阻塞当前调查。
- `withdrawal_evidence` 使用本人 mind 的条件、真值和输入单元。撤回不读取 physical 作为主体证据；正式问题、含意解释和历史事实仍须分列。该字段能记录来源输入，不证明整局中一定发生撤回。
- `manual_only` 在普通 AI 准入中被排除。`dvs_player_options`、`dvs_select_player`、`dvs_player_choice` 的 `manual_input=true` 只存在于临时资格视图，返回的持久状态仍使用原主体或原主体数组；审读中未发现该标志写回 AI 状态。
- 新增的沈鼎询问仍是具有实际资格与费用的自主动作。主代理已明确：本轮 manual-only 指新增人工建议选项，不要求整个询问链对 AI 的行动轨迹完全无影响，也不向主体注入宿主是否人工控制的全知条件。
- 模型上下文映射把未知单元写为 `dv_unknown()`，没有用默认数字填补。可能影响选项可行性、预测前提或价值读取的未知项仍能使回应不完整；选项平分将外层结果置为 unknown，调用链仅在外层 `detail.status == selected` 时应用选择桥，不能把内层暂选结果当作正式确定选择。
- 主代理已明确：首夜 `provisional-assent` 表达实际听到提议后本人选择的口头附和立场。它不作为接受案件错误事实或解释的证据，也不作为 physical 罪证。报告应保留这一区分。
- 主体行动的权威效果、观察、共鸣耦合及影响后果仍在 Complete 路径处理。候选、预测和人工选项本身没有调用这些完成记账函数。
