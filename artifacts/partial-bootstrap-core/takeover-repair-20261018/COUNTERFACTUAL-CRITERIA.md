# 反事实比较口径

依据：用户2026-10-18追加“完成设计文档中说的反事实测试”；现行设计规范第2节（双基线AI侦探），以及第一章各区内容段落。本文记录本任务的验收口径，不改设计目标。

八种配置为标准/愚蠢侦探分别置于乙、甲、丙、丁区。全部沿正式DV prepare/complete与章节扩展，以引擎侦探本人的认知和共同决策选择。各配置从全新会话开始，串行执行；不预写行动或答案，不在配置间修改源码。

每组记录以下实际证据及事件编号：

- 行动前本人收到的信息与来源、所选行动与目的、执行状态和后续观察；预测与真实效果分列。
- 乙区：实际证物检视、声路试验、四步答辩各自的接受/拒绝，以及实际出区；13:00为设计比较节点，不能按时刻代填结果。
- 甲、丙、丁区：材料核对、询问、本人回忆及收到的回答；辨认人物的部分答案与完整原因答复分别记录。完整原因依次为受命转移、伊莲娜示意关门、自体标定救治；作者侧事实不作为人物已知证据。
- 第二章：实际搭档协作、三案调查、粮仓开启、预留补记、取粮与台账、现场安全读数/停行及侵蚀后果。没有实际发生的分支不从设计表推算。
- 主观反事实：假设、假定、预测、模型比较、剪枝和论证的实际记录、来源与停止理由。模拟发生不等于论证成功，更不等于行动已经完成。

本轮为一级formal-model，无Godot几何、输入或画面结论。每组最多180秒工程执行窗口；构建和导出另记。窗口停止、五日时域、章末摘要、剧情达成与完整证据分别判断。源码冻结指纹只用于本轮版本定位，不重建历史保护基线，不作同条件速度比较。

本窗口未发生的节点按“本窗口未发生”记录；若超时使原始trace未封存，注明完整内部快照不足。缺少记录不解释为角色永远无法达成。比较围绕具体行为与设计差距，不使用通过数量、通过率或流程回归。
