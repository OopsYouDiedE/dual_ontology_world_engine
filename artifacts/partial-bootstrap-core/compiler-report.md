# DV 编译器自举实施记录

本轮实现全部位于 `language_core/`，现役 Core 与 Godot 未接入。新增通用计算启动子集编译器，其扫描、AST 解析、名称/作用域/调用元数检查与 C# 输出都在 `compiler/compiler.dv`。C# 启动编译器 C0 只负责产生第一代；C1 以后使用生成代码与最小数据/平台 ABI，运行程序集不依赖原 Kernel、Reader、Interpreter。

## 当前证据

最终自动判定为 `compiler-r4-auto/`，result.json 的 verdict 为 `bootstrap_compiler_self_hosted`；完整 DV 规格完成状态明确为 false。`sources.zip` 保留编译器、ABI、记录脚本和 C0 所需 Kernel/bootstrap 源文件原始字节；`sources.json` 是源指纹，`commands.json` 是真实命令与退出状态，工具链为 .NET SDK 8.0.400。`compiler-r3/` 是此前相同生成结果的验证，r4 自动重新执行整条链路并输出明确范围的机器判定。

C0 编译同一份 `compiler.dv` 得到 C1；C1 编译得到 C2；C2 编译得到 C3。各阶段均构建为独立 .NET 程序。C2/C3 生成 C# 的 SHA-256 均为：

```text
ac75e3068052e23caf5073ab2e026d04c3ffa88182dd78855afdd685db76ab8a
```

程序集指纹单独见 result.json，不要求含构建路径的程序集字节一致。固定点比较的是实际生成源码，没有对差异做删减或规范化。各阶段依赖清单只有生成项目本身；仍依赖 .NET 平台，不代表重写了 C# 编译器或操作系统。

C3 编译独立的递归求和与局部循环程序，实际输出 `65`。编译器源变体把目标类名改成 `DVChanged`，该变体经 C3 编译运行后，为新输入生成的目标类名也变成 `DVChanged`；说明实际编译算法受 DV 源变化控制。原始 U+0085、U+2028、U+2029 经编译、C# 构建与执行后文本保持原值。

未绑定名称、错误调用元数、重复函数、作用域外读取、非法转义、未闭合列表、未知宿主原语、占用 rt_ 函数前缀和局部遮蔽均记录了具体 DV 诊断，且没有写出目标文件。它们是给定输入的机制证据，不是完整语言正确性证明。

## 失败与修复

- `compiler-r1/` 完成了第一条自编译链路。新上下文审查 `compiler-review-r1/` 发现原始 Unicode 行分隔符被直接写入 C#，构建报 CS1010；DV 后端新增 cs_string 将这些字符转义后，重新从 C0 开始记录 compiler-r3。
- `compiler-r2/` 在工具链信息采集阶段停止：`dotnet --info` 尝试读取 Windows Service Control Manager，被当前权限拒绝。没有继续依赖这次失败记录。改用只读取 SDK 版本与运行时清单的命令后，在新目录 compiler-r3 重跑；未提升权限或变更系统服务。
- 最初编写 compiler.dv 时出现过 `28:42: Unexpected closing parenthesis`，在进入 r1 冻结验证前修正；该错误来自开发期命令输出，不冒称封存原始运行记录。

## 完成范围与缺口

完成的是**启动子集编译器的真实编译自举**。动态 Number/Text/Bool/List、普通命名函数、递归、局部绑定/赋值、分支和循环足以表达该编译器；目标程序执行 C# 函数，不解释 DV AST。

完整静态类型、能力检查、目标无关 IR、模块、泛型、闭包和领域语法仍待实现。当前检查与 C# 生成共用遍历，不能将目标文本称作目标无关 IR；类型错误在运行时发现。现有 `bootstrap/*.dv` 的解释语法尚未统一到新编译子集，全部推演核心编译迁移尚未完成。上述缺口已经在语言 README、DESIGN 和 AGENTS 同步说明，不以固定点缩减最终目标。

用户明确要求停止独立复评后，已中断复评 Agent。`compiler-review-r3/` 只保存停止前产生的片段，不作为完成审评或本轮验收前提；最终结论由上述自动化条件的真实执行直接给出。原 compiler-review-r1 是停止指令之前已经完成的历史缺陷记录。主代理对照设计边界：本轮没有新增剧情内容、世界规则、人物策略或改变现役推演机制。

本轮仅工程排错和编译器机制验证；一级剧情与引擎、二级 UI、三级游戏本体验收均未执行，人物行为与游玩效果未验证。没有运行 flow 系列或统一流程回归。
