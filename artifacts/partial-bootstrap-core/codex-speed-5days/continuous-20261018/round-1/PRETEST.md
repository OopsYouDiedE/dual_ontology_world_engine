# 第1轮集中修订
起点6970391e。用户授权至多四轮，每轮一次180秒会话，达到7200停止。

先完整处理上一轮暴露问题：无收益整人缓存改局部推知固定点缓存；批量记录更新迁入通用ABI；静态声明备忘；辅助陈述不获完整答辩分；询问移除答复正文并限制已知目标的重复请求；移动补正文，已收到自我介绍后显示姓名，规范表态附所谈内容。

第二章往返中包含饭桌检查、讲堂公告等不同目的，不能为速度直接删除合理目标。本轮保留原目标和待办中继，评估新的实际轨迹。尚未相识者仍未知姓名，不赋予全知名字。推知缓存不跨过未完成/预算阻塞的链，也不跳过语用和模型核验。

设计对照：本人信息与他人证言来源、真正执行后观察、当前公开问题与支持性结论不同、既有场景文本与知名边界。无答案注入、无提前宣判、无配额提升。所有修改先完成后静态检查与必要ABI工程排错，再冻结进行正式测试。

本轮唯一会话启用--profile，以取得后续轮次可依据的热点。每30秒保留已完成函数累计计时，强制超时后可能只有前150秒样本；插桩开销单列，不将其吞吐当原生性能。模型执行不含Godot几何。
