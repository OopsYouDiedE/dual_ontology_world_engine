# 测试前关键节点与证据要求

以下依据现行设计规范及用户本轮自然模拟说明，由主代理制定。这里是验收目标，不被运行器读取，不预置结果，不作为人物知识。

| 关键节点 | 本轮实际达成所需证据 |
| --- | --- |
| 乙区真实茶叙后开始六段广播 | 备茶、送茶、沈鼎话语实际成功；恶魔实际接收；广播逐段成功，事件时间与来源先后对应。 |
| 乙区证物、声路、四步答辩 | 本人实际检视和协作回执、重演与解释来源、四步正确回答实际被接受，不能以问题出现或移动替代。 |
| 各寝区推演与释放 | 各人本人证据和实际提交；正确结论、半截结论、外闩释放与跨门分开记录。默认乙区运行不能证明跨区侦探配置。 |
| 主动共鸣与私有夜呼 | 本人效用及资格来源、实际主动取回、成功结算、夜间现场与本人定向感知，不能用候选或时间窗替代。 |
| 第一夜及第二日内容交接 | 真实初会、取用/晚餐账、搭档与守望行动；章节内容可用事件不等同实际跨门。 |
| 三区翻案与三匠开仓 | 实际取得并理解新物证、当面对质与态度改变；主粮仓实际协作执行、开门和库存入账分别记录。 |
| 规范从提案到执行 | 真实提案或读板→本人内容收据→价值比较与决定→成功Complete的规范回执→后续实际行为。 |
| 震后安全与第四夜 | 本人实际获知变化与复测、实际劝阻/守门、莫兰实际后续选择和暴露结果。 |
| 第五日全体公约 | 各人的实际到场、获知提案、采纳、选票与签名；全十六人真实签署后才记录章末震颤。死亡不代替签名。 |

未到达节点与记录不足分别记录；本轮只有600现实秒工程窗口，不推断整局不可能达成。人物合理性依本人当时的信息、目的和选择解释，不能由设计目标倒推实际动机。无Godot的一级不提供几何、碰撞、输入或画面证据。
