## 工程参数与边界

- 标准/低配 `Replay_Depth` 为64/2个有序因果阶段；行动 `plan_depth` 独立为6/2。标准64容纳现有约二十段时间线，但不保证给定工作预算足够枚举所有变量组合；截断返回未完成，不能认证完整解释。
- drive、caution、信任、信息权重、语用阈值与共鸣量采用源码中明示窄域初值。参数是工程配置，不是设计已验证的心理测量。
- 病理阈值与耦合系数使用工程暴露单位；实际暴露是前提，不按日期预定人物伤亡。旧记忆重置按当前实现的开局快照处理，不能据此声称临床模型得到验证。
- 第一夜用八份原料单位记账；第二日用十六份标准口粮计餐；三周粮仓折算672标准份。具体菜肉重量、压力差数值、钥匙通用资产模型没有据此获得额外设计授权。
- 正式等待费用为180/60/15/5/1分钟，其估值记录时间机会成本补偿与0.01净偏好。没有注入未来观察、预写答题结果或强制主体路线。此为内容与行为基线变化，不作同条件提速比较。
- 原始保护基线与历史证据未修改。新的地图绑定只做静态路径核对，未验证 Godot 的现场几何与画面。
