对照 [设计规范](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md) 与当前 `language_core/`（含 `core/`、`verification/session/`、`verification/scenarios/` 与 `game/`）的全部代码，现行 DV Core 内容与设计规范存在以下四个层面的不符与缺口：

---

### 一、 核心系统机制与心智模型层（对比设计规范 总纲、第二部分、第三部分、第六部分）

1. **缺少双基线 AI 侦探配置（`Standard_Detective` vs `Foolish_Detective`）与跨区投放破局机制**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L618-L674)）：
     - 内置标准侦探（`Standard_Detective`）与愚蠢侦探（`Foolish_Detective`）两套心智参数配置，区分他心回放深度（`Replay_Depth`）、格赖斯语用补全抗性（`Implicature_Resistance`）、跨阶层调停主动性及第二章规则起草策略。
     - **乙区 13:00 分水岭**：标准侦探在 12:15–12:40 独立完成四步答辩正大光明开门；愚蠢侦探轻信恶魔修辞、答辩前后矛盾，引发苏泠失望谴责，直至 13:00 被雀儿从门外撬锁放出。
     - **跨区投放基准**：将标准侦探投放到甲/丙/丁任一寝区，可在第一章内替该区推翻字面误判、查明完整真相（如甲区识破半角残纸毛边、丙区发现莫兰画夹暗层、丁区查出维罗妮卡左臂旧疤）。
   - **Core 现状**（[chapter1-content.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-content.dv#L1721-L1740)、[chapter1-departure.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-departure.dv#L102-L120)）：
     - 仅有单一 `"detective"` 配置（外加旧验证残留的 `dvs_scenario_low` / `dvs_scenario_holdout` / `dvs_scenario_boundary` 仅开关 `model_budget` 或改 `information_weight`），没有 `Standard_Detective` 与 `Foolish_Detective` 的双基线参数及第二章分化策略。
     - 没有苏泠因侦探答辩前后矛盾而产生敌意谴责的交互机制。
     - 没有将侦探跨区投放到甲/丙/丁区并在第一章内破局的规则与动作。

2. **缺少自主共鸣判定公式 $U_{\text{resonance}}$ 与深层记忆取回的三重代价机制**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L194-L237)）：
     - 区分被动的“触物闪回”（无代价生理反射）与主动的“深层共鸣/取回”。
     - 主动深入共鸣由不等式 $U_{\text{resonance}} = (W_{\text{drive}} \times I_{\text{relevance}} + B_{\text{demon\_truth}}) - (S_{\text{caution}} + R_{\text{perceived\_risk}}) > 0$ 驱动（例如霍铎因听到恶魔在领取柜提及闭式热机图而产生 $B_{\text{demon\_truth}}$，从而压倒谨慎阈值主动深入共鸣回忆起门框暗槽）。
     - 取回深层记忆伴随三重真实代价：① 提高源质耦合深度加速身体侵蚀；② 触发名录库契约感应（夜半被铜口点名传唤）；③ 恢复旧日理念暗礁并重塑对相关人员的初始信任度。
   - **Core 现状**（[chapter1-content.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-content.dv#L1535-L1555)、[55-cognition.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/core/55-cognition.dv#L1-L240)）：
     - 霍铎、苏泠、沈鼎的回忆对话（`talk.recalled_copper`、`talk.recalled_names`、`talk.frame_hollow`、`talk.slate_code`）仅以侦探检视过对应物理线索（如 `slate_marks`、`starter_layers`）作为布尔前提，未计算 $U_{\text{resonance}}$；霍铎回忆甚至不依赖恶魔是否说过 `demon.opening.desire-offer`。
     - 无源质耦合深度、记忆取回三重代价、夜半唤名及信任度重塑的结算逻辑。

3. **缺少源质侵蚀的五阶段病理演进（设计规范 第三部分 §1.1）**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L186-L193)）：源质侵蚀按“早期（畏寒、注意涣散）→ 中期（低烧、夜间梦游、替恶魔传话或搬运物资而不自知）→ 晚期（顺行性遗忘，每天醒来只记得入岛第一天）→ 终末（陷入安眠）→ 死亡（彻底結晶化）”演进。
   - **Core 现状**（[chapter2-content.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter2-content.dv#L305-L315)）：仅在 `moran` 身上定义了静态字段 `fever`、`exposure_stage`、`exposure_terminal`（初始均为 `dv_unknown()`），且没有任何世界法则驱动其演进。

4. **缺少开局心智参数抽样机制与修罗线伦理静默记录**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L92-L108)、[L708-L716](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L708-L716)）：每名角色的心智参数（欲望权重、谨慎阈值、初始信任倾向、偏见强度）在声明区间内按开局种子抽样生成；前两章在底层静默记录玩家利用真话诱导他人的操纵行为。
   - **Core 现状**：所有角色的 `policy` 参数均为固定硬编码常数，无区间抽样机制，也无伦理操纵静默记录字段。

5. **规范口头认可与无人监督执行的分离不完整**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L64-L66)）：“角色在会议上投票赞成某项制度，只代表其更新了公开表态；在无人监督的夜间或紧急关头是否遵守该制度，仍由其当时的主观认知、个人价值排序与精力余额实时计算。”
   - **Core 现状**（[16-personal-choice.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/session/16-personal-choice.dv#L132-L165)、[chapter2-content.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter2-content.dv#L636-L654)）：`dvp_normative_ready` 仅检查角色 `mind` 中是否已知 `c2.norm.emergency_ration` 等布尔标志，未将“有人监督的公开表态”与“无人监督时的违约效用计算”分离。

### 二、 恶魔（代管者）物理二态性与契约博弈层（对比设计规范 第二部分）

1. **契约全文在第一章开局即可无依据直接问出，违反“前置认知的本局物理校验”**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L118-L120)、[L152-L162](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L152-L162)）：
     - 玩家不能在第一天毫无依据地向恶魔精准提问契约条文。
     - 必须在第一章尾声抓住门槛窄手印（E11）追问出“受学园契约授权封存”，并在第二章讲堂结合《学园守则》第 4 条“我所立之规皆张贴于此”的措辞漏洞当堂连续追问权限来源，迫使恶魔吐露契约全文（或第三章拓印石碑）。
   - **Core 现状**（[chapter1-opening.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-opening.dv#L617-L632)、[chapter2-dialogue.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter2-dialogue.dv#L51)）：
     - 第一章开场即为乙区四人注册了 `<id>.opening.ask-contract`（“约束你的契约，全文是什么？”），前提仅为 `c1_at(id, "hall")` 且知道 `opening.roles.custodian == "demon"`——恶魔刚做完 08:00 自我介绍，任何人即可毫无物理依据地直接问出契约十二条全文。
     - 第二章 `detective.c2.ask-contract` 的 `available_when` 直接写为 `dv_true()`，同样无任何前置证据链校验。

2. **恶魔缺少“虚体/显形”物理二态切换模型**
   - **设计要求**（[docs/design-standard.md](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/docs/design-standard.md#L123-L128)）：代管者平时为虚体（可穿墙越障，绝不能对物质世界施加任何机械力）；一旦触碰器物、板书、抬起外闩，必须转为实体显形并留下物理痕迹。
   - **Core 现状**（[chapter1-content.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-content.dv#L1656)、[chapter1-departure.dv](file:///c:/Users/iii/Desktop/dual_ontology_world_engine/language_core/verification/scenarios/chapter1-departure.dv#L225-L250)）：
     - `demon` 没有虚体/显形状态字段；且 `demon.state.location` 初始化为 `"hall"`，而 `chapter1-departure.dv` 将 `demon.location_ref` 改绑到 `demon.body.state.location`（初始为 `"living_hall"`，`observable_presence_when: dv_true()`），导致恶魔的两个位置引用分裂且常驻显形。

### 三、 第一章《门的这一侧》与第一夜内容不符点（对比设计规范 第四部分）
