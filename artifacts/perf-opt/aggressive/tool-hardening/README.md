## Changes

- Reuse requires v2 metadata: complete compiler/seed source closure, generated/project files, complete Release binary set (including required assembly/deps/runtimeconfig), profile mode, compiler identity and fresh/resume entry kind. File omissions, extras, changed bytes, profile/seed/compiler/entry mismatches and overlap reject. Copied bytes are checked again. Sources are checked again before session launch. Legacy v1 records require a fresh build; no old manifest is upgraded into proof.
- Runtime-switch metadata is retained separately in the compiled record; on/off runtime settings can share identical binary hashes. run_debug also records requested and actual DV config, DV_OPT_RUNTIMESPEED in the child environment, and runtime_config_matches. Parent agent supplied 60-game metadata support in 619da93c; planning supplies replaycache consumption. These consumers must be merged before a formal integration run. No new content/performance switch was invented here.
- run_debug and matrix share FLAGS: original 16 plus replaycache and runtimespeed. Baseline keeps selective on and turns all 18 off; precise-baseline uses separate precise-* directories and labels. Default session window is 300 seconds, independent from offline causal and outer launcher deadlines. Defaults do not authorize AI execution.
- Fixed-case cleanup waits for registered OS reader/runner leases and old path-associated processes, verifies the exact immediate task-root target, rejects reuse inside that target and reparse points, then deletes inside one native PowerShell. Windows process trees are assigned to a Job before the launch gate opens; timeout/stray-child/unknown cleanup failure retains the matrix failure lock. Successful completion alone removes it.
- Raw event indexes retain original parent_ids and host_action_event. The latter is an actionN host token, not an eN event ID. optimize on/off keep the same values/validation. No raw event/state field was removed.
- Report completion now requires a real applied inspect projection, matching completion actor/action/host/execution, committed host/execute index entries, matching original host action token and parent chain, and correct event ordering. A known true, unconflicted council_closed fact is required for the session speed goal. Unknown/false/empty claims cannot satisfy it. Older indexes missing these receipt fields remain insufficient.
- Chinese Markdown labels are restored; 35-campaign-schema participates in module fingerprints. Full compilation-input fingerprints and runtime conditions are separate. Build, execution, postprocessing, launcher command wall time and total case wall time including cleanup are distinct. The 180-second field explicitly means session execution only, not total command speed. Persisted command timing is bound to the current result.dvlog hash.
- Added an explicit diagnostics/aggressive-matrix route; discovery never invokes it. Compiler/runtime/generator sources were not changed.
