# DV Core 命令行界面与只读回放设计（修订）

本稿修订下载目录中的 dv_core_ui.md。当前实现依据 dv_core/cli、host_bridge 和 SmartReplay；设计目标、已经实现的功能和本轮预览分开说明。界面不定义人物、谜题、数值或剧情事实。

## 1. 视觉与内容结构

使用深靛蓝底色、青绿色重点、暖白正文和琥珀色未决提示；采用 ANSI 真彩、Unicode 细线与圆角面板，避免密集 ASCII 表格及 emoji 造成的宽度错位。普通文本和 JSON-Lines 仍可用于管道；颜色不是唯一的状态标志。

宽终端分为房间与拓扑、事件正文、当前候选三栏。房间按纵向组排列，不能把人物、地点、物件混成平铺列表：

- Room A
  - 本人在此 / 已知位置及来源
  - 本人实际可见的人物
  - 已交付的相关内容
- Room B
  - 已知位置及来源
  - 没有当前人物记录时明确写“未记录”，不写“空房”

每个房间的内容紧随该标题；当前房间用符号及颜色共同标识。房间有独立稳定身份，标题不作为匹配键。同名房间按地图区分。

拓扑采用节点、连接线和连接状态标签，连接表示已知关系，不表示角色已经走过、门已打开或有权通行。只消费观察者投影的 map_knowledge.rooms/doors；缺失连接不由原始场景、其他主体真值或候选名称猜出。现有连接记录没有门锁状态，显示“状态未记录”。可通行资格仍以本次正式候选为准。拓扑不是 Godot 几何、碰撞和距离验收。

窄终端改为纵向面板。正文按显示列宽换行，中文和非BMP字符不能按 string.Length 截断。底栏明确当前模式、帧索引、记录来源及可用命令。缺失的字段写“未记录”，不能补默认分数、置信度或成功状态。

## 2. 统一显示模型，分离权限

命令行实时投影和记录回放使用同一 TerminalModel 与渲染器。模型包括模式、观察者、当前房间、已知房间/连接、事件正文、当前候选、所选动作与来源提示。它是显示模型，不是新的世界执行器，也不能代替原始证据。

实时数据只来自 DvSession.TextStatus、Materialize 和观察者合法候选。当前生产快照没有面向普通玩家的评分拆解，不显示虚构的 Info/Progress/Cost 分数。候选不可用、尚未 Prepare 与旧日志未记录候选应分别说明。所选动作仅来自已有记录，不能把高亮游标当作提交成功。

普通模式只显示观察者已交付的信息。世界真值与本人认识的并排检查属于显式 --dev / Inspect 开发功能，不能进入普通候选、agent协议或一般历史浏览。历史记录也可能缺少所需心智来源，不能凭最终状态回填早期认识。

外部控制可提交简短行动理由作为解释元数据；这不是思维链，也不证明行动有效或人物采信。现有CLI尚无 --reason 语法，本轮不在文档中宣称已经支持。精确数保持Core原值；未知不伪写为 confidence=1.00。

## 3. 正式执行、控制与回放

正式命令继续沿 Prepare → formal-model执行 → Complete；命令行不包含Godot现场几何。status/options只读，不自动调度NPC。next明确推进一步；act只消费当前人工选项并重新核对。自主控制须显式 --controller ai，不能以打开UI或预览为由启动AI测试。

SmartReplay是只读消费端，不创建DvSession。移动游标、暂停、重播和界面恢复都不提交正式行动。现实现没有任意历史分叉、热切换控制者或随意切换观察者的合同；不提供误导的M/Tab快捷键。未来若实现恢复分叉，必须从带完整校验和版本身份的正式存档开启独立会话，不能把显示帧当可恢复状态。

当前可用回放操作为空格暂停/继续、右方向键单步、1/2/4/8调速、Q退出及命令行play/pause/step/restart。左箭头和LIVE游标暂不作为已实现能力。实时命令仍使用底部输入行。

## 4. 回放节奏与时间真实性

沿用共享SmartReplay的内容节拍，不另造与Godot不同的播放公式。原始现实时间、游戏时间、回放展示时间分列。阅读、外部响应和后台计算耗时是有意义的原始记录，不能全部称作无意义停滞，更不能从证据中丢弃。

节拍压缩只改变展示等待，不改事件顺序、输入、结果、预算、原始时间或正式会话。缺少现实时间戳时写“未记录”；不能凭帧数捏造“节省X秒”。不承诺零卡顿，不以回放更快声称引擎性能提升。

## 5. 入口与交付范围

- `dotnet run --project dv_core/cli/DvCli.csproj -- --tui`：现有正式命令入口，美化只改变呈现。
- `--replay <记录> --tui`：共享SmartReplay只读回放。
- `--jsonl`：既有结构化管道；与TUI互斥，不宣称新建agent-stdio命令。
- 本轮新增无会话UI预览与同画布SVG导出，供截图审阅；预览房间名及文案均明确为界面示例，不能冒充正式剧情进度或游戏验收。

渲染器放在dv_core/cli；复用截图转换工具归mcp/verification并在tools.json注册。临时文件放.scratch，任务提交前清理。本轮只做必要构建、无会话UI预览和截图，不自动开启Core AI验收。
