## 验收结论

有限 CLI 操作与封存成立；界面尚未全部验收。实际查看本目录四张 PNG：房间为分组列表，人物归入实际房间，通道为端点列表；双地图的长内容可以分页。图片是生产 CLI 同一单元画布的 SVG/PNG 导出，不是操作系统终端窗口截图。

本轮人工输入 focus 03、confirm、view detective、六次 next，并读取地图和分页。共完成三项正式行动，不是三项侦探行动：demon 的检视、侦探检视书架、quer 检视外闩。侦探获得书架灰尘、净痕与半枚手印的观察正文；仍在原房间，未测试回答、章节交接或完整结局。输入为批量转发，不把输入记录时刻视为实际行动完成时刻。

console.dvlog 的 closed：exit_code=0、timed_out=false、interrupted=false、changed_sources=[]、pipes_complete=true。记录器总区间约 24.594 秒，包含操作者等待及渲染；不作为纯计算性能测量。session.dvdag 与 session.dvsave 的完整性及精确行动来源由 independent-review.md 单独核对。

## 本轮修正

- 开局显示候选却仍处 idle 时，直接 focus 曾以“阶段 · idle”退出；现在先 Prepare，再聚焦，仍需确认才提交。
- 固定侦探检阅视角时，确认 Core 已准备的 NPC 行动曾以“行动视角”退出；现在按真实主体、动作与版本核对，不把检阅视角当成控制权。
- 采集器在 CLI 提前退出时，输入线程持有 Python 缓冲锁导致解释器退出错误；改用底层输入读取，后续失败窗口及正常窗口未再出现该错误。
- 交互记录拆分 actor、viewer、presentation_viewer，回放合并保留正文实际观察者；JSONL 的交互候选也裁剪到当前检阅者。构建及本轮 TUI/二进制结果字段已复测，JSONL 实时显示和完整回放尚未单独实测。

前两次失败窗口位于同任务的 cli-live-review-20261022、cli-prepared-review-20261022，分别因上述阶段校验、固定视角校验退出。其原始 console.dvlog 留在各自目录，没有用成功窗口补写失败。cli-current-check-20261022 是最后一次记录归属修正之前的成功窗口，不替代此处最终源码证据。
