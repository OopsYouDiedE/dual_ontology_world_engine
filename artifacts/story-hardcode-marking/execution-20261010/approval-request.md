## 已证实的失败场景与复用尝试

1. **一词两切面**：既有 Core 可以建立两个主体投影，AstDecoder 会报歧义；正式 WorldSession 仍拒绝多现实表现，KnownProjection/Inspect 取第一表现。主体词项桥不能据此静默挑一个。证据：D01A/REPORT.md、D01B/README.md、D03/REPORT.md，P04 与指定表现检查。
2. **一次求值混读**：中性同一 AST 的完整旧态和新态都为 False，一次求值却读出 True。现有主体实时 ProjectionWorld 没有一致版本快照合同。静止捕获可以冻结读值，但不能证明并发原子捕获。证据：D01A P05、D01B revision 实验。
3. **历史不可重建**：旧事件的 Target 仍指向当前可变对象；规则、Parent、Kind、Procedure 等不足以恢复过去，Forget 删除历史。实体的进程内引用不能充当跨进程稳定身份。证据：D04 规则权重冲突实验、D01A/B 历史实验；现有专章快照不能冒充通用保存。
4. **主观推演输入边界**：Core Reasoner 和中性规划未泄漏隐藏现实，但第二章适配器以完整现实快照及 CaseActual 值重建/比较；缓存只按已知集合。零深度与无行动结果不可区分。证据：D04/diagnosis.md、candidate-contracts.md。不能用 UI 隐藏结果掩盖上游全真输入。

已存在而**不申请新增原语**：Exists/Tagged/At/Not/All、准备/提交、条件 Wait、TemporarySetUntilEnd、Rule、SocialSystem、Subjective Reasoner。D02/D05 已证明旧习惯适用范围、目标完成条件及共同占岗可由它们组合；邀约 Target 槽误用和来源编号漏拷贝是适配问题，不新增万能效果。
