# D03 常见物件与感知组合：只读研究及首批中性实验

本轮结论：既有 Core 足以组合**显式拓扑的锁/通路、取放与容纳、公开数值状态、有限条件下的接触留痕**。它没有替作者补出布料遮挡、材料传递或声学传播规律。当前不宜承诺“任何常见物件都按直觉交互”。应先承诺有限、可声明、可观察、会明确拒绝的动作组合。以下均为范围草案与缺口检测，不是能力批准或规范变更。

## 能力证据与承诺交互范围草案

| 组合 | 既有能力/边界 | 本轮可承诺的有限交互草案 | 证据状态 |
| --- | --- | --- | --- |
| 锁与门/通道 | `LockProperty`、`PassageProperty`、`AcceptsKey`/`HasIdentity`；钥匙必须由行动身体持有；拓扑不隐含反向边 | 对已声明的锁进行匹配钥匙开锁；从当前空间沿已声明连边移动；错钥匙、未持钥匙、未连通或锁闭明确拒绝 | A01–A09、B01–B05 动态验证 |
| 可携物、支撑与容器 | `SpatialProperty.Space/Holder`，`Take/Place` 保留 Essence 身份；锁闭祖先阻断取物；Take 仅接受 `Object` | 取、持有、放至同室可达支撑/容器；取放后保留已有状态和子对象的容纳关系；不得由名字推定容量、开口、重量或移动附带后果 | A10–A11、B04–B07、B17–B20 动态验证 |
| 织物与表面痕迹 | 开放 `StateProperty` + `Require/When/Set/Change/Relate`，没有布料专门求解器 | 把某块可携织物声明为 Object，给它明确状态和有限动作配方；在完整位置、媒介状态条件成立时产生已声明的痕迹；不自动增加“织物类”标准实体 | A12–A19、B08–B10 动态验证 |
| 接触与媒介 | 数值标签/关系可以承载作者声明的状态；通用引擎不自动判定接触面积、介质流动或化学变化 | 支持有限“在同一支撑/容纳关系、状态满足时触发后果”的配方。条件必须覆盖行动者、支撑、物件的当前位置；本文只承诺直接父节点关系，不能把 `At` 当递归同室查询 | A13、A18、B09 动态验证；一般材质传播未验证 |

| 布遮挡/遮蔽 | 放置和 `covered` 状态不会自行过滤感知；Inspect 不能按传入侧面选择表现 | 只在宿主已有可验证感知筛选明确排除被遮物时承诺遮挡；在此之前不得承诺“盖上自然看不见”或“检视背面” | A12、B08、B14–B15 明确反例 |
| 工位 | 普通 Object/Space、状态、Procedure、临时状态租约可以承载用途和流程；没有因名称而获得的工位语义 | 暂限有明确位置与输入/输出状态的有限工位动作；占用、材料消耗、完成条件各自声明并验收，不把本作专用资源升格为 Core 类别 | 本轮验证支撑和状态组合；Procedure/资源消耗/租约工位仅静态候选，未动态验证 |
| 声学/其他感知媒介 | Core 可接受来源明确的 ObservationInput；获审 Acoustics 属有限章节拓扑及听感映射 | 当前仅承诺外部已裁定的感知输入入脑；不承诺任意材料或房网的声学传播、衰减、方向和遮蔽 | Core 观察边界静态核对；一般声学组合未验证 |

布、容器或工位的角色均由实例的能力组合决定。物件名称、本作特定物件 ID 或章节专用 Property 不构成标准类别。`Material` 的类别标记不自动获得取物能力（B10）。

## 最小缺口与下一步界限

1. **先补作者绑定边界，不新增物件专类。** F01-C002/C003/C012 与 ACT-01/02/06 已记录通用 world/v1 对锁、通道、身份、关系和切面声明的缺口。Core 本身已有大部分能力；本次直接 API 实验不是 `.story → 正式宿主 → UI` 的闭环证明。
2. **给每个玩家动作写出完整守卫。** `Set/Change/Relate` 是低层效果；不能因它们成功就宣称物理合理。有限配方用 `Require` 明确 actor/支撑/物件的当下位置、状态和资源条件。任意动态容纳图的“可接触”条件接口仍是缺口；本文没有复制一套递归事实执行器来填补它。
3. **把遮挡作为可验证的感知筛选契约。** Core 不推导遮挡。需要现有宿主传入真实符合范围的表现，再调用已有 Observe；遮挡移除后的显露、旧认知保持及侧面选择必须各自验收。本轮没有实现新筛选器，也没有 UI/几何证据。
4. **明确指定侧面 Inspect 的接口缺口。** 当前行为会选第一表现。若需要玩家指定面，先完成桥接/API方案审查及中性失败例；不要以直接送入想要的观察结果冒充正式 Inspect 成功。
5. **把媒介/织物/工位收敛为有限声明配方。** 开放整数状态可表达显式结果，不能自动承诺一般渗透、擦拭、磨损、柔性形变、声路或工位生产。现有章节物理结算是专用实现的证据，不是通用物理能力批准。首批范围到此停止，不扩至未来 40 日或追加物理体系。
