# 获批公共合同：分批实施边界

语义审批：`AR-CORE-01`，见 `../approval-record.md`。共同版本以 `v1` 开始；未知主版本、未知必要能力和失效引用必须在写入前明确拒绝。新能力目录只映射已批准 Core 操作，不新增章专用回调。单写者租约另列精确文件。

## 身份域

四个域分开：客观 `EntityId`；同一实体的 `FacetId`；作者词项 `AuthorTermId`；主体内部 `SubjectProjectionId`。不沿用两个实验中含义冲突的 ReferentId。词项提及的来源位置不是实体身份。主体句柄不得公开反查隐藏现实实体；只有引擎绑定层拥有映射。

作者给出的持久 ID 使用 Unicode NFC、Ordinal 比较、非空且不得静默修剪或按显示名称重绑。旧构造入口可分配不复用的 opaque ID；新正式 IR 必须提供持久身份。删后创建同名物不是旧实体；遗忘、重认、重命名和跨进程恢复分别处理。句柄/世界/主体域验证须显式。

解释使用指定主体的一致快照。保留 True 与 Unknown 的可能候选；Unknown 不能当 False 排除。结果分开：Unrecognized、Ambiguous、Unknown、Unsupported、InvalidReference/Stale、Resolved。命题真假仍为既有 Truth 三值；解析结果对象不能按一般 truthiness 当 True。限定词和别名只能来自该主体已获知词典；静态语法/冲突检查不得绑定隐藏事实。已消歧目标进入既有执行器，不增加万能效果。

## 认知提交、快照与历史

一次 Observation 或显式 Observation 批次经过完整校验后原子提交，成功的非空批次只增一个 revision；失败不发布部分变化。一次 AST 判断、评分或规划固定一个认知版本。读锁/不可变图实现可复用既有世界；禁止逐叶重新摄取。Changed 回调必须在完整提交后发出，重入不能看到半状态。

快照是完整 immutable 主体图，含名称、kind、existence、parent、tags、正/否关系、规则的权重/接受、procedure 及可见来源。AST/关系以主体句柄表示，不能持有源 Projection、Essence、runtime 或回调。重建分支显式二阶段分配/重绑定，引用缺失必须拒绝，不能默填。

引擎审计日志追加不可变完整变化与 tombstone，遗忘不销毁审计。主体快照不因此重新获得已忘内容，不能把审计历史直接分发给决策/自动玩家。兼容的旧 History 不作为新版历史正确性的证明；消费方迁移至相应主体快照或权威审计接口。

保存是本批交付，不采用 D01B 的 future-only 范围。认知图 codec 是第一阶段；随后正式连续会话保存必须同时覆盖现实属性、绑定、时钟、章/流程、随机状态、待处理行动/租约/呈现回执等实际状态，或在精确可保存切点明确拒绝未支持的活动状态。不得清零待执行状态或重跑初态。先完整解析校验再发布新会话；失败保留当前会话。未知属性/AST/版本明确 Unsupported，不能反射恢复任意类型。

## 主观推演与事件

主体推演入口只接 immutable 主体快照、获准模型与显式假设。模型的生产同样不得读取未获知现实。世界分支无源可变引用、无外部执行回调、无 UI/声音/认知写回。权威审计采用不同入口/类型/日志，不能默降为主体结果。

结果结论与停止原因分别记录；至少区分支持/反例/未知/不支持，以及完成、预算、深度、无行动、失败。预算在执行消费点检查，零预算不执行一步。缓存含主体、认知、词典、规则、模型、能力版本，不只按已知集合。

行动、观察、证词、传播、呈现各有事件类型和权限投影，含稳定 ID、时刻/单位、主体/对象/位置、阶段/结果、来源及因果引用。发言不是事实提交，接受不是执行，到场由实际动作得出。文本/译文只负责呈现。通用门/布/痕迹/工位复用现有条件、关系、提交和生命周期租约；不暗加全组原子事务或连续保持新原语。

## 验证

新正式 IR → 解释/决策 → 提交必须贯通两个结构不同的中性世界，失败/取消、错误声明、隐真变形、重复保存载入及压力规模均独立验证。实现者不运行验收，失败原始日志保留。虚拟侦探由正式 story 声明，顶替玩家位置，只接正常可见输入/候选/反馈；不预写行动顺序或谜底。中性 stress 与正式 3–5 日 stress 分开，未完成项不得记 PASS。原始 27 项失败和旧黄金保持独立可追踪。
