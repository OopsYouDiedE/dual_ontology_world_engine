# vplayer2：正式剧情的命题接线

日期：2026-10-10；分支：`codex/vplayer2`。未提交；未读取设计文件；未改 UI 或布局/样式资源；正式侦探仍为玩家，三份原有译文二进制修改保留。

## 改动与原因

- 第一章 `.story` 声明 40 个命题、83 条可见来源接线、20 条条件关系。编译器校验可靠性、说话人/言语行为、卡片/行/选项/变量/现场引用；声明无真值字段，不读取隐藏判定或共享答案表。
- 实际呈现经正式 `Observation` 进入本人认知。证言结合来源可靠性与本人信任，重听不覆盖已有信任修订；入口/陈述/重演选择只提出命题。内容与物体分开，物件失效不抹记忆，但不能再出示。
- Core 区分 Claims 与接受的 Infer，统一 Actor/Target/Tool/Scene 的本人引用，未绑定 Unknown；单份证明 Complete 与整轮预算/深度停止分开，输出材料、前提、结论及缺口。
- 控制器用本人 `SubjectiveReasoner` 选择有信息价值的调查及试验；优先当前问题缺失前提，有完整非假设证明才选陈述，出示必须参与该证明。新材料/新问题后重试旧入口，不设行动顺序或答案序列。
- 修复正式参数加载丢失 `argumentWeight/informationWeight`；深度 8、展开 32768、假设 128、答辩权重 16、信息权重 8 均为角色参数，中性检查经正式加载器取值。
- 归一人物现场 `person:` 前缀以接到作者编号。只记住实际见过的热点坐标，对既有移动候选施加软方向偏好；普通短步由正式碰撞/物理循环裁决，不读取未知路线。
- 现场/选择机会只匹配完整公开名称，修复含人物名的无关子菜单冒领父现场的信息价值；具体询问仍使用自己的实际接线。
- 驱动默认墙钟 600 s、观察预算 100000，逐步记录游戏时刻/展开数/命题/依据/推导/缺口；演出和重演不受空闲期限截断，仍受总墙钟约束；正式 ending 才算章末。
- 同步两个模块 AGENTS；正式产物用编译工具生成，既有测试断言和预期未改。
