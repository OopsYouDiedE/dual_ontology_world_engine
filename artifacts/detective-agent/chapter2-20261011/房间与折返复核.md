## 源码原因与本轮修改

- `Chapter1Session.ReadContext` 原来按几何区域 `room` 更新会话及身体所在房间，而房间触发与画面迷雾使用 `entered`。现在仅非空真实入室回执更新人物的位置、逻辑房间和地点名称；门槛处保留上次实际入室值。此适配对现场玩家与其他人物一并生效。
- `PilotNavigation` 原来构建完整实际地图导航网格，交界探测也查询未见一侧是否通行。现在记忆网格只在当前视线内采样通行，已见路线只在记忆网格上规划；未知方向由正常 WASD 与碰撞探索，不提前读未知落点。
- `SubjectivePlayerController` 原来每次采信新材料或切换当前问题，都清空所有非移动动作的尝试次数。现在只在对应公开材料的主观证明状态变化时重开相关输入；失败与碰壁记录仍保留。同一菜单标签按实际交谈对象隔离。
- 现场公开候选新增 `TravelDistance`，从本人已经见过的路线估算；无已知路线时只取已知坐标的距离下界，不补造通路。既有 Core `Cost` 接收该成本，同等信息收益下减少远处往返。
- 决策记录保存公开候选的分数和评分依据；FullTest 在现场动作前等待正常绘制帧，关联候选 token、真实脚底位置、入室回执和截图。实测时需要实际打开图片核对，不凭评分推断画面。

本轮不修改 Core，也不修改 `.story`；这部分属于几何到逻辑房间的适配、公开候选和真实反馈的接线。通用经验、成本评分仍复用上一轮已获批准迁入 Core 的能力。
