# 现场交互回执独立机制验证

本轮为独立中性机制验证及构建检查。验证 Agent 未读取设计文件、正式 `.story`、历史试玩或其他轮验收证据。未执行一级、二级、三级验收；没有本轮剧情、人物行为合理性、真实几何可达性或游玩体验结论。

## 本轮行为结论

现场调查选择只有待接触记录；没有抵达时实际检视次数保持不变。连续路径失败仍保留未知材料的信息价值和首次检视偏好，同时各次失败留下递增的失败代价。收到真正接触反馈后才登记实际检视和成功。真实检视后未知材料奖励按原机制耗尽；相关证明变化重开该材料的检视机会，已发生的失败和成功记录仍保留。无关证明不刷新该记录。

最终版本将失败归属到选择时本人和公开目标位置的 64 像素格所对应的接近路径；实际检视和成功仍按空间/目标名稳定保存。同一公开起点和目标格的失败代价保留，格内坐标抖动不会刷新。本人换到新公开格，或实际看见目标移到新格，新路径不会继承旧路径的失败；重新回到旧起点或看见目标回到旧格时，旧路径失败仍在。这些位置变化不刷新实际检视次数，也不会使已耗尽的未知材料奖励重新开放。测试没有读取目标不可见的新位置。

伪造 token、已经结束的旧 token、重复成功或失败反馈都不能改变当前接触。进入新决定时，未反馈的上一接触按失败结束；空候选和缺主体的入口早退同样结束待接触。失败接近另一人物不会切换话题上下文，原人物同名话题仍保留重复记录；只有真正接触才切换人物话题范围，回来后原话题记录也仍在。没有 `Location` 的普通 `interact` 和 `menu` 沿用选择时的检视计数。

正式 `AgentPilot.gd` 与 `Main.gd` 在独立中性宿主中使用正式 `submit_token → player_field → perform_field` 和 `field_event → take_field_reply → DispatchField` 链。选择地点只启动接近动作，未产生成功反馈。相同地点、相同地图和 `interact` 事件必须同时匹配；其他地点、其他地图或其他事件种类不会确认接触。匹配的现场信号只确认一次，并且发生在正式分派现场输入之前。仍在走路时没有接触反馈；现场重新空闲且没有收到接触事件时结束为失败。公开候选替代旧输入以及动作前/走路中停止，都结束待接触；后来的旧现场信号不会补记成功。

## 首次失败与修复范围

`controller-run-01.log` 实测暴露生产缺陷：空候选早退后旧接触 token 仍能被接受为成功。主代理将待接触清理移到入口早退之前，后续空候选及缺主体用例确认旧回执被拒绝。

`controller-run-02.log`、`controller-run-04.log`、`controller-run-05.log` 保存既有夹具在新合同下的首次不适配表现。既有人物话题和检视夹具此前以“选择”模拟已经接触，现明确调用真实接触回执。U 形及必要返回用例先在目标处完成中性检视，再回到起点比较路标。仅表示看见地点或尝试走路的步骤没有追加接触。旧断言的行为预期没有放宽。

`controller-build-02.log` 保存本验证 Agent 新增夹具中的 C# 目标类型写法错误；`controller-run-03.log` 保存新增话题返回夹具错误地要求单一候选产生重复扣分的情况，修正为有可比较候选并检查对应候选的依据。`godot-receipts-01.log` 保存本验证 Agent 中性 GDScript 夹具的变量类型推断错误，补全显式类型后重跑。这些为夹具错误，未据此改变生产评分或断言合同。

## 覆盖边界

Godot 中性信号链使用正式 Main 与 AgentPilot 方法和中性端口，未创建正式章节会话。C# 控制器的反馈计数与一次性凭据由正式控制器单独验证；Debug 构建核对正式 GameEngine 桥接签名。该组合不能证明正式地图寻路、物件移动后的视线处理、实际碰撞、UI 绘制或连续游玩时长；这些仍需主代理的正式实机复核。本验证进程均已退出，用户既有 Godot 编辑器保持运行。
