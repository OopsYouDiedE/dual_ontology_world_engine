# 待审查的性能优化范围

状态：只读排查，未改动保护源码，未建立新基线，不能宣称提速。

本轮真实四倍速会话的 `performance` 记录显示 NPC 调度反复调用 `core.external_graph_build` 和 `core.snapshot_graph_validate_bind`。例如现实24.880秒所在采样窗口：67次外部图构建耗时841.379毫秒，65次内部只读图构建耗时175.925毫秒；整个窗口1242.554毫秒，帧率约0.805。嵌套计时不能相加当总 CPU 时间。

可审查方向：相同的不可变、已发布主体快照已经有内部只读图时，公共推理适配复用该图。缓存只能按快照对象身份绑定；新修订不可复用旧图；预算和每次推理工作区仍独立。外部新建或反序列化快照保留完整合同校验；`CognitionGraph.Rebind`、答题判定、证据前提、CTB、时间、动作选择和输入均不得改动。

涉及核心文件：`csharp/SnapshotGraph.cs`、`csharp/SubjectiveReasoning.cs`。实施前须独立核对共享图是否存在写入、跨修订误用、合同检查旁路及并发访问问题，并留存精确差异。若实现后，仅构建速度改变不足以认定游戏改善：必须重跑正式会话，比较关键节点双时间、首次180秒轨迹和重复劳动。
