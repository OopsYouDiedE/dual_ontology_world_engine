# 本轮比较的关键节点定义

关键节点指角色在调查、推理和答辩中真正取得的进展，不指位置改变、菜单打开或决策计算结束。定义依据第一章剧本的证物、可习得命题、推演结果与答辩判定；只用于记录和事后比较，不交给侦探作行动路线。

## 1. 脑内推演与正确结论

- 分别记录首次形成有本人证据支撑的核心正确结论：闩门者是自己、声音来自主楼铜口而非门外、呼喊内容是“闩门别开”、因为此前相熟而信霍铎。
- 正式昨夜推演另设节点：实际提交推演后，结果达到“全部吻合”，且所需现场已经实际检视；未检视处猜中，或仅已查部分不冲突，均不能当完整正确推演。
- 来源必须是本轮侦探真实认知或正式推演结果。不能以候选中出现正确陈述、`ReasoningStop=complete`、计算结束或分析者事后从证据推知，冒充角色已正确推出。
- 若原始记录没有保存角色结论形成或完整推演结果，标记“无法核验时刻”；不能补猜游戏时间。本轮未发生正式昨夜推演，核心正确结论形成的具体时刻亦缺少直接记录。

## 2. 首次有效关键检视及验证

每件证物与后续验证操作分别记录首次有效获得新信息的时刻。以下路线可以互相补充或替代，不要求按列表顺序，也不要求为了评价而查遍所有证物。

| 调查问题 | 对应检视 | 另行记录的验证操作 |
| --- | --- | --- |
| 门闩状态与行动先后 | E1隔离门、E2灰与木楔、E4湿布 | 拔闩推门等实际结果 |
| 闩门者身份 | E3靴印、E7石板、E12外衣口袋 | 鞋底比对；石板符号与小图辨认 |
| 呼喊来源与内容 | E5音叉、E6乐谱、E8铜口与管接头；E7亦提供内容线索 | 音叉/门框检验、声路试验及其听到的结果 |
| 相识与信任 | E9杯子、E10酵种罐、E11书架痕迹、E12口袋线索；相关证言与回忆 | 手印比对、辨认习惯、实际取得相关回忆或拒绝信息 |

“收到新检视结果”与“完成验证并取得结论”分开。仅看见物件、到门口、打开空菜单、从笔记重开旧卡、重复展示同样内容，不能重复记节点。实际位置和内容来源不一致时，标为来源冲突，不当正常完成；r24的R06书架输出R05卡片属于此情况。

## 4. 章节收束

分别记录完成全部答辩、章节终局实际呈现、第二章实际启动。开门、正午救援台词或某个内部阶段改变，不能代替完成答辩或实际章节交接。本轮尚未达成这些节点。

## 时间与辅助指标

每个实际达成节点保留事件序号、现实耗时、游戏内时钟、自初始游戏时间累计耗时以及判定证据。若仅有相邻时钟，就给范围；未到达与记录不足分开标注，不填零、不按四倍速推算。关键检视、形成结论和答题接受分开计时，不能用后一项倒填前一项。

进出房间、门区折返、开卡/关卡、插话恢复和帧耗时属于辅助指标。现有`charts/game-clock-comparison.png`的走廊、空房和活动厅点是空间/开场参照，不是上述调查关键节点；到活动厅游戏时间早十分钟只说明这个辅助节点，不能据此认定有效推理效率提高。性能折线用于解释现实等待，亦不替代关键节点进展。
