# 人物连续帧初稿

使用内置image_gen生成，提示词见prompts.txt。侦探与占位人物分别为detective-source.png、placeholder-source.png。不是运行时资源，不替换现有图集。

目标布局：8列15行，左、前、后三个朝向块，每块5行。块内第1行站立1帧、交谈3帧、检查4帧；第2行行走8帧；第3行交互4帧、坐下4帧；第4行破坏6帧；第5行施法7帧。转向复用站立，右向计划镜像左向。

检查发现：生成图未严格遵守指定画布与等距锚点；部分侧向施法和坐姿混入正面，部分动作幅度不足。需要重绘错误朝向、固定切片边界与脚底、验证连续播放。不能把源稿缩小后直接称为原生32×48合格帧。当前只供用户检查第一版动作方向。
