# E 场景屏幕密度表面占位图

这是供 E 场景当前固定镜头绘制与裁切使用的工程指南，不是最终美术。纯图只有透明 RGBA 底和不带纹样的纯色色块；编号图单独显示编号。占位 PNG 不缩放；每个块的精确裁切坐标、投影四角、场景单位尺寸、来源函数及 SHA-256 均在 `manifest.json`。

## 画布与块坐标

画布为 1254×1254。坐标原点在左上，矩形使用 `[x,y,width,height]`；色块间有至少 20px 透明间隔。尺寸由当前 1600×1600 视口的正交相机投影得到，对宽、高分别向上取整为整数。精确小数 bbox 与投影四角另存于 manifest。各矩形是固定镜头的**屏幕密度绘制目标**，不是物理等比例的顶视纹理尺寸，也不是将几何模型缩放到画布尺寸。图案方向按投影四角和 UV 方向条目处理。

## 纹理方向与模型限制

- 阅读区长地毯在源代码中将 PlaneMesh 转 Y 轴 90°：局部 U 映到世界 -Z，V 映到世界 +X；会面地毯及寝室地毯不旋转，局部 U/V 分别映到世界 +X/+Z。
- 桌旗同样绕 Y 轴 90°：局部 U 映到世界 -Z、V 映到世界 +X。其屏幕投影四角单独给出，明确显示相机倾斜造成的压扁。
- 墙纸当前是 `uv1_triplanar` 和 world triplanar，不是普通平面 UV。`uv1_scale=0.65`，按完整 source-image repeat 计算周期为 `1/0.65 = 1.5384615` 场景单位；这与 RoomGrid 的 1 单位 GridMap 墙模块不同。浴室和四翼都使用非大厅 size=12.8 相机，因此共用同一屏幕尺寸块。墙纸周期按当前材质数值换算，未改动比例。
- 单片窗帘实际由 7 根竖直圆柱褶、绑带和流苏组成，椅背与椅垫是椭球，均没有可直接拿矩形替代的平面展开。其估算屏幕外接框仅放在 manifest 的非平面清单，**不在可绘图集里**。请先有作者 UV 或新的几何展开合同，再为它们制图。

## 未进入此位图的表面

manifest 登记了可见但当前应由程序材质或曲面负责的表面：窗帘褶、椅背/椅垫/簇绒、床垫/枕头/床罩、墙面护墙与压条、拼木地板、木作/金属/石材/瓷器/玻璃/镜面，以及动态水面。木地板、金属、水面等按当前 shader 或纯几何实现排除，不作为本轮 raster redraw；床罩虽然有方盒顶面，但当前是程序材质，且不属于当前已用纹理表面块，需用户/主代理另行决定是否纳入后续绘制。

## 量取方式和边界

尺寸、变换和材质周期由 `PublicHallE.gd`、`HallCraft.gd`、`RoomGrid.gd`、`scene.tscn`、`SalonCamera.tres` 的当前源码手工摘取；用标准正交相机基向量将表面角点投影到 1600×1600 屏幕，不是运行 Godot 的 runtime/unproject 采样。相机位置/目标来自 `show_room`；厅 size=18.2，寝室与盥洗 size=12.8。假设视口正方、相机 size 是垂直范围。房间相对原点不改变平面 bbox 尺寸。未用真实截图反推屏幕坐标，也未处理遮挡、裁剪和子像素抗锯齿；镜头固定时每个块的投影大小可复算。`manifest.json` 保留输入文件哈希，尺寸或相机变化后应重新生成。

复建命令：

```powershell
python mcp/art_style_trials/e_surface_atlas/build_atlas.py
```

原始画面对照仍是 `artifacts/style-route-comparison/runtime/E/normal.png`（1600×1600 Forward+）。它仅供视觉背景比照；尺寸数值来自 manifest 所述源码投影公式，不宣称截图采样证书。
