# 1.3 旧 Godot 宿主接入选定 DV 95 建筑（2026-10-29）

状态：正式旧宿主主楼二层开局加载通过，仍未达到 IG-01 全部验收门槛。

## 变更文件

- `godot_csharp/geometry/LegacyDvMap.gd`：复用 C# DV 解析器读取已发布的 `space.configurable_building`，将 1F/2F 房间矩形、楼层标高、楼面及锚点作为旧宿主使用的瞬时地图投影。坐标转换从设计米制经唯一转换模块 `DesignCoordinates.gd`，二维像素只作为旧导航层。
- `godot_csharp/scenes/World/Maps/DvLegacyBuildingMap.gd` 及 `main_1f.tscn`、`main_2f.tscn`：根据 DV 地板片生成路径有效网格，根据低墙片生成二维障碍。未声明的场景传送与交互不自动生成。
- `godot_csharp/scenes/Host/GeometryCatalog.gd`：将以上两个主楼地图定向交给 DV 投影，其他旧地图仍读取其原有场景；不会因缺少 DV 地图自动退回旧房间。
- `godot_csharp/scenes/World/Field/CampusMapView.gd`：在离树预加载阶段初始化 DV 地形与物理障碍。
- `godot_csharp/scenes/World/Runtime/WorldStage3D.gd`：旧 WorldView 对主楼地图改为构建 DV 95 的真实三维构件，每层独立；单一映射计算 2D 位置至 DV 设计位置再至 Godot 三维位置，三维模型不再读取旧的分散房间场景。修复楼板标高探测、原生候选站位、导航共享和初始站立。旧非主楼区域原逻辑保持不变。
