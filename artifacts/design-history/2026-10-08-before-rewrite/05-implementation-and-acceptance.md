4. **整合与盲玩**。
5. **统一（2026-10-04）**：宿主按总纲 §四 重写为第一章同样的玩法；原型的文字界面保留为开发与检查工具，不再是玩家界面。
第一章修订（第二部分 §8）与盲玩先于第二章原型完成。

### 4. 自动检查（不替代盲玩）
- 第一章：解空间穷举（不依赖行动值调参）、感知隔离、流程跳转、构建、日志无错误。
- 第二章原型：
  1. **确定性**：同一输入的六日推演结果逐位一致。
  2. **策略机器人**：至少十种玩家策略（只上课、只修机关、只拉拢某派、操纵、什么都不做等）各跑完六日；检查无万能策略、§8 五种名录库结局均可达、无死局、六日内无人饿死。
  3. **《少了一份》**：重演唯一解；对质中至少两种有效的新规则写法可被四名关键人物接受。
  4. **规则接受**：同一规则对不同人物的接受结果与其信任、欲望、成见相符，抽样人工核对。
  5. **性能**：十六人六日推演在宿主中无明显卡顿。

### 5. 独立盲玩
- 全新独立上下文的 Agent，只接收启动方式、通用输入协议与评价要求；不接收本文件、源码、谜底或历史记录。
- 有窗口、真实输入、从空白开局；保留输入与玩家可见画面。
- 报告：轨迹、有效时长、卡顿、剧情与人物、推理公平、两次反转（第一章）是否自己推出、“写”是否被感知为自己的影响力（第二章）、重复劳动、改进建议。
- 第一章目标：独立完成、无求助、体验 ≥ 8/10。不合格如实记录，修复后换新 Agent 复测。
