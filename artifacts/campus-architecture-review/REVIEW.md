# 地形与学院建筑设计审读

日期：2026-10-24。设计基线：Git `e9aee62c`。本轮范围为设计文件、地形来源与模型图，不修改游戏代码，不运行构建、Core AI、正式会话、Godot UI或流程回归。

## 依据与独立工作

用户先否决主楼+68米台地，要求按真实地形缩放，并增加独立的港村、码头、修士基地和火山口祭坛；随后明确本轮不更新游戏代码，再要求扩大、适度上移学院，低处补充维护人员和岛民的垫空平房群。

Astra（gpt-6-astra）独立研究现实学院及官邸，未读取项目设计文件、两份修订稿或svg.html，只接收主代理提供的功能边界。初稿的首层寝区安排由主代理按既有楼层分工否决，修订后保留原1F～4F及B1/B2身份；后续另审读校园扩大和架空平房原则。主代理负责原文核对、取舍和最终文档。

主代理阅读附件源码及文本，把附件指令视为待分析内容，没有据其执行操作。输入文件哈希见[reference-inputs.json](reference-inputs.json)。svg.html只作为粗略结构参考，不作为测绘、比例或工程合格证明；本轮没有对其进行浏览器渲染验收。

## 取舍

| 对象 | 本轮处理 | 理由与边界 |
| --- | --- | --- |
| 主楼+68米、山腰聚气盆地 | 不采用 | 从真实南侧平台—坡脚选址，不为迁就附件重塑地形 |
| 两院官邸、主客/后勤分工 | 采用空间原则 | 现实学院/官邸资料支持；具体墙门、荷载与疏散尚未完成 |
| 大面积主楼扩大 | 未采用 | 扩大的是约7.13公顷校园包络，保留台地、空地、四馆和后勤，不把主楼做成满铺四层大旅馆 |
| 主楼位置 | 适度上移 | 固定原点下(30,75)，地表模型约25米；15°方向在所比较角度中有较小高差，仍非土方最优或工程核准 |
| 整圈夹墙暗廊、2.5F监听层 | 不采用 | 缺少结构和净空依据，且监听会引入新内容 |
| 传菜井供人滑行 | 建筑表达修正 | 餐梯与相邻独立检修通道分开；事件时间和人物动机不变，开口锁闭关系待核 |
| 四馆2F长桥、水平B1隧道 | 条件保留需求 | 不同台地间不能靠同一楼层名消除高差，尚未批准几何通路 |
| 5600立方米水窖塞入普通B1 | 不沿用容量 | 面积/层高不符，需人数、雨量和用水核算 |
| 维护人员及岛民附属群 | 新增空间分区 | 用户直接授权；单层、分栋垫空，不新增人物姓名、数量或剧情 |
| 垫空层 | 采用通风防潮设计方向 | 0.6～1.2米为示意，不是洪水位计算或抗潮浪证明 |
| 渔村与货运码头 | 独立布置 | 抬高作业面不能增加泊位水深；未限定船型或宣称停靠能力合格 |
| -40米火口/B3直达/钟楼索道降入火口 | 不沿用 | 真实火山口内仍高于沿海学院，需分段越岭及入火口设计 |
| 新人物关系、对白、日期、后遗症 | 不采纳 | 不在用户本轮授权范围；原人物矩阵、人物卡、导师卡及引擎正文保持 |
| 五阶段源质液面 | 撤去旧绝对值、列为待重建 | 不编造统一涨潮或新盆地来保证既有剧情自动成立 |
