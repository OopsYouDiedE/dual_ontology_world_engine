## 保留的三项核心指标

令 W 为有效现实游玩小时，G 为实际推进的游戏小时，N 为本次新增正式选择数，C 为相应控制接口累计耗时小时。

| 名称 | 公式 | 单位 |
| --- | --- | --- |
| 推进速度 | G / W | 游戏小时 / 现实小时 |
| 决策频率 | N / W | 次 / 现实小时 |
| 接口耗时率 | C / W | 累计接口小时 / 现实小时 |

有效现实窗口为打开或恢复完成至关闭请求，包含窗口内的计算、投影、等待等实际经过时间。初始化和关闭归档在窗口外单列。引擎接口累计实际正式计算和提前计算的排他墙钟耗时；人工和大模型接口累计真实请求区间。并行接口区间可能重叠，因此耗时率不是 CPU 利用率，也不保证各来源相加为 1。

原来的“秒 / 游戏小时”“每游戏小时决策数”“每计算小时决策数”等反向或混用分母的指标不再作为核心显示。报告保留排他耗时、含子项耗时、均值、P95 直方图上界和实际工作量，供拆解原因使用。分母为零或接口没有记录时保持缺失，不伪造为 0。
