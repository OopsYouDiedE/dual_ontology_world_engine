# 对话与脑内推演界面实机操作记录

日期：2026-09-26。入口：Godot 4.6.1 .NET，`res://scenes/FirstAwakening/FirstAwakening.tscn`。通过 `scenes/FirstAwakening/check/playtest_ui.gd` 在真实运行视口向 Godot 发送键盘和鼠标输入事件，并保存 1280×992 视口截图。启动时将 `APPDATA` 指向工作区 `tmp/godot-profile`，日志写入本目录 `playtest-ui-godot.log`。工作区包含大量既有未提交修改，本轮不改动产品代码。

实际操作与观察：

- 开场侦探两句对白由空格推进并关闭；F 打开脑内推演。中文字符通过 Unicode 键事件输入 TextEdit，直接写成“音乐家走到门边观察。”，编辑器保持焦点。此方式不等于系统中文 IME 组合输入，后者尚未验收。
- 展开词汇后，鼠标点“音乐家”和“走到门边观察”，两段文字在当前光标合成合法行动句，焦点返回编辑器，“从头重演”启用。点该按钮得到非空 Core 结果和一条重演事件。
- 追加“未知人物开门。”后出现“第2行：未识别的行动句。”，错误行底色变化，“从头重演”禁用。重演后改稿显示“草稿已修改 · 旧重演”，旧结果保留供查看。点击“返回现场”再用 F 打开，未提交的错误草稿原样保留。
- 修正前：输入九行观察句，末行光标位于纸面下部；展开词汇会遮住末行及光标。修正后按完全相同输入路径重跑，词汇面板位于左侧，九行草稿及插入后的末行完整可见，面板没有越出 1280×992 画面。对应截图 `playtest-long-draft-before.png`、`playtest-long-draft-covered.png`、`playtest-long-draft-inserted.png` 均为修正后结果；修正前截图已按同名覆盖，前述问题系当时实机观察。
- 传声口对话通过场景方法准备入口（未从地图走到拉柄），界面显示八个选项。键盘方向键聚焦“这里原本是什么地方？”并按 Enter，实际显示铜口关于木地板和纸页的对应回应。对话期间按住 D 八个物理帧，玩家位移为零。

限制：没有验证真实 IME、完整案件流程、现场走到传声口的路径，亦未完成对话关闭后长按移动键的边界测试。截图只能证明本轮所示界面和操作状态。引擎运行时出现读取系统根证书错误，但没有阻止本轮场景及输入事件执行。
