# Core 自然书写实施记录

## 结果与范围

## 作者书写

以下是独立的语法示例，不增加游戏设定：

```dv
称谓 仓房 为「storeroom」。
称谓 木箱 为「crate」。
称谓 剩余件数 为「remaining」。

叙述 门前景象：
    她提起灯，看向门边的木箱。
    “里面还有东西吗？”

    屋内没有回答。

台词 门前交谈：
    “先看看门闩。”
    “好，我在这里等你。”

法则 领取物品，给定 人物：
    当 人物 位于 仓房。
    并且 木箱 的 剩余件数 至少 1。
    则 木箱 的 剩余件数 增加 -1。
```

叙述是一个保留正文换行的字符串；台词按非空行返回有序字符串列表。正文不需要字符串引号、转义、逗号或 `return`。文件内称谓只展开原有文字标识，不建立人物认识或对象绑定。自然法则继续使用三值命题、有序效果、既有采纳与正式执行接口。

`行动` 声明分别写明编号、类别、本人须知、现场要求、遵循、可获知和依据，并可附仅一次及原文表述；返回字段与既有行动数据一致，输入的可变容器保持独立复制。具体语法、例子和限制见 [SYNTAX.md](../../language_core/SYNTAX.md)。

## 失败记录与当前边界

[engineering-01](engineering-01/) 原样保留首轮失败：检查 runner 给负例遗漏了中性 `main`，导致两项未绑定符号在 `--emit` 中先报入口缺失，遮住目标诊断；`--check` 当时已正确定位。这是夹具错误。修复 runner 后，[engineering-02](engineering-02/) 只复核这两项；最终上下文关键字修复后，engineering-03 又以冻结的新输入完成整批检查。各批源、原始输出与失败状态分开保存，没有拼接成同一次运行。

当前语法是有明确句式的特化自然语言。它不进行任意中文意图理解、自动分词、指代消解或补全未知事实。自然连接词需要空格或引号边界；正文头以冒号结束，行尾注释另起一行。自然表达式的专用词不作为参数名；也不使用旧 define 将原文头改指其他语法。一般算法、复杂行动附加字段和精确控制字符可继续使用既有函数与字符串。完整边界统一维护在 SYNTAX，不以本报告扩大已实现范围。
