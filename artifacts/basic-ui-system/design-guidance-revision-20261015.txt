设计文档诱导性内容清理
日期：2026-10-15
修改前版本：e38297147a0fef72d1abea8b600cc3937eaa13df
依据：用户要求以移除诱导性内容为主要方式，以肯定句为主，并将更新规范写入根目录 AGENTS.md。

修改范围
docs/design-standard.md：删除历史现状表、重复裁定索引、阶段指令、实验参数与自证表述；有效的 DV 语义要求归并到系统章节。原文可从上述 Git 版本溯源。
AGENTS.md：增加设计文档更新规范，规定删减优先、肯定表达、信息身份、唯一正文、版本证据与文档核对方式。

主要处理
总纲：保留认知驱动与共同机制，删除自动推进、主案保通和动机公式；操作意图、实际执行、信息与请求回应分别表达。
世界与契约：保留既定历史与契约正文；删除未经具体行为核对的免责表述，将创作参考与世界规律区分。
人物：保留姓名、职业、年龄、外貌与既定关系；删除受众偏好预测、强制未来弧线和人格公式。当前习惯与实际经历共同参与选择。
第一章：保留昨夜时间线、物证和开场话语；删除共同居留已获证明的残留、固定误读结果、固定行动映射及证物编号直通答案表。答辩按完整因果论证说明依据。
时间：保留明确标识的节奏参考和测量预算，删除到点完成与保底救场的保证，作答、开锁和跨门分别记录。
第二章：保留物资分配、外出求生、世界压力和条件事件；删除人物过错配额、必然社会反应与无证据的预防成效结论。
系统：以现役 DV 动作合同替换旧 C# 类名和第二条动作接口；保留状态继承、独立推演、来源、成本、认知运算和强制刻画要求。
视听：删除字体认证真伪、匿名物证颜色泄密、资源完成声明与旧测量自证；保留艺术方向与制作参数，音乐随实际情境呈现。

文本核对
对照修改前文本审阅删除与新增内容，检查契约正文、昨夜既定历史、信息边界、格式边界、章节引用和表格结构。
使用 git diff --check 检查补丁格式，检索旧接口、历史时态、预设结果与失效章节引用。
本轮为纯文档修订，未执行游戏验收、构建或流程回归。DV 内容、引擎、宿主、生成物和保护基线保持原状；新设计的运行表现仍待后续实施与相应验收。
工作区已有未跟踪产物保持原状，仅提交本轮设计文档、根 AGENTS.md 与本记录。
