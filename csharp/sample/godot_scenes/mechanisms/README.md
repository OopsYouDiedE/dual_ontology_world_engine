# 五幕机制演示

在 `game_resource` 目录运行 `node server.cjs`，打开 http://127.0.0.1:4173/mechanisms/index.html 。

本目录为独立浏览器美术交互原型。尚未调用 C# Core；认知状态、凭证判定、邀约及规则废除使用本地演示脚本。移动、实时播放、界面留在展示层。国际象棋只演示邀约、入座和双方落子，没有完整棋规。

## 操作

- 点击顶部切换五幕，右侧操作推进剧情；重演按钮还原本幕。
- 点击地面或使用 WASD / 方向键八向移动威尔逊。斜向速度归一；剧情动作期间由分镜控制位置。
- 行走使用八列方向、三行动作的 sprite atlas；按 0、1、2、2 播放，末帧多保持一个帧长。闲置使用中间帧。
- 暂停画面后可单步一帧检查。音乐需点击开启，使用 Web Audio 生成 8bit 小调；未制作语音配音。
- 言灵：佩戴凭证 → 举符 → 七秒现实显露。
- 推演：危险词 → 停止联想 → 替换为“来访者” → 灰色人偶复现动作。
- 邀约：选择同意或婉拒。同意后走向棋桌，点击落子。
- 恶作剧：贴规则后自动演出；群体绕圈 → 伯爵加入 → 寻找来源 → 撕纸斥责。
- 保护：开始伏案 → 阴影增长 → 同伴靠近并打断 → 恢复注意。不呈现具体脑内线索连接。

## 美术

所有角色与场景由内置 imagegen 绘制，最终提示词见 `art-prompts.json`。共 5 张游戏图片：

- `assets/manor-stage.png`：1536×1024，斜俯视庄园书房。
- `assets/wilson-walk.png`：威尔逊，8 方向 × 3 动作，原生透明 PNG。
- `assets/maxwell-walk.png`：麦斯威尔，8 方向 × 3 动作。
- `assets/gray-walk.png`：共用灰色人，8 方向 × 3 动作。路人、同伴与人偶不另建形象。
- `assets/story-actions.png`：6 列 × 3 行，18 个动作格，原生透明 PNG。

动作图第一行：施法 3 帧、伏案/惊醒 3 帧；第二行：撕纸 3 帧、邀请 3 帧；第三行：双人棋局 3 帧、灰色同伴打断 3 帧。棋局第三行使用人工校准的横向切片边界。麦斯威尔和灰色人原图为白底，加载时仅清除与图边界连通的近白区域，保留被轮廓包围的面部、衣物与纸张，不改写源文件。

五幕共用同一书房，青灰覆盖层表示脑内复现；阴影、光晕、路径和简易规则纸为展示层绘制。精灵图是手绘生成稿，尚非完成逐像素修整的生产资产。

## 检查记录

已通过 JavaScript 语法检查，并在内置浏览器检查素材显示、无凭证失败与施法收束、停止危险联想与替代推演、同意邀约及入座落子、恶作剧自动废除规则、同伴打断后危险认识归零。点击地面可行走，暂停后单步可切换到第四个停顿帧，配乐开关可切换；浏览器控制台未出现错误。键盘八向的方向映射与斜向速度归一已作代码检查。
