# 动物园规则怪谈：认知与规则实验

网页和终端共用 `runtime/ZooSimulator.Runtime.csproj`，直接引用 `godot_csharp/core`。作品基准为 `docs/动物园规则怪谈原文和解析.md` 中的原文、作者 Q&A 及新增模拟推论。九份原始文书共 97 条；受控中文映射存于 `Rules.txt`。伤害速率、接触阈值和具体步行距离是本例的数值建模选择。

## 运行与对照

在仓库根目录执行：

```powershell
dotnet run --project csharp/sample/zoo/zoo_web --urls http://localhost:5127
dotnet run --project csharp/sample/zoo/zoo_simulator -- --seed 7 --visitors 120 --time 480
dotnet run --project csharp/sample/zoo/zoo_simulator -- --seed 7 --visitors 120 --time 480 --withdraw Visitor.8,Visitor.14,Visitor.6,Visitor.7
dotnet test csharp/Core.sln
```

一分钟对应一个行动值。默认从第 1 天 08:00 开始，每天仅 08:00–16:00 接待游客；首批 120 人，此后每 15 分钟一批，次日重新接待首批游客。步行速度 60 米/分钟，通道一般 2–8 分钟，参观 18 分钟、休息 20 分钟。角色按游览经历和入园时长形成离园计划。红衣员工下班后回家，次日 00:27 回到员工入口，依据脑内岗位和地图选择返岗行动。

`--time` 是持续时长，`--start-minute` 是绝对起始分钟，`--max-steps` 是计算预算。未到目标时刻就耗尽预算返回 2。`--report 路径` 输出人物、结局、各日入园量、交互次数和机制记录。`--catalog` 查看全部文书。诊断参数 `--rules standard|none|gate|all` 只保留于终端，网页不再显示四种模式。`none` 不含初始文书，人物仍可现场阅读，不能用于代替撤回规则的实验。

## 规则如何影响行动

```text
当 危险 时 优先 前往:狮子园区 权重 120；当 总是 时 禁止 喂兔子 权重 100
```

`ZooRules.Parse` 将受控中文解析为条件、行为及优先级；`ZooMinds` 在此人的内部世界中解析对象、路线及空间适用范围，通过 Core `AstDecoder` 编译为类型化 `Rule`。人物采信状态决定规则是否参与判断，理解程度缩放权重。`DecisionSystem.Assess` 列出候选、每个来源的加减分、禁令及最终排序。自然兴趣也形成候选，因此删除禁止喂食确实可以使喂食成为首选。

保存文书只更新现场版本。保存并广播通过 `ObservationSource.Testimony` 更新听见者；馆内及封闭宿舍收不到园内广播。仅撤下现场文书不会抹掉旧记忆；撤回并广播会撤销听见者的旧建议。之后入园的人阅读当时实际存在的版本。修改不追溯更改已排队的行动，实验者可明确取消未完成阶段并重新决策。

`ZooAnomalies` 不读取文书编号、规则目录或采信状态。喂食、换衣、受损、保护与逃离条件由真实行动和客观状态结算。同样的行动在不同规则知识下具有相同后果。删除某条文书不会直接生成死亡或黑衣人数。

## 脑内实验

网页可以编辑任意脑内对象的名称、类别、存在判断、所属位置、标签及关系；可新建未绑定现实的幻觉对象、遗忘对象、写入自定 Core 信念。所有写入经过 `Observation.Observe`。自身投影也可遗忘。遗忘后，人物无法在思维中指代行动主体，自主决策停止；宿主保留的身体与旧引用不会成为脑内对象。内部的当前判断和日常计划仅在仍能指代自身时重新形成。

1. 选择一名人物，修改脑内场景的 `危险征兆=1`，保留其他希望保留的标签。右侧比较改变前后的候选。
2. 点击“取消未完成行动并按脑内重选”，角色以现有认知提交行动。此按钮不会先重新观察而抹掉实验输入。此前已结算的消耗不返还。
3. 查看最近实际结算、个人路线和观察历史。点击“重新观察现场”，再比较决策。实际未锁而脑内认为锁住的门会被避开；幻想出口可以被选中，但实际执行失败。

在兔子园区选游客，再撤回并广播 `Visitor.8`，即可看到喂食候选从“禁止”变为“可选”。危险时其他避险规则仍可能胜过喂食，这正是完整评分对比所展示的结果。

## 言灵与 Core

网页言灵输入是通用 Core 效果 AST，例如：

```text
sequence(temporary_set($Scene, 树荫, 0, 15), temporary_set($Scene, 言灵安静, 1, 5))
```

游戏只提供人物的施放次数、准备意愿与一分种施放延迟。解析、资源支付、嵌套等待、实际结算、临时状态叠加和到期撤销均由 Core 执行。可在 AST 中组合 `set`、`change`、`require`、`wait`、`infer`、`say`、`temporary_set` 等节点。

`TemporaryStateProperty` 保存临时覆盖层：后施加者覆盖先前层，各自独立到期；期间普通 `set/change/spend` 操作基础值，到期后露出最新基础值。同一无等待阶段先准备再提交，失败不留下临时层或到期任务。等待之前已提交的阶段不会因后续失败而回滚。临时标签须由场景机制使用才有实际作用；只有声明为可观察的状态才出现在现实表现中，人物还需要再观察。`Locked` 属于独立门锁 Property，不能用临时标签覆盖；可用普通 Core 开锁或状态操作处理门锁。

## “它”和异常

“它”拥有独立身体与 `SoulEssence`。作品的超自然感知通道向它提供光影拓扑；它依据自己的认知选择相邻通道，白天寻找树荫，夜间趋光，正常白狮降低接近意愿。行动经 Core 等待后移动，抵达前会核验传播媒介是否仍存在。因此途中去掉树荫可以使行动失败。到达后显现所在区域对应的异常，之后约 15–20 分钟重新考虑行动。界面显示位置、选择和评分理由。

它只在近处感知人并更新分类；远处显示的是旧判断或尚未观察。真实物种、人的自我认知和它的分类分开保存。虚线纸与猿猴混处干扰分类；相邻暴露、察觉外露、认知侵蚀、身体接触和后续生理发展形成风险链。白狮驱逐关注并稳定可救者，严重兔化可能被清除；健康参观者不会被标成“获救”或获得终身免疫。员工被正常白狮咬伤但存活、实际在门口换上黑衣，均可产生新黑衣路径。

黑衣仍是真实人类。未发生危险条件时没有新增黑衣是允许的结果，不通过每日配额生成。其清晨离园窗口仍为 06:00–06:30，按行动完成时的实际条件判断。

## 避险、禁令与岗位返回

身份动摇的人抵达狮区后会先进行身份确认。白狮稳定可救者并驱散关注；已经稳定的身体症状不再单独触发重复避险，原有身体转化不会凭空治愈。身份恢复后只回忆此前因认知下降而遗忘的出口记录。严重身体兔化仍按原有机制处理。

被采信且条件成立的 FORBID 硬排除匹配行为，偏好权重不能抵消。匹配穿透外层等待与组合动作，目标槽位独立绑定；目的地禁令覆盖所有已知入境通道，包括多段行动中的通道。禁令属于人物的主观决策，直接提交实验行动仍由客观运行时判定可行性。

蓝衣与保安在脑内保存岗位地点关系，离岗完成行动后产生白天回岗计划。默认人员配置及四语编辑说明见网页 README。

遗忘会删除指向该概念的关系与依赖它的规则。正在执行且引用被遗忘对象的行动取消后续阶段，已提交的阶段保留。常规观察和自动思考不重新补出已遗忘的自身；身体继续承受环境影响。缺失自身认知不按人类信念为零处理。
