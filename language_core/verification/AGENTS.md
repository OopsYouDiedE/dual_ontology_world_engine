# 自动验证模块工作边界

本目录继承根和 `language_core/AGENTS.md`。当前只有正式设计；拟议模块、API 与四个 DV 入口见 DESIGN.md，均未实现，不提供虚构运行命令。

主程序及最多三个补充程序算法全部用 DV，C# ABI 仅平台 I/O。权威裁判、主体输入、只读证据和报告分域；checker 不回写主体或改变调度。章节实例与答案只从 `.story` 装载，本目录仅通用机制。

后续按数据分域与 manifest、代价执行、剧本接入/调度、来源记录、只读判定、补充程序推进。架构和合同调整同步本文件及 DESIGN.md；证据保存在 `artifacts/partial-bootstrap-core/` 新目录，保留原始字节、不覆盖。

本轮用户只授权正式设计，不实现或运行验收器；停止独立复评继续有效。工程检查不能代替机制或游戏验收，禁止流程回归及通过计数评价。

## 原生源、预算与人类报告的实施记录

新会话只执行原生DV定义的具名法则和命名构造函数，JSON只是编译执行后的DTO；旧.story仅只读溯源，不是运行输入。oracle独立分包，角色运行包不导入oracle。累计时间从initial.physical.time起算，允许时长由批准的DV实例给出；准备、提交、接受与分享各自记录，不重启计时或改代价。
`run_verification.py --source-root ... --session-only` 先真实执行隔离会话；`--judge-only ... --primary-only` 可单独封存只读主判定并明确补充未执行。`report/*.dv` 生成中文状态、节点、行动与来源，人物/动作名称来自冻结原生内容标签；原技术ID和完整refs保留在原JSON，不替代正文。会话进程与判定进程耗时分列，新判定合同重执行不冒称再次游玩。报告呈现版本与原判定版本分别封存，已知节点误绑定原输出不可覆盖。独立复评继续按用户裁定停止，未执行目标不得报成立。


历史只读重判可显式使用 `--judge-core-root` 独立封存判定器的 Core 依赖。原生产者、oracle与轨迹保持原封存版本，新ABI不得冒称旧会话运行过新机制；输出分别记录生产者与checker依赖来源。通用DV报告开头给简短实测结论及具体因果缺口，完整轨迹/原判定JSON保留。
