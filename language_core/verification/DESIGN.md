# DV 第一章会话结构

真实行动回执在Complete已结算时间后推进本人的元时间及已声明、已初始化的本地时钟，来源单列execution-receipt。同次钟面观察合并，未知时钟不注入值，不读其他世界事实或重复计时。完整轨迹可选gzip存储，解压值与原JSON相同；其保存时限与逻辑推进仍分列。


## 接管修复的当前接口（2026-10-18）

调度在时间推进后允许无候选主体再次处理现场与收闻，保留同一时刻的重复准备抑制。章节刷新不再用调查专用签名代替全部日常、沟通和规范目标；个人实际入厅后才结束携带目标。

章节目标以 navigation_room 声明执行地点，navigation_requirements 供选择意图时参考，navigation_methods 或 method_id 指向需完整核验的实质方法。日常、调查与沟通只产生一个路由首步意图。前缀只能沿本人已知开放并已采纳的移动法则；下游未知门只产生安全侧接近，不预测其开放或任务结果。正式执行资格、报价、Complete、观察与传播保持原链。

Runtime 完整保留传入 JSON 值；只读 debug 投影显式列出主观计算并说明快照范围。事件索引将选择、排队、可用与实际回执分列；时域停止与剧情完成不互相替代。

跨区投放把侦探接入实际开题、铜口、独立个人阶段与正式判答，人物辨认和完整原因分别保留条件与回执。真实侦探回执加入原放行/显现的报告条件，其余安全与时间边界保持；所有实际移动仍经同一Complete。

付费模型缓存采用保守的同上下文重比条件；不完整模型、来源变化或候选变化重新调用dvs_model。停止诊断明确空计划与未完整计划，不能将空预测解释为有效反事实。

2026-10-18接口维护：现役session归并为10-subjective、15-action-planning、20-speech、25-simulation和30-runner；下表旧35-model-argument的职责现归25-simulation。失败语义签名在可重复资格之前核对，Complete失败后保存，成功后清除；显式failure_grants仅对formal-model现场回执授权，native失败保留后续正规检视。等待按本人有来源的窗口边界分段，不读取同伴私有目标。

chapter2 daily将会议收束与完整签署分开；截止事件不写个人选择。成功后本人观察可由row.observation_grants声明；系统chapter_summary在真实闭会后输出，保留未知与未决，不成为人物认识。环境低鸣/余震为持续现场信号，经正式现场观察取得。具体内容以设计规范为准。

独立检查保留重演与撤回算法，核对dispatch、Replay_Depth、遮蔽、冻结切片输入、接纳及信任来源；生产撤回事件保留完整前后快照。编译、语法和序列化工程证据与正式一级会话分别报告，不执行流程回归。

同一次执行的本人、现场与公共授权共用感知身份。公共传播从本次action_execution之后的实际观察建立索引，只补新字段；public_grants_projection登记已有来源和入口，重复公共调用仍拒绝。观察事件grants保存实际子集、declared_grants保存声明；不产生第二份伪独立支持，不改变聆听与理解。第1轮异常保留，第2轮集中修复后从新正式会话复测。

第一章内容由原生DV声明，运行器由core与session模块编译而成。内容位于scenarios，oracle独立导出，JSON承接程序之间的数据交换。

宿主调用 `dvs_session_open` 建立会话，`dvs_session_prepare` 推进一个人物的决策，返回待执行行动；实际执行后以 `action_event/outcome/actual` 调用 `dvs_session_complete`。世界法则、代价结算、个人观察与听闻全部在 DV 完成。序列化会话可原样恢复待执行阶段；宿主不提供答案或认识补丁。`dvs_run` 是使用同一协议的连续逻辑执行器，实际 Godot 输入与几何接线单独实现。

## 模块关系

| 模块 | 职责 |
| --- | --- |
| scenarios | 初始世界、人物、规则、话语、方法和章节协议 |
| session/10-subjective | 本人推知、假说及准备状态 |
| session/15-action-planning | 目标、信息价值、多步路径与首步选择 |
| session/20-speech | 话语、实际收闻、理解和采纳 |
| session/25-simulation | 历史重演、特征比较、候选排除、解释论证、动态答案和公共提案 |
| session/30-runner | 主体轮转、执行、观察和回答协议 |
| checks / report | 只读判定与中文报告 |

已知机会等待只在规划根层比较；后继层不重复预测等待。扩章时内容依据主体实际地点决定是否继续携带第一章动作与目标，已到起居厅的首夜八人进入第二章内容；第二章学员规划深度最多为 2。等待时长、天气观察和连廊资格由内容声明，执行仍沿 prepare/complete。

回答协议在内容中提供 stage、progress_ref 和 completion_ref。公共提问的传递仍由实际听觉和发布回执形成，隐藏话语事实只沿个人聆听链进入认知。

推演时间线的 dispatch 指定选择字段和候选法则。运行器从已采纳法则本身提取合取中的等值条件，依据预测状态排除不适用分支，并记录选择输入。候选输出在推演开始时全部遮蔽。索引分派与每条实际预测分别计费，无法建立索引时执行原始规则组。候选排除证书登记可使用的推知法则版本，核验仍重放实际推知及其观察来源。

## 认知过程

运行器以各主体的初始认识开始。本人观察、已闻问题、采纳规则和策略决定推知、理解、假说及行动。话语的字面命题、预设和暗示分别保存；说话者的听者模型预测与听者实际理解分别产生事件。

重演使用本人的假说与预测法则，输出阶段状态、覆盖和特征比较。竞争解释及来源参与估计论证，论证支持输入变化后可以撤回。

## 行动与回答

规划比较多步路径，执行当前首步。候选资格、评分和选择门槛分别处理。独立场景可声明自己的时域；生产 campaign 覆盖五日内容时域，保留原有限行动额。共享时钟记录实际执行经过时间，时域边界不代表章节完成。

有净正值当前非移动行动时，有限策略仍先完整比较一层生成后继，之后保留已比较路径的最佳首步；根层结果、后继层结果、完整层数和停止原因保存在同一选择记录。不足以比较整层的预算、深度上限与无预测后继分别记录，不保证全局最优，不改变累计工作预算或真实费用。重新询问仅读取执行时的实际公开题目与开放字段，不提前授予答案。

若所选首步为移动，成功 Complete 后只暂存该路径的下一非移动行动。下一次本人决策重新运行认知与规划；新规划中该行动仍直接可执行且净正值时兑现，否则放弃。兑现记录本轮分数及被替换的路径，现场失败不会生成承诺，也不会把预测效果当作执行结果。

阶段交接的实际收据可成为本人重新确认公开题目的来源。内容目标以本人已收阶段字段的时刻刷新开放字段证据下界；错过问话后必须由正式听闻或本人现场重新核对取得新回执。重新核对读取当前物理公开字段作为直接观察，不复制漏听话语，也不触及答辩判准。

开场收到的持续公开信息可激活专业主体的本人材料目标，不随题目阶段改名失效。询问动作本身只形成请求；专业主体须由自己的检视或试验获得内容，再通过实际回复传播。包含话语的答辩在候选资格和完成时均检查本人话语真值。

动作费用分为时间、计算和体力；执行链包含报价、预留、实际回执和结算。回答协议分别表达字面成立、本人依据、问题匹配、完整性和正式接受，随后产生阶段转移及公开回执。

请求签名比较本人前提的语义状态及实际地点/声道，不因观察编号或时刻更新自动重问；仿真和论证仍保存完整来源。总模型预算耗尽时不再提供新的重演执行，已有有效模型读取保留。原生站点动作通过 travel.station 指定既有几何热点；同地点到达也需要现场回执，之后才执行 DV 接触法则和声明的本人观察。预测只改变接触标记，不预测未知回忆内容。

## 行动时间队列（2026-10-16）

正式会话在主体 scheduled_action 中保存 action、start、due、成本模型、选择所需引用及来源事件。Prepare 先扫描队列与可决策主体；等待者不进入认知和选择链。到期行动重新按当前物理世界报价，由宿主回执进入同一 Complete。scheduled_start 使 action-cost 只结算一次费用；世界时钟已经等待的部分不再累加。当前执行回执的时间必须等于排队时声明的时间，变化时明确报错，不能默默重排或倒拨时间。无排队起点的 Core 调用保持原即时结算合同。

等待推进按可分析时钟边界执行环境法则，变化尚未稳定时逐分钟结算，实际效果继续在 Complete 后产生。相同时刻按循环主体顺序处理到期项。空闲主体同一时刻至多尝试一次；零可用行动与仍有排队行动分开判断。队列和延后收闻随主体保存、扩章与恢复。pending_heard 只存实际听到的话语及当时声道证据，到期后理解；不重新检查已经结束的声道，也不让等待者执行话语理解模型。

dvs_owned_state_update 的线性会话外壳转交范围增加调度 cursor、physical、events、idle、actors、pending 更新；它仍不修改既有字段对象。队列只存 Complete 所需 relevant_refs 与 selected_path，不嵌入整个规划搜索结果。事件保留原独立快照合同。refresh_refs 将复查目标限定到本人已知的相关字段时间；内容列表重建不自动刷新所有观察目标。
