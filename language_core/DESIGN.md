# DuelView 语言与运行架构

DV 用原生声明和通用计算表达世界法则、不同主体取得材料、形成理解、采纳判断、规划与行动。本文维护现行工程架构及其语义边界；完整语言方案在 [SYNTAX.md](SYNTAX.md)，剧情与玩法以 [设计规范](../docs/design-standard.md) 为准。源码中的可执行能力、未来语言目标和实际验收证据分别判断。

## 当前架构

| 层 | 实现 | 边界 |
| --- | --- | --- |
| 编译器 | `10-compiler.dv` | 词法、缩进、启动/表层语法、基本名义检查、C# 生成 |
| 平台 | `compiler/seed/`、`compiler/Runtime.cs` | C0 语法启动及基础值、容器、文件、控制台 ABI |
| 领域机制 | `20-core.dv`、`30-session.dv` | 世界、认识、价值、费用、推演、规划和正式会话 |
| 原生内容 | `40-chapter1.dv`、`50-chapter2.dv`、`60-game.dv` | 内容条件、人物配置、连续章节与宿主呈现绑定 |
| 独立核验 | `70-checks.dv` | 因果检查、oracle、夹具与报告，不进入生产 include 闭包 |
| 宿主边界 | `Session/Session.cs` | 会话调用、审计作用域、序列化与存档 |
| 现场宿主 | `../godot_csharp/` | 实际输入、几何、碰撞、音画与执行回执 |

`60-game.dv` 依次 include 20/30/40/50；`70-checks.dv` include 60。模块由 `tools/dv_toolchain.py` 组合，并保留文件边界、define 作用域和位置。`tools/build_session.py` 默认编译生产入口，Session 项目将生成源与 Runtime 一同交给 .NET 8；旧 Kernel/WorldCore 解释链已退役，不保留第二套游戏执行逻辑。

编译器自身仍使用 S 表达式启动源，由 C0 生成 C1，再生成 C2、C3，工具比较 C2/C3 的生成源码。20–60 使用 surface-v2 执行子集，70 保留部分旧报告函数与 JSON 只读输入。当前直接生成 C#，完整闭包、通用泛型、量纲推导、能力系统及目标无关 Typed IR 尚未实现。自编译固定点只说明对应工程一致性，不构成语言正确性的形式化证明或游戏验收。

## 世界、认识与来源

权威世界记录真实状态与实际变化，mind 保存该主体已取得材料与可错认识。本人对他人的模型仍属于本人的预测空间。领域命题保留真、假、未知及支持/冲突信息；程序控制使用二值 Bool。观察、证词、回忆、推知、假设和估计分别携带来源，复制证据不会产生新的独立来源。

`infer`、`predict`、`enforce` 的采纳范围分开。主体运行只读取本人合法材料与采用的规则，预测不能读取隐藏物理值作为已知结果。证据支持份额与来源可靠度分别保存；默认置信度不超过最强实际来源可靠度。`dv_same_local_ref` 将省略主体的字段解析到本人，显式其他主体不等同；推知依赖由法则与输出字段标识，重新推知替换对应来源，事件身份继续表示实际发生的那次推知。

专业请求只是实际动作，不直接取得命题；另一主体必须自行知道、取得回复资格并真实发言，接收者再经实际听觉传播与解析取得材料。候选接收者与实际可达性分列，远端通信的本人端口地点不能替代远端身体共处。公开行动观察只传播到声明范围和真实同处/可听者，未知姓名、问题和规范不得提前公开。

`speech.advice` 在真实 listener_parse 后登记；advice_decision 经本人共同价值比较并成功 Complete 才更新立场。接受建议、执行行为和因果归因分开，选择发生在解析之前的行为不能归因于这次建议；只有时间链而无独立归因证据时保留 `causal_attribution=not-established`。实际操纵后果、规范表态与私人执行结果不能由预测生成。

`norm_proposals` 保存已取得内容，`norm_stances` 与 `policy.norm_rules` 由本人成功 norm_decision 更新。`owned_decision.context_policy_keys` 将明确列出的本人政策纳入上下文与来源快照；缺省仍使用原事实/请求比较，不读取他人政策。重复回复依 `repeatable`、`once`、`response_once` 与实际成功账本核对，收到材料不等于已经完成回应。

## 资格、选择与规划

人工候选、自主直接选择、预测搜索及同组个人选择共用正式门槛。`manual_only` 只在人工临时资格视图开放；候选出现不改世界，执行前再次验证。`completed_actions` 只记 applied Complete，`used` 保留失败尝试。正式个人答辩接受与公共结论独立，读到他人结论不能替代本人的支持材料与实际提交。

规划记录即期分、路径回传分、预测后继、本人来源、展开工作和停止原因。行动树使用独立的 `plan_budget/planning_limit`，依赖闭包使用 `dependency_budget`；付费模型资源与实际时间分别结算。`Replay_Depth` 限制有序因果重演，`plan_depth` 限制行动规划，两者不能互相冒充。总模型预算耗尽后不启动新的付费重演，旧有效缓存仍可读；上一方法余量不作为下一方法资格的错误门槛。

`owner_utility` 依本人声明数量进入共同评分并保留分项，所读本人引用进入依赖键。私人执行净效用可影响资格和共同比较，但不改资源扣费、世界法则或预算。支持性陈述与完整答辩的奖励、资格和权威接受分别处理，不能用通用话语分覆盖专用答辩证据。

根层存在可执行且净正值的非移动行动时，既有有限理性策略先完整比较一层后继，再保留已比较路径中的最佳首步，移动也参与比较。实际完整层数、预算不够、没有后继和深度不足分列；该策略不保证全局最优。成功移动后暂存下一非移动意向，也须在下次共同认知/规划中重新成为当前可执行正收益行动，否则丢弃；预测不预执行。

导航从本人已知开放路径和采用的法则生成首步，未核实下游只能接近安全侧。`navigation_room/requirements/methods` 维持本地实质资格；`maintain_presence` 在本人已达指定时窗地点时避免追加无关纯导航，实质行动仍参加比较，不锁死位置。一次导航按任务完成、要求、通路、位置与窗口选择意向，全部实质目标继续参与规划。

`opportunity` 只评价本人未完成目标的有据接近机会。access_only 只预测本人移动到明确方法地点，保留非空间资格，不预测他人响应或成功。起点已在场的机会也占去重键，同一路径按目标只计一次；机会分属于当前叶节点，不能累加到无关后继。路径循环键使用预测认知状态，临时位置成绩不让绕回同一状态成为新进展；跨路径非支配比较仍保留所需累计信息。

等待只从本人有来源、未完成且非时间条件已成立的未来机会生成，`known_opportunity_wait_choices` 要求准确 target_time、本人为真的 available_when 与非空 basis；歧义须报告。等待与当前责任是否同时比较由明确声明决定，保留费用、时段和真实 Complete，不能用预知答复压制当前行动。

## 检视、重演与缓存

检视的实际输入语义签名与明确新鲜度限制共同去重，未知结果同样是一项真实尝试。请求签名保留引用、已知/值/争议及前提真值，过滤纯观察时刻与来源编号；地点/声道、主题与方法前提继续区分。接收者无关 last_action_event 或时间戳变化不能制造新线索，真正前提或现场变化允许重新询问。

`refresh_until/refresh_refs` 只在本人尚不知停止命题时，用已知相关字段接收时刻和 minimum_time 刷新证据下界；缺声明保持原下界。本人时钟、无关观察与检视自身时间不自动刷新所有目标，不读取 physical 或预测历史。阶段交接仅记录实际收到的字段，错过公开问话者需要现场重新核对，不能补成已听闻。

重演由本人已采纳法则的读写依赖逆向选取证物相关切片，仍遮蔽计划全部输出并支付实际工作。切片一致不等于完整解释，矛盾须有实际预测和本人观察来源。付费重演缓存只对已完成且无执行失败的计划复用，完整候选、本人 revision/time、采用规则、响应模型、有效 Replay_Depth 与模型起点均匹配；缺新来源字段就失效，不刷新旧模型来源冒充重新推演。

纯预测备忘依赖完整 mind 或明确的完整投影，私有规划可省略不被算法读取的审计 history/seen，保留 revision 和所有语义输入；新增历史读取必须恢复对应依赖。公共预测、真实历史、事件去重和完整证据不由私有优化删除。局部推知固定点键涵盖 infer 采纳、前提/输出字段、来源、历史推导、签名和剩余预算，推知前后完全不变且未阻塞才能复用；语用、假说、准备、论证与话语继续按自身合同处理。

完整认知或空闲复用还须覆盖本人时刻、章节、政策、模型、解释、支持来源、实际收闻和同处上下文。单个长度、时间窗口或零候选不足以证明稳定；活跃解释或付费预测无法闭合依赖时按原链运行。`reason_reused`、`cognition_reused` 与真实 planning_stop 的引用分别报告，不生成虚假的新认知来源。

引用绑定索引按完整 bindings 构建，重复映射仍在核对时报告歧义，仅缓存依原次序完成的成功验证。来源事件索引保留完整候选、claim、after、basis 和原事件顺序；索引命中不是支持证明。动作目录可按声明地点保序切片，未知地点回退全目录，动态资格仍逐次求值。静态内容仅缓存不读取会话/世界/主体的构造器，动态目标仍核对本人条件与实际收据。

## 行动调度与状态提交

Prepare 先扫描到期队列与可决策主体，生产组合只刷新本次选中主体的内容，再进入共同认知、选择、报价与排队。已有人类选择时不另排主体，有 pending 时不重复分派。`scheduled_action` 保留动作、start/due、成本与必要 relevant_refs，不嵌入整个搜索树；到期回执经同一 Complete 结算一次费用。

环境推进使用已采纳时钟边界和真实到期点，未知或仍可能增量/级联的过程保留逐分钟结算；once 仅在实际 applied 后挂起。等待主体不重复搜索。`pending_heard` 保存实际听闻和当时声道证据，到期理解，不根据未来位置重写过去听闻。

实际 Complete 以已结算 execution.time 推进本人 mind.time，并只为有声明 clock_ref/bindings 的时钟生成执行回执观察。连续章节扩展保留世界、主体、剩余配额、队列、账本和事件，物理闩开启、授权放行、内容安装、主体到场和正式交接分别产生实际证据。

`dvs_owned_state_update` 只用于放弃前态的线性会话外壳更新，保留未知字段与 pending/initial/输入状态，不原地改旧字段对象。world/mind、预测与证据仍按独立复制合同分叉。`dvs_speech_owned` 只在线性 Complete 替换实际收闻者；通用 speech 先独立复制主体列表。法则、观察与采用表的私有暂存构建先复制输入，按原次序验证，失败丢弃，成功后发布；中间暂存不可当作共享世界或预测分支。

## 数值、接纳与刻画

基础通用数值保持有限 double，显式 Rational 提供精确有理数；数字文本不会自动成为运行数值，名义接纳、概率、置信度和动作评分各有用途。数学范围合法不等于领域命题为真，也不构成来源证明。详细 ABI 与重复键语义见 [compiler/README.md](compiler/README.md)。

`mapping` 将具名映射与输入展开为普通 DV 调用；乘法外观不规定矩阵算法。`acceptance` 根据显式 degree 与有序门槛分类，完整主体/依赖类型与自动更新系统仍属于语言方案，不能把库函数能力描述成已实现所有设计语法。

有限域 imprint 以目标、允许变量、守恒、资源/工作上限和价格声明构造配平。DV 搜索枚举声明域，独立核验器重算可行性、成本及最优覆盖；`dv_imprint_prepare/apply` 通过既有费用机制在同一返回状态提交认知、资源、账本与工作额度。Optimal、可行候选、无解和未解决分列，缺少覆盖证书不称已证明最优；连续和一般非线性求解器尚未接入。预测求解不产生真实支付或脑状态变化。

## 证据与实现边界

公开事件在不可变快照边界发布，原始 DAG 持续保存节点、事件、父边和来源；投影只供调试，不能作为人物新增认识。普通游玩按明确审计策略省略指定大字段，正式推理消费者所需历史仍保留；完整审计、精简模式和私有预测的范围必须分清。存档、恢复、partial、精确类型、共享 DAG 与关闭合同见 [Session/README.md](Session/README.md)。

后续语言目标包括带主体/来源/版本的类型、完整切片与认知运算符、record/enum/scalar/generic、单位/效果/能力推导、闭包、一般分布/模型声明和目标无关 IR。这些目标不由现有表层语法、数值构造器或编译固定点自动满足。具体实施必须接入同一编译器与正式会话，并依据实际工程及游戏记录说明覆盖范围。

研究来源集中在 [REFERENCES.md](REFERENCES.md)。旧报告、实验失败、候选基线和原始记录从其对应 Git 版本及任务目录追溯；本文不沿用它们宣称当前版本已通过完整验收。
