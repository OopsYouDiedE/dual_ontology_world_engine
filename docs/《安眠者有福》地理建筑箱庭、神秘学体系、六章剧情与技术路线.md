## 第四部分：现代 RPG 与模拟经营级技术路线（极致性能与等效双层认知架构）

为了在普通 PC 上实现**零卡顿、毫秒级结算**的多人博弈与环境模拟，引擎融合了《天国：拯救》《博德之门 3》《模拟人生 3/4》《环世界（RimWorld）》与《缺氧（ONI）》的工业级优化方案：

### 一、 四级多频时钟（Multi-Rate Tick Architecture）
1. **帧级时钟（Frame Tick，$60\text{ Hz}$）**：仅处理当前玩家所在房间内的 2D/3D 角色移动碰撞、灯光火苗微摆与手绘 UI 笔触动画。
2. **秒级时钟（Fast Sim Tick，$1\text{ Hz}$）**：处理邻近房间的声学漏音衰减、气闸压差变化与视野包络检测。
3. **刻钟级时钟（Macro Room Tick，游戏内每 $15\text{ min}$ 触发一次，耗时 $< 0.05\text{ ms}$）**：
   - 运行**【房间拓扑图元胞自动机（Graph-Based Cellular Automata）】**：全岛共约 $65$ 个房间节点，按海拔高度 $H_i$、门窗开度 $O_{ij}$ 与风向系数计算源质浓度扩散：
     $$C_i(t+1) = C_i(t) + \sum_{j \in \text{Neighbors}} k_{ij} \cdot O_{ij} \cdot \left( C_j(t) - C_i(t) + g_{\text{settle}} \cdot \text{sgn}(H_j - H_i) \right)$$
   - 驱动离场 NPC 在抽象房间节点图（Room Graph）上的日程转移与效用决策（无需在后台跑 A* 像素寻路，仅当玩家推门进入同一房间时才根据进度条插值生成 NPC 的精确站位）。
4. **昼夜结算时钟（Daily Ledger Tick，每日 $06:00 / 18:00$）**：结算主粮仓消耗、温室作物生长、源质侵蚀病理阶梯演进与“三槽位动态做局模板”匹配。

### 二、 32 位知情掩码、恶魔单实体锁与防群杀物理保护
1. **微秒级等效双层认知（`KnownByMask` & `ScholarMask`）**：
   - 全局注册的十六名学员占用 32 位掩码的低 16 位（`ScholarMask = 0x0000FFFF`），三名迷途客与杂役位于高 16 位。
   - 每条环境危险事实 `HazardFact` 维护一个 `KnownByMask`（记录谁知晓该危险）与 `AffectedMask`（当前房间或动作波及的人群）。
2. **恶魔单手压制与修罗线“调虎离山”的底层判定公式**：
   - 恶魔全局只有一个物理实体锁 `DemonEntityLock`（记录恶魔当前被钉在哪个房间执行强制保护，以及剩余锁定分钟数）。
   - 当某房间发生致命险情或有人试图锁门/开毒阀时，引擎在一微秒内计算：
     $$\text{IgnorantVictims} = (\text{Hazard.AffectedMask} \ \& \ \text{ScholarMask}) \ \& \ \sim\text{Hazard.KnownByMask}$$
   - 若 $\text{IgnorantVictims} \neq 0$（即波及范围内有至少一名注册学员处于“无知”状态）：
     - 若 `DemonEntityLock` 空闲，恶魔立即瞬移至该房间显形，执行**“一手压制施暴者、一手解除封锁”**，并将该险情写入全员 `KnownByMask`；
     - 若修罗线玩家此前已在 A 房间制造了持续性无知险情（如哄骗不知情者守在松动的蒸汽阀下），令 `DemonEntityLock` 被死死钉在 A 房间 $15$ 分钟，则玩家在 B 房间制造的瞬时致命陷阱将因恶魔分身乏术而成功得手！
3. **防顺手卡位/群杀的三重物理兜底**：
   - **内侧紧急脱扣杆（Panic Bar）**：1F 大食堂、2F 起居厅与大讲堂等多人聚集区，内侧均设有符合近代安全规范的机械脱扣横杆，无法从外侧单靠插闩锁死；
   - **恐慌碰撞穿透（Collision Ghosting）**：当房间处于高危报警状态时，NPC 的寻路自动开启碰撞体积穿透，彻底杜绝玩家用身体堵在门口卡死全员的恶性 Bug。
