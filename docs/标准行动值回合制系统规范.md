# 标准行动值回合制系统技术规范

## 1. 概述

标准行动值回合制系统（Conditional Turn-Based, CTB）是一种基于速度属性和离散时间累积的动态时序调度模型。
该系统不划分固定的大回合轮次，各战斗实体的行动频度直接取决于自身的速度属性与行动代价。

## 2. 核心数学模型

### 2.1 基础物理量定义

* **速度（Speed / SPD）**：实体的时间推进速率，为大于 0 的标量数值。
* **跑道距离（Base Distance / Gauge Threshold）**：实体完成一个标准行动周期所需跨越的基准数值，业界通用基准常数通常设为 $D = 10\,000$。
* **行动值（Action Value, AV）**：实体到达下一个行动点所需消耗的时间量度。数值越小，行动优先级越高。

### 2.2 基础行动值公式

实体的基础行动值（Base AV）由基准距离除以速度确定：

$$\text{BaseAV} = \frac{D}{\text{Speed}}$$

### 2.3 动作代价等级与后摇结算

不同类型的行动具有不同的动作代价乘数（Action Rank / Cost Multiplier $R$）。
实体执行动作后，其重入队列的新行动值增量为：

$$\Delta \text{AV} = \frac{D \times R}{\text{Speed}} = \text{BaseAV} \times R$$

标准普攻或常规技能通常取 $R = 1.0$。轻量技能或快速消耗品取 $R < 1.0$，重型技能或硬直动作取 $R > 1.0$。

### 2.4 行动提前与行动延后

* **行动提前（Action Advance / 拉条）**：按比例推进跑道距离，减少当前剩余行动值：

$$\text{AV}_{\text{new}} = \max\left(0,\, \text{AV}_{\text{current}} - \text{BaseAV} \times \text{Ratio}_{\text{advance}}\right)$$

* **行动延后（Action Delay / 推条）**：按比例增加当前行动值，延后其行动时机：

$$\text{AV}_{\text{new}} = \text{AV}_{\text{current}} + \text{BaseAV} \times \text{Ratio}_{\text{delay}}$$

### 2.5 进程中变速动态缩放

当实体在行动值消耗途中触发加速或减速效果时，已消耗的物理跑道距离保持不变，剩余的行动值根据速度比例进行动态线性缩放：

$$\text{AV}_{\text{new}} = \text{AV}_{\text{current}} \times \frac{\text{Speed}_{\text{old}}}{\text{Speed}_{\text{new}}}$$

## 3. 调度架构与执行状态机

### 3.1 核心数据结构

* **时间线优先队列（Priority Queue / Min-Heap）**：以实体的绝对行动时刻（Absolute Timestamp）或当前剩余行动值（Current AV）作为主排序键。
* **同分决胜键（Tie-Breaker）**：当多个实体行动值完全一致时，按入队顺序（Sequence ID）或既定优先级规则判定先后。

### 3.2 调度器执行循环

1. **寻峰（Peek）**：检查时间线队列顶部的实体，获取其剩余行动值 $t_{\text{min}}$。
2. **时间流逝（Tick / Advance）**：若 $t_{\text{min}} > 0$，全局行动时间推进 $t_{\text{min}}$。队列中所有其他实体的当前剩余行动值同步扣减 $t_{\text{min}}$。
3. **出队与激活（Dequeue & Turn Start）**：将归零的实体标记为活动状态（Active），触发其回合开始阶段（Turn Start）。
4. **决策与结算（Execution & Turn End）**：实体选定动作并结算效果，根据所选动作的代价等级计算新的行动值 $\Delta \text{AV}$。
5. **重入队（Re-queue）**：以当前时刻加上新行动值作为键，重新插入优先队列。

### 3.3 插入行动与中断机制

* 终结技（Burst / Ultimate）或即时反击属于瞬发中断行动。
* 触发中断时，系统暂停当前的正常时间推进流程，为中断者分配一个优先执行权（Immediate Turn）。
* 中断行动结算完毕后，系统恢复原有的主时间线流程，不消耗中断者原本排队的行动值。

## 4. 行动序列预测算法

预测队列（Turn Order Preview）用于向用户展示未来若干步的行动顺序。算法原理如下：

1. 建立当前优先队列的深拷贝或轻量模拟副本。
2. 循环提取当前队列首个行动者，将其加入预测列表。
3. 假设该实体使用标准代价（$R = 1.0$）生成下一次行动值并重新排入模拟副本。
4. 重复上述步骤直至预测列表达到指定深度（如未来 10 至 16 次行动）。
