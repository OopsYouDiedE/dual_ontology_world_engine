# 《异常感知学园：灰潮禁闭》内容层设计

## 1. 游戏起点

十六名学员保留姓名、职业、入学前经历、性格和身体习惯。他们失去了在校经历、师生关系、学员旧关系、泄露事故与临终契约经过。

恶魔以校内代管者身份宣布禁闭游戏。学员需要恢复真实但主观的记忆，修复四院防卫，取得四件封印部件，在核心隔离舱重新执行真名封印。

## 2. 人物羁绊与过去

### 2.1 被撤回的第二名录

言灵导师发现第二名录会暴露恶魔的语义地址，命神偷取走拓片。侦探追查盗窃。律师依保密誓约撤回能洗清嫌疑的证词。考古学家把原文拆成四段保存。

- 侦探不信任神偷的解释，神偷故意留下可供追查的银币保护侦探的调查路径。
- 律师替考古学家保守秘密，考古学家把真名结构托付给律师的契约判断。
- 对应材料是指纹卡、旧银币、撤证书和铭文拓片。
- 事件发生在文献工房，指向名录库中的真名部件。

### 2.2 无声首演事故

诗人、音乐家、舞蹈艺术家和画家排练稳定主阵的仪式乐章。诗人为保护音乐家的听觉改掉禁句，舞者补走缺拍，画家看见不存在的第五位指挥。

- 诗人曾保护音乐家。音乐家因阵法失拍而怨恨诗人。
- 舞者相信画家的灵视。画家敬佩舞者独自承受阵线回冲。
- 对应材料是咏唱稿、蜡筒、舞靴和速写。
- 事件发生在共鸣厅，揭示恶魔曾提前干预事故节拍。

### 2.3 温室灰疫封锁

源质孢子混入温室灌溉。化学家承认试剂泄漏，博物学家发现真正源头是旧阵土，主厨销毁整季配给，医生隐瞒四人的暴露记录。

- 博物学家欠化学家一次公开真相。化学家用虚假自认保护博物学家的样本。
- 主厨依赖医生的污染判断。医生负责维持四人的生命并阻止学园长实施解剖。
- 对应材料是压叶标本、配给账、事故报告和未登记病历。
- 事件发生在种植梯田与温室，连接食物、水务和白塔污染线。

### 2.4 西侧断电救援

西侧断电困住学员。建筑师拆开承重墙，工程师过载水轮机，神射手压制失控役魔，职业棋手切断名录库供电，把最后电力送往诊疗所。

- 工程师信任建筑师的结构判断，两人共同承担机械联锁烧毁的责任。
- 棋手以名录库为弃子救下诊疗所。神射手负责守住救援通道。
- 对应材料是继电器、供电图、空弹壳和拆改蓝图。
- 事件终点在机械联锁室，解释该锚点为何失效。

### 2.5 源质反应炉泄露

苏醒周期的校准误差使言灵定义漏过一个时空节点。反应炉破裂。学园长留在核心隔离舱拖延恶魔，其余三导师以存在为质押建立禁闭游戏契约。

十六人分别通过停摆课表、星盘合影、联锁手记和解剖日志恢复事故片段。任何一份材料都只形成当事人的主观 Claim。四份材料合并后才能形成完整事故解释。

## 3. 运行时表达

人物使用 `Character`，认知主体使用 `Soul`。人物与 Soul 双向绑定。

羁绊使用人物上的定向 `Facet`，目标直接保存另一人物的对象引用。羁绊来源指向实际历史事件。事件需要独立保存、被见证和被材料指向，因此使用普通 `Entity`。

记忆使用 `Knowledge Entity`。记忆的 `subject` 指向历史事件，`Claim` 保存当事人的主观描述。日记、照片、拓片、蜡筒和遗物使用 `InformationCarrier`，通过 `Carries` 指向记忆。阅读只改变 Soul 的知识，不改变客观历史。

场景使用带 `Scene` Tag 的 `Entity`。场景间连接使用 `Passage`。门锁和封印入口由 Passage 条件读取实际场景与规则环境。房间内不计算距离。

职业能力使用完整 `Intent`。行动发生后建立 `Event`，并由同场景见证者观察。职业能力产生的样本、记录、进度、安全路线和修复状态仍是 Entity、Tag、Facet 或事实表达式。

恶魔的既存限制使用活动 `Covenant Entity` 与 `HardConstraint`。临时制定的客观规则使用 `RulePublication` 和 `RulePatch`。规则发布物可以被理解、接受或拒绝；活动 RulePatch 直接参与行动前复核。

言灵与最终封印使用 `Recipe`。简单言灵立即建立并完成 Rite。最终封印包含四个步骤，持续 Rite 会记录投入、已完成步骤和真实稳定代价。完成后产生新的 Covenant 并移除恶魔实体。

## 4. 地图与资源

地图包含四十八个场景和七十一条 Passage。公共层、四院外环、生活小环、岛屿生存环、地下勤务环与四锚封印廊均提供替代路线。

六处场景开局受限：名录库、阵法基座室、机械联锁室、学园长隔离室、源质反应炉和核心隔离舱。门锁不会通过提高移动代价模拟。解锁需要实际言灵、职业行动或规则事实。

四件最终部件分别是逆写第七码真名结构、四院闭合封印阵图、导师指纹机械联锁和铅玻璃源质安全载体。它们保持独立身份，不合并成抽象进度值。

## 5. 人物决策树

所有学员使用同一组基础分支，并由实际目标对象和职业内容产生差异：

1. 角色只前往由共同作战板分配的搜索地点。隐藏载体必须先执行勘查，之后才能按载体恢复记忆。
2. 恢复个人记忆后，旧羁绊才进入效用计算，并产生分享、质询或保护 Intent。
3. 四院负责人以 HelpRequest 发出远程请求。匹配的协作者先承诺赴援，再逐 Passage 抵达并协助。
4. 职业行动仅由尚未完成的四院验证需求生成。需求完成后不再产生同一候选。
5. Objective、HelpRequest、记忆载体或 Rite 贡献目标在其他场景时，生成沿最短可用 Passage 的单段移动 Intent。
6. 没有未完成承诺且恐慌可下降时才生成休整 Intent；否则行动槽保持安静。

Soul 使用已接受规则评价全部候选，并根据近期真实 Event 对相同动作、行动者和目标施加重复衰减。恢复后的 PastBond、职业匹配和请求期限改变效用。Covenant 与 RulePatch 在候选筛选、行动提交和实际结算前执行客观复核。

恶魔拥有自己的 Soul 和 Timeline 行动槽。它会轮换执行灰潮渗流、广播疑念和伪造规则释义；三种行动都会改变现实压力或人物状态。临终 Covenant 仍会拒绝恶魔直接破坏锚点的高收益候选。灰潮压力达到临界值，或四名学员失去行动能力时，游戏立即失败。

## 6. 言灵与规则设立

“镇心三拍”需要黄铜共鸣音叉、足够的心识与缘系，只能作用于同场景且具有实际恐慌的目标。

“门槛正名”需要誓约庭重型钥匙、名契、律令和门隙，只能作用于相邻的受限场景。成功后同时改变场景锁定状态并写入解锁事实。

规则设立必须在契约审议室完成。发起者、见证者、受约束主体、精确行动、目标场景和作用域都保存对象引用。红墨水是有限资源。成功后同时形成规则发布物、见证关系和局部客观 RulePatch。

## 7. 胜利流程

四院目标均要求至少三份独立主观证词、一次远程求助闭环、对应负责人的职业验证，以及实际部件交付。玩家需要在契约审议室设立带见证的协同行动令。四院完成后，四名不同负责人进入核心隔离舱，分别以本院 Objective 的验证结果承担 Rite 步骤。

最终封印检查四院验证、至少十五个已恢复载体、四件独立部件、协同行动令和四名不同贡献者。单人无法重复推进，也不能以全局箱中的部件伪造胜利。

每一步消耗实际 Soul 稳定。最终 Covenant 成立后，恶魔从当前世界树移除，回归操作受到硬约束，游戏进入封印结局。
