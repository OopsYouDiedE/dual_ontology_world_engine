# 独创主客观二元拓扑隔离规范

## 商业领域现有技术局限

商业游戏中的感知与信息掩蔽方案（如策略游戏战争迷雾、潜行游戏视野锥体与听觉广播）始终建立在 单一客观物理世界的前提下。NPC 寻路、行为决策均在客观全知网格或共享导航多边形（NavMesh）上运行，通过几何射线检测（Raycast）过滤不可见实体。这种方案无法模拟角色由于信息闭塞而坚信某条已被封死的密道依然畅通，并在错误的信念图上进行合乎逻辑的多步长远规划。

---

## 本系统独创设计

本系统在底层数据模型上实现客观物理世界树与主观心智认识图的二元分裂与拓扑级隔离。

### 客观与主观的结构分裂

系统在架构中确立两套互不干涉的拓扑结构：
- 客观世界拓扑（Ontological Reality）：
  由世界树（TreeMember）层级包含与通路图（Passage）共同构成。门禁闭锁、容器封存、通道断裂等状态由客观物理实体真实持有，作为物理世界的唯一真理。
- 主观认识拓扑（Epistemic Graph）：
  每个智能体私有持有的认识图谱。图中的节点、连通边、门禁状态与空间内容由智能体在四阶段信念内化流水线（Received $\to$ Understood $\to$ Accepted）中被采纳的命题构成。

### 隔离推演与认知闭环

智能体在执行多步行动推理与路径搜索时，查询上下文严格封闭在其私有的主观认识图中：
1. 智能体不知道客观世界的真实阻断，只能依据自身信念图规划最优路线。
2. 当智能体到达现场并目睹密道被封死时，客观物理事件引发新的感知数据（Received）。
3. 智能体对新数据进行理解与置信度评估，将通道畅通信念转移为 Rejected，采纳通道封死信念，随后触发局部重规划。
4. 这种机制允许智能体在虚假信息误导、欺骗、信息过时等复杂情境下展现出完全自洽的心智演化。
