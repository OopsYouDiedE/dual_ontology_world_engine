# 侦探技能界面：脑内重演

状态：当前落地入口见 [家具喝茶谜原型说明](../godot_csharp/scenes/Reasoning/README.md)，运行场景为 `Reasoning.tscn` / `TeaReasoningScene`。本文仍是界面设计与交互边界参考，全部能力尚未接入或经过完整实机验收。遵循[设计与验收规范](design-standard.md)。

## 进入脑内世界

侦探在调查中调用自己的技能，现实暂停，当前现场的轮廓留在画面中；打开的是该段历史的重建，而非对现实人物下令。返回现实时恢复调用前的位置和交互，保留草稿、候选解释与回看位置。首次进入只有已调查材料和可编辑的未知项，没有作者的参考规则。

顶栏明确写“脑内重演”，并显示当前解释名称、草稿/已运行版本及“返回现场”。没有言灵实验页签；言灵属于另一项操作。未取得足够材料时依然允许进入、写假设和局部推演，但明确哪些材料缺失，不伪造完整初态。

主屏以房间为中心，右侧展开选中人物的思路札记，底部为连续重演的回看轴。证据默认收在左缘“调查材料”入口，点开才占用左侧；避免三份长文本同时争夺画面。初次进入不自动打开代码编辑器，先让玩家看见自己正在重建的现场。

## 画面与布局

以1280×800为游戏布局基准：顶栏56px，底部回看与简报144px，中间600px；右札记宽416px，余下宽度用于场景及边距。展开证据时覆盖场景左侧280px，不挤窄编辑器。证据可钉住一条摘录，与札记同屏对照。文字放大后允许切换场景/札记焦点；不把整个界面缩小。设计示意在窄屏改为上下排列，不代表游戏须支持手机。

场景延续墨绿暗室、骨白房间轮廓、琥珀假设的方向。文字书写面使用无纹理浅纸色。已知调查材料使用实线与“记录”字样；可改初态使用虚线与“假设”；回放对象附“模拟”标识。冲突用断开标记、红色及文字共同表达，不用全屏报错或频闪。场景内不常驻网格、路线和全部标签；选中对象才出现名字、位置关系和可检查的变化。

正式场景仍用32px地图格与整数倍像素显示，角色按现有32×48设计范围及运行时承载格规范处理；字体独立于地图缩放。此界面的示意房间不是美术资产或可走动地图验收图。

点击人物打开该人物札记；点击器物查看其模拟状态、被谁观察过及证据关联。点击空地不发出移动指令。对象可以插入语句的对象槽，但插入不授予人物认知。人物不知道其身份时，提示绑定“当时看到的杯子”或保留未绑定称谓；不自动绑定侦探已辨认出的真实物件。

## 札记：写得像句子，编辑的是结构

札记分“行为规则”“当时所知”两页。前者是整段历史通用的规则草稿，后者是当前回看时刻的只读认知。初始误认集中在独立“初态与假设”抽屉；不能在认知页直接改值。

默认使用可键入的受限中文，保留换行、撤销、复制粘贴和批注。句法词轻着色；对象与条件短语可点选改写；缩进表达条件范围。不要要求拖积木才能输入，也不展示JSON。光标处补全当前槽位可以使用的表达；只帮助表达玩家已有想法，不提示能通过证据的答案。

示意句法（待实现，不能粘贴进旧 RuleLanguage 执行）：

> 收到“收拾”通知后：
>   对我认为已经用完的杯子，优先尝试拿起它。
>   若我认为它仍有人使用，则不拿起它。

“收到通知”“认为已经用完”“它”都必须有确定语义；一个代词对应哪个对象、否定包含哪一段、条件管辖哪些动作，在选中语句时显示。存在多个可能绑定时要求玩家选择，不悄悄猜测。未绑定、不能解析和能力未实现分开提示，未知词不一律冒充剧情未解锁词。

选中一句才展开“对象 / 判断 / 行动 / 偏好”的结构摘要。结构编辑和文字编辑保存同一棵树；无歧义改写不改变含义。输入不完整时保留文本草稿，不执行半棵树。高级结构视图用于检查作用域，不额外维护一套程序。

规则不是播放清单。上下排版用于阅读，不能暗中表示“第一行做完再做第二行”。“优先”“避免”“禁止”明确影响决策；优先力度由可展开控件表达，须展示同次决策中实际如何合并。多个候选并列时显示既定并列处理方式，不靠隐藏的行号决定历史。需要过程性的任务时可写显式子过程及完成条件；没有人为限制行数，也不禁止合法的一次性行动、故意倾倒或连续操作。

玩家可以规定关注、判断、行动选择、偏好及可追溯的记忆变化。具体动作目录依靠游戏层已实现能力提供。世界状态写入、任意认知写入及模拟器元信息不出现在输入词库；不暴露“设置湿润”“证据已经通过”“这是第二次重演”。也不能把这些藏进条件或子过程中。动作的世界效果由能力定义与运行时结算；限制施加在完整的可提交结构上，而不是屏蔽几个词。

当人物的知识不足时，条件值显示“未知”，而非“否”。例如“没有看到有人用杯子”不等于“认为杯子无人使用”。人物可因旧记忆而失败：编辑器只说明句子能否成立，不提前从客观真相替他纠错。

## 当时所知：解释决定的来源

回看任一决策时刻，札记显示人物的判断、信息来源与取得时刻，例如“认为杯子已用完 ← 先前听到甲说‘我不用了’”。可展开完整观察/转述/记忆链；模拟内产生的来源也标“模拟”，不得混进现实调查材料。

“仅看他所知”开关以该人物的认知替换场景信息层。未看到的区域降暗，旧记忆使用轮廓及“上次所见”标记；这不是实时透视图，也不直接揭示认知背后的隐藏真实身份。切回“重建全景”只展示候选解释内的状态，不展示案件作者隐藏的答案。

默认只展开当前选择及主要依据；“为何没选另一项”展开同次候选、未知条件、偏好和禁止依据。“为何没有行动”同样可检查：无候选、等待中、条件未知、前一动作尚未结束需分别显示。这些是本次模拟的决策说明，不是作者判卷。

## 初态与假设

抽屉按“调查已确认 / 尚未知 / 本解释假设”展示位置、物件关系、人物起始认知等。已确认项可回到来源核对，不可随意改写。可设假设只限重建允许的未知项，不随意创造隐藏物品或新世界法则；边界来自材料和已知机制。

误认应显示“谁相信什么 / 假设起于重演开始前 / 来源尚未证实”。初态假设在整份候选解释中固定；运行后要改，产生新版本并从头重演。不允许回放到中途把杯子挪开或给人物补一段方便的记忆。尚未知项如果会影响结果，运行报告必须列出本次采用的假设；不静默填作者默认值。

## 连续重演与回看

主按钮“从头重演”统一提交全部人物规则与初态，生成不可变的运行版本。运行期间编辑的是下一版草稿；标题同时标示“正在回看解释一·第2版 / 草稿有修改”。再次运行从同一历史起点开始；旧证据状态不能继承。撤销、返回现场和重演都不删除调查材料。

底栏提供播放/暂停、下一决策、回看轴与速度。速度只影响展示，行动值来自嵌套调度。“下一决策”推进到下一个可解释的决策边界；同一行动值内的不同阶段保留先后，展开才显示原始调度细节。回拖读取记录，不逆向改写运行时状态。暂停、卡在动作前、到达记录片段、完整结束均有不同状态。

时间轴分两条：上为调查记录支持的时段/事件，下为模拟过程。证据只给相对顺序或时间范围时，用范围带或事件锚点，不擅自变成精确时刻；不用两个等宽点暗示相等时间间隔。阴性证据以有依据的观察区间显示。选择区间应可追查整段内发生过什么，不能仅检查区间终点。

发生冲突时默认暂停一次并展开差异，允许继续看到其余后果。当前标签使用“尚未检查 / 在已检查范围内相容 / 存在冲突 / 资料不足”。完整运行且全部有依据约束检查完毕，才显示“与当前证据相容”，并保留假设清单。暂停时绝不提前判整体通过。没有相容百分比、规则正确率、作者性格匹配度或金色标准答案。

## 证据差异与重新理解

差异抽屉并列呈现“调查记录说什么 / 本次重演出现什么”，注明对象、时段、观察来源。若材料是证人的原话，保留原话及其可核验范围；有关物件身份、代词或时刻的解释单独呈现，不能把玩家暂定理解硬化成事实。

典型反馈：“第二次目击时，记录中的缺口杯在椅旁；本次重演中，它已在清洗台。”按钮为“回看此前变化”和“查看当时所知”。前者回到最近相关行动，后者展示行动者认知。不能出现“第三条规则错误”“请改成不收杯子”。玩家由事实差异决定怎样修订。

一次完整操作：选择记录中的冲突 → 回看搬杯动作 → 发现人物根据旧消息认为无人再用 → 查看其后是否真的收到新消息 → 修改规则或有依据的初态假设 → 全部人物从头重演 → 重新核对前中后所有记录。语法错误就地修复；行动被现实条件阻止则保留真实失败及其认知后果，不能当成语法错误消去。

保存多份候选解释，各自保留规则、初态、完整结果与未解决差异。复制解释后修改独立运行；比较页对照证据与假设，不拼接两份解释中恰好通过的片段。可保留荒谬但相容的解释。额外改变历史条件的预测若后续提供，应单独标为“条件推演”，不计入案件事实或历史重建验收。

## 与现有实现的关系

已核对 C#：Core 的 Ast.cs 提供类型化 Noun、Condition、Effect、Rule，条件具有 True/False/Unknown；DecisionSystem 从 ProjectionWorld 评估候选、偏好与禁止；人物认知通过 Observation.Observe 更新。界面可以围绕这些真实能力设计，不恢复旧 Entity/Belief 系统。

当前 Core 同时包含 Set、Think 等更底层能力，不能因它们存在就全部暴露给玩家。游戏层负责受限中文解析、可提交能力边界、房间内行动、调查资料、版本和差异比较。Core 保持独立。关注策略、具体搬放/倾倒能力、观察溯源展示、优先力度和并列选择语义均需按真实接入结果补足，不能把本稿例句当现成 API。

旧 RuleLanguage.cs 仅支持前往、校时、监听等顺序指令以及“如果已校时”条件；旧 ReasoningScene.cs 允许执行单个人方案；BreakfastCase 是主动调查实验。新设计不能只换按钮文案和配色就宣布完成。旧[视觉草案](reasoning-art-direction.md)保留为前期参考，本稿描述本次提案，不更改现有游戏入口。

## 下一步可玩验收

先接一个最小因果场景，验证自然语言与结构往返、Unknown与False、人物认知隔离、真实行动失败、无行动原因、全程证据比较和修改后全量重演。输入合法动作但重演冲突时，必须能仅靠差异与认知链定位问题；两份不同规则若均满足约束，应同样相容。

同时检查点击对象不泄露身份、时间区间不被压成时刻、回看不改状态、旧结果不冒充新草稿、空白/非法规则不部分执行、返回现场不丢稿。1280×800及放大文字时核对可读性、键盘操作和地图整数倍率。完成这些后才能称可玩原型，再进入正式像素资产与试玩验收。
