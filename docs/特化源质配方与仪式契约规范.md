# 特化源质配方与仪式契约规范

## 商业游戏合成与制造系统体系

制造与合成系统是现代商业游戏（如《Minecraft》、《星露谷物语》、《炼金工房系列》、《密教模拟器》(Cultist Simulator)）与制造仿真的核心支柱机制。该机制经历长期商业实践，沉淀出工业级标准管线。

### 工业化架构标准

现代商业游戏中的主流制造架构主要包括两种成熟形态：
- 基于插槽矩阵与物品模板的网格合成（Grid Crafting）：依赖固定 UI 布局与精确物品静态 ID 匹配（如工作台网格）。
- 基于标签/属性集合的无序配方匹配（Tag/Element-based Synthesis）：物品携带若干元素标签及数值（如 木材 x1、热量 x2），合成器遍历候选原料计算累加总和，当总和满足目标静态配方阈值时立即实例化新物品并扣减原料。

在传统商业游戏中，合成通常是瞬时无状态、纯物品层面的替换过程，缺乏多实体协作约束与跨周期因果责任追踪。

---

## 本系统特化设计

本系统的特化设计在于将标签合成演化为多维正交源质（Aspect）空间投影，并将无状态合成升格为具备跨生命周期追踪能力的仪式因果契约（Causal Covenant）。

### 源质维度动态投影

配方摆脱对单一物品类型或静态清单的硬编码依赖，转向多维空间投影：
- 所有可参与交互的实体均投影为多维正交源质向量 $\vec{A} = (a_1, a_2, \dots, a_{12})$。
- 仪式或合成环境通过聚合场计算各参与物体的源质总和 $\vec{S} = \sum \vec{A}_i$。
- 配方校验转变为向量空间中的门槛判定：$\forall k \in [1, 12], S_k \ge T_k$。

### 仪式因果契约与违约惩戒

合成过程不直接执行简单的原子扣除与瞬时替换，而是建立多实体参与的仪式契约：
- 契约生命周期：绑定参与主体、见证实体、生效条件与时效窗口。
- 责任义务网络：参与实体被赋予因果履约承诺。若在仪式时效窗口内未能维持特定环境约束（如持续能量供给、专注施法或特定拓扑闭合），契约触发失衡破坏状态。
- 违约惩戒反冲：仪式失败不简单回滚物品，而是向参与者的认知切面与生理切面写入永久因果创伤或反冲状态效果。
