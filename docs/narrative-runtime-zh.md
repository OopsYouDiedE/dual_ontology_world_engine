# 文学运行机制：当前实现

本轮用低成本模型 gpt-5.6-luna 提出文学案例并实现初稿，由主代理审查因果关系、修改 Core，再运行反事实。完整提案包含《灰烬档案》《最后一席渡船》《无声第三证词》；目前渡船案例已落为可执行检查，另外两篇仍是压力场景提案。

## 从案例发现的问题

初稿中，药师可以不消耗药、不占用渡船就救人。这让“最后一席”的道德冲突失效。修正为先支付药物、装船，再由船夫选择渡运后，旧机制又无法自主启动合作：药师看不到自己的准备可以让另一个人推进共同目标。

现在公开的行动提议可以参与跨角色一步推演。角色仍按自己的关切计算收益，不读取对方私有动机，也不替对方执行提议。因此合作有预期，也有被背弃的可能。候选推演使用当前观察者的 StateView；条款后果预测也使用该观察者的知识。

这不是无限深度规划。隐藏提议、较长合作链和行动先后仍会影响结果；当前规划最多检查前 64 个自身候选和同场公开提议。提议是在作品装配时明确公开的能力说明，尚无自由语言谈判或动态承诺可信度模型。

## 使用接口

`LiterarySimulation.Narrative` 自动随模拟创建和释放，提供三项内容装配接口：

- `Care(actor, name, target, field, desired, importance, when)`：角色持续在意的状态。可选 when 按行动前的主观知识激活关切，使已知背弃影响后续援助选择；未知条件不会读取世界真相。得到与失去同样进入估值，同次行动先改后还原没有净收益。原来的 Person 单目标仍保留，Care 的重要性与它相加。角色亲自造成的第一次达成会记录对应事件，不因普通等待重复领奖。
- `Opportunity(actor, name, target, changes, requirements, cost, operation, announced)`：可信作者定义的行动机会。前置条件决定何时可用，成功结算才消费一次性标记；预测与失败不消耗。把前一机会的结果作为后一机会条件，就能组成有后果的事件链。默认不公开；`announced:true` 让同场角色知道该行动提议，具体世界事实仍须可知。
- `SharedOffers(observer)`：返回可用于合作推演的同场公开提议，不授予调用方执行权。执行仍由提议者自己的行动槽和 Runtime 决定。

这些入口接收可信 C# 内容，不是开放 AI 的任意 AST 授权接口。模型的文学构想须转为明确的状态、权限、代价和失败条件；不能把模型生成的“救人”效果直接当作平衡证明。

## 成长的执行闭环

成功的 `inspect` 必须真正向行动者心智写入新的 `evidence`，且内容与证物实际字段一致。同一心智对同一证物只能得到一次复核额度。听说、虚假观察、重复调查和 Prepare 不发经验；事件保存 LearningSource 引用。

`reflect` 是普通声明式行动，消耗 20 AV 和一个复核额度，两次复核至少间隔 200 AV。能力增量为 `2 × (1 - investigation / 100)`，因此收益递减。能力通过机会的 Requirements 解锁更精确的查证行动，不自动叠加伤害、收入等其他奖励。

当前只有调查这一条成长轴。它不是完整人格演化，也没有自动生成无限新证物。100,000 AV 检查使用 500 份明确供给的独立证据，验证支付、间隔和收敛，不把测试案卷数量当作剧情丰富度。

## 张力与结算

冲突来自同一有限资源无法满足全部关切，以及合作提议与实际选择可能不一致。有限机会、软禁令、期限和持续维护共用原来的 Runtime 和 AV 时间线；违约后果保留因果事件，不新增随机灾难驱动器。

渡船案例还验证了第二轮选择：守诺之后，药师会把余药留给船夫的女儿；遭背弃后，相同援助机会被条件关切压低。先违约、后补足履约不会清除违约记录，因此资源充足也不能自动恢复关系。这一反应来自明确的作者性格设定，并非通用的自主人格生成。

只有下一步可得收益的增量进入准备行动估值，避免无关动作借用某个未改变的高收益未来。无值得执行的行动时，文学模拟保留空闲检查槽，等待真实世界过程改变条件，不持续制造 wait 事件。时间仍然前进，后续期限仍能触发；这不意味着所有历史与知识存储已经有界。

疲劳的直接写入与声明式写入统一在 0..6 内，拒绝 NaN/Infinity；准备值与提交值一致。PatternBook 对后果先做无副作用准备，再按真实变化计算费用，支付与后果原子结算。数值赋值不再按一个操作收费，支付也不重复计入后果价格。

## 验证与边界

`tests/narrative_cases` 检查自主文学分叉、证据成长、条件解锁、重复兑换和长程收敛，并导出可阅读的实际轨迹。`tests/consequence_budget_checks` 检查实际后果价格与预测一致、预算不足和一次性截止。既有文学检查、架构检查与长期经济检查继续运行。

结果文件：[渡船轨迹](narrative-case-results.md)、[长期经济与开放构造风险](ai-construction-balance-results.md)。

现有证据足以证明这些因果机制可运行，不能证明长篇文学质量已经达标。自由对话的持久信用、复杂目标修订、多人长期记忆压缩，以及开放 AI 创建言灵和硬规则的权限层仍未完成。底层工厂可生成无成本效果、PatternBook 可安装作者硬规则的两项风险继续由严格测试报告，不宣称已经关闭。
