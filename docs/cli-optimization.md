# CLI、观察者投影与会话统计

本轮实现以 `artifacts/cli-ai-demo` 的既有记录为问题依据。实现涵盖投影、感知边界、CLI 布局、回放、统计、规划工作明细和封存来源。源码变更不等于已经取得运行效果；实际运行记录另存任务目录，不把旧会话数据当作本轮结果。

## 统一三个现实小时口径

设实际会话现实时间为 W 小时，正式推进为 G 游戏小时，正式提交的决策数为 N，所选决策接口实际累计耗时为 C 小时。

| 显示项 | 公式 | 接口字段 |
| --- | --- | --- |
| 推进速度 | G / W，游戏小时/现实小时 | `game_hours_per_real_hour` |
| 正式决策频率 | N / W，次/现实小时 | `decisions_per_real_hour` |
| 接口耗时率 | C / W，消耗小时/现实小时 | `interface_hours_per_real_hour` |

累计现实时间与累计游戏推进量紧随指标显示，少于一小时也按实际覆盖计算。这是本次采样区间的平均率，不预测后续整局速度。W 为零或原记录缺失时显示缺失；实际推进为零而 W 大于零时，推进速度可以为零。

引擎接口计入正式计算及实际发生的预备分支计算；两者在拆解中分列。人工和 LLM 接口计入可选择请求已交付到正式接受之间的实际区间，取消及关闭保留各自结果。外部适配器可报告 request、response、reading、confirmation 等真实阶段；未报告的阶段不推测。NPC 的引擎工作单独按 engine 来源记录，不能计入外部控制者的选择次数。接口耗时与后台计算可能重叠，不把这些数直接相加为串行现实时间。

自主观察台分行显示会话累计数量、每现实小时速率，以及用户要求的每游戏小时引擎选择数、真实选策计算秒数和现实经过秒数。每游戏小时数值按本次累计正式推进折算，零推进或计量不完整时保持缺失；选策只计实际 dvs_choose/规划墙钟并扣性能流编码写入及外部回调，不把接口总耗时当作思考。人工/LLM 普通主观界面不展开其他角色计数或全局新增计时；完整口径见 engine-performance.md。详细报告保留判断瓶颈所需的实际 engine、speculation、projection、startup、persistence 类别，含子项与排他耗时分别命名。对象维度明确区分触发主体、检阅人物和投影范围，分位数标明近似上界。

## 请求范围决定投影工作

人物目录只返回中立身份目录，不生成所有人物地图。正常 CLI 生成当前检阅人的主观视图；只有显式请求客观地图时才生成物理世界投影。同一状态版本下客观地图共享，人物高亮仅为显示覆盖。

DV 侧复用物件、位置链、容器索引以及完整声明值对应的站点和移动边目录。房间、区域和名称采用叶项缓存，单个字段以实际对象与字段为依赖。状态版本改变时，只有相关本人 mind、行动、绑定和控制输入改变才重新构造主体地图与即时候选；当前时间和状态每次覆盖，缓存评分保留真实取得时刻。宿主只保存不可变结果，不维护第二个世界、不授予事实。完整依赖之外的事件和时间变化不能擅自跳过。

## 减少没有必要的规划

生产默认 `selective-task-v1`，可显式 `--planning precise` 使用原完整搜索。先评估当前合法任务；在根层遇到已准入、非移动／答题／等待、净分为正且有实际信息、核验或成就价值的任务便提前选择，未命中时继续原有层内和后继求解。报告记录实际跳过候选、部分层、已进入层与完整层，部分层不声称已经比较所有候选。缺少当前任务才寻找本人采用预测支持的后继。成功移动后的路径后缀在下次决策时重核，末端任务失效便重新规划。无支持任务时进入 `approximate-yield` 等待，本人输入、实际收闻、接触、声明和真实时间边界变化再唤醒，不为凑进度反复走动或制造空事件。

该策略会改变选策顺序，报告明确为近似；原行动资格、费用、观察、重演和正式判答继续精确执行。统计区分真正预测与 memo 复用、新展开与路线续行，不能把减少的搜索量写成完整搜索的等价证明。

运行时缓存、可变父链与原始记录器归属于独立会话。冻结图到宿主只读图按身份复用，交互帧回写引用原不可变节点；记录更新只在确实需要独立可变子树时复制。精确数值使用相等的整数和同分母捷径。DAG 归档采用私有缓冲、单次 payload 编码与复用哈希，全部节点、来源、顺序、精确数和封存边界仍保留。

支持父证据按完整当前 cell 与对应实际证据列表复用，辅助索引增量追加，完整原始支持事件继续保留。侵蚀等级、阶段、失能和记忆周期没有变化时返回原主体；领域列表替换读取不可变前态，避免为更新一个主体而解冻其余主体。

历史规划索引增量消费正式事件。当前即时估值、同认知版本的历史根分、当时的最终选择路径分分别保留事件编号、游戏时刻和认知版本。`immediate_breakdown` 只解释当前即时估值；缺少根分或路径分的组成时不拿即时分项充当其拆解。

## 物件、称谓和通道

正常同室感知只读取内容明确声明的中性可见字段，当前为 name 与 location。它使用正式 perception/observation 链和原有心智更新；投影本身不改知识。直接同房的床、书架、石板或铜口因此可以与当前可用行动保持一致，口袋和柜内物件、痕迹意义、题解及他人姓名仍按原有观察或听闻取得。

所有权、携带和容纳分别呈现。人物先于物体，携带物挂在实际携带者下面，容器内物件依本视图已知的关系归组。地图只呈现物理身份，不把事件或谜题状态伪装成物品。

通道将已知连接、真实通过历史和当前门状态分开。有通过记录但没有当前状态记录时，显示“曾通过 · 现况未知”，不能把过去成功通过当成永久开门。称谓读取检阅者已知姓名，未知学员使用稳定匿名编号，未辨明的铜口发言显示“铜口里的声音”；客观视图使用中立名称。编号只用于界面区分人物，不是故事姓名。候选标签中的实名通过行动者本人的字段读取，不由候选目录提前公开。成功移动的结果可显示已抵达的房间，原有移动正文不重复追加。

## CLI 与回放

顶部显示会话状态和三个统计指标，最新正文全宽优先，候选和空间列表随后显示。行动默认五条独立分页，`actions next/prev/all/compact` 在原区域切换，地图后不再复制整份行动列表。人工与 LLM 默认隐藏 AI 分数。普通 AI 界面默认仅显示选中项已经记录的短分；`zoom in` 展开已有评分细节，显式 `--scores` 或 `scores on` 才请求额外即时估值及其拆解，缺失评分保持未记录。

当前区域与当前房间优先，其他主观房间默认摘要；宽屏中的空间列表与辅助记录可以并排，最新正文仍优先占据完整行宽。记录带真实时刻、主观说话人和来源条目标识，续页保留所属条目。页脚持续提供必要命令。SVG 继续使用合并文本段和格宽约束，中文破折号按双格处理。

一次重绘只布局一次，文本、SVG 与页数来自同一画布。共同费用仅在每个候选都有相同明确费用时显示为“各项”；其他情况费用跟随本项。采样时长显示小数秒，便于阅读短于三秒的窗口。JPG 栅格转换按 SVG 的文本目标宽度处理连续字串，实际字形按字体 cmap 选择后备字体，保留原始 ✕、✓ 等证据符号，不替换为近似字符。图片标注为正式回放的 SVG 栅格导出。候选不提前泄露检视结果。放大镜比对必须已检视穿着的风衣、已知口袋内放大镜，且在活动厅实际观察石板；正文比较圆框与短柄轮廓，不虚构柄上的刻纹。

回放明确区分选择时的候选与结果时的地图，保留 selection/result 的时间和状态版本。同一事件内的正文保持原行序，事件组可以倒序排列；地图结束后的记录续页使用完整宽度。最终 checkpoint 保存当前关闭边界真正取得的 closing_preview 和状态版本，标明本次记录停止并显示已有在途记录，不沿用旧聚焦高亮或旧认知地图。旧记录没有该预览时明确地图缺失。未记录某个检阅人的视图时保持缺失，不以客观世界回填。回放只消费已有记录，不运行新的决策。

## 完整记录与关闭边界

原始统计在运行中流式写入 `.dvlog.partial`；内存尾部只服务近期查询，生命周期汇总不因淘汰丢失。正式关闭后封存主流。中途导出另一个前缀只导出其声明范围的快照，并标出遗漏量，不误封正在运行的主流。

规划拆解记录真实候选检查、资格求值、预测、节点展开、前沿峰值、预算、深度和停止原因。命中缓存时本次工作量为零，重用的历史工作量单独保存，不重复累加。插桩不扩大预算、不改行动顺序或费用。

轨迹顶层带 `provenance`、`cut`、`lifecycle`、`pending_actions` 和 `performance`；存档带 `archive_provenance`、`archive_cut`。来源明确宿主、执行器、是否 Godot、程序集 MVID、控制方式和调用者提供的版本。formal-model 不声明 Godot 现场执行。

轨迹记录实际停止点，存档保持最后可恢复的提交点。两个截止点分别写游戏时刻、事件和状态版本，以及已选择、已排程、已完成、待执行、已进入存档和未进入存档的选择数量。等待回执或尚未到期不等于失败，关闭不会为它们伪造 Complete。

同一帧先完成所需投影，再取得一次统计快照，顶层和 preview 共用该计时截止点。初始化和关闭归档各自独立计时，不能混进正常游玩的现实分母。

## 本轮执行限制

遵从用户要求，整批修改完成之前不测试；不运行静态校验脚本、源代码修改验证、语法探针或差异检查。运行测试只使用引擎自主 AI 的正式动作链，每轮从进程启动到退出的硬时限为 45 秒，不扩展为人工、LLM 或 Godot 现场。全部源码、剧情、CLI 与采集工具修改完成后才构建并开启测试；同一现实预算内以实际正式推进的游戏时长为吞吐指标，保留初始化、引擎、投影和封存拆解。AI 驱动器使用包含开局与封存的硬预算，不在授权时间之外另加宽限。按本轮明确要求，CLI 回放导出 JPG，并保留图片与实际聚焦、执行、游戏时刻及原始帧的对应。每轮结束由子代理逐张查看截图，并依据设计规范记录内容、因果与界面差异；下一轮集中修正性能、剧情和 CLI 后再开新窗口。只读回放导出与截图审查的耗时单列，不增加 AI 模拟时间；未发生的后续剧情保持未覆盖。本轮以 45 秒内正式推进的游戏时长和真实剧情进展共同判断结果，不预设 95 游戏分钟停止点，不以空转、开发调时、跳过正式行动或排除归档制造提速。实际是否执行及结果由当前任务记录说明。

## 冻结读取、当前任务顺序与记录语气

正式 Prepare、后台 Prepare、Complete、正文与关闭入口读取当前状态的不可变快照。需要追加事件时，DV 先取得独立事件列表；主体、账本和世界更新通过原持久替换返回新根。事件流、实际回执、费用与观察顺序保持原有语义。只读阶段因此不必为每次字段访问实体化整棵可变分支。列表追加和保留项以不可变子值写入新的可变根，首次真正修改该子值时才取得独立副本。

选择性根层以声明有 grants 的非移动／非答题／非等待任务为先，并按声明的实际时长稳定排序；同长任务与其余项保持原序。完整准入及价值仍在真正检查到该项时求值。排序声明扫描与排序缓存复用单列为实际工作，不能记成已经完成资格评估。完成且不可重复的普通任务提前返回原拒绝结果，答题、语言行动和重演仍遵守各自的重试规则。

固定观察者只需要本人的候选集。其他人物的真实行动、选择事件与执行结果仍录制，但不会为了旁观其行动而额外枚举其全部私有候选。跟随观察时先更新检阅主体，再取得对应候选。

记录标题读取明确的 voice：对话显示说话人，visible-action 显示现场记录，visible-inspection 显示观察记录，bodily-flash 显示本人回想，execution-feedback 显示行动反馈，formal-receipt 显示答辩回执，其余明确的非对话内容显示旁白。旧记录缺少 voice 时保留兼容。最近记录窗口省略了早期条目时，显示当前保留范围与回到更早记录的命令提示；省略只发生在展示窗口，原始记录不删除。

## CLI 两章激进优化（2026-10-22）

本任务以 main 的 5dd2e323 为基线；此前 45 秒窗口为历史任务，不约束本任务。用户授权每局 180 秒，两章结局与场景因果分别核验。当前实现不更改内容规则或为策略档特判结果。

`run_debug.py` 接受 Standard/Foolish 别名、`--detective-zone none`，以及独立的 `--opt-readview`、`--opt-plancache`、`--opt-prune`、`--opt-lazytext`、`--opt-recordcache on|off`，默认 on。全关保留合并前的选择性规划；`--selective-planning off` 另行选择原精确规划。新增 cow、mask、lazyinternal、dirty、planreuse、blackbox 均为独立默认 on 开关；具体覆盖范围如下，开关存在不代表性能或剧情已验收。

- readview：在内容目标刷新及正文投影入口读取冻结值；独立更新仍返回新根。既有 Runtime 写时复制不是本轮新增收益。
- plancache：按完整本人认识（含 revision）、所在房间、本人时间、策略与目标复用路线；另缓存纯声明导航条件和本人声明行。正式行动仍重新准入。曾尝试的完整选择键成本过高，已收紧到这些纯计算。
- recordcache：原生计算并按有效冻结身份缓存记录形状与引用查找键；不缓存可变字段值，关闭时使用原 DV 函数。
- prune：所有主体按自身既有评分保留 Top-K 待预测边，并收紧原 beam，`--prune-top-k` 默认 3。无角色白名单，不提高分数或预写结果。
- lazytext：正式会话只保存当前实际回执后缀与当时观察者的冻结状态，结束后按原 step 投影完整正文；不拿最终认知重写过去。延迟范围为诊断播放器投影，内容内既有字符串不宣称全部移除。投影及封存仍计入进程时限；中断可能尚未输出正文。

无侦探配置移除其可调度主体与实际位置，不赋予其他人答案；保留供声明引用的身份对象。原始 DAG 的事件封包附 `process_elapsed_ms`，以进程启动的 UTC 锚点加单调时钟测量事件提交时刻；该字段不进入人物世界或事件值。旧证据缺失该字段时保持缺失。

基线已发现并修复非答题 `judgment=false` 的正文类型错误，此修复独立于优化开关。构建、计时、剧情、完整正文与封存结果以 `artifacts/perf-opt/aggressive/` 当前证据为准，不以开关接线或构建成功宣称验收完成。
