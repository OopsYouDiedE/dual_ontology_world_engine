# Astra 独立三维建筑研究

日期：2026-10-24。此目录是独立建筑方案与模型使用说明，不修改游戏代码，也不设定新的剧情、人物或常住人口。依据主代理提供的功能边界及真实 Terrarium 地形数据建模；未读取项目设计正文、旧 SVG 或另一模型方案。

## 交付与重建

产物目录：`artifacts/campus-architecture-review/astra/`。

- `astra_campus.blend`：可编辑主资产，按功能和楼层拆分网格；隐藏原始地形、地下层等可在 Outliner 中开启。
- `astra_campus.glb`：当前外观与局部地形的可旋转交换模型；完整楼层与地下草图以 `.blend` 为准。
- `01_island.png`—`10_basement_diagram.png`：全岛、组团、火山口侧正面、2F切开、修士群、低处生活区、同机位原始地形、1F切开、3F切开和地下局部示意。
- `model_manifest.json`：原点、比例、主轴、层高、逐栋坐标/楼层/面积、局部挖填及未解决项。
- `building_schedule.csv`：从实际几何参数导出的逐栋面积表。
- `concept_reference.png`：内置 ImageGen 生成的一张美术概念参考；`concept_prompt.txt` 为完整最终提示词。它不证明地形、朝向、精确层高、结构或建筑数量。

`prepare_terrain.py`、`build_scene.py`、`finish_outputs.py` 是随模型交付的可编辑重建源，不是临时一次性脚本，不属于游戏生产路径。依赖本机 Python 的 numpy/Pillow 与 Blender 4.2；不需要游戏或 AI 测试。

```powershell
python artifacts/campus-architecture-review/astra/prepare_terrain.py
& 'C:/Program Files/Blender Foundation/Blender 4.2/blender.exe' --factory-startup -b -t 6 -P artifacts/campus-architecture-review/astra/build_scene.py
python artifacts/campus-architecture-review/astra/finish_outputs.py
```

模型采用 SimHei 字体生成中文图例；重建需保留 `C:/Windows/Fonts/simhei.ttf` 或改为本地可用中文字库。原始高程来源及哈希见上级 `terrain-source/manifest.json`；本目录的 `terrain_elevation.npy` 是无改高的解码数据。原始下载文件未改写。

## 本版固定几何

水平坐标相对原点经纬度 `(-31.1155, 39.67325)` 缩放0.5，高程保持1。地形坡度因而增至原来的约两倍；建筑、门窗与人物尺度没有随之缩小。

主楼为错位五翼：南翼76×12m、西翼12×36m、东翼12×30m、北翼52×12m、中脊12×24m，形成两个约20×24m庭院。南北中翼三层，东西翼两层，名录库与钟楼局部上升。附馆、低处住宅和修士群各自沿地形错位，而非整个校园套用同一方阵。

主正面与礼仪入口朝火山口代表方向，轴线为真北顺时针约5.73°。代表点是 DEM 内火山口洼地采样 `(230,2060)`，约396m；这不是精测火口几何中心，也不意味着可越过山脊看见湖底。南侧为海岸/后勤方向，客务路线绕至北门。北入口使用局部下沉前庭与宽阶，尚须进一步评估挖方及排水。

主楼完成面标高：B2 40.6m、B1 44.8m、1F 49.0m、2F 54.8m、3F 60.4m、局部4F 66.0m；档案檐口70.8m、钟楼檐口76.8m。这里的标高保留原始DEM垂直尺度，但不是现场测量成果。

主要层间为5.8、5.6、5.6m。外墙高窗、楼板、主/勤务梯、屋面、钟楼和连廊接口同步调整；没有通过增加2.5F或吞掉既有上层房间实现挑高。主楼2F/3F、档案入口、钟楼基部与典型多层分馆有真实分片楼板洞口。高层差楼梯采用双跑和中间平台。

2F四区各含四个卧室、独立区入口、内部走廊、活动厅与备餐/盥洗位置；公共回廊在区外连接讲堂、起居厅与楼梯。S01—S16及A—D只用于本图定位，不能替换既有剧情房号，正式映射由主代理完成。

## 真实边界与尚未解决事项

- 渲染地形仅在独立台基范围做可见局部挖填，原DEM另存；不能把此处6—7m级局部挖填说成已验证的小台阶。逐台最大挖填见 manifest，尚无土方量、挡土、排水或基础验算。
- 四条封闭连廊有独立高差接口，避免用平直桥面埋进坡体。详细防火、货物运输、完整疏散及接口每级踏步仍未审定。
- B1到四馆的勤务隧道仍为保留的功能连接要求，本版没有声称完成其开挖几何；地下图仅表达主楼局部勤务、水窖、设备和四锚占位。
- 墙、门窗洞、支承、楼板和楼梯达到可查看的结构草图层级，不是施工图；钟楼上段终点、部分室内家具及全楼细部仍需深化。
- 运输路、生活路、科研服务路分色表达关系，运输坡度、转弯、实际防潮、防洪、实验安全距离没有完成验算。
- 低处建筑的石墩、底梁及短撑可见；不能因其架空就宣称能承受风暴潮或冲刷。
- ImageGen 概念参考加强了风格与高挑感，也自由改变了部分造型和环境；不可反向作为模型或地形事实来源。
