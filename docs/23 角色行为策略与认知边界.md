# 23 角色行为策略与认知边界

章节事件和人物评价见 [02 地理箱庭、文献与六章剧情](02%20地理箱庭、文献与六章剧情.md)。本文说明人物如何根据认知、情绪与主导 Buff 选择活动，以及任务驱动与动机推演机制。

## 一、人物所知与认知边界

每个人物分别保存自己的见闻、信念和脑内地图。人物按注意、目标和已有认识筛选收到的信息，在主动观察、持续观察结束或必要核查时更新认识。观察和交谈保留来源；同一件事可以被不同人物理解成不同含义。

客观物理事实与主观动机推断严格分离：
1. **客观物理事实**：物证的物理属性、痕迹走向、门栓状态、身体创伤等，经勘验或通报后作为确定性证据记录在案卷与认知库中。
2. **主观动机推断**：对事件成因、锁门意图（避险防卫 vs 灭口囚禁）与清场动机的解释，受角色立场、信任度和主导情绪影响，不同角色持有独立信念。

人物依据自己所知作决定。职业、经历、关系、承诺和正在承担的任务共同影响其判断。

## 二、主导 Buff 系统与核心情绪

人物的心境受当前身上的状态（Buff / Moodlet）动态塑造，采用主导 Buff 决定系统：

### 1. 七种核心情绪
情绪体系收拢为七种核心心境，分别对应不同的行为偏好矩阵（Tag 评分）：

| 情绪 | 核心作用与行为偏好 | 主要驱动标签 | 抑制标签 |
| --- | --- | --- | --- |
| **睡眠** | 生理睡眠状态，阻断除唤醒外的外部行为调度 | `睡眠` | 绝大部分主动行为 |
| **不适** | 伤痛、寒冷、污渍、饥饿或受惊引起的不良感受，优先处理生理与安全需求 | `自护`、`清理`、`服药`、`休整` | `闲聊`、`深谈` |
| **警觉** | 察觉危机、异常反锁或威胁时的防御状态，驱动环境搜查与戒备 | `勘验`、`防卫`、`求助`、`探索` | `休整`、`闲聊` |
| **专注** | 进入调查、解密、书写或工匠操作状态，驱动深度推进与证物推演 | `推演`、`记录`、`分析`、`破拆` | `闲聊`、`走神` |
| **担忧** | 惦记特定伤者、失踪同伴或潜在危险，驱动探望、照料与通报 | `照护`、`通报`、`探望`、`协作` | `独坐`、`娱乐` |
| **悲愤** | 面对同伴被害、誓约破裂或无端猜忌时的激烈情绪，排斥轻慢社交，紧盯事实 | `对峙`、`勘验`、`求证` | `闲聊`、`休整` |
| **安心** | 危机暂时解除、饱餐或得到盟友承诺后的平稳状态，恢复日常作息与温和社交 | `用餐`、`闲聊`、`休整`、`深谈` | `警戒`、`过度防卫` |

### 2. 主导 Buff 决定算法
1. **权重累加**：每个活跃 Buff 具有生活化描述（`label`）、情绪归属（`emotion`）及情绪权重（`emotion_weight`）。
2. **主导判定**：系统按情绪归属累加所有活跃 Buff 的权重，最高权重者成为当前主导情绪；无活跃情绪 Buff 时回退到人物基准情绪。
3. **动态切换**：在 Buff 添加、移除、刷新或随时间自然到期（`Tick`）时，系统自动重新计算主导情绪；主导情绪改变时立即触发 `[情绪切换]` 事件。

## 三、日常活动与行动评分公式

人物根据饥饿、社交、精力和照护等需求选择当前活动。平时使用单步需求与偏好评分，特殊谋划占用单独的思考活动。

### 1. 评分公式
候选活动的最终评分（Score）由以下组成：
$$Score = \left( BaseBias + \sum TagScores_{emotion} + \sum TagScores_{buffs} + \sum NeedUtility \right) \times ScoreScale - Duration \times TimeCost$$

- **BaseBias**：DV 声明的活动固定固有优先级；
- **TagScores_{emotion}**：当前主导情绪对活动包含标签的增减分；
- **TagScores_{buffs}**：当前所有活跃 Buff 对活动包含标签的额外增减分；
- **NeedUtility**：活动对当前需求赤字（$100 - Value$）改善的边际收益；
- **Duration \times TimeCost**：时间成本惩罚，防止低收益冗长动作频繁占用。

### 2. 行为执行生命周期
活动依次经过申请、预留、接近、就绪、执行、退出与完成。起身、走近、放下手持物和转向属于完成该活动的准备步骤。活动失败时释放占用。
人物之间不产生移动碰撞，受墙、门和家具的物理阻挡。设施站位预约、交谈站位、人物选择、视线遮挡和门的安全检测独立生效。

## 四、前五日任务驱动系统与动机争吵机制

任务驱动系统指导角色在特定情境下的自发推进，通过主导 Buff 与目标引导角色完成证据采集、协作推进与推演对峙。前五日（第一至二章）构成完整的五阶段演进链：

### 1. 第一天（Day 1）：破局、汇合与清场自锁猜忌驱动
- **任务目标**：打破空间反锁隔离，汇总全区现场异状，核验清场真相。
- **阶段流转**：
  - **室内自检与勘验**：受【不适】与【警觉】驱动，角色清洗伤处、服药、就地勘验门窗栓位与残留痕迹。
  - **跨区破局与情报交换**：受【警觉】与【专注】驱动，雀儿暗井潜行、霍铎销柄复位打通各区，在门厅汇合并通报物证。
  - **拼凑推演与动机争吵**：物证凑齐后拼凑出拖拽、湿布、自锁清场的物理闭环。但各方对**反锁动机**（避险防卫 vs 灭口囚禁、内部协力者猜忌）发生不可调和的激烈争吵，形成最初的心结与阵营分歧。

### 2. 第二天（Day 2）：风窗开仓协作与物资配给争端驱动
- **任务目标**：利用风窗开放（09:00~17:00）开启 B1 主粮仓，清点生活物资，确立配给规则。
- **阶段流转**：
  - **工匠结构协作**：霍铎（机械检修）、玛格丽特（结构应力测量）与雀儿（锁芯破拆）受【专注】驱动，协同开启沉降死锁的 B1 主粮仓。
  - **清点与配给分歧**：沈鼎与沃德受【安心】与【警觉】驱动清点面粉、煤饼、药品，就“按大宸惯例公推掌勺”还是“按欧陆律条严格定额”爆发配给主导权之争。
  - **独坐打谱谋划**：阮清月在 R10 独坐打谱 60~120 秒，根据互信漏洞在三套候选计谋（骗取探针 / 伪造毁药记录 / 调动清册）中选定最优试应手，准备次日测试众人。

### 3. 第三天（Day 3）：试应手案件调查与伪证拆穿驱动
- **任务目标**：调查清晨爆发的物品流转与签字争端，还原事件真相，化解信任危机。
- **阶段流转**：
  - **冲突爆发与指控**：以典型案【十四张赞成票与被骗走的探针】为例，卢西安利用全体赞成假象骗取雀儿探针卷，沃德发现后指控雀儿私藏违禁工具，引发甲区与全员对峙。
  - **调查任务推进**：侦探接入调查驱动系统，受【专注】驱动采集走廊出入时间戳、比对借条字迹，走访核实苏泠从未同意的事实，并在棋谱夹层提取试探草稿。
  - **动机推演与当众对质**：证据闭环证明雀儿无辜、卢西安被误导，逼出阮清月的“试应手”动机。阮清月坦然承认仅为测试侦探破案能力与众人防卫底线，全员对阮清月的心计产生极深戒备。

### 4. 第四天（Day 4）：倒灌危机抢险与伦理抉择驱动
- **任务目标**：应对 17:30 地脉微震引发的 B1/B2 低位高浓源质倒灌，践行契约第七条并做出夜间值守抉择。
- **阶段流转**：
  - **险情暴发与涉险抉择**：微震震松低位联锁阀门，毒雾倒灌。莫兰明知危险仍为绘画涉险，贝尔特朗涉险营救，双双打破“无知免死”保护；维罗妮卡紧急配制 R-07 螯合剂，茉拉完成施救。
  - **第四夜防卫抉择**：夜间面临再次倒灌威胁，侦探在三种策略中权衡（与雀儿霍铎锁死大门 / 制造虚假内务留人室内 / 组织正常夜间值守）。
  - **人物认知评价**：全员度过危险夜后，依据各自价值观对侦探形成深刻评价：沃德重程序与诚实，阮清月赏识算路，茉拉认可零伤亡善意，雀儿与贝尔特朗结下同袍信任。

### 5. 第五天（Day 5）：倒灌善后与长效秩序重构驱动
- **任务目标**：复核伤员身心状态，汇总前五日所有物证与契约文本，建立四院长期共存秩序。
- **阶段流转**：
  - **深度诊疗与声学特质确认**：茉拉复诊前臂灼伤与踝伤；维罗妮卡测试确认苏泠的听觉神经与源质高频泛音产生强共鸣（为后续第三章星仪院三站声学联锁埋下关键伏笔）。
  - **案卷总汇编与认清现实**：侦探召集全员汇总五日案卷、代管者字条、分时日志与配给清册，全员认清长达 40 天封闭无法单人逃离的客观现实，动机争吵转为务实求存。
  - **长效制度落地**：确立四院轮流巡守排班表、热厨公共供餐机制与紧急警报响应程序，前五日第一阶段圆满收束。

## 五、交谈与情报交互

持续交谈保存参与者、话题、说话者、听众、轮次、姿态、位置与退出原因。

受邀人物按自己的需求、关系和当前活动选择接受、拒绝或稍后回应。双方到位后开始交谈，每轮包含发言、聆听和反应。
听者在实际听到相应片段后更新认知证据。中途离开时保留已听到的内容。轮次结束时，双方可因满足、疲劳、敌意、急事或目标达成结束交谈。

多人交谈按可用站位加入，人数变化时局部调整位置。交谈不仅传递物证事实，还会因动机归因分歧实时叠加【警觉】、【悲愤】或【担忧】Buff，进而影响交谈后的后续行为决策。

## 六、关键场景谋划与抉择

- **阮清月的谋划**：第二天下午，阮清月在独坐打谱期间比较三套候选计谋（时长 60～120 秒，分摊到思考活动中）。她按本人掌握的信任、持有物、方案条件和收益选择计谋，打谱结束后按所选方案行动。
- **第四夜的选择与评价**：伊莲娜根据已知耳罩佩戴状态和现场疑点决定是否摘下耳罩；恶魔发现阀下伤员后可将其搬至安全房间。侦探根据工具、盟友和物资条件选择共同锁门、虚假内务问题或正常值守。各方人物根据各自所知和价值观评价其行为。

## 七、内容与状态持久化

需求初值、衰减率、权重、情绪定义、Buff 定义、行动预测与完成收益均由 DV 声明。
运行中持久化保存需求数值、活跃 Buff 清单、主导情绪、承诺、活动进度与认知证据。存档和重载完整保留这些状态，重载后主导 Buff 动态聚合与情绪判定保持连续。
