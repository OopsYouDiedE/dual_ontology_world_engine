# 独创非商业设计规范

## 架构定位

本引擎的核心哲学为本体论二元架构（Dual-Ontology Architecture），即客观物理现实与主观认知现实并存互构。在遵循工业成熟标准的基础上，引擎在多项核心机制上构建了未曾在商业软件或成熟游戏工程中出现过的独创设计。

---

## 核心独创机制

### 物理躯体与认知心智的非对称多对多解耦

商业引擎普遍将可交互单位绑定为单一实体（如 Pawn / Controller 一对一绑定），本引擎将肉体与心智彻底分裂为独立实体系统：
- 角色实体（Character）：承载物理世界树位置、随身背包收纳（Inventory）与客观物理性质。
- 心智实体（Soul）：封装主观感知观察（Observations）、学识信念（Beliefs）、性格偏好、对数情绪与多步决策管线。
- 非对称多对多映射：单个物理肉体可同时挂载多个心智（实现多重人格、双重意识共存或恶灵附身）；单个心智亦可同时支配多具躯体，两者通过强类型 Facet 动态解耦互联。

### 五层动态聚合的无副作用实时源质投影

商业游戏中物体的元素或魔力属性普遍为静态离散标签或显式数值字段，本引擎构建了完全纯函数式的动态源质投影系统（Aspect Dynamic Projection）：
- 实体不静态存储超自然点数。在交互发生或仪式判定瞬时，引擎实时聚合五层来源：
  1. 固有属性（Intrinsic）：实体自身携带的象征标签。
  2. 材料构成（Material）：自构成材料按完整度比例投影。
  3. 客观物性（Property）：14 项物理性质（硬度、锋利度、通透性、反应性等）按常数投影。
  4. 动态影响（Influence）：依附于实体的时间衰减情绪状态。
  5. 定向关系（Relation）：指向交互目标的专属语义关系（所有、见证、描绘、伤害、真名等）。
- 整个计算过程纯函数化执行，无修改实体状态的副作用，提供纳秒级动态响应。

### 客观世界树与主观认识图的主客观二元拓扑隔离

商业游戏中的非全知感知系统通常依赖全局数据的几何视线或迷雾掩码计算，本引擎在数据结构底层实现拓扑分裂：
- 客观世界树（Ontological Reality）：由世界树与通道拓扑组成，真实持有门禁闭锁、空间连通与容器内容。
- 主观认识图（Epistemic Graph）：智能体私有的信念拓扑。智能体行为决策与路线规划完全基于其私有的四阶段内化图（Received $\to$ Understood $\to$ Accepted）进行求解。
- 允许错误与虚假信念：智能体在主观认识与客观现实发生冲突时，依然在认知封闭环境中稳定推演，直到新的感知输入触发信念修正。

### 仪式因果契约与违约惩戒反冲

商业游戏中的制造合成系统为即时、单向且无状态的物料替换，本引擎将合成升格为跨生命周期的因果契约（Causal Covenant）：
- 仪式配方构建包含多槽位源质门槛、参与者角色以及跨周期履约义务（Obligation）的契约实体。
- 契约由言灵监督系统（KotodamaSystem）全局追踪。
- 若契约有效窗口期内环境平衡破裂或参与主体违抗义务，系统不进行数据回滚，而是强制触发反冲惩戒（Breach），向违约实体的认知与生理切面写入不可逆的因果创伤。

### 规则系统的双层分流裁决机制

商业规则引擎普遍实行条件不满足即硬性阻止执行的单轨机制，本引擎对同一套产生式 AST 规则实施分层求值：
- 心智决策层：规则的 Require/Forbid 模式转化为心理规则压力（RulePressure），与外部 Utility 效用共同求和参与竞争，允许智能体为谋求更高效用而顶着心理负罪感违抗规则。
- 客观契约层：规则在物理可行性与言灵契约审核中升格为客观硬性法则，触犯 Forbid 或未满足 Require 的行为将被底层事务直接硬性拦截。
