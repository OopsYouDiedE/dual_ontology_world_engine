# 物理—语义二重本体世界模拟引擎公理设定

## 1. 底层公理

基础公理是世界模拟的最高约束，不可被实体、能力或规则违反：

- **A1 状态闭合**：世界在任意时刻均处于被允许的确定状态，异常现象亦有确定定义。
- **A2 因果连续**：任何变化均由前置原因引发，不存在孤立无因事件。
- **A3 资源守恒**：改变现实必须支付对应代价，严禁自引用与无源复制。
- **A4 本体分层**：世界分为物理层、语义层与认知层，跨层改变必须经合法通道映射。
- **A5 有限改变**：主体改变量受承载力约束，跨层与长期改变依赖仪式与结构支撑。
- **A6 语义一致**：语义力量依赖稳定指向关系，含义模糊或矛盾将引发失效与反噬。

## 2. 核心定理

### 言灵与许愿
- **言灵结构**：言灵须转化为明确语义结构，依托真名、空间或因果绑定起效。
- **限制与代价**：施加自我限制可增强言灵稳定性，高阶改变必须通过多阶段仪式分步完成。
- **解释权归属**：许愿仅表达目标，解释权归属底层机制。含糊表述导致路径偏差。

### 规则与认知
- **规则传播链路**：普通规则按“产生 → 传播 → 理解 → 接受”起效，不具备客观物理强制力。
- **硬约束区隔**：客观阻止由系统硬约束、RulePatch 或契约执行，主观规则仅提供决策倾向。
- **认知自洽**：主体基于自身世界模型行动，面对未知优先维持自身模型稳定。
- **理智本质**：理智是维持认知结构自洽的能力，非单纯生命值。真实恢复依赖意义重建。

### 异常与身份
- **概念锚定**：异常严格受其核心概念约束，存在固有边界与反制条件，不可套利。
- **身份多维连续**：身份由身体、记忆、关系与他人见证共同构成。
- **名称与本体分离**：名称是身份的寻址表达而非本体，名称变动不直接消灭存在。
