# 物理—语义二重本体论世界模拟引擎公理设定

## 1. 基础公理

基础公理是世界运行必须遵守的最底层约束，任何实体、能力、规则、异常与事件均不得违反。

- **A1 状态闭合公理**：世界在任意时刻均处于确定状态。任何物理、语义或超自然变化均使世界进入被允许的确定状态；异常本身亦属于世界状态，不存在脱离定义的“无规则状态”。
- **A2 因果连续公理**：任何结果均有确定的产生原因（物理过程、语义关系、规则执行、言灵作用、个体选择或异常影响）。不存在脱离因果链的孤立事件。
- **A3 资源守恒公理**：改变现实必须承担对应代价（生命、时间、记忆、身份、关系、权限或未来可能性）。不同类型资源不可任意等价替代；严禁通过循环引用、自我复制产生无限收益。
- **A4 本体分层公理**：世界分为物理层（身体、物质、空间）、语义层（名称、身份、规则、意义、关系）和认知层（记忆、理解、信念、自我模型）。改变某一本体层不会自动改变其他层，跨层影响必须通过合法机制完成。
- **A5 有限改变公理**：主体对世界的改变受自身能力与世界承载力限制。影响范围越广、持续时间越长、不可逆程度越高、涉及本体层级越高，所需条件越严格。大规模改变依赖仪式、结构、权限或长期积累。
- **A6 语义一致公理**：语义力量依赖明确且稳定的指向关系。含义模糊或内部矛盾的语义结构无法稳定产生现实效果，且容易产生偏差或反噬。

## 2. 言灵定理

言灵是通过语言、概念、身份或仪式结构操作语义本体的能力体系。语言仅为媒介，起效核心在于其承载的语义结构。

- **L1 语义转换**：言灵必须将文字表达转化为包含目标、条件、范围与预期结果的明确语义结构方可生效。
- **L2 目标绑定**：言灵作用必须依托与目标之间的真实联系（真名、身体连续性、血缘、情感、身份、因果或空间位置）。无绑定的力量只能表现为范围现象。
- **L3 现实改变量**：改变量越大（范围、时间、不可逆性），所需门槛越高。改变认知通常先于改变物理状态。
- **L4 限制增幅**：主体主动施加真实、不可轻易解除且降低未来选择的限制（誓言、契约、禁忌），可大幅增强言灵的稳定性。
- **L5 情感催化**：强烈稳定的情感可强化语义结构，但失控情感亦会增加偏差风险。情感充当催化剂而非无来源能源。
- **L6 言灵守恒**：言灵效果必须具有合法来源（施放者、第三方授权、既有因果或环境资源），不可凭空套利。
- **L7 契约约束**：涉及未来因果的言灵通过契约固定触发条件与责任，条件越明确，执行越稳定。
- **L8 亡语机制**：以不可逆的死亡为支付凭据、以极端情感与责任关系为绑定的延迟触发式言灵。
- **L9 献祭限定**：献祭依赖材料与目标之间的语义相关性，无关的大量牺牲无法替代关键的高相关牺牲。
- **L10 高阶仪式结构**：大型现实改变需通过仪式、阵法、时间窗口与权限承载，不可由单一步骤瞬时完成。
- **L11 生命创造限制**：生命包含物理连续性与语义连续性，制造身体不等于创造生命，复活必须满足身份与灵魂的连续性。

## 3. 许愿定理

许愿是向外部或底层机制提交目标诉求的现实干预方式。言灵定义“如何实现”，许愿定义“希望发生什么”。

- **W1 解释权转移**：许愿者仅提供目标，实现路径与解释权归属执行机制。愿望越模糊，偏差空间越大。
- **W2 愿力有限**：许愿机制受次数、时间、交换条件及承载力限制，不存在无限制满足愿望的机制。
- **W3 选择性实现**：超出机制能力、违反基础公理或导致无限循环的愿望将被拒绝、修改或重新解释。
- **W4 愿望偏差**：歧义与过于开放的表述会导致实现路径严重偏离许愿者本意。
- **W5 愿望代价**：愿望实现的现实改变必须通过直接交换、未来限制或因果补偿维持守恒。

## 4. 规则定理

规则是描述、限制与组织行为的语义结构。普通规则本身无物理强制力，需经主体认知接受或通过授权机制执行。

- **R1 规则作用链路**：普通规则生效需经过“产生 → 传播 → 理解 → 接受 → 影响行为”的完整认知链路。
- **R2 规则分类**：分为描述事实的信息规则、指导行动的行为规则、定义权限的制度规则，以及直接由言灵/异常强制执行的超自然规则。
- **R3 规则接受**：主体是否受规则影响取决于可信度、合理性、经验、群体压力与心理状态。
- **R4 规则冲突**：多条规则矛盾时，主体需依据自身价值体系与认知进行抉择，规则冲突不会自动消除。
- **R5 规则优先级**：优先级由所处体系（权威等级、直接目标、紧急度、个人信念）决定，而非单纯文字强弱。
- **R6 非强制性**：普通物理/文字规则无法直接强迫行动或修改现实；具备强制力的规则属于超自然或异常系统。
- **R7 理智与规则**：高理智者能辨识规则矛盾与漏洞；低理智者认知防御降低，更易受暗示或异常规则渗透。
- **R8 规则传播与范围**：传播范围不等于有效范围，仅进入具体作用环境并被理解的规则才能发挥作用。
- **R9 规则漏洞**：复杂规则体系必然存在未定义边界，漏洞来自于既有语义边界而非临时造物。
- **R10 规则与现实分离**：认知层与社会层的普遍承认不等于客观物理事实的改变。

## 5. 理智与认知定理

理智代表主体维持自身认知结构（自我认同、世界模型、价值体系、因果判断）稳定性的能力，并非单纯的生命值或精神蓝条。

- **S1 理智独立性**：理智与身体健康、道德水平相互独立，理智归零不直接等同于身体死亡。
- **S2 理智侵蚀**：侵蚀源于无法解释的异常信息与主体固有认知结构产生不可调和的冲突。
- **S3 知识危险**：危险取决于新信息对主体自我模型与世界理解的颠覆程度，以及主体是否具备承载知识的能力。
- **S4 认知防御**：主体通过否认、重新解释、调整价值观等机制主动维护自身认知模型的稳定。
- **S5 低理智影响**：理智受损削弱认知防御，使主体更易接受极端解释或受外界暗示影响。
- **S6 情感锚定**：强烈而稳定的情感（责任、爱、信念）是维持自我连续性与抵抗认知崩溃的核心锚点。
- **S7 理智恢复**：真正的恢复依赖于重建自洽的解释体系与意义连接，而非单纯遗忘。
- **C1 认知模型**：主体基于感知、记忆、知识与信念在自身内部构建世界模型，行动直接基于该模型产生。
- **C2 认知有限**：主体认知受信息源与观察力限制，未知不等于不存在，主观相信不等于客观事实。
- **C3 解释优先**：面对未知现象，主体倾向于选择最能维持自身世界模型稳定的解释。
- **C4 认知传播**：信息型异常的扩散依赖媒介，但仅在满足理解与认知漏洞条件时造成实质感染。

## 6. 异常与身份定理

异常是遵循特定异常规则但在世界公理下闭合的特殊现象；身份是主体在物理、语义与认知上的连续关系。

- **X1 异常有限性**：异常能力受自身结构、作用范围与现实承载力限制，不存在无限扩张的异常。
- **X2 异常侵入入口**：异常必须经由感知、语言、记忆、身份或情感等具体通道影响现实。
- **X3 核心语义依赖**：异常行为严格受其核心概念（如替代、遗忘、循环、模仿、吞噬、污染）约束。
- **X4 异常弱点与反制**：任何异常均存在作用条件、语义漏洞或媒介依赖等固有边界，可被理解与限制。
- **X5 异常不可套利**：异常不能通过自我复制或循环规避代价，否则将引发系统性崩溃或被世界规则修正。
- **I1 身份多维连续**：身份由自我认知、身体连续、记忆、社会关系与行为历史共同维持，单一要素缺失不立即消灭身份。
- **I2 身份锚点**：自我认同、身体经验、重要记忆与他人见证构成身份锚点，锚点越丰富，抵抗身份篡改与吞噬的能力越强。
- **I3 身份与名称分离**：名称是身份的寻址表达而非身份本体；失去名称不等于失去存在，取得名称不等于直接继承完整身份。
- **I4 身份恢复**：受损身份可通过找回关键记忆、重建因果关系与获得他人承认实现连续性恢复。
