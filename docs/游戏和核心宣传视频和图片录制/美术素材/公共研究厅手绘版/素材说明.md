当前整景与分类绘制源稿已归档到 `godot_csharp/ShareAsset/assets/environment/research_hall/`，按 `reference`、`walls`、`floor`、`hanging`、`furniture` 分类。该目录内 README 记录文件用途与待制版事项。

以用户提供的《饥荒：哈姆雷特》室内截图为风格与视角参考。本版聚焦公共研究厅单一场景，使用不规则墨线、交叉排线、低饱和块面与平面道具。此前写实刺绣、皮革、铜器图保留为身份设计参考，不作为场景渲染风格。

## 整景

`01-公共研究厅整景.png` 是带透视的构图稿。背墙中央为主门，两旁书柜；左侧高窗和棋桌；右侧公告墙、推理桌与取暖炉；三旗与吊灯位于上方；地毯周围保留角色活动空间。

整景不包含角色和UI，方便检查道具遮挡和动作空间。窗外海洋与火山只作背景暗示，不制作室外场景。

## 子元素视图约定

用户已确认整景，并明确家具采用“2D立牌画成3D”。子元素不继承房间位置造成的透视变形。墙面、门窗与旗帜采用平直正视图；地面和地毯采用俯视图。家具保持完整单张立牌，在画内用平行投影式转折表现桌面、侧面与厚度，不拆成需要拼装的桌面和支架。灯具同样以单张平面图表达少量体积。允许手绘不规则轮廓。

场景组合时由游戏层处理地面投影、平面朝向、缩放、排序与接触阴影。核心引擎不承担空间显示。

素材板用于审阅和后续切分；生成图中的重复纹理不默认无缝，正式导入前需校准拼接边、统一徽记线形和设置各道具锚点。若保留纸面底色，它属于展示背景，不属于场景材质。

## 图形取舍

徽记缩减为大轮廓：科学院为桂冠火炬，学院为火山口与海波，公会为三角眼。三旗为红金、黑银、蓝银。角色视距下不绘制微小龙鳞或细密织线。
