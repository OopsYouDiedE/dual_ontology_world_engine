# 宣传片美术素材索引

本目录保留视觉身份与学院日常规范插图；其中旧版本编号只是来源时间标记，不能决定现行首宣的镜头与角色出场。角色设定图另见 [`docs/academy_setting/characters/`](../../academy_setting/characters/)。这些图片用于设定参考，不代表当前可玩片段或运行时资产已验收。现行制作顺序见[首宣大纲](../机制主线宣传片大纲.md)。

- `身份体系第二版/`、`学院日常应用第一版/`：长期身份与日常视觉规范，仍由 [视觉身份设定](../../academy_setting/academy-visual-identity-zh.md) 和 [宣传片指导意见](../宣传片指导意见.md) 引用。
- [主题影片概念归档](../../../artifacts/theme-film/concept-archive/README.md)：标题界面稿、演出文件及历史动态素材包。它们不是运行时资源。

现行地图基础格为32×32像素，制作与验收统一见 [设计规范](../../design-standard.md)。旧48px素材不得直接作为当前规格；原始交付物、来源与授权记录随概念归档保留。
