# 学院纹章素材 · 第一版

> 本目录第一版SVG及旧复合长旗已作为历史草稿保留，不再作为执行标准。当前使用三面独立旗与皇家印章、来源纹样体系，见 `身份体系第二版/` 和上级《游戏美术考.md》。

本版按照《游戏美术考》绘制，保留五方象征与三轴位置。全部原稿为可编辑 SVG 路径，没有嵌入位图，没有外部图形依赖。PNG 仅用于预览。

- `学院正式长条旗.svg`：1000 × 1500 画布，黑底、浅银纹、浅燕尾下摆，无完整外边框。用于大厅、礼堂的仪式挂旗。
- `皇家科学院.svg`：蛇绕火炬、顶部火焰、下方开放桂冠。
- `学院火山与海洋.svg`：宽轮廓火山、火山口与三道海波，可作为日常学院标识。
- `神秘学公会.svg`：全视之眼、十节点生命之树、圆形六芒星阵。
- `皇家盘龙.svg`、`创院贵族雄狮.svg`：辅助授权及创院纹样。
- `纹章设计总览.svg`：完整旗帜与三组独立主体的对照展示页。

## 使用约定

主体颜色为炭黑 `#101619` 与浅银 `#D9DCDA`。独立徽记带同色黑底，蛇与生命之树局部使用黑色遮挡实现前后关系；改底色时应同时替换这些黑色区域。银色表示织线或装饰材料，不自发光。

旗帜中央主体更宽、线条更强，两翼保留纵向构图。盘龙和雄狮面积较小。完整旗用于需要表达创院历史的镜头；很小的门牌、铭牌优先采用学院独立徽记，不要求完整三轴在所有尺寸下都可读。

本版是平面制版原稿，未绘制褶皱、投影、磨损。放入手绘场景后按织物或雕刻材质处理，并检查实际镜头缩放后的辨识度。总览页中的文字为说明文字，不属于旗帜图案。
