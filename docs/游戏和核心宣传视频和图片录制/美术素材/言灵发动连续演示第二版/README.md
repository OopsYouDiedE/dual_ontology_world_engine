# 言灵发动 · 连续演示第二版

本版包含 19 张独立关键帧、一张总览、16 秒可播放预演及对应绘制素材。全部画面从同一场景时间轴导出，采用已确认的公共研究室与《饥荒》式手绘平面角色。

## 查看

- 打开 index.html，点击“播放”或拖动时间轴；下方按钮可逐个查看关键节点。
- 连续动作预演.mp4 是同一时间轴导出的 16 秒、24 fps 动作预演。
- 连续关键帧总览.png 用于顺序检查；frames/ 内为 19 张 1536×1024 PNG。
- keyframes.json 记录每张图的时间与动作说明。
- assets/ 包含固定房间、威尔逊六姿势、麦斯威尔三姿势、木桌与棋桌、暗影手三阶段、书本素材。素材由内置 imagegen 绘制，最终提示词及修订记录见 prompts.json。
- scene.js 保存确定的锚点、位移、遮挡和效果时序。此页用于美术及动作预演，未接入核心引擎的言灵判定。

## 布局与动作

房间底图全程相同。为避免已有棋桌提前泄露转化结果，本段使用普通木桌，略向地毯左边移；两张椅子移出本段活动区域。门从开始就是打开状态，威尔逊从门槛进入，不额外加入开关门动作。

威尔逊沿中央门到地毯的一条连续路线进入，停步后用托脸、松肩表现偷懒。输入时保持站位。红书短暂拍到脸侧使他向右后退 24 像素，随后在该处跌蹲扶额。恶魔成句时，他在原地抬头、放下扶额的手，睁大眼睛看向麦斯威尔，并将这个反应保留到结尾。麦斯威尔始终站在木桌左侧，大笑和发动时只更换姿势；最终保留站姿，避免没有衔接的落座。

四本书在起始书架、飞行和落地阶段保持一一对应。第一本红书拍脸侧后迅速滑落，保留眼睛可见；其余三本从肩侧和身体后方掠过，不集中遮脸。落地后持续保留，桌子变形不改变书堆或人物位置。

## 道本语

威尔逊头顶逐字显示 `lipu mi wile o kama tawa mi.`。这是本段故意不严谨的命令：“lipu mi wile”把“我想要的书”直接压成修饰词串，目标没有明确锚定到一本书。本预演将失败表现为书架上四本书一起响应。该失败解释属于本游戏言灵设定，不是对自然语言含义的唯一判读。

麦斯威尔一次显示 `supa ni o kama supa musi.`，简明释义为“这张桌子，变成游戏桌”。`supa musi` 本身不专指国际象棋桌；在本段中，恶魔朝向确定所指桌子，更高位格与意愿将结果锚定为国际象棋桌。位格是首要原因，语法正确是次要原因。本句为演示用译写，不作为项目完整语言规范。

两者均是输入完成立即生效，没有 Enter 提交阶段。头顶直接显示文字，没有纸卷、输入框或空中按钮。威尔逊使用朴素字体；麦斯威尔使用 Gabriola 书法字体、暖金色字面和细小花饰表现更高位格（无该字体时回退 Palatino/serif）。命令句 `o` 的用法参考 [lipu sona pona 教程](https://lipu-sona.pona.la/en/7/)。

## 暗影手与棋桌的实现方式

先从桌底露出指尖，再伸出长腕抓住桌沿，随后压改桌面。双手用三张绘制姿态及固定地面锚点表现，分为桌后、桌前接触两次绘制。伸出和收回使用从同一底部展开的遮挡范围。

木桌本体始终使用同一张素材。棋盘只在桌面内沿的菱形遮罩中分三段显现，原桌框、桌脚与占地不变。暗影手收回后保留棋桌。言灵仅转换桌子，本段不无故额外生成棋子。

## 复核结果

已整体查看 19 帧总览，并检查扑脸、偷懒、改装与最终场景的原尺寸合成效果。

像素对照确认：

- 全部关键帧的上部背景、右侧家具和前部地板保持一致。
- 四本书完全落地后，后续每一帧的落地区域保持一致。
- 停步偷懒到输入中只改变头顶文字区域。
- 第一段改装到最终场景的变化边界为 x=401–661、y=547–786；其他位置像素相同。

PNG、播放页与录制均来源于 scene.js 的同一时间轴。当前交付属于可播放的美术动作预演，正式角色步态与帧间缓动仍可在接入游戏层时按既有动画系统调整。
