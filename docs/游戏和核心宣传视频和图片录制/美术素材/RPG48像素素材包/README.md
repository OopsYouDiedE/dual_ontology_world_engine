# RPG 48px 像素素材包

> 本版已废弃：旗帜格数错误且缺少动画。使用上级目录的 `RPG48动态素材包`，长旌旗为 48×96，横旗与纹样为 48×48。

本版使用内置 imagegen 重绘，按 48×48 网格切分。原始设计稿保留在上级目录。

## 内容

五方顺序：皇室团龙、皇家科学院、神秘学公会、学院、伯爵个人。伯爵沿用雄狮象征，本版个人旗采用酒红底金狮；皇室团龙按本次要求扩展为正式旗帜。

- 长条旗：5 张，每张 96×192（2×4 格）。
- 旌旗：5 张，每张 96×144（2×3 格）。
- 独立镂空纹章：5 张，每张 96×96；另附 5 张 48×48 小纹章。
- 透明图集：480×432，10 列、9 行，每格 48×48。
- 网格切片：90 张 48×48 PNG，包含保留排布所需的透明空格。
- 无字标题背景：768×432 原生使用版、1536×864 整数放大版。

所有旗帜和纹章均为真实 RGBA 透明背景，输出边缘使用二值 Alpha。图集无间距、无外边距；每件主体的透明留白已经包含在对应矩形内。源图由模型生成，成品经过裁切、最近邻缩放和透明边缘整理，并非将生成原图直接作为 48px 图集。

## 导入

使用 `图集/五方旗帜纹章_48px网格.png`，网格设为 48×48，纹理过滤设为 Nearest，关闭 mipmaps。图集从左到右为上述五方；长旗从第 0 行起，旌旗从第 4 行起，纹章从第 7 行起，行列均从 0 计数。每件占两列，具体矩形见 `图集/atlas.json`。

长旗和旌旗是多格静态装饰，按完整矩形放置；需要逐格拼装时，使用 `48px切片/tile_列_行.png`。不包含地形自动连接规则或飘动动画。

标题背景是完整场景图片，直接用于背景层。它没有文字、按钮或 UI，不按可重复地形砖使用。

`预览/旗帜纹章_3倍.png` 仅供观察像素细节，不作为游戏导入源。生成提示词记录于 `生成提示词.md`；运行 `打包.ps1` 可从本包源图重新生成成品（Windows PowerShell，System.Drawing）。
