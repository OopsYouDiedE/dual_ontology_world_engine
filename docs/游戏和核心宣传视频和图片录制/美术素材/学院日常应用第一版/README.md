## 制作边界

制服仍需按实际角色体型适配并制作动作；导师肩披是可移除的身份部件。地毯与砖图目前是带展示背景的概念图，砖缝、转角与重复纹样接缝尚未制成无缝纹理。徽记和纹样在不同载体上的精确轮廓需在生产制版时统一。
