# 动态帧参考

## 垂挂长旌旗

[TWD_BALDI — Modular_Banner_16x16](https://jbs-pixelstorm.itch.io/modular-banner-16x16)

实际下载并查看了 Banner/01-Quiet-Modular-Banner.png（64×16，四帧），并对照了 01-Windy-Modular-Banner.png（144×16，九帧）。本版采用 Quiet 的轻摆方向，参考固定顶部、侧缘折痕与下摆变化，重新生成八帧。长旗形状、配色与五方纹章来自本项目原设计。

## 横向飘扬旗

[Screaming Brain Studios — Animated Flags Pack](https://screamingbrainstudios.com/dl-animated-flags-pack/)

实际下载并查看了 FR_Ortho_Flat-192x136.png：4×4 排列，共十六帧，每帧 192×136。抽取 0、2、4、6、8、10、12、14 相位组成横向参考条，观察波形传递和色块宽度随褶皱压缩、展开的变化。参考包所附 License.txt 标注 CC0。

## 交付

两份参考帧图均作为图像输入交给内置 imagegen，配合本项目已有五方设计重绘本版帧表。第三方原图与下载包不放入素材压缩包；工作参考保存在工作区 tmp/flag-motion-reference/。压缩包包含本次生成成品、提示词及来源记录。

本版为八帧绘制动画，并非把参考十六帧直接转色。统一采样到 48×96 / 48×48，固定挂杆由首帧共用。循环预览见 预览/五方旗帜循环.gif。
