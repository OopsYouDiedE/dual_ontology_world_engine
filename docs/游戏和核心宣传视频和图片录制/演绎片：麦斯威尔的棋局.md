# 演绎片：恶魔麦斯威尔的棋局 — 完整台词与表演剧本

## 概述

本文为印象片的完整剧本，独立于宣传片机制演示部分。印象片负责建立心智预期与悬念，展现恶魔的压迫感、威尔逊的推理，以及真名和言灵带来的极致危险感。

- **对弈棋谱**：1971 年候选人赛四分之一决赛第四局（菲舍尔 vs 泰马诺夫，45至71回合象对马残局）。麦斯威尔执白（对应菲舍尔），威尔逊执黑（对应泰马诺夫）。
- **空间**：昏暗的公共研究厅壁炉前棋桌。

### 核心人物速查

- **恶魔（Maxwell / 麦斯威尔）**："麦斯威尔"仅是假名。绝对守约、无谎言、善于利用真实信息诱导对方失衡。优雅从容，威压极强。
- **侦探（顾知微 / 威尔逊）**：玩家主角。拥有能力【浮游幻梦】，可在脑内还原与逆演推演。克制、执拗、敏感，极易受认知侵蚀。

---

## 一、开局：他连棋都快下不稳了
```text
(麦斯威尔落子。)

[麦斯威尔]: 将军。

(威尔逊抬手移王。)

[麦斯威尔]: 那里也不行。

(威尔逊的手停在半空，重新检查棋盘。他漏看了一枚象。)

(麦斯威尔耐心等着，仿佛正在教一个初学者。)

[麦斯威尔]: 慢慢来。

(威尔逊收回手，换了一步。)

(麦斯威尔立即吃掉他的车。)

[麦斯威尔]: 你一直在看门。

[威尔逊]: 习惯。

[麦斯威尔]: 侦探的习惯？

(它将吃掉的车放在一旁。)

[麦斯威尔]: 还是逃犯的？

(威尔逊没有回答。)

[麦斯威尔]: 你进学院的时候，也是这样。先找出口，再找人。

[威尔逊]: 你见过我？

[麦斯威尔]: 你不记得的事，有很多。

(威尔逊盯着它。)

[麦斯威尔]: 要我帮你想起来吗？

[威尔逊]: 不必。

(麦斯威尔轻轻点头，继续下棋。)
```

## 二、中盘：现实里的劣势侵入脑内
```text
(威尔逊开始计算。)

(脑内浮现棋盘。一条变化推演到第三步，忽然多出一枚原本不存在的黑棋。)

(他重新计算。黑棋仍在那里。)

(现实中，麦斯威尔的指尖轻敲桌面。)

[麦斯威尔]: 该你了。

(威尔逊勉强走出一步。)

[麦斯威尔]: 你的后。

(威尔逊低头，才发现自己把后送进了攻击范围。)

(他立即伸手，碰到已经松开的棋子。)

(麦斯威尔看着他的手。)

[麦斯威尔]: 当然可以悔棋。

(停顿。)

[麦斯威尔]: 说一声就好。

(威尔逊把手收回去。)

(麦斯威尔吃后。)

(脑内，那枚黑棋也随之向前移动。威尔逊试图将它抹去，棋盘却越来越清楚，连闭眼也无法摆脱。)

[威尔逊]: 拿走。

[麦斯威尔]: 什么？

[威尔逊]: 我脑子里的东西。

[麦斯威尔]: 你得说清楚。要我进去替你拿吗？

(威尔逊张了张口，没有回答。)

(麦斯威尔俯身，声音温和。)

[麦斯威尔]: 你已经很累了。

(威尔逊猛地推开椅子，想站起来。脑内的棋盘骤然倾斜，他失去平衡，扶住桌沿才没有摔倒。)

(几枚棋子被碰歪。)

(麦斯威尔伸手，一枚枚扶正。)

[麦斯威尔]: 还没下完。
```

## 三、逼迫：恶魔借导师的声音开口
```text
(威尔逊重新坐下，额头冒汗。)

(脑内响起一个陌生，却让他本能恐惧的声音。)

[导师·脑内]: 不要改顺序。

(紧接着，是同一句话。更急，更近。)

[导师·脑内]: 不要改顺序！

(威尔逊的手抓紧桌沿。)

[威尔逊]: 这是他的声音？

[麦斯威尔]: 你开始记起来了？

[威尔逊]: 是你放进来的。

[麦斯威尔]: 那你为什么害怕？

(威尔逊无法回答。)

(他甚至不知道，自己听见的是伪造的声音，还是被唤起的记忆。)

(麦斯威尔落子。)

[麦斯威尔]: 将军。

(脑内的声音仍在重复。威尔逊看不清棋盘上的位置，伸手碰倒了自己的王。)

(麦斯威尔按住倒下的棋子，没有替他扶起。)

[麦斯威尔]: 需要我帮你吗？

(威尔逊低着头，喘息。)

[威尔逊]: ……你已经问第三次了。

[麦斯威尔]: 你终于准备回答了？

[威尔逊]: 你一直在等。

(麦斯威尔没有接话。)

[威尔逊]: 这些声音……你可以塞进来。但你碰不到我的记忆。

(脑内的声音骤然加重，盖住他后半句话。)

(威尔逊痛得弯下腰。)

[麦斯威尔]: 你可以继续这样安慰自己。

(威尔逊等到能够重新说话。)

[威尔逊]: 否则，你早就自己看了。
```

## 四、转折：威尔逊真的给它机会
```text
(麦斯威尔缓缓松开那枚王。)

[麦斯威尔]: 所以呢？

[威尔逊]: 我允许你帮我。

(这次轮到麦斯威尔安静。)

(威尔逊抬起头。)

[威尔逊]: 但我要你保证。拿走这些声音，然后退出去。不要碰我的记忆。

[麦斯威尔]: 好。

[威尔逊]: 说完整。

(麦斯威尔看着他狼狈的样子，露出一点笑意。)

[麦斯威尔]: 我会拿走这些声音，然后退出去。不碰你的记忆。

(威尔逊摇头。)

[威尔逊]: 我要知道，是谁答应我的。

[麦斯威尔]: 麦斯威尔。你不是一直知道吗？

(威尔逊开始念出残页上的称谓。他念了一半。)

[麦斯威尔]: 闭嘴！
[麦斯威尔]: 你连他为什么没写完都不知道，就敢接着念？

(他无法判断，麦斯威尔究竟是在阻止他念出完整真名，还是在阻止某种连他自己都不知道的后果。)
```

## 五、高潮：它知道有约束，仍然选择接受
```text
(麦斯威尔重新靠回椅背。)

[麦斯威尔]: 原来你找到了一点东西。

(它已经知道，这次承诺会生效。)

(但威尔逊也确实要给它一次进入意识的机会。它需要确认这个学员究竟掌握了多少知识，也愿意为此付出清除幻象的代价。)

[麦斯威尔]: 好。我答应。

[威尔逊]: 进来。

(脑内的声音全部停止。)

(短暂寂静之后，麦斯威尔的声音从意识深处响起。清晰、贴近，没有了先前的回声。)

[麦斯威尔·脑内]: 你还藏着多少？

(它发现威尔逊脑内没有准备中的封印，也没有复杂法阵。)

(只有刚才的棋局，以及一段被刻意记住的声音。)

(是它自己的声音。)

[麦斯威尔·记忆]: 我会拿走这些声音，然后退出去。不碰你的记忆。

(威尔逊在现实中开口。)

[威尔逊]: 依你亲口所允。

(麦斯威尔立刻试图寻找那段称谓的来源。)

(就在触及记忆边缘的瞬间，它被自己的承诺阻住。)

[威尔逊]: 取走你带来的声音。

(脑内棋盘上的黑棋逐一消失。)

(麦斯威尔的声音第一次失去从容。)

[麦斯威尔·脑内]: 你只求这个？

(威尔逊终于能够挺直身体。)

[威尔逊]: 然后，退出去。

(声音断绝。)
```

## 六、收尾：他赢得一次喘息，棋局仍然输了
```text
(现实中的麦斯威尔望着他。)

(威尔逊伸手，扶起自己的王。指尖仍然颤抖。)

[麦斯威尔]: 那些声音，我本来就随时可以收回。

[威尔逊]: 现在，是我叫你收回。

(停顿。)

(麦斯威尔低头看了一眼棋盘。)

[麦斯威尔]: 将死。

(威尔逊检查片刻，将王放倒。)

[威尔逊]: 是。

(麦斯威尔没有庆祝。)

[麦斯威尔]: 那张残页。你在哪里找到的？

(威尔逊第一次让它等待回答。)

(黑屏。)
```
