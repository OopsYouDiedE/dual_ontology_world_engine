# 游戏宣传展示规范

## 一、展示定位

宣传内容分为印象片和机制演示。

**印象片负责让观众觉得“这个游戏很酷”。**采用威尔逊与麦斯威尔下棋的剧情，表现恶魔的威压、威尔逊的推理，以及真名和言灵带来的危险感。它不展现游戏内的实际内容。

**机制演示负责展示玩家实际怎么玩。**核心是脑内编写、推演、规则执行，以及附加的其他小玩法。

本次只实现演示路径涉及的内容。镜头之外的交互不制作，演示之外的系统不扩展。

## 二、统一表现原则

脑内世界用于组织概念、编写言灵和规则，并推演人物已知条件下的结果。现实世界展示人物实际行动及其后果。

**脑内推演不能读取未知事实，也不能保证预测正确。**未知条件需要保留，不能由推演替玩家完成调查。演示中可以通过现实结果与推演的差异，引出新的线索。

规则使用项目已有 AST，其中填入指定概念。日常规则、避险规则和恶作剧规则使用同一套表达方式，不分别制作互不相通的系统。

人物是否执行一条规则，需要有明确依据，例如接受了安排，或处于已经成立的契约之中。玩家不能通过修改脑内结构，无条件控制其他人物。

## 三、核心机制演示

### 1. 编写言灵：把已有写法改成自己的方案

作为言灵，我们要反向的提高其编写复杂度，具体方法为：使用类似道本语的模式，降低总的可用词汇数量，提升语法复杂度。

玩家在脑内取出导师范式，填入已掌握的概念，形成完整言灵。随后修改其中一个执行关系，保存为自己的版本。

这一段应当展示一次有意义的结构变化。具体效果从项目已有能力中选取，先确认 AST 能够表达，再确定画面。

画面需要让观众看清：

- 原来的言灵如何组织。
- 玩家改动了哪个部分。
- 修改后的含义发生了什么变化。
- 成果能够保存，之后再次调用。

言灵的规则，并不是我们一般所理解的那样。它非常强调真知的锚定性。

### 2. 脑内推演：在不认识危险对象的情况下完成任务

玩家接到一项需要多人配合的任务。危险对象无法安全地直接描述，但调查提供了可以使用的间接判据。

玩家先调用导师的保守范式，再在脑内推演。推演表现为人物按照规则依次行动，并显示任务在哪里被中断、哪些人需要等待。

在宣传内容中，只展示脑内推演，人物采用一个灰色无名小人。演示动作。

本段重点是：

**玩家通过推演理解规则的后果，再利用有限知识完成任务。**

采用一条确定能够成功的演示路径。无需实现任意规则的完整模拟，但画面中的每个判断都必须有已知依据。

### 3. 调查改变推演：发现错误认识，而非只收集材料

安排一个短片段，展示初次推演保留了某个未知条件。现实中的一次可承受偏差，为玩家提供新线索。

玩家回到脑内，更新相关概念或条件，原本无法判断的分支得到补全。

这段不以首次尝试必然重伤作为代价。它要表现：

> 调查得到的信息，会直接改变玩家能编写什么、能推演到哪一步。

这可以复用上一段任务的场景和结构，无需另做一套关卡。

## 四、群像与日常机制演示

### 4. 日常互动：人物记得玩家如何对待自己

选择一个简单的日常互动，例如玩家注意到同伴的偏好，在之后的互动中作出对应选择。

先展示同伴当下的反应，再用一个后续动作表现关系变化：主动靠近、留下座位，或主动发起交谈。好感度变化可以作为辅助反馈。

这里不需要展示完整对话树。只制作一次互动及其后续回应。

人物关系不直接等同于服从程度。关系改善可以影响合作意愿，但不能让危险安排自动获得接受。

### 5. 恶作剧规则：严肃系统可以产生荒诞结果

使用一条临时成立、适用于参与者的日常规则，让人物在完成某项普通活动前，多走一段无意义的路线。

先让观众看懂规则，再连续展示不同人物的反应。有人照做，有人边走边抱怨，有人走到一半才意识到被捉弄。

最后，麦斯威尔也受到同一条规则约束。

**恶魔绕路必须有成立依据。**可以在前面的短对白中，让它明确接受这次活动的共同规则。不能因为玩家写了“所有人”，就突然拥有支配恶魔的能力。

路线通过几个预设地点和移动动画表现。核心只处理前往地点的行动顺序，不承担房间内寻路或碰撞计算。

这一段适合做成短传播片段。它能直观说明规则确实影响人物，也让观众看到游戏的幽默感。

### 6. 同伴保护威尔逊：推理能力也会成为弱点

威尔逊在脑内把几条线索逐渐联系起来，接近危险认识。

此前接受了保护安排的同伴，根据外部可观察的征兆中断他的调查，收起材料或接替当前工作。中断发生在危险关联完成之前。

脑内尚未成立的连接随之停止延伸，现实中威尔逊恢复对周围的注意。

这一段展示群像的实际价值：威尔逊需要别人帮助他控制风险。中断不会抹除已经形成的知识，也不能表现成通用的侵蚀治疗。

## 五、印象片

棋局单独作为印象片制作。

使用已选定的经典残局作为落子依据，重点保留：

- 威尔逊持续受压，动作和计算逐渐失常。
- 麦斯威尔以礼貌的方式试探并施加影响。
- 威尔逊从反复请求许可的行为中发现限制。
- 真名称谓即将完成时，麦斯威尔打断。
- 威尔逊争取到一次有限让步，棋局仍然告负。

完整真名不公开。麦斯威尔的打断同时保留自保和救人的解释空间。

此前尚未闭合逻辑的真名封印胜利，不放入印象片。

## 六、制作顺序与复用范围

先制作脑内编辑的统一表现，再制作推演和人物执行。日常互动、恶作剧和同伴保护复用已有角色、动作及规则表现。棋局演出单独安排。

首批必须完成：

1. 言灵编写。
2. 避险规则的编写、推演与任务完成。
3. 日常互动及关系反馈。
4. 包含麦斯威尔的恶作剧规则。

随后补充调查修正推演、同伴保护威尔逊。两段优先复用已有素材。

最终的机制演示应当让观众看见：**同一套脑内编写能力，可以用来施放言灵、组织求生，也可以改变人物之间的日常生活。**印象片再将这些能力推向与恶魔交锋的高潮。
## 人物风格与制作范围

人物采用类似《饥荒》的表现方法：以二维手绘、夸张比例和清楚的剪影表现人物，通过有限动画完成动作和表演。

参考的是制作方法与表现效率。人物轮廓、五官、服装和动作习惯需要独立设计，不能沿用《饥荒》的具体形象。尤其本项目主角也叫威尔逊，应当避开高耸尖发、相近脸型及红黑服装组合。

### 人物视觉方向

整体采用带有学院背景的手绘哥特风格。服装体现皇家匆忙建立的研究学院：正式制服与个人携带的职业服饰混用，配件保留实际用途。

人物需要适当夸张头部、手部和姿态，让日常动作以及桌前交锋在较小画面中仍然清楚。避免过多细碎装饰，将辨识度集中在轮廓、面部和一两处服装特征上。

日常画面使用有限帧数的二维动画。印象片中的关键表情和手部动作单独绘制，不要求日常角色素材支持全部特写。

### 威尔逊

威尔逊的设计重点是敏锐、克制，以及精神消耗带来的狼狈。

建议采用偏平直的发型轮廓、略长的外套和冷灰色系。调查用品作为局部识别元素，不堆叠成侦探符号。

动作上，他会先观察再伸手，思考时容易忽略周围。受到干扰后，这些习惯逐渐失常：重复检查、伸手停顿、抓紧桌沿。确认关键判断时，视线和动作重新稳定，身体的疲惫仍然保留。


### 麦斯威尔

麦斯威尔的人形应当足够可信，让人能够接受它平时坐下来与学员下棋。

建议用整齐的浅色服装、紧凑的发型轮廓和舒展的姿态建立辨识度，避开《饥荒》中麦斯威尔标志性的尖锐头型及黑色西装形象。

它的威压主要通过表演建立：很少调整坐姿，落子准确，等待时毫不焦躁。与威尔逊的慌乱形成关系。

异常表现只在少数镜头中出现，例如脑内声音继续说话，现实中的嘴已经停止。不要依赖常驻獠牙或持续变形，否则会削弱人形伪装。

### 制作人数

**首批只制作威尔逊和麦斯威尔。**其余人物不制作立绘、模型或动画。

如确有展示需要，最多追加两名同伴，每名都必须承担明确的演示用途。暂不扩展十六人的视觉设定。

这不会改变故事中的主角团规模，只限定本次宣传素材的制作范围。

### 对展示内容的调整

两人版本即可完成言灵编写、棋局印象片、日常互动，以及有明确承诺依据的恶作剧规则。

避险任务先采用威尔逊单人执行的方案，通过脑内推演展示规则效果。先前的多人接应、集体停止和群体绕路镜头取消。

如追加一名同伴，再加入好感度反馈、任务交接和中断威尔逊调查的动作。第二名同伴仅在需要展示不同人物对同一规则的反应时制作。

**先用两名角色把核心表现做成立，再按镜头需要增加人物。**不为尚未进入制作的内容预备完整角色资产。
