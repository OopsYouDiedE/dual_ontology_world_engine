# 游戏机制演示设计方案
## 目标和决心
利用游戏引擎核心特性，设计核心交互，以及围绕被展示的核心交互专门制作美术素材和UI交互。
本方案仅对会被展示的内容进行设计，在展示窗口外内容不会进行设计。

### 核心机制
本游戏核心机制为：
- 利用引擎对主客观二重世界并行维护的特性，完整的实现规则怪谈类游戏中超自然实体和恶魔对人类施加认知干扰。
- 一套基于和主流语言语法均不同，极度简化的语言，作为言灵的基础，为言灵增加复杂性。
- 要求玩家使用脑内推演和规避危险认知词汇方式，设计合适规则，能有效提升规则的设计难度。
- 继承规则怪谈体系中，关注异常本身会造成损害。利用规则，不认识到异常的同时绕过异常的设定。
- 继承规则怪谈和克苏鲁体系中，对知识的认知造成自我损害的特性，知晓针对高位阶实体真名，同时能够获得建立高强制性的契约和让自己疯狂的设定。
- 继承咒术回战中通过主动将自己暴露在危险境地提升法术能力的设定。

### 美术风格
目前已经确定，场景和人物的绘制方案类似于饥荒，采用斜俯视角，加上平面绘制的场景实体。

公共研究厅整景已由用户确认，参考《饥荒：哈姆雷特》室内图，采用粗细不均的墨线、交叉排线与低饱和块面。整景带透视；子素材不带房间位置造成的透视变形。墙面为平直正视图，地板为俯视图，家具是单张2D立牌，在画内保留桌面、侧面与厚度的手绘体积。当前整景与拆分稿见 `美术素材/公共研究厅手绘版/`。
人物仅绘制两个；以麦斯威尔为原型的恶魔伯爵，和以威尔逊为原型的主角侦探。
人物动作采用手绘，大部分动作保持三帧完成。在三帧和三帧间嵌入一不动帧。
仅绘制在演示中展示的人物动作。

### 音乐和配音
音乐采用统一的8bit风格配乐，主体旋律为不安的小调。
## 演示区域设计

演示主要发生在学院主楼一层的公共研究厅及其前廊。该区域兼具阅览、讨论、休息和小型研究功能，并设置明确的主入口、开放活动区域、棋桌、推理桌、书柜和规则公告墙，因此可以在同一场景内承载言灵发动、脑内推演、日常互动、恶作剧和认知干扰等主要演示内容。

言灵可直接作用于研究厅入口等已经成立的空间边界；脑内推演则以研究厅为基础，将现实场景逐步简化为门、人偶、路径和规则文本构成的主观模拟空间；麦斯威尔邀请威尔逊下棋发生在固定棋桌区域；恶作剧规则被张贴在公告墙，人物随后在中央开放区域执行错误规则；“保护威尔逊”则发生在推理桌，威尔逊陷入危险联想后由麦斯威尔强行打断。

场景美术只制作演示真正需要的内容，包括主门、高窗、棋桌、推理桌、少量书柜、公告墙、壁炉或取暖炉、地毯、学院长条旗和少量研究杂物。室内采用学院主楼统一的红砖、深色木材和黑色铁件体系，并在不同器物上少量使用王室、皇家科学院和神秘学公会的继承纹样。窗外可直接看到岛屿的火山与海洋，使学院徽记中的地理象征与真实环境对应。

整个场景遵循“仅制作展示窗口内内容”的原则，不制作完整学院、宿舍区、天文台内部、化学实验楼或岛屿全貌，其存在只通过窗外轮廓、背景、文件和装饰纹样进行暗示。
## 分场景设计
### 言灵发动
主角威尔逊右手高举象征物，发动言灵。主角发动的言灵会出现在人物上方，和饥荒一样。
当然，有些言灵发动也需要场地符合条件。
下面是候选内容。（由AI提议，不是我）
(
- sina ante ala e ijo. sina ante e nasin lukin mi taso.
你没有改变事物。你改变的，只是我看待它的方式。
该言灵的效果需要借助有效凭证发动，而发动的效果是短暂看清现实。



jan pi nimi ala li ken ala tawa insa.
无名之人不得进入内部。

nasin sina o lawa e sina.
你的规则，也应当约束你。
)


### 脑内推演

玩家会通过脑内推演复现场景，并使用一个人偶来模仿一个人进入时的动作。

玩家尝试制定规则，发现屏幕红了起来或者是出现自我意识丧失的征兆，原来是这个词汇本身很危险，不能用。威尔逊必须立刻停止联想。使用替代词汇来设计规则，并让人运动。

### 日常互动
玩家可以对其他人发出邀约，而在这次测试中，麦斯威尔就对玩家发出邀约，请玩家和他下国际象棋（前后呼应这一块）玩家选择同意回复策略，麦斯威尔和玩家就可以下象棋了。

### 恶作剧
玩家设立了一条非常有恶趣味的规则，把恶魔气的骂玩家并废除他的规则结束。
（这个规则是啥不需要管），总之玩家在贴了一个规则，然后过一会，莫名其妙所有人都在这里转圈。恶魔过来不明所以也转了几圈，然后找到问题的来源，把玩家编写的垃圾规则撕下来直接破口大骂。

### 保护威尔逊
场景展示威尔逊伏案推理，周围出现阴影。
同伴在察觉到威尔逊不对劲的时候，立刻打断了威尔逊。
现实中威尔逊恢复对周围的注意。
