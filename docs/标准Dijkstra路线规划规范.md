# 标准 Dijkstra 路线规划技术规范

## 1. 概述

Dijkstra 算法用于在非负权值的图拓扑结构上求解单源最短路径（Single-Source Shortest Path）。
在不依赖连续欧氏几何坐标与启发式估价函数的离散拓扑环境中，Dijkstra 算法提供最优解保证。

## 2. 形式化数学定义

给定加权图 $G = (V, E, w)$：
* $V$ 为有限顶点集合，代表可通行的离散场景空间。
* $E \subseteq V \times V$ 为有向或无向边集合，代表空间之间的直接通路。
* $w: E \to \mathbb{R}_{\ge 0}$ 为边权映射函数，赋予每条通道非负通行代价。禁止存在负权边。

## 3. 算法核心数据结构

* **邻接表（Adjacency List）**：预构建常驻内存的图结构，以顶点 $u$ 为键索引其全部出边集合 $\{ (v, w(u, v)) \}$。
* **最短距离表（Distance Map, $\text{dist}$）**：记录从起点 $s$ 到各顶点的当前已知最短距离。起点初始化 $\text{dist}[s] = 0$，其余所有顶点初始化为 $+\infty$。
* **前驱节点表（Predecessor Map, $\text{prev}$）**：记录最短路径树中各顶点的父级边与来源节点，用于路径回溯重构。
* **最小优先队列（Min-Priority Queue）**：维护待松弛顶点及其当前距离标号 $(u, d)$，以距离值作为升序排序键。

## 4. 算法标准执行流程

1. **初始化**：
   * 将起点 $s$ 压入优先队列：`Queue.Enqueue(s, 0)`。
   * $\text{dist}[s] = 0$。
2. **循环出队与松弛（Relaxation）**：
   * 若队列为空，说明目标不可达，返回失败。
   * 从优先队列弹出距离最小的顶点 $u$ 与标号 $d$。
   * **延迟删除判定**：若 $d > \text{dist}[u]$，忽略当前记录（已有更优路径覆盖）。
   * **目标截断（Early-Exit）**：若 $u == t$（已到达目标场景），立即终止循环。
   * **松弛邻接出边**：遍历 $u$ 的每条可用出边 $(u, v)$ 及代价 $c = w(u, v)$：
     * 若该通路当前受门禁阻断，跳过该边。
     * 计算尝试距离：$d_{\text{new}} = \text{dist}[u] + c$。
     * 若 $d_{\text{new}} < \text{dist}[v]$：
       * 更新 $\text{dist}[v] = d_{\text{new}}$。
       * 记录前驱：$\text{prev}[v] = (u, \text{edge})$。
       * 入队：`Queue.Enqueue(v, d_{\text{new}})`。
3. **路径逆向回溯（Path Reconstruction）**：
   * 从终点 $t$ 开始，根据 $\text{prev}$ 映射依次逆向寻回前驱边，直至回到起点 $s$。
   * 将收集到的边序列进行反转，输出最终的连续通行路径。

## 5. 复杂度与性能约束

* **时间复杂度**：使用二叉优先队列时为 $O((|V| + |E|) \log |V|)$。
* **空间复杂度**：为 $O(|V|)$，消耗集中于距离表、前驱表与队列空间。
* **工程约束**：拓扑邻接表应作为常驻图结构维护，禁止在单次寻路调用中执行全场景树扫描构图。
