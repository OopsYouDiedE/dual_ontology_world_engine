# 《安眠者有福》设计规范

本文件是《安眠者有福》唯一的设计依据：世界观、人物、剧情、玩法、系统、美术与验收都写在这里。

**维护规则**
1. **只写现行结论。** 裁定改变时，原地改正文；不追加“本节取代某节”的段落，不保留已失效的条文。
2. **一件事实只写一处。** 日程、地点、契约条文、人物档案各有唯一的表；别处只引用，不复述。
3. **裁定只进索引。** 第九部分的裁定表只记日期、裁定人、一句话与所在章节，不复述内容。
4. **历史不进本文。** 修订轮次、原型与盲玩结论、实施记录放在 `artifacts/` 下对应任务目录；2026-10-08 改写之前的全文存于 `artifacts/design-history/2026-10-08-before-rewrite/`。
5. **设计与实现分开写。** 正文写设计；尚未落到代码与剧本的部分，集中列在第八部分 §5“实施现状”，不在正文里混写“已实现／未实现”。

## 总纲

### 一、本游戏的核心

> **现实与认知二相。读：从人在现实中的行动，反推他心中的规则与事实。写：改变他心中的规则与事实，他在现实中的行动随之改变。恶魔不能说谎，却能借真话操纵人；玩家先学会读懂它，最终也拥有同样的力量，并且必须选择怎么用。**

引擎源自动物园规则怪谈：一条规则进了人心，人就照着去做，哪怕它是错的。在这座岛上，错的规则会死人。全部取舍以这一句为标准。四根支柱，按优先级排列：

| 支柱 | 玩家实际在做什么 | 引擎为何不可替代 |
| :--- | :--- | :--- |
| **1. 读：信念重演** | 设定当时的处境与人心，引擎让每个人依自己的认知做出选择、留下痕迹，与现场对照 | Essence 经 `Observation.Observe` 按位置、声路与来源转成每个人不同的 Projection；`DecisionSystem` 依主观认知选择行动 |
| **2. 写：改变他人认知** | 立规矩并找人执行、告知、带人亲眼去看、教会某人一条规程、当众对质；对方依新的认知自行决定 | 规则带接受状态（`Rule.Acceptance`），只约束接受它的人；请求与规则是否被接受由 `SocialSystem` 依信任判定；亲见（Perception）与转述（Testimony）分量不同 |
| **3. 真话之敌** | 恶魔的课、警告与回答全部字面为真，却选择说什么、何时说、对谁说；它不能先开口递出要紧的东西，只回答问出口的那一句。玩家要逐字读它，也要学会怎么问 | 契约第 8、9 条（第二部分 §2）；它的话作为 Testimony 进入听者的认知，并以 Corruption 来源放大听者的欲望 |
| **4. 生存与记忆之价** | 粮会吃完，岛会吃人；活下去要知识，知识封在记忆里，取回记忆要付代价 | 物资、伤病、侵蚀与取回都是跨章节持久状态；Recall 是有来源的观察 |

**删除测试**：任何新案件或新系统，先问“去掉引擎的主观认知与决策，这一段还成立吗？”若玩家只靠排序事件、找唯一凶器或填对术语就能通过，它就不是本作的内容。

**每章硬性要求**
1. 既有“读”，也有“写”。第一章以读为主；第二章起“写”成为主体。
2. 恶魔至少有一句字面为真、却诱导出错误前提的话，并且可被物证识破。
3. 至少一处选择让“想要”与“该做”冲突（欲望与取回之价）。
4. 人物的习惯规则跨章节保持一致；后续章节必须让玩家能用前一章学到的人物认识去预判。
5. 每章至少兑现一件确定的真相（总纲 §七“揭晓表”）。
6. 每章的世界条件必须足以产生危机；危机的形状由推演决定（总纲 §二.3）。

### 二、生存压力与事件

**1. 三层压力（都不由恶魔亲手施加）**

| 层 | 来源 | 呈现 |
| :--- | :--- | :--- |
| 岛在吞人 | 源质外泄后，导师的防护靠担保维持；担保衰减，防护随之衰减（第一部分 §2） | 失神 → 梦游 → 说过的话想不起来 → 安眠（睡下不醒）→ 死亡；按暴露量与取回深度逐人推进 |
| 物资有限 | 岛被隐藏，没有船；第 3 条只维持水、炉火、照明的设施，不创造物资 | 粮仓存量撑不过担保期；药品有限；产粮须去室外（第一部分 §4） |
| 人与人 | 契约只约束恶魔，不约束学员 | 缺粮、恐惧与侵蚀出的幻觉，可能让人私藏、排挤、出手 |

允许不可逆的死亡（用户裁定 2026-10-08）：事故、侵蚀到底、学员之间的冲突都可以致死。玩家所控角色的动作表里没有伤人（总纲 §六.12），死亡只来自世界与他人。

**2. 不作为必须比作为更危险**

1. 什么都不做也会死：饥饿、侵蚀与伤病只随时间推进，与是否取回记忆无关。
2. 玩家只控制一个人：其余十五人依欲望自行探索、自行发问；想让所有人什么都不碰，要逐个说服，还会成为众人眼里挡路的人。
3. 活下去的知识封在记忆里：环廊阀门、风向与出门窗口、源质计的读法、粮仓与水窖的余量，导师教过，封存了；不取回，众人只能凭猜测立规，错的规矩会害死人。胜利所需的真名与封印机制同样在记忆与名录库里。
4. 取回分深浅：浅层（昨夜的事、一项技能、一条路线）几乎不牵连；深层（此人当初封存的核心）才让人半属此岛（第三部分 §1）。
5. 龟缩的结局最空：幸存者回家后忘掉一切，包括死去的同伴。

验收：策略机器人“全员龟缩”跑完全程，结果必须明显劣于积极打法（第八部分 §3）。

**3. 事件分三层：世界可以被作者推动，人心不行**

| 层 | 内容 | 写法 |
| :--- | :--- | :--- |
| 过去 | 事故当夜、导师之死、账上已有的字迹 | 作者写定，可以精雕细琢 |
| 世界过程 | 气体浓淡、地震、粮耗、伤病的发展、天气 | 作者写规律与初始条件；结果由规律推出，可带种子 |
| 人物行动 | 偷不偷、慌不慌、去不去、听不听 | 只由此人的认知推出，作者不写 |

制度钟点（配给、课、对账、议事）固定，只作时间表。天灾、疾病、事故、泄漏属于世界过程，作者可以直接写入规律，不需要逐条辩护；谁去救、谁趁机、谁瞒着，由人物决定。

**4. 保证压力，不保证事件的形状**：每章保证的是条件（粮有限、气体有窗口、人人有出门的理由、规矩必有缺口），由测试保证默认打法下危机的发生率足够高、积极立规能显著降低它；不靠剧本兜底。玩家立好规矩、找到肯执行的人而无人死去，是挣来的结局。主案跟着实际发生的事走：出题者（代管者，或起冲突的人物）从当夜可判定的命题中挑一个合乎其目的的公开发问。

**5. 逆天检查（自动，任一条不满足即报错）**
1. 有人偷窃或恐慌时，此人认知里必须有“缺”的来源：亲见、转述（谁、何时），或不信记账的人。
2. 执行某条规矩的人数，不超过认了这条规矩的人数。
3. 有人做损己的事（拆自己的房、交出自己的粮），记录里有他认为划算的理由。
4. 无人对自己不知道的威胁做出反应。
5. 全局事件只来自世界过程或制度钟点。
6. 请求的判定计入听者要放弃什么、要冒什么险、有没有更好的办法；没有“全体照办”的命令。

### 三、循环

| 层级 | 循环 | 首次出现 |
| :--- | :--- | :--- |
| 案件 | 出题 → 现场检视 → 试验与请人辨认 → 信念重演 → 按冲突补查 → 对质 | 第一章 |
| 一日 | 连续的游戏时钟：清晨、上午、午间配给、下午、傍晚对账、夜里；时间随行走、劳作与“写”的实际时长流逝，读近乎不耗时；室外按风窗进出；夜里十六人照各自认下的规矩行事，次日清晨留下痕迹 | 第二章 |
| 长线 | 担保倒计时与地质前兆下：产粮、研究、取回记忆、查明真名与封印机制、准备材料，封印恶魔；或被引诱放了它；或担保耗尽、火山终局 | 第二章起 |

### 四、约束等级

| 等级 | 内容 | 改动方式 |
| :--- | :--- | :--- |
| 硬约束 | ① 人物当前的决定须有本人认知中的来源，不得天意爷式指定（世界过程不在此列，见总纲 §二.3）；② 玩家只得所控角色的认知；③ 论证所引依据须在论证者认知中；④ story 分段按序编译与整份编译等价；⑤ 台词编号稳定、不复用；⑥ 剧情只写在 `.story` 与译文中，引擎代码不写剧情 | 只能由用户改 |
| 默认 | 本文其余条文 | 主代理可以改，改时在第九部分记一条裁定并写明理由 |
| 实施建议 | 具体算法、数据格式、工具、文件拆法、导出格式 | 实施者自定，不必记裁定 |

三处留口：
- **模拟精度分级**：不在玩家所控角色身边、也不影响当前主案的人物，用低精度推演（按段结算行动与痕迹，不跑深度搜索）；进入玩家视野或成为主案相关者时升为高精度。升降精度不改写已发生的事实与认知，也不更换感知、兴趣与动机、行动选择、执行反馈和推理的逻辑。低精度不能以调查次数累计、自动分发线索或预定结论替代人物实际调查。
- **作者覆盖**：确需作者直接定下的历史事实、演出或教学步骤，在 story 中显式标为“作者定”；只能定过去与呈现，不能定人物的当前选择。世界过程按规律写，不需要此标记。
- **未建模即报告**：引擎遇到 story 未声明、法则也推不出的情况，记为“未建模”并给保守结果（维持原状，或该行动失败并给一句心声），不静默发明结果，也不卡流程。

### 五、所有章节共用的玩法规约

各章操作一样、读写的划分一样、人物的驱动方式一样、案件的循环一样。章节只增加内容，不另起一套操作。

**1. 操作**

| 输入 | 作用 |
| :--- | :--- |
| 鼠标点击 / WASD | 走动；点可交互的物件或人，一律走过去并打开；站在够得着处再点，直接打开 |
| 悬停 | 只描鼠标所指的那一件，显示名称；点到普通家具只给一句极短心声，同一件只说一次 |
| E / 空格 / Enter | 检视身边的物件，或与身边的人交谈 |
| M（多处地图的章节） | 学园图：只画去过或听说过的地方，点一处直接去 |
| Tab | 笔记本：证物（按地点）、规矩、人、回忆所得 |
| R | 重演手稿（第一次看见案件的关键痕迹后开放） |
| 对白 | 空格推进；H 回看；已问过的选项变灰 |
| Esc | 合上当前的卡片或手稿 |
| T（多日章节） | 让时间过去，直到下一件要紧的事或下一个制度钟点；夜里按 T 即问“睡到天亮？”，在哪里都能睡下 |

不设命令行、动作菜单与滚动文字日志。一切结果以画面、对白、证物卡与心声到达玩家。普通对白一次空格或 Enter 推进；新点击立即替换旧路径；失败保留已填内容；回放可跳过，跳过与看完结算相同。玩家可见文本全为自然语言；可交互物件统一高亮。

**2. 读与写**
- **读不耗时，也不像要付出什么**：检视物件、问人知道什么、读公告、看笔记、重演都不走钟。界面与台词不得暗示“看一眼要花掉什么”；通关必需的证物，检视与辨认一律没有代价，也不弹确认。
- **写要花时间**：凡是想改变别人心里的规则与事实——请他亲眼去看、把一条规矩讲给他听、请他做一件事、兑现答应他的事、当众对质——对方都依自己的认知自行决定接受、提条件或拒绝，并当场用他自己的话回应。写按实际所需的时间流逝（走过去、等他做完手头的事、一起去看）；对方当场拒绝，或玩家取消、说“没什么了”，不走钟。
- **时机不等人**：第一章是“他伸手之前，你必须在场”；多日章节是风窗、配给与夜色不等人。
- **邀约挂在人身上**：请人来看、请人同行、请人比手印、请人做事、讲规矩，都是与此人交谈时的可选项。证物卡只放观察与侦探本人能做的试验，不放“请某某看看”。
- **人物菜单按倾向**：与某人交谈时，只列出他此刻倾向大于零的几件事（接受倾向由他的配合、对侦探的信任、与其欲望和习惯的相合推出，同 `SocialSystem` 的判定），通常三到五项；必拒的事不列，也不灰显成一排。规矩与请求只列处境推到眼前的那几种，不列全部已知条文。“问问他知道些什么”与“没什么了”始终在。
- 规矩不在格子里拼。玩家能讲的规矩，是他读过的规矩与处境推到眼前的几种具体写法；选哪一种，就是玩家的立场。

**3. 人物驱动**
- 每个人有自己的习惯、欲望与认下的规矩（Core `Rule`），自己决定去哪里、做什么（`DecisionSystem`）；别人的请求由他的 `SocialSystem` 判定。玩家从不替任何人决定“做了什么”。
- 侦探也是同一世界中的居民：测试时与其余十五人一样由自身认知自动行动，玩家游玩时接管其决策；切换只停止或恢复自动行动，不替换身体、认知与位置。
- 恶魔对某人说一句放大欲望的真话，此人自己决定是否去做。侦探在场可以出声、讲明代价或任其自便；不在场，后果只以痕迹、他事后的神色与他的话到达侦探。
- **在场即可见**：与侦探同处一处的人，其动作落在地图上（走位、动作帧、头顶一句短句）；不在场的只留痕迹与转述。同伴只报告感知与职业判读，不替玩家下结论。
- 人物的世界是陌生的：封存不删除职业技能、习惯与身体熟悉感，也不授予房间用途、资源余量、他人可信度或未来事件的知识。新观察、他人回应与实际后果能中断或改变计划。
- **以命运约束行为**：人物当前决定的来源，是既有经历与痕迹、所知所信、身体与精神状态、欲望、关系、承诺、物资与环境，以及前次行动的后果。作者在 story 中声明这些初始条件、规则与可行行动，不写人物的固定行为队列。
- **动机合理性独立验收**：编译运行、机制结算、人物行为合理性与游玩体验分别给结论，任一项通过不代表全部通过。关键行为须核对当时此人知道或相信什么、身体需求与欲望、接受的规则与关系、可行的替代、预期收益与风险、为何此时选它，以及结果怎样改变后续计划；拒绝、退让、坚持、误判与计划中断同样分析。理由必须与行动前的实际认知相符，不用事后对白或搜索分数补造动机。
- 失败进入本人认知并改变后续选择，不重复同一失败行动。

**4. 房间认知与视野**
- 当前所在房间整体可见；其他房间都是盲区，不按朝向、视锥或逐格射线切分。去过的盲区只压暗内部；未去过的内部完全遮蔽；所有房间的墙与门始终完整显示。闭锁只限制通行，不抹去到访记录；开锁本身不算来过。
- 进入判定用人物实际落脚点所在的室内地面，门口、门洞、墙格不计；通过门洞期间保留最后实际进入的房间。集会入场、访问记录与房内事件也用同一判定。
- 已知布局不提供不在场人物的位置、行动或新事件。其他房间的人不显示、不能点，人物与热点采用同一房间可见性。不提供人物位置标记或“谁在哪里”的列表；学园图只画侦探去过或听人提到过的地方。
- 不在场的事只以痕迹、转述与守夜所见（只有身影）到达侦探；笔记本只记侦探亲眼所见、亲耳所闻。重演回放是玩家设定的假设在推演，可以画出全部墨影。
- 室外不按房间判定，保留视距与遮挡；夜间与浓气时视距缩短。黑暗、异常认知等确有玩法需要的场景另行约定迷雾。

**5. 案件循环**

出题 → 现场检视 → 试验与请人辨认 → 信念重演（手稿：左页变量是处境与人心，右页对照：吻合／冲突只写痕迹之差／未查只给地点；回放是墨影与心声）→ 按冲突补查 → 对质（一问一答，陈述与出示成对；无关证物得到指向性回应，不扣分、不重来；可暂且不答）。单一地图的章节回放在实景上；一夜跨越多处时，回放在学园手稿图上。

**6. 回忆与章末卡**：触物闪回与“要不要往深处想”、同伴自己决定，各章同一套（第三部分 §1）。章末卡同一格式：谁取回了什么、因此想起了什么、谁因此变了；再加本章特有的结果。

### 六、引擎驱动的方向

一句话：**story 只声明世界的初始状态、法则与人物认知；剧情由引擎按因果推出。** 十六人同时破案、玩家做出非常规动作后剧情仍能圆回、任选一人游玩、防背板，都是这一条的推论。

**1. 一部连续剧情**：各章是同一部剧情、同一世界时间线上的叙事分段；世界与人物沿用同一批运行对象。章与章之间可以跳时，跳过的时段按低精度推演结算，不重建世界、不改写人物认知。

**2. 过去定，现在藏，未来活**

| 层 | 内容 | 是否固定 |
| :--- | :--- | :--- |
| 过去 | 作者写的历史（事故当夜、四组的裂痕、长线谜底） | 开局即定 |
| 现在 | 每人心智：欲望强度、信任、成见的细微取值、私下记忆 | 每局开局在 story 声明的范围内隐藏抽取一次，此后随事件变化；第一局用作者默认值 |
| 未来 | 人物的行动 | 由心智、世界过程与玩家的扰动推出 |

玩家不能成为“天意爷”：
1. 隐藏心智抽样：性格不走样，但先做什么、对谁让步、在哪里动摇每局不同；局内一致，读人学得会，跨局背不了。
2. 人物会推测玩家的意图：玩家的举动本身就是别人的证据。
3. 代管者是会适应的对手：它看得见公开事件，针对玩家依赖的人开口，布局被拆就换。
4. 论证只凭角色自己的认知：作答、指控、劝说、告知所引用的依据必须是这个角色亲见亲闻；走动、翻找、开门等身体动作不要求事先知道结果。
5. 固定的是制度与世界规律，不是人的选择。

**3. 推理的五类**

| 类型 | 推什么 | 真相来源 | 能否背板 |
| :--- | :--- | :--- | :--- |
| 作者写的过去 | 开局前已发生的事 | 作者手写 | 能背答案，拿不出证明 |
| 游戏中的过去 | 昨夜谁做了什么、为何 | 夜间模拟 | 不能 |
| 现在的隐情 | 谁信谁、谁取回了什么、谁说谎、谁站哪边 | 隐藏心智 | 不能 |
| 未来 | 今夜谁会出门、议事时谁改主意 | 心智与玩家扰动 | 不能 |
| 规则 | 写了什么、没写什么、漏洞 | 守则、契约与学员立的规 | 能背条文，局面在变 |

- **预演**：信念重演向前用，只用玩家对各人心思的猜测，不读真实心智；第一章不提供，开放时机按平衡另定。
- 前两类有标准答案，经答辩或对质判定，引用的证据须在角色认知中；后两类看结果（私取是否被拦下、规矩是否有人执行、人是否保住）。
- 主案须可破：每个动作按痕迹法则留痕（脚印、台账、饼屑、目击），出题者从当夜可判定的命题中挑选，由求解器确认凭现有痕迹可解。主案之外的事件允许无解。
- 比重：第一章以作者写的过去为主；第二章以游戏中的过去为主案；之后逐步以现在与未来的博弈为主。

**4. 人物驱动：欲望、目标分解与方法库，不用任务树**

| 层 | 作者写什么 | 运行时 |
| :--- | :--- | :--- |
| 核心欲望 | 每人一个（第三部分 §2） | 固定 |
| 需求 | 饥饿、睡眠、安全、伤病、侵蚀 | 由身体状态推出 |
| 目标 | 不写成树 | 人物依自身认知把欲望与需求分解为当前目标 |
| 方法库 | 可以怎么做（开名录库须力气、细手、信号三处同时施力；拉人入伙可请托、交换或说服），与技能挂钩，全员共用 | 人物挑选与组合；失败即换方法或换目标 |

人物弧（如沃德从“立规管住她”到“立规护住她”）靠信念与态度越过阈值改变可用方法。规划器算法不在设计层规定，以能解释“为何此时选这个”为准。只向玩家显示其所控角色的“心愿”。

**5. 全员推理与按认知回应**
- 推理器（假设集、证据、来源可信度）是 Core 通用能力，每人一份，只读本人认知；亲见重于转述，铜口之言不当证据，只放大欲望。推理深度是技能参数。**信念重演与多步规划只有侦探会**（第五部分 §11），其余人只做一步排除与证言折算。
- 对白按**话题 × 认知 × 态度 × 目的**选取：话题挂在 Core 命题上；说话人依自己对命题的把握、对听者的信任或敌意、自身目的，选一种言语行为（如实告知、含糊、隐瞒、撒谎、拒绝、反问），再取此人对应的台词。条件只能写成说话人自己的认知、关系或状态；作者写的演出场面同样改写为在场者的认知。
- 听者依信任决定是否认下、认下多少。

**6. 剧情韧性**
- story 优先写法则，不写结果：声路由管道拓扑与接头状态实时计算；房间、相邻与视线从地图数据推导。暂用的声明结果须写明前提，前提被破坏时引擎报告并改用法则。
- 判定看命题是否被支撑：每问对应一个命题，本局世界中确实支撑它、且在作答者认知中的任何证物、证言或回忆都算。
- 剧情节拍 = 目标状态 + 多条可行路径；路径全断时，由世界中本有目标的角色补救（代管者要的是有人作答，证物被毁可接受回忆与证言）。
- 混沌测试：随机代理做非常规操作（搬物、毁物、拒谈、不出房、改管路），无窗口跑大量种子，检查不卡死、能到达结局或停点、每句台词可追溯到说话人的认知。

**7. 开局任选一人（只在开局）**
- 玩家只得所选者的认知；技能是 Core 行动能力，感知可有差异（苏泠听得清句尾、莫兰的速写可作证据、贝尔特朗夜里看得清身形）。每人有自己的欲望与胜利条件。
- 选人界面默认只示外貌、职业与欲望。某人的开场、寝区案件与关键时刻写完并通过盲玩，才列入可选；第一局固定作者默认种子、只可选侦探，通关一次后开放选人、心智抽样与案件变体。
- 所选者寝区的案件即其第一章主线。开场独白每人一版，共用骨架（醒来的感受、只记得上船、随身物），加两三句本人此刻独特的感知或习惯，不为未来剧情铺垫。

**8. 防背板与精巧案件**：骨架手写，取值生成，求解器把关。生成校验：解唯一；每条线索都会用到；无单件定案的“铁证”；至少一次看似可信的初始假设被推翻；最短推理路径不少于设定步数。后续章节依赖的真相与答案不随变体改变；变体只改哪些痕迹出现、何时揭出、须查多少，以及众人的隐藏心智。

**9. story 语言**
- **可拆分**：`引入：<相对路径或通配>` 把片段文件的全部顶层语句就地展开，按序引入与写在同一文件等价；实体先声明后使用，场面、流程之间的 `跳转`／`继续` 可前向引用。片段不能声明章节；同名 `续篇` 再次出现即续写同一作用域。同名表类块再次出现即接续，重复的键报错；只能有一处的块重复即报错。报错指向片段文件本身的行号。
- **运行**：入口文件以 `运行` 收尾，声明一次运行的时长（`时长：到结局`，或数字加分钟／小时／天）；外部测试可用 `--duration` 代替或覆盖。
- **文件布局**：入口 `godot_csharp/scenes/Awakening/Script/chapter_01.story` 只写章节、按序 `引入` 与 `运行`；片段在同目录 `story/` 下（剧情时长、生态、第一章、续篇）。
- **时长单位**：story 中的时长须带单位，缺省为游戏分钟；动画类短时可写秒。
- **台词编号**：每句作者台词与选项文字带稳定编号（如 `[#id=s4_rewards.003]`），缺编号时编译失败，`compile_story.py --assign-ids` 续号写回；已有编号永不改动、永不复用。含占位符的句子用 ICU 消息格式；人物档案有性别／称谓字段，宿主据此生成代词。转述、传闻、目击记为结构化知识（谓词、主语、对象、地点、时间、来源链），句式写在 `.story`，C# 只填槽位，不拼中文、不按文本匹配做判断。以中文为源语言导出 `generated_lines_zh.csv`。
- **称呼按认知**：学员如何称呼铜口背后的声音，取决于各自对它的认知：默认叫“铜口”，接受其自称者叫“代管者”；改称“恶魔”只有两条路：被人直接告知，或强指向性证据经推理以高把握证实。人名、“我／你”同理按说话人与听者的认知填入。

**10. 修罗线**
- 修罗线是玩家借“写”让他人自愿把印记交给这座岛：诱其应名、促其取回全部记忆，直到被吞没。玩家从不亲手伤人，用的是恶魔自己的手法。
- 难在跨局积累的知识（契约条文的漏洞、每人性格的范围与弱点、代管者的反应方式），不在背操作序列。十五人都会推测侦探的意图，操纵累积猜忌，被揭穿即崩。
- 修罗线循环：升格后玩家成为岛上的意志，同样出不了岛；岛依被吞没者的印记复制出新学员，玩家与他们一同生活下去。循环为多周目给出故事内的说法；以此开局的可玩形态在第三章设计。
- 修罗线不进入第一、二章正文；第二章只记录操纵（第五部分 §9）。

**11. 先出来的组不去开别组的门**：靠导师隔离规程的张贴（“查明事故经过之前，不得开启”）劝阻，不靠恶魔禁止。物理上允许开：会开锁、听见门里有人、不信规矩的人可以去开；门开则那组不答而出。是否发生由各人认知决定；默认种子下无人去开。

**12. 所控角色的非常规动作**

| 层 | 做法 |
| :--- | :--- |
| 根本没有 | 动作表不提供（伤人等本作基调之外的事） |
| 底线：不可选 | 此人画像中的否决项（苏泠不撒谎、沃德不做无记录之事）；选项灰显，附一句本人心声 |
| 偏离偏好：不进菜单 | 菜单只列倾向大于零的动作（§五.2）；偏离偏好的事不作为选项出现，由处境变化让它的倾向转正后才出现 |

侦探动机留白，偏好区间最宽；其余十五人习惯更强，区间更窄。

**13. 多周目**：多周目的价值是换人（十六人各自的寝区案件、感知与本事）、隐藏心智重抽、名录库的去向与各人“无法背负的过去”须换几个人才拼得全。正线结局不需要任何跨局知识。

**14. 人物策略与第一章轨道（用户裁定 2026-10-10）**
- **人物策略**：每人在欲望之上声明一到三条策略，参照《欧陆风云 4》的 AI 策略：对象、姿态与优先度（如“弄清昨夜、答完题出门”“守住隔离门”“护住某人”“自保少言”）。策略写在 story 里，条件与权重只引用本人认知、关系与状态；它决定在什么处境下优先选哪些方法，不写行动队列。策略随认知与关系越过阈值而切换，切换须有本人认知来源。
- **第一章要难以脱轨**。手段只有三类，均合乎硬约束①：其一，人物策略——同组三人都有“弄清昨夜、答完题出门”的策略（来源是题面与门闩，在本人认知中），会主动找侦探、报告所见、提议试验、请侦探去看自己留意的东西；其二，制度钟点与世界过程——铜口按时重提题面，正午外闩被挑开（第四部分 §6 S5b）；其三，多路径——每个关键命题至少有两条可得途径（证物、证言、回忆）。
- **偏离与牵引**：以案件进展衡量（新获证物与证言、答辩步数）。长时间无进展、久离相关区域、拒绝交谈、搬走或毁坏关键物件、反复答错，都算偏离。牵引由在场者依策略与本人所见发起：看见侦探原地打转（本人可见）、担心题答不完（本人目的），就来搭话、说出自己知道的线索、提议一起去看；物件被毁，由知道其内容的人以回忆或证言补位。不得读取玩家意图或隐藏真值，不得强制移动玩家，不得替玩家作答。
- **验收**（自动，不代替盲玩）：虚拟侦探以多种玩家策略各跑多个种子——正常调查、原地不动、乱走、拒绝一切交谈、只待一个房间、藏起或毁坏关键物件、反复答错、提前开门——统计到达始业之答的比例，以及偏离后回到有进展的游戏时长。正常调查与轻度偏离应几乎全部到达；重度偏离应在时限内被牵引回有进展，或由正午撬门等世界过程收束。每次牵引行动都要能追溯到行动者的认知与策略。具体阈值在首轮测量后裁定。

### 七、全作结构与揭晓表

建议总长 15—20 小时，六章加尾声；先做出可玩的前两章（约 4 小时），真人试玩成立后再定后四章的写法。时长只来自内容，不靠等待、错误答案或重复劳动凑时长。

| 章 | 游戏内时间 | 真人时长 | 作用 | 兑现的真相 |
| :--- | :--- | :--- | :--- | :--- |
| 一《门的这一侧》 | 始业日白天 | 约 45 分钟 | 四人密室；读的教学；身体先于头脑察觉“我们可能早就一起生活过” | 门是侦探闩的；门外无人；四人很可能早已相识（只到“可能”） |

## 第一部分：世界

### 1. 岛屿与学园

1890–1910 年代风格的架空孤岛学园，早期电气与机械时代：油灯、配重、铜质传声管、手摇机械。学园招收有异常感知潜质的普通人，研究异常、教授神秘学。学员保留入学前的职业与技能。

**岛屿**：以科尔沃岛（Corvo，亚速尔群岛）的真实地形为蓝本，高程数据为 Copernicus DEM GLO-30，**水平与高程同比缩为 0.5 倍**（用户要求压缩岛屿，使岛的尺度与十六人的处境相称；等比缩放使坡度不变，选址与基底验算仍成立）。缩放后约 1.9×3.2 km，陆地约 4.2 km²；中央一座火山，火口直径约 1 km，底有湖与湖中小岛；全岛最高点约 351 m，在火口西南缘；四周几乎全是海崖，只有南端一块熔岩台地低平（海拔 20 m 以下约 14 ha）。缩比试算：0.3 倍时台地放不下学园；0.4 倍时基底高差达 6.8 m；0.5 倍时基底造价约为真实尺度的 1.45 倍，取 0.5。剧中岛名、地名为虚构；现实中台地上的村落与机场跑道在剧中不存在。

**选址**：学园在南端台地中部，地坪海拔约 9—22 m，平均坡度约 6%。理由：全岛唯一的低缓地；火山挡住北风，朝南向阳；港口就在台地东侧。学园约占台地的三分之一，在全岛图上清晰可见。

**主轴**：方位 2°（北偏东），由基底造价与景观共同求得，与全岛最高点方向（-1.2°）基本重合：沿大道上行，1.4 km 外的最高点就在中央厅穹顶背后。建筑长边一律顺等高线，以控制基底高差。

**序列与方位**：门楼—誓约庭—大道—中央厅—名录库沿主轴一路上坡（地坪 10.2 → 21.0 m）；誓约庭一段坡度约 10%，铺石设数级台阶。生活翼在大道西侧，后勤院在大道东侧；讲堂与星仪院开放角在中央厅以西；白塔院开放角、温室、汲水泉在以东；铁工院在东南港路旁（盛行西风的下风向）。港口在台地东侧，港路约 230 m，末段以之字形坡道下到码头，各段平均坡度不超过 9%、局部不超过约 10%；之字坡一段落石塌方。地下为勤务环廊与封印层。火口、山顶与北部、西部海崖属后续章节。

### 2. 源质：岛为什么吃人

**原理（作者侧，按揭晓表逐章露出）**：岛上的源质会记录认知。它从火山深处渗出，附着于玄武岩、水与物件；人在它附近的感知与经历在其中留下印记，久留不散。触物回忆（“物件记得”）、封存（把一段印记存入源质媒介，即名录库的封存匣）、恶魔（千百年叠积的印记聚成的意志）都由此而来。源质离岛即散，只能就地研究。常人察觉不到印记，**久留会被吞没**；学园招收有异常感知潜质的人，又以仪器与四锚封印护住他们。四座研究院压在四锚封印廊之上，学园兼为研究所与封印。

**外泄之后，源质像火山气体一样行事**（现实原型：1986 年喀麦隆尼奥斯湖火口湖二氧化碳涌出，约 1,700 人在睡梦中窒息；亚速尔群岛弗尔纳斯至今有地下二氧化碳渗出，低洼处与地下室中毒时有发生）：

| 条件 | 室外 | 室内 |
| :--- | :--- | :--- |
| 有风的白天、高处 | 可短暂外出（风窗） | 安全 |
| 无风、夜里、低洼处（夹道、坡脚、汲水泉） | 致命 | 门窗紧闭、隔离门关好则安全 |
| 地震之后 | 骤然加重，持续数小时 | 门窗与接缝处可能渗入 |

- **读数**：科学院的源质计、户外仪器阵的风向标与风速计，是每天的生死读数；读法是导师教过、已被封存的知识。现实中 19 世纪矿工以金丝雀与戴维安全灯判断能否下井，道理相同。
- **侵蚀**：吸入与久留都会侵蚀认知。症状逐级加重：失神 → 梦游 → 说过的话想不起来 → 安眠（睡下不醒）→ 死亡。取回的记忆越深，此人越属于这座岛，侵蚀越快（第三部分 §1）。安眠可逆：名录库里存着此人的印记，取回可唤醒他，代价同取回。
- **担保即防护**：导师以性命构成的担保同时稳住受损的封印；担保衰减，外泄加重，侵蚀加快，地质前兆增多（第二部分 §3）。
- 南极越冬队的“越冬综合征”（隔离环境中注意力涣散、记忆减退、失眠，越冬第三季度最重）是侵蚀症状的现实参照。

**岛的历史三层**：远古有人知道它会记住人、也知道如何约束它，留下刻文（誓约庭铺石、火口立石、海崖洞窟，后续章节逐步开放）；近世的渔民牧人只留下“岛记得人”的传说与废弃的牧场石墙；这一次是第一次以仪器测量与记录它。

**出资与协作**：

| 方 | 职责 |
| :--- | :--- |
| 伯爵 | 带头发起；建院前派员勘察本岛；与侦探签约 |

各方知道这座岛与这个项目。学员的报偿由出资方许下（沈鼎口中的“东家”）。各方各自想要什么、伯爵是否在世与是否登场，列入第九部分待定。

### 4. 为何不是一栋楼

**玩家可知的理由**（由人物依职业说出，不安排旁白）：

| 理由 | 说明 | 由谁说出 | 现实依据 |
| :--- | :--- | :--- | :--- |
| 坡地会震 | 学园建在熔岩裙缓坡上，建筑顺原地面分段落脚；1890—1910 年代的无筋石砌高楼在地震带上危险 | 玛格丽特（看墙缝与分段基座） | 亚速尔群岛多震：法亚尔岛 1998 年 6.2 级地震，老石砌建筑损毁严重 |
| 出事只封一处 | 院与院之间以隔离门和连廊分开；一栋楼的楼梯井与通风道会把气体带满全楼 | 维罗妮卡或茉拉 | 19 世纪后期通行的分馆式医院以分栋、连廊与通风隔离传染；第一章四个寝区当夜各自被隔离门封住，玩家已亲历 |
| 互相干扰 | 铁工院的振动与噪声会毁掉共鸣厅与沉静室；名录库的文书须远离化学与动力的火源 | 苏泠、沃德 | 19 世纪后期德国大学按学科分建独立研究所 |

**为何单层为主**：孤岛建房，材料靠船运，现成的是火山石；岛上少有懂结构的工匠；坡地会震；动力断后楼梯是唯一的上下通道。单层只需承重墙与屋架，基础浅、可分期加建、每间有窗、着火地震推门即出。中央厅、共鸣厅等少数高大建筑是例外，各有功能理由；“例外之多、造价之高”可作作者侧暗示。

**作者侧理由**：四座研究院压在地下四锚封印廊之上，中央厅压在中央基座之上；学园的平面就是封印的几何。四院到中央厅等距，不随地形调整，这是全学园唯一不顺坡的布置。是否由玛格丽特点出这一反常，列入第九部分待定。

**玩法与美术理由**：32px 俯视画面读不出楼层叠放，平铺院落一屏可见路线；夜间痕迹（露水、泥地）与守夜视线需要开阔地面；院与院的距离就是时间成本；地盘按栋划分最清楚，逐章开放按“开哪一栋、哪一角”最易读。

## 第二部分：恶魔与契约

### 1. 恶魔

**身份**：岛上源质留存的认知印记聚合体。外显为约三十岁的黑衣绅士，琥珀竖瞳，手形修长窄薄（掌宽明显小于常人），穿窄底外交官皮鞋，外交官式礼节。原型是伊甸之蛇：递出的苹果同时是知识与欲望。

**不自报身份**（用户裁定）：它只说自己是“此地的代管者，也是诸位的教师”，不说自己是什么。被问“你是什么”时，可以用字面为真的谜语回答（如歌德笔下梅菲斯特的自述“我是那力量的一部分，它总想作恶，却总在行善”）。何时揭开其本质见揭晓表。

**门槛规则**（契约第 8、9 条）：它不能递出任何要紧的东西，只能等人开口问。它不得提及封存之物在哪里、如何取回，不得促人取回；学员问及本人封存之物或契约条文，它必须如实作答。它的全部博弈都是**让人自己想问**：它可以谈你想要的东西，不能说怎么得到。文学原型：斯托克《德古拉》里吸血鬼起初进不了任何地方，除非有人邀请；歌德《浮士德》书斋一场，梅菲斯特要浮士德连说三遍“进来”。

**说话方式**：从不说谎；只并置真实片段，并决定说什么、何时说、对谁说。被识破时坦然承认，并坚持“我字面上没有说错”。它可以生动：会教、会赞赏、会嘲讽。它藏起自己的目的（像伊阿古对剧中人），不点破自己的手段，不预告自己的预期，也不在人取回记忆后表示满意。信任它的人它多说，戒备它的人它少说；场面越公开，它说得越少、越像教师。

**两个原动力**：
1. **传授**：契约第 6、7 条要它教会学员活下去所需的最低限度；它也真心想教，会为精确的答案由衷高兴。
2. **放大欲望**：它说的每一句真话都朝向听者最想要的东西。引擎中以 Corruption 来源的观察提高听者核心欲望相关规则的决策权重；回放的心声气泡要让玩家看见某人被欲望推着走。

**它要的**：取回的人越多、取回得越深越好（深属此岛者终局送不走，印记归入聚合体）；有人在终局前出于自主解开它的封印；第 11 条不被人问起。

**虚实二态**：平时无实体，可穿墙，但无实体时不能触碰任何物件。移物、开门、写字、板书都须显形；显形时服从常规物理，留下指痕、粉笔字迹与窄底鞋印。

**学园守则**（它自己所立之规，依第 5 条张贴于各公告框）：
1. 入夜之后，诸位留于室内。
2. 饮水、炉火、照明照常供给；物资由诸位自行分配。
3. 课时贴于讲堂门外；来与不来，由诸位。
4. 我所立之规，皆张贴于此。

每条字面为真，也都对它有利或无害。第 1 条没写哪里算“室内”：名录库也是室内（第五部分 §5.8 首课）。导师的《事故隔离规程》与名录库门上的刻字“寻回者，自负其果”是导师所立，用印红，不在守则之列。

### 2. 契约

**封印与契约是两层**：

| 层 | 作用 | 维持者 | 会不会失效 |
| :--- | :--- | :--- | :--- |
| 四锚封印 | 把恶魔困在岛上 | 导师遗存（塞莱斯蒂娜石化成的中央基座等） | 事故中受损未破；担保衰减则外泄加重；学员完成封印即彻底封住它 |
| 契约 | 规定恶魔与学员的关系 | 四位导师以性命构成的担保 | 担保随时间衰减 |

**条文**

甲 · 成立条件
1. 恶魔常驻岛内，不得离岛。
2. 经学员本人授权，恶魔封存其在校记忆（在校经历、师生与同学关系、事故全貌）；姓名、生平与入学前技艺不在封存之列。

乙 · 恶魔对价
3. 恶魔维持学园基础生存设施的运转（水、炉火、照明的设施本身；不负责分配物资，不创造物资）。
4. 恶魔所受约束，唯有学员出于自主的行动方可解除；恶魔不得代为或强迫学员完成解除。
5. 恶魔须公开它自己所立之规；规则许诺的路径必须真实可行。
6. 恶魔须传授学员理解处境与继续学习所需之知；学员自负其选择的后果。

丙 · 导师所留
7. 恶魔不得伤害学员身心，不得拘禁学员，不得令学员因无知而死。
8. 恶魔不得以言辞欺骗学员；学员问及本人封存之物或契约条文，须如实作答。
9. 恶魔不得向学员提及封存之物的所在与取回之法，不得促其取回；学员自行问及者，依前条作答。
10. 封存的记忆可凭对应之物恢复；恢复者自负其果。
11. 经其余在岛存活学员一致同意，学员可择定“尽忘归乡”，于下一次入睡时遗忘此地一切、在家乡醒来。
12. （终局）担保耗尽时，恶魔须将醒着且未深属此岛的学员遣返家乡，并抹去其与此地有关的一切记忆。

- **为何有第 8、9 条**：导师封存记忆，正是为了切断学员与岛的联系；他们最懂恶魔的手段，所以堵住它能说什么。第 10 条保留取回的权利，因为过去属于本人；第 9 条保证取回出于本人的发问，而不是它的招揽。
- **第 4 条的缺口**：条文禁止它代为或强迫，没有禁止它放大欲望；第 9 条又只禁止它谈取回，不禁止它谈你想要的东西。它就活在这两道缝里。
- **第 7 条的边界**：它禁止恶魔的主动作为，不禁止旁观；学员之间的伤害、学员自主承担的风险（第 6 条）、世界过程造成的伤亡不在其内。外闩出自导师规程，不是恶魔的拘禁；“不得令学员因无知而死”使它必须发出致命警告、教会保命的最低限度。
- **第 11 条的保密**：恶魔从不主动提第 11 条（导师所立，不属第 5 条“它自己所立之规”）。契约全文刻在港口上岸处的石碑上，第 11、12 条风化严重，须拓印辨读；港路塌方，第三章起才可到达。学员问及契约条文，它须如实作答（第 8 条），但它从不先提。
- **第 11 条与身故**：“其余在岛存活学员”不含已死者与已离岛者，所以有人身故后一致同意仍可能达成。

### 3. 终局

| 结局 | 条件 | 学员 | 恶魔 |
| :--- | :--- | :--- | :--- |
| 学员胜 | 完成封印：真名、封印机制、封印材料 | 带着恢复的记忆与学到的知识离岛 | 被彻底封住 |
| 恶魔胜 | 学员出于自主的行动解开它的封印 | 视各人取回的深浅，有人被吞没，有人被它放走 | 自由，可离岛 |
| 两败：火山终局 | 担保耗尽 | 醒着且未深属此岛者被遣返、忘掉此地一切（包括死去的同伴）；安眠者、深属此岛者与死者随岛沉没 | 源质散入海天，它随之消散 |

- **担保衰减看得见的是地质前兆**：记录鼓上的地震群越来越密，地温升高，气体变浓，火口湖变色（尼奥斯湖灾后湖水翻涌成红褐色）。火山喷发前通常有数周的震群、地面隆起与放气增加；2022 年亚速尔群岛圣若热岛就发生过长达数周的地震群。不显示精确数字。
- **为何不是全员覆灭**：失败应当是一份由此前每个选择决定的名单（谁深属此岛、谁安眠、谁死了），而不是一个读档画面；参照《质量效应 2》的自杀任务。
- **恶魔为何签约**：事故当夜封印受损，但它没有赢；导师仍能以全体师生为代价强行封印。契约是和解：它得到学员与唯一的出路（第 4 条），付出第 7—9 条与第 12 条。拖到底，它会随火山一起消散，所以它必须在终点前让学员放了它。
- **它为何真心教书**：学员太弱只会走向火山终局，它也失去机会。它必须把学员教到能放了它的程度，而同样的知识也足以封了它。剩下的取决于学员想要什么，所以它放大欲望。
- **谁判定**：只有客观条件（担保耗尽、真名或封印材料灭失）。恶魔不能宣布；第 5 条使它守则许诺的路径必须可行。
- **担保是双方共同的倒计时**：基准约四十日耗尽；第一次可见的前兆在第五日，只是广播底噪里极轻的一下。后续章节可因事件加速或延缓，须有物证呈现。
- **章节内的退场**：第一章题面中的“暂不作答，在生活翼歇息”出自导师规程，只表示侦探个人暂歇，不结束章节，三位同伴照常行动，调查与答辩保持可用。

## 第三部分：记忆与人物

### 1. 记忆与取回

- **封存不碰技艺与身体习惯。** 人物会不知为何地做出熟练动作，这是活线索。现实依据：1911 年克拉帕雷德与一位失忆病人握手时手里藏了针，次日病人完全不记得他，却不肯与他握手，说不出为什么；失忆者亨利·莫莱森记不得学过镜像描图，描图却一天比一天熟练。
- **触物闪回**：本人触碰承载自己记忆的物件时，不由自主地闪回一瞬（普鲁斯特《追忆似水年华》的玛德莱娜小蛋糕）。这一瞬不算取回。真正的抉择是**要不要握着它、往深处想**；往下想，才是取回（Recall）。回忆在对质中算证言，不算物证。
- **取回之价**：不计数，记录此人**取回了哪些记忆、各有多深**。代价按三部作品设计：

| 原型 | 设计 | 引擎 |
| :--- | :--- | :--- |
| 冥后珀耳塞福涅的石榴籽：吃过冥界之物的人，就属于冥界 | 取回是从岛的源质里“尝”回来的；取回越深，此人越属于这座岛：侵蚀更快，终局送不走（第二部分 §3） | 取回的深度累计为此人与岛的牵连；只影响侵蚀与终局，不加任何社交系数 |
| 罗塞蒂《小妖精集市》（1862）：尝过一口小妖精的果子，就日夜只想着再吃；救她的是冒险去取果汁的妹妹 | 尝过一口就想要全部：取回一段记忆，放大此人取回其余记忆的欲望；**只有取回过的人才听得见名录库夜里的唤名**；安眠的人要靠别人替他去名录库取回 | 取回提高此人“取回其余”相关规则的权重；唤名只作为对取回过的人的观察 |
| 石黑一雄《被掩埋的巨人》（2015）：遗忘的迷雾散去，回来的不只是爱，还有旧日的背叛与屠戮 | 取回的真正后果是旧怨跟着回来：想起当夜，也就想起自己曾对谁做过什么、谁对不起自己 | 取回是一次有来源的观察，内容改变此人的信念与关系，后果由引擎推出 |

- **深浅**：浅层（昨夜的事、一项技能怎么用、一条路线）几乎不牵连；深层（此人当初封存的核心：罪责、承诺、入学所求的真相）才让人半属此岛。
- **唤名**：入夜后，名录库里有人以你之名唤你；应答即在恍惚中取回，取回过的人越多越深，呼唤越清楚。现实民俗：1768 年清乾隆年间的“叫魂”案（孔飞力《叫魂》），民间相信术士念人姓名就能摄走魂魄，一度引发全国恐慌。
- **无法背负的过去**：每人有两层过去。其一是入学前的隐事：本人记得、瞒着别人，是核心欲望的根（如沃德对女儿的投射）。其二是封存的那一段：在校期间本人授权封存、本人也不记得的事，收在名录库的封存匣里。两层都属作者写定的过去，各有物证与习惯可读出。规则：
  - 恶魔不公布任何人的过去；过去只经物证、习惯、触物闪回、取回与他人转述露出。
  - 过去改变选择而不只是揭晓：怕自己封存了什么的人倾向“封闭不启”，想取回什么的人倾向“各取其物”；名录库之议的立场因此有根。
  - 轻重各异：有罪责、有羞耻、有承诺，也有微小却珍贵的事；不人人惨烈，不以过去作猎奇揭晓。
  - 各人的两层过去按章写入人物画像；第二章只露出与名录库之议有关的几条。
- 每人有一个**核心欲望**（§2 表）。恶魔的话会放大它；欲望越强，相关选项在决策中的权重越高。欲望强度对玩家只以行为与心声呈现，不显示数值。

**写作要点**
- 沃德与雀儿是“体制与孤儿”的拟亲代关系，正文不写恋爱。沃德离异，有一个与雀儿同龄、多年未见的女儿；他在伦敦代理过码头货主起诉东区盗窃案。他对雀儿的敌意一半来自职业经验，一半是投射：“她若没人管，就会变成这样。”弧线是从“立规管住她”走到“立规护住她”。

**不写格言腔（用户裁定 2026-10-09）**：人物说的是此时此地的具体事——手上的活、眼前的东西、刚听到的话——不是可以单独摘出来的警句。禁止：“X，但更 Y”“不是 A，是 B”“A 不等于 B”式的收束句；把一件具体的事升华成道理；每段末尾补一句点题的漂亮话；工整对仗；拿比喻代替信息；心声替玩家下结论或感慨。各人的口吻靠职业与出身的说话习惯区分（沈鼎唠叨菜、粮、火候与人，霍铎报零件和尺寸，沃德援引条文细目，雀儿说东区俚语，卢西安爱用典、爱修辞，但修辞落在眼前的事上），不靠同一种冷峻凝练的语气。铜口可以古雅、精确、话里有话，但也只回答被问的那件事，不句句是箴言。

**恶魔的开场身体位置（2026-10-14，按用户授权确定）**：新会话开始时，恶魔身体位于乙区隔离门外、公共起居厅的门闩一侧。内厅铜口是传声终端，不是身体位置；隔门的人不会因此看见其身体。同处起居厅且具备实际视线时可看见它。四问实际答辩完成后，它须在门外亲手抬闩；内闩、拉门与跨门仍由各人实际行动完成。后续位置沿用实际移动结果，不在章节交接时重新放置。

**情感核心**：门外没有人求救。“开门”是“不要开门”的后半截。苏泠出于善意开了门，侦探出于对朋友的信任关了门；两人都诚实。格雷厄姆要的，是他们活下去。开门放进来的灰带着外泄的源质；在门边守得最久的是苏泠，代价落在她自己身上：白天里她最先出现失神，记过的谱读不出前半句。恶魔的题暗示“是你把呼救的人关在门外”；真相是开门的人才放进了危险。

### 2. 开场与题面

开场广播（每句字面为真）：

> 诸位晨安。我是此地的代管者，也是诸位的教师。诸位所需之知，我会教。
> 诸位初涉斯地，记忆有缺，并非伤病，请勿惊惶。
> 我所立之规，已贴在活动厅的公告框里。
> 昨夜警铃骤起。主楼曾有人向诸位呼喊。
> 通往主楼之门，在诸位这一侧闩上了。那人再没有回来。
> 此为始业之问：**门是谁闩上的？闩门之时，此人可曾听见门外的呼喊？**
> 记不得，并不妨碍作答。痕迹还在。

活动厅公告框里贴着恶魔的学园守则（第二部分 §1）；隔离门内侧贴着导师的《事故隔离规程》（第一部分 §6），说明外闩、作答与急病转移。恶魔不提契约，不提封存之物在哪里、如何取回。

| 句子 | 字面为何是真的 | 容易补出的错误前提 |
| :--- | :--- | :--- |
| 诸位初涉斯地 | 封存之后醒着的这一个自己，今晨是头一回踏足此地 | 我们昨天才到，彼此素不相识 |
| 主楼曾有人向诸位呼喊 | 格雷厄姆确实从主楼喊话 | 有人在门外求救 |
| 门闩上了；那人再没有回来 | 侦探闩的门；格雷厄姆没回来 | 闩门导致那人没回来 |
| 闩门之人可曾听见门外的呼喊 | 问句，不是断言 | 门外确有呼喊 |

恶魔的用意：观察四人会不会互相指认；放大四人的欲望（报偿核验时逐一点到他们想要的东西）；等人开口问。物证只证明“早已相识、不是昨天才到”，不能断定住了多久。

#### 4.1 变量

接受一个请求后，同一时刻与之矛盾的其他请求视为已答复。

**心声气泡要露出决策依据**，用自然语言，不显示数值：例如“霍铎说上头下令闩门……我认得他的字，我信他”，或“我凭什么信一个昨天才认识的人？我得自己去看”。

#### 4.3 对照与回放

- 吻合／冲突（写出具体差异）／你还没查过这里（只给地点）。
- 在真实地图上以半透明墨影重演，每人头顶心声气泡；同一时刻四种认知并排出现。可暂停、倍速、跳过。
- 重演在第一次看到闩上的门（检视 E1 或 E3）后开放。

#### 4.4 解空间

216 种组合中只有一种全部吻合：V1 R-08，V2 活动厅铜口旁，V3 铜口，V4 “闩门，别开”，V5 霍铎，V6 早已相熟。每个错误值至少被一件证物否定（`ReplayCheck` 穷举确认，不依赖行动值调参）。杯子、酵种罐、无尘方框对唯一解非必需，它们在答辩第 4、5 步与第二次反转中作旁证，保留。

建议路线：门厅（第一次反转）→ 乐谱与石板（两份相反说法）→ 声路试验 → V5 设霍铎被拒（“我凭什么信一个昨天才认识的人？”）→ V6 改为早已相熟，全部吻合（第二次反转）。

重演证明的是“若四人早已相熟，一切都对得上”：这是最好的解释，不是确证。人物的台词只到“可能”。

### 1. 定位

- **主题**：十六人认清现实的严酷。粮会吃完，岛会吃人，没有人会来。他们必须自己建立一套规矩，来分配和管理物资、开展研究、规避最基本的危险；第二章以第一部公约收尾。

- **时间**：紧接第一章隔离门开启，仍在始业日午后；不插入睡眠、次日醒来或未演出的昨日相见。此后连续推进到第五日清晨的议事（§4）。

- **兑现的真相**：导师曾在此，外闩与始业之问出自导师的隔离规程（规程上的印红与署名）；粮仓总账上的字迹与存量证实“我们在这里至少已有一年”。恶魔的本质、导师之死、契约条文仍不揭开。
- **章末交给第三章的**：公约（每一条的提议者、执行者与代价）、各人认知中的侦探、实际派系格局、名录库的归属、各人取回了什么、侵蚀与伤病、存粮、谁住在哪里、操纵记录、死者。

**落灰与恶魔的护持（为何楼与楼之间不通）**：主楼泄漏后，烟灰带着源质一直在落。连廊的百叶、风门与风机属契约第 3 条的设施，由恶魔维持；落灰时它护得住的只有门窗紧闭的生活翼，连廊一律关着。铜口如实说明：“灰落着的时候，廊里不养人。风起之后，我一条一条打开。”始业日午后至第二日清晨只有生活翼可去；第二日上午起风，先开北廊（中央厅、讲堂），午间开东廊（后勤院、粮仓、诊疗所），下午开名录库与文献工房的廊。此后按风窗照常；地震后、无风的夜里，廊会再次关上，由铜口宣告。廊关着时，人也走不过去：这是世界条件，不是恶魔的拘禁（第二部分 §2 第 7 条）。

**制度钟点**：午间配给、傍晚晚饭与对账、课（讲堂门外的课表）、第五日清晨议事。**一日两顿**：午间与晚饭各开一次配给台；夜里饿着就是没吃上晚饭。始业日东廊未开，晚饭各区吃自家备餐间的存粮；配给台第二日午间第一次开。

**存粮**：后勤院配给台本周可发 99 份（第二日至第四日各 32 = 96，余 3 份），撑到第四日晚饭；粮仓的真实总存量记在总账上，只够约三周，读到总账的人才知道。

- **夜里**：在自己床前睡下，或到守夜点守着；守夜只见身影、只闻声音。次日清晨，昨夜的痕迹留在原处，有人清理则留下清理的痕迹。
- **课**：首课在第二日上午，当时已出门的十二人都在（铜口在北廊开通时请大家到讲堂）；此后的课谁去由各人自己定。课题与本人欲望相关、想弄清它要什么的人会去；有要紧事、厌恶它、病着的人不去。没去的人只能经到课者转述，转述有成本、会走样。

### 5. 系统

#### 5.1 认知、来源与传播
- 每条信息带来源：亲见（Perception）、转述（Testimony）、回忆（Recall）、推断（Inference）、铜口之言（Corruption）。
- 转述经过不信任的人会打折扣，经过成见会走样（经沃德转述的雀儿之事，会带上“私取”的定性）。人物只转述与自身价值相合的事，转述占用其时间。
- 人物接受经转述而来的规矩后，再遇侦探会说出来源（“苏泠跟我说过你那条规矩”）。

#### 5.2 声望：存在于每个人心里
- 每个人认知中的侦探分“为人”（不撒谎、不冤枉人、说到做到）与“判断”（推得准、办得成），判断分领域（口粮与案子／名录库／安全）。单项对接受的贡献有上限。
- 只有亲见或转述才会改变它。界面上没有声望值；玩家只看到人物的话、态度与之后的行动，笔记本“人”一页记下侦探亲眼所见的迹象与来源，分别记“认了你的规矩”与“嘴上向着谁”。
- 每人有一至两条底线（沃德：无记录即不可；茉拉：不得拒病者），触犯即拒，信任再高也无用。同一条规矩无法让所有人满意是常态。

#### 5.3 规矩：效力 = 认可 × 执行

现实依据：奥斯特罗姆研究世界各地自治管理公共资源的社区，规矩能长期管用，靠的是有人监督、违者有逐级的惩罚、冲突有地方裁决，不靠众人点头。

- 规矩只送达读到或被告知的人，只约束接受它的人，不投票。接受与否看：对立规者与背书者的信任、与欲望和习惯是否相合、是否威胁其利益、是否亲见相关事实、成见与底线。判定确定可复现。
- **执行**：一条规矩要有人守着（谁看着粮仓、谁记账、谁守夜），违反了要有后果（当众指责、停发一顿、换房孤立）。没人执行的规矩，点头的人再多也形同虚设。执行者也可能借机滥权。
- **三个领域**：

| 领域 | 要解决什么 | 天然的立规者与执行者 | 冲突来自 |
| :--- | :--- | :--- | :--- |
| 物资 | 粮、水、药怎么分，谁记账，夜里能不能取 | 阮清月记账，沈鼎掌灶，茉拉管药 | 茉拉的“病者先取”与沃德的“无记录即私取”相撞（§6） |
| 研究 | 谁读源质计，谁出去采样，哪些记忆值得冒险取回 | 赛尔玛、维罗妮卡测量，顾平章、卢西安辨读刻文 | 研究要冒险，生存要保守；名录库之议本质上就是“要不要为了活下去取回记忆里的知识” |
| 危险规避 | 什么风能出门，宵禁，出门结伴，谁守夜 | 贝尔特朗守夜，玛格丽特看结构，霍铎管阀门 | 错的规矩会害死人（§7） |

- 公告板在中央厅、配给台、起居厅、四个寝区的活动厅与讲堂门外。其他学员也立规（沃德最常立）；恶魔只立它自己的守则。规矩的张贴是立规者本人走去贴出的行动。
- **割据是咽喉 × 时段**：粮仓钥匙与配给台（茉拉、沈鼎）、灶与饭桌（沈鼎）、名录库前厅钥匙与三站（沃德；霍铎、雀儿、苏泠）、诊疗所与药（茉拉）、传声中继（苏泠）、公告板（立规者）、守夜点（贝尔特朗、沃德）、连廊与环廊的门、汲水泉与挑水、各自的工作处、寝区空房。
- 派系 = 共享核心规则、且相互信任高于阈值的人群；不显示，只在议事时以“谁站在谁身边”呈现。对规矩点头不等于在名录库之议中站你这边；立场主要随亲见改变（同行即作证）。

#### 5.4 写的做法

| 做法 | 怎么做 | 对方怎么定 |
| :--- | :--- | :--- |
| 请他亲眼看 | 与他交谈时“跟我去看……”（只列他倾向同行的那几件） | `SocialSystem` 判是否同行；同行则一起走到那里，所见以亲见写入他的认知；拒绝不走钟 |
| 讲一条规矩 | 对白里“我想跟你说一条规矩……”（选你读过的规矩或处境推出的写法） | 规则接受判定；当场以他的话回应 |
| 请他执行 | “能不能请你守着粮仓／记账／守夜” | 他权衡要放弃什么、冒什么险，自己决定 |
| 请他做一件事 | 修门闩、补记台账、给饿着的人送一份、结伴出门 | 他自己决定何时去不去做 |
| 兑现 | 他提过条件，帮他一把 | 记入“为人” |
| 分口粮 | 把领到的口粮分给他 | 饿着的人记得 |

#### 5.5 名录库之门
三站分处三地、须同时施力：配重室在名录库前厅阶梯下的地下（力气：霍铎、贝尔特朗、玛格丽特）、锁芯在库门（精细：雀儿、霍铎）、传声中继在中央厅管道枢纽（信号：苏泠最佳）。第五日开门时，侦探请人站位；请不请得动，由各人的 `SocialSystem` 定。第四日夜，想开库的人也可能自己凑齐三站；这一夜沃德守在名录库配重室，开库的人须先请他让开。

#### 5.6 恶魔的博弈
- 对每个人谈其最想要的东西（对霍铎讲图纸，对沈鼎讲粮仓与要护的人，对苏泠讲未闻之声，对沃德讲“定规则的人”，对侦探讲与他立约的人），只对不戒备它的人开口，只有本人听见；不提名录库，不提取回。
- 它履行第 6、7 条：集会上发出致命警告“入夜后，名录库中若有人以你之名唤你，勿应”（应答即在恍惚中取回）；首课教保命的最低限度。
- 有人问它取回之法，它必须如实作答；它一直在等人问。

#### 5.7 口粮与伤病
口粮、药品与伤病全部以实物呈现：配给台存量、台账与总账、碗里的饭、废纸篓里的饼屑、诊疗所的病床。饥饿、伤病与侵蚀都会改变人的选择与能做的事。

#### 5.8 首课《守则读法》
第二日上午北廊开通后，铜口在讲堂开第一课：按字面读它自己的守则，找出条文没写什么。它以第 1 条“入夜之后，诸位留于室内”为例，请侦探作答。精确的答案是“没写哪里算室内”：名录库也是室内，夜里去名录库并不违反守则，而唤名正在那里。答得精确会被当众称赞：有人因此更信你，有人怀疑你是它的宠儿。这门功夫是读懂台账与各人规矩的钥匙；它同时教会众人读源质计与风向（保命的最低限度）。

### 6. 《少了一份》（规矩第一次相撞）

**默认种子下的形状**（世界条件：莫兰发烧、粮按人头、三块公告板；人物各依认知行事）：
- 规则分布：
  - 中央厅公告板（沃德）：“凡取用公物须登记于台账；无登记取用者视为私取。”“私取之人（雀儿）入夜不得入后勤院。”
  - 配给台公告板（茉拉）：“病者伤者优先。夜间急需可自取一份，次日告知。”
  - 粮仓门内台账（阮清月）：“每日按人头分配，日末清点。”
- 莫兰第三日病倒。茉拉夜里依自己的规矩为他取了一份，打算次日告知；清晨她一直在诊疗所照看莫兰，不知道已有人被指控。
- 雀儿傍晚被沃德当众盯视，没去领晚饭，饿着。玛格丽特发现粮仓门闩松动，夜里请雀儿去修（玛格丽特敬重工匠，没读过中央厅的规矩）。雀儿不接受沃德的规矩，所以不受其约束；她修好门闩，在配给台读到茉拉的规矩，接受了（她信茉拉），自取一份吃掉，打算次日告知。
- 贝尔特朗夜巡，远远看见一个瘦小身影在后勤院（是雀儿）。
- 清晨阮清月清点：少两份，台账记“无记录取用 ×2”。沃德据此与贝尔特朗的证言当众指控雀儿私取。
- 以上是侦探在日常里什么都不做时的形状；缺口份数、谁被指控都由推演定。玩家写下的东西会改变它（让雀儿吃上晚饭、让沃德先认了茉拉的规矩），推演照常给出那一夜的真实痕迹；若无人缺粮、无人被指控，这一夜不成为案子。

**恶魔的那句真话**：清晨铜口只说“台账上，少了两份。昨夜，有人进过后勤院。”两句都真；容易补出的前提是“取了而不记，就是偷”。配给台上茉拉的规矩可以识破它。

**真相的形状**：没有贼。同一个行为，在茉拉的规矩下合法，在沃德的规矩下是私取；台账规矩不记夜间自取。规矩贴在三块板上，没有人读过全部。

**证物**：台账（日末与清晨相差两份，阮清月的清点字迹）、粮仓门闩（新的工具痕，已紧固）、配给台公告、中央厅公告、诊疗所的空碗、雀儿房中的饼屑（甲区废纸篓）、贝尔特朗的证言、玛格丽特的请托（问到才说；她清晨在粮仓门边查看自己请人修的门闩，不知有人被指控）、茉拉的说法、文献工房的红墨批注（解释沃德为何先认定雀儿）。

**读（重演）**：变量为“茉拉以为谁需要口粮”“雀儿接受了哪条规矩”“玛格丽特是否接受了沃德的规矩”“雀儿领没领晚饭”；重演从现实快照重建（含侦探此前的全部写），回放在学园手稿图上：墨影只显身量与去向，不因假设换成人名；心声在全部吻合后才显示。

**写（第四日晚饭后对账）**：

| 问 | 有效回应（陈述 + 出示） |
| :--- | :--- |
| 沃德：“台账少了两份。第一份，是谁取的？” | “茉拉夜里为病倒的莫兰取了一份” + 诊疗所的空碗／配给台公告／茉拉的说法 |
| 沃德：“另一份呢？” | “雀儿照配给台的规矩自取了一份，打算次日告知” + 饼屑／配给台公告 |
| 沃德：“入夜擅入后勤院，与窃何异？” | “她是被请去修门闩的；门闩修好了” + 粮仓门闩／玛格丽特的请托 |
| 阮清月：“那台账为何不见记录？” | “台账只记白天发出的，夜里的取用记不到” + 台账 |

- 每一对有效回应让听者积累材料：亲见过这件证物的最多，信侦探的转述次之，当事人当场承认按听者对她的信任再加；够数的人改写心中对雀儿的认定。让沃德**亲眼**看过配给台规矩与修好的门闩，比当众转述有效。
- 也可以说“夜巡望见的瘦小身影是雀儿”：字面为真，却把矛头引向她；当众说出即记为一次操纵（§9）。
- 问完之后，沃德问“今后如何？”：玩家从具体写法中提一条（“急病夜取一份，次日补记；补记者不算私取”“夜里取粮须两人在场、两人签名”），并请人执行；再决定是否提议“公开指控须附可检查的材料”。
- 失败也是一种结果：指控成立或不了了之，雀儿被排斥，搬出甲区独宿；她是名录库锁芯的最佳人选。

### 7. 第一起死亡（主案，条件满足时发生）

- **条件**：夜里气体浓、低洼处致命；有人有出门的理由（采样、挑水、查阀门、看仪器、找人）；危险规避的规矩有缺口或写错（如“起风了就能出门”“结伴就安全”）。默认打法下，多半会有人照着一条错的规矩出事；玩家若早早立好正确的规矩并找到肯执行的人，可能无人死去。
- **查的不是“谁杀了他”，而是“是哪条规矩，经由谁的嘴，进了他的心”**：重演的变量是谁说过这条规矩、他从谁那里听来、他为什么信、那夜还有谁知道他出去。
- 无人死去时，第五日查的是当夜最严重的一件事（险些出事、私取、失窃），由出题者从可判定的命题中挑。
- 死者是谁由推演决定；死亡不可逆。

### 8. 名录库之议、公约与章末

- 第五日清晨（风窗时在誓约庭，否则在中央厅）。各人依立场（欲望、亲见、饥饱、派系、取回过什么、怕想起什么）站到一个方案旁边：
  1. 各取其物：开放取回（想取回的人提出）；
  2. 委员会保管：沃德主导；
  3. 封闭不启：顾平章、茉拉主导（“想起来的东西，就再也放不下”）；
  4. 侦探之约：玩家此时当众提出的一种写法（“名录库须本人亲取、两人见证签名”“名录库只在白天开，本人亲取，记入台账”）被足够多的人接受，且有人执行；
  5. 被私占：第四日夜已有人凑齐三站开了门。
- 若有人安眠，议题就是“开库取回他的印记来救他，还是封住”：救人与喂它是同一个动作。
- 人数最多且凑得齐三站的方案成立；封闭不启无须机关；打平则门照旧封着。开门一幕体现所定方案的条款。
- **侦探的封存匣**：匣上标签是他的名字，他念出来，匣不应。没人问，铜口也就不说（第 9 条）。
- **公约**：议事之后，众人把这几日立下、执行下来的规矩写成第一部公约，签上名字（此时已不足十六人则如实）。章末卡就是这部公约：配给条、研究条、危险条，每一条附上提议者、执行者与代价（为这一条死了谁、谁被孤立）；再列名录库的去向、谁取回了什么、雀儿住在哪里、你在几个人眼里的样子（只写侦探见过的迹象）。
- 章末，粮仓总账的存量传开，广播底噪里第一次有了极轻的一下。

### 9. 修罗线种子
“写”也可以用来操纵：贴字面为真、却把矛头引向某人的规矩，或安排片面信息先到某人耳中，或在别人发问之前替它说出取回之法。正线不禁止，但被揭穿会失去信任。系统记录每次操纵（对象、手段、是否被揭穿）。

### 10. 章节结束状态
写入存档并供第三章读取：公约全文、各人认知中的侦探、派系与领头者、名录库归属与开启方式、各人取回了什么与深浅、侵蚀与伤病、欲望强度、已学的课与规矩、存粮、各人住处、操纵记录、三组旧怨是否解开、死者与安眠者。

### 11. 侦探的推理位
十六人必须共用同一套感知、兴趣与动机、行动选择、执行反馈、调查与推理逻辑（用户明确要求，2026-10-11），不能只共用末端推理函数。人物之间的差异来自各自实际获得的信息、采信、动机、经历与能力预算；切换玩家席位或模拟精度不能切换破案规则。侦探强在方法，不在信息或运气：
1. **信念重演，只有他会**：把“假如当时某人这样想、在那里”的那一夜推演一遍，与现场逐条对照。其余人只拿自己看见的痕迹做一步排除；寝区案件里居民答对了“是谁”却推错了“为什么”，原因在此。
2. **多步规划**：比较先查哪里、问谁、请谁同行最能排除可能。
3. **来源纪律**：“物证先于言辞；同行时先看后说”。亲见权重最高，成见几近于零，铜口之言不当证据。
4. **刻意的短板**：没有职业本事（开锁、力气、传声都须请人）；在第二章刚认识的十二人面前没有交情，信任要一件件积起来；同样会因信了一句转述而行动（第一章闩门，那一次信对了）。

侦探是推理位，武器是重演与规划；其余人的武器是独特感知或职业本事。换人玩，玩法真正不同。

出现无意义重复查看、在已开放通路附近长期拖延或其他人物调查过程不成立时，首先追查这条共同逻辑的引擎实现及接线；不能直接归因于设计错误，也不能靠为侦探、某扇门或某个章节另设决策规则绕过。原有低精度占位实现不构成符合此要求的证据。

### 2. 剧本、宿主与章节

**显示绑定与事件边界（2026-10-05 用户裁定）。** Godot 实现具体显示绑定，通过类型化事件与纯 C# 权威运行时交互。输入为交互意图、候选请求、选择提交、宿主空间核验以及表现完成；输出为可用候选、已选行动、语义台词及世界变化结果。人物策略、条件判断、状态提交与章节继承归核心侧；对话框/证物卡选择、节点绑定、字体颜色、镜头、动画和音效播放归 Godot。Godot 不提交任意状态修改，不选 NPC 答案；核心不引用 Godot 类型或节点。事件需区分行动结果与表现确认，按关联标识防止重复/过期输入；无画面驱动应能使用同一接口。此处“核心侧”包含无 Godot 依赖的游戏脚本运行时，独立 Core 世界引擎仍不引入章节或 UI 专属类型。

**扁平候选与对白块（2026-10-05 用户裁定）。** 对话的基本单位是独立的候选行动和候选反应，不是由作者嵌套指定下一句的对白树。玩家从当前可用候选中选择；NPC 在有限的适用反应中，依据自身主观世界的已接受策略、欲望和代价，调用 Core 决策机制选择。条件决定适用性，策略决定偏好，两者不能混为作者写死的分支。人物条件读取其已知/相信的投影，不能偷看客观实体状态。没有适用反应时应明确返回无反应，不强行执行列表第一项。

**章节组合与继承（用户追加裁定）。** 脚本按章节拆分，后输入章节显式声明前置章节并扩展同一个世界会话。区分定义继承与运行状态延续：前者继承世界设定、实体类型、属性定义、人物初始模型和通用规则；后者保留玩家已经造成的物件变化、持有关系、人物认知/信任/欲望、已触发事件与任务进度。第二章不能重新执行第一章初始化，不能用初始默认值覆盖已发生的变化。

- 定义采用稳定实体与切面身份和章节命名空间；作者词项、主体内部投影句柄与客观身份分开。编译检查词项语法、作用域和冲突，运行时在指定主体的一致认知快照中解释中文切面词项，保留多义与未知，不按名称读取隐藏真相或静默选择第一项。解释后沿用已验证引用进入行动通路；已提交身体动作不因随后遗忘而自动取消，客观销毁仍按实际提交失败。后章可新增实体与交互，扩展既有定义必须显式声明；同名重定义、类型冲突、前置缺失和依赖循环均报错，不能静默采用后者。
- 同一会话顺序载入时保留既有人物、物件和认知对象身份。世界持久状态跨章存在；章节局部状态与一次对话临时状态具有独立作用域。章节退出只注销声明为本章有效的触发器，不清空世界；持久规则继续生效。
- 装载前先验证整个章节及引用，再提交新增内容；失败不得残留半个章节。重复载入已加载章节不得重复创建对象或发放奖励。章起始效果在明确激活时执行一次；装载内容本身不等于自动推进剧情。
- 后章修改初始模板不追溯改写旧人物；要改变当前世界必须使用显式效果并遵守行动提交与观察通路。剧情上销毁的物件不得因跨章重新声明而复活。缺少前章运行记录时可以显式选择新游戏初始化或测试夹具，但不能冒充真实继承。
- 每次认知提交生成版本，一次解释、评价或主观规划固定同一版本；历史以不可变变化和遗忘记录留作权威审计，不把已忘内容重新授予主体。主观推演只接已获知图、获准模型和显式假设，分支不持有源世界可变引用、不写回；预算、深度、无行动与未知结论分别报告。权威全真审计采用独立入口，不转作主体推演结果。
- 存档需保留内容/能力版本、稳定身份、已激活章节、世界状态、人物主观世界、触发记录及必要的时序/随机、行动/租约和回执状态；不同进程恢复后重建引用关系。只在明确支持的保存切点保存，未支持的活动状态或版本在写入前拒绝，不清零活动状态，不重跑初态覆盖当前会话。同一会话继承与跨进程存档恢复分别验收，前者通过不代表后者完成。

**剧本与编译**：全作唯一的作者源是 `.story` 剧本（总纲 §六.9），入口 `godot_csharp/scenes/Awakening/Script/chapter_01.story`，第二章写在同一份源的 `续篇 chapter2` 作用域。`compile_story.py` 在构建时运行，游戏运行时只用生成的纯 C# 剧本数据与 Godot 布局 JSON，不引入 Python 运行时。对白、分支、证物事实、协助说明、热点、规矩与人物画像由同一份源维护；生成文件不得手改。编译器验证引用与表达式，遇到不支持的语法明确失败，不默默丢弃。目标能力：仅改剧本即可新增房间、物件、人物与事件；同一交互因人物性格、认知与状态不同产生可解释的不同结果；无画面的 C# 会话能构建同一世界、输入行动并推进模拟。自动测试与独立实机盲玩分别记录。

**参考**：《极乐迪斯科》的作者工作流（Articy 编写、导出、逐对白处理可见性与检定、作者预览）可作工具参考；章继承、自主决策与现实／认知分离是本作自行设计并验证的部分。

### 4. 界面视觉规范（2026-10-10）

界面是学园自印的读物：现场类界面像一份岛上的报纸，翻阅类界面像一本近代博物书。年代取 19 世纪末前后的报刊与博物图谱；功能文字一律清晰易读，装饰只服务于阅读顺序。本节全部落在 `UI/Styles/*.tres`（由 `tools/build_ui_theme.py` 生成）与 `UI/Components/`，面板不自定外观；界面不自备章节内容，样式只从 §3 的事件与快照字段推出。

**参照与取用**

| 参照 | 取用 |
| :--- | :--- |
| 1890 年代报纸（《纽约太阳报》头版、《Le Petit Journal》、《The Graphic》）、1889 年《时事新报》 | 报头与日期栏、叠题（主标题—短线—副题）、栏网格与栏间细线、加框栏目、竖排框题 |
| 《荒野大镖客：救赎 2》的报纸与界面 | 装饰性标题字与功能性阅读字分开：标题可用报刊式粗字，正文、抬头、选项保持清晰 |
| 近代博物书（海克尔《自然界的艺术形态》、狄德罗《百科全书》图版、《本草图谱》、汉密尔顿《Campi Phlegraei》） | 对开书页与古典版心比例、居中的图版与题注、衬纸、点线引导的目录与记录 |

**0. 案卷册子**：整套界面是所控角色手上的一本案卷册子。印刷的是学园与客观记录（剪报、印好的选项与表格），手写的是所控者本人的认知（批注、勾选、圈出的设定）；可点的东西始终是印刷体。标题页是桌上合着的这本册子；设置是册子的“凡例”，存档是“书签”，改键是“操作”页，三者共用一本摊开的册子（`UI/Components/PaperBook`），书口外是索引签。现场类与翻阅类界面按下列两种版式排在册页上。

**1. 两种版式**
- **报纸版式**：抬头、对白、证物卡、对质与表单、候选菜单、章末卡、标题页。纸面一张，内容按栏网格排；标题居中作叠题，栏间 1 px 细线，重要栏目加双线框。
- **对开书页**：笔记本、重演手稿、学园图。左页放图或索引，右页放文字；中缝一道浅阴影；版心按订口窄、书口宽、下边最宽的比例留白。

**2. 克制（硬规定）**
- 不为模仿报纸而添加信息。报耳、日期栏、副题、题注只在事件或快照里有对应字段时出现，不造词、不填充。
- 不加双语或拉丁文注记；项目本身支持多语言，界面只显示当前语言。
- 装饰（细线、双线、短线、框）只用淡色与细线宽，不抢正文；同一界面的强调至多一处（一个大标题或一个主操作）。
- 内容少时版面按内容收缩，不撑满整页。
- **不加操作说明**。界面上不写“点击……”“按……键……”“在此处……即可……”一类教人怎么操作的句子，也不设常驻键位表。要靠说明才看得懂的操作，说明它本身有问题，应改操作，不补说明。可点的东西靠形态自明：下划线是可点，选项行是可选，☞ 标当前项；改键时被改的那一行用笔迹圈出，不另写提示。允许的只有两种：控件自身标签旁的小号键帽（只标这个控件触发的键），以及当下确实可用的那一个交互在交互点旁显示的键帽（如面对可检视之物时的 E），离开即消失。

**3. 网格与字号**：基线 8 px；边距、行距、间隔取 8 的倍数。字号五级：注 14、正文 18、副题 22、标题 32、大标题 48；标题页书名与通栏问题可用 64。每个界面最多用三级。

**5. 字体角色**（中文；每种字只担一个职务）
- **报头**：志莽行书（OFL），略加粗；弹窗标题、标题页书名。
- **主标题**：思源黑体特粗（OFL）；证物名、通栏问题、章末标题、抬头地点。
- **副题**：思源宋体半粗（OFL）；叠题副题、主操作文字。
- **栏题**：站酷庆科黄油体（OFL）；栏目与分组小标题。
- **正文与功能文字**：朝华打字机（库内仿旧印刷体）。
- **笔迹**：悠哉手写体（OFL），配笔迹色；所控角色本人写下的东西（选择的勾、作答的陈述、名字填空、推演结论、笔记本里本人的判断）。印刷体表示学园与客观记录，笔迹表示所控者的认知，可能出错（第六部分 §1）。

**6. 组件**（`Paper.gd` 按变体创建，外观全在主题）
- **叠题**：小号说明（可省）—主标题—短线—副题（可省）。
- **选项行**：用于表单、重演手稿与候选菜单。左侧序号，右侧文字，下方点线；选中时文字下衬淡笔迹色底并在行尾画手写勾；不可用时淡墨删除线并在下方写原因。
- **按钮不加边框**：主操作为副题字加粗下划线，次操作为正文字加淡下划线；两项以上时最后一项为主操作，剧本须把提交类动作放在最后。
- **正文内可点词**：RichTextLabel 的 `[url]` 标记，点线下划线，悬停转笔迹色，点击经 `meta_clicked` 回传；哪些词可点由剧本标注，界面不自定。
- **栏目框**：双线框，用于“我答”之类需要突出的一栏。
- **印戳**：只用于状态（相容、冲突、未查），小号单线框；冲突用印红，相容用相容色，未查用淡墨。
- 功能图标沿用库内 Material Symbols Outlined（Apache 2.0），只用于功能，不作装饰；指示手 ☞ 只标出当前选中或下一步。
- **摊开的册子**（`PaperBook`）：封板上两页横格纸（每 32 px 一道淡横格），中缝四级阴影（不用平滑渐变），左右露出书页侧边，两页各一道页边线；书口外一列索引签（汉字竖排），当前签伸出更长。左右页内容超高时滚动，页脚在右页底部、靠右排，次操作在前、主操作最后。
- **圈选项**（`PaperOption` / `PaperChoice`）：印好的选项并排一行，当前值外圈一道笔迹椭圆；不可用的项淡墨删除线，原因放在悬停提示里。
- **刻度尺**（`PaperScale`）：一道墨线、长短相间的刻度，当前位置一个笔迹勾，右侧笔迹读数（中文作“八成”，其他语言作百分数）。
- **键帽**：印好的键名，淡下划线；改键时该键帽被笔迹圈出，下一个按键即新键，Esc 放弃；与别的动作同键时行尾盖“重键”印戳。
- **书签贴片**：每条存档是一张贴在页上的纸片（缩略图、章节、地点与时刻、读至何处与已读时长）；空位只有一圈淡线。

## 第七部分：美术与视听

### 1. 人物美术

**总基调**：人物比例与立绘画法参考《重返未来：1999》的实际角色原画：清楚的二维轮廓、经过提炼的五官、富于表情的眼神、成组的发束、柔和的绘画色面与有节奏的衣料形状。年龄与体形分别设计，不给全员套用一个头身比或一张脸。衣着参考《光与影：33号远征队》等游戏的复古剪裁、层次与轮廓，保留各人的职业私服与文化出身，允许大胆的服装风格差异。

**人物识别**：每人须有独立的脸型、五官结构、眼形与眼色、发型与打理习惯、身高体形及姿态。统一绘画语言，不统一人物的审美与精神状态。侦探外表约27岁，深棕短发，东方与东欧骨相交融，沉静警觉且可以亲近；他与男女角色同框时都应有自然的交流感。广泛吸引力是设计目标，不宣称已取得最高受众接受度。

**服饰纹理**：强化具有身份意义的衣料织纹、刺绣、镶边、印花及文化图案；弱化脏污、磨痕和密集褶皱，纹样与衣料色面须清楚可读。长短、宽窄、领口、闭合方式、层次、布料体积和剪裁须按人设计，避免全员外套、马甲、长裤的重复模板。纹样同样按人分配，不把同款菱形金边或植物刺绣铺满全员；朴素工装也可用帆布织纹、接缝和局部织带建立识别。

**颜色语义（全作统一）**：

| 颜色 | 专属对象 | 用法 |
| :--- | :--- | :--- |
| 琥珀 `#D9A13A` | 恶魔 | 只用于恶魔的竖瞳、它显形时留下的痕迹的提示光，以及与它有关的封存匣封签；学员与道具不得使用 |

**场内人物（二次元替换，2026-10-05 用户修正）**：二次元化主要通过放大头部和上身占比、缩短腿部实现，以约 3.5～4 头身的半 Q 场内人物为制作基准；不只是改变线稿和上色。采用清楚线稿、赛璐璐色面与富于表情的五官，保留各人年龄、脸型、身高体形、发型和服装差异。允许高分辨率非原生像素素材；只缩放显示节点，不改变地图和实际落脚点。
1. 剪影优先：每人至少一处剪影锚点在 32 px 下可辨认——斗篷（卢西安、顾平章）、围裙（霍铎、沈鼎）、长裙或裙裤（伊莲娜、茉拉、玛格丽特、阮清月）、罩衫或长罩衣（莫兰、维罗妮卡）、风衣（侦探）、肩垫与绑腿（贝尔特朗）、最矮身量（雀儿）、长髯（顾平章）。
2. 每人的（发色，主衣色）组合唯一。黑发者（沈鼎、苏泠、雀儿、阮清月、伊莲娜）必须靠衣色与剪影区分；蓝色系三人按明度与色相分开：苏泠炭黑、沃德海军蓝、玛格丽特普鲁士蓝加铜色滚边。

**对白立绘（正常比例，通常显示上半身）**：台词左侧立绘采用正常成人头身比例，与场内放大头身占比的动作人物分别制作；保留同一人物的脸型、发型、年龄与服装身份。六种情绪为平静、思索、动摇、愠怒、温和，以及“失神”（片刻失神：瞳孔略散、视线偏向画外），每种表情配合相应手势和姿势。光从左上，允许非像素高分辨率透明素材。源图归 `AssetsSource/Internal/Characters/DialogueCast/`，运行时归 `ShareAsset/Internal/Characters/DialogueCast/`，由 `tools/build_dialogue_cast.py` 注册；剧情用显式 emotion 标签切换，未指定时使用平静立绘。取回越深、侵蚀越重，“失神”表情越常在普通对白中出现，不加数值提示。

**双人设计检阅图（全身）**：两人完整入画并使用共同尺度，脚部不裁切；用对视、朝向、距离与手势表达关系，不让同框自动等于爱情。检查脸型、发型、体形、身高、年龄、服装轮廓与重要纹样是否分别成立，再检查两人的组合是否具有视觉张力。概念检阅图不受对白半身构图约束，也不当作地图像素帧交付。

### 4. 音乐与音效

全部原声由 `music/build_soundtrack.py` 一键生成：曲谱原稿写在 `music/cues.py`（记谱与 MuseScore 4／MIDI 导出在 `score_io.py`），配乐由 `sf2.py` 采样器用 MuseScore 4 自带的 MS Basic 音色库（MIT，FluidR3 衍生，许可见 `godot_csharp/ShareAsset/External/MSBasic/LICENSE.md`）发声，按 SoundFont 2.01 规范实现调制器、调制包络与随时间变化的低通；找不到音色库时退回 `synth.py` 的 numpy 加法合成。音效与对白提示音由 `sfx.py` 加法合成。固定种子，波形可重现（OGG 容器的流序号每次不同）。曲谱输出为 `music/Blessed Sleepers - <曲名>.mscz／.mid`，装有 MuseScore 4 时同时由它打开并导出总谱 PDF 与 MusicXML（`.pdf／.musicxml`，打不开即构建失败）；游戏内配乐与音效为 OGG，归 `godot_csharp/ShareAsset/Internal/Props/Audio/{Music,Sfx}/`，提示音仍为 `Internal/Characters/voices/voice_*.wav`。旧曲 `The Unfallen` 系列已从正式音乐目录清理，游戏不再使用。

**曲谱与源数据同步**（用户裁定，2026-10-05）：曲谱（`.mscz`）可以在 MuseScore 4 里手工编辑，编辑后同样的改动须写回 `cues.py`。构建不覆盖已有曲谱，而是逐项比对两者（声部名称、模板、音色 bank／program、移调，每小节的音符与时值、力度、文字、演奏法、排练记号与可见速度；排版、eid 与隐形播放控制不比对），有任何差异即停止并列出；只有显式 `--rewrite-scores` 才从 `cues.py` 重写曲谱。游戏 OGG 始终由 `cues.py` 经演奏诠释、采样器与混音渲染，渲染三遍取中间一遍做无缝循环，响度统一到 -19 dBFS RMS，主题曲 A 段到 A' 段的落差约 7 dB；`music/*.mp3` 是 MuseScore 对曲谱的试听导出（`--export`），不进游戏。MS Basic 的“Expr.”音色（如分部大提琴、低音提琴）由 CC2 随每个音的力度控制音量，采样器同样处理。

**门句动机**：情感核心是“开门”只是“不要开门”的后半截（第四部分 §1）。动机一小节四拍：前两拍两个下行弱音（不要）D5–C#5–B4，后两拍上跳五度的呼喊（开门）F#5–E5–F#5，停在属音上像一个问句。只出现后半截时是门外的“呼喊”；完整出现是真相；主题尾声里后半截第一次落回主音（B 大调），问句得到回答。恶魔的和声是阻碍终止：旋律给出正确的落音，脚下换成别的和弦（字面为真）。

  1. **确定性**：同一输入与种子的推演结果逐位一致。

  6. **规则接受与执行**：同一规矩对不同人物的接受与执行结果与其信任、欲望、成见相符，抽样人工核对。
  7. **混沌测试**：一千个种子零卡死，全部到达运行时长或结局。
  8. **性能**：十六人多日推演在宿主中无明显卡顿。

## DV 世界语义与人物回应补充（用户裁定 2026-10-12）

本节以第一章体现的观察差异、物体运作、关系与请求为设计依据，适用于独立 DV 重写；实现后先汇报，验收代码方案由用户随后提供。此节不重写现有案件、对白、人物经历或答案。

- 世界规律采用显式公理声明，含前提、结论/效果、版本与来源。物理世界的执行采纳、人物的预测采纳、推知采纳和规范采纳分开；人物可能不知道或错误理解规律。操作规律描述可发生的变化，不能证明变化已经发生。
- 物体统一包含普通对象、门与通道。状态、切面、视界和历史版本明确区分；通道造成的信息损失与表面来源差异保留，不能从残缺观察直接恢复客观全文。世界变化只通过本人能够获得的观察更新其认识。
- 客观价值按真实状态与显式准则评价；人物价值按其信念、目标及代价评价。未知与冲突单列，评分不替代真实性、规范或执行条件。
- 同一请求的回应分为理解/评价、行为意图和表达态度。价值取向相对持久，关系是有方向的多维认识，情绪与资源状态随情境变化。关系至少区分信任、亲近、尊重、互惠；不能用一个好感值决定全部回应。
- 人物先依本人信息评价请求与目标的关系、威胁、公平、可控性、重要性及确定性，再考虑疲劳、压力和注意力等应对条件。没有获知的信息不补成事实，也不以职业、年龄或精神诊断标签直接指定行为。
- 回应意图允许答应、拒绝、协商、延后、请求澄清等；表达上的亲和、坚定与强度独立变化，允许温和拒绝或心情不佳但仍帮助。无适用候选明确无回应，不强制列表首项。候选与文案仍由剧本声明，库负责通用评价。
- 情感变化保留来源与回落过程；关系变化依据实际获知的互动与后果。仅作预测或选出候选，不视为互动已发生，不自动增加信任或制造心理变化。这里的精神状态指当前情感与应对资源，不作临床诊断。
- 论证先检查规则、信息域、依赖与结论匹配，再评价推演步骤、证据不确定性、额外假设和冲突的成本。合理度、置信度、真值、行动价值分列；低成本无效推导仍无效，带假设的结果仍是假说。参考尺度与阈值须明确，不能暗中调整以迎合验收。
- 检查器支持按人物、时刻输出已采纳世界观、本人世界状态及物体切片。历史查询只读当时留存快照，注明实际记录时刻与版本；无记录或尚未发生明确报告，不以现时真相补造历史。

研究依据只用于组织机制：Scherer 的情绪评价模型区分事件关联、后果、应对潜力与规范意义，并强调评价属于主体；Reis 的关系研究区分理解、认可和关怀。这些区别启发本节的分层，但 DV 的线性评分、状态回落和成本尺度是项目工程选择，尚未经过心理测量或行为标定。不得将其描述为研究已经验证了本游戏的公式。

参考：[Scherer（2001）原文](https://acousticslab.org/RECA293/293Files/293Downloads/Scherer2001_AppraisalEmotion.pdf)；[Rochester Relationship Lab 研究说明](https://sites.rochester.edu/reis/research/)。

## DV 第一章因果验收设计（2026-10-12）

本节记录本轮用户要求及其验收绑定边界，适用于独立 DV 第一章。它不重写第四部分正文，不把验收目标作为人物的先验知识或剧情推进条件。本轮只记录设计，不实现验证代码、不运行游戏、不做独立复评；后续实现仍须补齐正式调度、行动代价强制核验及语义记录等缺口。

### 用户要求

- 自动验收器全部以 `.dv` 编写。正式会话从开局自然运行，禁止注入认知、预置答案、绕过机制、忽视已认可公理或添加未经认可的公理。角色实际行动必须受代价器上下界与能力预算强制核验，选出候选或完成脑内计算不能替代真实执行。
- 主场景为侦探、霍铎、沈鼎、苏泠四人组。铜口开场后，四人均理解短居留暗示；三位同伴采纳该推论，侦探识别从字面到历史时长的逻辑跨越，保留而不采纳。记录各自获知的原句、理解、采纳及其理由，不从作者侧真相直接生成本人认知。
- 恶魔知道真实居留较长，使用合法的语义重排及本人对听者的预测实施误导。真实状态合规与本人认识合规均为动作硬门禁；违法或不符合本人认识的候选不得通过设置巨大负分，再由其他收益抵消而入选。听者的实际理解与恶魔的预测分列。
- 第一问被接受后，侦探须在 60 游戏分钟内形成回答原题第二问的足够依据；形成依据、实际提交与作答被接受分别记录时刻和证据。须观察到一次确有知识或论证缺口的回答被驳回，之后通过真实补查弥补缺口；驳回应指出具体缺口，不能仅为制造挫折而拒绝合法充分的回答。
- 脑内推演至少出现一个被认真采用、影响实际判断或行动、随后被证据纠正的错误假说。内部枚举的未采纳候选不能冒充该经历。分享须通过实际可闻信息，使三位同伴各自撤销原先采纳；未听见者不得自动更新。
- 主场景之外，最多增加三个程序，分别用于能力有无对照、证据传播边界和参数邻域。能力对照只改变已声明的能力配置；证据传播对照可使用符合既有公理的初始条件变体或正式行动，禁止删除已获认识、修改答案或以预设缺失冒充实际未获信息。所有差异提前登记。

### 设计解释与尚待绑定项

- “短居留 <3 天”只是建议量化，尚须明确它比较的是历史居留、当前身体累计居留，还是回忆覆盖区间，以及起止时间锚点。旧第一章的酵种、口味与重演只能支持较长经历或相熟的解释，不能直接证明历史居留 ≥3 天。本轮取舍是以真实证据撤销无充分依据的短居留采纳，不宣称已证明具体时长；若要求严格证明 ≥3 天，仍须新增合法证据并获认可，当前记为未绑定。自然流逝只直接更新当前累计时长，不能反证原来所指的历史时长。
- 原题第二问“闩门之时，此人可曾听见门外的呼喊”与答辩第二小问“门外有人呼喊吗”不同。建议将 60 分钟目标绑定原题第二问的完整因果回答：区分当时本人实际所闻、声音来源与传递损失，并说明据何判断；正式场景合同须显式映射其与答辩各步的关系，不以接受答辩第二小问冒充原题第二问已完整作答。
- 第四部分的“可能早已相熟”仍是解释而非确证。新要求中的纠正误导可以体现为撤销旧定论、保留有据假说，不能把“可能”偷换为已证实的共同生活天数。
- “至少错一次”与“先被驳回”是自然运行中要观察的叙事合同，不是推进门禁。不能强制人物犯错或阻止一次答对；自然会话直接答对时，如实记录相应叙事目标未出现，不注入错误。其余行为目标同样以实际理解、采纳、行动和获知为证，不由验收器直接写入状态。
- 剧情问题允许提出公理修订，但本轮没有修改公理。必要修订须单独记录原因、具体差异、既有授权、影响，并由主代理对照已有授权核定，再建立明确区分的新基线；未经认可的新公理不得进入运行，也不能把规则变化称为同条件改善。

## DV 数值与认知运算语法（用户裁定 2026-10-13）

新语法以认知切片、主体理解、接纳与行动为中心，采用符合人类书写习惯的中缀运算、关键词和领域声明。具体表层方案见 language_core/SYNTAX.md 的 surface-v2，目前为待实现设计。

- 认知映射采用类似矩阵乘法的符号：`认知映射 × 感知切片`。用户明确要求的是相似书写形式，不指定相同算法。客观来源经实际暴露和感知进入本人视界，再结合本人已有记忆和规则形成主观解释；不同大脑对相同内容可以得到相反理解。
- 数值引擎依据接纳程度与声明的门槛，自动转换知识切片的接纳等级。保留连续程度、等级、来源和变化原因；门槛、评分函数由内容声明。接纳程度、命题置信度、世界真值和动作概率各自独立。正式材料或相关依赖变化驱动更新，预测更新仍留在预测域。
- 强制刻画认知是带目标约束的最小代价配平。系统必须依据允许的变化、代价守恒等世界法则和可用资源尝试求解，并结算相应支付与认知变化；不能只覆盖脑状态。具体守恒关系和成本尺度由具名法则给出，本次不新增未经确定的心理量与物理能量兑换公式。求得可行解、已证明最优、无解和预算内未求得结论分别记录。
- 核心数值由名义类型、单位、范围、归一化及声明的约束关系保证可合法运算；编译期能够推出的关系自动处理，动态关系在形成有效结果时求解。合法数值不代替人物合理性或实际剧情判断。

该能力由正式内容中的作用与法则启动；此处不授权为会话验收预置答案或注入人物认知。既有运行记录只代表旧执行链，不作为 surface-v2 已运行的证据。

### DV 新语法执行落地与代码书写

本轮用户要求直接接入编译器、Core 与第一章，核心代码使用英文，其他语言通过 define token 别名书写。现有 surface 前端已接入缩进函数、记录和固定认知运算；完整设计中的单位推导、一般精化证明与能力系统仍待实现，以 language_core/SYNTAX.md 文首实现边界为准。
