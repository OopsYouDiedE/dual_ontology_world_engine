# 《安眠者有福》统一设计与验收规范（重制版）

本文件是重制分支 `claude/remake-belief-replay` 的唯一主控设计。它取代旧版规范中的游戏逻辑、第一章剧情与推理设计；世界观骨架、人物档案要点、32px 美术规格与 Core 引擎原理按本文保留或精简。重制实施只以本文为设计依据。

---

## 设计总纲

### 一、本游戏的核心

> **物证说明发生了什么，人心说明为什么发生。玩家不排列事件，而是还原“当时每个人信了什么”，让世界自己重演；重演留下的痕迹与现场一致，才算找到真相。对手是一个从不说谎的恶魔——所以它设下的陷阱，永远在玩家自己的推论里。**

这一句是全部取舍的标准。拆开是三根支柱，按优先级排列：

| 支柱 | 玩家实际在做什么 | 引擎为何不可替代 |
| :--- | :--- | :--- |
| **1. 信念重演**（核心动词） | 设定少量“当时的处境与人心”：谁在哪、听到了什么、信谁；按下重演，看每个人依照**自己的认知**做出选择，留下痕迹；与现场对照，按冲突去补查 | Essence（客观）经 `Observation.Observe` 按位置与声路转成每个人不同的 Projection（主观），`DecisionSystem`/`SocialSystem` 依主观认知选择行动。同一句话传到不同房间就是不同的认知；人物不是按剧本走位，是被“推演出来”的 |
| **2. 真话之敌** | 恶魔的每道题都由字面全真的句子组成，却暗含一个错误前提。答辩不是“选对凶手”，而是指出题面哪一句真、哪一个推论是自己脑补的 | 恶魔受契约第 5 条约束不能说谎；它的话作为 Testimony 进入侦探自己的认知，与玩家笔记同属“可被误导的主观层” |
| **3. 记忆之价** | 可以请同伴（或自己）触物回忆，直接确认某个昨夜认知；代价是一枚“钩”——恶魔与此人的联结 | Recall 是有来源的观察；钩是跨章节持久状态。不回忆也必须能完整解题，回忆只是用确定性换风险 |

**删除测试**：任何新案件或新系统，先问“去掉引擎的主观认知与决策，这一段还成立吗？”若玩家只靠排序事件、找出唯一凶器或填对术语就能通过，它就不是本作的内容，须重做。

**体验目标**：玩家在第一章结尾得到两次反转——“闩门的人是我自己”与“我们根本不是昨天才到”。第二次反转必须由信念重演本身推出来（重演拒绝成立，逼玩家改掉“今晨的共识”），而不是由某张文书直接告知。

### 二、核心循环（案件层，约 30 分钟）

```
恶魔出题（全真之句 + 暗含前提）
   ↓
现场检视：看见痕迹，只记事实与来源
   ↓
现场试验：亲手让机构/声音再发生一次（不读结论，看结果）
   ↓
昨夜重演：设定处境与人心 → 引擎推演每个人的感知与选择 → 痕迹对照
   ↓        ↑
   冲突指向一个地点或一个人 ──→ 补查 / 询问 / （可选）触物回忆
   ↓
始业之答：用重演结论逐句回应题面；最后反问恶魔的暗含前提
```

日程层（一日）与长线层（二十日之后）在本重制中只保留接口：钩数、人物间的信任、已公开的物证，保存到章节结束状态，供后续章节读取。本轮不实现日程与长线玩法。

### 三、旧版诊断与禁止回退项

旧第一章《未归的红筹》经七轮独立盲玩可以通关，但体验评分停在 6–6.5/10。根因与本版对策：

| 旧版问题 | 根因 | 本版规定 |
| :--- | :--- | :--- |
| 案件像流程审计：排灰扳柄、滤布层次、双槽归还匣、纸带压印 | 题目是“某个工序是否合规”，没有人的处境与情感代价 | 案件必须围绕一个**有情感重量的选择**（本章：门外有人喊叫时，是谁、为什么闩上了门） |
| 16 项证物包、子面、术语密度高 | 为了“证明范围严谨”不断加机构 | 本章证物 ≤ 12 件，每件是一眼能看懂的实物；不需要读规程才能理解 |
| 推演是给事件排序、给岗位分配动作 | 引擎的主观认知只做了装饰 | 推演变量是“处境与人心”，行动由引擎推出；玩家从不直接指定某人做了什么 |
| 答辩填写“材料/解释/保留未知”九字段，下拉里有一眼可排除的绝对化选项 | 把证明强度做成了表格 | 答辩是对恶魔逐句质询的回应：出示物证或陈述重演结论；有效物证允许多种 |
| 检视页替玩家下结论；同伴提前代作推断 | 文本承担了推理 | 检视只写看见了什么；同伴只报告自己的感知与职业判读，不说结论 |
| 推演入口被隐藏计数门槛挡住，玩家找不到 | 门槛依赖“看过 7 件证物” | 第一次看到闩上的门后，重演即开放；未查过的地点在对照中只提示“你还没查过这里” |
| 内部错误码、`E09.deep` 等后缀外露；看起来能点的装饰物没反应 | 实现泄漏到界面 | 玩家可见文本全部为自然语言；可交互物件有统一高亮，装饰物不高亮 |

以下旧版交互经验继续有效：普通对白一次空格或 Enter 推进；新点击立即替换旧路径；台词按玩家已取得的材料分支，不引用未取得的东西；失败保留玩家已填内容；重演可跳过，跳过与看完结算相同。

## 第一部分：世界与角色（精简保留）

### 1. 世界

1890–1910 年代风格的架空孤岛学园，早期电气与机械时代：油灯、配重、铜质传声管、手摇机械。学园招收有异常感知潜质的普通人，研究异常、教授神秘学。学员保留入学前的职业与技能。

学园的生活翼是第一章的全部舞台：四间单人宿舍（R-05 至 R-08）、走廊、活动厅（铜口与研习长桌）、备餐间、门厅（通往主楼的隔离门）。主楼在门的另一侧，本章不可进入。

### 2. 恶魔与契约

**恶魔（“无名之蛇”）**：岛上源质留存的认知印记聚合体。外显为约三十岁的黑衣绅士，琥珀竖瞳，手形修长窄薄（掌宽明显小于常人），穿窄底外交官皮鞋，外交官式礼节。

- **虚实二态**：平时无实体，可穿墙，但**无实体时不能触碰任何物件**。要移物、开门、写字，必须显形；显形时服从常规物理，会留下指痕与足迹。它的全知只体现在言辞上，不体现在物证上。
- **说话方式**：从不说谎，只并置真实片段，让人自己补出错误的因果。被识破时坦然承认，并坚持“我字面上没有说错”。
- **本章中的声音**：恶魔通过活动厅的铜口说话。铜口本是学园的传声管。

**契约（作者侧全文，玩家在本章只听到与处境有关的部分）**：

1. 恶魔常驻岛内，不得离岛。
2. 经学员本人授权，恶魔封存其在校记忆（在校经历、师生与同学关系、事故全貌）；姓名、生平与入学前技艺不在封存之列。
3. 恶魔维持学园基础生存设施的运转。
4. 恶魔所受约束，唯有学员出于自主的行动方可解除；恶魔不得代为、诱使或强迫。
5. 恶魔须公开所立之规；规则许诺的路径必须真实可行。
6. 恶魔须传授学员理解处境所需之知；学员自负其选择的后果。
7. 恶魔不得伤害学员身心，不得拘禁学员。
8. 封存的记忆可凭对应之物恢复；恢复即重新接通，后果自负。
9. 经其余十五名学员一致同意，或封印已无法完成时，学员可择定“尽忘归乡”，于下一次入睡时遗忘一切、在家乡醒来。

**作者侧前史（本章不揭示全貌）**：四位导师在反应炉事故中以性命立约，把恶魔拘束于契约之内。事故当夜，学园长亚历山大·格雷厄姆从主楼通过铜口向生活翼下达了最后一道指令，之后再没有回来。十六名学员此前已在学园共同生活了二十余日；他们逐人授权恶魔封存了这段记忆。

### 3. 胜负条件与退场规则

- **第一章目标**：四人醒来只记得“登船”。霍铎、沈鼎、苏泠首要核验接待者能否兑现入学时约定的报偿；拿到可信的兑现凭证后，自愿参加始业之问。侦探的入约动机保持留白：他问起时，恶魔只答“你所求之物，在你封存的东西里”。
- **通关**：回答始业之问，恶魔开启主楼一侧的闩。
- **退出考题**：在恶魔说明去留之后，选项列在末位：“不作答，在生活翼歇息”。无需认罪或指认任何人，基本水食照常。选择后本 Demo 以简短收尾结束。界面与同伴不主动推荐此项。
- **长线**（后续章节）：找回真相，封印恶魔（真名、封印机制、封印材料）；或在满足第 9 条时尽忘归乡。

### 4. 记忆与钩

- 封存不碰技艺与身体习惯。四人会**不知为何地**做出熟练动作：沈鼎给苏泠的茶不放糖，霍铎读得懂石板上自己的速记。这些“身体记得”的瞬间是本章的活线索。
- **触物回忆**：本人触碰与昨夜直接相关的物件，可唤回一个短片段（昨夜此人的一个认知）。每次回忆给此人记一枚**钩**。钩在本章的后果：恶魔对有钩之人改用更亲近的称呼与语气；结局台词按钩数变化；钩数写入章节结束状态。
- 回忆是主观材料（Recall），在答辩中算证言，不算物证。

### 5. 第一章四人

| 人物 | 要点 | 在本案中的职业作用与习惯（会写进其决策规则） |
| :--- | :--- | :--- |

## 第二部分：第一章《门的这一侧》

### 1. 作者侧真相：昨夜

**空间与声路（固定事实，须在地图上可见）**：

- 铜口位于活动厅研习长桌旁，铜牌上刻着符号 **◎**（学园图纸中“传声口”的标记）。
- 铜口的传声管沿门厅墙面走向主楼，在**隔离门门框旁有一个管接头**，接口松动。管内说话时，接头只漏出低沉、重读的音节。站在门边的人会觉得声音“从门外传来”。
- 隔离门向主楼一侧开启，由配重自动拉合；门后角落常备一枚木楔。门内侧有插闩；门上有猫眼。
- 备餐间与活动厅之间隔着门，烧水声会盖过远处的人声。宿舍走廊尽头的 R-05 离门厅最远，R-08 紧挨门厅。

**这一夜的情感核心**：门外没有人求救。那句“开门”是格雷厄姆“不要开门”的后半截，从墙里的管接头漏出来。苏泠出于善意开了门，侦探出于对朋友的信任关了门；两人都诚实，都依照自己听见的东西行事。格雷厄姆要的，是他们活下去。

### 2. 恶魔的题面

开场广播（每一句字面为真）：

> 诸位晨安。初涉斯地，诸事生疏；记忆有缺，乃履约之初的规则界限，请勿惊惶。
> 昨夜警铃骤起。主楼曾有人向诸位呼喊。
> 通往主楼之门，在诸位这一侧闩上了。那人再没有回来。
> 此为始业之问：**门是谁闩上的？闩门之时，此人可曾听见门外的呼喊？**

| 句子 | 字面为何是真的 | 玩家容易补出的错误前提 |
| :--- | :--- | :--- |
| 初涉斯地 | 今晨醒来的、失去记忆的诸位，确是第一次“以这样的自己”站在这里 | 我们昨天才抵达此地，彼此素不相识 |
| 主楼曾有人向诸位呼喊 | 格雷厄姆确实从主楼喊话 | 有人在门外求救 |
| 门在诸位这一侧闩上了；那人再没有回来 | 侦探闩的门；格雷厄姆没有回来 | 闩门导致了那人没有回来 |
| 闩门之人可曾听见门外的呼喊 | 这是问句，不是断言 | 门外确有呼喊 |

恶魔的用意（作者侧）：观察四人在猜忌下会不会互相指认；鼓励他们触物回忆（每一次回忆都给它一枚钩）；守住“共同生活二十余日”的秘密——但它不说谎，所以只要玩家拿得出物证，它必须承认。

### 3. 证物

每件证物都是一眼能看懂的实物。检视文本只写看见了什么和从哪里看到，不写结论。“现场试验”是玩家亲手让机构再动一次的操作；试验结果记入该证物卡，之后可以出示。

| 编号 | 证物 | 位置 | 玩家看到的事实 | 现场试验 / 同伴协助 | 在推理中的用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| E1 | 闩上的隔离门 | 门厅 | 内闩落下；门外侧另有横闩（拉不动）；猫眼玻璃外侧糊满烟灰，看不见任何东西 | 拔闩推门：内闩可拔，门仍被外闩卡住 | 题面事实；昨夜无人能从猫眼看见门外 |
| E2 | 门底灰扇与木楔 | 门厅地面、角落 | 门内地面一片扇形灰，形状与门开一道窄缝时的缝隙吻合；角落木楔上面沾灰、底面干净，楔尖有新磨痕；门底有对应的擦痕 | 把木楔塞回门底：门停在与灰扇吻合的开度 | 昨夜有人用楔撑开门，烟灰在门开着时进来 |
| E3 | 灰上的靴印 | 门厅，插闩下方 | 一枚马球靴印踩在灰上，鞋尖朝向插闩 | 检视自己的靴底：纹路相同，纹槽里嵌着灰 | **闩门的是侦探自己**（第一次反转） |
| E4 | 湿布 | 门底 | 一条拧过的湿抹布沿门底压成直线，正好贴着闭合的门；布的一端压住靴印的鞋跟边缘 | 沈鼎：“这布是我拧的，这手法我认得。” | 湿布在门关上、靴印留下之后才放；放布的人到时门已闭 |
| E5 | 音叉 | 门框旁地面 | 刻有 “S.L.” 的纯银音叉；门框齐肩高处有一个小凹痕 | 苏泠用音叉轻敲凹痕：音色与她敲桌面不同，她能说出“这里贴着空管” | 苏泠昨夜在门边辨声；门框后面有管 |
| E6 | 苏泠的乐谱 | R-08 书桌 | 一小节记谱：前两拍是弱音，记着问号；后两拍重读，字是“开门”，同样的一小节记了两遍；旁注“门外？”。下方换了一种墨迹：“他们关了门。” | 苏泠读谱：“男声，很低。前两个字太轻，我听不出。” | 苏泠听到的是一句话的后半截；她相信声音来自门外 |
| E7 | 霍铎的石板 | 活动厅长桌、铜口旁 | 粉笔速记 `G：⊥门 ✕开 ◎`；下面一行是一个小小的放大镜图样加 `⊥✓` | 霍铎辨认：“是我的字。⊥ 是闩，✕ 是禁止……◎ 我不确定。”放大镜图样他认不出指谁 | 有人通过某个渠道下达了“闩门、禁开”的指令；有人回来报告闩好了 |
| E8 | 铜口与管接头 | 活动厅铜口；门厅门框旁的管接头 | 铜口铜牌刻 ◎（于是 ◎ = 铜口，“守铜口”）；管道沿门厅墙面走，门框旁的接头松动 | **声路试验**：请铜口（恶魔乐意配合）说一句话，侦探或同伴分别站在铜口旁、门边、备餐间、R-05 听。门边只听到句尾重读的字，且像是从门外来 | 苏泠听到的“开门”可能来自铜口，经管接头漏到门边 |
| E9 | 四只杯子 | 备餐间水槽 | 四只用过的杯子，各不相同：青瓷小杯（杯底无糖渍）、刻着 H 的凹痕锡杯（杯底厚糖渍）、缺口白杯、粗瓷大杯 | 沈鼎：“我泡茶按人放糖。”——“可我怎么会知道谁不吃糖？” | 泡茶的人熟知四人的口味 |
| E10 | 酵种罐 | 备餐间架上 | 活跃的酵种，罐上标签刻着 24 道短线，最后一道歪斜 | 沈鼎：“是我的刻法。一天一道。” | 沈鼎在这里至少续养了 24 天 |
| E11 | 架上的无尘方框 | 四间宿舍书架 | 积灰的架上留着几块干净的长方形，像相框和书立过很久的位置；R-05 架沿有半枚手印 | 请同伴比手：手印比四人的手都窄 | 有人取走了长期摆放的物件；取物者不是四人之一 |
| E12 | 侦探的外衣口袋 | R-05 衣架 | 石墨笔、放大镜、证物袋；放大镜铜框的样子与石板上的小图一样 | — | 放大镜图样指的是侦探 |

证物可以任意顺序发现。没有任何证物被藏起来等待某一轮才出现。

### 4. 昨夜重演

#### 4.1 玩家设定的变量

重演面板只问六件事。每个变量的选项都写成自然语言；未取得相关证物时选项仍可选，但对照结果会标“你还没查过这里”。

| 变量 | 选项 | 初始值 |
| :--- | :--- | :--- |
| V1 警铃响时，苏泠在哪 | 她的房间（紧挨门厅）／活动厅／备餐间 | 未定 |
| V2 警铃响时，霍铎在哪 | 活动厅铜口旁／他的房间／门厅 | 未定 |
| V3 那人是从哪里喊话的 | 从主楼对着铜口说／就在门外走廊 | 未定 |
| V4 那人说的是什么 | “闩门，别开”／“开门，救我” | 未定 |
| V5 侦探最后照谁的话做 | 霍铎／苏泠／谁也不听，自己判断 | 未定 |
| V6 昨夜之前，四人彼此 | 素不相识（**今晨的共识**）／早已相熟 | 素不相识 |

V6 预设为“素不相识”并标注“今晨大家都这么以为”。这是本章唯一预填的值，因为它正是题面引导玩家形成的错误前提。

玩家**不能**设定任何人“做了什么”。行动全部由引擎从下列规则推出。

#### 4.2 引擎推演：感知 → 认知 → 选择

**感知（`Observation.Observe`，按声路过滤）**：

| 说话位置 \ 听者位置 | 活动厅 | 门厅或 R-08 | 备餐间 | R-05 / R-06 |
| :--- | :--- | :--- | :--- | :--- |
| 铜口 | 全句清楚 | 只有句尾重读字（“……开门”／“……救我”），听来像在门外 | 有人说话，听不清 | 只有警铃 |
| 门外走廊 | 听不到 | 全句，隔着门发闷 | 听不到 | 只有警铃 |

**人物规则（`DecisionSystem` 规则，写在各人的 ProjectionWorld 中）**：

| 人物 | 条件（主观认知） | 行动 |
| :--- | :--- | :--- |
| 苏泠 | 相信“门外有人要开门” | 到门厅，开门并用木楔撑住，贴缝听；敲音叉辨声路；回房记谱 |
| 苏泠 | 听清“闩门，别开” | 留在原处，不碰门 |
| 霍铎 | 听清一条指令 | 在石板上速记；若指令含“守铜口”则留在铜口旁，向走廊喊出指令；有人来到身边时，请他去执行（`Say` + Request） |
| 霍铎 | 听到“开门”类片段且在门厅 | 自己开门查看（工装靴印会留在灰里） |
| 侦探 | 收到请求“去闩门”，且对请求者信任足够（`SocialSystem` 判为接受） | 到门厅，撤楔，插闩，回去报告 |
| 侦探 | 收到相互矛盾的两种说法，对双方都无足够信任 | 物证先于言辞：自己到门边听。听到“开门”且看见烟——撤楔让门合上挡烟，但不插闩，不回报 |
| 侦探 | 选择照苏泠的判断 | 保持门开，向门外喊话查看 |
| 沈鼎 | 闻到烟 | 浸湿抹布，到门厅沿门底压住缝 |
| 沈鼎 | 众人受惊 | 泡四杯茶；若熟知各人口味则按人放糖，否则四杯一样 |

**V5 与 V6 的关系**：V5 表示玩家假设的侦探选择；引擎会检查该选择在侦探的主观认知下是否成立。V6 =“素不相识”时，侦探对霍铎的信任不足以让 `SocialSystem` 接受一句转述，因此即使玩家设 V5 = 霍铎，重演中的侦探也会犹豫、改为自己去门边听。这一刻要在回放中清楚呈现：侦探的心声气泡写“我凭什么信一个昨天才认识的人？”

#### 4.3 对照

重演结束后，引擎得到一份“预测的晨间世界”（Essence 状态），逐件与玩家已检视的证物对照：

- **吻合**：预测痕迹与证物一致。
- **冲突**：写出具体差异，例如“重演中门没有闩上；但门厅的内闩落着”“重演中四只杯子放了一样的糖；但青瓷杯底没有糖渍”。
- **你还没查过这里**：重演在某处留下了痕迹，而玩家尚未检视该处。只给地点，不给结果。

回放：在真实地图上，用半透明墨色人影重演，每人头顶显示心声气泡（他此刻听到/相信的东西）。同一时刻，四个气泡并排显示四种不同的认知，这是“双重本体”最直观的画面。回放可暂停、倍速、跳过；跳过与看完的结算相同。

#### 4.4 解空间要求

6 个变量共 216 种组合。以全部证物对照时，**有且只有一种组合完全吻合**：

> V1 她的房间，V2 活动厅铜口旁，V3 从主楼对着铜口说，V4 “闩门，别开”，V5 霍铎，V6 早已相熟。

每个错误值至少被一件可取得的证物否定（实施时须用穷举自动检查确认）：

| 错误值 | 被什么否定 |
| :--- | :--- |
| V1 活动厅 | 苏泠会听清全句、不去碰门 → 无灰扇、无楔痕（E2）、音叉不在门边（E5） |
| V1 备餐间 | 苏泠听不清，没理由去门边 → E2、E5 |
| V2 他的房间 | 无人记下指令 → 石板无速记（E7） |
| V2 门厅 | 霍铎只听到“开门”片段，会自己开门 → 不会写“禁开”（E7）；灰上会有工装靴印（E3） |
| V3 门外走廊 | 活动厅听不到 → 石板无速记（E7）；苏泠在门边听清全句 → 若为“别开”则不开门（E2） |
| V4 “开门，救我” | 霍铎会记下“开门”并请人开门 → 与石板 `✕开` 冲突（E7）；门不会被闩（E1） |
| V5 苏泠 | 门保持开着 → 内闩未落（E1），无靴印指向插闩（E3） |
| V5 自己判断 | 门合上但未插闩、无回报 → E1；石板没有第二行（E7） |
| V6 素不相识 | 侦探不接受初识者的转述，同上 → E1、E7；沈鼎四杯一样的糖 → E9 |

**推进节奏（建议路线，不是强制顺序）**：

1. 看门厅：门、灰扇、靴印 → 第一次反转“是我闩的”。重演开放。
2. 看 R-08 乐谱与音叉，看活动厅石板 → 两份相反的说法：“开门” vs “禁开”。
3. 声路试验 → 两者可以同时为真。重演中 V1–V4 收敛。
4. 设 V5 = 霍铎 → 重演拒绝：“我凭什么信一个昨天才认识的人？”与石板第二行冲突。
5. 改 V6 = 早已相熟 → 全部吻合；而杯子、酵种、无尘方框、放大镜小图都成了旁证 → 第二次反转“我们不是昨天才到”。

### 5. 触物回忆

可回忆的物件（每人一件，须本人同意；同伴可能犹豫，玩家可以作罢）：

| 物件 | 回忆者 | 唤回的片段（昨夜此人的一个认知） | 确认的变量 |
| :--- | :--- | :--- | :--- |
| 音叉（E5） | 苏泠 | “门边……有人在喊开门。我想开门让他进来。” | V1，以及她相信声音来自门外 |
| 石板（E7） | 霍铎 | “铜口里的声音很清楚……‘守在铜口旁，等我下一次通知。’——他再也没有来。” | V2、V3、V4；◎ 的含义 |
| 酵种罐（E10） | 沈鼎 | “第二十四道。阿泠的茶不放糖，老霍的放两勺……” | V6 |
| 插闩（E1） | 侦探 | “霍铎说闩。我就闩了。我信他。” | V5、V6 |

- 恶魔会在玩家走近这些物件时温和地鼓励“不妨一试”；邀请侦探触闩时，侦探可以拒绝（符合他拒绝未经证明之力的性格）。
- 回忆片段把对应变量标为“回忆所证”，但不替玩家改变量；玩家仍须自己在重演中设定。
- 不回忆也能完整解题。

### 6. 始业之答

答辩是与铜口的一场对话，不是表格。恶魔按顺序追问，玩家每步可以**陈述**（从重演结论里选一句）或**出示**（从证物中选一件）。每一步接受多个有效证物；无关证物得到指向性的回应（“这件东西说明了别的事”），不扣分、不重来。

| 步 | 恶魔的追问 | 有效回应 | 恶魔的回答（字面不改口） |
| :--- | :--- | :--- | :--- |
| 1 | “门，是谁闩上的？” | 陈述“是我”，出示 E3（或 E12 + E7 第二行） | “坦率。那么——你闩门的时候，可曾听见门外的呼喊？” |
| 2 | “门外有人呼喊吗？” | 出示 E8（须已做声路试验）或 E5：门外无人，那是管接头漏出的铜口之声 | “我说主楼有人向诸位呼喊。他确实在主楼。” |
| 3 | “他喊的是什么？” | 出示 E7（`✕开`）或 E6（“开门”只是句尾）：他要你们闩门 | 恶魔沉默片刻：“……他要的，是诸位活下去。” |
| 4 | “闩门的人，为何不听门边那位女士的？” | 陈述“我信霍铎”，并出示一件证明四人早已相熟的证物（E9、E10、E11、E7 的放大镜小图任一） | “信任，需要时日。” |
| 5（反问） | 玩家主动反问：“你说我们‘初涉斯地’。” 出示 E10 或 E11 | — | “今晨醒来的诸位，确是初次。我从未说过诸位昨日方至。……至于昨日之前的诸位，那是你们自己的事了。” |

第 5 步是本章的高潮。它必须由玩家主动发起（铜口对话中出现“反问”选项，前提是重演中 V6 已设为“早已相熟”并全部吻合）。不发起反问也能通关，但结局台词不同，恶魔会在最后轻声说：“诸位……没有别的想问了吗。”

### 7. 章节流程与台词纲要

| 场 | 内容 | 要点 |
| :--- | :--- | :--- |
| S1 醒来 | R-05。侦探只记得登船。外衣挂在衣架（E12），架上有无尘方框（E11）。内心独白一句：“我只记得上船。” | 第一个异样留在背景里，不点破 |

| S4 始业之问 | 广播题面（§2）。恶魔说明去留：作答则开主楼之闩；不愿作答者可在生活翼歇息，无需认任何事。选项末位为“不作答，歇息” | 不推荐退出 |
| S5 调查 | 自由行动。同伴各在一处，可以请他们协助（辨声、读速记、认手法） | 同伴只报告感知与职业判读 |
| S6 第一次反转 | 检视靴印并对照自己的靴底后，侦探独白：“……是我。” 苏泠看他一眼，不说话 | 重演开放 |
| S7 重演与补查 | 循环。关键反馈见 §4.3 | — |
| S8 第二次反转 | V6 改为“早已相熟”并全部吻合时，四人短暂沉默。沈鼎看着酵种罐：“二十四道。”霍铎：“……我们在这里很久了。” | 由玩家的重演结果触发，不由某件证物触发 |
| S9 始业之答 | §6 | — |
| S10 门开 | 门外传来窄底皮鞋的脚步声（恶魔须显形才能抬闩），外闩抬起。门开，主楼走廊里烟灰已落定，远处另外三个寝区的门后有人声。苏泠走到侦探身边：“你昨夜没听我的。”停一下，“你听对了。” | 结尾按钩数与是否反问变化恶魔最后一句 |

**文风**：每句短；同伴说话带职业口吻；恶魔用古雅、礼貌、精确的书面语；侦探独白克制，不替玩家下结论；不出现“Essence/Projection/假说H1”等术语；不用感叹号渲染。全章正文目标 6,000–8,000 字。

## 第三部分：系统与界面

### 1. Core 映射

| 设计概念 | Core 实现 | 归属 |
| :--- | :--- | :--- |
| 客观世界（门、闩、楔、灰、布、杯、石板、乐谱） | `Essence` + `Property`（状态用 `StateProperty` 或专用 Property） | 游戏层定义对象，Core 只提供类型 |
| 人物 | `SoulEssence`，各自 `ProjectionWorld` | — |
| 声路感知 | 宿主按 §4.2 表计算每个听者得到的内容，以 `ObservationInput`（Source = Perception）经 `Observation.Observe` 提交；转述用 Testimony，回忆用 Recall | 声路计算属游戏层 |
| 人物习惯与认知规则 | `Rule`（Condition / Effect / Mode / Weight）写入各人 ProjectionWorld，`DecisionSystem.Choose` 选择 | 规则内容属游戏层 |
| 请求与信任 | `Effect.Say` 携带 Request；`SocialSystem.Evaluate` 依 Trust 判 Accept / Negotiate / Reject；V6 决定侦探对霍铎、苏泠的 Trust 初值 | — |
| 行动结算 | `ActionRuntime` 准备后提交；`SimulationSession` + `CTBSystem` 排先后；同一身体不能同时做两件事 | — |
| 重演 | 每次重演新建独立世界与人物认知，绝不改动现实（玩家所在的晨间世界） | — |

Core 只做通用扩展（如确有必要的新 Condition 或 Effect 类型），不出现门、楔、杯等专案名词。

### 2. 现场调查

- 鼠标点击移动与交互；键盘 WASD 亦可移动；E 或空格交互。可交互物件悬停时统一高亮描边，装饰物不高亮。
- 检视：一次点击打开证物卡（局部像素图 + 事实文字 + 来源），可直接在卡上执行该物件的现场试验或请在场同伴协助；任意键返回现场。
- 笔记本（Tab）：已取得证物按地点分组，名称为自然语言（“门底的灰”“霍铎的石板”），无内部编号外露。

### 3. 重演手稿

- 左页：六个变量，每个是一行横排的纸质选项；回忆所证的变量旁有小钩记号。
- 右页：对照结果列表（吻合／冲突／未查），每条可点开对应证物卡；冲突条目写出具体差异。
- 按“重演”后在真实地图上回放（§4.3）。修改任一变量后旧结果标为过期。
- 首次开放时用一句话说明玩法：“设定当时的处境与人心，让昨夜重演一次。”

### 4. 始业之答

铜口对话框 + 底部两个按钮：“陈述”“出示”。陈述列表只来自玩家重演中已设定的值；出示列表是笔记本。没有下拉表单，没有“保留未知”字段。
