# 《安眠者有福》设计规范

本文件定义《安眠者有福》的世界观法则、人物心智模型、核心玩法循环与视听工程标准。文档旨在为叙事、程序与美术团队提供统一的因果律底座。本作的一切剧情走向均由“世界初始条件 + 物理法则 + 人物认知推演”自然涌现，不在硬性规则之外预设强制性的剧本轨道。

各章描述的调查、协作、立规与生存关键节点，是用于核对自然模拟结果的设计目标。初始事实与世界法则提供条件，人物依据本人实际获得的信息、动机、能力和资源选择并执行行动。关键节点由这些行动及其后果实际达成时，构成剧情与引擎在该覆盖范围内相符的证据；未达成时保留实际原因与未知分支，不能预置答案、代写选择或强制写入成果来制造符合。具体时刻与标准路线保留其目标或示例身份，不直接充当人物行动指令。

## 总纲

### 一、 核心设计哲学

> **现实与认知二相。**
> **读（Read）：从他人在现实中的行动与现场痕迹，反推其内心的规则与事实认知。**
> **写（Write）：通过立规、告知、带人亲见、教学或对质，改变他人的认知，使其在现实中的行动随之改变。**
> **恶魔受契约约束不能说谎，却能利用“字面为真”的话语操纵人心；玩家先学会拆解它的语言陷阱，最终也将掌握同样的力量，并独自承担使用这股力量的伦理代价。**

本作的叙事引擎源于“规则怪谈”的深层逻辑：每个人都在依据自己认定的规则与已知事实来理解处境、选择行动。当认知与客观现实发生错位时，真实的危险便会降临。游戏围绕四大支柱展开：

| 核心支柱 | 玩家的核心体验 | 模拟引擎的驱动方式 |
| :--- | :--- | :--- |
| **1. 读：信念重演** | 设定当事人的处境与心理变量，推演其行动轨迹，并与现场物证对照。 | 每名角色作为独立主体，严格依据自身的感知、记忆、目标与技能采取行动。 |
| **2. 写：认知改写** | 起草公约、通报险情、邀请同行、现场教学、当面对质。 | 听者根据信息来源的可信度、自身利益与既有观念，独立完成“理解—评估—采纳—执行”的完整链条。 |
| **3. 真话之敌** | 剖析代管者的授课、警告与日常应答，剥离字面事实与会话隐含推论。 | 恶魔的发言受契约公理约束（真值恒为真），但会利用信息不对称诱导听者产生致命的语用推论。 |
| **4. 生存与记忆之价** | 清点物资、观测环境、组织协作、决定是否深入追索被封存的往事。 | 生理状态、物资存量、源质侵蚀度与记忆取回深度在全周期内连续结算。 |

### 二、 生存压力与系统涌现

游戏中的危机并非由剧本按时间表强行派发，而是由三层客观环境压力与人物的主观应对交织产生：

1. **环境侵蚀（岛在吞人）**
   - **机制**：源质从火山深处外泄，导师留下的防护随契约担保的衰减而减弱。
   - **病理表现**：遵循神经认知退行规律，按暴露量与记忆取回深度逐级演进：**注意涣散（工作记忆受损） → 异态睡眠（梦游症） → 顺行性遗忘（近期言行转瞬即忘） → 木僵状态（“安眠”，丧失对外界刺激的反应） → 脑干功能衰竭（死亡）**。
2. **资源枯竭（孤岛闭环）**
   - **机制**：契约期间岛屿处于超自然隐匿状态，无外界船只往来。契约第 3 条仅维持供水、炉火与照明的管网设施运转，不凭空创造消耗品。
   - **表现**：初始室内口粮与药品有限。要维持长期生存，必须冒着源质灰尘的风险前往室外修复温室、开辟采集路线或打开紧锁的储备仓。
3. **社会张力（人性博弈）**
   - **机制**：契约只约束恶魔，不约束学员。
   - **表现**：饥饿、未知恐惧、过往成见与源质引发的感知异常，会促使不同性格的学员采取囤积、排他、抗命或激进冒险等行为。

**生与死的边界**：
- 允许不可逆的角色死亡（因环境事故、重度侵蚀或人际冲突导致）。
- 玩家所控角色的动作集中不包含直接伤害他人的暴力选项；一切伤亡均源于物理环境法则或人际认知的崩坏。
- **知识获取与风险规避**：保命所需的基础知识（源质计读法、风向规律、低洼积气区、停行条件）可通过恶魔的契约授课与现场安全规程习得，无需以取回深层记忆为前提。当证据不足或环境恶劣时，等待风窗、暂停试验、优先照护伤员等保守策略均是合理且有效的生存手段。

### 三、 模拟层级与因果律

为了保证推理的公平性与剧情的自由度，世界运行严格区分以下三个层级：

| 层级 | 包含内容 | 生成与运行原则 |
| :--- | :--- | :--- |
| **既定历史（Past）** | 事故当夜的经过、导师的牺牲、封存前的旧痕、器物上的既有字迹。 | 由作者预先写定，在单局游戏内作为不可篡改的客观真相存在，供玩家通过物证发掘。 |
| **世界过程（World）** | 气体扩散与沉降、地质微震、气象风窗、生理代谢、物资消耗、病理演进。 | 由物理与生物法则驱动，根据初始条件与随机种子随时间连续推演。 |
| **人物行动（Agency）** | 谁去取粮、谁起疑心、谁听从规劝、谁违背公约。 | 完全由角色当时的主观认知图谱（所知事实、欲望、信任度、身心状态）实时决策产生，绝不由剧本强行指派。 |

**行动因果公理**：
- **认知边界**：角色的每一次决策、发言与指控，其依据必须来源于本人亲眼所见、亲耳所闻或基于已有认知的合理推论。角色不会因为“剧情需要”而未卜先知。
- **移动目的与现场查验**：为实质任务移动时，人物须已有该任务前提成立的本人依据；前提未知或需要复查时，以独立的现场查验目的接近，并通过真实检视取得信息。到达地点不等于任务完成。针对午餐与规则草案等有明确时段的事项，窗口前的旧观察与窗口内的新观察分别判断。
- **规范与执行的分离**：角色在口头上“认可一条规矩”、“因群体压力被迫服从”与在无人监督时“实际执行该规矩”在系统中独立计算。
- **物理真实性**：声学传播、视线遮挡、门锁结构与空间移动均遵循物理拓扑。角色必须通过真实可达的路径前往目的地，其行动必然在环境中留下符合物理规律的痕迹（如露水脚印、泥地鞋印、门闩磨损、物品位移）。

### 四、 核心循环与通用交互

各章节共用一套统一的操作语言与模拟底层：

#### 1. 时间与日常循环
- **案件循环**：接收问题 → 现场勘查 → 物理试验 / 请同伴辨认 → 信念重演（推演假设并与现场对照） → 针对冲突点补查 → 陈述与出示对质。
- **昼夜循环**：采用连续推进的游戏时钟（清晨、上午、午间配给、下午、傍晚对账、夜间）。行走、劳作、勘查与交谈消耗真实游戏时间；查阅已获取的笔记与手稿时时钟暂停。夜间各角色按各自认定的规矩与需求行动，并在次日清晨留下物理痕迹。
- **长线循环**：在契约担保逐渐衰减、火山地质前兆加剧的背景下，平衡“日常生存（产粮、防疫、立规）”与“终局探索（取回记忆、破译铭文、探明真名与封印机制）”。

#### 2. 基础操作规约
- **移动与交互**：鼠标点击或 `WASD` 移动；`E` / `空格` / `Enter` 检视身边物件或与人交谈。普通家具仅在首次交互时浮现一句简短心声。
- **空间接近与行动结算**：同房间内的行走由宿主执行连续碰撞与鼠标寻路，只改变现场坐标，不扣减DV游戏时间、认知预算或动作步数。到达热点后交互，或请求跨门洞进入另一房间时，才提交本人可用动作并经Prepare、现场回执和Complete结算。跨门前保持原逻辑地点，实际执行成功后再交接房间。普通跨房移动通过现场位置和房间显示反馈，不为重复的通用过路描述开启对白；具有剧情来源的发言仍按实际执行结果呈现。
- **现场选择**：普通探索保持地图直接操作。单个热点只有一个合法动作时直接提交；存在多个动作时在该物件或人物旁显示局部选项。对话话题与答辩由对应接触点进入，随身回想与重演从本人手稿进入；等待输入不自动弹出全局动作列表。
- **学园图（`M`）**：仅绘制所控角色亲自到访过或听他人明确提及的地点，点击可发起寻路。不提供全员实时位置雷达。
- **案卷册子（`Tab`）**：按地点归档的物证记录、已读规矩、人物观察印象（仅记录亲见迹象与转述来源，允许存在主观误判）、闪回与回忆片段。
- **重演手稿（`R`）**：首次发现案件核心痕迹后开启。左页设定当事人的处境与心理变量，右页显示推演结果与已查物证的对照状态（相容 / 冲突差异说明 / 尚未勘查的地点），并在实景或手稿图上以半透明墨影回放当时的行动与心声。
- **时间推进（`T`）**：在当前位置等待至下一制度钟点或突发事件；夜间可选择入睡或守夜。等待与睡眠前会提示角色当前已知的环境风险；期间若发生警报、他人唤醒或急性病理症状，将按真实条件中断。

#### 3. 视野与空间认知
- **房间级视野**：室内以房间为基本视野单元。当前所在房间整体可见；已到访过的其他房间压暗显示静态布局，未到访过的房间内部遮蔽，但墙体与门洞结构清晰可见。
- **信息隔离**：不在同一房间（或超出室外可视距离）的人物与动态事件不可见。不在场期间发生的事，玩家只能通过事后留下的现场痕迹、守夜时瞥见的模糊身影，或他人的口头转述来还原。
- **室外视距**：室外不按房间切分，受视线遮挡、昼夜光照与源质烟灰浓度影响，夜间与浓雾时段可视距离显著缩短。

### 五、 叙事结构与多周目设计

1. **连续世界会话**：全作（规划六章加尾声；15–20 小时仅作初期内容容量假设，须由实际体验校准）运行在同一个连续的世界时间线上。章节切换时完整继承世界物理状态、物资余量、人物身心状况、人际关系与已立下的规矩。章与章之间的时间跳跃通过低精度模拟自然结算。
2. **心智抽样与重玩价值**：
   - **过去固定**：事故当夜的客观历史、导师遗存与长线核心谜底在开局前写定。
   - **现在微调**：每名角色的深层心智参数（欲望权重、谨慎阈值、初始信任倾向、偏见强度）在声明的合理区间内于开局时抽样生成（首局默认使用标准种子），使每一局的人际化学反应呈现微妙差异。
   - **未来涌现**：后续事件完全由心智模型、环境变化与玩家的介入共同推演出不同的走向。
3. **十六视角切入**：通关首局（默认扮演侦探）后，开局可任选十六名学员之一作为主视角。不同角色拥有专属的开场感知、职业技能（如苏泠的精密听觉辨位、莫兰的现场速写取证、霍铎的机械结构拆解）以及各自所在寝区的始业案件。
4. **修罗线（隐性伦理分支）**：玩家在掌握了“写”的机制后，若效仿恶魔的手法——利用片面真话诱导他人、蓄意促成他人无节制地取回深层记忆直至被源质吞没——以换取自身的认知升格，将逐步滑向修罗线。系统静默记录玩家每一次操纵行为的对象、手段与后果，由其他角色基于各自的察觉作出真实反应。

## 第一部分：世界观与地理建筑

### 1. 时代背景与孤岛地理

- **时代风貌**：1890–1910 年代风格的架空孤岛学园，处于第一次与第二次工业革命交汇的早期电气与精密机械时代。照明与供暖依赖煤油灯、煤气与燃煤锅炉，通讯依赖铜质传声管网（Voicepipe），机关依赖配重块、发条与机械联锁。学园招收具有异常感知潜质的各行业人士，他们在保留原有职业技能的同时在此研习神秘学与自然哲学。
- **地形蓝本与尺度校准**：
  - 以大西洋亚速尔群岛的科尔沃岛（Corvo Island）真实火山岛地貌为蓝本。
  - **工程尺度校准**：为适应游戏步行体验，将岛屿水平尺寸按 $0.5$ 倍缩放（缩放后南北长约 $3.2\text{ km}$，东西宽约 $1.9\text{ km}$，陆地面积约 $4.2\text{ km}^2$）。为避免水平与垂直同比例缩放导致坡度不变而步行距离减半所带来的视觉与水力失真，高程采用独立曲线校准：中央破火山口（Caldera）直径约 $1\text{ km}$，底部发育火口湖与湖心岛；全岛最高点位于火口西南缘（海拔约 $350\text{ m}$）；四周环绕陡峭海崖，唯南端发育一片平缓的玄武岩熔岩台地（海拔 $9\text{ m}$ 至 $22\text{ m}$，面积约 $14\text{ ha}$，平均坡度控制在 $6\%$ 左右）。
- **学园选址与主轴序列**：
  - 学园建于南端熔岩台地中部，背靠火山口北风屏障，南向面海朝阳，东侧紧邻天然避风港。

### 2. 源质（Prima Materia）：物理特性与病理机制

- **基本定义**：源质是一种从火山深部岩浆房逸出的特殊惰性气溶胶与矿物微粒复合体，具有极强的**信息拓印与认知耦合特性**（类似摄影干板对光的记录，源质对生物神经电活动与强烈情绪具有物理级的记录与回放效应）。它附着于玄武岩、水体与日常器物表面；一旦脱离本岛的地磁与热力场即迅速衰变消散。
- **三种现象的同源解释**：
  1. **触物闪回**：器物表面的源质微粒记录了持有者过往强烈的感知片段，当本人再次接触时引发神经谐振。
  2. **记忆封存**：将个体特定时间段的记忆印记剥离并转存至高纯度源质媒介（名录库中的“封存匣”）。
  3. **恶魔（代管者）**：千百年来岛上累积的无数人类认知印记在火山源质池中自发涌现出的高阶聚合意识。
- **气溶胶流体力学（环境危险法则）**：
  - 含源质的火山烟灰比空气重（类似 $1986$ 年喀麦隆尼奥斯湖二氧化碳喷发或火山氟化氢沉降）。
  - **高处与有风白天（风窗）**：受海风吹拂与热力对流影响，高处与开阔地带的源质浓度降至安全阈值以下，具备室外通行条件。
  - **低洼处、无风与夜间**：受辐射冷却与重力沉降作用，源质气溶胶极易在露天夹道、坡脚、汲水泉等低洼盲区积聚至高危浓度。
  - **震后效应**：地质微震会破坏地下裂隙封堵，导致数小时内源质逸出量骤增，并可能通过建筑受损的接缝渗入室内。
- **测量与防护**：
  - **源质计**：皇家科学院特制的检测仪器（利用源质在特定晶体上的光学折射率变化或电离效应驱动指针与记录纸）。读数仅代表**采样点在采样时刻**的局部浓度。
    - 记录分别保存采样地点、采样时刻与实际收到信息的时刻。查阅旧表或延后听到转述保留原采样时刻；室外通行规程采用半小时内实地读数，已知微震或风停后须停行复测。人物依据本人取得的信息判断，真实暴露由当下现场环境结算。
  - **建筑气闸与通风**：室内安全依赖于门窗气密性、双道隔离门（气闸）以及受控的通风路径。只有当补风口位于清洁空气区且排烟道畅通时，方可利用壁炉热压拔风；高浓度时段需关闭受污染进风口，依靠室内既有空气维持。

#### 既成绑定与实际脱身条件

学员在入院后的研究、仪式、共鸣与事故暴露中已经与岛屿建立联系。记忆封存压低正在发生的显性共鸣、使人暂时不记得这些经历，却不撤销既成联系，也不把人格、身体与他人的处境恢复到登岛前。开局须继承这段历史；关闭名录库只能阻止部分后续取回，不能把十六人统一置为无绑定状态。

**完整绑定（契约所称“深属此岛”）**指岛上源质场已经成为当事人部分认知活动持续存在的必要载体：离开此场会使该部分失去维持，直接切断又会牵连本人尚在使用的感知、记忆或生命功能。它与病情严重程度、清醒程度、愿否留下分别记录。清醒者可以已经深属此岛，木僵也不能单凭症状判为永远不可救；有无主动取回记录另按“夜半唤名”规则处理。

本次既定历史将**苏泠在事故当夜的长时暴露**落实为已经形成的完整绑定。她仍可在缓冲治疗后恢复对话、活动并继续生活，但这只能稳定病程，无法直接恢复离岛资格。第一、二章的救治目标继续成立；白塔后续研究通过场内支持下的短时隔离、反应变化与复查揭示脱耦难点，不能以重病、耳鸣或恶魔一句判词代替证据。其他人的既有耦合按其实际往事记录，之后是否发展到完整绑定按本人经历结算，不补造第二个必定绑定的人维持难度。

**可脱耦**要求相关认知与生命功能已经能够脱离岛场维持，或本人接受的切离处置已经实际完成且身体能够承受离岛。现有缓冲剂、短暂唤醒、再次封存与普通遗忘均不能完成这种转移。进一步研究可以寻找有限的分离办法，但须先具备可验证的方法、设备、照护和恢复时间；切弃不可迁移的印记可能连带损害原有感知或人格连续性，不能把这些额外损害并入第十一条本就约定的遗忘而注销。不可逆失去肉身支持的场内意识也不能凭投票恢复成可遣返的活人。

人物对岛屿的归属还包括已经真实承担的研究、照护、保护与见证责任。这些关系决定他们为什么继续接触源质、为什么不肯先走，以及解除某人的联系会把哪些工作和危险留给别人；它们不直接充当超自然传送锁。承诺的转交必须有人能够并愿意实际承接，循环签署互保书不消除无人承担的最后一份责任。完整绑定的客观后果与人物是否愿意付出解除代价，共同构成归乡困境。

### 3. 建筑格局与连通逻辑

学园为何采用“单层为主、多院分散、连廊相接”的格局？这一设计同时满足**工程现实、神秘学结构与游戏视野**三重需求：

1. **抗震与施工现实**：火山岛地震频发（参考 $1998$ 年亚速尔法亚尔岛地震），19 世纪末的无筋火山石砌体难以承受多层高楼的剪切力；单层建筑承重简单、基础浅，且在实验动力断联后无需依赖电梯与机械扬水。
2. **分馆隔离制（Pavilion System）**：参照 19 世纪后期南丁格尔式分馆医院（如赫伯特医院）与德国大学独立研究所制度。将动力噪声（铁工院）、剧毒试剂（白塔院）、精密测音（共鸣厅）与珍贵文书（名录库）物理隔离；一旦某处发生泄漏，只需落下该区的配重隔离门即可切断扩散通道。
3. **地下封印几何（作者侧真相）**：四座研究院正下方对应地下“四锚封印廊”的四个阵脚，中央厅正下方压着封印核心基座。四院与中央厅保持严格的几何等距，是全学园唯一违背顺坡等高线原则的反常布局（可供懂建筑结构的角色如玛格丽特在勘查中发现）。
4. **三级通行网络**：
   - **地面封闭连廊**：连接生活翼、中央厅、讲堂、名录库与后勤院。设顶盖与可调配重百叶窗，每座建筑入口处设气闸式隔离门，是灰尘天气下的生命线。
   - **地下勤务环廊**：连接四座研究院、中央厅与水窖的地下管网通道，遍布蒸汽阀、传声管主干与检修门。
   - **室外步道**：连接誓约庭、温室、汲水泉与野外设施（采石场、地震观测站、引水渠风车泵房、废弃牧场、港口码头与契约石碑），通行安全严格受气象风窗与地面浓度制约。

## 第二部分：恶魔、契约与语用博弈

### 1. 代管者（恶魔）的行为模型

- **外显形态**：约三十岁的黑衣绅士，琥珀色竖瞳，手掌修长窄薄（掌宽显著小于正常成年人），穿窄底外交官皮鞋，举止遵循严谨的古典外交礼仪。
- **物理二态性**：
  - **虚体状态**：平时无物理实体，可穿过墙体与门扇，但**绝对无法对任何物质施加机械力**（不能开门、不能移物、不能写字）。
  - **显形状态**：一旦需要触碰器物、板书、搬运燃料或落闩，必须凝聚为实体；显形期间严格服从牛顿力学与物质交换定律，必然留下窄手印、粉笔字迹、窄底皮鞋印等物理证据。
- **语言哲学机制（字面为真与会话含义诱导）**：
  - 恶魔受契约第 8 条绝对约束，所言之事在客观世界中的**语义真值（Semantic Truth）必须为真**。
  - 它的操纵手段建立在语言学家保罗·格赖斯（Paul Grice）的**会话含义理论（Conversational Implicature）**之上：通过违反“关系准则”或“数量准则”（即只提供局部事实、隐去关键背景、将两件时间先后发生的事并列陈述），诱使听者根据日常语言习惯自动补全错误的因果链条。
  - **身份隐匿**：它自称为“此地的代管者，也是诸位的教师”。除非玩家凭物证与契约条文直接质询其本质，它不会主动自报“恶魔”或“源质聚合体”的身份。
- **判真、知情与必答分别成立**：事实断言的客观真值受契约约束，不意味着它自动知道答案。“某人说只服过一剂”与“某人脑内只留下服过一剂的记忆”分别需要证言记录与真实记忆检视；不能借语义限定将听到的自述升级为读心结论。它不能用自己并无把握的断言试探世界真值。
- **可取得的知情来源**：代管者拥有实际位置与行动日程，通过在场观察、真实可达且声压足够的传声路径、事后收到的证言或实际检视的源质印记取得信息。设有铜口不代表每句私语必然传到中央厅；挡板、封堵、底噪与监听者位置均须核对。源质印记是有限的主观感知片段，须现场取得和解读，既非全岛实时摄像，也不直接提供他人全部心智参数。
- **答复范围**：第八条强制回答本人封存之物及条文问题，按它实际掌握的事实答复；未知须明确说明未知，自己经手的登记、保管与履约记录不得佯称不知。询问真名或犯罪经过不会仅因句中提到“契约”就变成无限必答；已问明某条具体含义及其所知事实时，也不能以悬念为由拒绝。第九条禁止主动指示或劝促取回，适用于相关记忆媒介，无论它此刻在库内还是库外。普通设备资料和保命教学依第六、七条提供，不能用授课之名暗示学员去取回。

### 2. 契约十二条与“尽忘归乡”的脱身条件

封印与契约分属两层结构：**四锚封印**是困住恶魔的物理与仪式牢笼（由导师遗存维持）；**契约**则是规定恶魔与学员权利义务的法则（由导师性命构成的担保维持，随时间缓慢衰减）。

公共契约由四位导师提供担保、与恶魔缔结，十六名学员是权利人和被保护者，逐人授权的是本人记忆封存。学员不因另有雇佣、报偿或身份保管私约而失去这些权利；不存在“一人只能有一份主契约”的通则。私约只能处理其真实约定的事项，不能转移或削减导师为学员保留的保护。

#### 契约正文

- **甲 · 成立条件**
  1. 恶魔常驻岛内，不得离岛。
  2. 经学员本人授权，恶魔封存其在校记忆（在校经历、师生与同学关系、事故全貌）；姓名、生平与入学前技艺不在封存之列。
- **乙 · 恶魔对价**
  3. 恶魔维持学园基础生存设施的运转（供水、炉火、照明的设施管网本身；不负责分配物资，不凭空创造消耗品）。
  4. 恶魔所受约束，唯有学员出于自主的行动方可解除；恶魔不得代为或强迫学员完成解除。
  5. 恶魔须公开它自己所立之规；规则许诺的路径必须真实可行。
  6. 恶魔须传授学员理解处境与继续学习所需之知；学员自负其选择的后果。
- **丙 · 导师所留**
  7. 恶魔不得伤害学员身心，不得拘禁学员，不得令学员因无知而死。
  8. 恶魔对学员所作事实断言不得为假；学员问及本人封存之物或契约条文，须按所知如实作答，未知须明言未知。
  9. 恶魔不得向学员提及封存之物的所在与取回之法，不得促其取回；学员自行问及者，依前条作答。
  10. 封存的记忆可凭对应之物恢复；恢复者自负其果。
  11. 学员本人未深属此岛，且经其余在岛存活学员一致同意，可择定“尽忘归乡”；在条件仍成立的下一次入睡时，遗忘此地一切、在家乡醒来。
  12. **（终局条款）** 担保耗尽时，恶魔须将醒着且未深属此岛的学员遣返家乡，并抹去其与此地有关的一切记忆。

#### 契约的博弈空间与漏洞分析
- **门槛法则（第 8、9 条）**：如同《德古拉》中吸血鬼未经邀请不得入内、《浮士德》中梅菲斯特需浮士德三次请入。**恶魔绝不能主动提及“封存之物在哪”，也绝不会主动劝说任何人与关键证物共鸣或取回记忆**。它可在核验报偿或授课时，利用本人已表露、它实际知晓的渴望提供片面真话；听者是否因此深入探索由实际接收、理解和权衡决定。不得以“谈论欲望”为名绕过禁止指示、劝促取回的边界。
- **自主解除的灰色地带（第 4 条）**：禁止“强迫或代为解除”，却未禁止“用真话放大欲望”。它必须在担保耗尽前，培养学员具备解开封印的知识与能力，并诱导至少一人自愿解封；而讽刺的是，**足以解开封印的知识，同样足以彻底加固封印**。因此，它必须真心实意地授课。
- **免于无知而死的底线（第 6、7 条）**：恶魔必须提供最低限度的保命教学（如源质计读法、低洼积气规律、震后停行原则）并在迫近致命危险时履行告知义务。当某名学员因外伤、急性源质侵蚀或门外毒气超标而一旦跨门即会遭受不可逆身心伤害时，契约第 7 条会直接阻止恶魔为其抬起外闩，直至环境达标或医疗危机解除。

#### 第 11 条“尽忘归乡”：既成绑定、有效选择与真实脱身

归乡的首要困难是人物已经与岛屿形成的绑定。即使十六人全部知情、真心想走且全票同意，已经深属此岛的人仍不满足脱身条件；苏泠的起始绑定是明确的既定案例。为救她、接续导师的工作或查清自己正在失去什么，同伴又可能付出时间、接触源质并加深自己的联系。表决只授权一个本来可以执行的离岛方案，不能解除源质依赖。第十一条与第十二条采用第一部分同一套“深属此岛／可脱耦”定义。

**1. 前置认知与公开条件**：角色须从本局信息知道存在契约，才可据此追问。第一章追查取物窄手印、第二章结合守则追问代管者权限来源，或第三章实际取得港口石碑拓片，均可通向全文。依法提前问得的条文立即有效。恶魔答复第十一条时须完整说明本人选择、其余存活者同意、未深属此岛与下一次入睡的条件，并解释它所知的脱身边界；不得在投票通过后才补出绑定例外，也不得把自己尚不知晓的某人状态冒充已确诊结论。

**2. 有效执行与失能边界**：申请人须仍活着、已不深属此岛、作出有效的本人选择，并取得执行前其余在岛存活学员的一致同意，随后进入下一次符合条件的睡眠。本人选择与对别人离岛的同意分开记录；同意送走某人不等于同意自己遗忘。

清醒且具备相应理解能力时可以事先表达本人归乡选择，也可对明确对象、时段和条件作出同意；预授权须可辨认、可核验，适用对象和失效条件须写清，本人恢复表达能力后仍可撤回。书面、口述与见证只是保存真实选择的方式，伪造、代签或未经授权的代理不能生成同意。欺瞒与压力可能改变当事人依据并促成其真实作出的表态，须分别保留意愿效力与知情损失；失去表达和理解能力后不能靠操纵签字补造本人决定。

木僵者仍在存活集合内；没有相应有效授权时，其他人不能替其补票，某项一致同意可能因此冻结。短暂唤醒只提供重新理解和表态的机会，不能保证他愿意同意，也不证明脱耦成功。已经处于木僵或睡眠中不自动构成“选择后的下一次入睡”；须有随后真实成立的入睡过程及执行时的离岛资格。执行前重新核对存活在岛名单、条件与撤回；多人可在各自条件确实成立时同一时段归乡，不人为限制每夜一人。最后一人的“其余学员”集合为空，只免去他人的同意，本人意愿、脱身资格与入睡仍须成立。

**3. 人物已经置身其中的联系**：下表固定的是由人物履历形成的归属和责任，不是预置赞成／反对票。取回、救治、履责与风险暴露可使这些联系进一步转为完整的源质绑定。

**5. 代管者的干预范围**：恶魔可依据自己实际听见的游说、已知人物目标与公开表态选择接触对象，以有来源的片面真话影响决定；不能读取全体隐藏欲望参数或保证制造一票反对。第九条的禁言范围、第七条的迫近危险告知及第八条的必答义务持续有效。即使它完全不干预，既成绑定和相互依赖也足以使部分归乡条件不成立。

**6. 全员结果的边界**：正常进程没有靠诚实协商便可完成十六人无损归乡的路线。限制来自已经成立的绑定，以及实际解除所需的损失、工作与风险；少一张票只是可能出现的表层现象。极端提前部署可以争取干预窗口，隐瞒、诱导或胁迫可以让人接受本会拒绝的处置，但只有真实处置改变了依赖才可能改变脱身资格。未卜先知也不能撤销开局前已经发生的伤害；不得用尚无本局来源的未来知识替人物自动完成准备。

如特别精密的行动使十六人最终活着离岛，仍须逐人结算脱耦损伤、舍弃的认知与能力、知情情况和未履责任；既有机制尚不能解除的完整绑定者，不能仅因“特殊路线”获得豁免。保住部分人的生命、为留岛者提供照护、完成带代价的脱耦或选择封印，都是有价值的结果。事实若显示某条无损路径确实成立，应回查本轮绑定设计和实现遗漏，不得在结算末尾追加人数锁或回填事故。

## 第三部分：记忆机制、心智博弈与十六名学员

### 1. 记忆心理学、共鸣判定公式与“取回”的代价

本作成熟运用认知心理学中的记忆分类学，将“记忆缺失”转化为可交互的推理线索与伦理抉择：

1. **外显记忆与内隐记忆的分离**
   - 契约第 2 条封存的是在校期间的**外显记忆（Explicit / Declarative Memory）**，即情景记忆与人际关系。
   - **内隐记忆（Implicit / Procedural Memory）**——包括运动技能、职业肌肉记忆与条件反射——完全保留（科学原型：1911 年爱德华·克拉帕雷德的藏针握手实验，以及著名失忆症患者 H.M. 的镜像描图实验）。因此，沈鼎会下意识按四人的口味放糖，霍铎会画出约定俗成的速记符号。这些“身体比头脑更诚实”的细节，是玩家在前期破局的活证据。
2. **触物闪回（被动反射）与深层共鸣/取回（主动选择）的自主判定机制**
   - **被动触物闪回（Involuntary Flashback）**：当角色在日常劳作或调查中直接触碰承载自身过往经历的旧物时，会不由自主地触发短暂的感官闪回（普鲁斯特效应）。**闪回属于自然的生理反射，不计入取回代价。**
   - **恶魔绝不劝诱共鸣（契约第 9 条铁律）**：在第一章及后续调查中，**恶魔绝对不会主动劝说任何人与证物共鸣，也不会提示“握紧这件物品去回想”**。
   - **角色自主共鸣/深究的决策不等式**：当一名角色触发被动闪回、或面对一件与自身核心执念高度相关的源质媒介时，他是否会选择继续深入共鸣（或主动追索记忆），完全由其心智模型内部的**“源动力驱动值”与“谨慎阈值”**博弈决定：
     $$U_{\text{resonance}} = \left( W_{\text{drive}} \times I_{\text{relevance}} + B_{\text{demon\_truth}} \right) - \left( S_{\text{caution}} + R_{\text{perceived\_risk}} \right)$$
     - $W_{\text{drive}}$：该角色的核心渴望权重（原动力）；
     - $I_{\text{relevance}}$：眼前物件与该角色核心渴望的关联度（例如石板上的闭式动力符号之于霍铎、奇异声学轨迹之于苏泠、未见过的源质色层之于莫兰）；

     - $S_{\text{caution}}$：该角色本人的理性谨慎分数（如维罗妮卡、沃德基础谨慎分较高，而莫兰、卢西安在涉及艺术与未知时谨慎分较低）；
     - $R_{\text{perceived\_risk}}$：角色当前已知的源质侵蚀风险。
     - **推演结果**：当 $U_{\text{resonance}} > 0$ 时（即**受源动力驱动产生的共鸣加成超过了其自身的谨慎分数**），该角色便会在无人劝说的情况下，自主选择紧握旧物深入共鸣或追索往事！反之，若玩家提前向其普及了源质风险（提高 $R_{\text{perceived\_risk}}$）或满足了其求知欲，则可阻止其盲目共鸣。

代管者受契约约束，不能说谎、不能伤人、不能劝人取回记忆；契约只约束恶魔，不约束学员。因此前两章持续搅动社群、制造摩擦的破坏力来自学员一侧。为避免开局秩序全面崩溃、保持严酷现实的基准线，学员侧的“魔丸”行为遵循**阶梯式激活与上限约束**：

#### 4.1 第一章魔丸上限原则（双雄死斗与谐星调剂）
第一章严格限制最多 3 人产生主动破坏或干扰行为，且局限于失忆后的职业成见与性格放大，不涉及致死陷阱：
1. **死斗双雄（沃德 vs 雀儿）**：
   - **沃德（体制性有罪推定）**：搜身扣帽、利用恶魔字面裁决将雀儿定性为窃贼，在起居厅动议剥夺其行动自由，试图以法治权威压制混乱；
   - **雀儿（街头反骨与物理掀桌）**：被诬后拒不口头辩解，利用精钢丝当面挑开外闩越狱；顺走沃德随身小物件并反向设套戏弄，以手艺报复体制。
2. **谐星与伪红鲱鱼（卢西安）**：
   - **自恋狂言犯**：21岁的贵族诗人，面对密室与契约产生强烈的戏剧亢奋；在起居厅或讲堂黑板写下语气森严的“深渊预言诗”试图扮演指路先知；
   - **破绽与解密**：其十四行诗格律、华丽词藻与袖口残留的普鲁士蓝墨水极易被侦探、顾平章与沈鼎识破，沦为全员哭笑不得的闹剧，构成排除超自然邪教疑云的假红鲱鱼与日常轻喜剧调剂。

#### 4.2 核心智谋搅局者：阮清月（第二章接棒）
阮清月在第二章全员汇合后正式接棒成为全场主考官。她独立行动，与代管者无合作，把学园视作与代管者对弈的棋盘，以“试应手”探查契约边界并测试同伴成色：
- **定位**：十六人中最早自发使用“写（Write）”的人：只说字面为真的话、隐去关键背景、制造可控压力，观察代管者与众人如何应对。
- **与玩家的关系**：尊重能看穿其棋路的人；被拆穿后认可侦探的对手资格，和解只针对具体误会，不改变其下棋求胜的核心动机。

#### 4.3 危机驱动的潜在破坏者（中后期条件性激活）
其他角色在前期保持正常职能，仅在特定欲望（$W_{\text{drive}}$）被恶魔真话引爆或面临清算恐慌时条件性觉醒：
- **维罗妮卡**：因害怕自体标定受伦理审查而酸蚀锁孔毁证；
- **莫兰**：因痴迷紫金以太色层与害怕被隔离而藏真画稿、乃至夜闯高危毒气区；
- **霍铎与沈鼎（中后期暗雷）**：闭式热机图纸成瘾私启联锁，或为庇护熟人破坏规矩。

#### 4.4 极端死手与致命抉择机制（非侦探专属的极端杀戮阈值）

下死手与冷血清除并非侦探专属。当人物处于极端绝境、背叛阈值被突破或博弈到达零和生存死角时，具备专业技能的学员同样会自主触发致命甚至无差别的绝地杀戮行动。该行为由心智引擎中的绝望度、自尊创伤、信任倒挂与效用极化驱动，遵循严格的物理机会与现场手段约束：

1. **伊莲娜（创伤破防与同归于尽）**：
   - **成立条件**：再次被信任的同伴（如侦探、阮清月或沃德）作为弃子出卖致残，且左踝伤势恶化丧失起舞可能，其自尊防御与被弃创伤突破谨慎阈值（$T_{\text{caution}} \le 0$）。

2. **维罗妮卡（军工化学家的无差别反击）**：
   - **成立条件**：被同伴指控投毒、遭受私刑拘禁或面临被强制驱逐进毒雾区，军工世家的傲慢与绝地反击本能觉醒。

### 4. 乙区信念重演与始业之答

沈鼎在实际触物闪回后，可以主动向同处的侦探询问是否继续回想。玩家手动回应时，既可陪伴、劝停或交还本人决定，也可只强调陶罐归属和已有熟悉感而省略风险。片面真话须由玩家实际发出、被沈鼎收到并理解，才登记其对象、手段与来源；深层取回仍由沈鼎自己的认识和动机决定，发生后再关联实际后果。一次劝说不自动构成修罗线达成。

- **重演变量（手稿左页）**：
  - **V1 警铃响时，苏泠身在何处？**（她的房间 R-08 / 活动厅 / 备餐间）
  - **V2 警铃响时，霍铎身在何处？**（活动厅铜口旁 / 他的房间 R-06 / 门厅）
  - **V3 呼喊声的实际源头在哪？**（从主楼对着铜口传声 / 就在门外起居厅拍门）
  - **V4 那人喊话的原意是什么？**（“闩上门，不要开” / “打开门，救救我”）
  - **V5 侦探在门厅面对分歧时更信谁？**（信霍铎的石板指令 / 信苏泠的门外呼救说 / 谁都不信）
  - **V6 四人在昨夜之前的关系？**（昨夜初见的陌生人 / 早已熟识的同住者）
- **四步对质（始业之答）**：
  1. **门是谁闩上的？** → 陈述“是我自己闩上的”，出示 **灰上的靴印（E3）** 或 **霍铎的石板（E7）+ 放大镜（E12）**。

### 2. 双基线 AI 侦探与自动化测试规范（Core 推演基准）

为比较不同认知参数下实际发生的调查、协作与生存行为，侦探的 AI 配置在 DV 内核中与其余十五名学员使用共同认知和决策机制。人工游玩时由玩家选择动作：系统处理实际收闻、现场感知、基础推理和语用更新，普通回合由玩家判断假说和发言，不替玩家展开全部假说、论证与听者预演。玩家实际完成付费重演后，系统按共同规则刷新相应推演与论证；动作准入、事实来源、正确条件和正式费用继续由 DV 核对。系统内置两个不同认知参数配置的 AI 侦探基准模型——**标准侦探（`Standard_Detective`）**与**愚蠢侦探（`Foolish_Detective`）**。下列时段与结果是设计基准；实际达成情况依据新正式会话的行动、可见信息与结果记录判断，未执行的分支保持未知。执行范围与验收方式遵循仓库 AGENTS.md，不使用流程回归。

#### 2.1 两个 AI 侦探的核心参数差异

| 认知与决策维度 | 标准侦探 (`Standard_Detective`) | 愚蠢侦探 (`Foolish_Detective`) |

| **主线推进目标与社群生态位** | 主线聚焦“高维探索与破解封印”：探明真名、解构契约、担任智力破局领袖 | 主线自适应降维至“生存与团结”：放弃高深推理，转入后勤协助、照护伤员与守夜；同伴不抛弃他，展现包容守护 |

### 3. 界面视觉规范：案卷册子与近代印刷美学

游戏的信息整理以**所控角色随身携带的案卷册子（Casebook）**为中心；推演界面作为独立手稿展开，与案卷采用一致的纸色、墨色和排版层级。视觉风格汲取 **1890 年代欧美与东亚报刊（如《The Graphic》、《Le Petit Journal》、《时事新报》）** 以及 **近代博物学图谱（如海克尔《自然界的艺术形态》）** 的排版语言，整体取向为典雅、疏朗、克制。

#### 版式与排版法则
1. **两种基础母版**：
   - **报纸版式（单页栏网格）**：用于现场 HUD 抬头、对白条、证物卡、对质表单、候选菜单与章末总结卡。以小号引题、宋体标题、短规线和疏朗正文组织阅读；层次优先由字号、版心、留白与淡纸色建立。规线使用低对比淡墨，普通阅读区不绘制闭合双线框、密集角花或默认现代按钮外壳；键盘焦点和选中状态仍须明确可见。
   - **博物书版式（对开书页）**：用于案卷笔记本、学园线路图与设置册（凡例/操作/书签）。遵循古典版心留白比例（订口窄、书口宽、天头地脚疏朗），以柔和中缝阴影与书口索引组织目录。信念重演保持独立手稿界面，仅展示宿主实际提供且属于所控角色可知范围的假设、记录与结果；未提供的内容保持空缺，不从作者候选、他人心理或界面样张补造。
   - **卷首桌面与书页导航**：桌面、书本、油灯、放大镜、墨水瓶和笔采用统一尺度的真实三维形体，以共同相机、光照和阴影建立透视、遮挡与接触关系。依据用户提供的卷首参考图，标题场景使用深暖胡桃木、磨损墨绿烫金书皮、象牙色旧纸、旧黄铜与钴蓝玻璃，暖金油灯集中照亮近处。以明确的书封实体尺寸建立统一毫米比例，道具按可核查的实物规格标定长、宽、高与握持粗细；不为凑入画面而缩小道具。俯视角保持约 60°，以缩短取景距离形成近景，俯角与距离分开控制；物体放大后通过摆放与自然裁切组织构图，不拉远相机来容纳所有道具。开书后平移跟随阅读页，保持约 60°俯角与近景，允许封皮沿实体轨迹离开画面。材质分别提供颜色、切线法线与线性粗糙度，微表面随物体及翻页网格运动。鼠标移动产生克制视差，点击位置随同一相机投影反向校正。风干扰同时影响火苗偏摆、光源位置与亮度以及物件实时软阴影，保留阅读清晰度。开始阅读、凡例设置与续读书签通过实体书籍翻页进入，返回时翻回封面；减少动态效果时保持稳定照明与投影，翻页立即落定。
   - **同册入口与资料边界**：卷首与游戏内的凡例设置、续读书签共用同一本实体书及翻页表现。目录整理所控角色实际采集或读到的证据、物品记录、人物资料与立像、CG 图版、猜想和个人批注；条目保留既有来源、时间、地点与关联，未取得内容不预先开放，个人猜想与已获事实分开。实际推演工作台独立展开，书内只提供资料整理与进入推演的入口。中、日、英三语及音量、显示、辅助功能属于界面偏好，与 Core 世界状态分离；切换语言不改写原始证词、玩家批注或世界事实。
2. **印刷体与手写体的语义区分**：
   - **铅印字体**（如思源黑体特粗、思源宋体、仿旧打字机字体）：代表客观题面、剪报记录、已印好的公告条文与可点击的功能选项。
   - **钢笔手写体**（配铁胆蓝黑墨水色 `#2F3B57`）：代表**所控角色本人的主观介入**——包括勾选的选项、填写的姓名、重演手稿中设定的心理假设、对质时写下的陈述，以及笔记本上的个人批注。
3. **克制与易读性原则**：
   - 装饰元素（细线、双线框、印戳）仅使用低对比度淡墨色，绝不喧宾夺主；字号严格控制在五级以内（注 $14\text{ px}$、正文 $18\text{ px}$、副题 $22\text{ px}$、标题 $32\text{ px}$、通栏大标题 $48/64\text{ px}$），遵循 $8\text{ px}$ 基线网格。
   - 提供完善的无障碍与外观开关（高对比度模式、简明现代字体替换、关闭纸张纹理、减少动效）。

### 房间舞台与现场阅读

室内镜头围绕玩家所在房间构图，小房间整体成景，大厅随玩家移动并保持房间边界。相邻区域以柔和暗角收束，房间门洞和可见热点保持可读；镜头缩放只影响呈现，不改变物理尺寸、距离和交互费用。

环境底色采用冷灰褐与蓝灰，壁灯、落地灯和炉火提供暖瓷白、淡玫瑰色的局部衰减光，窗光采用冷青灰。窗光中可显示少量缓慢微尘；减少动态效果时停止微尘并取消镜头缩放动画。家具与人物脚下有接触阴影，道具保留材质轮廓、纸页折角与器皿高光。普通灯光遵守下文专属色限制。

玩家阅读期间，远处人物可按本人认知和正式行动链继续活动，移动仍真实执行寻路、碰撞和到达回执。调度遇到玩家输入、当前房间行动或新的可见对白时暂停提前推进，按实际事件顺序交给前台。正在阅读的正文保持稳定，后续世界状态与新正文在阅读结束后更新。人工游玩与AI会话的行为和耗时分别记录。

### 3. 音乐声学与“门句动机”设计

全作配乐由一套严谨的**主导动机（Leitmotif）变形体系**统摄，将第一章的核心悬念直接编码进旋律与和声结构中：

#### 核心音乐密码：“门句动机”与“阻碍终止”
1. **门句动机（The Door Motif）**：
   - 对应学园长当夜那句被截断的呼喊——**“不要｜开门！”**
   - 动机由一小节四拍构成：前两拍为两个微弱的下行音符 **$\text{D}_5\text{–C}^\sharp_5\text{–B}_4$**（对应轻读的“不要”），后两拍为猛然上跳五度的强音呼喊 **$\text{F}^\sharp_5\text{–E}_5\text{–F}^\sharp_5$**（对应重读的“开门！”），尾音悬停在属音（$\text{F}^\sharp$）上，形成一个悬而未决的音响问号。
   - **叙事对应**：在调查初期的曲目中，钢片琴只远远奏出后半截（$\text{F}^\sharp\text{–E–F}^\sharp$），模拟苏泠听见的半句漏音；当真相大白时，钢琴与簧风琴才完整奏出包含前两拍的整句动机；而在主题曲尾声中，旋律首次落回 $\text{B}$ 大调主音，象征问句终于得到解答。
2. **恶魔的和声签名：阻碍终止（Deceptive Cadence）**：
   - 每当涉及代管者（恶魔）或对质博弈时，旋律声部明明给出了完全正确的属到主落音，低音声部却在最后一刻悄然滑向六级和弦（在 $\text{b}$ 小调中落向 $\text{G}$ 大三和弦）。
   - **听觉隐喻**：“旋律字面为真（每个音都对），脚下的和声根基却被偷梁换柱”——完美对应恶魔“真话诱骗”的法则（也对应了第一章甲、丙、丁三区答出了“字面正确但定性错误”的半截答案）。

### 2. 第三章：拓荒、水源与名录库（M1–M3）

#### M1《泉亭、温室与双签之争》

**处境与利益**：室内饮水由后勤院雨水蓄水窖供应。坡脚汲水泉、风车泵和高位清水槽另供温室灌溉及铁工院冷却补水；海拔低于温室的泉水须经扬水后使用，不能直接凭重力上坡。温室修复争取后续产粮，霍铎希望保护冷却设施与导师热机研究，沃德担忧人员独赴低洼地。工业试验回路的维修属于学员工作；恶魔仍须依第三条维护基础生活供水管网，不能靠拒绝履约制造生活饮水危机。

**危险的两条因果**：停炉后的地下余热可使烟道水封失水，导致维修区烟气侵入；旧冷却回路还留有污染沉积和失修的止回阀。污水倒灌必须同时具备热回路压力高于清水支管、检修旁通连通、止回阀失效这三个条件。水封干涸本身不等于污水必然逆流，温度表和水位痕也不能单独证明阀门卡死。现场需要核对管网图、停泵前后的压力水头、阀件动作及分支水样。

**可介入的行动**：公开霍铎的紧迫需求、陪同实查、隔离污染旁通、趁风窗检修止回阀、为温室和冷却回路安排分时供水。所需人手、零件和白天工时仍要从本局资源中支出；若缺件，可先停用危险支路、人工补水或接受部分苗床停灌。双人签字记录实际查验和交接，不能凭签字使设备恢复或使所有人永久守规。

**可能的案件与后果**：在研究损失迫近、霍铎实际低估危险、缺少他认可的替代方案且确有工具和通路时，他可能自行改阀；同伴也可能先完成维修，或说服他等待。违规后若逆流条件齐备，温室污染会留下阀位变动、工具痕、分支沉积和维修记录差异。后续损失由实际受污染面积、清理工时与人员暴露结算，不固定两天恢复，不预定赛尔玛或卢西安必须受伤。调查目标包括还原错误判断和修复水路，不只寻找应被处罚的人。

#### M2《港路石碑与五方停航令》

港路在风窗、道路和人员状态允许时可被勘查。顾平章、卢西安及实际具备警戒、搬运能力的同伴可协作拓印契约石碑；其他视角也可通过教学、已有记录和对应工具参与。第二章已经依法问得契约全文者可直接使用，不等港路或第十一日再次“解锁”。拓片提供独立条文证据和传播媒介，其张贴不自动使每个人读过、相信或同意离岛。

星仪院测量揭示地上四院与中央厅的几何对应，并与地下锚座实际位置互证。玛格丽特的测绘、伊莲娜的步位经验、莫兰已有速写及他人实地测量可以提供不同部分；不在现场产生过的记录不能因原记录者缺席而补出。

查明后，伊莲娜可罢演、要求改装、限定动作或同意经过解释的风险；阮清月也可承认模型局限、争论必要性或拒绝代价过高的改法。知情同意约定只承认本人有权决定自身参与，不能签完就令她必然恢复跳步。共鸣试验可延迟或使用精度较低的机械替代，实际损失由时间、材料和误差体现。

同归于尽只在第三部分所列的再次背叛、伤势恶化、绝望与现实破坏机会同时达到条件时成为她可能选择的行动。制造这种处境的人可以是任何具备相应行为与关系的人，不以玩家是否点选某句台词作为唯一开关。若她实际破坏承重装置，坍塌、伤亡、器械丢失及绕行成为后续状态；仍允许他人提前察觉、制止或抢修。

#### M6《窄治疗窗与重复的一剂》

白塔的观察记录与学园长遗物提供侵蚀治疗研究，并保存格雷厄姆和塞莱斯蒂娜的同袍之誓。第二章已完成的医化协作和照护记录继续有效，不能因进入新模块便恢复最初的不信任。高阶缓冲剂 B-03 面向已有治疗不足的深侵蚀者，只缓冲病程，不承担解除完整绑定的功能；配方、标准浓度、单次份量、复用间隔和重复用药风险必须先经可见的研究与配制记录进入使用者认知，不能到事故后才补写。

本作将深侵蚀的顺行性遗忘表现为新近事件难以巩固：患者可短时维持动作和对话，分心后可能不记得已服药；外部记录、持续提示和照护仍可提供帮助。它不是每十五分钟或每次跨门必定清空的计时机关。反复返回用药目标需要该目标和相关习惯实际存在，不能从一个病名直接指定行为。

**预防与案发条件**：集中保管、分次发放、本人可见的服药记号、照护交接及适度复核可阻止重复服用，各需真实人手和执行。仅当有相应病患、可自行接触多次份量、记录或交接失效，并发生实际重复用药，才产生过量事件；无人处于该病理就继续研究和照护，不强令另一同伴或照护者顶替案发。

**证据与限度**：固定浓度药瓶减少三份，首先说明取用或损失量；药盘的不同杯底干燥残留与烤饼碎屑、震落玻璃之间的真实叠压交界，至多限定接触发生在送餐前、送餐后至落玻璃前、落玻璃后。须检验再润湿、移动和同一落物事件等条件，不能反推出精确的三次钟点。进一步结合各自见到一次取药的同伴证言、空包装、现场出入和安全的非服药任务重演，才可区分患者重复自服、照护交接重复或他人投药；证据不足时保留尚未排除的解释。

恶魔可以准确转述患者说过“只记得一次”，不能在没有记忆检视依据时认证其脑内确实仅有一次。其判词若利用听者将自述当事实的倾向，仍须满足第二部分的知情与判真边界。维罗妮卡家族军工史可以形成新的戒心，但贝尔特朗是否采信投毒指控还取决于本人看见的用药事实、既往救治与程序进展，不能由一张旧公函抹去此前合作。

可协商合成与批次标定由维罗妮卡负责、临床处方由茉拉负责、库存与交接由获认可者监督；高危柜可采取多钥匙管理，但急救取用、代班和解除失效授权须有实际办法。贝尔特朗的处决仍须达到蓄意牺牲无辜且正常程序失效的极端条件，维罗妮卡的报复也须具备迫害处境、认知与现实手段。化学室损毁会消除后续合成能力，不在下一章恢复。

### 4. 第五章：物资、锚座与归乡协商（M7–M8）

#### M7《暗火、余粮与第一道锚锁》

地震、漏水、燃料消耗和既往保养共同决定是否出现粮仓受潮、供暖不足的压力；第二十五日是压力参考点，不固定扣掉三分之一库存。未开主粮仓的世界能否到达此时，须有此前实际取得的存粮、成熟作物或采集产出支撑，不能以“温室块茎”补写二十天口粮。新栽作物按生长阶段结算，发芽不等于已经提供可食产量。

只受潮、尚未腐败且未被源质污染的面粉，可经及时干燥或烤制保全一部分；已污染的部分另行封存评估。烘炉需要燃料，鼓风不创造热量，干燥失水也不能直接按同一百分比扣掉可食热量。风车、干燥间、减少供暖空间、回收可用燃料和调整劳动安排提供不同方案；删除未有依据的石灰碱洗或溶剂洗粮万能解法。无化学室时仍可进行实际具备条件的物理保粮，但不能凭兜底名称产生燃料和粮食。

在现有配给未覆盖病弱者、沈鼎认为公开申请无望且确有可挪用食物时，他可能私留营养较高的份额；公开配额、补偿或信任变化也可能使他据实上报。其护短对象与数额由本局关系和库存决定，不预先凭空藏十二份。霍铎若发现松动第一锚可打开地热旁路，会面对取暖与封印稳定之间的取舍；恶魔提及此事实仍须履行已知迫近危险的告知义务。拆锚前可调查独立换热、减少热损和部分停暖，是否可行由设施条件决定。

阮清月的极端清除不是“余粮少于五天”自动触发：须由她的真实信息和计算指向均分必致全灭，且没有她已知并认可的补给、减耗、救治或撤离方案。若其信息有误，玩家可带她核查；若她已实施手段，药剂取得、投放机会、察觉与反制均须实际发生。保住资源能避免这些行为，也可能仍留下关于分配公平与隐瞒的未决争议。

#### M8《咽喉博弈与尽忘之辩》

生活翼气闸、地下勤务枢纽、名录库入口与港路的价值来自通行、工作和信息传播。派系随实际目标、信任和控制能力形成：希望送走伤病者的人、要求证据的人、还要研究或保留记忆的人可以跨寝区合作，同一人也可能同时支持别人离岛而拒绝自己遗忘。不能在第二十九日把固定名单自动分配到三个据点。

归乡首先核对第二部分的实际脱身资格，再处理有效选择、撤回、失能与时间规则。苏泠即使病情稳定、所有人都想送她回家，既成绑定仍使方案无法直接执行；继续寻找分离治疗又会牵住医护、研究者与照料者。要求先行者验证归乡安全的人，必须面对离岛者无法返回报告、信物消散不能证明在家乡安然醒来的证据限度；相信契约可是一种有理由的信任，也不能冒充现场验证。医护和工匠提前离开会改变留守者的安全边际，研究者完成心愿可能需要更多劳动、取回或危险暴露，解除一个人的异议未必降低全体阻力。

玩家可促成局部撤离、重排工作、保留共同看护、提供真实接应凭据、接受有人自愿留守，也可通过遮蔽危险、截断转述、夸大承诺或施压争取表态。后者必须实际改变听者依据并由其本人选择，签名伪造不产生有效票。它可能得到更多生还者，也会留下未获充分知情的选择、被利用的信任和未履约责任；暴露与否由实际证据决定，不安排全知公审兜底。

恶魔只能依据自己已知的游说、票型与人物表现干预。它可选择接触对象、提供有来源的片面真话，不能读取全体隐藏欲望表或保证必造出一张反对票。玩家能察觉并反制，也可能只知道协商突然受阻。既成绑定才是归乡的核心阻力，即使恶魔沉默、表决一致，也不能消除；其初始事实、解除代价及特殊路径边界见第二部分，不另设人数结算锁。

### 5. 第六章：质询、追责与终局行动（M9–M10）

#### M9《真话之庭与第十六号席位》

**质询代管者**：侦探已经取得的私约登记和记忆可以补足自身来历，封印工作则由公共工程资料、四院实测和依法追问契约共同推进。第八条可以要求解释封存程序、已经明确的条文与恶魔所知的对应事实；它不把任何与真名沾边的问题变成全知问答。提前问得的答案当时有效，人物不得等到第三十四日才使用。母码是公共封印体系的一部分，不借“恰好放进侦探匣内”制造专属强制吐露权。

**对操纵者的追责**：受害者遗留记录、确实听见的谈话、物资与动线以及反事实重演可以形成指控；私聊与次日伤亡的相关性不单独证明因果或恶意。谁愿意调查、是否举行公议、哪些人支持限制权力，取决于他们实际掌握的证据、关系和行动能力。调查可能提前发生、失败、止于怀疑，也可能揭露打着救人旗号实施的归乡操纵。不能按隐藏伦理分数召集全员。

**监禁后的行动**：若真实公议与执行使玩家被隔离，看守保留此前对其手段的认知。铜口仍可传递警报、证据和交易；可信险情可以促使看守求援或核查，并不自动要求打开囚室。出逃需要另一个可成立的机会，例如获准带押协助维修、外闩确被操作、监督分配失误或可实际利用的结构弱点。封堵铜口、留下第二看守和远程复核也可以成为对方的应对。叙事不保证被囚者一定能反扑成功。

#### M10《四锚终局：安眠者有福》

担保末期开放的火山口步道、地下四锚廊、港口与祭坛仍受地形、风窗、结构和侵蚀约束。人物只能选择已有认知支持、本人愿意且现实可执行的行动：组织封印、促成下一批归乡、承担留守照护、等待第十二条，或实施解封和升格。实际条件提前满足时可以提前行动，不为最后三日强制拖延。

四锚闭合须具备各锚受力与相位资料、可用材料、真实操作条件及已被参与者接受的分工。解开锚座、保持安全工况与最终封印是不同动作，掌握一种不自动完成另一种。不可逆选择前以本人已知的人员处境、可用手段和未查明事项提供反馈；未知维持未知，不能用结局菜单替代现场执行。

替代方案在人员齐整时也可以调查、制作和使用，条件与成本不因人物死亡才凭空出现。机关优先按实际需要分清持续持载、触发一次、信号转发与实时校准；只有可以被装置保持的职能才可替代。单人操作不要求无限模拟精度，但须有从备料、安装到触发的完整时间账。

### 7. 意识回声与终局事实

源质场承载的印记可以持续响应新问题、形成新的记忆和偏好；本作以同一印记状态的连续更新作为场内意识延续的虚构规则。临床短暂唤醒前后的报告、只有在场者知道的新信息与重复观测提供玩家可核验的证据，单凭声纹相似或一次脑电读数不完成此判断。仍存活的木僵者、肉身已死而场内印记尚存者、已无法恢复的残片分别记录，不能把所有死亡与所有梦境影像都归成同一种“尚可救回”。

意识场依赖岛屿的地热、地磁与源质条件；活体连接还依赖宿主真实的代谢、照护和可维持的神经活动。删除“热力学必然推出以活人脑干为燃料”的论证，不能用生物负熵一词跳过供能、连接与消耗条件。失去维持条件会使回声衰减、固着或消散，“永恒重逢”不作为恶魔可无条件承诺的客观回报。

完成封印会切断高阶源质耦合并使依赖开放源质场存在的回声失去维持；能否救回仍有身体的患者须以此前达到的脱耦与生命支持条件判定；封印的切断作用不能自动代替安全分离治疗。解封允许继续耦合，也使恶魔获得离岛条件，并使深属此岛者难以回到原来的肉身生活。玩家可以在已知事实与残留不确定性下权衡保留回声、照护活人及自身归属；不必把某种价值选择包装成物理真相，也不强求各结局具有相同吸引力。

### 8. 退场结果、人物评价与结局表现

| 《深渊代管者》 | 担保耗尽前，其余十五名同伴实际死亡或永久深度木僵，操作者取得对应印记并完成祭坛仪式 | 延续全员献祭与升格的既有条件；已安全离岛、未被取得的印记或仅暂时失能不能充数。是否被察觉、阻止或审判由此前真实证据与行动决定 |

同伴对低认知者的照顾可以来自共同劳动、善意、职责和既有关系；牺牲、霸凌、宽恕与驱逐均不得因某类角色人数占多数而统一生成。可保留沈鼎递汤、雀儿带路、霍铎邀人扶架、茉拉安置病患等具体日常，但前提是人物在场且有相应意愿与资源。也不因玩家采用不光彩手段便保证恶有恶报；没有人知道的越界可以未受公开追究，同时仍是实际发生过的知情或承诺损失。

音乐与画面服从实际人物名单、关系和处境。封印结局可使用主题的明亮解决；缺席者对应声部、空杯和遗物仅在相应事实发生时出现。归乡后的人际重逢依普通文书、地点和真实兑现展开；文书未兑现、本人选择不接受安排或仍有伙伴留岛时，同样保留这些结果。

### 9. 尚待细化的内容与实作边界

三至六章需进一步细化的项目包括：各研究院可达几何与声路；工业补水的压力和隔离关系；作物、燃料与医护劳动预算；联锁在不同人员组合下的具体安装和转场时间；病理、药剂与短暂唤醒的可观察条件；外部五方不同文件的证据层次与伯爵现况。既定记忆账目、契约效力、归乡难度与人物真实过错采用本次正文，不再同时保留相冲突的旧路线说明。

归乡验收首先核对已经成立的绑定：即使人物充分知情且全票同意，苏泠等已经深属此岛者是否仍必须经过真实的分离处置，处置是否确实改变场依赖，造成何种额外损失。然后才检查照护承接、研究窗口与人物愿否接受。不能把“归乡困难”退化成心智随机抽一张反对票，也不能把“没有打开名录库”当作清除起始绑定的凭据。若实际合法会话出现十六人无损归乡的反例，应保留事实并回查既定绑定、转移机制或代价遗漏；不得在结算末尾补人数开关、回填事故或取消已经有效的选择。异常提前部署须核对其使用了本局信息、合理试探还是无来源的未来事实，不能将高水平但诚实的行动随意改称操纵。

### 人物动机反事实的验收边界

CF-1/CF-2分别观察标准与低认知配置的实际答辩、取证、协作及后果；低认知配置若凭合法取证完成答辩，保留实际成功，不额外设置失败门槛；认知差异分别核对暗示采信、撤回、重演深度、规划分支及错误假说的实际评分来源，并区分证据支撑的作答与被拒后的答案穷举。CF-3/CF-4在甲丙丁区比较同一材料下的本人介入和答案被接受的范围。CF-5只改变苏泠开场当前房间，逐次核对声学传播时她实际所在的位置；这不改变昨夜事故史，也不保证她始终留在该房间。CF-6只改变本人私下行动收益倍率，比较实际资格、净收益评分和选择，不能以结果预置代替动机效应。CF-7核对片面真话、听者实际接收、本人选择和真实后果的关联。因果归因还须比较相同种子与同一真实前置状态下的单一干预：有无该话语，或有无该话语引起的效用、态度变化；只有对照中的行为差异才能支持相应因果结论。时间先后本身仅说明关联。CF-8分别核对既定绑定史、当下病程与场依赖、本人选择及其余存活者同意、实际脱耦和离岛执行。即使全票同意且已准备普通文书，完整绑定仍未解除时应保留无法归乡的真实原因；改变本人意愿不能直接改变绑定，失忆、缓冲、唤醒和封库也不能冒充脱耦。未实现的检查、治疗、承诺或退场阶段保留未知。
