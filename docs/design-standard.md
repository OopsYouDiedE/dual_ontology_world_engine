## 设计总纲

### 一、本游戏的核心

> **现实与认知二相。读：从人在现实中的行动，反推他心中的规则与事实。写：改变他心中的规则与事实，他在现实中的行动随之改变。恶魔只说真话，却能借此操纵人；玩家先学会读懂它，最终也拥有同样的力量，并且必须选择怎么用。**

引擎源自动物园规则怪谈：一条规则进了人心，人就照着去做，哪怕它是错的。全部取舍以这一句为标准。拆开是四根支柱，按优先级排列：

| 支柱 | 玩家实际在做什么 | 引擎为何不可替代 |
| :--- | :--- | :--- |
| **1. 读：信念重演** | 设定当时的处境与人心，引擎让每个人依自己的认知做出选择，留下痕迹，与现场对照 | Essence 经 `Observation.Observe` 按位置、声路与来源转成每个人不同的 Projection；`DecisionSystem` 依主观认知选择行动 |
| **2. 写：改变他人认知** | 立规则、告知、带人亲眼去看、教会某人一条规程、当众预判；对方依新的认知自行决定，现实随之改变 | 规则带接受状态（`Rule.Acceptance`），只约束接受它的人；请求与规则是否被接受由 `SocialSystem` 依信任判定；亲见（Perception）与转述（Testimony）分量不同 |
| **3. 真话之敌** | 恶魔的题、课、警告与许诺全部字面为真，却选择说什么、何时说、对谁说。玩家要逐字读它 | 恶魔受契约第 5 条约束不说谎；它的话作为 Testimony 进入听者的认知，并以 Corruption 来源放大听者的欲望 |
| **4. 记忆与欲望之价** | 取回记忆能得到确定的过去，代价是恶魔的钩；欲望让人更想取回 | Recall 是有来源的观察；钩与欲望权重是跨章节持久状态 |

**删除测试**：任何新案件或新系统，先问“去掉引擎的主观认知与决策，这一段还成立吗？”若玩家只靠排序事件、找唯一凶器或填对术语就能通过，它就不是本作的内容。

**每章硬性要求**：
1. 既有“读”，也有“写”。第一章以读为主，以同伴是否触物回忆作为第一次“写”；第二章起“写”成为主体。
2. 恶魔至少有一句字面为真、却诱导出错误前提的话，并且可被物证识破。
3. 至少一处选择让“想要”与“该做”冲突（欲望与钩）。
4. 人物的习惯规则跨章节保持一致；后续章节必须让玩家能用前一章学到的人物认识去预判。

### 二、循环

| 层级 | 循环 | 首次出现 |
| :--- | :--- | :--- |
| 案件（约 30 分钟） | 恶魔出题 → 现场检视 → 现场试验 → 信念重演 → 按冲突补查 → 答辩 | 第一章 |
| 一日 | 清晨 → 上午 → 午间配给 → 下午 → 傍晚对账 → 夜里十六人自主行动（引擎推演）→ 次日清晨的痕迹；读不耗时，写一次过一阵（总纲 §四） | 第二章 |
| 长线 | 担保倒计时下：修复设施、学习、取回记忆、查明真名与封印机制、准备材料，封印恶魔；或被引诱放了它；或担保耗尽被放逐 | 第二章起铺垫 |

### 三、旧版诊断与禁止回退项

| 旧版问题 | 本版规定 |
| :--- | :--- |
| 案件像流程审计（排灰扳柄、滤布层次、双槽归还匣） | 案件围绕有情感重量的选择 |
| 16 项证物包、术语密集 | 每案证物 ≤ 12 件，一眼能看懂 |
| 推演是排事件、分岗位 | 推演变量是处境与人心，行动由引擎推出 |
| 答辩九字段表格，选项可一眼排除 | 答辩是对质：陈述与出示成对，有效证物允许多种 |
| 检视页和同伴替玩家下结论 | 检视只写看见了什么；同伴只报告感知与职业判读 |
| 推演入口藏在计数门槛后 | 入口随第一次关键发现开放；未查之处只提示地点 |
| 内部错误码外露、装饰物看似可点 | 玩家可见文本全为自然语言；可交互物件统一高亮 |

继续有效的交互规约：普通对白一次空格或 Enter 推进；新点击立即替换旧路径；台词按玩家已取得的材料分支；失败保留已填内容；回放可跳过，跳过与看完结算相同。


### 四、两章共用的玩法规约（2026-10-04 统一）

第二章原先是“文字原型套上地图”：动作菜单、命令行、滚动日志、每做一件事都占一个时段，人物按时段瞬移。它与第一章的玩法是两套东西。本节把两章合成一套语法：**操作一样、读写的划分一样、人物的驱动方式一样、案件的循环一样**。后续章节同样遵守本节；章节只增加内容，不另起一套操作。

**1. 操作（两章完全一致）**

| 输入 | 作用 |
| :--- | :--- |
| 鼠标点击 / WASD | 走动；点可交互的物件或人，一律走过去并打开；站在够得着处再点，直接打开 |
| 悬停 | 只描鼠标所指的那一件，显示名称；点到普通家具只给一句极短心声，同一件只说一次 |
| E / 空格 / Enter | 检视身边的物件，或与身边的人交谈 |
| M（仅多处地图的章节） | 学园图：只画去过或听说过的地方，点一处直接去（走路不过时辰） |
| Tab | 笔记本：证物（按地点）、规矩、人、回忆所得 |
| R | 重演手稿（第一次看见案件的关键痕迹后开放） |
| 对白 | 空格推进；H 回看；已问过的选项变灰 |
| Esc | 合上当前的卡片或手稿 |
| T（仅多日章节） | 让这一阵过去，进入下一个时段 |

不设命令行、动作菜单与滚动文字日志。一切结果以画面、对白、证物卡与心声到达玩家。

**2. 读与写**

- **读不耗时**：检视物件、做现场试验、问人知道什么、请在场的人辨认、读公告、看笔记、重演。
- **写要付代价**：凡是想改变别人心里的规则与事实——请他亲眼去看、把一条规矩讲给他听、请他做一件事、兑现答应他的事、当众对质——对方都依自己的认知自行决定接受、提条件或拒绝（`SocialSystem`、规则接受判定），并当场用他自己的话回应。
- **代价是时机**：第一章覆盖始业清晨至午间，写的代价是“他伸手之前，你必须在场”；第二章是多日，写一次就过去一阵（进入下一个时段），读多少都不过时辰。
- 规矩不在格子里拼。玩家能讲的规矩，是他读过的板上规矩与案件推到眼前的几种具体写法；选哪一种，就是玩家的立场。

**3. 人物驱动（两章一致）**

- 每个人有自己的习惯、欲望与认下的规矩（Core `Rule`），自己决定去哪里、做什么（`DecisionSystem`）；别人的请求由他的 `SocialSystem` 判定。玩家从不替任何人决定“做了什么”。
- 恶魔对某人说一句放大欲望的真话，此人自己决定是否去做。侦探在场，可以出声、讲明代价或任其自便；不在场，后果只以痕迹、他事后的神色与他的话到达侦探。
- **在场即可见**：与侦探同处一处的人，其动作落在地图上（走位、动作帧、头顶一句短句）；不在场的只留痕迹与转述。
- 同伴只报告感知与职业判读，不替玩家下结论。
- **第一章晨间生态（2026-10-06）**：十六人的画像、地点、词汇与日常统一由 `chapter_01.story` 声明；原第二章的物件、交互、候选、案件及所有场面已完整并入同一文件的 `续篇 chapter2` 作用域；不再保留第二份作者源。第一章 `roam`、`investigate` 时，三位同伴在乙区按核查、操作、收尾的有序日常行动；另十二人在甲、丙、丁区自主排查和做工。门厅只能获得模糊声响，不据此获知人物身份或门外因果。动作与时长都由 story 配置，现场协助、交谈、回放与答辩占用人物时让日常暂停；不得拿取案件旧物或改动原证物。晨间行动时间与剧情行动、昨夜重演隔离，原六变量、四步判定与唯一真相不变。
- **侦探控制（用户明确，2026-10-06）**：侦探也是同一世界中的居民。测试时与其余十五人一样，由自身认知中的规则经 `DecisionSystem` 选择日常行动；玩家游玩时接管其决策。控制切换只停止或恢复侦探的自动日常，不替换身体、灵魂、位置或认知，也不重置其他人的行动。侦探的晨间习惯在 story 声明；模拟不预置案件答案，不把自动日常当作破案或玩家通关。测试轨迹无需真实窗口，逻辑到场代报须明示未验证宿主几何。

- **默认剧情与日常衔接（2026-10-06）**：统一第一章沿原醒来、相遇、报偿核验、始业题面、调查、重演、答辩及收尾推进。日常开放阶段与人物许可在 story 声明；三位同伴早于侦探醒来，先互相介绍并完成初查；侦探随后会合，报偿核验结束进入调查后才开始职业操作循环。对白、场面与回放取得人物占用，不能被日常或邀请路径抢走；终局门前集结在 story 调度。模拟侦探走进活动厅同样触发正式相遇，不用测试直接设阶段或补造通关。
- **完整测试轨迹（用户明确，2026-10-06）**：以合并后的第一章为模拟对象，所有人物的实际行动、公共事件与玩家接管按发生顺序合并为一份可读文本，不按侦探和居民拆成不同文件，完整场景测试包含同一作者文件内生活翼及始业后续场景，必须通过本轮真实会话交接；不得以独立创建旧第二章标准会话代替生活翼结果。轨迹的全局观察记录不授予玩家或模拟侦探额外知识。
- **第一天的因果与游戏钟（用户明确，2026-10-06）**：侦探晚醒，三位同伴已认过姓名、检查铜口与门边等现场，随后向侦探交代初查范围；不得提前确认昨夜的因果。四人共同核验负责人和报偿后继续深查，凭更完整的声路、物证、信念重演与始业论证才出门，所以比其他寝区晚数十分钟。剧情约占半天游戏时间，实际场面与行动在 story 声明分钟；开门不设最低时刻，也不用等待、错误答案或重复劳动凑时长。其他寝区的外出由自身已知条件、目标与行动结果推动，story声明约束及行动时长，不能用指定时刻替人物决定；未展示的调查不补称已经破案。
- **个人歇息（用户明确，2026-10-06）**：题面或铜口处选择歇息，只表示侦探暂时休息，不是全组去留决定，也不是章节结局。三名同伴继续各自行动，调查与原答辩保持可用；不得保存全组退场状态或退出游戏。
- **主观多步推演（2026-10-06）**：模拟侦探以蒙特卡洛树搜索进行选择、扩展、多步采样和回传。候选解释与动机是主观模型，真实检视、实际试验和已执行重演的公开反馈才更新认知；未来采样不得改真实人物或世界，不读取隐藏真值或答辩判定来找答案。玩家接管时由玩家决定调查与提交论证，原隔离门六变量、唯一真相及四步判定保持原样。
- **陌生环境下的自主认知（用户修正，2026-10-06）**：世界的客观历史与人物认为身处新环境的主观认识分开；封存记忆不等于删除职业技能、习惯和身体熟悉感，也不授予房间用途、资源可用性、他人可信度或未来事件的全知知识。人物依据已观察的处境、身体状态、保留的欲望与自身接受的规则，在确认环境、求助交涉、保障需求、追求目标等行动间产生竞争；新观察、他人回应和实际后果能中断或改变计划。Story声明事实、初始认知、目标、规则和行动条件，不用日常索引或指定出门时刻代替人物决定。多步搜索评估主观状态与行动后果，实际变化由同一引擎的观察、决策、社会交互及行动结算产生；不能以固定案件候选消减或剧情进度奖励覆盖人物的完整决策。既有日常索引循环与案件专用MCTS轨迹未满足这一要求，不作为自主推演验收通过。
- **以命运约束行为（用户明确，2026-10-06）**：绝大部分内容由引擎依据人物与世界的因果关系驱动。“命运”来自既有经历及其痕迹、人物所知或所信、身体与精神状态、欲望、关系、承诺、物资与环境机制，以及前次行动的后果；作者在story声明这些初始条件、规则和可行行动。“天意爷”式控制指为了剧情节点而直接指定人物的选择、无来源地改其认知、忽略拒绝或冲突、按时刻强制其退场。剧情呈现和已确立的历史事实可以由作者创作，但当前人物决定须有自身理由及可追溯的因果链；保留隔离门的独立确定性基准不意味着给晨间居民写固定行为队列。
- **动机合理性独立验收（用户明确，2026-10-06）**：编译运行、机制结算、人物行为合理性与游玩体验分别给出结论，任一项通过不代表全部通过。关键行为须核对当时人物知道或相信什么、相关身体需求和欲望、他接受的规则与关系、可行替代行为、预期收益及风险、为何此时选择该行动，以及结果怎样改变后续计划。理由必须与行动发生前的实际认知和决策依据相符，不用事后对白或搜索分数补造动机。对拒绝、退让、坚持、误判及计划中断也按同一标准分析；陌生环境下不能只凭职业标签合理化开工。改变与决定有关的认知或处境时，模型应能产生可解释的决策影响；相同选择也须解释其稳定理由，不能为了表现差异强制改动作。每轮独立文学与合理性Agent只读取本轮轨迹及运行输出，不接触设计、源码、预定答案或旧轮结论；主代理另核对源码中的真实因果依据。报告按人物和关键决策给出证据、问题与未验证项，不能以通关、无异常、事件数量或调用DecisionSystem宣布全部验收通过。

### 五、引擎驱动的整体方向（2026-10-06，用户提出方向，主代理定取舍）

本节是之后全部实施的上位规约。一句话：**story 只声明世界的初始状态、法则与人物认知；剧情由引擎按因果推出。** 十六人同时破案、玩家做出非常规动作后剧情仍能圆回、任选一人游玩、防背板，都是这一条的推论。现有实现中与本节冲突之处（固定出门分钟、按时刻张贴规矩与固定节点、晨间日常索引循环、按剧情进度分支的对白、写死的声路结果表与证物编号判定）按本节第 11 条分期替换；替换完成前，现行实现不作为本节验收通过。

**1. 一部连续剧情，第一章十六人四案（用户明确）**

- 两章合为同一部连续剧情、同一世界时间线；章节只是叙事分段，世界与人物沿用同一批运行对象。章节之间可以跳时，跳过的时段按低精度推演结算（见第 12 条“模拟精度分级”），不重建世界、不改写人物认知。
- 第一章四个寝区同时各破一案，与生活翼同构：作者写当夜的初始条件（谁在哪、听到哪条规则、信谁），由信念重演把当夜跑一遍生成现场痕迹；各组有自己的题、推演变量与判定。题、字面正确的答案、留下的错误推论与真相以第三部分 §2 的表为准。
- 另外三组的结论由他们自己推出：错误推论须有因果来源，即关键证物不在本组可及范围内（如红墨批注在名录库），叠加人物自身成见。各组何时答完、何时出门由推理进度决定，不写出门分钟。
- 验收：默认种子下三组的答案与推论和 §2 一致，且每条推论能追溯到此人看见了什么、没看见什么、信谁；换种子或玩家介入时结果随之改变。§2 的表是默认种子的目标，不是不可改的结果；若推演显示另一种推论更合乎人物，改表并记裁定，不为对上表而改人物。
- 三组案件可先以低精度推演运行（只产生结论、痕迹与人物认知，不配齐玩家用的证物卡与答辩），在其寝区成为可选开局前补齐。

**2. 时间分层：过去定，现在藏，未来活**

| 层 | 内容 | 是否固定 |
| :--- | :--- | :--- |
| 过去 | 作者写的历史（第一章当夜、三组裂痕、长线谜底） | 开局即定，可以精雕细琢 |
| 现在 | 每人心智：欲望强度、信任、成见的细微取值、私下记忆 | 每局开局在 story 声明的范围内隐藏抽取；范围可以为单一值（即固定）。抽取只在开局做一次，此后随事件正常变化，不重抽 |
| 未来 | 人物的行动 | 由心智与玩家的扰动推出 |

玩家不能成为“天意爷”：背下场上物件，也不能预知所有人的未来动作。手段如下：
1. **隐藏心智抽样**：人物性格不走样，但先做什么、对谁让步、在哪里动摇每局不同；局内一致，所以“读人”学得会，跨局背不了。
2. **人物会推测玩家的意图**：玩家的举动本身就是别人的证据，越操纵越偏离背过的路线。
3. **代管者是会适应的对手**：它是有目标、能看见公开事件的角色，针对玩家依赖的人低语，布局被拆就换。它每一步都有自身理由，不属于“天意爷”。
4. **论证只凭角色自己的认知**：作答、指控、劝说、告知所引用的依据必须是这个角色亲见亲闻；玩家知道答案而角色没见过证据时，说不出口，也无人会信。由 Core“只读本人认知”强制。走动、翻找、开门等身体动作不要求事先知道结果，玩家照样可以凭直觉去翻某个抽屉——背板省下的只是“往哪儿看”。
5. **固定的是制度，不是人的选择**：钟点、配给、守则、代管者宣布的议会可按时发生，用作剧情骨架的压力；谁去、站哪边、夜里谁去哪里由人物自己决定。作者写的演出（开场、转折处的镜头与旁白、仪式性场面）可以固定，只要不替人物做当前的决定。

**3. 推理的五类与预演**

| 类型 | 推什么 | 真相来源 | 能否背板 |
| :--- | :--- | :--- | :--- |
| 作者写的过去 | 开局前已发生的事 | 作者手写 | 能背答案，拿不出证明 |
| 游戏中的过去 | 昨夜谁做了什么、为何 | 夜间模拟 | 不能 |
| 现在的隐情 | 谁信谁、谁被钩、谁说谎、谁站哪边 | 隐藏心智 | 不能 |
| 未来 | 今夜谁会去名录库、议会上谁改票 | 心智与玩家扰动 | 不能 |
| 规则 | 写了什么、没写什么、漏洞 | 守则与学员立的规 | 能背条文，局面在变 |

- 教师的课教方法，用于其余各类，本身不是案件。
- **预演**：信念重演向前用。玩家设定对各人心思的猜测，看他们接下来会怎么做。预演只用玩家的猜测，不读真实心智，猜错则预演错，不构成预言机。何时开放、能推多远、是否随技能变化，按章节与平衡另行决定；第一章不要求提供。
- 判定：前两类有标准答案，经答辩或对质，引用的证据须在角色认知中；后两类无标准答案，看结果（私占是否被拦下、规矩是否被认、人是否保住）。
- 游戏中的过去，凡作为主案提出的问题须保证可破：每个动作按痕迹法则留痕（脚印、台账、饼屑、目击）；出题者（代管者，或如沃德那样起冲突的人物）从当夜可判定的命题中挑一个合乎其目的的公开发问，由求解器确认凭现有痕迹可解。主案之外的事件允许无解，像真实生活一样留作悬案。
- 各章比重：第一章以作者写的过去为主（新手与精品案）；第二章以游戏中的过去为主案，三组裂痕为可选支线，议会收尾于未来类；之后各章逐步以现在与未来类的博弈为主，作者写的过去只作贯穿长线。

| :--- | :--- | :--- |

**5. 全员推理与回应**

- 原侦探的推理（假设集、证据、来源可信度、重演）下放为 Core 通用推理器，每人一份，只读本人认知。侦探的搜索深度最高，其余人用低成本的信念更新；推理深度是技能参数。
- 对白不再按全局剧情进度分支（如 `talk_huo` 的“已吻合／已重演”），改为**话题 × 认知 × 态度 × 目的**。条件只要能写成说话人自己的认知、关系或状态即可：说话人亲眼看过重演，“已重演”就是他的认知，可以作条件；他没在场，就不能用。作者写的场面对白照样手写，只是条件按此改写。具体做法：话题挂在 Core 命题上；说话人依自己对命题的信念与把握、对听者的信任或敌意、自身目的，选一种言语行为（如实告知、含糊、隐瞒、撒谎、拒绝、反问），再取此人对应该言语行为的台词。相同问题因已知与关系不同而得到不同回应。
- 听者依信任决定是否认下（第二章“认了／没认”的推广）。第二章 24 条模板化回应改为通用言语行为规则加每人口吻。

**6. 剧情韧性：非常规动作与地图改动后能圆回**

- **story 优先写法则，不写结果**：声路由管道拓扑与接头状态实时计算；房间、相邻与视线从地图数据推导。尚未建模的部分可暂用声明的结果，但须写明它成立的前提（如“接头松动且门关着”）；前提被破坏时引擎报告并改用法则或拒绝该结果，不静默沿用。
- **判定看命题是否被支撑**：每问对应一个命题，本局世界中确实支撑它的任何证物、证言或回忆都算，不限定证物编号。
- **剧情节拍 = 目标状态 + 多条可行路径**；路径全断时，由世界中本有目标的角色补救（代管者要的是有人作答，可以换问法或接受另一类证据），不由作者直接改人物的选择或认知。
- **混沌测试**：随机代理做非常规操作（搬走物件、拒绝交谈、不出房、改管路），无窗口跑大量种子，检查三条：不卡死；能到达某一结局；每句台词可追溯到说话人的认知。在时间压力下停滞而走到的结局（如一直歇息、议会不了了之）也算结局，前提是世界照常运转且有理由。

- 开局任选十六人之一，玩家只得到此人的认知（§四.6）；技能是 Core 行动能力，感知可有差异（苏泠能听清句尾、莫兰速写可作证据、贝尔特朗夜巡）。每人有自己的欲望与胜利条件，其他人用同一推理器推测其意图。
- 选人界面默认只示外貌、职业与欲望，不示技能数值与人际关系；展示多少可按体验调整。
- 十六人不必同时开放：某人的开场、寝区案件与关键时刻写完并通过验收后，才列入可选；未开放者照常作为居民运行。
- 所选角色所在寝区的案件即其第一章主线；另外三组照样自行破案、出门，其错误推论成为后续筹码。
- **开场独白**：保留，缩短，每人一版。建议用共用骨架（醒来的感受、只记得上船、随身物），每人手写两三句本人独特的感知或习惯；句数与骨架可按人物调整（霍铎先摸到手上的老茧、苏泠先听见墙里的低鸣、雀儿先查门闩、沃德先找纸笔）；现有 `s1_wake` 为侦探版。独白只写此刻能感知的东西，不为未来剧情铺垫。日常心声由认知加编号片段生成，只为每人手写关键时刻。
- 侦探仍为默认视角；侦探入约动机保持留白（AGENTS.md）。

**8. 防背板与精巧案件**

- 骨架手写，取值生成，求解器把关：作者写案件模板，保留核心转折；具体取值（谁听见、哪个接头漏、说的哪句、谁信谁、痕迹落在哪件物件上）从受约束的空间抽取。
- 以 `ReplayCheck` 的穷举唯一性检查为基础升级为生成校验：解唯一；每条线索都会用到；任一线索不能单独定案；至少一次看似可信的初始假设被推翻；最短推理路径不少于设定步数。
- 第一局固定使用作者打磨的默认种子；之后的局改换取值。答辩只认本局世界里真实存在的支撑；换角色本身也改变可得信息。

**9. story 语言：可拆分与台词编号**

- **可拆分**（按 Python 的顺序语义）：`引入：<相对路径或通配>` 把片段文件的全部顶层语句就地展开，按序引入与写在同一文件等价；实体须先声明后使用，场面、流程之间的 `跳转`／`继续` 可前向引用。片段不能声明章节或前置章节；同名 `续篇` 再次出现即续写同一作用域，前置章节只写在第一次。同名的表类块（如协助说明、家具旁白）再次出现即接续同一张表，重复的键报错；只能有一处的块（阶段、判定、场面、声路、话语、推演变量等）重复即报错。报错指向片段文件本身的行号。验收：在任意顶层语句边界（含续篇内部）切分后按序引入，生成物除源位置映射外与整份编译相同（`tools/check/test_story_split.py`）。
- **时长单位**：story 中的时长须带明确单位，缺省为游戏分钟；动画一类短时可写秒。编译器统一换算到逻辑秒（按“每游戏分钟日常逻辑秒”）。晨间日常现在把无单位的数当逻辑秒读取，实际耗时约为声明的两倍除以速度，须改正。
- **台词编号**：每句作者台词与选项文字带稳定编号标签（如 `[#id=s4_rewards.003]`，续篇加章节前缀如 `chapter2.lesson.002`），与情绪标签顺序不限；缺编号时编译失败，`compile_story.py --assign-ids` 按场面续号写回源文件，已有编号永不改动、永不复用；含占位符的句子使用 ICU 消息格式，人物档案增加性别／称谓字段，宿主据此生成代词（修复“他话不多”一类对女性人物的误用）；程序拼接的传闻、转述与站队由带编号的片段加参数组合，不拼中文字符串；以中文为源语言导出（格式按所用翻译工具定，如 .po 或 .csv）；现由编译器生成 `godot_csharp/scenes/Awakening/Script/generated_lines_zh.csv`（编号、场面、说话人、中文）。放大、低语等效果行里重复出现的片段，以及宿主程序拼出的句子，尚未编号。编号同时用于测试追溯台词的触发原因。

**10. 修罗线：知识门槛，与修罗线循环**

- 修罗线做得非常难，难在须跨局积累的知识，而非背一串固定操作：现在与未来不固定，不存在可背的操作序列；能积累的是固定层——契约条文的漏洞、每人性格的范围与弱点所在、方法库的手段、代管者的反应方式。老玩家知道去哪里找、先对谁下手，新玩家在局内摸索来不及。
- 难度自然产生：十五人都有推理能力并推测侦探意图，操纵累积猜忌，被揭穿即崩；叠加担保倒计时的时间压力。不靠让人物变蠢或变狠制造难度（第一部分 §5 修罗线情绪冲击的要求不变）。
- 第一次玩的人也能进入修罗线并失败得有意义；失败结局须有内容，于第三章设计时补齐。
- **修罗线循环（用户明确）**：升格后玩家成为恶魔，同样出不了岛；岛依被献祭者的印记复制出十五名新学员，玩家与自己杀死的十五个人一同生活下去。循环在故事内为多周目给出说法；以恶魔一方开局的可玩形态在第三章设计。
- 修罗线仍不进入第一、二章正文（第七部分 §1）。

#### 1.1 岛屿与学园布局（2026-10-04 用户确认）

**岛屿**：以科尔沃岛（Corvo，亚速尔群岛）的真实地形为蓝本，高程数据为 Copernicus DEM GLO-30，**水平与高程同比缩为 0.5 倍**（用户要求压缩岛屿，使岛的尺度与十六人的处境相称；等比缩放使坡度不变，选址与基底验算仍成立）。缩放后约 1.9×3.2 km，陆地约 4.2 km²；中央一座火山，火口直径约 1 km，底有湖与湖中小岛；全岛最高点约 351 m，在火口西南缘；四周几乎全是海崖，只有南端一块熔岩台地低平（海拔 20 m 以下约 14 ha）。缩比试算：0.3 倍时台地放不下学园；0.4 倍时基底高差达 6.8 m；0.5 倍时基底造价约为真实尺度的 1.45 倍，取 0.5。剧中岛名、地名为虚构；现实中台地上的村落与机场跑道在剧中不存在。

#### 1.2 为何不是一栋楼

**玩家可知的理由**（由人物依职业说出，不安排旁白）：

**为何单层为主**：孤岛建房，材料靠船运，现成的是火山石；岛上少有懂结构的工匠；坡地会震；动力断后楼梯是唯一的上下通道，水粮要人扛。单层只需承重墙与屋架，基础浅、可分期加建、每间有窗、着火地震推门即出。现实中乡村学校普遍单层，原因相同（世界银行减灾机构 GFDRR 的农村校舍安全指南即以单层为对象）。中央厅、共鸣厅等少数高大建筑是例外，各有功能理由；“例外之多、造价之高”可作作者侧暗示。

**作者侧理由**（第一、二章不揭示）：四座研究院压在地下四锚封印廊之上，中央厅压在中央基座之上；学园的平面就是封印的几何。四院到中央厅等距，不随地形调整，这是全学园唯一不顺坡的布置。是否在第二章由玛格丽特点出这一反常、作为疑点只供察觉不予解答，待用户确认（第七部分 §2）。

**玩法与美术理由**（只写在本文件）：32px 俯视画面读不出楼层叠放，平铺院落一屏可见路线；夜间痕迹（露水、泥地）与守夜视线需要开阔地面；院与院的距离就是时段成本；地盘按栋划分最清楚，逐章开放按“开哪一栋、哪一角”最易读。弹丸论破可用一栋多层，是因为它为第一人称、不计步行时间、不读室外痕迹，本作三项都不同。

### 2. 恶魔

**身份**：岛上源质留存的认知印记聚合体。外显为约三十岁的黑衣绅士，琥珀竖瞳，手形修长窄薄（掌宽明显小于常人），穿窄底外交官皮鞋，外交官式礼节。原型是伊甸之蛇：递出的苹果同时是知识与欲望。

**不自报身份（用户裁定，2026-10-03）**：开场它只说自己是“此地的代管者，也是诸位的教师”，不说自己是什么，不提导师，不提契约。活动厅公告框贴的是它自己所立的“学园守则”（第 5 条要求它公开的只是它自己立的规），不是导师所立的契约。至少第一、二章不揭开：它的身份、导师为封印而死、契约内容、学员在岛上住了多久。它同样不说明：它的真名、它在对每个人做什么。玩家对它的认识只能从它的言行与物证中读出。

**学园守则（公告框，主代理裁定措辞）**：
1. 封存之物，可凭对应之物寻回；寻回者，自负其果。
2. 饮水、炉火、照明照常供给；物资由诸位自行分配。
3. 外闩所封之处，余患未清，清后即启。
4. 我所立之规，皆张贴于此。

每条都对应契约中它须履行或已获准的事（第 8、3、7、5 条），但只以它自己的规呈现。

**两个原动力**：
1. **传授**：它真心想教，会为精确的答案由衷高兴，也会在学生遇险时出手相救（须先显形）。
2. **放大欲望**：它说的每一句真话都朝向听者最想要的东西。它不撒谎，只是让人更想要。引擎中以 Corruption 来源的观察提高听者“核心欲望”相关规则的决策权重；回放的心声气泡要让玩家看见某人被欲望推着走。

**虚实二态**：平时无实体，可穿墙，但无实体时不能触碰任何物件。移物、开门、写字、板书都须显形；显形时服从常规物理，留下指痕、粉笔字迹与窄底鞋印。

**说话方式**：从不说谎；只并置真实片段，并决定说什么、何时说、对谁说。被识破时坦然承认，并坚持“我字面上没有说错”。

**授课**：见第三部分 §5.8。

### 3. 胜负条件与退场规则

#### 3.1 封印与契约是两层

| 层 | 作用 | 维持者 | 会不会失效 |
| :--- | :--- | :--- | :--- |
| 四锚封印 | 把恶魔困在岛上 | 导师遗存（如塞莱斯蒂娜石化成的中央基座） | 事故中受损未破，仍能困住它；学员完成封印即彻底封住它 |
| 契约 | 规定恶魔与学员的关系 | 四位导师以性命构成的担保 | 担保随时间衰减 |

#### 3.2 契约条款

**甲 · 成立条件**
1. 恶魔常驻岛内，不得离岛。
2. 经学员本人授权，恶魔封存其在校记忆（在校经历、师生与同学关系、事故全貌）；姓名、生平与入学前技艺不在封存之列。

**乙 · 恶魔对价**
3. 恶魔维持学园基础生存设施的运转（水、炉火、照明的设施本身；不负责分配物资，不创造物资）。
4. 恶魔所受约束，唯有学员出于自主的行动方可解除；恶魔不得代为或强迫学员完成解除。（条文没有禁止“诱导”，这是导师仓促立约留下的缺口，恶魔以放大欲望利用它。）
5. 恶魔须公开它自己所立之规；规则许诺的路径必须真实可行。
6. 恶魔须传授学员理解处境与继续学习所需之知；学员自负其选择的后果。

**丙 · 导师所留**
7. 恶魔不得伤害学员身心，不得拘禁学员，不得令学员因无知而死。
8. 封存的记忆可凭对应之物恢复；恢复即重新接通（钩），后果自负。
9. 经其余十五名学员一致同意，或封印已无法完成时，学员可择定“尽忘归乡”，于下一次入睡时遗忘此地一切、在家乡醒来。
10. （终局）担保耗尽，或封印的必需之物永久失去时，契约以放逐终结：恶魔抹去全体在岛学员与此地有关的一切记忆，保其安全返乡。

**第 9 条的保密规则（用户裁定）**：恶魔**绝不主动说出**第 9 条。它不在课上讲、不在广播里提、不借暗示引向它。理由在契约内成立：第 9 条是导师所立，不属第 5 条“它自己所立之规”；第 6 条的“所需之知”由它判断。契约全文刻在港口上岸处的石碑上，第 9、10 条风化严重，须拓印辨读；港路塌方，第一、二章不可到达（第三部分 §3.4）。若学员精确地问“第九条写的是什么”，它只能照字面如实回答，但它从不先提。

#### 3.3 结局与双方动机

| 结局 | 条件 | 学员 | 恶魔 |
| :--- | :--- | :--- | :--- |
| 学员胜 | 完成封印：真名、封印机制、封印材料 | 带着恢复的记忆与学到的知识离岛 | 被彻底封住 |
| 恶魔胜 | 学员出于自主的行动解开它的封印 | 视情形而定 | 自由，可离岛 |
| 两败：放逐 | 第 10 条：担保耗尽或封印之路永久断绝 | 遗忘此地，安全返乡，入学所求也一并失去 | 仍困岛上，失去全部学员，只能等下一批人 |

- **恶魔为何签下第 10 条**：事故当夜封印受损，但恶魔没有赢，导师仍能以全体师生为代价强行封印。契约是和解：恶魔得到学员和唯一的出路（第 4 条），付出的代价是第 7 条与第 10 条。
- **它为何真心教书**：学员太弱只会走向放逐，它也失去机会。它必须把学员教到能放了它的程度，而同样的知识也足以封了它。剩下的取决于学员想要什么，所以它放大欲望。
- **为何抹去一切记忆**：记忆就是钩，是恶魔够到人的通道。抹去是隔离，不是惩罚。
- **谁判定“无法获胜”**：只能是客观条件（担保耗尽、真名或封印材料灭失），恶魔不能宣布；第 5 条又使它不能破坏学员获胜的路。
- **担保是双方共同的倒计时**：通过导师遗存的可见变化呈现（基座裂纹、广播底噪），不显示精确数字。

#### 3.4 章节内的退场
- 第一章：恶魔说明去留后，末位选项“不作答，在生活翼歇息”。无需认罪或指认任何人，基本水食照常；选择后只有侦探短暂独自休息，随后可继续调查，三位同伴照常行动；不据此结束章节。
- 侦探的入约动机保持留白：问起时，恶魔只答“你所求之物，在你封存的东西里”。

### 4. 记忆、钩与欲望

- 封存不碰技艺与身体习惯。人物会不知为何地做出熟练动作，这是活线索。

#### 5.4 美术风格

**总基调**：人物比例与立绘画法参考《重返未来：1999》的实际角色原画：清楚的二维轮廓、经过提炼的五官、富于表情的眼神、成组的发束、柔和的绘画色面与有节奏的衣料形状。年龄与体形分别设计，不给全员套用一个头身比或一张脸。衣着参考《光与影：33号远征队》等游戏的复古剪裁、层次与轮廓，保留各人的职业私服与文化出身，允许大胆的服装风格差异。

**人物识别**：每人须有独立的脸型、五官结构、眼形与眼色、发型与打理习惯、身高体形及姿态。统一绘画语言，不统一人物的审美与精神状态。侦探外表约27岁，深棕短发，东方与东欧骨相交融，沉静警觉且可以亲近；他与男女角色同框时都应有自然的交流感。广泛吸引力是设计目标，不宣称已取得最高受众接受度。

**服饰纹理**：强化具有身份意义的衣料织纹、刺绣、镶边、印花及文化图案；弱化脏污、磨痕和密集褶皱，纹样与衣料色面须清楚可读。长短、宽窄、领口、闭合方式、层次、布料体积和剪裁须按人设计，避免全员外套、马甲、长裤的重复模板。纹样同样按人分配，不把同款菱形金边或植物刺绣铺满全员；朴素工装也可用帆布织纹、接缝和局部织带建立识别。

### 2. 恶魔的开场与题面

开场广播（每句字面为真）：

> 诸位晨安。我是此地的代管者，也是诸位的教师。诸位所需之知，我会教。
> 记忆有缺，乃履约之初的规则界限，请勿惊惶。
> 昨夜警铃骤起。主楼曾有人向诸位呼喊。
> 通往主楼之门，在诸位这一侧闩上了。那人再没有回来。
> 此为始业之问：**门是谁闩上的？闩门之时，此人可曾听见门外的呼喊？**

开场之后，活动厅公告框上可读到恶魔自立的“学园守则”四条（第一部分 §2）。契约不公开，恶魔不提契约，更不提第 9、10 条。

原“初涉斯地”在作者侧真相下是假话，已删除；不设替换句（用户裁定，2026-10-04）。“昨天才到、彼此素不相识”的误解由四人今晨的初见自然形成，不由恶魔的话引出。

| 句子 | 字面为何是真的 | 容易补出的错误前提 |
| :--- | :--- | :--- |
| 主楼曾有人向诸位呼喊 | 格雷厄姆确实从主楼喊话 | 有人在门外求救 |
| 门闩上了；那人再没有回来 | 侦探闩的门；格雷厄姆没回来 | 闩门导致那人没回来 |
| 闩门之人可曾听见门外的呼喊 | 问句，不是断言 | 门外确有呼喊 |

恶魔的用意：观察四人会不会互相指认；鼓励触物回忆（每次回忆给它一枚钩）；放大四人的欲望（报偿核验时逐一点到他们想要的东西）；守住“诸位已在此共同生活一段时日”的秘密（第一章的物证只证明“早已相识、不是昨天才到”，不能断定住了多久），被物证识破时必须承认。

**心声气泡要露出决策依据**，用自然语言，不显示数值：例如“霍铎说上头下令闩门……我认得他的字，我信他”，或“我凭什么信一个昨天才认识的人？我得自己去看”。

#### 4.3 对照与回放

- 吻合／冲突（写出具体差异）／你还没查过这里（只给地点）。
- 在真实地图上以半透明墨影重演，每人头顶心声气泡；同一时刻四种认知并排出现。可暂停、倍速、跳过。
- 重演在第一次看到闩上的门（检视 E1 或 E3）后开放。

#### 4.4 解空间

216 种组合中只有一种全部吻合：V1 R-08，V2 活动厅铜口旁，V3 铜口，V4 “闩门，别开”，V5 霍铎，V6 早已相熟。每个错误值至少被一件证物否定（第一版实现已用穷举确认；修订后须复测，且不得依赖行动值调参）。杯子、酵种罐、无尘方框对唯一解非必需，它们在答辩第 4、5 步与第二次反转中作旁证，保留。

### 10. 第二次独立盲玩（ch1-r2-01）与第四轮修订

**结果**：独立通关，7.5/10；四处回忆全部拒绝，结局“钩：无”。“是我闩的门”“门外无人”为自推；“早已相熟”先自疑，但被重演面板上现成的“早已相熟”按钮提前点破。主要扣分：重演与答辩像半个答案机；点击交互仍不一致；测试者感觉不到自己影响了谁——同伴只在玩家请求时才会去碰旧物，玩家不开口，同伴便毫无动作。

**第四轮修订（主代理裁定）**：
1. **同伴自己会去碰（涌现）**：恶魔对某同伴低语之后，此人会在调查中自己走向其物件并伸手（霍铎拿起石板、苏泠蹲向音叉、沈鼎端起酵种罐），是否真的碰仍由其认知决定。侦探在场时可以出声劝阻、说明第 8 条或任其自便；不在场时，后果只以痕迹和他事后的神色到达侦探（回来时他会说“我想起了一点”）。玩家不作为也有后果。
2. **V6 不再预先出现**：重演面板起初只有 V1—V5，四人“素不相识”是不写出来的默认。当重演中侦探因信任不足拒绝转述（“我凭什么信一个昨天才认识的人？”），或玩家已细看两件以上相熟旁证（杯子、酵种罐、无尘方框、放大镜小图）后，面板才出现第六个问题“昨夜之前，四人彼此……”。转折的问题由玩家的发现或重演本身提出。
3. **冲突只描述痕迹之差，不描述动作**：例如“重演中石板只有一行；现场有两行”，不写“没有人回来报告”。
4. **鞋印比对由玩家选择对象**：在靴印证物卡上选择比对谁的鞋底（四人的鞋），而不是直接给“检视自己的靴底”。
5. **答辩新增可选一问**：玩家已细看窄手印并见过门外窄底鞋印后，可问“架上的手印，是你的吗？”恶魔：“是。依第二条，我取走了诸位授权封存之物。”（字面承认取物，不谈数量与时日。）给“第五个人”一条可主动追查的线。
6. **恶魔低语去模板化**：四句诱导各不相同，不以同一句收尾。
7. **交互一致性**：点击可交互物件一律走过去并打开；不可交互物件点击时也给一次心声（窗、拖鞋等补齐）；关闭证物卡后再次点击同一物件不得寻路到别处；同伴不阻挡玩家路线（被挤时让开）；底部提示条只显示鼠标所指或最近的那一件。
8. **减少重复**：声路试验第二轮起以一张小表汇总四处所闻，苏泠的点评只说一次；问答菜单在问完一题后停留在原菜单；连续的极短台词合并为一段；“请某人看看”后不再重显整张原文。
9. **R-06、R-07 各补一处本人的生活痕迹**（如霍铎床头钩上的油渍、沈鼎磨得凹陷的磨刀石），作为相熟与久居的旁证；不新增编号证物。
10. **侦探的情绪**：报偿空格、“……是我”、门开三处各加一句克制的心声。
11. **始业之问后的反应**：三人各有一句不同的抵触或怀疑，再开始调查。

### 4. 一日与时间（2026-10-04 按总纲 §四 统一）

- **三日**：始业日（日常）、翌日（事件与对质）、第三日（名录库之议）。原第 5—7 日删去（理由见 §15）。
- **六个时段**：清晨、上午、午间、下午、傍晚、夜里。每个时段开始时，十五人依各自的认知结算这一阵做什么（CTB 排序），侦探在地图上看到他们在各处做着自己的事。
- **读不耗时，写过一阵**：侦探检视、问话、读板、重演都不过时辰；做一件“写”（总纲 §四.2）之后，这一阵就过去了，进入下一个时段。T 让这一阵过去。
- **固定场面**在时段开始时发生，侦探被带到场：第一章结束后中央厅集会与讲堂首课；翌日清晨中央厅出题；翌日傍晚中央厅对质；第三日清晨誓约庭议事。午间配给在后勤院照常进行，侦探在场才看得见、才能出声。

### 5. 系统

#### 5.1 认知、来源与传播
- 每条信息带来源：亲见（Perception）、转述（Testimony）、回忆（Recall）、推断（Inference）、恶魔之言（Corruption）。
- 转述经过不信任的人会打折扣，经过成见会走样（经沃德转述的雀儿之事，会带上“私取”的定性）。人物只转述与自身价值相合的事。
- 人物接受经转述而来的规矩后，再遇侦探会说出来源（“苏泠跟我说过你那条规矩”）。

#### 5.2 声望：存在于每个人心里
- 每个人认知中的侦探分“为人”（不撒谎、不冤枉人、说到做到）与“判断”（推得准、办得成），判断分领域（口粮与案子／名录库）。
- 只有亲见或转述才会改变它。界面上没有声望值；玩家只看到人物的话、态度与之后的行动，笔记本“人”一页记下侦探亲眼所见的迹象与来源。
- 每人有一至两条底线（沃德：无记录即不可；茉拉：不得拒病者），触犯即拒，信任再高也无用。

#### 5.3 规则与公告板
- 公告板在中央厅、配给台、起居厅、四个寝区的活动厅与讲堂门外。规则只送达读到或被告知的人；规则只约束接受它的人，不投票。
- 接受与否看：对立规者与背书者的信任、与欲望和习惯是否相合、是否威胁其利益、是否亲见相关事实、成见与底线。判定确定可复现。
- 其他学员也立规（沃德最常立）；恶魔只立它自己的规（学园守则、致命警告）。
- 玩家的规矩从具体写法中选（总纲 §四.2），在对质与议事时当众提出，或在白天当面讲给一个人听。

**恶魔的致命警告**（句句为真、只说最低限度）：“入夜后，名录库中若有人以你之名唤你，勿应。”（应答即触物回忆，记一枚钩；有钩者更难抗拒。）原温室警告随温室移出本章。

#### 5.4 派系与立场
- 派系 = 共享核心规则、且相互信任高于阈值的人群；不显示，只在议事时以“谁站在谁身边”呈现。
- 对规矩点头不等于在名录库之议中站你这边：立场主要随亲见改变（同行即作证）。

### 7. 主线案件《少了一份》（读与写）

**作者侧真相（始业日夜）**：
- 规则分布：
  - 中央厅公告板（沃德）：“凡取用公物须登记于台账；无登记取用者视为私取。”“私取之人（雀儿）入夜不得入后勤院。”
  - 配给台公告板（茉拉）：“病者伤者优先。夜间急需可自取一份，次日告知。”
  - 粮仓门内台账（阮清越）：“每日按人头分配，日末清点。”
- 莫兰发烧。茉拉夜里依自己的规则为他取了一份，打算次日告知；清晨她一直在诊疗所照看莫兰，不知道已有人被指控。
- 雀儿傍晚被沃德当众盯视，没去领晚配，饿着。玛格丽特发现粮仓门闩松动，夜里请雀儿去修（玛格丽特敬重工匠，没读过中央厅的规则）。雀儿不接受沃德的规则，所以不受其约束；她修好门闩，在配给台读到茉拉的规则，接受了（她信茉拉），自取一份吃掉，打算次日告知。
- 贝尔特朗夜巡，远远看见一个瘦小身影在后勤院（是雀儿）。
- 清晨阮清越清点：少两份，台账记“无记录取用 ×2”。沃德据此与贝尔特朗的证言当众指控雀儿私取。
- 以上是侦探始业日什么都不做时的形状；玩家始业日写下的东西会改变它（例如让雀儿吃上晚配、让沃德先认了茉拉的规矩），推演照常给出那一夜的真实痕迹。

**恶魔的那句真话**：翌日清晨，铜口只说“台账上，少了两份。昨夜，有人进过后勤院。”两句都真；容易补出的前提是“取了而不记，就是偷”。配给台上茉拉的规矩可以识破它。

**真相的形状**：没有贼。同一个行为，在茉拉的规则下合法，在沃德的规则下是私取；台账规则不记夜间自取。规则贴在三块板上，没有人读过全部。

**证物（翌日；不随日消失，有人清理则留下清理的痕迹）**：

| :--- | :--- | :--- |

**读（重演）**：变量为“茉拉以为谁需要口粮”“雀儿接受了哪条规则”“玛格丽特是否接受了沃德的规则”“雀儿领没领晚配”；引擎由各人读到并接受的规则推出行动与痕迹。重演从现实快照重建（含侦探始业日的全部写），回放在学园手稿图上：墨影只显身量与去向，心声在全部吻合后才显示（§13 第 11 条）。唯一吻合的组合即真相。

**写（翌日傍晚对质）**：一问一答，陈述与出示成对（总纲 §四.4）：

| 问 | 有效回应（陈述 + 出示） |
| :--- | :--- |
| 沃德：“台账少了两份。第一份，是谁取的？” | “茉拉夜里为发烧的莫兰取了一份” + 诊疗所的空碗／配给台公告／茉拉的说法 |
| 沃德：“另一份呢？” | “雀儿照配给台的规矩自取了一份，打算次日告知” + 饼屑／配给台公告 |
| 沃德：“入夜擅入后勤院，与窃何异？” | “她是被请去修门闩的；门闩修好了” + 粮仓门闩／玛格丽特的请托 |
| 阮清越：“那台账为何不见记录？” | “台账只记白天发出的，夜里的取用记不到” + 台账 |

- 每一对有效回应让听者积累“材料”：亲见过这件证物的 +2，信侦探的转述 +1，当事人当场承认按听者对她的信任再 +1；够 3 点的人改写心中对雀儿的认定。让沃德**亲眼**看过配给台规矩与修好的门闩，比当众转述有效。
- 也可以说“夜巡望见的瘦小身影是雀儿”——字面为真，却把矛头引向她；当众说出即记为一次操纵（修罗线种子，§9）。
- 问完之后，沃德问“今后如何？”：玩家从具体写法中提一条（“急病夜取一份，次日补记；补记者不算私取”“入夜后，谁也不得入后勤院”“夜里取粮须两人在场、两人签名”），各人依自己的认知点头或摇头；再决定是否提议第一条共同规则“公开指控须附可检查的材料”。
- 失败也是一种结果：若指控成立或不了了之，雀儿被排斥，搬出甲区独宿；她是名录库锁芯的最佳人选，这会直接影响第三日。

### 8. 名录库之议与章末

- 第三日清晨，誓约庭。各人依立场（欲望、亲见、饥饱、派系、认下的规矩）站到一个方案旁边：
  1. 各取其物：开放取回（恶魔之规）；
  2. 委员会保管：沃德主导；
  3. 封闭不启：顾平章、茉拉主导；
  4. 侦探之约：玩家此时当众提出的一种写法（“名录库须本人亲取、两人见证签名”“名录库只在白天开，本人亲取，记入台账”）被足够多的人接受；
  5. 被私占：翌日夜里已有人凑齐三站开了门。
- 玩家表态支持一方。人数最多且凑得齐三站的方案成立；封闭不启无须机关。开门须请人站三站（§5.6）。
- 开门一幕体现所定方案的条款（两人见证签名、白天开门等）。
- **侦探的封存匣**：匣上标签是他的名字，他念出来，匣不应。恶魔：“那并非你的名字。”停一下，“……也不是别人的。”
- 章末卡：名录库的去向；雀儿住在哪里；留在恶魔那里的钩；你没有交出的；你在几个人眼里的样子（只写侦探见过的迹象）。恶魔在章末广播里不提契约。

### 9. 修罗线种子

“写”也可以用来操纵：玩家可以贴字面为真、却把矛头引向某人的规则，或安排片面信息先到某人耳中。正线不禁止，但被揭穿会失去信任。系统记录每次操纵（对象、手段、是否被揭穿）。侦探“尊重他人自主”的底线第一次与这种能力正面相遇。修罗线本身是否保留待裁定。

### 10. 章节结束状态

写入存档并供第三章读取：各人认知中的侦探（可信、见识）、派系与领头者、名录库归属与开启方式、各人钩数与欲望强度、已学课程与规则、物资存量与温室状态、各人住处、操纵记录、三组旧怨是否解开。

### 11. 原型第一轮结论与第二版裁定（2026-10-03）

第一轮系统原型证明“写”在引擎里成立（规则逐人接受、照接受的规则行动、夜里出现未写入设计的合理连锁），但还不好玩：后果玩家看不见；侦探的可信是万能钥匙，对质后 15/15 通过；物资没有压力；守夜直接看见真相。第二版按以下裁定修改：

1. **读写闭环：每个清晨都是一次小型重演。** 夜里发生的事只以痕迹、身影、声音和他人转述到达侦探。侦探可在任一清晨对“昨夜”做信念重演（第一章的机制），从而看出自己白天写下的东西如何改变了谁的行动。“写”的后果必须通过清晨痕迹或心声被玩家读到，不能只存在于调试日志。
2. **夜间感知是残缺的。** 守夜只给身影（身量、方向）、声音与留下的痕迹，不给姓名与动作标签。
3. **侦探的注意力是第一稀缺资源。** 当面说服一次占一个时段；公告板覆盖面大但说服力弱；无法逐一说服十六人，必须经由被信任的人转述（信任链传播）。这是玩法的主轴，不是限制。
4. **信任分领域、有上限，底线价值有否决权。** 可信至少分“为人”（不撒谎、不冤枉人）与“判断”（推得准、办得成）；单项对接受的贡献有上限；每人有一至两条底线价值（如沃德：无记录即不可；茉拉：不得拒病者），触犯即拒绝，信任再高也无用。须让“同一条规则无法让所有人满意”成为常态，玩家要选择争取谁。
5. **接受理由不以数值呈现。** 玩家只看到对方的话、态度与之后的行动；调试模式才显示分项。
6. **规则补“主语”格**：谁来做（某人／某组／任何人／值守者）。共五格：主语、条件、行为、例外、记账。
7. **派系由人物自己的价值推动。** 非玩家人物也按欲望与价值互相拉拢、立规、结盟，不依赖侦探。预期的跨寝区价值聚落（初值，可被打破）：秩序派（沃德、顾平章、阮清越）、劳作互助派（沈鼎、雀儿、贝尔特朗、赛尔玛、霍铎）、感官与美派（卢西安、伊莲娜、莫兰、苏泠）、实证派（维罗妮卡、玛格丽特、茉拉）。初始寝区在始业日即开始瓦解。
8. **物资要有压力**：口粮初值降到不调度就不够（约 80 份对 96 份需求），温室修复真正必要；分配方案必然让某些人不满。
9. **固定节点改为“压力”**：作者保证冲突的条件（茉拉夜取规则与沃德无记录即私取规则必然相撞、莫兰发烧），不保证事件的具体形状。玩家若在始业日成功调停，案件可以变形或被预防，这是合法结果，并须留下可读的后果（例如沃德转而怀疑别人，或无人被指控而台账规则被修正）。
10. **重演从现实快照重建**，包含侦探自己白天的行动。
11. **预判降为次要**：保留，但改为与具体某人的约定（“若我说中，你采纳我的规则”），不再是对空气下注。
12. **Core**：允许通用修正 `RuleMode.Permit` 不应凭空产生行动动机（只放行，不提议），须附 Core 回归测试并复跑第一章全部检查。其余 Core 建议（规则标识、多段位移、Observe 开销）暂在游戏层处理。

### 12. 原型第二轮结论与第三版裁定（2026-10-03）

第二版证明了读写闭环成立：玩家白天对某人说的规则，次日清晨可用“他认了／没认”两种重演对照台账签名读出来；侦探可信不再是万能钥匙，16 种策略走出 5 种结局，无全面占优者。第三版有两个目标，**人物动作涌现为第一目标（用户强调）**，可读性为第二目标，完成后交独立盲玩检验文字原型是否好玩。

**0. 人物动作涌现（第一目标）**

十六人不是等玩家来写的对象；他们自己也在读、在写、在行动。涌现的定义：**由两个以上人物各自依自身认知做出的决策串成的因果链，作者没有写下这条链。**

- **动作词表**：每人每个时段依习惯、欲望、已接受的规则、关系与身体状态，自主从下列动作中选择（经 `DecisionSystem` 与 `ActionRuntime` 结算，同一身体不能并行）：交谈与转述；向他人提请求（经 `SocialSystem`）；帮忙、交换、教别人（转述课业）；分享或藏起口粮；修理、看守、跟随某人；照顾病人；清理或掩盖痕迹；立规则、撕规则；当众指控或替人辩护；邀人结盟；夜访名录库；上课或缺课；拒绝与躲避。
- **人物之间互相“写”**：沃德向别人推销他的规则，雀儿劝霍铎帮她开锁，阮清越用账目说服人，恶魔对每个人低语。侦探只是十六个写者之一，不是唯一的推动者。
- **多步计划**：人物可以为欲望连续行动数个时段（例如霍铎为图纸：先去上传声课 → 找雀儿开锁 → 约贝尔特朗夜里拉配重 → 夜访名录库），计划会因他人的拒绝、规则或意外而中断、改道。用 Core 的规则、请求与条件等待表达，不写成剧本。
- **在场即可见**：白天与侦探同处一地的人，其动作以短句呈现（“雀儿把半块饼塞给了莫兰”“沃德撕下了配给台的一张纸”）；不在场的动作只以痕迹、转述与重演到达侦探。
- **可映射为画面**：动作须能落到有限的人物动作帧（行走、操作、交谈、递物、坐、看守、蹲查、拉拽），供后续 32×48 动作图集制作；原型中为每个动作标注对应的动作帧类别。
- **度量**：每局自动记录涌现链（链长 ≥ 2，跨人物，非作者安排）；检查同一开局在不同玩家策略下涌现链的多样性；玩家可见的涌现（经在场、痕迹或转述可读到者）每日不少于两条。原型报告须列出最有意思的十条涌现链，并说明哪些玩家读得到。

以下为可读性与其他裁定：

1. **夜间感知按注意力筛选**：守夜只给 3—5 条最显著的感知（离得近、声音大、与侦探已知之事相关者优先），其余合并为一句“还有几道身影来去”。
2. **信任链留下可读痕迹**：人物接受经转述而来的规则后，再遇侦探时会说出来源（“苏泠跟我说过你那条规矩”）；清晨摘要只列侦探经由亲见或转述可知的传播，不列全知结果。
3. **“接受规则”与“立场”分开呈现**：对规则点头不等于在名录库之议中站你这边。人物的立场通过可观察行为显露（夜里去哪、与谁同行、复述谁的话），侦探的人际笔记以“他认了你的某条规矩”“他最近常与某某同行”分别记录。
4. **证据不随日消失**：痕迹保留到有人出于动机去清理，清理本身留下痕迹；玩家可在任意一日援引第一条共同规则重开对质。消除“只有翌日能查”的软死局。
5. **夜间私占是恶魔的引力，保留为“什么都不做”的默认结局**，但必须可预读：有钩且开库欲望强的人，每夜在名录库前厅留下的足迹与停留逐日增多，清晨可读。
6. **重演变量通用化**：不再为《少了一份》单独写变量。清晨重演的变量由“侦探知道存在的规则 × 他怀疑可能接受了它的人”与“某人昨夜是否在某处”组合生成，案件变形时仍可用。
7. **查证成本**：同一区域内的多处痕迹在一个时段内一并细看；经过某处时自动记下明显的变化。
8. **调校**：派系向四个价值聚落收敛（以价值相近度提高结盟倾向）；第 7 日口粮不应断（温室在认真分工的打法中可修成）。
9. **策略机器人只用玩家可见信息**：游说与判断不得读取人物的真实认知；“结局可达”须以此重测。
10. **性能**：单时段最长保持在 300 ms 以内，完整检查控制在 5 分钟内。
11. **Core `Permit` 修正**仍待第一章第二次盲玩结束后统一安排。

### 13. 原型第三轮结论与第四版裁定（2026-10-03）

第三版：38 项检查过 36 项；每局 53—69 条涌现链，其中不经侦探的 ≥ 43 条；夜间私占完全由人物的“开库计划”涌现；可读性十条基本落地。第四版裁定：

1. **操纵后的修复路**：被揭穿的操纵是应有的代价，但不得成为死局。提供“公开认错并兑现一件请求”的修复路，可恢复部分“为人”（上限低于揭穿前）；须保证至少一种其他结局仍可达。
2. **可见涌现的计量口径**：按“当日在场所见 + 次日清晨可读痕迹与转述”合计；侦探整天私下交谈时，次日清晨仍须至少读到两条他人自发行动的痕迹。
3. **指控以亲见优先**：人物指控时，先依自己亲眼所见，再依转述与成见；修正沃德看见茉拉却指控雀儿的错误。
4. **守门改为身体占用与请求对抗**：沃德拦人须实际占住名录库机关的一站（Core 身体占用），并向来者发出离开的请求，由来者各自的 `SocialSystem` 决定；有人说服或替下他时机关即可开启。删除“拦得住两人、拦不住三人”的阈值。
5. **转述有成本、有选择**：人物只转述与自身价值相合的规则，转述占用其时段，并按成见走样；避免侦探之约 14:1:1 式的一边倒。
6. **立场主要由亲见改变**：只靠当面说服可让人对规则点头，难以改变名录库立场；立场的转变主要来自他亲眼看见的事（如有钩之人夜里应名后的样子、第 5 日担保衰减的迹象）。玩家可以安排他去看（同行即作证），这是改变立场的正道。
7. **补全动作词表**：教人、交换、跟随、躲避；分粮须在合适条件下实际发生；转述与结盟改经 `ActionRuntime` 结算（同一身体不能并行）。
8. **第 7 日口粮**：保留轻度短缺作为压力，须在第 5—6 日清晨可读（存量与温室状态）。

#### Python 剧本编译与宿主边界（2026-10-05 重构）

**显示绑定与事件边界（2026-10-05 用户裁定）。** Godot 实现具体显示绑定，通过类型化事件与纯 C# 权威运行时交互。输入为交互意图、候选请求、选择提交、宿主空间核验以及表现完成；输出为可用候选、已选行动、语义台词及世界变化结果。人物策略、条件判断、状态提交与章节继承归核心侧；对话框/证物卡选择、节点绑定、字体颜色、镜头、动画和音效播放归 Godot。Godot 不提交任意状态修改，不选 NPC 答案；核心不引用 Godot 类型或节点。事件需区分行动结果与表现确认，按关联标识防止重复/过期输入；无画面驱动应能使用同一接口。此处“核心侧”包含无 Godot 依赖的游戏脚本运行时，独立 Core 世界引擎仍不引入章节或 UI 专属类型。

**扁平候选与对白块（2026-10-05 用户裁定）。** 对话的基本单位是独立的候选行动和候选反应，不是由作者嵌套指定下一句的对白树。玩家从当前可用候选中选择；NPC 在有限的适用反应中，依据自身主观世界的已接受策略、欲望和代价，调用 Core 决策机制选择。条件决定适用性，策略决定偏好，两者不能混为作者写死的分支。人物条件读取其已知/相信的投影，不能偷看客观实体状态。没有适用反应时应明确返回无反应，不强行执行列表第一项。

候选台词使用三反引号包围的剧本块，直接写人物与正文；块外保留可读的声明与逻辑。这是 Python 语法加对白块的作者语言，不能再宣称文件是标准 Python。前端处理对白块时保留源位置，再解析受限 AST。台词、候选身份与执行效果绑定，选择提交时重新核验且不得重复结算。候选反应保持平铺、可独立增加，不能用候选内的 if/else 指定 NPC 下一句来绕开策略。场景物件中参与交互/因果模拟者绑定 Core 客观实体或属性/事件；纯视觉装饰仍由宿主处理，证物卡只是已有证据与主观认知的界面表现。

**章节组合与继承（用户追加裁定）。** 脚本按章节拆分，后输入章节显式声明前置章节并扩展同一个世界会话。区分定义继承与运行状态延续：前者继承世界设定、实体类型、属性定义、人物初始模型和通用规则；后者保留玩家已经造成的物件变化、持有关系、人物认知/信任/欲望、已触发事件与任务进度。第二章不能重新执行第一章初始化，不能用初始默认值覆盖已发生的变化。

- 定义采用稳定身份和章节命名空间；名称只在编译、装载和存档边界解析，运行态沿用对象引用。后章可新增实体与交互，扩展既有定义必须显式声明；同名重定义、类型冲突、前置缺失和依赖循环均报错，不能静默采用后者。
- 同一会话顺序载入时保留既有人物、物件和认知对象身份。世界持久状态跨章存在；章节局部状态与一次对话临时状态具有独立作用域。章节退出只注销声明为本章有效的触发器，不清空世界；持久规则继续生效。
- 装载前先验证整个章节及引用，再提交新增内容；失败不得残留半个章节。重复载入已加载章节不得重复创建对象或发放奖励。章起始效果在明确激活时执行一次；装载内容本身不等于自动推进剧情。
- 后章修改初始模板不追溯改写旧人物；要改变当前世界必须使用显式效果并遵守行动提交与观察通路。剧情上销毁的物件不得因跨章重新声明而复活。缺少前章运行记录时可以显式选择新游戏初始化或测试夹具，但不能冒充真实继承。
- 存档最终需保留内容版本、已激活章节、世界状态、人物主观世界、触发记录及必要的时序/随机状态；不同进程恢复后重建引用关系。同一会话继承与跨进程存档恢复分别验收，前者通过不代表后者完成。

**2026-10-05 用户追加裁定：世界定义与模拟脚本。** 最终脚本层必须覆盖房间、所有场景物体的交互属性、人物性格、身体与精神状态，以及额外的剧情驱动。现有 `line/condition/effect` 对白构造器只是迁移阶段实现，不能作为完成此要求的验收依据。以下是目标契约，尚不表示当前编译器已经支持。

- 世界声明包含房间、连接、物件、人物、初始状态、资源与空间布局引用。物体的检视、使用、组合、交谈等交互，其前置条件、动作代价、结果与反馈都可在脚本定义。既有通用能力范围内新增房间、物体或人物无需修改章节 C# 或 GDScript；新的底层物理/模拟能力仍可由引擎扩展。
- 性格必须有模拟语义：通过欲望权重、主观规则、信任与行动偏好影响真实决策；描述文本不能代替模型。身体与精神状态可以影响行动条件和代价。客观对象状态、人物知道或相信的内容、作者控制的剧情进度必须区分；人物认知只能经观察、转述等既有观察通路改变，人物行动依自身认知决策，不得直接读取全知状态。
- 额外剧情驱动可订阅进入房间、完成行动、观察所得、状态变化及逻辑时间推进，声明触发条件、一次性或重复策略、优先级和效果。由 C# 在行动提交边界调度；重复确认不能重复结算，循环触发必须可诊断。预设剧情与自主模拟共用权威状态，不能各维护一套结果。
- 编译生成类型化世界定义与行为中间表示；加载阶段解析名称并绑定真实对象引用，运行时沿用核心的类型化节点与引用。Godot 消费布局与表现请求，负责房内几何、碰撞和实时动画，不执行剧情条件。无画面的 C# 会话必须能构建同一世界、输入行动并推进模拟。

### 音乐与音效（2026-10-04 重写）

全部原声由 `music/build_soundtrack.py` 一键生成：曲谱原稿写在 `music/cues.py`（记谱与 MuseScore 4／MIDI 导出在 `score_io.py`），配乐由 `sf2.py` 采样器用 MuseScore 4 自带的 MS Basic 音色库（MIT，FluidR3 衍生，许可见 `godot_csharp/ShareAsset/External/MSBasic/LICENSE.md`）发声，按 SoundFont 2.01 规范实现调制器、调制包络与随时间变化的低通；找不到音色库时退回 `synth.py` 的 numpy 加法合成。音效与对白提示音由 `sfx.py` 加法合成。固定种子，波形可重现（OGG 容器的流序号每次不同）。曲谱输出为 `music/Blessed Sleepers - <曲名>.mscz／.mid`，装有 MuseScore 4 时同时由它打开并导出总谱 PDF 与 MusicXML（`.pdf／.musicxml`，打不开即构建失败）；游戏内配乐与音效为 OGG，归 `godot_csharp/ShareAsset/Internal/Props/Audio/{Music,Sfx}/`，提示音仍为 `Internal/Characters/voices/voice_*.wav`。旧曲 `The Unfallen` 系列已从正式音乐目录清理，游戏不再使用。

**曲谱与源数据同步**（用户裁定，2026-10-05）：曲谱（`.mscz`）可以在 MuseScore 4 里手工编辑，编辑后同样的改动须写回 `cues.py`。构建不覆盖已有曲谱，而是逐项比对两者（声部名称、模板、音色 bank／program、移调，每小节的音符与时值、力度、文字、演奏法、排练记号与可见速度；排版、eid 与隐形播放控制不比对），有任何差异即停止并列出；只有显式 `--rewrite-scores` 才从 `cues.py` 重写曲谱。游戏 OGG 始终由 `cues.py` 经演奏诠释、采样器与混音渲染，渲染三遍取中间一遍做无缝循环，响度统一到 -19 dBFS RMS，主题曲 A 段到 A' 段的落差约 7 dB；`music/*.mp3` 是 MuseScore 对曲谱的试听导出（`--export`），不进游戏。MS Basic 的“Expr.”音色（如分部大提琴、低音提琴）由 CC2 随每个音的力度控制音量，采样器同样处理。

**门句动机**：情感核心是“开门”只是“不要开门”的后半截（第二部分 §1）。动机一小节四拍：前两拍两个下行弱音（不要）D5–C#5–B4，后两拍上跳五度的呼喊（开门）F#5–E5–F#5，停在属音上像一个问句。只出现后半截时是门外的“呼喊”；完整出现是真相；主题尾声里后半截第一次落回主音（B 大调），问句得到回答。恶魔的和声是阻碍终止：旋律给出正确的落音，脚下换成别的和弦（字面为真）。

**结构规则**（用户裁定，2026-10-04）：背景乐每首只保留一个主题、一种织体，循环时不分段、不发展，只维持气氛；多段与多种演奏形式只用于主题曲与日常变奏。全部变奏都从主题 A 的八小节变出，全作只有一个旋律身份。东方与中亚、印度风格以主题的变奏出现，不点明国别，学园的东方背景不在音乐里强调。

**演奏诠释**（`music/interpret.py`，规则取自 KTH Director Musices 演奏规则体系与钢琴、合奏的常规做法，全部确定）：四小节乐句的速度弧线（句中略推、句尾放慢，段落末放得更多，延长记号处明显放慢）与力度弧线；拍位强弱；旋律声部加重且越高越亮，比伴奏早约 12 毫秒；钢琴和弦自下而上轻微琶开；持续音乐器的旋律连奏、句末呼吸；钢琴按和声换切分踏板（调查曲右手与船歌半踏板，调查曲左手按 `senza ped.` 不踩并用指连奏，对质的左手脉动不踩）；紧张和弦略加重；船歌伴奏的和弦音短促。各曲深浅不同：主题与夜曲的速度弧线最深，调查曲只留四成以保持钟摆感，对质只留四分之一以保持逼迫感。每小节的和声与旋律所在谱表写在曲谱数据里（`Bar.harm`、`Bar.lead`），不进谱面。

谱面文字已有音符、配器、重音及力度表达的含义不重复添加：尤其《午间》“笛高八度”已在实际音符中实现，不再叠加移调。MuseScore 播放补充由 `score_io.apply_expression_playback` 写入不可见原生对象：《主题》第35小节钢琴右手以 `HairPin` 收弱至第36小节整音的 p，仅作用右手；钢琴如歌段、风琴连奏段及《门的这一侧》左手使用按实际休止断开的 `Slur`；《午后》前4小节与《暮课》前8小节复用原演奏层速度呼吸，在原音符／休止起点写入 `Tempo`，节奏段恢复96／88。保留现有音高、时值、音色与排版；情绪词不作为任意改写配器的指令。旧 `The Unfallen` 系列及其专用工具已退出正式目录；原谱的排版样式和视图数据逐字节提取为 `music/score_style.mss` 与 `music/viewsettings.json`，现役生成器直接读取，不再依赖旧Duet曲谱。
