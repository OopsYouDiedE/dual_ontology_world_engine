# 《安眠者有福》设计规范

本文件记录《安眠者有福》的现行设计要求。用户当前指令优先。世界事实、人物初始条件、玩法、内容边界与视听目标分别在对应章节定义。

文档更新规范见根目录 `AGENTS.md`。实现状态、测量结果和修订历史保存在带版本与证据来源的任务记录中。本文中的目标、示例和预算用于设计；运行结果以实际记录为依据。

---

## 总纲

### 一、本游戏的核心

> **现实与认知二相。读：从人在现实中的行动，反推他心中的规则与事实。写：改变他心中的规则与事实，他在现实中的行动随之改变。恶魔不能说谎，却能借真话操纵人；玩家先学会读懂它，最终也拥有同样的力量，并且必须选择怎么用。**

引擎源自动物园规则怪谈：人物依据自己认下的规则理解处境、选择行动，错误认识可能带来真实危险。本作围绕以下四个方面展开：

| 支柱 | 玩家实际在做什么 | 引擎为何不可替代 |
| :--- | :--- | :--- |
| **1. 读：信念重演** | 设定当时的处境与人心，推演行动与痕迹，再与现场对照 | 每个人依据自己的观察、理解、目标和能力选择行动 |
| **2. 写：改变他人认知** | 立规、告知、带人亲见、教学、对质 | 听者分别形成理解、评价与回应；规则的接受和现实执行各自记录 |
| **3. 真话之敌** | 阅读恶魔的课、警告与回答，识别字面与额外推论 | 话语受契约约束，听者依本人认知理解与采纳，见第二部分 |
| **4. 生存与记忆之价** | 学习、测量、协作与追索记忆 | 物资、伤病、侵蚀与取回状态跨章延续 |

**案件重心**：核心谜题让人物的认识与选择参与因果。物理线索、生活细节与人物交流共同支撑调查。

**章节设计要求**
1. 既有“读”，也有“写”。第一章以读为主；第二章起“写”成为主体。
2. 准备恶魔以真话诱导额外推论的机会，材料允许听者识别；是否采用该话术、谁接受、是否被骗依实际情境，不强制每局有人受骗。
3. 至少一处选择让个人欲望与对他人的责任发生冲突。前两章可由粮食、照护、冒险与信任承担；不要求每章以取回记忆支付代价。
4. 人物价值与习惯具有连续性，改变须有实际经历与认知来源；后续章节让玩家用既有认识预判并理解变化，不要求人物永远固守同一条款。
5. 每章准备可调查、可兑现的事实（总纲 §七“线索范围表”）；是否获知以人物实际取得的证据为准。确定的行动事实与仍有竞争解释的身世、关系和居留时长分开，不以章节进度授予知识。
6. 每章的世界条件必须足以产生危机；危机的形状由推演决定（总纲 §二.3）。

### 二、生存压力与事件

**1. 三层压力（都不由恶魔亲手施加）**

| 层 | 来源 | 呈现 |
| :--- | :--- | :--- |
| 岛在吞人 | 源质外泄后，导师的防护靠担保维持；担保衰减，防护随之衰减（第一部分 §2） | 失神 → 梦游 → 说过的话想不起来 → 安眠（睡下不醒）→ 死亡；按暴露量与取回深度逐人推进 |
| 物资有限 | 岛被隐藏，没有船；第 3 条只维持水、炉火、照明的设施，不创造物资 | 粮仓存量撑不过担保期；药品有限；产粮须去室外（第一部分 §4） |
| 人与人 | 契约只约束恶魔，不约束学员 | 缺粮、恐惧与侵蚀出的幻觉，可能让人私藏、排挤、出手 |

允许不可逆的死亡（用户裁定 2026-10-08）：事故、侵蚀到底、学员之间的冲突都可以致死。玩家所控角色的动作表里没有伤人（总纲 §六.12），死亡只来自世界与他人。

**2. 生存压力与知识来源**

1. 饥饿、侵蚀与伤病依实际时间、暴露和照护发展，休息与治疗按世界法则改善状态。资源消耗与补充按实际存量结算。
2. 玩家只控制一个人：其余十五人依欲望自行探索、自行发问；限制他人的探索需要沟通，各人依据所知风险、目标与关系回应。
3. 最低限度的保命知识由恶魔依契约传授；源质计、风向、危险地点与停行条件须能实际学会。库存靠清点，设备靠检视与协作，专业判断可经有防护的试验核实。不取回记忆也能建立前两章的生存规矩；深层历史、真名与封印机制仍属于后续记忆线。知识不足不等于只能盲猜，缺乏证据时允许暂停行动、求证或采用保守方案。
4. 取回分深浅：浅层（昨夜的事、一项技能、一条路线）几乎不牵连；深层（此人当初封存的核心）才让人半属此岛（第三部分 §1）。
5. 归乡后的遗忘按契约结局处理，不以选择暂时避险判定玩家道德或额外加重损失。

等待风窗、暂停危险试验和照护伤员均可形成有效进展，后果依据真实资源与身体状态结算。

**3. 历史、世界过程与人物行动**

| 层 | 内容 | 写法 |
| :--- | :--- | :--- |
| 过去 | 事故当夜、导师之死、账上已有的字迹 | 作者写定，可以精雕细琢 |
| 世界过程 | 气体浓淡、地震、粮耗、伤病的发展、天气 | 作者写规律与初始条件；结果由规律推出，可带种子 |
| 人物行动 | 偷不偷、慌不慌、去不去、听不听 | 只由此人的认知推出，作者不写 |

制度钟点规定配给、课、对账与议事的时间。天灾、疾病和泄漏沿预先声明的规律与初始条件发展；人物依据自己获知的处境决定应对。

**4. 事件的形成**：物资、环境、劳动与照护构成持续压力。争议沿实际行动与痕迹形成，避险和协调可以改变结果。没有新案件时，人物继续清点、复盘、照护和安排劳动。

**5. 行动因果约束**
1. 行动理由来自本人已有的信息、目标、价值取向、关系和身体状态。
2. 规范认可、主动遵守、受迫服从与现实执行分别记录。
3. 损己行动保留本人重视的责任、承诺或其他理由，以及可行替代。
4. 对威胁的有意识回应依据本人获知的信息；身体反应依据实际暴露。
5. 广泛后果沿世界过程、制度安排或人物实际行动的因果传播。
6. 请求评价计入听者的目标、责任、代价、风险与可行替代。

### 三、循环

| 层级 | 循环 | 首次出现 |
| :--- | :--- | :--- |
| 案件 | 出题 → 现场检视 → 试验与请人辨认 → 信念重演 → 按冲突补查 → 对质 | 第一章 |
| 一日 | 连续的游戏时钟：清晨、上午、午间配给、下午、傍晚对账、夜里；时间随行走、劳作与“写”的实际时长流逝，阅读已有材料保持时钟；室外按风窗进出；夜里十六人照各自认下的规矩行事，次日清晨留下痕迹 | 第二章 |
| 长线 | 担保倒计时与地质前兆下：产粮、研究、取回记忆、查明真名与封印机制、准备材料，封印恶魔；或被引诱放了它；或担保耗尽、火山终局 | 第二章起 |

### 四、内容与机制边界

人物决定以本人认知为依据，玩家获得所控角色可知的信息。论证保留来源与依赖；台词使用稳定编号；内容与通用机制分别维护。正式内容格式见第六部分 §2。

- **模拟精度**：不同精度沿用共同的感知、动机、决策、执行和推理语义，保留已发生的事实与认知。精度与预算说明记录在实际运行证据中。
- **作者声明**：明确区分既定历史、初始条件、世界法则和呈现方式。当前选择由人物在实际处境中作出，演出使用已发生的行动结果。
- **未建模情况**：保留当前有效状态，报告缺失条件及受影响的行动。后续进展依据仍然成立的路径。

### 五、所有章节共用的玩法规约

各章共用移动、交谈、检视、笔记与重演的基本操作，采用同一人物驱动机制。新增交互沿用已有的输入和反馈习惯。

**1. 操作**

| 输入 | 作用 |
| :--- | :--- |
| 鼠标点击 / WASD | 移动；点击物件或人物发起走近与交互意图，到达后按现场条件执行 |
| 悬停 | 只描鼠标所指的那一件，显示名称；点到普通家具只给一句极短心声，同一件只说一次 |
| E / 空格 / Enter | 检视身边的物件，或与身边的人交谈 |
| M（多处地图的章节） | 学园图：显示去过或听说过的地方，点击目的地发起寻路 |
| Tab | 笔记本：证物（按地点）、规矩、人、回忆所得 |
| R | 重演手稿（第一次看见案件的关键痕迹后开放） |
| 对白 | 空格推进；H 回看；已问过的选项变灰 |
| Esc | 合上当前的卡片或手稿 |
| T（多日章节） | 让时间过去，直到下一件要紧的事或下一个制度钟点；夜里按 T 即问“睡到天亮？”，在哪里都能睡下 |

不设命令行、动作菜单与滚动文字日志。一切结果以画面、对白、证物卡与心声到达玩家。普通对白一次空格或 Enter 推进；新点击立即替换旧路径；失败保留已填内容；回放可跳过，跳过与看完结算相同。玩家可见文本全为自然语言；可交互物件统一高亮。

**2. 读与写**
- **阅读**：阅读已经取得的材料与界面内容保持游戏时钟。第一章证物调查的呈现边界见第四部分 §5。
- **实际行动**：移动、试验、劳作、推演、交谈和等待使用各自声明的代价；取消尚未执行的操作保持原状态。请求的回应包括接受、协商、延后、澄清和拒绝。
- **时机**：风窗、配给与夜色随连续世界时间变化。
- **邀约挂在人身上**：请人来看、请人同行、请人比手印、请人做事、讲规矩，都是与此人交谈时的可选项。证物卡只放观察与侦探本人能做的试验，不放“请某某看看”。
- **人物菜单**：依据所控者已知的话题、当前处境和可提出的请求组织选项，常用项通常三到五项。实际请求送达后，对方依据本人认识回应。“问问他知道些什么”与“没什么了”始终可选。
- 规矩不在格子里拼。玩家能讲的规矩，是他读过的规矩与处境推到眼前的几种具体写法；选哪一种，就是玩家的立场。

**3. 人物驱动**
- 每个人依自己的习惯、欲望、所知与认可的规矩选择行动，对请求作出回应。
- 侦探也是同一世界中的居民：测试时与其余十五人一样由自身认知自动行动，玩家游玩时接管其决策；切换只停止或恢复自动行动，不替换身体、认知与位置。
- 恶魔对某人说一句放大欲望的真话，此人自己决定是否去做。侦探在场可以出声、讲明代价或任其自便；不在场，后果只以痕迹、他事后的神色与他的话到达侦探。
- **在场呈现**：当前房间按 §4 显示人物与动作。观察、辨认、理解和采纳各有成立条件；同伴可以表达有本人依据的观察、专业判断与推论。
- 人物的世界是陌生的：封存不删除职业技能、习惯与身体熟悉感，也不授予房间用途、资源余量、他人可信度或未来事件的知识。新观察、他人回应与实际后果能中断或改变计划。
- **以命运约束行为**：人物当前决定的来源，是既有经历与痕迹、所知所信、身体与精神状态、欲望、关系、承诺、物资与环境，以及前次行动的后果。作者在内容中声明这些初始条件、规则与可行行动，不写人物的固定行为队列。
- **动机合理性独立验收**：编译运行、机制结算、人物行为合理性与游玩体验分别给结论，任一项通过不代表全部通过。关键行为须核对当时此人知道或相信什么、身体需求与欲望、接受的规则与关系、可行的替代、预期收益与风险、为何此时选它，以及结果怎样改变后续计划；拒绝、退让、坚持、误判与计划中断同样分析。理由必须与行动前的实际认知相符，不用事后对白或搜索分数补造动机。
- 失败记录进入本人认知；新的信息、条件变化与重试成本参与后续选择。

**4. 房间认知与视野**
- 当前所在房间整体可见；其他房间都是盲区，不按朝向、视锥或逐格射线切分。去过的盲区只压暗内部；未去过的内部完全遮蔽；所有房间的墙与门始终完整显示。闭锁只限制通行，不抹去到访记录；开锁本身不算来过。
- 进入判定用人物实际落脚点所在的室内地面，门口、门洞、墙格不计；通过门洞期间保留最后实际进入的房间。集会入场、访问记录与房内事件也用同一判定。
- 已知布局不提供不在场人物的位置、行动或新事件。其他房间的人不显示、不能点，人物与热点采用同一房间可见性。不提供人物位置标记或“谁在哪里”的列表；学园图只画侦探去过或听人提到过的地方。
- 不在场的事只以痕迹、转述与守夜所见（只有身影）到达侦探；笔记本只记侦探亲眼所见、亲耳所闻。重演回放是玩家设定的假设在推演，可以画出全部墨影。
- 室外不按房间判定，保留视距与遮挡；夜间与浓气时视距缩短。黑暗、异常认知等确有玩法需要的场景另行约定迷雾。

**5. 案件循环**

出题 → 现场检视 → 试验与请人辨认 → 信念重演（手稿：左页变量是处境与人心，右页对照：吻合／冲突只写痕迹之差／未查只给地点；回放是墨影与心声）→ 按冲突补查 → 对质（一问一答，陈述与出示成对；无关证物得到指向性回应，不扣分、不重来；可暂且不答）。单一地图的章节回放在实景上；一夜跨越多处时，回放在学园手稿图上。

**6. 章末卡**：按实际结果展示已获信息、关系变化、资源与身体状态、已生效约定和未完成事务。发生取回时，列明内容、来源与后果。

### 六、引擎驱动的剧情

内容声明世界初态、法则、人物认知、话语与可行行动。引擎依据这些声明和实际输入推进因果。

**1. 一部连续剧情**：各章是同一部剧情、同一世界时间线上的叙事分段；世界与人物沿用同一批运行对象。章与章之间可以跳时，跳过的时段按低精度推演结算，不重建世界、不改写人物认知。

**2. 过去定，现在藏，未来活**

| 层 | 内容 | 是否固定 |
| :--- | :--- | :--- |
| 过去 | 作者写的历史（事故当夜、四组的裂痕、长线谜底） | 开局即定 |
| 现在 | 每人心智：欲望强度、信任、成见的细微取值、私下记忆 | 每局开局在 内容声明的范围内隐藏抽取一次，此后随事件变化；第一局用作者默认值 |
| 未来 | 人物的行动 | 由心智、世界过程与玩家的扰动推出 |

玩家不能成为“天意爷”：
1. 隐藏心智在声明范围内抽样，保留人物特征；局内变化由经历产生。
2. 人物会推测玩家的意图：玩家的举动本身就是别人的证据。
3. 代管者依据它实际观察或获知的事件调整话语与计划。
4. 论证只凭角色自己的认知：作答、指控、劝说、告知所引用的依据必须是这个角色亲见亲闻；走动、翻找、开门等身体动作不要求事先知道结果。
5. 固定的是制度与世界规律，不是人的选择。

**3. 推理的五类**

| 类型 | 对象 | 判断依据 |
| :--- | :--- | :--- |
| 作者写的过去 | 开局前已发生的事 | 历史声明与人物可取得的证据 |
| 游戏中的过去 | 实际行动及其原因 | 运行历史与可调查痕迹 |
| 现在的隐情 | 信任、认识与立场 | 当事人的表达、行动及有来源的推论 |
| 未来 | 行动与规则后果 | 明示假设下的预测，随后对照实际结果 |
| 规则 | 条文、适用条件与例外 | 文本、各人的理解与执行记录 |

- **预演**：信念重演向前用，只用玩家对各人心思的猜测，不读真实心智；第一章不提供，开放时机按平衡另定。
- 过去的行动事实通过有本人依据的论证核对；当下隐情与未来行动保留推测，并与随后取得的信息和实际结果对照。规则按文本、理解与执行分别判断。
- 出题者依据实际可调查材料提出问题。作者侧检查证据是否可达、可知，以及足以支持哪些结论；运行中保留证据缺失、未解与失败的结果。
- 比重：第一章以作者写的过去为主；第二章以游戏中的过去为主案；之后逐步以现在与未来的博弈为主。

**4. 人物驱动：欲望、目标分解与方法库，不用任务树**

| 层 | 作者写什么 | 运行时 |
| :--- | :--- | :--- |
| 核心欲望 | 人物档案中的主要追求（第三部分 §2） | 与需求、责任和关系共同参与选择 |
| 需求 | 饥饿、睡眠、安全、伤病、侵蚀 | 由身体状态推出 |
| 目标 | 不写成树 | 人物依自身认知把欲望与需求分解为当前目标 |
| 方法库 | 可以怎么做（开名录库须力气、细手、信号三处同时施力；拉人入伙可请托、交换或说服），与技能挂钩，全员共用 | 人物挑选与组合，并依据执行反馈调整 |

人物的变化通过实际经历、认识、关系和后续选择表现。玩家看到所控角色当下的心愿及其可知依据。

**5. 全员推理与按认知回应**
- 推理是全员共用能力，只读取本人认识。观察与证言保留来源、内容、时效和不确定性；推理深度与预算由能力配置表达。侦探侧重信念重演、规划和证据核对。
- 对白按**话题 × 认知 × 态度 × 目的**选取：话题挂在 Core 命题上；说话人依自己对命题的把握、对听者的信任或敌意、自身目的，选一种言语行为（如实告知、含糊、隐瞒、撒谎、拒绝、反问），再取此人对应的台词。条件只能写成说话人自己的认知、关系或状态；作者写的演出场面同样改写为在场者的认知。
- 听者结合内容、来源、已有证据、价值与处境形成理解、置信和接纳。

**6. 剧情韧性**
- 内容优先写法则，不写结果：声路由管道拓扑与接头状态实时计算；房间、相邻与视线从地图数据推导。暂用的声明结果须写明前提，前提被破坏时引擎报告并改用法则。
- 判定看命题是否被支撑：每问对应一个命题，本局世界中确实支撑它、且在作答者认知中的任何证物、证言或回忆都算。
- 剧情节拍声明目标状态和可能路径。人物依据自身目标与所知提出补救；路径是否成立由现实条件和可得依据决定。
- 非常规行动也须有因果记录：搬物、毁物、拒谈、不出房、改管路后，查看真实痕迹、可行后续与回应来源；失去依据就允许未知或停点，不为维持剧情补出信息。验证方式见第八部分 §1。

**7. 开局任选一人（只在开局）**
- 玩家只得所选者的认知；技能是 Core 行动能力，感知可有差异（苏泠听得清句尾、莫兰的速写可作证据、贝尔特朗夜里看得清身形）。每人有自己的欲望与胜利条件。
- 选人界面默认只示外貌、职业与欲望。某人的开场、寝区案件与关键时刻写完并通过盲玩，才列入可选；第一局固定作者默认种子、只可选侦探，通关一次后开放选人、心智抽样与案件变体。
- 所选者寝区的案件即其第一章主线。开场独白每人一版，共用骨架（醒来的感受、只记得上船、随身物），加两三句本人此刻独特的感知或习惯，不为未来剧情铺垫。

**8. 防背板与精巧案件**：历史骨架手写，运行中的行动依认知与世界条件生成。事实题须有可得、足以区分相关解释的证据；人物动机、关系与历史时长可以保留不确定性，不要求所有变量唯一解。线索可有旁证与生活意义，不强求逐件用于定案；不强迫玩家犯错或走够推理步数。变体不能改写真相来迁就玩家答案，也不能预置本应由夜间行动生成的案件结果。

**9. 内容语言**
- 正式内容使用原生 DV 声明，具体边界见第六部分 §2。
- 台词与选项具有稳定编号，译文沿用编号与来源。时长声明带单位，游戏时间与现实测量时间分别记录。
- **称呼按认知**：学员如何称呼铜口背后的声音，取决于各自对它的认知：默认叫“铜口”，接受其自称者叫“代管者”；改称“恶魔”只有两条路：被人直接告知，或强指向性证据经推理以高把握证实。人名、“我／你”同理按说话人与听者的认知填入。

**10. 修罗线**
- 修罗线是玩家借“写”让他人自愿把印记交给这座岛：诱其应名、促其取回全部记忆，直到被吞没。玩家从不亲手伤人，用的是恶魔自己的手法。
- 玩家对人物与契约的认识影响操纵方法；他人依据自己获知的行为推测侦探的意图，随后形成各自的回应。
- 修罗线循环：升格后玩家成为岛上的意志，同样出不了岛；岛依被吞没者的印记复制出新学员，玩家与他们一同生活下去。循环为多周目给出故事内的说法；以此开局的可玩形态在第三章设计。
- 修罗线不进入第一、二章正文；第二章只记录操纵（第五部分 §9）。

**11. 跨区开门**：无署名隔离规程提供劝阻理由。人物依据所知、能力和动机尝试处理门闩，真实到达与操作决定结果；旁人依获知的行为评价责任。第一章开锁机会见第四部分 §7。

**12. 所控角色的非常规动作**

| 层 | 做法 |
| :--- | :--- |
| 根本没有 | 动作表不提供（伤人等本作基调之外的事） |
| 底线：不可选 | 所控者当前明确坚持的底线及适用条件；选项附本人可表达的理由 |
| 偏好 | 菜单依据所控者当前处境组织行动；请求对象的接受与否在实际交谈中决定 |

侦探动机留白，偏好区间最宽；其余十五人习惯更强，区间更窄。

**13. 多周目**：多周目的价值是换人（十六人各自的寝区案件、感知与本事）、隐藏心智重抽、名录库的去向与各人“无法背负的过去”须换几个人才拼得全。正线结局不需要任何跨局知识。

**14. 人物策略与调查协作**
- **人物策略**：每人在欲望之上声明一到三条策略，参照《欧陆风云 4》的 AI 策略：对象、姿态与优先度（如“弄清昨夜、答完题出门”“守住隔离门”“护住某人”“自保少言”）。策略写在内容中，条件与权重只引用本人认知、关系与状态；它决定在什么处境下优先选哪些方法，不写行动队列。策略随认知与关系越过阈值而切换，切换须有本人认知来源。
- 同伴依据已知题目、门闩与个人目的参与调查，可以报告所见、提出试验或邀请同行。关键命题准备具有独立来源的调查路径。
- 探索、拒谈与暂缓作答均保留实际后果。同伴的帮助依据本人看见的处境、已获信息与合作意愿发起。
- 节奏目标和开锁机会见第四部分 §7；实际进展记录形成依据、执行、作答接受与跨门各自发生的时刻。

## 第一部分：世界

### 1. 岛屿与学园

1890–1910 年代风格的架空孤岛学园，早期电气与机械时代：油灯、配重、铜质传声管、手摇机械。学园招收有异常感知潜质的普通人，研究异常、教授神秘学。学员保留入学前的职业与技能。

**岛屿**：以科尔沃岛（Corvo，亚速尔群岛）的真实地形为蓝本，高程数据为 Copernicus DEM GLO-30，**水平与高程同比缩为 0.5 倍**。缩放后约 1.9×3.2 km，陆地约 4.2 km²；中央一座火山，火口直径约 1 km，底有湖与湖中小岛；全岛最高点约 351 m，在火口西南缘；四周几乎全是海崖，只有南端一块熔岩台地低平（海拔 20 m 以下约 14 ha）。剧中岛名、地名为虚构，地形参数用于概念布局。

**选址**：学园在南端台地中部，地坪海拔约 9—22 m，平均坡度约 6%。理由：全岛唯一的低缓地；火山挡住北风，朝南向阳；港口就在台地东侧。学园约占台地的三分之一，在全岛图上清晰可见。

**主轴**：方位 2°（北偏东），与全岛最高点方向（-1.2°）基本重合：沿大道上行，1.4 km 外的最高点就在中央厅穹顶背后。建筑长边一律顺等高线，以控制基底高差。

**序列与方位**：门楼—誓约庭—大道—中央厅—名录库沿主轴一路上坡（地坪 10.2 → 21.0 m）；誓约庭一段坡度约 10%，铺石设数级台阶。生活翼在大道西侧，后勤院在大道东侧；讲堂与星仪院开放角在中央厅以西；白塔院开放角、温室、汲水泉在以东；铁工院在东南港路旁（盛行西风的下风向）。港口在台地东侧，港路约 230 m，末段以之字形坡道下到码头，各段平均坡度不超过 9%、局部不超过约 10%；之字坡一段落石塌方。地下为勤务环廊与封印层。火口、山顶与北部、西部海崖属后续章节。

**水**：亚速尔群岛海边年降水约 1,100 mm，山顶更多，无真正旱季。学园屋面合计约 6,350 m²，八成收集率下年集水约 5,600 m³，约为十六人用水（每人每天约 80 L，年约 470 m³）的十二倍；屋面集水入后勤院下的水窖，是室内可取的水；坡脚的汲水泉在室外，按风窗去挑。维持供水设施属契约第 3 条恶魔的义务。

### 2. 源质：岛为什么吃人

**原理（作者侧，按线索范围表逐章露出）**：岛上的源质会记录认知。它从火山深处渗出，附着于玄武岩、水与物件；人在它附近的感知与经历在其中留下印记，久留不散。触物回忆（“物件记得”）、封存（把一段印记存入源质媒介，即名录库的封存匣）、恶魔（千百年叠积的印记聚成的意志）都由此而来。源质离岛即散，只能就地研究。常人察觉不到印记，**久留会被吞没**；学园招收有异常感知潜质的人，又以仪器与四锚封印护住他们。四座研究院压在四锚封印廊之上，学园兼为研究所与封印。

**外泄之后，含源质烟灰的危险按以下架空世界规律表现**：

| 条件 | 室外 | 室内 |
| :--- | :--- | :--- |
| 有风的白天、高处 | 有形成风窗的条件，仍须核对当地即时读数与路线 | 密封、通风与现场读数满足条件时可用 |
| 无风、夜里、低洼处（夹道、坡脚、汲水泉） | 易积聚至致命程度，依浓度与暴露时长结算 | 依密封与通风状态隔离；门窗紧闭不是受损建筑的绝对安全保证 |
| 地震之后 | 骤然加重，持续数小时 | 门窗与接缝处可能渗入 |

- **读数**：科学院的源质计、户外仪器阵的风向标与风速计，是每天的生死读数；作者侧读法曾被教授并随在校经历封存，当前须依安全教学重新获得，不要求先取回。
- **侵蚀**：吸入与久留都会侵蚀认知。症状逐级加重：失神 → 梦游 → 说过的话想不起来 → 安眠（睡下不醒）→ 死亡。取回的记忆越深，此人越属于这座岛，侵蚀越快（第三部分 §1）。安眠可逆：名录库里存着此人的印记，取回可唤醒他，代价同取回。
- **担保即防护**：导师以性命构成的担保同时稳住受损的封印；担保衰减，外泄加重，侵蚀加快，地质前兆增多（第二部分 §3）。
火山气体积聚与隔离生活的现实案例用于创作参考；源质的认知作用由本作世界法则定义。

**岛的历史三层**：远古有人知道它会记住人、也知道如何约束它，留下刻文（誓约庭铺石、火口立石、海崖洞窟，后续章节逐步开放）；近世的渔民牧人只留下“岛记得人”的传说与废弃的牧场石墙；这一次是第一次以仪器测量与记录它。

| :--- | :--- | :--- |

现实依据：南丁格尔式分馆医院的各馆以封闭连廊相连（如 1865 年的赫伯特医院）；学院回廊；矿井的安全巷道。连廊与环廊的门与岔口，就是“割据靠咽喉 × 时段”里的咽喉（第五部分 §5.3）。

### 4. 为何不是一栋楼

**可经观察提出的解释**：人物结合现场材料与职业经验表达判断。

## 第二部分：恶魔与契约

### 1. 恶魔

**身份**：岛上源质留存的认知印记聚合体。外显为约三十岁的黑衣绅士，琥珀竖瞳，手形修长窄薄（掌宽明显小于常人），穿窄底外交官皮鞋，外交官式礼节。原型是伊甸之蛇：递出的苹果同时是知识与欲望。

**不自报身份**（用户裁定）：它只说自己是“此地的代管者，也是诸位的教师”，不说自己是什么。被问“你是什么”时，可以用字面为真的谜语回答（如歌德笔下梅菲斯特的自述“我是那力量的一部分，它总想作恶，却总在行善”）。何时揭开其本质见线索范围表。

**门槛规则**（契约第 8、9 条）：它不能主动提供封存之物的所在与取回之法；这一门槛不限制契约要求的安全教学与警告。它不得提及封存之物在哪里、如何取回，不得促人取回；学员问及本人封存之物或契约条文，它必须如实作答。它可以谈学员的欲望，引起对封存之物的追问。文学原型：斯托克《德古拉》里吸血鬼起初进不了任何地方，除非有人邀请；歌德《浮士德》书斋一场，梅菲斯特要浮士德连说三遍“进来”。

**说话方式**：古雅、礼貌、精确，能教学、赞赏与嘲讽。它依据自己的目的和对听者的认识选择真实内容、时机与对象。契约约束每次实际话语；字面范围、预设和可能的听者推论分别核对。

**两个原动力**：
1. **传授**：契约第 6、7 条要它教会学员活下去所需的最低限度；它也真心想教，会为精确的答案由衷高兴。
2. **放大欲望**：它选择与听者欲望有关的真话。实际影响依听者的理解、接纳与后续选择呈现。

**它要的**：取回的人越多、取回得越深越好（深属此岛者终局送不走，印记归入聚合体）；有人在终局前出于自主解开它的封印；第 11 条不被人问起。

**虚实二态**：平时无实体，可穿墙，但无实体时不能触碰任何物件。移物、开门、写字、板书都须显形；显形时服从常规物理，留下指痕、粉笔字迹与窄底鞋印。

**学园守则**（它自己所立之规，依第 5 条张贴于各公告框）：
1. 入夜之后，诸位留于室内。
2. 饮水、炉火、照明照常供给；物资由诸位自行分配。
3. 课时贴于讲堂门外；来与不来，由诸位。
4. 我所立之规，皆张贴于此。

守则中的“室内”包括已开放的封闭连廊，其安全性还取决于现场读数、密封与通风。匿名《事故隔离规程》的作者侧来源见第一部分 §6。名录库的门楣与取回线索属于后续章节范围。

**前两章的信息边界**：导师及封存历史属于作者侧事实。匿名规程、生活旧痕与熟练协作提供可调查材料；熟悉感保留相识地点、时长与共同经历的竞争解释。前两章线索保持这一证据范围。人物依据已获信息自由追问，恶魔依契约回应。

### 2. 契约

**封印与契约是两层**：

| 层 | 作用 | 维持者 | 会不会失效 |
| :--- | :--- | :--- | :--- |
| 四锚封印 | 把恶魔困在岛上 | 导师遗存（塞莱斯蒂娜石化成的中央基座等） | 事故中受损未破；担保衰减则外泄加重；学员完成封印即彻底封住它 |
| 契约 | 规定恶魔与学员的关系 | 四位导师以性命构成的担保 | 担保随时间衰减 |

**条文**

甲 · 成立条件
1. 恶魔常驻岛内，不得离岛。
2. 经学员本人授权，恶魔封存其在校记忆（在校经历、师生与同学关系、事故全貌）；姓名、生平与入学前技艺不在封存之列。

乙 · 恶魔对价
3. 恶魔维持学园基础生存设施的运转（水、炉火、照明的设施本身；不负责分配物资，不创造物资）。
4. 恶魔所受约束，唯有学员出于自主的行动方可解除；恶魔不得代为或强迫学员完成解除。
5. 恶魔须公开它自己所立之规；规则许诺的路径必须真实可行。
6. 恶魔须传授学员理解处境与继续学习所需之知；学员自负其选择的后果。

丙 · 导师所留
7. 恶魔不得伤害学员身心，不得拘禁学员，不得令学员因无知而死。
8. 恶魔不得以言辞欺骗学员；学员问及本人封存之物或契约条文，须如实作答。
9. 恶魔不得向学员提及封存之物的所在与取回之法，不得促其取回；学员自行问及者，依前条作答。
10. 封存的记忆可凭对应之物恢复；恢复者自负其果。
11. 经其余在岛存活学员一致同意，学员可择定“尽忘归乡”，于下一次入睡时遗忘此地一切、在家乡醒来。
12. （终局）担保耗尽时，恶魔须将醒着且未深属此岛的学员遣返家乡，并抹去其与此地有关的一切记忆。

- **为何有第 8、9 条**：导师封存记忆，正是为了切断学员与岛的联系；他们最懂恶魔的手段，所以堵住它能说什么。第 10 条保留取回的权利，因为过去属于本人；第 9 条保证取回出于本人的发问，而不是它的招揽。
- **第 4 条的缺口**：条文禁止它代为或强迫，没有禁止它放大欲望；第 9 条又只禁止它谈取回，不禁止它谈你想要的东西。它就活在这两道缝里。
- **第 7 条的边界**：按具体行为、因果和契约义务核对恶魔的作为与旁观。最低限度安全教学说明读数地点与时刻、低洼和夜间积聚、地震后停行与复测；缺席者经实际补授或转述获得信息。自主承担风险以本人当时理解的危险与可选路径为依据。
- **第 11 条的保密**：恶魔从不主动提第 11 条（导师所立，不属第 5 条“它自己所立之规”）。契约全文刻在港口上岸处的石碑上，第 11、12 条风化严重，须拓印辨读；港路塌方，第三章起才可到达。学员问及契约条文，它须如实作答（第 8 条），但它从不先提。
- **第 11 条与身故**：“其余在岛存活学员”不含已死者与已离岛者，所以有人身故后一致同意仍可能达成。

### 3. 终局

| 结局 | 条件 | 学员 | 恶魔 |
| :--- | :--- | :--- | :--- |
| 学员胜 | 完成封印：真名、封印机制、封印材料 | 带着恢复的记忆与学到的知识离岛 | 被彻底封住 |
| 恶魔胜 | 学员出于自主的行动解开它的封印 | 视各人取回的深浅，有人被吞没，有人被它放走 | 自由，可离岛 |
| 两败：火山终局 | 担保耗尽 | 醒着且未深属此岛者被遣返、忘掉此地一切（包括死去的同伴）；安眠者、深属此岛者与死者随岛沉没 | 源质散入海天，它随之消散 |

- **担保衰减看得见的是地质前兆**：记录鼓上的地震群越来越密，地温升高，气体变浓，火口湖变色（尼奥斯湖灾后湖水翻涌成红褐色）。火山喷发前通常有数周的震群、地面隆起与放气增加；2022 年亚速尔群岛圣若热岛就发生过长达数周的地震群。不显示精确数字。
- **为何不是全员覆灭**：失败应当是一份由此前每个选择决定的名单（谁深属此岛、谁安眠、谁死了），而不是一个读档画面；参照《质量效应 2》的自杀任务。
- **恶魔为何签约**：事故当夜封印受损，但它没有赢；导师仍能以全体师生为代价强行封印。契约是和解：它得到学员与唯一的出路（第 4 条），付出第 7—9 条与第 12 条。拖到底，它会随火山一起消散，所以它必须在终点前让学员放了它。
- **它为何真心教书**：学员太弱只会走向火山终局，它也失去机会。它必须把学员教到能放了它的程度，而同样的知识也足以封了它。剩下的取决于学员想要什么，所以它放大欲望。
- **谁判定**：只有客观条件（担保耗尽、真名或封印材料灭失）。恶魔不能宣布；第 5 条使它守则许诺的路径必须可行。
- **担保是双方共同的倒计时**：基准约四十日耗尽；第一次可见的前兆在第五日，只是广播底噪里极轻的一下。后续章节可因事件加速或延缓，须有物证呈现。
- **章节内的退场**：第一章题面中的“暂不作答，在生活翼歇息”出自导师规程，只表示侦探个人暂歇，不结束章节，三位同伴照常行动，调查与答辩保持可用。

## 第三部分：记忆与人物

### 1. 记忆与取回

- **封存不碰技艺与身体习惯。** 人物会不知为何地做出熟练动作，这是活线索。现实依据：1911 年克拉帕雷德与一位失忆病人握手时手里藏了针，次日病人完全不记得他，却不肯与他握手，说不出为什么；失忆者亨利·莫莱森记不得学过镜像描图，描图却一天比一天熟练。
- **触物闪回**：本人触碰承载自己记忆的物件时，不由自主地闪回一瞬（普鲁斯特《追忆似水年华》的玛德莱娜小蛋糕）。这一瞬不算取回。真正的抉择是**要不要握着它、往深处想**；往下想，才是取回（Recall）。回忆在对质中算证言，不算物证。
- **取回之价**：不计数，记录此人**取回了哪些记忆、各有多深**。代价按三部作品设计：

| 原型 | 设计 | 引擎 |
| :--- | :--- | :--- |
| 冥后珀耳塞福涅的石榴籽：吃过冥界之物的人，就属于冥界 | 取回是从岛的源质里“尝”回来的；取回越深，此人越属于这座岛：侵蚀更快，终局送不走（第二部分 §3） | 取回的深度累计为此人与岛的牵连；只影响侵蚀与终局，不加任何社交系数 |
| 罗塞蒂《小妖精集市》（1862）：尝过一口小妖精的果子，就日夜只想着再吃；救她的是冒险去取果汁的妹妹 | 尝过一口就想要全部：取回一段记忆，放大此人取回其余记忆的欲望；**只有取回过的人才听得见名录库夜里的唤名**；安眠的人要靠别人替他去名录库取回 | 取回提高此人“取回其余”相关规则的权重；唤名只作为对取回过的人的观察 |
| 石黑一雄《被掩埋的巨人》（2015）：遗忘的迷雾散去，回来的不只是爱，还有旧日的背叛与屠戮 | 取回的真正后果是旧怨跟着回来：想起当夜，也就想起自己曾对谁做过什么、谁对不起自己 | 取回是一次有来源的观察，内容改变此人的信念与关系，后果由引擎推出 |

- **深浅**：浅层（昨夜的事、一项技能怎么用、一条路线）几乎不牵连；深层（此人当初封存的核心：罪责、承诺、入学所求的真相）才让人半属此岛。
- **唤名**：入夜后，名录库里有人以你之名唤你；应答即在恍惚中取回，取回过的人越多越深，呼唤越清楚。现实民俗：1768 年清乾隆年间的“叫魂”案（孔飞力《叫魂》），民间相信术士念人姓名就能摄走魂魄，一度引发全国恐慌。
- **无法背负的过去**：每人有两层过去。其一是入学前的隐事：本人记得、尚未告知别人，是核心欲望的根（如沃德对女儿的投射）。其二是封存的那一段：在校期间本人授权封存、本人也不记得的事，收在名录库的封存匣里。两层都属作者写定的过去，各有物证与习惯可读出。规则：
  - 恶魔不公布任何人的过去；过去只经物证、习惯、触物闪回、取回与他人转述露出。
  - 过去改变选择而不只是揭晓：后续开放名录库后，怕自己封存了什么的人可能主张封闭，想取回的人可能主张开放；具体立场仍依当时所知。
  - 轻重各异：有罪责、有羞耻、有承诺，也有微小却珍贵的事；不人人惨烈，不以过去作猎奇揭晓。
  - 各人的两层过去按章写入人物画像；第二章只露出影响分配、照护与外出信任的片段，不揭封存历史的身份和年限。
- 人物的核心欲望见 §2。欲望与需求、责任、关系共同影响选择，玩家通过实际行为和有依据的心声认识它。

**后续名录库的保留设计**：名录库在第二章之外开放。原有配重室、库门锁芯与中央厅传声中继三站协作机制保留；力气、精细操作与信号工作由实际愿意协作的人承担，不按第五日固定站位。开放取回、共同保管、封闭或被私占等结果依后续真实行动产生。侦探封存匣不应其名的异常仍为后续可遇事实，不在第二章章末强制展示；具体首次开放时点与证据顺序在后续章节设计时确定。

**写作要点**
- 沃德与雀儿是“体制与孤儿”的拟亲代关系，正文不写恋爱。沃德离异，有一个与雀儿同龄、多年未见的女儿；他在伦敦代理过码头货主起诉东区盗窃案。他对雀儿的敌意一半来自职业经验，一半是投射：“她若没人管，就会变成这样。”保护与管束之间的取舍通过具体经历呈现。
- 性向不作档案字段。作者侧备注只用于写作一致性（卢西安、维罗妮卡为同性倾向；苏泠无恋爱意向；侦探留白）；第一、二章不写恋爱线。人与人之间的感情只以信任、亏欠、守护与成见呈现。
- 恶魔的“亲近”是师长与对弈者的亲近，不写调情。它亲近取回过的人，表现为更多的称赞、更准确的提问、更像“只对你说”的真话。
- 维罗妮卡认同的是同区的玛格丽特；雀儿依赖霍铎、沈鼎。
- 莫兰话少、停顿长、用颜色代替形容词，不写口吃。他有记录和比较所见的主动目的，画作不是自动预言；安全的观察、请人同行与放弃窗口均须可选。不固定由他承担每次病倒、缺粮与救援事件。
- 职业提供经验与偏好，不指定阵营。对同一议题的立场须有具体认知、责任、资源与关系来源；程序派可承认紧急例外，实证派可因证据不足暂停外出，医护可反对无把握且耗尽药物的行动。事实澄清、责任评价、信任恢复分别推进，不用一件证物自动洗清所有争议。
- 霍铎全名 Halvard Brenner，母亲是在易北河造船厂做工的挪威船匠之女，名字随外祖父。
- 卢西安为浅栗发，避免与恶魔的漆黑微卷相混。

### 4. 羁绊与写作边界

- **可以写满的羁绊**：侦探—霍铎（同区互信）、沈鼎—雀儿（饭桌）、卢西安—雀儿（护卫）、维罗妮卡—贝尔特朗（不记得的救治）、玛格丽特—霍铎（同行敬意）、伊莲娜—阮清月（灰色旧怨）。初始关系按各自可保留的经历声明，后续变化由实际互动形成。
- **不写恋爱线的组合**：沃德—雀儿（拟亲代）；塞莱斯蒂娜—格雷厄姆（同袍之誓，第一部分 §6）；恶魔与任何学员（§2 写作要点）。

- **留白**：侦探的倾向与入约动机保持留白，正文呈现其实际选择与可知事实。

**恶魔的开场身体位置**：恶魔初始位于乙区隔离门外、公共起居厅的门闩一侧。内厅铜口传递声音，人物依实际视线见到身体。四问答辩完成后，它到门闩处处理尚未解除的外闩；其他人实际拉门与跨门。后续位置沿用移动结果。

**事故的情感关系**：门外没有人求救。“开门”是“不要开门”的后半截。苏泠出于善意开了门，侦探出于对朋友的信任关了门；两人都诚实。作者侧发令者格雷厄姆要他们活下去；玩家只知主楼传来禁开指令，不由音色或闪回补出姓名与职务。开门放进来的灰带着外泄的源质；在门边守得最久的是苏泠，代价落在她自己身上：白天的失神表现依其实际侵蚀与照护状态出现。恶魔的题暗示“是你把呼救的人关在门外”；真相是开门的人才放进了危险。

### 2. 开场与题面

开场广播：

> 诸位晨安。我是此地的代管者，也是诸位的教师。诸位所需之知，我会教。
> 诸位初涉斯地，记忆有缺，并非伤病，请勿惊惶。
> 我所立之规，已贴在活动厅的公告框里。
> 昨夜警铃骤起。主楼曾有人向诸位呼喊。
> 通往主楼之门，在诸位这一侧闩上了。那人再没有回来。
> 此为始业之问：**门是谁闩上的？闩门之时，此人可曾听见门外的呼喊？**
> 记不得，并不妨碍作答。痕迹还在。

活动厅公告框里贴着恶魔的学园守则（第二部分 §1）；隔离门内侧贴着无署名的《事故隔离规程》（第一部分 §6），说明外闩、作答与急病转移。恶魔不主动提契约或封存之物的所在与取回方法；实际被问及时遵守第二部分 §2。

| 句子 | 作者设定的指涉范围 | 听者可能补出的推论 |
| :--- | :--- | :--- |
| 诸位初涉斯地 | 封存之后醒着的这一个自己，今晨是头一回踏足此地 | 我们昨天才到，彼此素不相识 |
| 主楼曾有人向诸位呼喊 | 格雷厄姆确实从主楼喊话 | 有人在门外求救 |
| 门闩上了；那人再没有回来 | 侦探闩的门；格雷厄姆没回来 | 闩门导致那人没回来 |
| 闩门之人可曾听见门外的呼喊 | 询问闩门者当时所闻 | 门外确有呼喊 |

恶魔意在观察四人的判断、触动欲望并引起追问。实际理解与接纳由各听者形成。

各分支使用相同的感知与决策机制。模型声明位置、声路、所闻、信任及行动能力，再推演人物可能采取的行动与痕迹。昨夜的既定历史见 §1，模型输出与本人已查材料对照。

互相冲突的请求分别保留接受、拒绝、延后或取消状态，执行结果按实际行动记录。

**心声气泡**：以自然语言表达该次模型决策实际使用的依据。

#### 4.3 对照与回放

- 吻合／冲突（写出具体差异）／你还没查过这里（只给地点）。
- 在真实地图上以半透明墨影重演，每人头顶显示模型中的心声气泡；同一时刻四种认知并排出现。可暂停、倍速、跳过。
- 重演在第一次看到闩上的门（检视 E1 或 E3）后开放。

#### 4.4 解空间

既定有限模型比较 V1—V6 的候选与本人已得痕迹。相容表示模型能解释已查材料，未知材料单列。声音、行动和先后由相关证据约束；信任与关系保留为带来源和不确定性的解释。

调查可以从靴印、相反证言、声路试验或其他可得材料切入。有据解释按统一条件接受；杯子、酵种罐与无尘方框同时保留生活意义。

人物可以撤回无据的陌生定论，并保留相熟假说。相识地点、共同居留和具体时长继续按实际证据分别判断。

### 5. 触物闪回与调查

**第一章调查呈现**：检视、辨认与必要信息获取直接呈现实际结果，省去代价确认提示。触物闪回按真实接触发生；深层取回的自愿选择与代价见第三部分 §1。

| 物件 | 闪回者 | 接触时出现的片段 | 支持的变量与边界 |
| :--- | :--- | :--- | :--- |
| 音叉 E5 | 苏泠 | “门边……有人在喊开门。我想开门让他进来。” | V1 |
| 石板 E7 | 霍铎 | “铜口里的声音很清楚……‘等我下一次通知。’——他再也没有来。” | V2、V3、V4 |

| 插闩 E1 | 侦探 | “霍铎说闩。我就闩了。我信他。” | 支持当时的信任，不证明这种信任持续了多久 |

- **闪回由身体触发**：同伴在调查与日常中拿起自己的旧物（霍铎守在铜口旁的石板、苏泠门边的音叉、沈鼎要喂的酵种罐），闪回不由自主地发生。恶魔可以对他谈他想要的东西（对霍铎：“不烧煤的那张闭式动力图，此地有人画过”），不能提这件物件，也不能劝他去想。
- **闪回只在身体接触时发生**：同伴被请来辨认自己的旧物、或在日常里拿起它，侦探本人拔闩推门握住插闩时。证物卡不提供“请他握着想一想”之类的按钮；恶魔不对着物件低语。
- 侦探本人实际接触插闩时同样会闪回；查看证物卡本身不伪造身体接触。
- 回忆标注本人片段与来源，结论范围限于片段所含信息。现场材料也提供完整调查路径，玩家自行调整模型变量。

### 6. 始业之答

铜口对质以陈述与出示成对组织。每步检查本人材料对所问命题的支撑，提供具体的缺口回应。

| 步 | 所问命题 | 需要说明的依据 |
| :--- | :--- | :--- |
| 1 | 谁闩了门 | 行动者身份、闩门动作与现场痕迹的联系 |
| 2 | 声音从哪里来 | 当时所闻、实际声源与传递损失；声路试验结合历史材料形成解释 |
| 3 | 原指令是什么 | 石板、残缺听闻和其他可得材料的相互印证 |
| 4 | 闩门者为何这样行动 | 当时取得的请求、接受理由与实际行动；关系时长保留不确定性 |

原题“闩门之时，此人可曾听见门外的呼喊”要求完整因果回答。声源子题、完整论证、实际提交与正式接受分别记录。同伴的回答保留其本人署名；侦探以自己的依据完成正式答辩。

答辩到第 4 步为止。门开后，细看过窄手印的玩家可问“架上的手印，是你的吗？”，恶魔：“是。诸位封存之物，是我取走的。”（问及本人封存之物，须如实作答。）问过，它说“问得精确。……请。”；没问，它轻声说：“诸位……没有别的想问了吗。”恶魔不主动提契约条文；实际被依法问及仍按契约回应。

**新台账**：第二日接管配给间后，由实际接受记账职责的人从空白页登记，阮清月是具备动机与技能的默认候选。逐项区分清点、发放、预留、夜取、补记与差额；有病号或维修者未领晚饭，预留粮仍在账内，只有额外未记取用才形成差额。主粮仓的开启时间与清点结果依协作推进，不以断粮为唯一开锁条件。

**时钟与学习**：实际行动按声明的代价推进连续时间，阅读已获材料保持时钟。T 等待至下一件要紧事或制度钟点。课程更新实际收闻者的认识，缺席者通过补授或转述学习；入口安全说明经实际读取与理解发挥作用。

### 5. 系统

#### 5.1 认知、来源与传播
- 每条信息保留来源类型、提供者、时刻与内容；亲见、转述、回忆和推断分别记录。铜口的话同样沿实际听闻与理解进入认识。
- 转述由人物的目的、内容判断、关系和时间成本共同决定，保留原来源与本人添加的评价。
- 人物谈及已获规矩时，可说明自己从谁处听到以及如何理解。

#### 5.2 声望：存在于每个人心里
- 每个人认知中的侦探分“为人”（不撒谎、不冤枉人、说到做到）与“判断”（推得准、办得成），判断分领域（分配与对账／外出测量与劳作／安全与照护）。单项对接受的贡献有上限。
- 只有亲见或转述才会改变它。界面上没有声望值；玩家只看到人物的话、态度与之后的行动，笔记本“人”一页记下侦探亲眼所见的迹象与来源，分别记“认了你的规矩”与“嘴上向着谁”。
- 人物明确认可的底线按适用条件参与回应，同时保留本人已接受的例外与冲突处理方式。

#### 5.3 规矩的接受与执行

公共资源管理的研究提供监督、冲突处理和协作安排的参考。游戏中的效果依据各人的实际理解、资源掌控与行动产生。

- 规矩经阅读或告知送达，人物分别理解和接受。接受依据来源信任、目标、利益、证据和价值；群体协商通过具体提议与回应进行。
- **执行**：记录自觉遵守、分工、监督、协商、制止与处罚各自的实际行动及后果。执行者的能力、资源和滥权同样影响规则运作。
- **两个相互牵动的领域**：

| 领域 | 可争论的条款 | 有动机提出的人 | 必须面对的具体代价 |
| :--- | :--- | :--- | :--- |
| 内需：物资与照护 | 双签、公开登记与紧急补记；按劳动增补、病弱保障与预留；公开指控的证据要求 | 沃德、顾平章重程序与核验；阮清月计得失；茉拉、沈鼎关切照护与饭桌 | 登记延误救治、增补挤占别人的粮、护短造成不公；劳动能力不能由职业标签或失神一词直接判定 |
| 外拓：测量、通行与搜集 | 读数的地点、时效与复测；结伴、报备、停行和撤回；劳动分工与所得分配 | 赛尔玛、维罗妮卡测量；霍铎、玛格丽特维护；贝尔特朗巡查；其他人提供各自观察 | 采样与维修耗费人手、防护和口粮，保守停行也延迟补给；单点读数与结伴都不是普遍安全保证 |

每次提案依据本人已知库存、危险、责任与关系。人物可以要求同行、远处观察、核实或放弃。规矩记录对象、适用条件、例外、公布范围与本人理解。

- 公告在中央厅、配给间、起居厅、寝区与讲堂；张贴与传达是实际行动。锁闭粮仓内部不存放开仓前必须读写的公告或台账。
- **资源与通道的掌控**：配给间与粮仓钥匙、灶与饭桌、诊疗所与药、传声中继、公告位置、守夜点、气闸与外门、汲水与工作处都可影响执行。占有钥匙须由实际取得和移交产生，不按派系标签赠予。
- 派系来自实际共享规则和相互信任；按议题形成，不预先指定永久名单。赞同一条规矩不等于支持该人全部主张，未接受规则者也可能受到持钥匙者的限制；主观不认可不能消除客观拦阻或争议。

#### 5.5 粮仓与气闸的协作

内间粮仓的变形门闩与重锁分别需要结构检查、机械处理与细致开锁，人物可依自身技能组合方法；不能因剧情想留到第四日而禁止已经具备条件的开启。修好门闩、打开重锁与实际清点是不同进展。配给间可独立进入和取粮，修闩不等于主粮仓已开。

供水、炉火、照明的基本维持仍是恶魔的契约义务；人物承担扩建、产粮和自选劳动，不以它故意停供制造外出理由。气闸须查当前读数、检查密封、按操作规程启闭；同行、钥匙保管、记录与回报是人物制定的制度，不能改变世界危险法则。外侧读数须能从安全侧读取或用有防护的方法取得，不能要求先冒死出门才知道能否出门。名录库三站机关及封存匣留在后续章节，本章不要求开库换取安全知识。

#### 5.6 恶魔的博弈

- 它可谈人物的欲望、真实库存与既有规则，选择暴露某个真实片段，使听者补出未证实的罪名或安全保证；具体话语必须有其本人依据。学员是否接受依实际收闻和判断。
- 保命警告与最低限度教学仍须完成，不能靠漏报危险制造案件。前两章不主动提名录库位置、取回方法或导师身份；被依法问及的如实回应按第二部分处理。
- 操纵可以通过追问“有记录吗”“是谁定下的”暴露规则冲突；玩家可拒绝其暗示，不强制发生被骗、病倒或伤亡。

#### 5.7 口粮、伤病与个人目的

口粮、药品与病情通过实物、记录与观察呈现。身体需要与劳动负担参与分配讨论，侵蚀按第一部分 §2 发展。照护、康复、安眠与死亡各依其条件结算，并跨章保留结果。

莫兰希望比较不同位置、时刻的色层。他可以从安全窗内记录、请人核对仪器或同行，实际暴露依行动与防护产生。画作保留所见与绘画来源，安全判断结合仪器核验。

#### 5.8 首课《守则读法》

第二日上午北廊开放后，铜口邀请已出门者到讲堂。首课分别说明守则文字范围、通行条件和环境安全条件；封闭连廊的用途结合现场读数与气闸状态讲解。

实际教学包括源质计的读法、读数所代表的地点与时刻、风向变化、低洼夜禁、地震后停行复测和撤回条件。听者可以复述或据当前实例判断，回应暴露的误解须有后续解释；缺席补授见 §4。侦探可指出条文范围，未作答则不强制让其代讲。学会读条文不等于自动接受其他人的规则，更不能免除后续的新危险警告。

### 6. 《少了一份》（规矩第一次相撞）

**参考情境**：需要额外照护的人、未领晚饭的夜间劳动者、尚未协调的规则与可达配给间，可以形成以下争议机会。各条规则由提议者依据当时所知需求提出，公布与理解范围逐人记录。

- 沃德在中央厅提出先登记、必要时双签，怀疑雀儿并要求限制其夜间进入；是否有人认可、持钥匙执行，须实际发生。
- 茉拉在配给台提出：“急病需食者，或未领当日晚饭的夜间劳作者，可由本人或照护者先取一份；次晨配给前说明姓名、用途与数量并补记。”额度、时间与对象明确；修闩和确实未领晚饭时，雀儿才适用劳动例外。不满足时只能是误读或另有动机，不能称依此条合法。
- 阮清月可承担清点、发放与预留记录，提出日末核账与按劳增补。分配提案说明标准、对象与收支，人物依据实际需要和认可的规则回应。
- 若莫兰或其他人实际病倒且需要加餐，茉拉可能夜取一份、准备晨间补记；若雀儿未领晚饭、接受玛格丽特的维修请求、到达并读到适用条款，她可能取一份。未领取的晚饭若已预留，则依预留项扣减，不能又算一次“凭空少粮”。
- 贝尔特朗的夜巡只能记录实际可见的身影与行动；维罗妮卡若去取药材，必须有本人目的、可用材料和通路，不为增加嫌疑固定夜访，也不因此自动制得有效中和剂。

**清点与指控**：台账存量和实物不一致才有差额；两次未登记取用且此前无对应扣账时，清晨可能差两份。先清点、尚未到补记期限与逾期不补记分开。铜口只有在差额与到访真实且本人获知时，才可说“台账上，少了两份。昨夜，有人进过后勤院”；缺口改变就改变话语，无缺口不得照念。

**要查的事实**：谁取了什么、给谁、是否符合其所读条款、当时是否能登记、补记是否到期、哪位执行者认可哪条规矩。三块板并不自动推出“没有贼”；本人相信有权、条款确实适用、他人是否认可与是否存在故意隐瞒分别判断。满足参考条件时可以纠正把救护或合规劳动取粮定成盗窃的指控；确有侵占时不能为主题洗白。

**证物**：新台账的前后清点与预留项、领餐和补记记录、配给台与中央厅公告、空碗、饼屑、门闩维修痕迹、实际请托与目击证言。文献工房旧怨只解释成见来源，不证明本次未取粮。

**读与写**：用实际痕迹重演各人的信息与目的，再提出能执行的改法：公开预留项、急需先取后补、夜间可用的自记栏、见证与复核、公开指控须附材料。先让有关的人实际读到、理解并决定是否接受；下一餐或下一次劳动呈现规矩怎样运转，不直接跳到公约签字。

提前送饭、完成补记、协调规则或没有病人，均可能使案件不发生。此时对账确认具体收支和服务安排，记录实际完成的协调与仍存的分歧。若指控未解或执行不公，保留被排斥、拒绝合作和照护不足的后果；不强制所有人接受侦探的解释。

### 7. 《错规之祸》与成功避险

第四日地震与积灰是世界压力，夜里谁出门、是否出事由真实目的、本人知识、通路和执行决定。结伴不抵消毒性，高处白天读数不保证夜间低处安全；采样、检修、找人均须有具体所需，不能以粮仓“只够几周”自动迫使人当夜抢粮。

- **事故路径**：有人实际接受了缺少地点、时效或停行条件的规则，又据此进入危险区域，暴露达到相应程度，才产生病情、昏迷或死亡。记录是谁何时告诉他、他为何相信、是否听到更正、是否有人拦阻或施救；人数与身份不写死。
- **险情路径**：有人准备外出或已到入口，在看见新读数、收到警告或同伴劝阻后撤回。保留实际行动与阻止原因，不把未进入危险区称为重度中毒。
- **成功避险路径**：已有规则包含地震后停行复测，执行者落实，人物没有出门。第五日核对谁检查、谁收到通知、哪项工作延期及其物资代价；成功执行本身是“写”的后果，不需要险些死亡来证明。

第五日有案件则查实际因果，无案件则复盘规则执行与未完成劳动。判明某条规则有错，不自动证明所有听者都按它行动；同样，人物未认可规则也不代表守门人无法阻止其通行。严重伤病与死亡沿真实结果继承，不为全员签约恢复状态。

### 8. 第一部公约与章末

第五日清晨按 §4 的安全条件集合。议事讨论实际清点、配给、劳动、照护和测量记录，也允许提出有依据的风险与预防方案。每项提案保留支持、异议和未定部分。

| 议题 | 可谈的具体安排 | 需要记下的责任 |
| :--- | :--- | :--- |
| 粮水与伤病 | 标准配给、劳动增补、病弱保障、预留、夜取对象与额度、补记期限、复核和指控依据 | 谁掌灶、记账、照护和见证；缺人时怎样交接；谁承担增补挤占的份额 |
| 读数与气闸 | 测点与时效、读数核验、低洼夜禁、地震后停行复测、结伴、回报和撤回 | 谁测量、告知、守门与复查；例外不能豁免世界危险 |
| 拓荒与采办 | 温室与引水设施的后续修复、墙外采集、港路勘察与清理的顺序、所得归公与奖励 | 谁自愿承担、用多少粮药和工具、谁留守照护；第三章开始后才执行墙外任务 |

- 每条分别记录提议者、实际接受者、执行者、适用范围、例外和争议；只由实际愿意且能够签署的人签名。尚未统一的条款明确留白或列并行安排，人数最多不自动使未接受者服从。
- 未开粮仓时只写已知外间存量与开仓计划；已清点则引用有来源的余粮估算。库存不因议事自动向全员传播，要通过清点报告与实际听闻。
- 章末卡展示实际生效和未生效的约定、照护与劳动安排、未解旧怨，以及侦探亲见的信任变化。无人伤亡时如实写执行成果与代价；有人失去行动能力或死亡时如实保留，不强求十六人站齐。
- 名录库归属、取回分配、侦探封存匣不应名均不在本章兑现。作者侧既有机制留给后续章节；广播异响仅为可感知异常，不解释其来源。

### 9. 修罗线种子
“写”也可以用来操纵：贴字面为真、却把矛头引向某人的规矩，或安排片面信息先到某人耳中，或把尚未核实的读数说成足以出门的保证。获知操纵的人依据自己的理解与关系作出回应。系统记录每次操纵（对象、手段、是否被揭穿）。

### 10. 章节结束状态
写入存档并供第三章读取：公约各条的接受与执行状态、异议、粮食与药品实物、新台账、主粮仓是否开启及清点来源、测量与气闸状态、外出任务和延期、各人实际认知与关系、真实取回片段、侵蚀与伤病、住处、操纵、旧怨的事实澄清与和解状态、死者与安眠者。未发生的开库、取回或相识不填默认完成。

### 11. 侦探的推理位
十六人共用感知、兴趣与动机、行动选择、执行反馈、调查与推理机制。差异来自各自信息、采信、动机、经历和能力预算，玩家席位与模拟精度沿用同一语义。
侦探侧重信念重演、多步规划与来源核对。其他人物通过各自能力配置使用相同的推理机制，职业经验影响可行方法与信息辨识。合作来自实际能力、资源和关系的互补。

重复查看、拖延与调查失效需要核对共同机制、接线、内容声明和设计前提，依据实际因果定位问题。

## 第六部分：系统与界面

### 1. 世界、认识与回应

- 世界规律以具名公理声明前提、效果、版本与来源。物理执行、人物预测、推知与规范采纳分别记录。
- 对象、通道、切面、视界与历史版本具有稳定身份。信息经实际暴露、感知与传播进入本人认识，保留损失与不确定性。
- 人物关系包含有方向的信任、亲近、尊重与互惠。情绪和应对资源随实际经历变化。
- 请求依次形成理解、评价、意图与表达；接受、协商、延后、澄清和拒绝均有各自成立条件。
- 论证区分有效性、假设、置信度和世界真值；行动区分合法性、价值、能力与成本。正式采纳的硬约束、代价上下界与能力预算作为执行条件。
- 预测与重演使用独立分支；现实变化沿正式执行结算。历史查询读取指定版本的记录。

情绪评价与关系研究用于组织上述维度。项目的权重、阈值和回落方式属于工程模型，参数及标定依据在实现记录中说明。

### 2. 剧本、宿主与章节

**执行与显示边界**：DV 负责决策、报价、权威效果、观察、传播与结算。正式动作通过 prepare → 执行回执 → complete 推进；Godot 执行现场移动并返回结果，按所控者可知信息呈现。回执核对主体、行动与序号；到达、接触、观察和界面呈现分别记录。

**候选与对白**：候选行动与反应分别声明。条件确定适用性，人物依据自己的认识、目标、策略与代价选择；候选为空时记录无适用回应。对白表达实际选择及其依据。

**章节组合与继承（用户追加裁定）。** 脚本按章节拆分，后输入章节显式声明前置章节并扩展同一个世界会话。区分定义继承与运行状态延续：前者继承世界设定、实体类型、属性定义、人物初始模型和通用规则；后者保留玩家已经造成的物件变化、持有关系、人物认知/信任/欲望、已触发事件与任务进度。第二章不能重新执行第一章初始化，不能用初始默认值覆盖已发生的变化。

- 定义采用稳定实体与切面身份和章节命名空间；作者词项、主体内部投影句柄与客观身份分开。编译检查词项语法、作用域和冲突，运行时在指定主体的一致认知快照中解释中文切面词项，保留多义与未知，不按名称读取隐藏真相或静默选择第一项。解释后沿用已验证引用进入行动通路；已提交身体动作不因随后遗忘而自动取消，客观销毁仍按实际提交失败。后章可新增实体与交互，扩展既有定义必须显式声明；同名重定义、类型冲突、前置缺失和依赖循环均报错，不能静默采用后者。
- 同一会话顺序载入时保留既有人物、物件和认知对象身份。世界持久状态跨章存在；章节局部状态与一次对话临时状态具有独立作用域。章节退出只注销声明为本章有效的触发器，不清空世界；持久规则继续生效。
- 装载前先验证整个章节及引用，再提交新增内容；失败不得残留半个章节。重复载入已加载章节不得重复创建对象或发放奖励。章起始效果在明确激活时执行一次；装载内容本身不等于自动推进剧情。
- 后章修改初始模板不追溯改写旧人物；要改变当前世界必须使用显式效果并遵守行动提交与观察通路。剧情上销毁的物件不得因跨章重新声明而复活。缺少前章运行记录时可以显式选择新游戏初始化或测试夹具，但不能冒充真实继承。
- 每次认知提交生成版本，一次解释、评价或主观规划固定同一版本；历史以不可变变化和遗忘记录留作权威审计，不把已忘内容重新授予主体。主观推演只接已获知图、获准模型和显式假设，分支不持有源世界可变引用、不写回；预算、深度、无行动与未知结论分别报告。权威全真审计采用独立入口，不转作主体推演结果。
- 存档需保留内容/能力版本、稳定身份、已激活章节、世界状态、人物主观世界、触发记录及必要的时序/随机、行动/租约和回执状态；不同进程恢复后重建引用关系。只在明确支持的保存切点保存，未支持的活动状态或版本在写入前拒绝，不清零活动状态，不重跑初态覆盖当前会话。同一会话继承与跨进程存档恢复分别验收，前者通过不代表后者完成。

**内容与编译**：正式人物、世界、话语、公理实例、场景与自动验收逻辑使用原生 `.dv` 声明，译文按稳定编号维护。权威 oracle 独立分包。通用机制处理声明，生成物由编译器产生，分段按序编译与整体编译保持语义等价。旧 `.story` 保留迁移溯源用途。章节扩展沿用当前会话状态。

**认知运算**：表层语法围绕认知切片、主体理解、接纳与行动组织，核心代码使用英文，其他语言通过 `define token` 别名表达。`认知映射 × 感知切片` 表示认知映射记法，算法由具名法则定义。数值保留类型、单位、范围与约束；连续接纳程度、等级、置信度、真值和动作概率分别记录。新材料或相关依赖变化触发重评，曾采纳的解释失去支持时记录撤回，尚未采纳的解释被否定时记录拒斥。

**强制刻画**：根据声明的变换域、资源、守恒关系与代价求解满足目标的最小代价认知变化，并结算实际支付。结果区分可行解、已证最优、无解和预算内未求得结论。具体价格与变换条件由正式内容声明。

**参考**：《极乐迪斯科》的作者工具用于参考内容编辑、导出与预览的工作方式。

### 3. 共同界面与交互语义

各章共用界面组件与交互语义。宿主接收输入意图、核对执行回执、呈现结果；界面读取内容提供的文字、来源、候选和状态。

| 层 | 职责 |
| :--- | :--- |
| DV 核心与会话 | 通用世界法则、认知、决策、动作结算及连续会话 |
| 原生 DV 内容 | 人物、场景、话语、规则实例与章节扩展 |
| Godot 现场 | 真实路径、碰撞、位置、移动执行及现场回执 |
| 界面 | 对白、卡片、手稿、地图、设置和章末结果的显示与输入 |

界面呈现完成与世界动作完成使用不同语义。字段、路径和调用约定由现役接口与对应目录的工程文档维护。

**界面行为（两章完全一致）**
- 现场：点击移动与交互，WASD 移动，E、空格或 Enter 交互；可交互的物件与人统一高亮，悬停显示名称；普通家具一句心声。
- 证物卡：局部图、事实与来源，可发起本人试验；邀请同伴通过交谈提出。
- 对白：共享对白框与立绘；各章对白与候选由原生 DV 内容编译产物供给，人物回应按其认知与策略选取。
- 笔记本（Tab）：证物按地点分组；读过的规矩（谁立的、贴在哪）；人（侦探亲眼见过的迹象与来源，可能错）；回忆所得。
- 重演手稿（R）：所有章节共用 `UI/Panels/Manuscript/ReplayManuscript`，问题、选项、对照与证物名全由快照 `replay` 给出；左页变量，右页对照，“重演”后回放（单一地图的章节回放在实景上，多地点的一夜回放在学园手稿图上）。
- 对质：一问一答；题目与所选的陈述、出示固定在顶部，“陈述”“出示”两列各选一项后“作答”。
- 多日章节另有：顶栏显示日期与连续钟点；制度钟点到来时呈现相应通知；夜里在床前或守夜点选择睡下或守着；议事时选择站在哪一方。这些由快照与事件决定，界面不分章节。
- 墙上交互点按其朝向房间显示，实际交互依可达站点与接触条件执行。

### 4. 界面视觉规范（2026-10-10）

界面是学园自印的读物：现场类界面像一份岛上的报纸，翻阅类界面像一本近代博物书。年代取 19 世纪末前后的报刊与博物图谱；功能文字一律清晰易读，装饰只服务于阅读顺序。本节全部落在 `UI/Styles/*.tres`（由 `tools/build_ui_theme.py` 生成）与 `UI/Components/`，面板不自定外观；界面不自备章节内容，样式依据 §3 的内容与状态语义呈现。

| :--- | :--- |
| 1890 年代报纸（《纽约太阳报》头版、《Le Petit Journal》、《The Graphic》）、1889 年《时事新报》 | 报头与日期栏、叠题（主标题—短线—副题）、栏网格与栏间细线、加框栏目、竖排框题 |

| 近代博物书（海克尔《自然界的艺术形态》、狄德罗《百科全书》图版、《本草图谱》、汉密尔顿《Campi Phlegraei》） | 对开书页与古典版心比例、居中的图版与题注、衬纸、点线引导的目录与记录 |

**0. 案卷册子**：整套界面是所控角色手上的一本案卷册子。印刷体用于剪报、选项与表格，手写体用于所控者的批注、勾选与模型设定；内容的来源与证据等级另行标明；可点的东西始终是印刷体。标题页是桌上合着的这本册子；设置是册子的“凡例”，存档是“书签”，改键是“操作”页，三者共用一本摊开的册子（`UI/Components/PaperBook`），书口外是索引签。现场类与翻阅类界面按下列两种版式排在册页上。

**1. 两种版式**
- **报纸版式**：抬头、对白、证物卡、对质与表单、候选菜单、章末卡、标题页。纸面一张，内容按栏网格排；标题居中作叠题，栏间 1 px 细线，重要栏目加双线框。
- **对开书页**：笔记本、重演手稿、学园图。左页放图或索引，右页放文字；中缝一道浅阴影；版心按订口窄、书口宽、下边最宽的比例留白。

**2. 克制（硬规定）**
- 不为模仿报纸而添加信息。报耳、日期栏、副题、题注只在事件或快照里有对应字段时出现，不造词、不填充。
- 不加双语或拉丁文注记；项目本身支持多语言，界面只显示当前语言。
- 装饰（细线、双线、短线、框）只用淡色与细线宽，不抢正文；同一界面的强调至多一处（一个大标题或一个主操作）。
- 内容少时版面按内容收缩，不撑满整页。
- **操作呈现**：可点词用下划线，选项行表达选择，☞ 标当前项。控件和当前交互点显示对应键帽，改键项用笔迹圈出。界面通过清楚的结构、状态与反馈说明可操作内容。

**3. 网格与字号**：基线 8 px；边距、行距、间隔取 8 的倍数。字号五级：注 14、正文 18、副题 22、标题 32、大标题 48；标题页书名与通栏问题可用 64。每个界面最多用三级。

**4. 色板**（语义色统一定义在主题 `Paper/colors/*`）

| `paper` 纸 | `#EAE0C4` | 纸面 |

**5. 字体角色**（中文；每种字只担一个职务）
- **报头**：志莽行书（OFL），略加粗；弹窗标题、标题页书名。
- **主标题**：思源黑体特粗（OFL）；证物名、通栏问题、章末标题、抬头地点。
- **副题**：思源宋体半粗（OFL）；叠题副题、主操作文字。
- **栏题**：站酷庆科黄油体（OFL）；栏目与分组小标题。
- **正文与功能文字**：朝华打字机（库内仿旧印刷体）。
- **笔迹**：悠哉手写体（OFL），配笔迹色；所控角色本人写下的东西（选择的勾、作答的陈述、名字填空、推演结论、笔记本里本人的判断）。字体表示书写形式，来源与确定性使用内容标记。
- **英文与日文**（接入多语言时）：英文报头用哥特体、主标题 Playfair Display、副题 Old Standard 斜体、正文 Special Elite、笔迹 Playwrite（库内）；日文报头祐字（Yuji Syuku，库内）、主标题 Dela Gothic One、副题しっぽり明朝、正文 Zen Antique、笔迹 Zen Kurenaido（库内）。字体均为开源授权，接入时下载并随素材保存许可证。

**6. 组件**（`Paper.gd` 按变体创建，外观全在主题）
- **叠题**：小号说明（可省）—主标题—短线—副题（可省）。
- **选项行**：用于表单、重演手稿与候选菜单。左侧序号，右侧文字，下方点线；选中时文字下衬淡笔迹色底并在行尾画手写勾；不可用时淡墨删除线并在下方写原因。
- **按钮**：内容显式指定主操作，使用副题字加粗下划线；次操作使用正文字加淡下划线。提交类主操作排在最后。
- **正文内可点词**：RichTextLabel 的 `[url]` 标记，点线下划线，悬停转笔迹色，点击经 `meta_clicked` 回传；哪些词可点由剧本标注，界面不自定。
- **栏目框**：双线框，用于“我答”之类需要突出的一栏。
- **印戳**：只用于状态（相容、冲突、未查），小号单线框；冲突用印红，相容用相容色，未查用淡墨。
- 功能图标沿用库内 Material Symbols Outlined（Apache 2.0），只用于功能，不作装饰；指示手 ☞ 只标出当前选中或下一步。
- **摊开的册子**（`PaperBook`）：封板上两页横格纸（每 32 px 一道淡横格），中缝四级阴影（不用平滑渐变），左右露出书页侧边，两页各一道页边线；书口外一列索引签（汉字竖排），当前签伸出更长。左右页内容超高时滚动，页脚在右页底部、靠右排，次操作在前、主操作最后。
- **圈选项**（`PaperOption` / `PaperChoice`）：印好的选项并排一行，当前值外圈一道笔迹椭圆；不可用的项淡墨删除线，原因放在悬停提示里。
- **刻度尺**（`PaperScale`）：一道墨线、长短相间的刻度，当前位置一个笔迹勾，右侧笔迹读数（中文作“八成”，其他语言作百分数）。
- **键帽**：印好的键名，淡下划线；改键时该键帽被笔迹圈出，下一个按键即新键，Esc 放弃；与别的动作同键时行尾盖“重键”印戳。
- **书签贴片**：每条存档是一张贴在页上的纸片（缩略图、章节、地点与时刻、读至何处与已读时长）；空位只有一圈淡线。

## 第七部分：美术与视听

### 1. 人物美术

**总基调**：人物比例与立绘画法参考《重返未来：1999》的实际角色原画：清楚的二维轮廓、经过提炼的五官、富于表情的眼神、成组的发束、柔和的绘画色面与有节奏的衣料形状。年龄与体形分别设计，不给全员套用一个头身比或一张脸。衣着参考《光与影：33号远征队》等游戏的复古剪裁、层次与轮廓，保留各人的职业私服与文化出身，允许大胆的服装风格差异。

**人物识别**：每人须有独立的脸型、五官结构、眼形与眼色、发型与打理习惯、身高体形及姿态。统一绘画语言，不统一人物的审美与精神状态。侦探外表约27岁，深棕短发，东方与东欧骨相交融，沉静警觉且可以亲近；他与男女角色同框时都应有自然的交流感。广泛吸引力是设计目标，不宣称已取得最高受众接受度。

**服饰纹理**：强化具有身份意义的衣料织纹、刺绣、镶边、印花及文化图案；装饰性脏污、磨痕和褶皱保持克制；有证据意义的痕迹按实际状态清楚呈现，纹样与衣料色面须清楚可读。长短、宽窄、领口、闭合方式、层次、布料体积和剪裁须按人设计，避免全员外套、马甲、长裤的重复模板。纹样同样按人分配，不把同款菱形金边或植物刺绣铺满全员；朴素工装也可用帆布织纹、接缝和局部织带建立识别。

**颜色语义（全作统一）**：

| 颜色 | 专属对象 | 用法 |
| :--- | :--- | :--- |
| 琥珀 `#D9A13A` | 恶魔外观 | 用于其可见竖瞳与已识别形象；匿名物证沿物理材质呈现 |
| 纯黑 `#0E0C10` | 恶魔 | 它的燕尾服是全画面唯一的纯黑；学员最深只到炭黑 `#262833` |
| 印红 `#8A3324` | 印戳与红墨材料 | 匿名清册红墨、界面印章及后续文书可使用；颜色不表示导师身份。前两章无导师徽记、姓名或身份图例；学员服装避开这一红 |
| 手稿底 `#E6DCBF`、墨 `#2B2016` | 回忆与推演 | 触物回忆与重演回放用双色手稿调，与现实画面区分 |

**场内人物（二次元替换，2026-10-05 用户修正）**：二次元化主要通过放大头部和上身占比、缩短腿部实现，以约 3.5～4 头身的半 Q 场内人物为制作基准；不只是改变线稿和上色。采用清楚线稿、赛璐璐色面与富于表情的五官，保留各人年龄、脸型、身高体形、发型和服装差异。允许高分辨率非原生像素素材；只缩放显示节点，不改变地图和实际落脚点。
1. 剪影优先：每人至少一处剪影锚点在 32 px 下可辨认——斗篷（卢西安、顾平章）、围裙（霍铎、沈鼎）、长裙或裙裤（伊莲娜、茉拉、玛格丽特、阮清月）、罩衫或长罩衣（莫兰、维罗妮卡）、风衣（侦探）、肩垫与绑腿（贝尔特朗）、最矮身量（雀儿）、长髯（顾平章）。
2. 每人的（发色，主衣色）组合唯一。黑发者（沈鼎、苏泠、雀儿、阮清月、伊莲娜）必须靠衣色与剪影区分；蓝色系三人按明度与色相分开：苏泠炭黑、沃德海军蓝、玛格丽特普鲁士蓝加铜色滚边。
3. 空手前站是身份基准；工作器具只在“操作”帧出现，按场景任务取用（霍铎扳手、沈鼎厨刀、苏泠音叉、雀儿发簪、莫兰炭条等）。
4. 墨线用 `#1A1418` 一类暖黑，不用纯黑（纯黑留给恶魔）。

**对白立绘（正常比例，通常显示上半身）**：台词左侧立绘采用正常成人头身比例，与场内放大头身占比的动作人物分别制作；保留同一人物的脸型、发型、年龄与服装身份。六种情绪为平静、思索、动摇、愠怒、温和，以及“失神”（片刻失神：瞳孔略散、视线偏向画外），每种表情配合相应手势和姿势。光从左上，允许非像素高分辨率透明素材。源图归 `AssetsSource/Internal/Characters/DialogueCast/`，运行时归 `ShareAsset/Internal/Characters/DialogueCast/`，由 `tools/build_dialogue_cast.py` 注册；剧情用显式 emotion 标签切换，未指定时使用平静立绘。“失神”表情依据人物当时的实际症状出现，不加数值提示。

**双人设计检阅图（全身）**：两人完整入画并使用共同尺度，脚部不裁切；用对视、朝向、距离与手势表达关系，不让同框自动等于爱情。检查脸型、发型、体形、身高、年龄、服装轮廓与重要纹样是否分别成立，再检查两人的组合是否具有视觉张力。概念检阅图不受对白半身构图约束，也不当作地图像素帧交付。

**立绘方向**
- 稳定的个人特征与具体场景中的情绪、精神及身体状态分别处理，状态由剧情依据决定；不要求全员年轻、微笑或精神饱满。未明确的眼色等细节属于试稿选择，不反向成为已确认设定。
- 制作参考使用明确的文件与版本，先查看实际参考图再确定取用特征。场内角色与对白立绘分别按本节规格制作。

### 2. 地图与场景

- 地图保持 32×32；二次元人物使用高分辨率透明动作表，依据实际脚底配置显示缩放与偏移；碰撞盒仍为 16×12、中心 (0, -6)，遮挡按世界脚底 Y 排序。重演墨影沿用场内动作比例；对白立绘使用正常比例，以共同的外貌和服装保持身份一致。
- 场内人物放大头和上身、缩短腿，约 3.5～4 头身，同时保留成年与老年身份，不把全员画成相同幼儿脸；空手前站为身份基准，工具按场景任务取用。

### 4. 音乐与音效

原声使用可编辑曲谱与可复现的源数据，输出总谱、MIDI 与游戏音频。素材来源、许可、音色映射与生成入口随制作版本记录。正式原声曲目见下表。

**曲谱与源数据同步**：手工曲谱与可生成的源数据保持一致。生成前核对声部、音色、移调、音符、时值、力度、文字、演奏法和速度；差异保留并报告，重写依据用户授权进行。试听导出与游戏音频分别保存。

**门句动机**：情感核心是“开门”只是“不要开门”的后半截（第四部分 §1）。动机一小节四拍：前两拍两个下行弱音（不要）D5–C#5–B4，后两拍上跳五度的呼喊（开门）F#5–E5–F#5，停在属音上像一个问句。只出现后半截时是门外的“呼喊”；完整出现是真相；主题尾声里后半截第一次落回主音（B 大调），问句得到回答。恶魔的和声是阻碍终止：旋律给出正确的落音，脚下换成别的和弦（字面为真）。

**结构规则**（用户裁定，2026-10-04）：背景乐每首只保留一个主题、一种织体，循环时不分段、不发展，只维持气氛；多段与多种演奏形式只用于主题曲与日常变奏。全部变奏都从主题 A 的八小节变出，全作只有一个旋律身份。东方与中亚、印度风格以主题的变奏出现，不点明国别，学园的东方背景不在音乐里强调。

配乐全部无缝循环（渲染三遍取中间一遍，接缝处余音与混响连续），响度对齐到 -19 dBFS RMS；宿主 `GameAudio`（自动加载，`scenes/Shared/Audio/`）以两条轨交叉淡化，重演回放时压低 9 dB。场景经 `Sound.gd` 调用，必需资源缺失时记录具体错误；可选预览按其声明范围播放。
