# CLI 模拟、剧情与截图合同

本合同依据本轮用户要求和 `design-standard.md`。当前策略继续使用生产 DV 会话与正式 Prepare → 现场回执 → Complete；作者既定历史、开局条件、环境法则与人物自主行动分别保留。

## 修改与运行顺序

先完成整批性能、剧情、CLI 呈现和记录工具修改，再构建并运行。每轮 AI 进程从启动到退出最多 45 秒，默认 41 秒内请求自主推进、4 秒留给在途调用和关闭封存，关闭预留包含在这 45 秒之内。最后 250 毫秒预留终止与回收，44.75 秒独立 watchdog 保持有效；超时如实保留失败或部分证据。构建、只读回放导出和截图审查分别记录耗时。发现差异后完成下一批修改，再开启新窗口。不得在修改途中以测试、探针或校验脚本反复试跑。

## 速度口径

以正式游戏时钟的实际前进量衡量模拟吞吐，同时列明真实剧情节点。正式选择、完成、待回执与最后可恢复状态分别统计。保留游玩窗口、完整进程耗时、初始化、引擎排他耗时、投影和封存耗时；未经本轮记录不外推多日或 Godot 现场性能。减少选择频率、浅层近似和缓存都标明策略来源，观察、支付、判答与权威效果保持精确。等待只推进到真实声明的环境、义务、排队执行或中断边界。

可提前中断的纯等待须显式声明 `interruptible=true`、`activity="wait"`、`kind=wait` 或 `wait.*`，并满足 `minimum.time=0`、`actual.time>0`。只接受本人的实际新听闻、观察或当前可见变化；按真实 elapsed 继续 Prepare → receipt → Complete，非时间费用照常结算。原完整等待法则不执行，不进入 `completed_actions`，不以普通拒绝签名封锁后续等待；`failure_class=activity-interrupted` 与普通失败分列。完整且输入未变的认知捕获允许 guard 在无来源恒真 topic 上休眠，不为条件真值补造知识。

## 内容和呈现

晨间广播与始业之问属于 08:00 开局义务，后续调查依据实际收闻开始。甲、丙、丁的人物行动取决于各自初始材料、现场发现、动机和环境压力；设计中的具体未来时刻作为对照目标。人物发言和旁白保持本人可知范围，试验正文展示真实地点的听觉结果及实际报闻来源。未知学员、未辨明的铜口声音与已听闻自称的代管者使用相应称谓。

带来源的实际 `pending_heard` 自介仅供只读“自称某某”显示，并进入称谓与几何缓存依赖；它不等于本人已采纳姓名。未知人物使用稳定匿名编号，候选 `label_parts` 只从行动者自己的无争议字段取得姓名。判答只呈现本人真实 judgment 的 reason、stage 和正式回执，不补造恶魔对白或公开私有条件；普通失败与等待中断使用各自的保守反馈。

房间作为一级列表，人物与物体作为二级列表；主观地图保留未知，客观地图仅供显式检阅。候选标题表达行动意图；检视和试验结果在成功 Complete 之后出现。人工、模型和引擎控制共享先聚焦、后执行的回放逻辑。

最新正文在候选和地图之前全宽呈现。引擎默认仅显示选中项已有短分，`scores on` 展开评分并显式请求即时估值，`zoom detail` 展开已有细节；人工与 LLM 默认隐藏评分。停录只标明本次记录的边界，不宣称剧情完成。JPG 通过真实字体 cmap 回退保留 `✕`、`✓` 等原始符号及 SVG 格宽、基线；缺字明确失败，不替换字符或生成近似图形。

## 截图与审查

原始会话、输入和回放保持二进制记录。JPG 从实际记录的 CLI 画布导出，索引关联帧序号、聚焦/执行阶段、游戏时刻和图片路径；重复画面的合并必须保留覆盖关系。每轮完成后由子代理查看全部实际导出的图片，逐项对照设计规范，记录可见差异、对应证据与未覆盖段落。用户本轮这项明确要求覆盖旧 AGENTS 中独立盲审不得读设计的通用规则，审查子代理须读取设计并逐图核对。只读回放不新增 AI 决策，不修改或补造原始事实。

本任务固定输出位置为 `artifacts/cli-ai-optimization/current/`。下一轮在前一轮审查完成后替换本任务旧输出，不覆盖其他任务或把不同版本记录合并成一轮。

## 当前实施边界

本批等待中断、固定点 guard、称谓与判答呈现、正文布局、短评分、41+4 秒预留及字体回退均只完成源码实施，尚未进行下一轮实际会话和逐图验收。当前 CLI 未打开 live `RawDagWriter`，最近实测 `world_cut` 未生效，不能声称这条压缩已经改善性能；完整历史未删。规划器内部墙钟硬期限尚未实现，外部 watchdog 不能替代它。已完成的实测和三代理评估见 [cli-optimization.md](cli-optimization.md)，不与本批未测源码混为同一运行结果。
