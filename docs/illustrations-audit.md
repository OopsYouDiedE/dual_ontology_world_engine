# 旧25镜分镜审查（历史记录）

> **历史资料，非现行分镜、资产清单或制作指示。** 本页记录早期25镜概念稿的来源与当时审查发现。过去的逐镜“应制作”“需补齐”和时间线判断已撤下，避免再次按旧方案扩产。首宣以[现行75–80秒大纲](游戏和核心宣传视频和图片录制/机制主线宣传片大纲.md)为准；世界观以[学园设定](academy_setting/academy-game-design-zh.md)为准，验收以[设计规范](design-standard.md)为准。

## 旧素材的身份

旧主题影片的分镜首帧、原提示词及音乐时码存放在[概念档案](../artifacts/theme-film/README.md)。这些图只证明当时构想过相应构图，不证明镜头、动作、房间、规则结算或游戏内录制已经完成。旧图的编号保留用于查找来源，缺号及未生成图片的提示词不能当作制作缺口要求补齐。

旧提示词把地图格写成48px，且人物比例、职业器具与当前游戏资产规格不同。当前地图基础格为32×32，角色基础设计帧为32×48；源素材按原生尺寸切片，进入游戏后仍须验证比例、接缝、遮挡、碰撞及动作。旧图不能直接转换为运行时资产，不能把缩放派生称为原生像素重绘。

旧01/02/03对应的中央厅、早餐厅、围谈场景已有[Story剧情打样](../godot_csharp/scenes/Story/README.md)，这些是可操作的剧情原型，不等于首宣三场都要出镜。脑内推理和言灵分别有[独立机制原型](../godot_csharp/scenes/Reasoning/README.md)，它们尚未与恶魔授课、真名救场或未来决战连成一段可玩宣传内容。现有动作图集、概念首帧、对白和尺寸检查各自只能证明被检查的部分。

## 已撤销的旧判断

| 旧镜号或安排 | 当时方案 | 现行处理 |
| --- | --- | --- |
| 01–05 | 远景后依次早餐、聚会、音乐、棋局 | 首宣只用约12秒建立日常与人物好感；其他旧图仅供空间和情绪参考。 |
| 06–07 | 恶魔与导师同场的言灵失败、导师观察后订正 | 事故后恶魔可以具象授课，四位导师不出镜。现行15秒课堂由有言灵适性的学生精准命中目标，恶魔作关键提点或赞许；旧“恶魔不能可信授课”的审查结论已撤销。 |
| 09–12 | 阵法纠错与导师救场 | 退出首宣。不能把旧导师救场图改名充当恶魔真名救场。 |
| 13–17 | 脑内研究、编写、多人模拟、失败和重试 | 只复用“同一问题、真实输入、差异、修订”的因果；现行约30秒由恶魔提出当时所知的关键问题，学生自行修改重演。 |
| 19–20 | 规则改变现实通路及范围过宽 | 现实规则展示留给二宣；旧通路图不证明现实人物决策或规则接入。 |
| 23–25 | 核心隔离舱、四锚大阵和完整反制 | 首宣只要约8秒可落实到游戏中的未来对峙一瞥。完整四锚终局须另做玩法与资产验证，不能由旧图或剪辑宣称已可玩。 |
| 26及旧曲谱 | 《The Unfallen Duet》旧标题、2:10.333排期、逐小节切镜 | 只作历史音乐与视觉资料。首宣片名采用《安眠者有福》，75–80秒配乐按实录重排。 |

真名打断是新的剧情演出：先让观众看见学生受到认知危险，再以黑影逼近、白手套压住真名载体、短促失焦与声音骤停表现恶魔本能救人。其操作对象、场景站位与演出后状态都须在游戏中落实；旧25镜没有对应的完成资产。

## 引用与验收

旧图和原提示词由概念档案保留，版权、来源及原创源保留要求不因退出首宣而消失。现行制作仍按“玩家操作或剧情触发—实际规则或状态机—可见结果”检查；Dialogue可以组织演出，不能代替脑内推演与言灵结算。场景、资源和代码以当前实际引用为准，文件名及“完成”字样不构成验收。
