# 回合与异常反应模型

## 1. 设计来源

引擎从规则怪谈中借鉴矛盾规则、局部异常，以及信息来源与客观机制的分离；从《咒术回战》中借鉴代价交换、束缚、术式权限和局部规则；从《诡秘之主》中借鉴言灵寻址、仪式、授权、污染与身份锚定；从《魔法少女小圆》中借鉴愿望契约、灵魂载体、精神污浊与主体相变；从《JOJO的奇妙冒险》中借鉴高度个体化的能力规则、信息差、作用距离和条件反制。

## 2. 时间与交互

游戏采用**回合制主体框架**。玩家和 NPC 在回合中进行观察、推理、言灵构造与行动选择；异常背景在行动执行期间以**反应子回合**介入。

玩家通过 QTE 或限时选择提交反应，NPC 由其感知、认知和决策系统提交反应。QTE 只替代瞬时反应判定，不能绕过角色的知识、权限、身体条件、资源和客观规则。

## 3. 统一行动模型

所有主体只能提交标准化意图，不能直接修改世界：

```text
玩家 / NPC / 异常主体 / QTE / 预设反应
                    ↓
                  意图
                    ↓
      条件核验、时间展开、冲突解决
                    ↓
                  事件
                    ↓
                  效果
                    ↓
                原子提交
```

- 决策系统决定主体想做什么。
- 条件系统判断动作能否成立。
- 时间系统判断动作何时成立。
- 规则系统解释事件意味着什么。
- 资源系统验证代价及其来源。
- 事务系统提交或回滚最终变化。

自然到期、环境变化和延迟诅咒等无主体变化，直接作为计划事件进入同一结算流程。

## 4. 因果批次结算

同一因果批次中的候选效果基于同一个初始世界版本求值：

```text
提交意图
→ 展开候选事件与效果
→ 检测异常介入
→ 必要时开启反应子回合
→ 根据反应重算效果
→ 解决冲突
→ 原子提交
→ 由新状态开启后续因果批次
```

效果可以有生成和反应顺序，但最终状态统一提交。外部系统不能观察到批次的中间状态；批次无法收敛或违反公理时整体回滚。

## 5. 规则怪谈的认知分层

规则文本不自动等于客观规律。系统必须分别保存：

| 层级 | 内容 |
|---|---|
| 客观机制 | 世界实际执行的条件与结果 |
| 信息记录 | 告示、广播、笔记及他人陈述 |
| 主体认知 | 角色对信息的理解、怀疑和推断 |

NPC 可以依据错误认知提交合理意图；意图是否合法及其真实结果仍由客观世界核验。

## 6. 触发与检定

引擎不在每个短时间步扫描全部规则。只有以下情况触发增量检定：

- 相关状态发生真实差分；
- 定时事件到期；
- 状态跨越规则阈值；
- 主体进入或离开作用范围；
- 新的感知、理解、身份、关系、权限或资源状态成立。

同一规则面对同一目标和同一输入版本只求值一次。连锁影响运行到局部稳定点后提交；重复支付、自引用、振荡或无限传播导致批次失败并回滚。

## 7. 核心结论

本引擎采用：

> **回合制决策、异常反应子回合、统一意图接口、因果批次求值与原子结算。**
