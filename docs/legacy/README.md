# 历史美术源追溯

本目录仅保存历史素材的原创源图和生成提示词，用于来源追溯与授权核对，不属于当前游戏运行资源。当前项目规格与资源使用边界见 [设计标准](../design-standard.md)。

历史 `art_assets/` 现归档在 [`artifacts/theme-film/concept-archive/legacy-art-assets/`](../../artifacts/theme-film/concept-archive/legacy-art-assets/)，包含native48原图、旧RPG48素材包源图、旗帜成品、提示词与原始ZIP。它们不是当前游戏生产源或运行资源；当前身份资产以Godot Identity README登记的独立源与重建链为准。

> 历史源稿中的48px规格仅描述旧产物，不是当前制作要求。现行地图基础格为32×32；原图与提示词保留用于追溯，未通过实机资产验收。统一规范见仓库 `docs/design-standard.md`。
