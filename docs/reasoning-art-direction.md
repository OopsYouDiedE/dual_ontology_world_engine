# 推理界面：现实、札记与脑内工作区

## 2026-09-29 动机还原修订

当前规格见[人物行为规则与脑内推理](detective-reasoning-interface.md)及[初醒动机设计](academy_setting/first-awakening-design.md)。保留直接书写、词语插入、精简常驻控件和纸面视觉；脑内还原驱动动作的规则，规则本身就是动机；现场调查提供经过依据。沿用现有纸面，不新增独立动机界面、问卷或目的字段。词汇自由组合，不按职业或作者分工限制人物；五处决策仅作导航，不改成固定选择题。旧物理回放可供复核，不再靠踩中痕迹解锁动机或答辩。以下是历次视觉与交互记录，其中旧三词槽通关和动作稿主流程不再作为新玩法规格；截图只证明当时被检查的版本。

## 2026-09-26 初醒界面审查与用户纠正

本节记录用户确认要求；下方历史问题已在2026-09-26的FirstAwakening界面修订中处理，具体以本节实现记录与实机截图为准。用户再次明确：保留直接输入，追求如 Apple 般简洁，删除多余文字提示。此前已确认的纸面直接书写、词语插入光标位置、帮助按需展开继续适用于 FirstAwakening；不可用整句按钮拼接替代直接编辑。直接输入沿用受限行动语言与必要的句法反馈，不等于任意自然语言自动判案。初醒设计稿的答辩词槽约定不得被扩张为禁止脑内行为草稿直接输入。

修订前 FirstAwakening 的问题：右侧大纸面只能点句修改，下方同时摆人物、条件、动作和编辑操作；留白没有形成明确操作层级。禁用动作和答辩选项仍露出完整解法。减少文字应通过精简控件与渐进呈现完成，不能把所有按钮变为低对比小字。保留清晰的输入焦点、选中状态和必要错误反馈。

常驻内容以现场回放、可直接编辑的草稿及必要播放/重演操作为主。空白草稿只给一条可实际运行的例句；词汇按需展开。删除“无需猜出……”等作者说明、重复模式标题与泛化教学文案；规则错误指出实际不符之处，不直接补出正确行动顺序。不要以增加指导段落解决可操作性。

### 初醒实现记录

FirstAwakening的右侧纸面现为可直接输入的TextEdit，受限行动语言按行解析，不用整句按钮替代书写。词汇面板默认折叠，人物与行动词插入当前光标并返回编辑焦点；不预填答案。语法错误定位具体行，空白或非法草稿禁用重演。编辑暂停旧回放、清除待印证请求，并禁止旧结果核对；返回现场再打开保留未提交文字。解释编译到原有Core事件，撤楔后的配重合门仍由原行为组织器衔接。

对话采用深绿平面面板，保留人物、正文、继续/回应及历史回看，删除章节重复标题、分隔竖线与常驻操作提示。八选项按两列排列。答辩保留既定三词槽机制，改成按项展开已解锁内容，删去大段说明及未解锁完整答案。该输入机制与脑内草稿直接书写分开。

实际截图固定归artifacts/first-awakening：dialogue-preview、dialogue-broadcast-preview、transmitter-preview、replay-empty-preview、replay-vocabulary-preview、replay-preview、replay-edit-preview、replay-conflict-preview，以及answer-locked/filled-preview。截图设置的案例用于布局检查，不等于未经引导的玩家解谜验收。

### 日本平面设计图片参考

2026-09-26 查阅以下作者/机构原站。以下用途为本项目的设计判断，不代表原作者对游戏界面的建议；参考作品不作为运行时资产。

- [原研哉《DRAW》](https://www.ndc.co.jp/projects/draw/)：官方页含封面和内页图片。参考纸面、线稿、正文和页边的层级，用于直接书写工作区；避免添加仿旧噪点与装饰性说明。
- [大黑大悟书籍设计](https://daikoku.ndc.co.jp/work/books/)：重点看《皇后美智子さまの御歌》及《椿山荘三重塔》。前者参考图片与文字的阅读节奏，后者参考线图和文字组织机械结构说明；不照搬日文竖排到可编辑行动语言。
- [色部义昭 TAKEO PAPER SHOW 2011「本」](https://irobe.ndc.co.jp/en/work/takeo-paper-show-2011/)：官方完整图片组，用于比较字级、重复单元、书籍与展示导视的统一关系，供札记分类和选中状态设计参考。
- [21_21 DESIGN SIGHT「もじ イメージ Graphic 展」](https://2121designsight.jp/program/graphic/)：参考汉字作为图形的构图方法，适合章节标题与宣传视觉；高密度叠字不用于推理输入区。

优先研究方向为《DRAW》的书写版面与大黑大悟的图文编排；沿用已确认的深绿和米色基调，颜色、字体和版式的具体变化须以新的可操作截图审看，不能以收集参考代替完成设计。

当前入口为 `res://scenes/Reasoning/Reasoning.tscn`。本轮实现界面分离与控件主题，仍是待用户视觉确认的原型，不代表案件、美术或十至三十分钟体验已验收。

现实调查保留全幅 TileMap、侦探移动与现场物品。札记只收录已取得的材料，打开后集中阅读正文与来源；没有人物规则或模拟结论混入。脑内使用独立场景实例、人物和 World2D，复用房间资产以便识别地点，但不复用现实中的可变对象。返回现场保留侦探位置。模拟回看不会写回现实，也不会解锁新证据。

脑内工作区左侧显示重演和时间轴，右侧只编辑当前人物的行为假设。“当时所知”默认折叠，显示当前回看时刻的人物认知，明确标注为假设中的信息。语法帮助单独展开。查阅证据时遮蔽工作区并暂停自动推进；修改草稿后必须从头提交，旧回放不会被当成新方案。

2026-09-24 脑内工作区按用户提供的 Mental Replay 参考图重新排版：深绿底、左侧纸边场景、独立播放与回退/逐步控制、右侧整张米色书写纸，词汇和重新提交入口放在纸面下方。`TeaReplayLayout.cs` 负责这一工作区的布局与局部主题，现有 `ReasoningTheme.Create` 继续负责现场及资料窗口。地图保持原生整数倍率；参考图的英文、钟表时间和示例错词不作为案件事实或新增语言要求。

人物标题和规则当前优先使用简体中文系统楷体（KaiTi），再回退到简体中文系统字体；跨系统实际字形仍须审看。清松手写体5（SIL OFL 1.1）保留为另一套候选，字体源与运行时副本分别归 `AssetsSource/External/JasonHandwriting/`、`ShareAsset/External/JasonHandwriting/`，附来源与许可证，但当前推理草稿不加载它。辅助文字使用系统宋体。规则正文保持清晰纯色，不叠纸纹。当前没有逐词拼写纠正；解析器给出人物、行号和错误说明，对当前人物的错误行着淡红底色。任何人物草稿非法都会禁用从头重演，旧记录仍可回看；修正后恢复提交。

下方词语点击后插入当前光标位置，并把焦点还给书写区；句式与可用对象仍以现有中文行动语言为准。时间轴显示已生成的记录范围与实际模拟时间，不伪造全天时间。回退只移动回看帧，不逆改世界状态；每次重新提交仍从案件初态计算。

参考 Apple 的[布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)、[按需展开](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)和[独立模式](https://developer.apple.com/design/human-interface-guidelines/modality)：借用层级、留白、明确退出与渐进呈现，不直接复制平台的玻璃外观。实现采用 Godot 官方[Theme / StyleBox](https://docs.godotengine.org/en/stable/tutorials/ui/gui_skinning.html)机制，主题作用于本场景。

按本轮要求参考旧动物园的 `archive/zoo/csharp-sample/zoo/zoo_simulator/README.md`：保留“人物相信什么、为何作出选择、世界实际结算”的区分。没有移植旧实验任意改写认知、制造幻觉的权限，亦未恢复旧对象系统。

验证使用实际 Godot 窗口：调查收录、规则非法提交保护、连续播放、回看、两个 World2D 相互独立、脑内按键不移动现实侦探、返回现场与草稿保留。截图位于 `artifacts/tea-reasoning/`。临时铃声时间、整案证据与多解仍按场景 README 的未完成边界记录。
