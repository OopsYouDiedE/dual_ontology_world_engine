# 《安眠者有福》剧情总脉络与呈现边界

> 2026-09-27 梳理。本文按现行默认入口、初醒设计和学园设定归并剧情，不把设定储备或独立样片写成已经连通的游戏章节。需要改动既定世界事实时，先修改对应源规范。

## 一句话主线

十六名失去在校记忆的学员，在恶魔代管的孤岛学园里重新认识自己与同伴。他们一面依靠学园存活、学习和修复设施，一面追查导师牺牲、恶魔泄露和记忆封存的缘由；最终要以自己验证过的知识重建封印，保有记忆离开，也始终可以选择安全退场。

剧情的核心矛盾不是“找到反派并听它说明真相”，而是：恶魔确实教会并保护学生，同时希望学生用所学替它拆除束缚；学生必须判断每次帮助的代价，亲手取得证据并承担行动后果。

## 作者侧时间线（玩家开局不知道）

1. **入学与数月生活**：十六名学员进入学园的具体方式未定。侦探等四人在生活翼长期住宿、研习，留下磨损、修补、练习纸、杯子与木盒的相互对应痕迹。四人保留入学前职业与人格。
2. **地下研究失误**：导师组试图以言灵、机械、仪式与医学观测拘束恶魔并提取源质；认知偏差和时间校准失误使容器破裂。这是大局事故，不是初醒案能够直接证明的事。
3. **生活翼当夜**：主楼异动和灰黑热烟传到隔离门。音乐家以木楔撑开自闭门探视；侦探撤楔使门闭合，工程师插上内销；音乐家移开止挡座，厨师擦地；侦探用自用练习纸包起沾灰木楔。四人之后正常入睡。
4. **契约与封存**：四位导师牺牲，以生命和存在建立保护十六人的契约。恶魔按约封存在校经历与立场，保留入学前身份和技能；它从门外主楼侧落下外闩，未进入生活翼改造内部物证。契约限制其离校、直接伤害或控制学员、亲自破坏束缚，并要求公开稳定规则、保留真实胜路和生存条件。
5. **苏醒**：四人醒在自己的生活区域，但不记得此处的经历；其他学员在不同区域面对各自的初筛。其余人的具体闯关经过目前只有背景设定。

依据：[初醒案设计](first-awakening-design.md)第五节、[学园设定](academy-game-design-zh.md)第二至四节。以上是作者知识，不应直接成为开场旁白、人物记忆或铜口答案。

## 玩家实际经历：现行可玩首章

| 阶段 | 玩家面对的问题 | 玩家可做的事 | 到阶段末可确认的事 |
| --- | --- | --- | --- |
| 宿舍醒来 | 这里为什么像自己的房间，却完全不记得？ | 移动、检查寝具/笔记/包纸，走出房间 | 现场有生活痕迹；笔记有未解私人指代，不能直接解释事故 |
| 结识三人 | 他们知道多少、信谁？ | 找工程师、厨师、音乐家谈话，检查杯片、补线、盒底与公共空间 | 各人记得职业，不记得在校经历；他们对同一痕迹可能各自误读 |
| 铜口与封闭门 | 谁在问话，门为何打不开？ | 阅读装置守则、接通传声口；检查内销、外闩、门向、配重、灰迹 | 有内外两套锁止；发话者提出考验和退场途径，但没有提供可信日历或事故真相 |
| 四人会议 | 牢房、御敌、越狱三说哪一个经得起物证？ | 收集会议要求的物证，在长桌前逐项辩驳 | 三种解释各有直观诱因，也各有物理或操作主体上的反例；同伴推侦探答辩 |
| 脑内推演 | 哪些过去行动能留下今天的痕迹？ | 写人物行动，重演，从同一初态比对已调查痕迹；修改、重试和回现场核验 | 某条行动链与现有证据相容；相容不等于唯一的历史证明 |
| 正式答辩 | 能说到哪一步，哪里必须承认未知？ | 在铜口旁组合场所、门因果与外侧锁止论据并提交 | 有依据的“长期居住史”或“新生考场”两种答法均获通过；也可安全退场并失去此地记忆 |

运行依据：[初醒对白](../../godot_csharp/scenes/FirstAwakening/first_awakening.dialogue)、[场景状态与答辩条件](../../godot_csharp/scenes/FirstAwakening/FirstAwakening.gd)、[操作说明](../../godot_csharp/scenes/FirstAwakening/README.md)。当前默认入口到首章结局为止；上述顺序是剧情梳理，玩家在区域内的探索次序并非全部固定。

### 首章的知识边界

- **客观发生过**：四人曾在此生活，主楼发生异动，四人自主关门并处理灰迹，之后记忆被封存，恶魔从外侧加闩。
- **玩家能较强支持**：这里有长期研习和日常使用的痕迹；门曾撑开后闭合；内销和外闩分属两侧；几种惊险解释无法解释全部痕迹。
- **玩家尚不能唯一证明**：当前绝对日期、距约定入学日多久、谁造成主楼事故、恶魔或导师的契约细节、自己是否在此住了数月。故“新生考场”是物证相容的合格回答，**不是**作者侧实际历史。铜口应认可论证的边界，避免宣布相容解为历史真相。
- **笔记伏笔**：末页的“旧例、那一回、原来的、那一项”留待后期与原件和独立材料交叉验证。首章不应让角色凭空解开。

## 首章之后：已定的大局方向，尚未连成剧情章节

1. **重新进入公共学园**：从封闭生活翼转向中央厅与公共区域；和其他已通过初筛的学员汇合。需要一场正式的门禁/通路、身份和信任过渡，现行工程尚无这一章。
2. **在日常中重建关系**：早餐分工、听钟、娱乐室围谈等片段展现人际关系与可维持的生活。现有[前三场样片](../../godot_csharp/scenes/Story/README.md)可单独游玩，但没有绑定首章结局，不能推定它们发生在苏醒前或苏醒后某一具体天。其对白里的“才住了几天”“这几天”要等桥接时间线确定后校正。
3. **学习与调查并行**：学生修复厨房、水务、工房、诊疗和研究工作站，调查遗物、记录与设施；接触材料可恢复真实但主观的记忆片段。人物之间会因保全生活与冒险探查产生真实分歧。材料本身不自动宣布客观真相。
4. **辨认恶魔的双重关系**：恶魔公开规则、授课、阻止危险，也在规则许可范围内诱导学生破坏封印。学生需通过可操作的言灵、推演与设施事件，发现“它救我”和“它利用我”同时成立。
5. **查明事故与四锚**：从四座研究院分别取得真名结构、仪式阵图、机械隔离机构和安全载体；在地下层把导师遗留的语义、能量、物理、认知四条防线与事故证据对上。到达核心隔离舱不等于已经能封印。
6. **终局选择与执行**：既定胜利方向是查明真名、理解封印、实际准备材料并完成封印，保有记忆离岛。安全退场结局是忘掉学园、回乡生活。具体终局失败触发、各关系结局和恶魔能否完全脱困尚未定，不在此编造分支。

这里给的是已设定因果与需要实现的章节功能，不把研究院列表当作逐章剧情。各研究院的具体案件、人物关系和先后路线仍需分别设计。

## 需要解决的连续性与呈现问题

1. **开场位置旧设定冲突**：[学园设定](academy-game-design-zh.md)人物卡仍写侦探“初始场景：中央厅”，而现行默认入口和[初醒设计](first-awakening-design.md)都是生活翼自有宿舍。当前剧情以宿舍开场为准；人物卡应在统一设定时修订。
2. **首章接日常缺桥**：没有“答辩通过→实际开门→遇见其他学员→知道自己能去哪里”的可玩连续段。日常三场目前作为独立样片保留；应先确定其相对失忆的时间位置，再改对白与场景入口。
3. **两种答法的后效未定义**：两条通过结局均通向更大的学园，但后续人物对“我们是否曾住在这里”的认知应有差异；不能下一章不加说明地让两组玩家都笃定同一答案。
4. **开场有人替玩家归纳**：[现行对白](../../godot_csharp/scenes/FirstAwakening/first_awakening.dialogue)中的部分侦探心声、阶段对话与铜口结语直接解释线索。具体行号与改成行动的示范见[首轮审查](../../artifacts/first-awakening/narrative-review.md)。优先让玩家触摸、比对、重演、质询后再得到人物反应。
5. **宏观主线还缺戏剧链**：学园设定已有四锚、设施和角色功能，却没有逐章的“谁要什么、与谁冲突、玩家做什么、关系如何变化”连续场景。下一步应先设计公共学园过渡与首个能改变人物关系的调查事件，再扩写各院；不要用广播、日记或旁白一口气宣读四锚与导师往事。

## 写作与审查的执行准则

每个场景记录六件事：**入场状态、角色眼前目标、玩家可做的动作、可观察反应、知识/关系/通路的变化、退场状态**。先安排人与物的行动，再写对白。心声可以写感官、犹豫和个人决定；不能代替玩家归纳物证。恶魔可以提出具有立场的问题、明示规则和裁决已经提交的论证；不能充当全知讲解员。纯生活戏不必硬加失败分支，但选择应至少改变可见行动、信息或人物回应。

当前 MCP 的 `story_scene_design_contract`、`inventory_story_project`、`audit_story_project` 和 `review_story_beats` 用于逐场检查结构、台词与知情顺序；静态提示和设计稿均不能替代实玩节奏与人物演技审查。
