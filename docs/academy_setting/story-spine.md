# 《安眠者有福》剧情总脉络与呈现边界

> 2026-09-27 梳理。本文按现行默认入口、初醒设计和学园设定归并剧情，不把设定储备或独立样片写成已经连通的游戏章节。需要改动既定世界事实时，先修改对应源规范。

## 一句话主线

十六名失去在校记忆的学员，在恶魔代管的孤岛学园里重新认识自己与同伴。他们一面依靠学园存活、学习和修复设施，一面追查导师牺牲、恶魔泄露和记忆封存的缘由；最终要以自己验证过的知识重建封印，保有记忆离开，也始终可以选择安全退场。首章先区分“发生了什么”和“当时的人为何那样行动”：现场调查为事件经过提供依据；脑内重建通过玩家编写并运行的人物行为规则体现动机，让行动者在其当时所知的条件下作出选择。

剧情的核心矛盾不是“找到反派并听它说明真相”，而是：恶魔确实教会并保护学生，同时希望学生用所学替它拆除束缚；学生必须判断每次帮助的代价，亲手取得证据并承担行动后果。

## 作者侧时间线（玩家开局不知道）

1. **入学与数月生活**：十六名学员进入学园的具体方式未定。侦探等四人在生活翼长期住宿、研习，留下磨损、修补、练习纸、杯子与木盒的相互对应痕迹。四人保留入学前职业与人格。
2. **地下研究失误**：导师组试图以言灵、机械、仪式与医学观测拘束恶魔并提取源质；认知偏差和时间校准失误使容器破裂。这是大局事故，不是初醒案能够直接证明的事。
3. **生活翼当夜**：主楼一侧出现异动，灰黑物质由隔离门缝进入生活翼；门曾由木楔撑开，随后撤楔、合门并插入生活翼内销，现场留有擦拭、清洗与包裹木楔的痕迹，主楼侧另有外闩。作者侧可保留一条事件经过供校验；玩家调查支持物态与相对先后，不自动证明每步由谁执行或为何行动。脑内重建通过规则如何驱动人物行动来呈现其动机，不另设一份动机问卷或独立目的字段；行动者可依据当时掌握的信息选择、等待或改变做法，未能区分的动机保持开放。
4. **契约与封存**：四位导师牺牲，以生命和存在建立保护十六人的契约。恶魔按约封存在校经历与立场，保留入学前身份和技能；它从门外主楼侧落下外闩，未进入生活翼改造内部物证。契约限制其离校、直接伤害或控制学员、亲自破坏束缚，并要求公开稳定规则、保留真实胜路和生存条件。
5. **苏醒**：四人醒在自己的生活区域，但不记得此处的经历；其他学员在不同区域面对各自的初筛。其余人的具体闯关经过目前只有背景设定。

依据：[初醒案设计](first-awakening-design.md)第五节、[学园设定](academy-game-design-zh.md)第二至四节。以上是作者知识，不应直接成为开场旁白、人物记忆或铜口答案。

## 玩家经历与当前剧情稿

以下新版开场和首案叙事仍处于设计、改造阶段；[活动厅开场对白](../../godot_csharp/scenes/FirstAwakening/activity_hall_opening.dialogue)尚未接入场景，不能据此称为已实现的可玩流程。旧入口与实现状态须以当前项目场景为准。本节描述的是目标连续性和设计方向，不是运行状态报告。

| 阶段 | 玩家面对的问题 | 玩家可做的事 | 到阶段末可确认的事 |
| --- | --- | --- | --- |
| 活动厅初遇 | 三人记得为何登船，侦探为何说不出自己的来意？ | 与三人交谈、确认姓名、听他们谈各自所求并回应追问 | 三人记得求艺、工艺或报酬；侦探记得签约与登船，却想不起当时为什么答应。三人因此疑虑；记忆机制和侦探与学园的关系尚未揭晓 |
| 铜口广播与质询 | 代管者承诺兑现什么，为什么把门前考题交给学员？ | 听广播、质询封存记忆与契约承诺，决定如何回应同伴 | 铜口承认封存过往、承诺在主楼兑现；要求解释重门如何变成现状，并允许调查与互通信息 |
| 分头调查 | 门前发生过什么，现有痕迹能支持到哪一步？ | 搜查宿舍及公共空间，按专业分工检查隔离门、备餐间、研习室并汇总 | 物证支持器物状态、动作经过与相对先后；人物归属和行动理由须看证据强度，不能由行为外观直接定性 |
| 长桌讨论与脑内重建 | 哪些行为规则能在人物当时所知的信息下产生与现场经过相容的行动？ | 整理调查所得，编写人物行为规则并运行；依据实际行动与可观察结果修改规则 | 规则运行产生相容经过，说明这是一种可行解释，不证明唯一历史。规则不得让角色使用当时未获知的信息；人物和动作自由组合，不按职业限人 |
| 铜口答辩 | 如何陈述现场经过、重建依据与尚未确定处？ | 提交调查支持的经过和一套完整的行为规则解释；可自愿比较其他解释 | 一套完整相容的解释即可提交。是否存在第二套同样可行的规则不构成玩家通关条件；未能确认的操作者或深层目的可以保留 |

新版叙事依据：[首章运行对白](../../godot_csharp/scenes/FirstAwakening/first_awakening.dialogue)与原案[活动厅剧本草稿](../../artifacts/first-awakening/activity_hall_opening_script_draft.dialogue)；调查与脑内推理的详细规则见[初醒设计](first-awakening-design.md)。生活翼宿舍苏醒、活动厅初遇、纸面登记卡取名、首次广播质询、2+2同行勘验与脑内推演已在 `first_awakening.dialogue` 与 `FirstAwakening.gd` 中实现并完成实机通关验证。

### 首章的知识边界

- **现场调查负责支持**：重门、木楔、灰迹、擦洗和包裹等物态，及撑门、撤楔、合门、插销、清理之间可成立的相对先后。现场材料提供经过依据，不替脑内推理宣布人物动机。
- **脑内重建负责呈现动机**：人物行为规则结合其当时能知道的信息，驱动观察、行动、等待与改策；玩家通过规则实际产生的行为及其结果理解人物为何这样做。撤楔或清理本身不能证明善意、恶意、恐惧或隐匿意图。
- **必须允许的未决与实据否决**：撑门可能出于辨险，也可能仍在试探长期逃生；遇烟后的撤楔可服务于多种同时存在的顾虑；内销既可能为了暂不重开，也可能服务于囚禁，但后者必须有行动者的知识依据；顺拧平铺晾晒与练习纸包木楔属于常住生活者的起居习惯与肌肉记忆，在生死关头从容做家务直接推翻了“潜入的第五人伪造现场”的伪命题；外闩由侧别支持操作位置（主楼外侧施加封锁），但外侧操作者的具体深层目的保留未决。当前学员的求艺、求工艺、求报酬与侦探的失忆疑惧只属于当下，不得移植为昨夜人物的动机。
- **结论范围**：多种动机可以通过同一事件经过而同时成立。脑内推理若不能区分，只能报告解释相容但未唯一；不得把作者侧完整事件链或某个“善意”动机宣布成唯一历史答案。
- **笔记伏笔**：末页的“旧例、那一回、原来的、那一项”留待后期与原件和独立材料交叉验证。首章不应让角色凭空解开。

## 首章之后：已定的大局方向，尚未连成剧情章节

1. **重新进入公共学园**：从封闭生活翼转向中央厅与公共区域；和其他已通过初筛的学员汇合。需要一场正式的门禁/通路、身份和信任过渡，现行工程尚无这一章。
2. **在日常中重建关系**：早餐分工、听钟、娱乐室围谈等片段展现人际关系与可维持的生活。现有[前三场样片](../../godot_csharp/scenes/Story/README.md)可单独游玩，但没有绑定首章结局，不能推定它们发生在苏醒前或苏醒后某一具体天。其对白里的“才住了几天”“这几天”要等桥接时间线确定后校正。
3. **学习与调查并行**：学生修复厨房、水务、工房、诊疗和研究工作站，调查遗物、记录与设施；接触材料可恢复真实但主观的记忆片段。人物之间会因保全生活与冒险探查产生真实分歧。材料本身不自动宣布客观真相。
4. **辨认恶魔的双重关系**：恶魔公开规则、授课、阻止危险，也在规则许可范围内诱导学生破坏封印。学生需通过可操作的言灵、推演与设施事件，发现“它救我”和“它利用我”同时成立。
5. **查明事故与四锚**：从四座研究院分别取得真名结构、仪式阵图、机械隔离机构和安全载体；在地下层把导师遗留的语义、能量、物理、认知四条防线与事故证据对上。到达核心隔离舱不等于已经能封印。
6. **终局选择与执行**：既定胜利方向是查明真名、理解封印、实际准备材料并完成封印，保有记忆离岛。安全退场结局是忘掉学园、回乡生活。具体终局失败触发、各关系结局和恶魔能否完全脱困尚未定，不在此编造分支。

这里给的是已设定因果与需要实现的章节功能，不把研究院列表当作逐章剧情。各研究院的具体案件、人物关系和先后路线仍需分别设计。

## 需要解决的连续性与呈现问题

1. **开场位置与入场连续性已统一**：新版确立侦探从生活翼宿舍苏醒，走入活动厅与已在场的工程师、厨师、音乐家相遇；纸面取名卡已嵌入对白等待，四人间制式宿舍陈设已统一。
2. **首章接日常缺桥**：没有“答辩通过→实际开门→遇见其他学员→知道自己能去哪里”的可玩连续段。日常三场目前作为独立样片保留；应先确定其相对失忆的时间位置，再改对白与场景入口。
3. **答辩如何保留未决仍待设计**：脑内重建允许同一经过对应不同动机，也允许操作者或深层目的未明。正式答辩后的记录与同伴回应应保留玩家证据边界，不能把不同的合格动机解释改写成不同的客观历史。
4. **新版首章流程已实机通关**：首章对白、姓名输入、2+2深入勘验、脑内规则回放反驳与终局答辩已全面接入并在实机通关；后续重点是首章终局通往主楼/中央厅的剧情桥梁。
5. **宏观主线还缺戏剧链**：学园设定已有四锚、设施和角色功能，却没有逐章的“谁要什么、与谁冲突、玩家做什么、关系如何变化”连续场景。下一步应先设计公共学园过渡与首个能改变人物关系的调查事件，再扩写各院；不要用广播、日记或旁白一口气宣读四锚与导师往事。

## 写作与审查的执行准则

每个场景记录六件事：**入场状态、角色眼前目标、玩家可做的动作、可观察反应、知识/关系/通路的变化、退场状态**。先安排人与物的行动，再写对白。心声可以写感官、犹豫和个人决定；不能代替玩家归纳物证。恶魔可以提出具有立场的问题、明示规则和裁决已经提交的论证；不能充当全知讲解员。纯生活戏不必硬加失败分支，但选择应至少改变可见行动、信息或人物回应。

当前 MCP 的 `story_scene_design_contract`、`inventory_story_project`、`audit_story_project` 和 `review_story_beats` 用于逐场检查结构、台词与知情顺序；静态提示和设计稿均不能替代实玩节奏与人物演技审查。
