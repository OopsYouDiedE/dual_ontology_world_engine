# 异常感知学园视觉与身份体系规范

本文件规范学园的徽记层级、纹章象征、日常器物应用与制服标准。

## 一、三旗徽记与体系象征

三旗确立了学园与外部势力的政治、学术与神秘学权属关系：

1. **中央学园旗（黑底银纹 · 核心锚点）**
   - **象征**：火山口与海波纹。开敞式火山口象征孤岛地脉与源质熔炉，下方双层浪花波纹象征深海隔离，火山口升起微收敛如意云气。
   - **载体**：学园主旗、校舍主建筑挑空、学生与导师制服胸徽、学园藏书封面银印。

2. **左侧世俗科学旗（红底金纹 · 外部世俗学术盟友）**
   - **象征**：燃烧火炬与开敞月桂叶环。体现理性科学、工业技术与标准化观测体系。
   - **载体**：光学仪器外壳黄铜蚀刻、动力设施铭牌。

3. **右侧秘仪学会旗（蓝底银纹 · 外部神秘学传承）**
   - **象征**：三角视界之眼与如意云托座。短芒射线表示受控的超感认知与危险观测。
   - **载体**：神秘学档案皮卷搭扣、封印器具。

## 二、皇家印章与来源工坊体系

1. **最高权威：皇家团龙朱砂印**
   - 传统中式团龙外廓，配合正圆形青铜印章，用于最高学术任命与特许状。

2. **制造凭证：双向如意云工坊印**
   - 次级简化标志，以对向双如意云头结合短台足呈现，作为仪器制造、青铜铸件与皮革封皮的标准工坊验收标。

## 三、制服与器物日常应用

1. **学院制服规范**
   - **共用要素**：黑色立领、胸前银色山海胸徽、袖口海波暗纹，背部不设大型图样。
   - **学员款式**：利落短外套，下装配高腰窄腿裤或分幅裙，适应日常操作与应急奔跑。
   - **导师款式**：及踝修道长外套，配可拆卸深灰短肩披与单侧金属链扣。

2. **室内器物与地面铺装**
   - **研究厅地毯**：炭黑低绒织物，居中编织灰银色山海大徽记，四周以连续海波纹缘饰收边。家具陈设避开中央徽记。
   - **建筑地砖**：大面积采用米灰素砖，仅在主通道与边界铺设直边波纹砖，主入口节点镶嵌单幅山海节点地砖。
   - **伯爵捐建铭牌**：安装于主楼门厅内侧墙面，黄铜底板阳刻铭文，底座配单只小型卧狮。
