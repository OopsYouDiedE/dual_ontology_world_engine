# 《初醒》Demo 客观技术规格与美术重构交接书 (Claude 接手指南)

> **文档性质**：客观技术规格与叙事边界清单。  
> **核心原则**：本文档**仅提供硬性物理几何、场景拓扑、部件尺寸与物证法医事实约束**。所有的**美术风格、视觉基调、色彩体系（调色板）、材质表现形式与 UI 视觉皮肤，完全交由 Claude 自由设计**，项目不施加任何先验预设限制。当前游戏内运行的美术贴图仅作功能性占位，等待 Claude 提供全套正式美术设计进行替换。

## 一、 叙事背景与设计边界

> 详细世界观、案情推理与因果判定规则以作者原案为准：参见 [first-awakening-design.md](first-awakening-design.md)。

1. **场景定位**：
   - 封闭的生活翼末端区域。四名学员（侦探、工程师、厨师、音乐家）在各自单人宿舍醒来，失去了近期的情景记忆，但完好保留了各自的职业天赋与程序性常识。
2. **核心调查问题**：
   - 问题一：这真是我曾经生活的地方，还是有人布置给我看的房间？
   - 问题二：四个人为什么被留在同一片封闭区域？这道封闭是谁造成的？
   - 问题三：我们能否在不依赖广播答案的情况下，说明这里是什么地方、我们与它是什么关系？
3. **系统认可的双重合法结局**：
   - **历史客观解（生活研习与自主隔离）**：四人曾长期在此居住研习，门厅封闭是当夜察觉外部异动后自主实施的防护性隔离，外闩为外部追加。
   - **合法相容解（刚入学的新生与入学考核）**：四人是刚来报到的新生，眼前的封闭与器物是校方设计的入学考核试炼场地；四人利用残留痕迹推导出了房间构造与因果机制。在缺乏独立可信日期基准的前提下，该回答同样符合全部已知物证。

## 二、 硬性物理几何与引擎技术规格

| 维度 | 强制规格 | 说明 |
| :--- | :--- | :--- |
| **基础地图网格** | **32 × 32 px** | 所有墙体厚度、地面方砖、门洞净宽（至少 32px，主通道 64px）均基于 32px 栅格对齐。 |
| **角色规格** | **32 × 48 px 实体** | 位于 **64 × 64 px** 透明承载画布中。脚底接触点位于画布 `(32, 56)` 附近。 |
| **景深排序 (Y-Sort)** | **开启 (Enabled)** | 所有场景物件、角色均按真实物理接触线（脚底/底座触地线）的 Y 坐标进行动态深度排序。 |
| **视口与缩放** | **640 × 360 逻辑分辨率** | 相机以 **2.0 倍最近邻（Nearest-neighbor）整数放大**至 1280×720，纹理过滤全部强制 `NEAREST`。 |
| **光照与遮挡系统** | **2D Occluder & Light** | 墙体与家具按实际占地脚印建立 `LightOccluder2D`；光源采用 2D 衰减点光源与窗户漫射光。 |

1. **北侧四间宿舍（R-05 至 R-08）**：一字排开，朝南开门连通走廊，北墙有固定带铁格窄窗。
2. **东西向主走廊**：中央横向干道，净通行宽度 64px（2格），东西两端设通道南下。
3. **西南共用起居/研习室**：4 人长研习桌、材料柜，东侧墙面安装铜质传声口与拉柄。
4. **东南盥洗与备餐间**：重力水箱与手拧水阀、储食柜（分装口粮）、操作台、洗盆与湿布。
5. **南端中央门厅**：两间共用房间在此汇合，形成环形回流通路；南侧正中为核心谜题结构——厚重机械隔离门。

## 六、 脑内推演案卷与交互界面结构

1. **脑内推演（Mind Presentation）**：
   - 布局：左侧为独立的现场空间行为回放舞台（复用 32px 场景几何）；右侧为大面积书写稿纸，玩家可直接键盘输入受限行动语句（如“音乐家 撑门”、“工程师 撤楔”等）。
   - 底部提供折叠式的可用词汇标签，点击可插入光标处。
   - 校验时系统进行 Core 因果推演，并在左侧舞台按步回放，遇到关键物理痕迹自动暂停并展示预测对比。
2. **对话与物证查看器**：
   - 对话采用简洁的半透明面板与角色名牌，支持键盘快速推进与历史回顾。
   - 物证查看器居中展示 22 幅物证卡的大图，下方配以精炼的法医勘验文字与操作按钮（如掀开检视盖、拔出内销等）。
