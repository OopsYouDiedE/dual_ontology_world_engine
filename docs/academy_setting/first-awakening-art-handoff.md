当前宿舍表现以四间近乎相同的制式陈设为准：墙面、寝具、地毯和家具位置统一，桌面清空，不按职业陈列量具、乐谱、私人笔记。恶魔事先清除了能证明共同生活的痕迹；这是作者侧信息，玩家只能观察到物品缺失。侦探袖口灰痕与纸篓包楔、公共区域案件物证保留。下方旧物料表中的职业道具与私人笔记是历史参考，不用于当前宿舍重建。

## 一、 叙事背景与设计边界

> 新版剧情依据为[活动厅对白创作稿](../../godot_csharp/scenes/FirstAwakening/activity_hall_opening.dialogue)；调查与动机重建规则以[初醒事件调查与动机还原设计](first-awakening-design.md)为准。对白稿尚未接入场景，不能描述为已实现。

1. **当前剧情定位**：侦探醒在生活翼宿舍，随后到活动厅加入已互相介绍的三人。三人记得各自登船所求，侦探记得签约和登船却不记得自己的来意。初遇、广播、同伴质询及搜查分工详见新版对白创作稿；场景接入状态以 README 为准。
2. **调查与脑内推理的分工**：现场调查给器物状态、动作经过和相对先后提供依据；脑内推理通过编辑和运行人物行为规则来体现动机，人物依其当时所知行动或改策。规则本身就是动机模型，不另加动机问卷、目的字段或评分。具体规则见[主设计](first-awakening-design.md)。
3. **结论边界**：不再使用“长期居住 / 新生考核”双答案作为本案判题结构。调查结果不自动确定行动者或其动机；同一经过可由不同动机解释，一套完整相容的解释即可提交。侦探的登船愿望、完整旧身份、事故深层原因和外闩操作者不在本案定案范围。

## 六、脑内推理与界面参考

脑内推理沿用当前行为规则编辑器与运行回放，不在旁边另建动机问卷、目的/代价/改策字段、动机评分或独立五题界面。现场物证限制行为规则可以解释的事件经过；人物规则运行实际驱动角色行动，动机体现在玩家选定的规则如何使人物根据当时知识行动或改策。词汇和动作应允许自由组合，不按职业限制；一套完整相容的规则解释即可提交。

规则、反馈类别和能力边界以[初醒事件调查与动机还原设计](first-awakening-design.md)为准；既有脑内界面尺寸、场景连线与运行情况以[场景 README](../../godot_csharp/scenes/FirstAwakening/README.md)为准。不要把旧“准确法医事实”、唯一人物分工或特定动作链转成程序答案。有意义但尚未支持的动作组合属于实现缺口，不能拿来判玩家推理错误。

## 七、旧版美术委托方向（参考，不是当前任务单）

旧稿曾提出重绘墙体 TileSet、31 件家具和 22 张检视卡，并将当前贴图称为占位。这些是早期生产构想，不等于现状或本轮强制工作：场景 README 记录了家具、建筑、检视图各自当前来源与重建入口；家具、内部物件和地形的生产源归 `godot_csharp/AssetsSource/`，运行时资源归 `godot_csharp/ShareAsset/`。不要以旧表要求全量重绘、改变生产入口或另建并行资产目录。

若后续明确安排美术更新，可以自由确定风格，再选取本文件的布局图、资产 ID 与旧图作为比较参照；每次只按实际目标复核相关资产的原生尺寸、锚点、占地、碰撞、遮挡及场景引用。美术构想或局部摆景不代表已完成资产或已验收场景。
