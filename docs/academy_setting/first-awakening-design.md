# 初醒：调查经过与还原动机

2026-09-29 修订。剧情依据为用户修订的[活动厅对白](../../godot_csharp/scenes/FirstAwakening/activity_hall_opening.dialogue)。本文件负责推理设计；运行状态见[场景 README](../../godot_csharp/scenes/FirstAwakening/README.md)。活动厅开场已接入运行对白；原稿后半的自动揭底不作为玩家推理操作。

## 一、核心定义

**驱动人物动作的规则，就是动机。** 脑内推理要还原的是人物会依据什么采取行动，而不是在动作之外另填“目的、代价、动机标签”。现场调查提供事件经过的依据；玩家在脑内修改人物规则，让行为实际发生，再看这些规则是否能解释已知经过。

本轮沿用已有脑内纸面、直接输入与回放，不设计另一套动机札记、问卷、评分或界面。规则、所知与行为构成同一条因果链。不能用“善意／恶意／求财／求知”等标签代替执行规则，也不能通过附加一句“为了救人”获得通过。

**词汇允许自由组合，有意义的动作必须允许，不准按人物或职业限制。** 人物能否执行由实际位置、知识、工具与对象状态决定。主厨可撑门，音乐家可洗布，工程师可包楔，侦探可选择继续观察。没有作者指定的必选行动者。

## 二、新版开场如何进入推理

四人记得签约登船，却不记得如何进入生活翼。三人记得各自所求，侦探连受邀理由也缺失。铜口承认封存过往，声称遗忘程度与和学园的牵连有关，拒绝公开侦探契约。同伴的疑虑有具体来源，共同受困促成合作。

活动厅相遇→单向广播→主厨拉柄回传质询→回各自房间找行李和招募信→汇合与公共房间调查，是新版连续性。侦探房中没有辨认身份的私人文字，仅发现包楔；旧私人笔记、补纸和缺口杯认人不能继续充当本版必要事实。

四间单人宿舍使用同一套普通床铺、书桌与收纳配置，整体整洁且差异很小。搜索只能确认个人行李、职业用品、私人文字和共同生活留下的日常痕迹不在房内；玩家不能仅凭空荡整齐的房间知道是谁、为何清理，或得知恶魔事先清理过。恶魔清理共同生活痕迹属于作者侧事实，不是现场直接供给的证据。侦探房中与门厅案件有关的包楔、袖口灰痕仍作为可观察线索保留；门厅的灰迹、窄缝、楔痕、内销与外闩、止挡座及擦拭痕也不随宿舍清理设定删改。

铜口提出说明门如何变成现在的样子，并交代所据实证。现场勘验给出器物联系和可支持的先后；源对白后半的整段解说是作者路线参考，不应在玩家操作前揭完，再要求录入。广播与同伴自述有来源边界，不能直接成为过去人物的记忆。

旧“长期居住／新生考核”双答法和旧安全退场承诺不再替代新版题目。大厅相遇与广播后各自查房，首次会合选搭档，同行勘验后回圆桌交换见闻。**玩家在圆桌讨论开始之后才开启脑内推演**；完整规则重演相容后，出示正确证物回应同伴，最后向铜口答辩。推演结果不直接代替会议证物回应。其他宿舍从开局不可进入或看见内部，仅由当前搭档陪同时开放其房间。开场演出、同行路线、痕迹图像与行为规则分别验收。用户源对白保持原文。

## 三、规则如何体现动机

一条行动记录“他撤下木楔”只说明做过什么。一条规则“察觉烟气进入时，停止保持门口开放”说明人物在这种处境下如何选择。实际撤楔、松手或关门取决于当时的支撑方式和可用动作，不把动机绑死到一种动作。

规则应能表达条件下的行动倾向、优先与禁止，以及必要的后续行为。它们接受当事人当前所知，产生实际候选行动；世界规则结算后果，新的观察再影响下一次选择。不能让规则只在排到某一行时检查一次，然后把未满足的条件永久丢掉。

已有局部动作次序可以保留，比如拿取后使用、撕纸后包裹；但全局行号不是人物动机。等待烟气的规则不应阻止人物先去门边观察，危险条件成立后高优先响应也不能被后续无关的家务指令堵住。

规则不是结果设值。“避开危险”不能直接把门设为关闭，也不会凭空给人物发一枚木楔。合法但失败的行动应实际失败，失败后取得的信息同样可以触发下一条规则。

### 3.1 同一行为可由不同规则产生

“遇见烟气就停止暴露”和“发现同伴仍在门内就阻止烟气进入”都可能促成关门。在本案资料不能区分二者时，两套规则都可相容。系统不通过人格评分决定哪套才是真动机。

如果规则在本次历史中恰好产生同样行动，仅凭回放不能区分。无需强迫玩家再写第二解；设计验收应检查两者都不被误拒。更换参与者也不能使原本相容的规则突然不合法。

### 3.2 同一规则可以产生不同动作

门被手扶着时，停止撑门可以松手；门被木楔撑住时，需要撤楔；想保持观察口，可以自己扶住或用可用支撑物。选择须受工具、位置、持续占用和可知信息约束，不是后台替玩家填固定步骤。

有意义的组合未实现时，保留输入并明确能力缺口，不能判为案情错误。指出缺口不是完成：后续应沿实际动作关系补齐，不把当前24动词表当成永久边界。

### 3.3 不追加独立的动机输入层

玩家直接写驱动行动的规则。设计者可解释一组规则呈现了自保、求证或控制的倾向，但这些词不成为必须填写的字段，也不成为程序判卷的关键词。游戏要展示的是规则触发、选择与后果，不是为文字标签授予正确分数。

## 四、已知事实与人物所知

现场记录注明亲见、操作、比对或同伴转述。物证约束动作经过，不能自动揭示行动者和动机。灰迹位置、楔与门的受力、纸张断口等可供比较；“为了救人”不属于观察事实。

历史人物只能依据当时取得的信息。今日在纸篓找到楔、铜口今日承认封存记忆，不能成为当夜行为的前提。脑内给人物安排亲见或传话必须真的具备位置和信息传递条件。没有看到不等于不存在；未知不等于否。

初始认知中无法证实的部分可作为假设，但不能混入调查证据。规则运行中产生的观察标为本次重建所得；不能让回放自行生成现实证据或恢复真实记忆。

## 五、调查为哪些经过提供依据

| 材料 | 支持的约束 | 不能单独推出 |
| --- | --- | --- |
| 开向、配重、止口 | 持续开启须有支撑；失去支撑可合门 | 谁撑门、为何撑门 |
| 窄缝磨痕、楔体受力及缺角 | 某次撑门的形态、器物联系 | 门从未开大；不存在逃生意图 |
| 灰、楔面、纸内转印与撕口 | 受灰、取下、包裹的相对顺序 | 精确毒性、压力、事故源和致死时间 |
| 内销、外闩、检视孔 | 操作侧别、锁止条件与当前状态 | 必为两人；自愿隔离或强制拘禁 |
| 洗盆、布、擦拭痕 | 清理、冲洗与器物处置经过；常住生活者习惯否决外来伪造 | 必为主厨一人独立完成；当时是否慌乱 |
| 案台、量具、椅痕与纸 | 取物、离席的候选经过 | 四人同时起立；同一震源；地下具体设备 |
| 口粮、冷灶、恒雾窗 | 当前食水与通行、观察条件 | 全时段无争抢；精确日期或失忆时长 |

新版窄缝、缺角与低频声等要有场景和检视材料对应，不能声称现有Core已模拟压力或声学。尚未接入的内容按制作缺口记录，不借脑内文字补成已调查事实。

## 六、首案动机规则的设计重点

以下五处是作者分析关键决定的顺序，不是新增界面的五道题，不固定人物、动作数量或方案数量。

### 6.1 保持开口：求知和撤离可以共享同一段行为

外部不明时，有人可能采取“无法判断危险时先获得可退回的观察条件；不贸然通过”的规则。想探明异动与想找安全出口，都可能形成这样的行为。保持关门损失信息，大开门增加暴露；这是规则选择真正需要处理的分歧。

允许扶门、置楔、让同伴观察、自己留守等有意义组合。规则中具体参与者由玩家安排；能否腾手、能否离开由实际状态决定。十厘米不能排除“先探路，后逃生”，不能把逃跑一词当错误答案。

### 6.2 遇烟改策：最重要的是规则响应新信息

“危险不明时观察，察觉烟气进入后停止保持开口”，可解释先开后关，而无需更换一个动机标签。原先的求证规则和后来避险规则应能并存，后者在新条件下优先。

“继续观察，即使烟已进入”也必须可表达。它可能产生与合门记录不符的经过；反馈应指出门仍开启，而非断言人物不该这么想。玩家据此改变规则、观察位置或条件，而不是猜一段正确心声。

不能让未在门边、也未收到消息的人因为客观烟已出现就立即撤楔。需要补出获取信息的行动，或把是否知情保留为假设。

### 6.3 插销：维持状态的规则与控制他人的规则

“危险未解除时，不再让门开放”可能在门关后促成插销；“不允许门内的人离开”也可能如此。资料不足时不能从内销直接区分。两者都受能否接近、门是否合拢与当时所知制约。

相关规则应能在条件改变后不再生效，而不是永远强制插销。若玩家采用“确认外面安全后允许开门”，有何确认方式也需表达。不能引用后来考试规则作为当时的知识。

### 6.4 善后：用同一组习惯规则解释连续处置

“接触脏物前先隔开手”“用过的清洁物及时冲洗归位”“保持走道可用”可以分别促成包楔、洗布与移物。不要强迫玩家逐句重复家务循环；需要判断的是谁遵循什么规则、当时看见了什么，以及实际对象是否满足条件。

也允许“尽量不留下可识别的痕迹”这类不同规则，但它必须通过真实取物、搬移和擦拭产生行为，不能直接删除证据。留下残痕不一定说明没有隐匿意图，可能是能力有限或处置失败。

习惯提供相容解释，不证明唯一身份。侦探房间发现楔不证明全程由侦探经手；但冷水顺拧平铺晾晒、练习纸包防烫焦黑木楔，均系常住生活者的起居习惯与肌肉记忆。外来潜入者在剧毒危急关头不可能从容做家务，实据直接否决了“潜入的第五人伪造并离开”的假说。

### 6.5 外闩：不替未知人物编造内心

只能由外侧够到的锁止要求满足物理操作条件。主楼外侧横闩由主楼自外侧施加封禁锁闭；在会议推演与答辩中，将生活痕迹推诿给虚构的“潜入第五人”属于伪命题，推演引擎与答辩规则均予驳回。对于主楼外侧行动者的具体身份，保留未决，不要求玩家从恶魔设定中抄动机。

已经能够说明外闩造成通行限制，并不等于已知它出于防灾或囚禁。源稿铜口的全盘赞许如果保留，应视为答辩后新增证词，不能反过来证明玩家之前已知。

## 七、侦探自身的悬念

侦探不知道自己为何登船，却能重建人如何依规则选择。这使他必须区分“希望自己曾救人”和“这组规则确能解释留下的痕迹”。不得为了洗清嫌疑强迫他采用英雄行为。

工程师可以质询动作是否有效，主厨关注善后，音乐家追问信息来源；这是剧情分工，不是人物动作权限。最后合作可以加深，但过去身份仍未解，不能一次推理就换来无条件信任。

## 八、判定与重试

表达是否合法、动作是否有实现、行为是否可执行、经过是否相容分别判断。无意义组合说明对象关系；有意义但未实现的组合列能力缺口，不能冒充案情反例。

实际规则触发后结算动作，回放展示原条件、当事人所知和后果。观察不到的条件保持未知；不从客观世界偷取知识。没有适用规则、规则被禁止、行动失败与模拟未完分开。改规则后重算，旧结果失效，不改现场材料。

通关依据现场支持的经过和本次完整规则运行，而不是填写动机词、作者动作顺序或角色分工。局部运行与相容不能证明唯一真相。不能通过重演次数或三次核验解锁正确词汇。

一条作者验证路径：先写持续保持门口开放的规则，回放与合门记录冲突；补入在门边察觉烟后优先终止开放的规则，实际撤楔合门；其他人的锁止、处置规则依据可观察的变化继续运行。交换执行者应仍按位置和条件判断；另一组规则若同样符合记录，也应接受。外闩操作者目的保留未知不阻止有限陈述。

## 九、实现边界与验收

保留现有纸面、词库与回放，不新增动机界面。语言到规则的接入使用真实C#实现，不恢复旧Entity/Belief系统；Core的规则与主体认知边界不能被场景判题字典替代。既有Hall桥接层是有限动作解释器，是否已接通持续规则和通用决策必须对照代码说明，不能只改文案就宣布完成。

至少验证：词元自由组合、人物互换、条件规则不被行号堵住、危险规则对新信息有响应、规则优先与禁止真实影响选择、未知不当否、合法行动失败、同规则不同手段、同经过不同规则、修订后旧结果无效、输入不丢失。完整通关通过实际调查、输入、运行和提交，不直接设置通过标志。

源对白、用户已有翻译和创作档案保持原样。新对白完整演出与三条同行调查另列接入状态。实际命令、结果和局限记入场景README，复用artifacts/first-awakening。未读谜底试玩、人类乐趣与艺术审看不能由自动检查代替。
