# 侦探失忆前事件重构：生活翼封闭区设计方案

> 状态：生活翼封闭区设计方案。四人、生活翼末端封闭区、恒雾窗户、笔记后期解读为本案设计边界。侦探苏醒初始位置为生活翼自有宿舍；Demo 阶段聚焦四人生活区。

## 一、设计目标与核心问题

侦探在自己的床上醒来。开场围绕三个核心问题展开调查：

1. 这真是我曾经生活的地方，还是有人布置给我看的房间？
2. 四个人为什么被留在同一片封闭区域？这道封闭是谁造成的？
3. 我们能否在不依赖广播答案的情况下，说明这里是什么地方、我们与它是什么关系？

前两个问题构成入学考试的调查过程。通过考试意味着四人展现了理解处境与物证推理的能力，获得参与后续博弈的资格。

### 1.1 合法回答范围与定性
系统与恶魔认可两种基于严密事实根据的合法回答：
1. **历史客观解（生活研习与自主隔离）**：四人曾长期在此居住研习，门厅封闭是当夜察觉外部异动后自主实施的防护性隔离，外闩为外部追加。
2. **合法相容解（刚入学的新生与入学考核）**：四人是刚来报到的新生，眼前的封闭与器物是校方设计的入学考核试炼场地；四人利用残留痕迹推导出了房间构造与因果机制。在缺乏独立可信日期基准的前提下，该回答同样符合全部已知物证，恶魔予以正式认可通过。

### 1.2 队长推选与全员通过的背景设定
- **答辩代表的形成**：四人保留职业技能，先各自检查出口、食水和声音，再交换所见。玩家选择物证回应具体说法，说明哪些结论尚不能成立；完成讨论后同伴请侦探代为陈述，并继续负责补充。专业能力通过行动体现，不由同伴无条件赞叹来授予指挥权。
- **十六名学员全员通过的宏观背景**：学园本期招募的十六位学员各具超常天赋与独特的“专长凭据（专业感知）”。在不同的分流封闭区中，其他学员同样凭借各自不可替代的专业维度（如工匠的结构感知、医者的生理化验、学者的文献敏锐度等）获取了超常信息，从而全员在各自的初筛考核中破局通过。

本案物证不足以证明的内容（留待后续展开）：学园的精确地理位置、记忆封存的具体法则、地下事故的发动者与深层起因。

## 二、现场生活细节的证据边界与解读原则

### 调查文字的写法

本节的证据边界供设计和判定使用，不直接作为玩家检视物品时的旁白。调查文字只写看见、听见、触摸或实际操作所得的细节；保留物证，不替玩家给出空间用途、因果顺序或排除结论。不要写“诱导牢房想法”“不能证明”“先移座、后擦地”等设计者分析，也不凭空罗列未出现的现代设备。需要比较时描述实际比对结果，例如杯片与杯口的断边相合。推断和辩驳由玩家在推演、对话中完成。

检视卡使用物件名、图片、简短正文和一个关闭动作；删除重复的“调查 /”前缀与常驻“滚轮阅读、任意键结束”等说明。

醒来现场的生活细节作为氛围感知和调查入口，其证据效力受到严格约束，不作为推翻物理常识或直达超自然结论的决定性证据：

- **书写中止与合笔**：停在半个词、墨点与盖好的笔帽，表明书写中止后笔被正常收起。突发声响、离席查看或疲倦就寝均可产生类似状态，不单独对应意识突然湮灭。
- **寝具与衣物整理**：衣着、被子与鞋子的摆放状态兼容正常就寝，亦不排除他人整理；侦探无法直接调取在校生活习惯以确认动作发起人。
- **地面痕迹与灰尘**：未见可辨脚印不等于绝对无人走过；在缺乏沉降条件与参照样本时，灰尘不作为绝对计时工具。
- **计时与外部参考（虚拟时长推进）**：机械钟的钟点和调查时的走动只表明本区的相对时间；恒雾窗户阻隔日照与方位。四人可回忆入学前约定的报到日期，但需要与不受本区布置者控制的当前日期来源交叉校准，才可断言该日期已经过去多久。日历页、墙钟、广播自报日期及普通落款都可被改动，不能承担这一证明。玩家的每次深度调查、比对与盘问会推进游戏内虚拟时长，但这种推进不能倒推失忆跨度。
- **身体与就寝状态**：无当夜新增的明显外伤表明身体未受剧烈暴力；四人按正常作息入睡后在睡眠中经历记忆封存，现场保留正常就寝痕迹；身体习惯不等于失去意识后的自主跨房间导航与就寝。

这些生活细节保留为环境氛围和调查入口，不作为彼此独立的决定性强证据。

## 三、封存区域：生活翼末端的一组宿舍与共用房间

### 3.1 空间拓扑结构与平面布局

本案采用一层生活翼末端区域，按 32×32 像素基础格规划，形成“北宿南厅、东西双联、环形回流”的完整可通行平面：

```text
                  [ 北侧外墙 / 固定恒雾铁格窄窗 ]
  ┌──────────────┬──────────────┬──────────────┬──────────────┐
  │   侦探宿舍   │   甲宿舍     │   乙宿舍     │   丙宿舍     │
  │  (单人研习)  │  (工程师)    │   (厨师)     │  (音乐家)    │
  └───[ 门1 ]────┴───[ 门2 ]────┴───[ 门3 ]────┴───[ 门4 ]────┘
  ══════════════════════ 东西向主走廊 ══════════════════════════
          │                                      │
       [ 门5 ]                                [ 门6 ]
  ┌───────┴──────────────┐              ┌────────┴─────────────┐
  │ 共用起居室 / 研习室  │              │    盥洗与备餐间      │
  │ (长研习桌 / 铜传声口)│              │ (重力水阀 / 食物柜)  │
  └───────┬──────────────┘              └────────┬─────────────┘
          │                                      │
       [ 门7 ]                                [ 门8 ]
          └──────────────────┬───────────────────┘
                    ┌────────┴────────┐
                    │      门  厅     │
                    │ (止挡座 / 沉积) │
                    └────────┬────────┘
                          [ 门9 ] (厚重机械隔离门)
                             ▼
                         主楼方向 (封闭)
```

**空间方位与功能划分：**
1. **北侧宿舍区**：四间规整的单人宿舍一字排开，自西向东分别为侦探宿舍、甲宿舍、乙宿舍、丙宿舍。每间宿舍门朝南开向走廊；北墙设固定带铁格窄窗。
2. **东西主走廊**：中央横向通行干道，连通四间宿舍，并在东西两端设通道分别南下进入起居研习室与盥洗备餐间。
3. **西南共用起居室 / 研习室**：内设 4 人研习长桌、练习材料柜，东侧墙面安装铜质传声口与拉柄。北门连走廊，东南门通向门厅。
4. **东南盥洗与备餐间**：内设重力水管手动阀、储食柜、操作台、洗盆脏布及针线修补盒。北门连走廊，西南门通向门厅。
5. **南端中央门厅**：两间共用房间南门在此汇合，形成 `走廊 ↔ 起居室 ↔ 门厅 ↔ 备餐间 ↔ 走廊` 的完整环形回流；南侧正中即为通往主楼方向的厚重机械隔离门。

所有门洞净宽至少 32px（1格），主通道宽 64px（2格），确保角色移动、探索与错身几何通畅。

### 3.2 建筑边界与物理设施（含牢房与隔离门双重诱导特征）

- **隔离门机构（双重误导的核心物理实体）**：
  - **机械开向与止口**：门向主楼侧开启（外开门），门洞四周在主楼侧设有厚重石砌止口（Rebate），门扇合拢时紧紧贴合止口，外部施加推力只会让门死死抵在止口上，绝无法向生活翼内部推开；
  - **自闭配重系统**：生活翼内侧设有外露绳索、滑轮与铸铁悬垂配重。门一旦被推开，重力配重便会自动将门扇拉回闭合状态；
  - **锁止构件**：生活翼内侧设有一根水平滑动的手动锁止铁销（销身带新鲜刮擦痕）；主楼外侧另有一根横跨两只铸铁卡座的沉重落闩。内销拔出后，门因外闩抵靠仍无法通行；透过内侧检视盖窄孔可见外闩位置。
  - **门前构件**：门前原本放置有一座重型铁止挡座（底座积灰轮廓吻合，现被移至墙边）；门底内侧附着灰黑沉积与楔形干净遮蔽区；
  - **误导设计**：沉重门体、外侧死横闩、内销擦痕与木楔挤压凹痕，极易误导调查者忽略“外开止口”与“自闭配重”，从而误判为“顶门御敌”或“撬门越狱”。
- **窗户与外墙**：全区窗户均为带固定铸铁格栅的窄扇，铁格净空小于人头尺寸，负责物理通行阻断；玻璃外常驻浓白恒雾，阻断外界视线。视觉上极度接近拘禁监牢。
- **宿舍编号与配给设置（牢房诱导特征）**：四间宿舍门框上刷有冷硬的黑漆铅印编号（`R-05` 至 `R-08`）；备餐间储食柜的面包按份均等切块，包以油纸并贴有冰冷的定额标签（`每日口粮-丙型配给`）；研习室抽屉内带钉眼方木与带刻度木条，在失去背景时极像监规下的惩罚性计件劳作物料。这套强烈的“临时收容所/监狱”视觉符号构成了极具迷惑性的诱导证据链。
- **生活保障与通风**：重力水箱与储食柜供给充足，日常食水处于可用状态；通风道为固定小格栅通道，尺寸无法容纳人体穿行。
### 3.3 人物配置与交互提示

- **在场四人**：区域内仅出现四人：侦探及三名学员（工程师、厨师、音乐家，作者侧以甲、乙、丙标识行动），玩家对白以职业相称。四人原本住在此处并使用各自房间，不引入外部人员搬运或换房安置。
- **新交互微光提示**：凡具有新对话分支、未调查线索或产生状态变化的人物与场景交互点，其头顶或物件轮廓呈现柔和、不刺眼的低饱和微光（微弱闪光提示），引导玩家视线；该轮交互完成或完成首次检视后，微光平滑隐退，确保不破坏写实压抑的探索氛围。

### 3.4 早期电气与学园传声技术

遵循时代技术上限：本区使用油灯、发条机械钟、重力供水与手动阀门，无现代电子面板、传感器或远程门禁。
起居室墙上的铜质传声口为固定机械共鸣装置：带固定导线穿入砌体（终点不可见）与带口部图案的传话拉柄。
- **传声操作规则**：机旁附有木质蚀刻《传声装置使用守则》。玩家初次使用时，在同一段Dialogue中读到拉柄旁的简短说明，随后连续接通、听广播和交谈；拉柄拉下接通单向传声与接收，松手即刻切断回传；装置不具备录音、自动识别身份或远程开门功能。
- **物证提交交互**：当玩家在传话机前提出论证或出示物证时，界面除展示对应规则条目外，同步弹出对应物证的高清物品图片与图文特征卡，作为正式答辩的证据展示。

## 四、笔记：现在能读，后期才能理解

### 4.1 玩家当前可见内容

笔记装订完整，无涂黑、刮改或缺页，自开局即可翻阅，字形与侦探当前书写习惯一致。纸页上没有导师姓名、身份代号、校名或事故文字。

末页正文：
> 照旧例，还是会错。那一回已经排过。  
> 留原来的；相同的不能抵作一次。  
> 先核那一项，余下的等——

这是缺少上下文的私人工作备忘。“旧例”“那一回”“原来的”“那一项”均具有未在当前区域明示的私人指代。文中不使用“折处、第三处”等词汇，避免与眼前包纸和三名同伴形成无意的物件寻谜误导。

### 4.2 后期对应的预设语境（跨案接口）

该页对应侦探在事故前记录的两次异常观察，指向一张特定折叠记录纸：
- “旧例”：按特定折线划分记录段落的旧校对方法。
- “留原来的”：保留第一次未经誊抄的原始观测数据。
- “相同的不能抵作一次”：相似异常现象发生在不同观测轮次，不得合并。
- “那一项”：当时约定的核心校准项目。

上述语境依赖后期案件的原件与独立材料兑现，在当前 Demo 仅作为未解伏笔存在。

## 五、作者侧完整经过：先有人行动，后有失忆

以下为作者侧客观历史，玩家在调查中仅能重建其中有限部分：

侦探入学前曾约定报到日。作者侧确定从那个约定日期到本次苏醒已经过去数月，其间四人确曾在生活翼居住；这段时长不由房内墙钟、练习纸或广播向玩家直接证明。约定日期与当前绝对日期的具体写法须随全局年表统一，未定前不得由主持人临时编造日历答案。

1. **当夜前期**：四人在生活翼进行日常自习与备餐。侦探在宿舍整理上述私人记录，甲在起居室收拾器材，乙在备餐，丙往返门厅与起居室。四人均不知晓地下研究真相。
2. **主楼异动**：主楼方向发生事故，热气与灰黑尘烟由门缝渗入，吹动门旁布条。四人感知到危险，决定暂时留在生活翼。
3. **撑门探视**：丙从共用研习室取出一只木楔，将隔离门临时撑开一条缝隙以观察主楼动静，未跨出门槛。
4. **合门阻隔**：侦探赶到门厅，见热气扑面且门缝熏黑，取走木楔让门扇依靠配重自行合拢；甲见门合拢，顺手插上生活翼侧手动内销。
5. **现场处置**：丙将松动的铁止挡座移至墙边以清理通道；乙取来湿布擦拭门厅地面积灰及止挡座原位；侦探随手撕下一张废练习纸包裹沾灰的脏木楔，带回宿舍扔进废纸篓。
6. **正常入睡**：热气不再渗入，水电设备可用。四人各自回房休息。侦探收笔合帽、更换睡衣正常就寝；笔记末句仅因门厅异动打断而未续写。
7. **契约封存**：导师在地下立约牺牲。恶魔依约在四人熟睡时段执行记忆封存，剥夺其在校研习与事故记忆，不操控身体，保留职业能力、性格与生活常识。
8. **恶魔落闩**：恶魔维持生活翼基础设施，并在主楼一侧（封闭区外）亲手将原有外闩落下入座，测试四人的判断力；其行动严格局限在主楼侧，未进入生活翼内部，未碰触内侧木楔、包纸与地面痕迹。
9. **四人苏醒**：四人先后醒来，各自保留身份技能，失去本地经历记忆。

## 六、物证：从“陌生房间”到“自己参与的封闭”

物证分为观察事实、能支持的结论及不能推出的推断边界：

### A组：此处是否曾被长期使用（与强力诱导假说）

- **A1 宿舍里的分层修补**：书桌抽屉内侧有多层边缘磨毛的新旧补纸；衣物合身且袖口鞋底有长期磨损。支持持续使用，削弱纯粹临时牢房假说。
- **A2 个人物件与公共空间的配对**：甲手持的缺口杯与盥洗间修补片咬合吻合；乙所穿旧衣补线与共用针线盒余线材质色彩相近；丙腰侧小盒底部突起与研习桌磨损轮廓吻合。支持四人的现有物件与此处多个空间存在对应。
- **A3 反复练习的研习材料**：共用柜内有多人笔迹的测量练习纸（测木条、方木钉眼观测及互换复测记录），抽屉内有配套直尺、带缺口木条和钉眼方木。支持此处曾承担持续性研习活动。
- **A4 研习材料与涉案包纸的同源撕口**：侦探纸篓内包裹脏木楔的纸张，其不规则撕口与桌边旧练习册撕痕吻合，测量表格版式一致。将侦探宿舍、公共研习纸张与门厅隔离行动物证（脏木楔）直接相连。
- **A5 监所风格的编号与配给设置（诱导证据）**：宿舍门框上的冷硬铅印编号（`R-05` ~ `R-08`）；备餐间储食柜中按人头标准切块、包以油纸并贴有冰冷编号的口粮（`每日口粮-丙型配给`）；抽屉内带刻度与多孔钉眼的方木（极像监狱劳役计件品）。这组物证与外侧铁座横闩、铁格窗结合，在前期构成了强烈的“临时拘禁牢房”诱导表象。

A组确立此处曾长期用于住宿和研习，但其规整冰冷的形制在前期给“临时收容所/监狱说”提供了充足的诱导根据。

### B组：隔离门经历了什么（与隔离门的两大误导证据链）

- **B1 门的机械开向与自闭力学**：门向主楼侧开启（外开），门框设止口挡块；生活翼内侧设绳索滑轮自闭配重，开门受重力反拉；生活翼内侧设手动铁销。
  - *诱导误读*：忽略外开止口，误以为门向内开，将内侧木楔和止挡座当成“顶门御敌”或“撬门撬棍”。
- **B2 门底楔形遮蔽带**：门底内侧连续附着灰黑沉积，唯独木楔塞入处留有一段锐利的斜边干净区。
  - *客观证明*：黑灰渗入时，门正处于被木楔垫住、阻止配重自动合门而微开数寸的状态；
  - *诱导误读*：被误认为是剧烈撞门、摩擦产生的破损灰印，或外部火烧烟熏时的局部受阻痕迹。
- **B3 包在纸里的木楔**：一面附着与门底形状相符的斜向灰黑边界，另一面有受力挤压凹痕。
  - *客观证明*：木楔受力凹痕来自配重自闭拉力与木质挤压的静态支撑；
  - *诱导误读*：受力挤压凹痕被视为“强力撬门越狱时的撬痕”或“抵挡外敌凶猛冲撞的撞痕”。
- **B4 包纸的接触面转印**：展开后，纸内侧接触面留有从木楔转移的灰迹，纸外侧相对干净。
  - *客观证明*：木楔先撑门沾灰，随后被废纸包裹带回纸篓，推演先后严密；
  - *诱导误读*：被误认为逃犯惊慌中随手藏匿作案工具。
- **B5 门厅的清理残留**：门下地面留有连续擦拭痕迹，缝隙残留微量沉积；备餐间洗盆边缘和折叠湿布留有同类灰垢。
  - *客观证明*：异动平息后，内部人员从容用湿布擦洗了地面浮尘与洗盆；
  - *诱导误读*：被误认为暴乱镇压后的清扫现场，或扑灭余烬、清洗战斗血污的痕迹。
- **B6 双套锁止机制与销身擦痕**：生活翼内销插紧且销身有新鲜金属擦痕；主楼外侧横闩落入铁座。
  - *客观证明*：封闭由生活翼内销与主楼外闩两套独立装置共同维持；
  - *诱导误读*：内销擦痕被当成“外部暴徒/看守搏斗时生死争夺插销”的搏斗痕迹。
- **B7 止挡座的新旧位置**：重型铸铁止挡座由门前正中移至墙边，原放置处覆盖着后来的擦拭带。
  - *客观证明*：止挡座先被移开，原座底随后被擦拭；
  - *诱导误读*：重铁原本顶在门前，直接诱导了“将重铁作为防冲撞顶门路障”的防御假说。

B组物证不仅构成了真实的物理因果链，其表面特征更极具欺骗性地同时支撑着两套截然不同的错误假说。
### C组：四人的记忆与当前状态

- **C1 四份独立陈述**：四人均能陈述入学前的个人经历与职业技能，对本地旧事与昨夜经过一致失忆；侦探记得自己原定的报到日。它支持存在相近的记忆缺口，但不能单独证明缺口起止日期、共同经历或封存机制。
- **C2 能力保留与经历缺失**：能流畅运用职业常识，但回忆不起眼前的具体旧物。显示通用能力仍可使用，本地经历不可回忆；原因留待后续调查。
- **C3 正常就寝现场**：睡衣、整齐被褥、归位的鞋帽和盖好笔帽的钢笔，符合正常作息入睡特征；它们只能反对“现场刚发生明显剧烈挣扎”，不能单独排除他人整理、搬运或预先布置。

## 七、竞争假设与真正的反例（客观真实性定性与证据检验）

### H0：我们是刚来报到的新生，眼前的考验是入学考试
- **定性：真实成立的合法相容解（恶魔予以认可通过）**。
- **依据与逻辑**：四人脑中保留着即将前来学园报到的明确记忆，恶魔广播亦直接将其定义为“入学考试”。在缺乏不受布置者控制的绝对日期校准、且四人无法唯一确证自身何时入住的前提下，将此处解释为“校方预置的新生考核封闭考场”，四人正在通过因果逻辑证明自身能力以完成入学，在全部物理物证与因果逻辑上完全自洽相容。恶魔对该回答予以正式认可通过。

### H1：陌生人把我们抓进了临时监狱

作者侧历史不是临时监狱，但玩家不能用内侧插销或旧家具直接排除拘禁。编号、口粮、铁格和封闭出口足以引发怀疑；抽屉修补、研习材料及私人旧物支持这里有此前用途。讨论要区分“现在被困”与“原来是什么地方”。以临时监狱作完整回答会因根据不足而被追问，不因侦探一句话被宣布物理不可能。

### H2：用内侧木楔顶住外面向内推门

这是可由机械结构直接检验的具体动作假说：门向主楼侧开启，向内运动受止口限制；内侧木楔阻止门合拢，不能按该设想对抗向内推门。结合配重与灰迹再重建具体顺序。这个反例不证明外部从未出现威胁，也不直接证明撑门者为了探视；目的仍需额外依据。

### H3：木楔受力说明撬门越狱并遭镇压

木楔受力、横闩和灰迹允许提出该猜想，但不能独自证明越狱或镇压。包纸撕口、接触面的灰与地面擦拭要求解释物件来源和先后；“人慌乱时不可能包纸擦地”不是反证。双锁要求分别交代两侧的操作，不排除内部人员自己插销，也不凭侧别断言必有两名不同操作者。当前答辩拒绝的是把未经证明的动机当作结论；玩家仍可保留未决猜想。

### H4：四人曾在这里生活学习，并参与了一次局部隔离（历史客观真相）
- **客观定性：真实成立（作者侧客观真实历史，恶魔认可的终极解）**。
- **真相事实**：四人原本在此生活研习；察觉主楼异常烟气后，丙用木楔撑门探视；侦探赶到发现热烟危险，撤下木楔依靠配重合门，甲顺手插上内销避险；丙移开止挡座清理通道，乙擦拭地面，侦探用草稿纸包木楔扔进纸篓；随后正常入睡并经历契约封存；恶魔在外部落下外闩设立试炼。
- **检验机制**：能够完整自洽容纳全部物证、破解全部误导伪闭环的最节省解释。与 H0 并列作为合法的通过答案。

### H5：药物、疾病或异常力量导致记忆问题
- **客观定性：真实成立（异常力量所致）**。
- **真相事实**：世界观中记忆封存确由恶魔契约法则直接执行。
- **检验机制**：现场无医学化验物证供玩家在 Demo 中完成医学确诊，允许玩家提出该猜想，但不作为答辩必须提供的证据项。
## 八、逐步遇见同伴与四人小组会议辩驳机制

### 8.1 初始相遇与动线交汇
1. **宿舍**：玩家检查笔记、寝具、旧物与纸篓里的包纸硬物，形成“无法识别生活现场”的疑问。展开包纸发现带灰木楔，产生向外探查的动机。
2. **走廊遇甲（工程师）**：甲在观察房门，手持缺口杯；甲告知起居室墙上铜口刚才发出过短促共鸣，自己尚未触碰。
3. **备餐间遇乙（厨师）**：乙在检查食水，手持一只干净水杯，衣袖有旧补线。发现定额口粮包装标签、脏布、脏盆与水管。
4. **门厅遇丙（音乐家）**：丙在门厅观察大门，腰佩小盒。丙陈述其刚才推过门但受阻，门内销仍插着，尚未尝试拔销。
5. **拉下拉柄**：拉下铜口拉柄触发恶魔广播，同伴步入起居室汇合，准备在长桌前展开正式商讨。

### 8.2 四人小组会议：共同调查后的具体分歧

工程师关注编号、受力与出口；厨师关注灰垢、清理及食水；音乐家只陈述自己听见的风声，不把未知声源说成怪物。三人分别提出可能解释并承认未确定之处。会议的入口物证门槛仍按当前实现保留，但角色不因玩家漏听旧阶段介绍而重演初醒戏。

### 8.3 玩家选择物证，再由人物回应

会议按钮选择讨论对象，进入Dialogue后选择已取得的物证。门牌不能独自反驳房屋用途；洗盆灰垢不能回答木楔受力；口粮不能解释包纸。选错后人物说明这件物证没有回答哪一部分，可重选或离开。

有效回应分别使用反复使用的材料、铰链止口配重、包纸撕口与接触灰迹。回应限定结论范围，不预讲完整历史动作链。三项讨论完成后同伴邀请侦探代为陈述，不交出自己的去留决定权。

### 8.4 背景呼应：十六位学员全员通过的真正原因
这也正是学园十六名学员最终全员通过考核的深层设定：学园招募的每位学员都拥有顶尖的天赋与不可替代的“专长凭据（专业感知）”。在其余封闭区域中，其他学员同样凭借各自独特的专长凭据（如医学化验、建筑测绘、文献考据、机械应力解析等），突破了各自考场的信息盲区，从而全员在各自的考核中破局通过。

## 九、恶魔的入学考试

### 9.1 动机

恶魔需要具有处境判断能力与推演潜力的博弈对手。若四人连眼前场所性质与自身关系都无法理清，便不具备参与主博弈的价值。“入学”指失忆后重新取得博弈资格。

### 9.2 广播全文

> “声音穿过冷铁，想必已落入各位耳中。面包尚有余温，清泉亦未封涸；只是通向外界的门扉，此刻仍安卧于锁钥之下。
>
> 在这间暂避风暴的温床里，诸位不妨先为我解开三道微末的困惑：这里原本作何用途？你们与此间陈设可能有什么关系？而门前的旧痕与现在打不开的门，又各由什么造成？
>
> 请携上你们用双眼与指尖丈量出的确据来对答。无从知晓之物，大可坦陈未知；在此地，盲目的臆测比沉默更为下劣。
>
> 诚然，求知并非唯一的恩典。若有人倦于辨认身处的阴影，大可转身离席——我自会将他安然送返故里的炉火旁，拂去所有关于此地的记忆尘埃。唯有那些心怀执念、甘愿直面真实之人，方有资格踏入接下来的试炼。”

### 9.3 客观判定规则

- **场所与关系判定（含新生入学考试合法解）**：系统与恶魔认可两种回答：
  1. **历史客观解**：“长期住宿与系统练习场所／学园生活翼”，四人曾在此生活学习并实施主动防灾隔离；
  2. **新生相容解**：“我们是刚来报到的新生，眼前的封闭与器物是校方的入学考试试炼场地”。在缺乏独立日期基准的前提下，该回答与物证相容，恶魔予以正式认可通过。
  恶魔不苛求答出学园专名或坐标，只要逻辑自洽、具有已知物证支撑即可通过。
- **门厅因果判定**：至少说明门曾被木楔撑开、木楔沾灰后才被包起、门合拢与内侧插销分别需要相容的操作；当前打不开还须区分生活翼侧内销与主楼侧外闩。不得要求玩家猜出操作者、动机、绝对日期或无证据支持的完整动作顺序。
- **恶魔应答机制**：
  - 恶魔以契约者与审视者的冷峻质感予以回应（见 §12），仅针对包含**已调查事实根据**的陈述予以推进和评判；
  - 面对纯无根据的猜测，统一驳回并要求出示物证，防止穷举试错；
  - 针对解释中的逻辑/物理冲突（如先包纸后进灰、单方外部锁门等）进行针对性质询。
- **退场结算**：确认退出者安全返回家乡并遗忘学园经历（Demo 以独立退场结局演出呈现）；全员继续或分流选择均被支持。

## 十、脑内重建与制作边界

### 10.1 玩法输入、控制流编排与反向证据推断

脑内重建负责检验历史因果。玩家不直接修改现场物证，界面提供互补的推演、控制流与概念提炼机制：

#### 10.1.1 连续动作组合

当前使用纸面输入的受限行动句，词汇页公开人物、24类动作、对象与13类观察条件。句号、分号或换行连接顺序动作，观察条件只控制下一行动；没有要求玩家写寻路或重复循环。完整动作表、执行条件与未实现边界见[侦探技能界面](../detective-reasoning-interface.md#初醒组合动作表与执行边界)。旧STEP/IF/GOTO是兼容存稿路径，不作为当前玩家界面。

#### 10.1.2 踩中关键点与观察验证机制（解锁猜想的唯一通道）
连续行动流并非只要动作通畅即可通关，系统内置关键因果判定网：
1. **踩中关键事件节点（Key Nodes）**：角色的连续动作必须在特定时间与物理条件下**精确踩中关键节点**（例如：“垫木楔必须精准踩在烟雾涌出之前或正溢出时”、“撤木楔必须在侦探察觉危险的窗口期”、“移开止挡座必须先于地面擦拭步号”）。
2. **生成待验物理特征**：当动作流成功踩中关键节点时，推演沙盘在该位点高亮闪烁，生成“待验证模拟物理痕迹（Pending Trace）”。
3. **主动观察验证（Targeted Inspection）**：玩家必须主动点击该物理位点发起比对验证。
4. **发放核心猜想与推理词汇**：**唯有当且仅当玩家编排的动作流踩中关键点、且观察验证确认模拟痕迹与实际物证相符时**，系统才正式向玩家发放对应的【核心猜想（Conjecture）】并解锁对应的【专用推理词汇】！未踩中关键点或未发起观察验证的盲目推演无法获得任何有效猜想。

#### 10.1.3 先验推断：无证据状态下推断出物证（Predictive Trace Deduction）
这是侦探职业天赋在推演系统中的核心体现：
- **逻辑闭环先于物理发现**：在传统解谜中，玩家必须先在现场点击搜出物品；而在脑内推演中，侦探能够在**尚未亲眼调查某一角落、未翻开某一物品前，通过逻辑自洽性直接反向推断出证据的存在**！
- **实例推断**：
  - 若玩家在推演中建立了“有人曾探视外部热烟并阻止自闭门拉拢”的连续模型，推演引擎便会在没有门底遮蔽带物证的情况下，**反向推断出“门底地面必定存在一段未被熏黑的三角干净阴影”**；
  - 若推演成立，系统直接在脑内图景中标记出该推断证据，玩家随后可直接前往门厅“精准印证”，实现先验因果发现。

#### 10.1.4 闭卷槽位式推理词汇机制（杜绝同义词挫败）
为彻底防止玩家被文本输入器的近义词歧义（如“牢房”vs“监狱”、“门栓”vs“插销”、“撤下”vs“拔掉”）恶心，最终答辩采用**槽位式给定词汇机制**；脑内行动稿采用受限句法的可编辑文本（具体词表不在本规范中穷举定死，由后续实现与关卡调优落实）：
- **抽象词汇槽位（Slot-in Mechanism）**：玩家基于推演与物证解锁抽象认知概念，通过拖拽或点选已解锁的标准词块填入论据槽位中，构建答辩与辩驳逻辑链；
- **杜绝文本输入歧义**：系统仅接受合法的词块组合，避免玩家陷入“猜词游戏”或因输入法/同义词匹配失败导致的体验挫败。

#### 10.1.5 验证限制与虚拟时间成本
- **单次检查限制**：每轮推演阶段最多允许检验 3 处位点，避免无序试错。
- **推演消耗虚拟时长**：每次发起位点观察检验，**固定推进游戏内虚拟时长 10 分钟发条时间**，给玩家带来逼真的心智耗费与时间流逝感。

#### 10.1.6 动作词汇与推理选择

公开中性动作词汇及别名，不把“越狱”“御敌”等动机结论包装成动作，也不强迫玩家先选错才解锁有效动作。难度来自选择人物、对象、观察位置与因果顺序。不会预填完整解法；自动处理接近等执行细节，具体物态由规则结算。当前工具携持与通用传讯尚未实现，动作表如实标明。

### 10.2 核心因果反例矩阵（含隔离门力学检验）

系统检验并输出六项物理与力学因果冲突：
1. **外开止口力学反例**：在顶门御敌模型中，外开门受外部推力时已被门框止口阻断，内侧顶木楔无法提供对抗力矩，模型提示力学悖论。
2. **自闭配重撑门反例**：自闭配重持续提供拉合力矩，模型验证木楔的力学平衡角色仅为阻闭支撑，而非撬门或顶门。
3. **门底遮蔽时序反例**：若门处于闭死受冲状态（御敌模型），门底迎灰面无法生成带有锐利斜边的干净遮蔽区。
4. **接触转印反例**：先包干净木楔再置于灰气的模型，灰迹在纸外侧，与“纸外干净、内侧折印处转印”相悖。
5. **双锁空间操作反例**：单侧外部操作模型无法同时生成生活翼内销插上与主楼外闩落座的共存状态。
6. **清理时序反例**：先擦地后移止挡座的模型，无法生成原座底下的后发连续擦拭带。
### 10.3 机制边界与技术分工

- **Core 引擎**：负责无引擎依赖的规则状态推演与行动因果检验。
- **Godot 宿主**：负责 32×32 地图几何、碰撞、房间切换、Dialogue 对白树及交互 UI。
- **调查叙事**：微观物理化学化验（纤维分析、成分检验）限定为文本描述，不建底层多余物理系统。

### 10.4 界面约定：地图尺度、推演控制流与槽位式答辩

1. **地图尺度**：地图严格遵循 32×32 像素格，大件与角色自然跨格。
2. **物证检视浮窗（Detail Card）**：微观物证对比（门底遮蔽带与木楔斜边比对、木楔与包纸内侧灰黑转印比对、杯片断口咬合、练习册撕口对接等）采用专用悬浮检视窗展示。浮窗左侧/上方展示放大像素特写图片，右侧/下方配以精炼客观的物证文字描述。

3. **推演控制流面板（Flow Sequencer UI）**：
   - 界面采用双页纸面，右侧为可编辑行动稿与公开词汇，左侧为场景回放及时间轴；
   - 界面中央为连续行动沙盘回放区，支持快进与单步单帧复核；

4. **抽象词汇槽位面板（Slot-in Deductive Board）**：
   - 界面右侧为结构化词汇槽位栏，分类展示已解锁的【场所性质】、【隔离门因果】、【外部锁止定性】三大维度的推理词块；

5. **传话机（传声口）界面流程**：

   - **物证与词汇图文联动**：在向传话机提交论证时，界面展示选定的标准推理词汇卡，并同步弹出对应物证（木楔斜边图、自用纸同源撕口图等）的高清特写卡，作为正式答辩的证据陈述。
## 十一、验证要点与文字问答验收规范

1. **视觉可读性**：门底遮蔽、楔面灰黑附着与包纸转印需在细节卡片中图形化呈现，保证特征一目了然。
2. **场所推导体验**：未读谜底者应有机会提出“刚来报到的新生”这一合理解释，并检验日期与旧物来源。若没有可信的独立日期基准及个人旧居证据，判定必须接受保留该解释；字迹与练习册不能承担身份定案。
3. **笔记伏笔边界**：确认笔记文本不透露导师与真相，语境依赖后续案件兑现。
4. **机械闭合制作**：固定窗、内销与外闩的操作与视觉表现能在 Godot 中完整复现。
5. **12轮文字问答验收**：
   - 从醒来现场开始，每轮限一次调查、比对、操作或询问；
   - 目标：未读谜底者在 12 轮内得出“场所曾供生活研习”、“四人是否旧居尚待证明”及“门口先撑后关、内外双锁”的有据推论；第12轮若尚未自行提交，主持人直接问这三项，不再开放新调查；
   - 允许前期出现自然竞争假设（如 H1、H2），并在发现反例后主动修正。
