# 《安眠者有福》内容储备：学园篇

> 本文件保留剧情、角色关系和内容状态需求，供后续实现与宣传片片段取材。内容尚未实现，不构成当前版本验收标准。通用设计约束见 [设计规范](../design-standard.md)。

## 1. 游戏起点

十六名学员保留姓名、职业、入学前经历、性格和身体习惯。他们失去了在校经历、师生关系、学员旧关系、泄露事故与临终契约经过。

恶魔以校内代管者身份宣布禁闭游戏。学员需要恢复真实但主观的记忆，修复四院防卫，取得四件封印部件，在核心隔离舱重新执行真名封印。

## 2. 人物羁绊与过去

### 2.1 被撤回的第二名录

言灵导师发现第二名录会暴露恶魔的语义地址，命神偷取走拓片。侦探追查盗窃。律师依保密誓约撤回能洗清嫌疑的证词。考古学家把原文拆成四段保存。

- 侦探不信任神偷的解释，神偷故意留下可供追查的银币保护侦探的调查路径。
- 律师替考古学家保守秘密，考古学家把真名结构托付给律师的契约判断。
- 对应材料是指纹卡、旧银币、撤证书和铭文拓片。
- 事件发生在文献工房，指向名录库中的真名部件。

### 2.2 无声首演事故

诗人、音乐家、舞蹈艺术家和画家排练稳定主阵的仪式乐章。诗人为保护音乐家的听觉改掉禁句，舞者补走缺拍，画家看见不存在的第五位指挥。

- 诗人曾保护音乐家。音乐家因阵法失拍而怨恨诗人。
- 舞者相信画家的灵视。画家敬佩舞者独自承受阵线回冲。
- 对应材料是咏唱稿、蜡筒、舞靴和速写。
- 事件发生在共鸣厅，揭示恶魔曾提前干预事故节拍。

### 2.3 温室灰疫封锁

源质孢子混入温室灌溉。化学家承认试剂泄漏，博物学家发现真正源头是旧阵土，主厨销毁整季配给，医生隐瞒四人的暴露记录。

- 博物学家欠化学家一次公开真相。化学家用虚假自认保护博物学家的样本。
- 主厨依赖医生的污染判断。医生负责维持四人的生命并阻止学园长实施解剖。
- 对应材料是压叶标本、配给账、事故报告和未登记病历。
- 事件发生在种植梯田与温室，连接食物、水务和白塔污染线。

### 2.4 西侧断电救援

西侧断电困住学员。建筑师拆开承重墙，工程师过载水轮机，神射手压制失控役魔，职业棋手切断名录库供电，把最后电力送往诊疗所。

- 工程师信任建筑师的结构判断，两人共同承担机械联锁烧毁的责任。
- 棋手以名录库为弃子救下诊疗所。神射手负责守住救援通道。
- 对应材料是继电器、供电图、空弹壳和拆改蓝图。
- 事件终点在机械联锁室，解释该锚点为何失效。

### 2.5 源质反应炉泄露

苏醒周期的校准误差使言灵定义漏过一个时空节点。反应炉破裂。学园长留在核心隔离舱拖延恶魔，其余三导师以存在为质押建立禁闭游戏契约。

十六人分别通过停摆课表、星盘合影、联锁手记和解剖日志恢复事故片段。任何一份材料都只形成当事人的主观 陈述。四份材料合并后才能形成完整事故解释。

## 3. 待实现的内容状态与信息来源

人物需要分别保留身体状态、主观记忆、关系变化和可被他人见证的行动结果。关系目标、事件来源和材料来源应能追溯到具体内容对象；实现方式服从 Core 当前类型和设计规范。

记忆应区分客观发生的事件、角色对事件的主观说法，以及承载线索的日记、照片、拓片、蜡筒和遗物。阅读材料只改变读者掌握的信息，不改写已经发生的事件。

场景、通路、门锁和封印入口需要表达可达条件；房间内距离、碰撞和实时追逐属于游戏层。职业行动产生的样本、记录、进度、安全路线和修复状态都应能被后续行动引用。

恶魔的长期契约限制、临时发布的规则、规则的理解与接受状态需要分开记录。言灵实验和最终封印需要保留投入、步骤、失败原因与稳定代价，具体数据结构待实现时按 Core 现状确定。

## 4. 地图与资源提案

地图提案包含公共层、四院外环、生活小环、岛屿生存环、地下勤务环与四锚封印廊，并为关键目标保留替代路线。场景数量和通路数量待实现后确定。

名录库、阵法基座室、机械联锁室、学园长隔离室、源质反应炉和核心隔离舱作为候选的开局受限场景。解锁应依赖言灵、职业行动或规则事实，不能只提高移动代价。

四件最终部件分别是逆写第七码真名结构、四院闭合封印阵图、导师指纹机械联锁和铅玻璃源质安全载体。它们保持独立身份，不合并成抽象进度值。

## 5. 人物决策提案

人物根据自己掌握的信息寻找线索、恢复记忆、分享判断或寻求帮助。求助需要有人接受并实际抵达工作地点；职业特长应产生可见结果。共同计划提供协作目标，不让全知作战板替角色读取未发现的线索。重复行动、休整和目标结束后的行为需在片段中验证。

## 6. 言灵与规则设立提案

“镇心三拍”需要黄铜共鸣音叉、足够的心识与缘系，只能作用于同场景且具有实际恐慌的目标。

“门槛正名”需要誓约庭重型钥匙、名契、律令和门隙，只能作用于相邻的受限场景。成功后同时改变场景锁定状态并写入解锁事实。

规则设立必须在契约审议室完成。发起者、见证者、受约束主体、精确行动、目标场景和作用域都保存对象引用。红墨水是有限资源。成功后同时形成规则发布物、见证关系和局部客观 规则约束。

## 7. 胜利流程提案

四院目标需要相互印证的线索、实际协作、职业验证和部件交付，具体数量由玩法验证确定。玩家需要在契约审议室设立带见证的协同行动令。四院完成后，四名不同负责人进入核心隔离舱，分别以本院 研究目标 的验证结果承担 仪式 步骤。

最终封印应检查四院验证、恢复的线索载体、四件独立部件、协同行动令和多名贡献者。数量、重复推进限制和具体结算方式待实现确定。

## 8. 待实现的可重复轨迹

实现后应能导出协作成功与无人干预失败两类轨迹。每个 事件 应保存行动者、起点、终点、效果、决策原因、效用分、状态前后差分、契约复核和见证者，并能汇总职业重复占比、NPC 移动、独立记忆、远程求助、恶魔行为、关系行为、部件取得、仪式贡献和玩家主线占比。

设计目标是让每一步消耗实际 心智 稳定；最终 契约 成立后，恶魔从当前世界树移除，回归操作受到硬约束，游戏进入封印结局。
