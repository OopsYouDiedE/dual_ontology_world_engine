# 学园人物与设定总览

本文件记录十六位学生、四位导师、恶魔的设定档案及立绘映射。

## 一、恶魔与导师

### 1. 恶魔代管者
- 身份：学园代管者（Game Master）
- 职责：广播疑念、选择性事实诱导、维持基础生存脉冲
- 立绘文件：characters/demon-game-master.png

### 2. 四位核心导师
- 立绘文件：characters/core-mentors.png
- 言灵导师：言灵与文书学导师，契约担保者。
- 阵法导师：阵法与仪式学导师，能量封印核心。
- 工程导师：动力工程与自动化导师，物理阻隔控制者。
- 学园长：异象与医学导师／学园长，事故第一目击者。
