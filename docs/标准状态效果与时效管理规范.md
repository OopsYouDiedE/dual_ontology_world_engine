# 标准状态效果与时效管理技术规范

## 1. 概述与理论溯源

状态效果（Status Effects / Buffs / Debuffs / Auras）是角色扮演（RPG）与策略模拟系统中最核心的非即时持续干涉机制。该体系规范参考自经典桌上角色扮演游戏（D&D 3.5e/5e 持续法术系统）以及 MMORPG（如《魔兽世界》Aura 架构）。
系统负责跟踪临时施加于实体上的正面增益、负面减益、持续伤害（DoT）或心理影响，并依照全局时间轴动态结算其强度衰减、堆叠与到期注销。

## 2. 状态效果核心数据模型

一个标准的状态效果（Influence / Status Effect）实例具备以下独立属性：
* **宿主实体（Host）**：效果所附着的载体（角色身体、心智实体或特定场景）。
* **来源对象（Source）**：赋予该状态的攻击者、物品、机制或法术实体。
* **基准强度（Base Intensity $I_0$）**：效果在施加初始时刻的原始数值大小。
* **起始时刻（StartedAt $t_0$）**：状态在全局时间线上被激活并开始生效的绝对时刻。
* **过期时刻（ExpiresAt $t_{\text{expire}}$）**：状态完全失效并应被清除的绝对时刻。
* **线性衰减速率（Decay Rate $\lambda$）**：单位时间流逝导致的强度损失数值。若 $\lambda = 0$，表示在整个持续期内强度恒定。

## 3. 时效强度动态计算公式

状态实体在任意给定绝对时间时刻 $t$ 的当前有效强度 $\text{Intensity}(t)$ 遵循以下闭式公式计算，无需在空闲帧高频离散轮询：

$$\text{Intensity}(t) = \begin{cases} 
0, & \text{若 } t < t_0 \text{ 或 } t \ge t_{\text{expire}} \\
\max\Big(0,\, I_0 - \lambda \times (t - t_0)\Big), & \text{若 } t_0 \le t < t_{\text{expire}} 
\end{cases}$$

此公式确保：
1. 未到起始时间或已越过过期时间的判定严格为 0；
2. 衰减强度的下限被截断为 0，杜绝负数强度的异常发生；
3. 任何外部查询只需传入当前行动值时刻即可获得确定性输出。

## 4. 堆叠策略规范（Stacking Policies）

当同一宿主被重复施加同类状态效果时，系统依据预设策略进行仲裁：
* **持续时间刷新策略（Duration Refresh）**：保留当前有效强度，仅将 $t_{\text{expire}}$ 顺延重置为当前时刻加上新持续时间。
* **强度层数累加策略（Intensity / Stack Stacking）**：将新强度累加到当前强度上，受最大层数或最大数值阈值限制。
* **独立多实例策略（Independent Multi-Instance）**：每个施加的状态作为独立实例分别计时与衰减，对外综合输出取其总和或最高值。
* **最高值覆盖策略（Highest-Value Override）**：仅当新施加的强度高于现有剩余强度时，方才覆盖原状态。

## 5. 生命周期流转与垃圾回收（Garbage Collection）

1. **施加阶段（Apply）**：将状态实体挂载为宿主的子节点或专用状态集合，触发 `OnApply` 监听事件。
2. **时序推进与结算（Advance & Tick）**：时间线前进时，依赖该状态数值的属性计算自动按上述衰减公式读取当前有效值。
3. **过期注销阶段（Expire & Cleanup）**：
   * 当检测到 $\text{Intensity}(t) = 0$ 或 $t \ge t_{\text{expire}}$ 时，标记该状态为已到期；
   * 触发 `OnExpire` 离开事件，归还或恢复其占用的物理资源；
   * 从宿主实体中安全解绑并移出世界树，完成内存释放。
