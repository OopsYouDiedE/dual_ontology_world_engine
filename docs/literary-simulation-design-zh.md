# 文学范式驱动的规则、言灵与人物模拟设计

状态：2026-09-05 已落实 C# 短篇互动基线，尚未完成长期数值校准。实际接口、验证及未完成边界见 [实现与使用规范](./literary-simulation-implementation-zh.md)。本文按用户最新要求取代上一版方案中有关旧代码兼容、仅提供抽象能力和物品交由游戏设计的决定。C# 为主线。

## 1. 产品定位与设计原则

引擎默认支持规则怪谈与封闭群像推理中的人物互动。核心提供能够组合的规则句式、契约、言灵、灵异物品、调查与对话机制，以及可运行的默认数值。游戏作者主要决定人物想要什么、知道什么、隐瞒什么，以及世界起点。

这里的范式和物品能力是本项目原创的类型化设定，并非对现实民俗或某部作品机制的考据。它们提供明确的共同语义；作品可以改变外观和称呼，也可以明确替换规则。

不追求任意自然语言都能直接执行。文学句式是结构化范式的可读表达。文字中的对象、时间、条件和指代都有确定绑定；展示文本不能悄悄添加不在定义中的力量。

保留实体引用、单条 AV 时间线以及物理—语义—认知分层。删除旧接口与重复执行路径，不建立兼容层。旧演示只选择值得保留的内容重写，不要求保持旧 API、轨迹或数值。

## 2. 核心的两部分

```text
游戏：人物、秘密、关系、场景、规则实例、剧情起点
                         ↓
Core 默认机制库：文学范式、灵异物品、人物交互、数值档案
                         ↓
Core 结算机制：实体与来源、效果准备/提交、认知、决策、AV、因果事件
```

默认机制库属于 Core，开箱即用，不要求游戏再安装或设计一套领域系统。文件分开放置是为了维护，不是把工作退回游戏层。首版默认加载全部标准机制；有实际需要时才选择性替换。

对象、能力、规则、记忆与承诺仍由 Entity/Facet 表达。范式通过工厂组合现有 Expr/Effect，物品是实体预设，不给每个句式或道具建立派生类。只有执行计划、变化记录与必须区分未知状态的读取结果需要专门的运行时载体。

拟定组织：`core/effects` 共用执行；`core/patterns` 句式与绑定；`core/content` 道具及数值；`core/mind` 认知、目标、对话；`core/simulation` 组合与预测。沿用模块只在仍有明确职责时保留，不以保留旧类名为目标。

## 3. 十二种首发文学范式

每个范式同时提供条件、作用、边界、终止方式、默认代价算法、预测方法和表达模板。下表是首发范围，支持组合，不声称已覆盖所有文学表达。

| 范式 | 可读句式 | 运行时语义与默认行为 |
| --- | --- | --- |
| 禁令 | 在 C 情况下，不得做 A | 规范层产生选择压力；异常层可绑定违规后果。是否物理阻止必须明确，默认不阻止。 |
| 前提与许可 | 只有满足 C，才可以 A | 许可由指定授权者或有效凭证产生；授权范围、对象与期限确定。 |
| 限期义务 | 在 T 之前完成 A，否则 B | 建立可履行义务；到期按记录核对，最多结算一次本期违约。 |
| 条件应验 | 一旦发生 A，就会发生 B | 匹配真实事件，触发一次有来源后果；持久规则按各自新事件重新触发。 |
| 交换与抵押 | 我交付 X，你交付 Y；违约处置 Z | 双方同意、托管、履约及违约可区分；接受前不自动扣除对方资源。 |
| 例外与解除 | 除非 C；直到 A 为止 | 修饰已存在的条款或效果，不凭一句例外覆盖其他契约。 |
| 真名与指代 | 以此名／此物，指向 X | 建立或使用有来源的语义指向；名称相同不等于实体相同，错误指代不能自动命中真目标。 |
| 真言与隐瞒 | 对命题 P 不得说谎／不得向 G 泄露 P | 约束指定范围的言说行为；不创造知识，也不默认强制回答。沉默与明确拒答仍是候选。 |
| 自缚与增幅 | 我放弃 A，以换取 B | 自缚必须可执行、可追索且持续有效；缩小作用范围或取消能力选择换取明确折扣。 |
| 替代与代偿 | 以 X 承受本应落在 Y 的 E | 仅转移声明类别的效果；替代物实际承担耗损并留下因果痕迹。 |
| 封存与释放 | 将 X 封于 M，满足 C 才能释放 | 改变封存状态与可交互能力；宿主、完整性、维持与释放条件完整定义。 |
| 见证与质证 | 我见过 P／凭 E 指认 P／这与 Q 矛盾 | 生成可追溯陈述与争议；他人可要求来源、反驳、承认或拒绝，不把指控直接写成客观事实。 |

### 3.1 句式共有信息

所有实例拥有发布者或施术者、作用对象、范围、条件、结果、起止、来源和执行依据。由预设推导的字段不要求作者填写。作品只覆盖与当前设定有关的部分。

“必须”“不得”本身不决定超自然强制力。执行依据分为社会规范、双方承诺、异常法则或言灵能力。选择预设时已给出该默认依据，不要求游戏逐条重新设计解释器。

条款间不存在通用的“后说的话优先”。允许相互冲突的社会规范形成两难；超自然改写必须具备范围内的明确修改权。无合法修改权时，新条款可以被说出或被相信，但不能覆盖原约束。

“否则”响应的是已经发生的违规；硬禁止使行为无法发生。这两种语义不可混合，否则会在未发生违规时凭空惩罚。

### 3.2 指代、含糊和文字游戏

作者定义客观绑定。角色的理解可以不同，分别存入其认知。引擎记录“角色以为指谁”和“实际上指谁”，允许误解和诱导造成后果。

首版支持显式定义的多种解读及角色采信，不支持运行时随意解释自然语言。提出新解读属于质证行动；改变客观条款仍需要原有修改权、双方同意或具有该能力的言灵。

客观真言检查命题在说出时的真值；未知或无法判定的命题不能获得“宇宙已证明”的结论。说话者不知答案时可以拒答。自相矛盾或自指命题默认不属于可执行真言目标。

### 3.3 开箱可用的组合与后果

Core 附带“禁忌守则、借物归还、保密誓约、单题真言、实名封存、护身代偿”六种现成组合。作者只绑定对象、命题及必要期限，未覆盖的成本、范围与反制直接采用默认档案。

共用后果包括标记／暴露、有限负荷、封闭／解封、转交／扣押、记忆读取受限和指定效果转移。记忆读取受限只改变访问能力，不删除客观历史；“暴露”只使有相应感知能力的对象获得线索，不向全世界广播秘密。

禁忌守则默认组合为社会禁令与“违规后被锚点标记一段”的异常后果；借物归还默认以所借对象为抵押，到期仅在契约具备取回能力和预算时执行；保密誓约默认允许拒答，泄密后结算约定负荷；单题真言仅约束一次明确问题的回答。超出这些权限的惩罚必须显式替换，不能默认升级为死亡或永久控制。

普通场景规章采用纯社会版本。选择怪谈组合时才创建异常锚点及其默认有限储备，避免一张普通纸自动具备超自然权威。

## 4. 物品进入 Core 并完成机制闭环

首发十二种原型全部由 Core 提供。作品通常只需指定名字、放置地点、关联对象和初始持有人。物品描述不会覆盖能力定义。

| 原型 | 默认用途 | 消耗／失效及反制 |
| --- | --- | --- |
| 符纸 | 承载一条封存或条件应验条款 | 启用消耗符墨；撕毁终止其承载效果，已完成后果不回滚。 |
| 盐包 | 在场景通口建立短期守界 | 按份耗用；沾污或效期结束后失效，不能同时充当无限材料库。 |
| 烛 | 提供短期显迹与维持介质 | 燃料随 AV 消耗；熄灭停止能力，重新点燃只使用剩余燃料。 |
| 铜铃 | 产生可被同场景感知的惊动或揭示机会 | 每次使用消耗有限共鸣余量；会暴露使用者位置，不能只拿好处。 |
| 镜 | 观察已有映照关系，或反射一种被允许的效果 | 消耗镜面完整度；无指向关系或类别不匹配时不能反射。 |
| 红线 | 建立限定对象之间的联结 | 耗用线段；切断撤销本线提供的关系，其他来源关系保留。 |
| 名牌／姓名纸 | 提供对特定对象的指代依据 | 错名、伪造和来源不明影响认知可信度；称呼相同不建立同一身份。 |
| 旧照／遗物 | 提供残迹与调查入口 | 只能揭示其实际承载的片段；查阅可重复，真相和源质不会无源增加。 |
| 规则纸／日记 | 携带条款、陈述与版本来源 | 复制传播信息，不复制权威或力量；篡改形成新版本并保留来源差异。 |
| 录音机 | 记录在感知范围内发生的言说 | 消耗电量与记录容量；重放证明记录内容，不自动证明陈述为真。 |
| 封盒 | 保存被封对象及封条 | 有限承载力与完整度；破坏可释放内容，同时触发真实危险。 |
| 纸人／替身 | 承担指定类别的一次代偿 | 承担后耗损或销毁；不能复制被替代者的身份、记忆或源质来源。 |

预设默认自动发布使用、检查、携带、展示、交付及适用的言灵候选。道具的社会作用也进入默认机制：交出证据、借出护身物、破坏他人的封条都会生成实际关系和认知后果。

同物不同外观通过改名和描述完成；改变力量性质才需要替换范式。新增原型应有独立机制组合价值，不以道具名称数量扩充核心。

## 5. 默认数值档案：初始设计值

以下数字是待实现验证的首版基线，不是已证明平衡的结论。统一放在 Core 的一个可读数值档案中，游戏默认无需填写。原型工厂引用该档案，不能在闭包内散落奖励常量。

### 5.1 时间与效力

基本节拍为 10 AV。短暂回应 5 AV，普通使用或有内容的对话 10 AV，调查／准备／休整 20 AV，仪式阶段 30 AV。紧急嵌套回应仍占用反应者的后续行动时间。普通角色默认每一因果链只主动回应一次，避免人群连续插话导致恢复时间无限累积；链内已承担的反应代价不能靠换措辞取消。

现有十二种 Aspect 保留。首发道具和效果使用 1／2／3 三档效力，范围限制为预设标定，不把全世界实体都当默认目标。

效力需求计算统一为：

`Q = 效力档位 × 实际目标数 × 维持段数`

即时效果的维持段数为 1；持续效果每 20 AV 为一段。Q 是预算单位，不是额外世界货币。物品预设将有限墨量、盐份、燃料或承载余量映射为可支付预算，投入必须有实际来源。

新目标进入持续范围时先获得下一段所需预算；不能支付则不纳入效果。持续效果启动支付首段，后续在边界先支付再生效，终止后不继续计费；未使用的预留解除，已经生效的阶段不退款。

无限期条款可以存在，但每次真正产生超自然效果仍需预算。系统级异常可由具备有限储备或明确定义补给的锚点供能。普通角色不能仅靠发布文字制造该锚点。

默认怪谈锚点储备为 12 Q，首版无自动恢复。场景或通口的登记不等于把所有受影响者合并为一个目标；每个实际受影响的独立实体都计入目标数。锚点不足时条款文字继续存在，但未付费的超自然后果不生效，并留下可调查的失效迹象。

### 5.2 支付、恢复与自缚

同一单位投入只能支付一次；同一来源不因转移、别名、影像或复制而重复贡献源质。工具的源质资格可复用，但产生效果仍支付实际预算或承受明确耗损。

默认常人允许以精神负荷代付适用效果，1 点负荷支付 1 Q。复用并统一现有疲劳状态：初值 0，上限 6；达到 4 后优先考虑恢复，达到 6 后无法主动发动新增负荷的言灵。安全且未被中断的 20 AV 休整消退 1 点。瞬时安抚可以改变情绪，不能替代这种实际恢复。

代价不能由本次效果生成的资源支付。以同一通用力量恢复同种施术负荷的路线默认禁用；有外部真实药物或长期恢复时按独立来源支付。资源转化必须有净消耗，自动检查可达转换循环是否产生正收益。

首发自缚为“仅自己、仅一个实名目标、仅指定场景、限制一种后续能力”四种模板。单次最多减免 1 Q 且最终不少于 1；相同作用的条件不叠加减免。已事实成立且不限制原本能力的空条件不提供收益。自缚提前破坏导致尚未完成的增益终止，已约定追索另行执行。

### 5.3 原型起始容量

默认包：符纸 2 Q；盐包 3 份、每份 1 Q；烛 3 段、每段 1 Q；铃 3 次、每次 1 Q；镜完整度 3、每次反射按效力扣除；红线 2 段、每条联结至少消耗一段；封盒承载 2、持续封存每段 1 Q；纸人一次可承受最多 2 Q 的指定效果。

名牌、旧照、规则纸不免费供能，只提供资格、来源和信息。录音机默认记录 6 个对话节拍，每节拍消耗 1 格电量；重放 1 格。电量补充来自实际电源，不由播放自动恢复。

这些原型在默认威胁 1 档下具有可用应对，在 2 档下需要投入或合作，在 3 档下需要准备、交换或缩小目标。此处是校准目标，不保证任何局面都有安全解；游戏可设计绝境。

## 6. 具有人的表达的人物机制

### 6.1 角色需要的最少设定

每个角色填写当前欲求、在意的人或承诺、想隐瞒的事实；从 Core 预设选择性格倾向和说话方式，允许覆盖。未指定的常识、基本调查行为、资源使用和对话能力由默认包提供。

角色可以兼有相冲突的欲求。判断收益时包含关系、承诺、暴露秘密和自我形象的代价；不把所有人设成追求同一个总体收益的合作求解器。

重大承诺可以设为底线，默认不会因一次小收益被交换。持续反证、目标落空、关系变化或明确的高压处境可以触发重新考虑；每次改变态度记录其实际原因。不能用随机数直接替代人物转变。

### 6.2 十二种默认交流行动

陈述、追问、质疑、出示证据、提出交换、作出承诺、请求帮助、安抚、施压、隐瞒、承认／撤回、拒答／沉默。

每个动作都指向具体命题、争议、人物或请求，具有信息与关系后果。措辞变化不能重复领取“社交收益”；没有新内容的重复陈述不会自动强化可信度。

谈话围绕尚未解决的争议推进：有人提出主张，相关人物得到回应候选，可以追问来源、反驳某个环节、保护他人或选择不说。局部回应使用嵌套 AV，长期调查与准备回到普通时间线。

证据只能支持它所能证明的部分。录音中出现一句话，不等于说话内容为真；看见某人出现，不等于证明其完成某行为。矛盾暴露生成争议和态度变化，不自动迫使所有人接受推论。

### 6.3 默认价值档案

角色评价安全、当前目标、重要关系、自主权、求真和社会形象六类预期变化。它们从真实状态及认知差异推导，不再增加六条可被任意动作刷高的资源槽。首次获得相关证据有信息价值，反复播放同一段记录没有重复求真收益。

首发档案的相对权重如下，作者选一个即可。它们是混合取向，不限制职业或允许的动作；角色秘密、承诺和底线在权重之外保留独立意义。

| 取向 | 安全 | 目标 | 关系 | 自主 | 求真 | 形象 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 审慎 | 3 | 2 | 2 | 2 | 1 | 1 |
| 求证 | 2 | 2 | 1 | 2 | 3 | 1 |
| 护伴 | 2 | 2 | 3 | 1 | 1 | 2 |
| 自主 | 2 | 2 | 1 | 3 | 2 | 1 |
| 体面 | 2 | 2 | 2 | 1 | 1 | 3 |

预期改善按默认评价器归一到 -1 至 1 后乘相对权重。负荷、AV、消耗品和风险使用集中代价系数；相同事实或来源的收益只计一次。普通短对话与耗材使用的机会成本必须在样例校准中可比较，不能直接把未经归一的生命值和关系强度相加。

默认以一个 20 AV 准备行动为 1 单位时间成本；每消耗 1 Q 的已持有有限材料为 1 单位材料成本，新增 1 点负荷为 1 单位成本。明确不可接受的承诺破坏先作为角色底线处理，不允许仅靠这些小额收益抵销。上述系数与范式强度一样须经过阶段 E 的行为校准。

### 6.4 表达生成顺序

先决定角色采取什么交际行动，再依据其知识、目的、关系与表达倾向组织话语。默认渲染提供克制、直接、迂回、尖锐等可组合表达方式，使用原创句式，不复制特定角色台词。

表达同时可呈现动作、停顿、拒答和自我修正。角色不能在默认台词里宣布自己尚不知道的幕后事实；旁观者也不能直接听见内心评分。

采用“语义行动＋可替换措辞”的约束。未来可接生成式模型润色，但模型不能新增证据、承诺、物品或已经发生的效果。作品可提供自己的台词，运行仍由同一语义行动决定。

这使人物具备可解释的表现基础；作品级语言质量仍需通过生成片段审读和迭代，不能仅凭模板数量保证。

## 7. AI 如何通过模拟估算效果

NPC 决策与作者评估复用同一效果执行器，但使用不同的世界视图。

NPC 从已知事实和有来源的假设出发，为当前候选做短程推演。未知保持未知，可比较若干合理假设；没有依据时报告不确定，不偷偷调用客观世界答案。改变的局部状态放入独立覆盖视图，推演不污染真实实体、事件、观察、AV 或正式 RNG。

默认先评估直接后果，再展开一项准备或回应，有限预算内比较更长链。预估输出收益、代价、被发现风险、违约风险、不可逆变化和不确定部分。具体决策权重来自角色预设，不要求游戏逐动作打分。

作者可以在完整世界的独立分支进行多轮模拟，比较不同规则措辞、初始道具数量和知识分配。输出实际分布和失败原因；只有重复试验足够时才展示频率，不能将确定计算包装成伪概率。

新范式必须提供可准备的效果计划和生命周期，因此预测、执行、审计和表现使用同一语义。执行器不能留一个核心无法理解的必经任意副作用闭包。

## 8. 游戏作者的最低配置

第一版新游戏的必要输入收敛为四组：

1. 场景及通口；
2. 人物的欲求、关系和秘密；
3. 从核心范式实例化的规则／契约／言灵；
4. 核心物品的放置与关联。

威胁档案、道具数值、普通行动、调查和对话、默认效用、观察传播、违约结算和文本解释均由 Core 默认提供。游戏可以覆盖，不能被要求先重新实现这些系统才能运行。

作品特有的谜底和起始事件仍由作者决定。Core 不负责替作者选择主题或保证某个剧情结局。配置需使用对象引用或明确的模板槽位，不再额外填写用于定位运行时对象的 ID。

## 9. 实施顺序

| 阶段 | 交付范围 | 完成依据 |
| --- | --- | --- |
| A | 共用效果执行、状态覆盖视图、来源、投入、生命周期与事件变化记录；删除被替代旧路径 | 推演不改真实状态；相同定义预估与执行一致；支付和重复来源不存在套利。 |
| B | 十二范式的结构与默认句式；先贯通禁令、限期义务、真言、封存、质证，再完成其余范式 | 条件、生效、见证、解除和反制逐项成立；换措辞不改变执行语义。 |
| C | 十二物品及集中数值档案，自动装配能力 | 耗尽、破坏、转移、复制、恢复及组合均有确定结果；游戏不写物品执行代码。 |
| D | 默认人物取向、交流、局部推演和分视角表达 | 角色会因不同知识和承诺作出不同决定；沉默、误解、合作与反对有可追溯原因。 |
| E | 两个独立主题场景及作者模拟报告 | 只更换四组内容配置即可运行；两个场景均使用规则、言灵和社会互动，不能以资源村替代。 |

阶段 E 的场景是“夜班守则”与“封闭学园质证”。使用原创人物与台词；前者侧重错误规则、异常条件和有限护具，后者侧重证据、保密承诺、真言及保护同伴。两者共用全部基础机制。

重写受影响的学园运行入口和验证，不保留旧 API、旧导出格式或旧时间轨迹的兼容承诺。旧生成报告作为历史文件保留，不用于证明新设计已完成。

## 10. 验收与数值校准

机制验证覆盖：重复投入、无源复制、跨范围指代、期限边界、失效撤销、自缚空条件、反射和替代循环、封存破坏、隐瞒与真言、证据来源、误解与未知、推演隔离。

反事实验证固定其他条件，分别改变规则版本、角色是否获知、关系承诺、关键证据、护具余量与行为是否被见证。检查变化发生在正确的因果位置；不要求每次干预都改变结局。

数值报告比较效力 1／2／3 档和低／标准／充足三种补给档，记录耗用 AV、材料与负荷、违规次数、义务完成、人物目标实现和无法继续的原因。确定性机制先做边界与循环检查；有随机机制时再做固定种子的重复推演。

出现无代价维持、无限恢复、某件道具跨场景支配多数选择，或对话无需新信息就无限提高关系时，不能完成数值验收。若某个优势来自明确的人设或剧情条件，必须能从报告定位该条件。

人物表达另做片段审读：对话是否围绕实际争议，角色是否具有自己的利益，改变立场是否有依据，台词是否泄露未知事实，句式重复是否掩盖没有行动后果。机械正确与文学表现分别验收。

最终向作者提交两份最小配置及一个新增范式组合的改动清单。达到“无需修改核心和逐动作评分即可使用”的要求后，才认定本轮减少了游戏自身设计负担。
