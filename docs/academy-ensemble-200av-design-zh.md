# 《异常感知学园》群像认知与相遇事件设计

## 设计目标

群像不为十六个人分别编写固定日程。系统只保存人物的稳定性格、人物对他人的主观认知、当前处境与学园规则，再从少量反应种类中选择符合当事人的行动。

人物可以判断错误。只要错误来自其已知信息，并且行动符合其性格与关系，这种错误就是有效模拟。关系变化必须能追溯到具体事件，不能凭日期自动增加好感。

十六人开局失去在校经历、师生关系与彼此旧关系，只保留姓名、才能、入学前经历、性格和身体习惯。过去羁绊在相关材料被发现、相信以前，不参与决策。

## 一日与行动值

一日为 200 行动点，每 20 点构成一个基本阶段。

- 天亮占 120 点，共六个阶段。
- 天黑占 80 点。正常角色将其作为一次连续睡眠结算，不生成四轮日常行动。
- 穿过一条普通通路消耗 20 点，较远通路消耗 40 点或 60 点。
- 同场景的一次完整交谈、进餐或对象检查通常消耗 20 点。
- 一段交谈中的表情、回应和打断嵌套在当前行动内，不单独收费。
- 角色需要在天亮结束前支付返回住处的移动成本。

夜间醒来、移动、交谈和使用设施都是违规。被异常惊醒仍会形成违规事实，诱因另外记录。夜间违规只由特殊事件触发，不作为普通日程内容。

## 最小人物状态

人物决策只读取四类内容：

1. 稳定性格：人物重视什么、害怕什么、受到压力时如何保护自己。
2. 当前状态：疲劳、饥饿、恐慌、受伤、正在履行的承诺。
3. 主观认知：他认为另一人是否可靠、危险、亲近，以及这种判断来自什么。
4. 客观约束：时间、地点、校规、可用物品、在场者和行动成本。

才能不直接产生目标。人物先决定要不要处理问题，才能只影响他采用的手段和成功可能。

## 定向认知关系表

每个人都拥有一份指向其余十五人的认知记录。`A 对 B` 与 `B 对 A` 分开保存。

每条记录只需要以下内容：

| 内容 | 形式 | 含义 |
|---|---|---|
| 亲近意愿 | `-2` 到 `2` | 没有任务压力时，A 是否愿意陪伴、闲谈或私下袒露 |
| 履约预期 | `-2` 到 `2` | A 是否相信 B 会按已经说好的方式行动 |
| 伤害预期 | `-2` 到 `2` | A 是否认为 B 可能使自己、他人或公共目标受损 |
| 人物判断 | 少量带来源的 Claim | A 认为 B 会保密、擅长某事、正在欺骗或容易做出某种选择 |
| 未结事件 | 直接引用 Event | 欠情、受辱、失约、被保护、待解释的隐瞒等尚未消化的事情 |

`0` 表示没有足够依据，不表示普通朋友。三个数值只调整候选行动的顺序。能力是否可信、行为是否可预测、危险是故意还是意外，都保存为具体人物判断，不再增加全局数值。

主动接触不是关系数值。角色可以因为监视、质询、利用、救助或没有替代方案而接近自己认为危险的人。伤害预期只压低无防备接触；只有即时危险或客观规则才会删除单独接近等候选。

例如，A 可以不喜欢 B，却认为 B 一定守约；也可以亲近 B，却认为 B 不适合保守秘密。两种关系会产生不同合作方式。

### 认知的形成

- 亲眼见证的行动产生高把握判断。
- 可靠人物的转述产生中等把握判断。
- 流言、恶魔广播与身份偏见只能产生低把握判断。
- 当事人的解释不会直接覆盖旧判断，只会成为新的证词。
- 守约提高履约预期，不自动提高亲近意愿。
- 主动关心可以提高亲近意愿，不证明对方办事可靠。
- 制造实际风险提高伤害预期；新证据确认这是意外时，只修正相应判断。
- 道歉只建立“对方承认责任”的事实，不自动恢复亲近意愿或履约预期。
- 新证据可以修正人物判断，但已发生的伤害仍然保留。
- 同一事件不能因被反复谈论而重复加减数值。

所有在场者会根据自己的性格和既有认知，分别解释同一事件。因此一次公开争执可能让一人同情当事人，让另一人更加怀疑。

## 七类基本反应

系统只需要七种反应方向：

1. 核实：追问、观察、对照证词、检查结果。
2. 交涉：解释、请求、劝说、给出台阶、交换条件。
3. 协作：共同完成一件可以验证结果的事情。
4. 制止：打断、拒绝、收回权限、限制危险行动。
5. 保护：优先照顾人或资源，代挡压力、转移风险。
6. 回避：离场、保持距离、暂缓表态、拒绝卷入。
7. 隐匿：暂不公开信息、利用误解或私下布局。

反应方向不是台词模板，也不自带善恶判断。一次行动可以有一个主要方向和一个附带方向。人物性格决定表达方式，认知关系决定对象、公开程度和风险容忍。

## 人物设定提供的首次候选

下表不是已经成立的反应规则。它只在人物第一次面对某类处境、尚无剧情依据时提供低风险候选。第一次实际选择发生后，后续反应必须优先引用具体剧情中的刺激、当时认知、实际动作和现场边界；不能继续只凭人设标签推断。

| 人物 | 主要敏感处境 | 初始反应倾向 | 认知造成的变化 |
|---|---|---|---|
| 雾岛律 | 证词矛盾、无证据指控 | 验证 | 玩家决定是否公开、包庇或继续追查 |
| 鸣海澄 | 被忽视、发言失去效果、真实危险 | 先扩大表达，危险落实后寻求退路 | 在意者的忽视会造成受伤；敌视者的忽视更容易被他转成嘲讽 |
| 久世弦 | 噪声、失真、强迫参与 | 纠正或退出 | 信任对象会得到具体解释；不可信对象只得到拒绝 |
| 野野宫蕾 | 未知生物、样本受损、社交边界 | 接近观察，必要时保护对象 | 被提醒者可信时会调整行为；认为对方无知时会绕过阻止 |
| 真壁铸 | 设施故障、同伴认为他无用、计划停滞 | 立即动手，失败后加大投入 | 信任他人时愿意交出部分工作；受轻视时容易逞强 |
| 榊火澄 | 浪费、拒绝进食、后勤被擅自处置 | 直接制止并照顾实际需要 | 对可信者会解释分配；对反复破坏者会限制其接触资源 |
| 冬城史 | 史料被误读、记录受损、被迫立即表态 | 保留意见并核对原文 | 信任提问者时会逐步说明；害怕被利用时会隐藏关键判断 |
| 月见里鸢 | 所有权、权威命令、弱者受压 | 试探边界或绕过规则 | 对守约者会归还并合作；对滥权者会故意证明规则可被突破 |
| 御影章 | 含糊义务、规则漏洞、单方面要求 | 追问条件并重述责任 | 对守约者提供可执行方案；对失信者要求公开见证或担保 |
| 白峰局 | 无选择的集体决定、重复劳动、明显博弈 | 观察局势，必要时指出最优解 | 相信执行者时愿意给方案；不信任时只指出风险而不接管 |
| 赤星砾 | 未知反应、实验受阻、结论被否定 | 立即验证，兴奋时忽略他人节奏 | 尊重的质疑会促使复核；敌意质疑容易让他冒险证明自己 |
| 苍井砥 | 边界不清、武器失控、规则被破坏 | 建立警戒并要求服从 | 信任对象违规时先问原因；危险对象违规时优先控制行动能力 |
| 绯宫巡 | 公开失态、未经允许的评价、必须承担的舞台 | 维持仪态并完成眼前行动 | 重视者的评价会被私下回想；轻视者的挑衅会得到正式拒绝 |
| 青栖绘 | 被注视、作品被代为解释、看见异常细节 | 观察、记录或退出交谈 | 信任对象可以看到未完成记录；不可信者只能看到处理过的结果 |
| 方城础 | 空间失序、路线含糊、结构风险被忽视 | 先纠正结构问题 | 认可对方判断时会协商；认为对方鲁莽时会直接封闭路线 |
| 灰原朔 | 伤情被拖延、隐私被公开、无效安慰 | 先处理风险，语言保持冷淡 | 信任对象可获得完整诊断；不可信者只得到最低必要信息 |

这些倾向不能单独决定行动。人物对目标的认知、当前压力和规则会改变最终选择。前五日如何产生首批行为依据，见[《前五日剧情规则树》](./academy-first-five-days-rule-tree-zh.md)。

## 决策树

每次产生行动时，按固定顺序处理：

```text
当前是否处于强制睡眠、失去行动能力或客观禁止状态？
├─ 是：不生成普通行动；只有特殊事件能够继续。
└─ 否：检查当前最显著的需要或刺激。
       ├─ 没有显著刺激：从吃饭、休息、闲谈、独处、检查环境中选择日常行动。
       └─ 存在刺激：确认角色实际注意到什么。
              ↓
       按敏感点生成至多三个解释。
              ↓
       读取角色对目标的认知，调整善意、敌意和不确定解释。
              ↓
       检查公开或私下、在场者、紧迫伤害与当前需要。
              ↓
       用规则、行动点和地点删除不能执行的候选。
              ↓
       从七类反应中选择主要方向，形成具体动作。
              ↓
       各目击者分别解释事件，更新自己的认知。
```

不合并成一个总效用分。若两个方向都可行，先处理眼前真实危险；没有迫切危险时，优先处理仍在影响关系的未结事件；仍然接近时才允许小幅随机。随机只能表现犹豫、疲劳或冲动，不能让人物无理由违背核心性格。

规则只负责禁止行动、要求代价或规定程序，不替人物生成动机。才能只在目标形成后改变具体手段。

## 认知差异如何改变同一反应

以“B 隐瞒了重要信息”为例，A 可以采用同一种性格基础，却因认知不同采取不同动作：

- A 对 B 的履约预期高：私下追问，允许 B 在明确期限内暂时保密。
- A 愿意亲近 B，但履约预期低：先阻止其继续行动，再要求解释。
- A 认为 B 危险：在公共场合揭露，并要求限制 B 的行动。
- A 欠 B 人情：暂时替 B 遮掩，同时留下补充说明的期限。
- A 曾被 B 欺骗：把本次隐瞒与旧事件连接，拒绝口头解释。
- A 对 B 几乎不了解：先检查信息来源，不立即站队。

同样的公开侮辱也不固定触发争吵。重视对方的人可能更受伤并私下追问；轻视对方的人可能当场嘲讽；害怕对方的人可能暂时顺从；对方若已多次守约，角色也可能先判断这次失言是否另有原因。

## 相遇事件节点

自由行动不会被固定剧情强行替换。系统持续检查是否形成了具有戏剧意义的条件；条件成立时，普通相遇可以升级为特殊事件节点。

一个节点只保存：

- 参与者与可替代角色条件。
- 必须存在的关系事实和主观判断。
- 触发刺激，例如公开质疑、失约、资源争议、违规或隐瞒。
- 必须在场或不能在场的人。
- 可以采用的反应方向。
- 会使事件暂缓、变形或失效的条件。
- 结算后形成的新事实、新认知和后续节点。

事件不固定在某一天或某个房间。如果参与者、认知、刺激和现场条件仍然成立，它可以在等价场景发生。玩家提前消除条件，事件就不会照常出现。

### 冲突链

一段完整关系通常由多个独立节点组成：

```text
轻微摩擦
→ 同类问题再次出现
→ 公开冲突或实际损失
→ 回避、站队或错误解释
→ 新证据、共同任务或承担代价
→ 有限合作、关系修复或继续恶化
```

修复条件必须真正改变双方判断。可用条件包括共同承担风险、兑现承诺、提供原本可以隐瞒的证据、保护对方利益或纠正公开误解。单独道歉不足以完成修复。

关系修复也不要求全面恢复。人物可以恢复工作合作，却仍不愿分享秘密；可以接受对方道歉，却继续避免私下相处。

## 前二十天的事件组织

前二十天不写成固定日历剧情。使用四个事件阶段控制密度：

- 第 1—3 天：自我介绍、勘察、吃饭与作息。形成第一印象和少量生活摩擦。
- 第 4—8 天：钥匙、配给、隐私、噪声、任务分配和公共规则使第一批冲突条件成立。
- 第 9—14 天：冲突产生回避、站队、失约和错误传闻。开放第一批修复机会。
- 第 15—20 天：异常威胁与既有关系交叉。此前形成的可信、欠情和怀疑决定谁愿意共享情报、保护谁或公开指控谁。

日期只控制可用设施、总体压力和事件密度，不保证某一对角色必然发生某件事。

二十天内至少应形成：

- 三条仍在发展的冲突链。
- 两次需要实际代价的关系修复机会。
- 一次修复失败或被拒绝。
- 一项工作信任与情感亲近明显不一致的关系。
- 一次由错误认知引起、被后续证据修正的集体判断。
- 数个只处理吃饭、闲聊、无聊、休息和小摩擦的普通日子。

### 首批事件链条件池

以下六条链用于提供可收束的故事压力，不保证固定人物、日期或结局。

#### 临时规则的授权争议

御影章提出留档、登记或见证程序时，月见里鸢可能把未经同意的登记理解为权力扩张；苍井砥可能因安全边界明确而支持。只有规则已经限制实际行动、反对者没有得到有效复议、多人同时在场时，争议才升级为公开节点。

修复需要制定者接受规则同样约束自己，反对者以可验证方式指出漏洞，执行者撤销超过授权的限制。玩家提前完成公开复议，公开冲突便失效。

#### 照顾、隐私与集体资源

榊火澄关注进食与配给，灰原朔保护身体信息，白峰局可能提出有效但需要有人承担代价的方案。食物或药物真正短缺，同时有人拒绝说明需要时，摩擦才升级。

修复目标是有限信息边界：灰原保存完整病情，榊只取得配餐所需信息，账目公开数量而不公开诊断。仅停止争吵而不改变信息流，不算修复。

#### 危险样本的保留争议

野野宫蕾关注活体状态，赤星砾关注可重复反应，方城础检查容器与房间，真壁铸相信装置能够解决问题，苍井砥关注失控后的封锁。只有样本出现可观察异常，且保留与销毁都有实际代价时，事件才成立。

修复需要一次有边界的联合试验，并明确中止权。玩家提前销毁样本会取消原冲突，只留下“谁有权进行不可逆处理”的余波；找到第二份样本则会把零和争议改成低压力对照试验。

#### 公开排练中的纠正与羞辱

鸣海澄需要回应，久世弦难以容忍失真，绯宫巡重视公开完成度，青栖绘不愿别人替自己解释记录。多人合作时出现错误，并且旁观者把技术纠正理解为人格羞辱，冲突才升级。

修复不是互相夸奖，而是低风险复演：指出问题者提供可执行修改，被指出者实际完成修改，旁观者不再用旧失误取笑。玩家取消公开展示，会使公开羞辱节点失效并转成私下纠正。

#### 记忆材料的不对称披露

冬城史发现涉及多人但无法证明完整事实的残缺材料。材料只交给一名被认为可靠的人，其他涉事者后来得知自己被排除时，才产生披露争议。旧材料只能形成可怀疑的 Claim，不能恢复旧感情。

修复先恢复程序合作：封存原件、公开复制件、区分事实与推测、允许涉事者表达。玩家提前公开材料会取消不对称披露节点，转为群体解释分裂。

#### 夜间违规与错误归因

夜间异常使某人因急救、保护、取证或掩盖行为而违反睡眠规则。次日留下的脚印、门锁变化或遗失物只能证明有人活动，不能自动证明动机。此前被认为爱试探规则的人更容易受怀疑，曾经守约的人更可能先得到解释机会。

修复必须分开处理违规事实和行动动机：违规者承担规则后果，指控者撤回超过证据的判断，受助者或物证验证实际经过。玩家白天消除异常时，这条夜间节点完全失效，所有人正常睡眠。

## 玩家介入

玩家可以改变事件条件，而不是只选择预写结局。

- 提前公开证据，改变他人对刺激的解释。
- 阻止两人同场，使冲突延后或转移。
- 私下调停，避免公开场合放大面子压力。
- 承担某项任务，让两人的竞争失去对象。
- 违背承诺，自己成为新的关系事件来源。
- 夜间违规，改变次日所有目击者与听闻者对玩家的危险判断。

玩家无法用一次正确选项直接获得信任。其他人物只根据自己看见、听见并相信的事实更新认知。

## 叙事输出

模拟层保存行动、认知、事件来源、见证者和行动值。文学脚本只把玩家视角内的重要部分写成场景。

场景应包含正常人的停顿、插话、误解、无意义闲谈和未完成回应。不是每个在场者都必须发言，也不是每句台词都必须推进谜团。人物的性格通过选择、说话方式和事后行动表现，不由旁白宣布。

## 验收条件

- 不存在由才能名称直接推出日常目标的逻辑。
- 所有关系变化都能追溯到实际事件或被相信的证词。
- 同一事件对不同见证者可以产生不同认知。
- 同一角色面对不同对象时，可以采用不同反应，但变化必须由认知解释。
- 亲近意愿、履约预期、领域能力判断和伤害预期能够彼此分离。
- 冲突不会按日期自动发生，也不会因一次道歉自动结束。
- 事件条件被玩家破坏后，原事件不会强行出现。
- 记忆材料出现前，过去关系不进入任何行动优先级。
- 正常夜间不产生普通人物行动；违规必须留下可观察事实。
- 人物在压力下可以犯错，但不能无缘无故变成另一个人。
