# 双重本体世界引擎运作原理说明
## 文件阅览说明
本引擎的设计理念是本体论二元，也就是语义中的现实和物理中的现实共同组成现实。
基于此设计理念，我们开发了双重本体论世界引擎。

本文件通过将引擎运行机制拆分成通用机制、工程特化与项目核心组合，来降低阅读者和维护者的理解难度。

本引擎采用若干已有理论与工程方法，但实现以本项目的离散模拟需求为边界，不宣称与某个外部产品或学术模型一比一等价。下文只陈述当前 Core 中已有、可由源码和测试验证的能力。
## 通用机制的 Core 实现

### 基于行动值的回合制系统

Core 实现的是离散行动值时间线。`Timeline` 以绝对行动值与登记顺序作为优先级，按最小值推进并触发任务。
`CalculateBaseAv` 和 `CalculateActionAv` 提供 $\text{BaseAV} = \frac{10\,000}{\text{Speed}}$ 与动作倍率换算；`SimulationSession` 则直接按 `Intent.MotionCost` 记录身体的恢复时刻。速度换算是否用于某个具体行动，由游戏层在生成行动代价时决定。
拉条、推条、变速缩放、中断与行动序列预览由 `Timeline` 分别提供明确入口。

详细标准技术实现规范与数学模型参见独立文档：[标准行动值回合制系统规范](标准行动值回合制系统规范.md)。

### 场景树和连接拓扑

场景树（Scene Tree）与连接拓扑（Connection Topology）分别承担空间包含与通路图结构的职责。
场景树以父子层级维护实体包含关系与同级位置，不负责坐标变换；连接拓扑作为独立的带权图结构维护场景邻接关系与通路开销。
门禁实体作为对象存在于树中，拓扑边直接持有场景和门禁对象引用，并在寻路或迁移时查询门禁状态。Core 不计算房间内坐标、碰撞或实时空间变换。

详细标准技术实现规范参见独立文档：[标准场景树与拓扑连接规范](标准场景树与拓扑连接规范.md)。

### 智能体效用决策

智能体效用决策系统（Utility AI）基于微观经济学效用理论构建。
`UtilityMath` 提供需求衰减、归一化、线性/多项式/Logistic/分段响应曲线与带权乘法聚合。`UtilityArbiter` 提供优先级分桶及当前行动的切换奖惩。
这些函数是可组合的决策部件；Core 不会自动把每个 `Soul` 的所有动机转换为统一的 Utility AI 状态机。

详细标准技术实现规范参见独立文档：[标准智能体效用决策规范](标准智能体效用决策规范.md)。

### 基于 Dijkstra 的路线规划

Dijkstra 路线规划算法在非负权值的离散空间拓扑图上求解单源最短路径。
`TopologyGraph` 缓存邻接索引；`FindPath` 从传入通道集构造本次查询的邻接索引，并使用优先队列执行边松弛，支持到达目标节点时立即返回。
算法提供严格最优解保证，时间复杂度为 $O((|V| + |E|) \log |V|)$。

详细标准技术实现规范参见独立文档：[标准Dijkstra路线规划规范](标准Dijkstra路线规划规范.md)。

### AST文本编译器

AST 文本编译器将项目 DSL 编译为 `Rule`、`Expr`、`Directive` 和 `Effect` 对象。
当前管线包含词法分析、递归下降语法分析和符号解析；它会校验规则槽位和 `@实体` 引用，但不会依据每个操作符的签名执行完整的参数类型与数量检查。

详细标准技术实现规范参见独立文档：[标准AST文本编译器规范](标准AST文本编译器规范.md)。
### 智能对象与环境可承受性系统

智能对象体系（Smart Objects）基于生态心理学可承受性（Affordance）理论构建。
交互逻辑由环境对象通过 `Offer` 发布工厂或描述符；智能体通过 `Discover` 从游戏层提供的感知对象集合收集行动候选。
`InteractionSlotManager` 以可用、已预约、占用和释放流程提供逻辑槽位互斥。槽位不是房间内物理坐标，实际可见性与到达判断仍由游戏层负责。

详细标准技术实现规范参见独立文档：[标准智能对象与环境可承受性规范](标准智能对象与环境可承受性规范.md)。

### 两阶段事务与命令模式

Core 使用单进程的 Prepare/Commit 计划机制，不是分布式系统中的标准 Two-Phase Commit 协议。
准备阶段在 `StateView` 分支中校验并构造 `EffectPlan`，不修改真实实体；提交阶段先检查读取集是否过期，再一次性应用计划。`ActionRuntime` 在结算后创建可追溯的事件实体；事件保存在内存对象模型中，Core 本身不提供不可变存储或持久化。

详细标准技术实现规范参见独立文档：[标准两阶段事务与命令模式规范](标准两阶段事务与命令模式规范.md)。

### 言语行为与会话协商协议

言语行为体系借鉴言语行为理论和 FIPA ACL 的部分命名，将对话建模为离散动作。
`Performative` 包含 Inform、Propose、AcceptProposal、RejectProposal 等 FIPA 同名行为，也包含项目自定义的 Challenge、Testify、Retract 和 Declare；因此当前实现不是完整的 FIPA ACL 兼容层。多轮对话由质询查验与协商交换状态机表达，七类 `ResponseMode` 用于行动倾向标注。

详细标准技术实现规范参见独立文档：[标准言语行为与会话协议规范](标准言语行为与会话协议规范.md)。

### 空间门禁与容器收纳机制

空间门禁与容器收纳体系基于锁钥空间拓扑（Key-Lock Puzzle）与层级包含模型构建。
开合状态与锁记录共同表达开启、闭合未锁和闭合上锁三种有效组合；锁记录支持指定阻断场景方向的单向非对称锁定。容器收纳在重挂载前执行通达性、容量与无环检查。

详细标准技术实现规范参见独立文档：[标准空间门禁与容器收纳规范](标准空间门禁与容器收纳规范.md)。

### 状态效果与时效管理

状态效果体系（Status Effects / Buffs）管理施加于实体上的临时增益、减益与时效影响。
状态实体持有基础强度、生效时刻、过期时刻与线性衰减速率，当前有效强度依据闭式时效公式确定性求解；系统提供持续时间刷新、层数累加、独立多实例与最高值覆盖四种标准堆叠策略。

详细标准技术实现规范参见独立文档：[标准状态效果与时效管理规范](标准状态效果与时效管理规范.md)。

## 工程特化机制

### 产生式规则专家系统与双层分流裁决

规则系统基于 AST 条件求值和效果模式匹配产生裁决。
在主观心智层，已采信规则形成 `RulePressure` 并参与候选评分，智能体仍可选择不合规行动；在客观层，激活的 `RulePatch` 与契约 `HardConstraint` 会在执行前阻断不合法效果。

详细技术规范与特化架构参见独立文档：[特化产生式规则专家系统规范](特化产生式规则专家系统规范.md)。

### 认识逻辑与BDI信念流转流水线

本系统借鉴认识逻辑与 BDI 的概念，分别保存客观事实、主观观察、规则信念和行动承诺。
规则信念具有接收、理解、评估、采纳/拒绝阶段，只有已采纳规则参与规则压力计算。主观路线规划仅使用 `Soul.KnownPassages` 中明确获知的通道；通道知识目前不复用规则信念的阶段或置信度模型。

详细技术规范与特化架构参见独立文档：[特化认识逻辑与BDI信念流转规范](特化认识逻辑与BDI信念流转规范.md)。

### 情绪认知评价与非线性对数动力学

情绪系统保存按来源划分的离散情绪强度，并以对数公式聚合同类来源；它没有实现完整 OCC 评价变量与分类体系。
`CalculateDualTimescaleDecay` 和 `DecayEmotionsDualTimescale` 使用快、慢两项指数衰减；持久来源采用不同权重和衰减系数。

详细技术规范与特化架构参见独立文档：[特化对数情绪动力学规范](特化对数情绪动力学规范.md)。

### 实体语义切面与轻量内聚属性图

语义网（RDF）与属性图（Property Graph）通过结构化图关系描述实体概念与能力。
Core 不使用中央三元组库，而将语义关系附着为实体宿主持有的轻量 `Facet`。常用关系由 `FacetType` 枚举表达并直接保存对象引用，同时仍保留自定义字符串切面的兼容入口。

详细技术规范与特化架构参见独立文档：[特化实体切面与语义图规范](特化实体切面与语义图规范.md)。

### 源质空间配方与仪式因果契约

仪式系统把投入实体投影为十二项 `Aspect` 强度并按门槛校验配方。持久配方可生成跨行动周期保留的 `Covenant`，其义务违规会触发配方声明的 `Breach` 效果；惩戒内容由配方决定，并不固定为创伤。

详细技术规范与特化架构参见独立文档：[特化源质配方与仪式契约规范](特化源质配方与仪式契约规范.md)。

## 项目核心组合

以下内容描述本项目选定的组合方式。由于无法穷尽商业产品、论文与未公开实现，本文件不对“首次出现”或“商业实践中从未出现”作事实断言。

### 物理躯体与认知心智的非对称多对多解耦

Core 将肉体与心智拆解为独立实体：`Character` 承担场景归属与背包包含，`Soul` 保存观察、规则信念和决策步骤。二者通过双向 `Facet` 对象引用绑定，支持一个身体关联多个心智，也支持一个心智关联多个身体。

详细技术规范与架构设计参见独立文档：[独创躯体心智非对称解耦规范](独创躯体心智非对称解耦规范.md)。

### 五层动态聚合的无副作用实时源质投影

`GetAspectContributions` 在调用时从固有源质标签、材料与完整度、14 项物理性质、时效影响和定向语义关系五类来源汇总十二项源质。投影结果不写回实体，固有标签与各类输入状态仍正常持久保存。
当前仓库没有基准测试，因此不对纳秒级性能作保证。

详细技术规范与数学模型参见独立文档：[独创无副作用实时源质投影规范](独创无副作用实时源质投影规范.md)。

### 客观世界树与主观认识图的主客观二元拓扑隔离

客观 `TopologyGraph` 保存真实通道和门禁状态，`Soul.KnownPassages` 保存该心智明确获知的通道。`FindPathSubjective` 只在提供给它的主观通道集合上寻路，因此未知、遗漏或过时的通道知识可以产生与客观路线不同的结果。

详细技术规范与推演闭环参见独立文档：[独创主客观二元拓扑隔离规范](独创主客观二元拓扑隔离规范.md)。

### 仪式因果契约与违约惩戒反冲

持久仪式可建立具有生命周期的 `Covenant`。运行时在后续成功效果发生后检查 `Obligation`，违规时执行 `Breach` 效果；`HardConstraint` 则在效果发生前拦截。契约可由 `Revoke` 显式撤销，当前 Core 没有通用到期时刻，也不保证惩戒不可逆。

详细技术规范与生命周期参见独立文档：[独创仪式因果契约与违约惩戒规范](独创仪式因果契约与违约惩戒规范.md)。

### 规则系统的双层分流裁决机制

产生式 AST 规则在主观决策层把 Require/Forbid 等指令转换为 `RulePressure`，并与外部效用、偏好和承诺惯性共同计分。客观 `RulePatch` 与契约硬约束使用同一规则匹配能力执行硬阻断。两层规则来源与执行入口彼此分开。

详细技术规范与裁决流程参见独立文档：[独创双层分流规则裁决规范](独创双层分流规则裁决规范.md)。
