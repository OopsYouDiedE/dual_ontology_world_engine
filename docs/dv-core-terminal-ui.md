# DV Core 命令行界面与回放

## 内容层级

房间以纵向列表呈现。一级标题为房间名，二级标题为房间中的人物与物体；附属状态、行动成本及通道使用更低对比度。成员独占行，长标题自然换行，不合并为逗号串。房间、成员与通道都使用稳定身份，不以标题或排序关系推断连接。

界面只出现短标签、状态、正文、行动和评分，不添加说明段落、教程、来源句或图例。没有数据时使用短横。ANSI 与 SVG 共用生产渲染器，粗体、色彩、缩进和留白共同区分文字主次；纯文本模式保留结构。

## 主客观地图与人物

默认显示当前人物的主观地图。显式 map objective/both 打开只读全知预览；宽窗口并排主客观列表，窄窗口按组纵向显示。客观地图、主体认知地图和控制者身份分别保存。

主观地图只包含该人物实际认识的地点、人物和物体，不从另一栏补充未知事实。客观预览从真实权威状态与有效目录构造，显示完整已存在地图；不授予观察、不改变准入、不中断或重新运行规划。view ID 切换检阅人物；--viewer ID 指定启动会话的正式人物。检阅另一人物不暗中接管其控制。

候选标题只消费 DV 内容声明的 `label`，表示单一行动意图；检视结果和角色台词保留在成功 Complete 后的观察与事件正文。询问标签含本人已知的对象名；同屏仍重名时附最短可区分的 ID 后缀。已准备动作保留原选择标签，记录缺失时显示“（未记录标签）”。

候选评分来自 Core 的本人认知求值与已记录规划信息，并携带 `score_kind`。根节点、最终选择及即时评分分别标注；只有明确未评估的记录显示“未展开”，不能根据数值等于 -0.01 推断。候选顺序和稳定 ID 不因展示评分改变；原精确值、未知与未记录保持区别。当前分数不得回填旧帧。

人物显示名随角色目录和回放快照记录；主观成员只使用本人认识的姓名，未认识者保留“同伴”。回放时钟取已记录的当前帧游戏时刻，播放进度、播放/暂停与“帧内：聚焦/确认”等阶段分别显示。

## 操作与记录

人工、外部模型和引擎自主操作都通过同一正式动作链。界面层只维护聚焦选择，执行仍使用 Prepare → formal-model → Complete。

1. focus 聚焦对应选项，显示当时候选、评分和人物视角。
2. confirm 重核版本与资格，提交已聚焦行动；实际到期时使用 Complete。

act 是同一两步的便捷调用。next 将一次自主/NPC 行动拆为 Prepare 后聚焦和下一次确认；一次输入不排空未来调度。人工选择进入队列后若另一人物先到期，该次确认显示已排程；下一次 next 聚焦真实待执行行动。排队结果独立封存，后来的执行结果不倒并到此前确认帧。地图与人物切换、读取状态、截图不推进会话。

新记录保存交互 ID、阶段、选择值、源版本、当时选项与评分、角色投影和结果。展示记录不写入人物认识，不作为游戏事件资格。保存仍取正式稳定提交点；展示游标不构成可恢复状态。

## 只读回放

CLI 与其他宿主共用 SmartReplay。回放不创建 DvSession、不执行 Prepare/Complete、不运行 AI，也不将显示状态写回世界。不同输入来源消费同一 focus → confirm 帧合同，区别只保留在来源元数据。

每个可见帧按内容节拍停留，保留焦点调整与确认的先后。原现实等待不进入播放时钟；原始时刻与因果关联仍保留。播放器逐帧展示，慢渲染后的追赶不吞掉焦点帧。

旧记录按已有输入和正式行动结果构建展示步骤，未记录的候选、评分、地图或身体轨迹保持缺失。初始/最终检查点保留各自时刻，不以终态补齐前态。view ID 检阅该帧已记录人物，view follow 跟随行动者；restart 清空显示缓存。

## 入口与检查

--tui、--jsonl、普通文本使用相同状态和选择逻辑。--replay FILE 自动播放；--interactive 启动暂停的命令回放。状态、选项、地图和截图均可在回放中检阅。键盘空格暂停/继续，右方向键单步，1/2/4/8 调速，Tab 切地图，Q/Esc 退出。

--preview 在会话创建前返回，显示明确的短预览标签；示例不作为正式行为证据。capture 导出当前真实显示；SVG/PNG 与操作系统终端截图分别标明来源。TUI 首页显示选中项附近最多五个行动，并保留可见编号范围；长标签缩略时保留区分后缀，完整行动列表放在地图后供翻页检阅。主客观地图均先显示当前房间。标题与状态固定，page N/next/prev 检阅全部内容；聚焦和确认回到首页行动窗口。相同费用在行动标题集中显示，不同费用逐项列出，缺失费用保持明确，零值项省略。评分固定在首行，完整标签续行对齐编号之后。zoom 仅调整行距密度。

复用工具在 mcp/verification；capture_cli 默认 90 秒硬超时，只结束本次子进程树，保留超时和 .partial。工程构建、正式有限操作、记录回放和实际界面分别检查，结果放本轮 artifacts 子目录。具体命令和状态见 dv_core/cli/README.md。
