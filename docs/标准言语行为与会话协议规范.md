# 标准言语行为与会话协议技术规范

## 1. 概述与理论溯源

智能体间的高级社会交互与对话建模，建立在语言哲学与多智能体系统（MAS）的理论交集之上：
* **言语行为理论（Speech Act Theory）**：由约翰·奥斯汀（J. L. Austin, 1962）创立、约翰·塞尔（John Searle, 1969）系统化完善。其核心论点是“言即是行”（To say something is to do something），语言不仅传递信息，本身就是一种施加意图、改变社会因果关系的离散行动。
* **智能体通信语言标准（FIPA-ACL）**：由国际智能实体基金会（FIPA, 2002）标准化制定，采用形式逻辑精确规范智能体间消息原语（Performatives）的语义先验与后效。

## 2. 言语动作原语体系（Performatives）

系统将智能体发出的言论结构化为具体的施事动作（Communicative Acts），主要分为四大类：

### 2.1 断言类（Assertives）
* **告知事实（Inform / StateClaim）**：发言主体就外部世界的某一命题进行声称，表达自身持有该信念，并使听者获知该命题。
* **提供证言（Testify / Evidence）**：发言主体出示特定物证或观测事实，为某一命题提供客观置信度支撑。

### 2.2 指令类（Directives）
* **询问（Query / Ask）**：发言主体要求目标对象提供关于某实体或状态的已知信息。
* **质询（Challenge）**：发言主体对前置某一断言提出合理怀疑，要求原断言者出示进一步证据，否则该断言将被暂时挂起。

### 2.3 承诺类（Commissives）
* **提议协商（Propose / Offer）**：发言主体提出一项带有互惠条件的行动建议，承诺若对方履行指定动作，自身将支付对应对价。
* **承诺接受（AcceptProposal）与拒绝（RejectProposal）**：对协商提议做出确定的承诺或否决。

### 2.4 宣告与撤回类（Declarations & Retractions）
* **撤回主张（Retract）**：发言主体宣布废弃自己此前声明过的某一断言或指控，消除该言论对自己及他人的持续社会影响力。
* **宣告（Declare）**：具备特定法定权威的主体即时改变世界语义状态（如宣布休会、宣布结界封锁）。

## 3. 会话交互协议状态机（Interaction Protocols）

单次言语行为通常嵌入于结构化的社会交互协议之中：

### 3.1 质询-查验协议（Challenge-Verification Protocol）
1. 主体 A 发出断言：$\text{Inform}(P)$。
2. 主体 B 产生异议，发起质询：$\text{Challenge}(P)$。
3. 主体 A 面临分支抉择：
   * **举证回应**：发出 $\text{Testify}(P, \text{Evidence})$，若证据确凿，质询解除；
   * **坚持主张**：拒绝提供证据，承担信用下降风险；
   * **撤回言论**：发出 $\text{Retract}(P)$，终止争议。

### 3.2 协商交换协议（Negotiation Protocol）
1. 发起者发送 $\text{Propose}(\text{Action}_A, \text{Condition}_B)$。
2. 接收者通过效用系统评估该提议对自身利益的净收益。
3. 接收者回复 $\text{AcceptProposal}$（形成因果契约）或 $\text{RejectProposal}$（会话关闭），或发起 $\text{CounterPropose}$ 反向提议。

## 4. 社交应对模式（Response Modes）

智能体在接收言语互动事件时，根据自身人格特征与当前态度，采取标准化的七类应对模式：
* **核验模式（Verify）**：优先选择质询与实证查证动作。
* **协商模式（Negotiate）**：优先选择交换条件、平衡利益的沟通动作。
* **协作模式（Cooperate）**：积极响应对方请求，主动提供已知信息。
* **压制模式（Restrain）**：通过物理阻断、限制行动或强制打断对抗恶意言行。
* **庇护模式（Protect）**：遮蔽弱势主体，分担或阻挡不利言论后果。
* **回避模式（Avoid）**：拉开距离、拒绝应答，消极退出交互。
* **隐匿模式（Conceal）**：模糊信息、掩盖证据，维持关键状态的保密。

## 5. 消息结构与语义载荷规范

一条标准言语行为消息必须封装为不可变记录对象：
* **会话标识（Conversation ID）**：标识当前多轮对话的上下文线索。
* **发言主体（Sender）** 与 **接收主体（Receiver）**：直接持有智能体实体引用。
* **施事原语（Performative）**：声明该动作的类型。
* **命题载荷（Content）**：所论述的纯数据事实或表达式 AST。
* **时空锚点（Context）**：记录发生该言行的场景实体与绝对行动时刻。
