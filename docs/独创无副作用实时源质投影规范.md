# 独创无副作用实时源质投影规范

## 商业领域现有技术局限

商业游戏中的属性与元素机制（如《原神》元素附着系统、《密教模拟器》卡牌 Aspect、《炼金工房》材料炼金成分）均采用 显式静态写入模式。物体的属性以离散标签、静态字段或持久化哈希表形式直接依附在数据行或内存对象中。这种模式导致属性表达僵化，难以表达同一把小刀在用于切面包与用于刺杀仇人时展现出截然不同象征力量的动态语境。

---

## 本系统独创设计

本系统构建了完全纯函数式、纳秒级瞬时计算的五层动态源质投影机制（Aspect Dynamic Projection）。世界中的实体表面不直接持久化存储抽象的源质数值，而是在单次交互或仪式判定的瞬间无副作用动态计算。

### 五层聚合流水线

给定求值实体与当前交互目标，系统聚合五层异构来源的贡献（AspectContribution）：

1. 固有属性层（Intrinsic）：
   实体自身携带的象征标签（如纯粹的形式 Form、法则 Law 标记），提供基础常数贡献。
2. 材料构成层（Material）：
   实体追溯其底层构成原料，根据当前物体的物理完整度（Integrity）比例继承原料所蕴含的源质力量。
3. 客观物性层（Physical Properties）：
   实体持有的 14 项连续物理性质（硬度、耐久度、锋利度、通透性、反应性、生命力、致死性、辨识度、权威度、认知度、亲和力、动机、冲突性、古老度），依据静态投影规则矩阵映射至对应的源质类型并按固定乘除比例换算。
4. 动态影响层（Dynamic Influences）：
   实体表面附着的时间衰减情绪状态，其当前有效强度经时间积分计算后投影为主次源质。
5. 定向语义关系层（Target-Specific Relations）：
   仅当实体与交互目标存在特定既成事实关系（所有者 Owner、见证者 Witness、描绘 Depicts、造成伤害 Harmed、真名关联 TrueName 等）时，按关系类型与强度定向激发出对应的源质。

### 纯函数化执行保障

源质投影算法由纯函数 AspectSystem.Project 驱动，计算过程不修改实体的任何运行时状态，不分配托管堆垃圾，确保高频决策下的确定性与纳秒级性能。
