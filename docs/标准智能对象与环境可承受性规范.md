# 标准智能对象与环境可承受性技术规范

## 1. 概述与理论溯源

智能对象（Smart Objects）体系是游戏人工智能中去中心化决策的核心架构。该体系源自认知心理学家詹姆斯·吉布森（J. J. Gibson, 1979）提出的“生态心理学可承受性”（Ecological Affordance）理论，由威尔·赖特（Will Wright）在《模拟人生》（*The Sims*, 2000）中首次工程化实现。
其核心思想是将交互逻辑与世界知识从智能体内部剥离，分布至环境实体之中。智能体通过与环境对象协商获取可执行动作，实现高度解耦的模块化行为扩展。

## 2. 分布式智能架构模型

### 2.1 职责划分

* **环境对象（Smart Object）**：承担交互能力的提供者（Provider）。对象自身持有并对外发布其所允许的全部交互形态、执行门槛、物理占用槽位以及对主体需求的满足数值。
* **智能体（Agent）**：承担交互能力的使用者（Consumer）。智能体持有内在动机（Motives）与生理/心理状态数值，通过传感器扫描可见环境实体，收集其发布的可用能力，并交由决策器权衡选择。

### 2.2 解耦优势

系统新增道具、设施或环境机制时，无需修改智能体决策核心或角色状态机。新对象只要遵从标准发布协议，即可自动被全体现有智能体认知并接入交互循环。

## 3. 可承受性发布与发现协议

### 3.1 交互描述符（Affordance Descriptor）

环境对象对外发布的每一项可承受性能力包含以下独立元数据：
* **动作标识（Action Identifier）**：指示该交互在通用动作原语中的语义类型（如使用、坐下、开合、进食）。
* **物理槽位（Interaction Slot）**：智能体执行该交互时在空间上的相对位置与朝向要求。
* **前置条件谓词（Prerequisite Predicate）**：针对行动主体状态、持有物及环境上下文的无副作用校验函数。
* **代价规格（Cost Specification）**：执行该交互预计消耗的行动值、体力或其他资源。
* **效益分布（Payoff Profile）**：该交互对主体各项内在需求动机（如饥饿、疲劳、娱乐）的预期变更增量。

### 3.2 感知与收集循环（Discovery Cycle）

1. **环境扫描**：智能体在决策阶段，通过空间视界与感知范围检索环境实体集合。
2. **能力收集**：对每一个检索到的实体，提取其当前公开的可承受性描述符。
3. **前置过滤**：智能体依据自身当前状态就地核验前置条件谓词，排除不合规动作。
4. **效用输入**：将过滤后合规的交互效益分布送入智能体决策器进行打分排序。

## 4. 槽位并发与互斥预约系统（Slots & Reservation）

### 4.1 物理交互槽位管理

大型设施（如长椅、工作台、餐桌）可容纳多个智能体并发交互：
* 每个交互槽位（Slot）具备独立的空间坐标偏移与容量限制。
* 设施整体持有最大并发上限与当前已占用槽位列表。

### 4.2 状态流转与互斥锁

为防止多个智能体在行进途中争抢同一不可共享的对象，系统采用三阶段预约状态机：
1. **可用状态（Available）**：槽位空闲，允许外部检索与打分。
2. **已预约状态（Reserved）**：智能体选定该对象作为当前目标后，向对象发起预约。预约成功后该槽位对其他智能体暂时隐匿，防止产生决策冲突。
3. **占用执行状态（Occupied）**：智能体到达物理槽位，开始结算持续动作与动机消耗。
4. **释放注销（Released）**：动作完成或因意外被中断时，主动释放槽位与预约标记，回归可用状态。

## 5. 异常处理与边界安全

* **预约超时回收**：若已预约的智能体在规定时间内未能到达指定槽位（如中途遭遇门禁阻断或死亡），对象必须自动超时清除预约，避免出现永久死锁。
* **状态失效校验**：智能体在行进结束、即将开始执行动作的瞬间，必须进行二次合法性重验。若对象在行进期间被损毁、移走或被更高优先级事件占用，当前动作安全终止并回退。
