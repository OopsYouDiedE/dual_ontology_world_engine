# 地图、物品与时间光照

E 美术库继续通过 `Content/presentation.dv` 的布局记录程序化构建不同场景，并通过 `PrefabLibrary` 复用物体场景；但是这些三维资源与正式剧情宿主的二维运行路径分别验收。

`rendering/WorldTimeLighting.gd` 消费游戏分钟数，按照 DV 的 `layout daylight` 插值太阳角度、颜色、能量、环境光和背景色，室内使用 DV 提供的系数；但是渲染器不推进游戏时间、不修改天气事实，也不根据电脑时钟重置会话。

美术库公开 `set_world_time(minutes, outdoors)` 和 `apply_world_snapshot(snapshot)`，后者读取正式观察中的 `game_time`，切换地图后保留输入时间；但是正式宿主仍需在三维视图迁移时调用此接口，接口存在不等于迁移完成。

美术库左上角提供分钟输入和三小时间隔的时间选择器，导出器会把时间光照节点随地图保存；但是旧导出的地图需要重新生成才包含新节点，单场景画面不能证明正式游戏通关。

`layout prop_physics` 在 DV 中列出具有家具实体碰撞的类型，未列出的物体保持装饰分类；但是点位仅提供前后站位与接触目标，站位可达性、占用和行为授权仍由正式宿主与 Core 校验。

`PrefabLibrary` 对新建和旧版导出资源统一应用分类，家具生成网格表面碰撞，小物件和装饰清除旧版 `Solid`，点位与碰撞坐标均相对预制件根节点计算；但是嵌套家具保留自己的碰撞，外层不再重复生成同一份碰撞。

`RoomGrid`、四翼房间、公共厅和录音舞台均添加地板与墙体碰撞，公共厅的平台和台阶按几何尺寸生成，视觉剖切墙保留完整高度的实体边界；但是门洞下方保持净空，室内通行与人物动作仍须在正式三维宿主迁移后实测。

室外地面具有地板碰撞，室外建筑主体具有墙体碰撞，树木等装饰保持非实体；但是早期封闭建筑与新建实际开洞的建筑仍按资源分别记录，室内门禁与通行始终须由正式宿主校验。

本轮作者导出生成 121 个预制件与 81 个地图场景，真实 Godot MCP 单场景检查覆盖乙区总览、公共厅总览、室外 12:00 与 00:00 切换及导出公共厅，回执保存在 `.runtime/runs/map-art-review/`；但是该检查未执行三维人物穿行、坐起或接触动作，室外仍含标记为 `retained-raster` 的既有资源，因此不作为完整三维换代验收。

2026-10-26 的正式 `GodotMCP` 引擎 AI 新局测试运行 60 秒，回执为 `.runtime/runs/godot-e9fb9c113020e44dd9380dc5/report.json`，截止时位于第一章乙区活动厅、游戏时间 8:49，`faulted=false` 且 `host_errors=[]`；但是状态为 `deadline_reached`，这份回执只覆盖正式宿主实际路径，不证明三维人物碰撞或剧情通关。

室外继续采用俯视构图，`Content/outdoor_art.dv` 为 `campus_nw` 提供精细化区段的镜头、铺装、园艺布置和高程参数，通用构造分别由 `OutdoorFinish`、`ExteriorArchitecture` 与 `ExteriorLandscape` 实现；但是本轮先覆盖共鸣厅门前的可检查区段，其他室外地图仍沿用原资源，不能称为全岛更新完成。

建筑锚点来自既有 DV，新的墙体具有厚度与门窗洞，窗框、窗台、落水管和台阶按米制构造，重复建筑和园艺物体复用预制件；但是可视门扇与候选交互标记不改变门禁，未迁移的旧位图物件记录在场景 `deferred_legacy_visuals` 元数据中，当前不把它们算作三维成果。

室内地面保持平整，室外通过 DV 网格高程和局部地形参数生成缓坡，建筑周围保留平整衔接，地板三角面碰撞、草根、铺石和路缘共享高度采样；但是这里的高程是局部景观整地方案，不是已核验的科尔沃岛测绘高程。

实机证据保存在 `.runtime/runs/exterior-detail-review/observations.json` 与同目录原始 PNG，覆盖俯视总览、地面近景、午夜灯光和重新加载的导出场景，均通过真实 Godot MCP 返回；但是它们是 AI 单场景美术检查，尚未验证正式人物在新三维地形上的穿行、坐起和门口动作。

本轮正式 `GodotMCP` 引擎 AI 新局回归运行 60 秒，回执为 `.runtime/runs/godot-0b1ea3eb873b7e294d57444a/report.json`，截止时为第一章乙区活动厅、游戏时间 8:53，`faulted=false` 且 `host_errors=[]`；但是结果为 `deadline_reached`，不属于剧情通关或新三维地形通行验收。

2026-10-27 起室内外采用相同的表面层次与观察尺度适配规则，木材、石材、涂层、织物、室内铺装与室外抹灰／石板共享米制细节基准，远景允许低对比细节适度放大，静态曲面模型按投影大小降低细分；但是各材质结构尺寸和独特图案分别保留，正式人物及三维通行仍需独立验收。

真实 Godot Compatibility 检查覆盖公共厅与室外入口的 12／24 米横向跨度、乙区 6 米近景及两张重新加载的导出场景，回执与原始 PNG 位于 `.runtime/runs/density-review-2026-10-27/`，均未报告脚本错误；但是这些是 AI 单场景美术检查，连续缩放、移动闪烁和全部区域不在本轮视觉验收范围。

实机 UI 记录公共厅 12 米时中档 29／低档 715、24 米时中档 27／低档 717，室外入口对应为中档 90／低档 2467 与中档 0／低档 2557，乙区 6 米近景记录高档 21／中档 64／低档 660；但是该数量只描述受控静态曲面，不表示全场景模型数量或帧率。

本轮作者导出成功保存共享预制件与地图，室内外代表场景也通过真实 Godot 重新加载检查；但是完整无界面导出进程退出时仍报告 dummy renderer 资源未释放告警，日志保存在 `.runtime/density-lod-export.log`，不把返回码 0 表述为导出全程零告警。

按 2026-10-27 的最新制作顺序，室内地毯、长毯与桌旗暂用素色织物，保留表面质感、尺寸和摆放，公共厅与四翼共用入口均已改用素色材质；但是花纹设计延后至其他部分处理好后开展，现阶段不恢复原位图花纹或程序化装饰纹样。

素色版本已重新导出，并通过真实 Godot MCP 加载公共厅与乙区总览检查，回执和原始 PNG 保存在 `.runtime/runs/plain-textiles-2026-10-27/`，两次观察均为 `host_errors=[]`；但是该证据只覆盖这两张三维场景的显示效果，不属于剧情或物理验收。
