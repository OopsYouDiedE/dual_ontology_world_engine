# 游戏与文学机制调研与设计依据

## 1. 文学机制迁移结论

### 1.1 《咒术回战》：规则交换与局部环境
- **束缚（Binding Vow）**：束缚是主体自愿施加限制换取特定效果的规则补丁（`RulePatch + Obligation`）。信息公开与风险暴露本身可作为合法支付代价。多人契约监听违约并在违约时结算后果。
- **领域（Domain）**：领域是具有空间范围、目标识别与局部规则注入的独立环境。重叠时支持覆盖、抵消与竞争。
- **自动反应（Simple Domain）**：自动反击与防御机制依然作为标准 `Intent` 进入统一行动模型，遵循命中与速度核验，不构成系统级特权。

### 1.2 《诡秘之主》：语义寻址、仪式与污染
- **尊名与语义寻址**：尊名是指向高位实体的多段称谓。寻址为语义约束匹配，含糊表述引发多目标歧义、误指、无响应或污染反噬。
- **异步仪式**：仪式是包含寻址、诉求、材料与授权的异步请求协议。简化仪式基于既有关系与授权模板，不修改底层规则。
- **精神污染**：污染携带来源、位格与烙印，渐进式侵蚀认知结构、记忆权重与偏好，而非单纯扣减理智数值。

### 1.3 《魔法少女小圆》：主体拆分与守恒净化
- **多维主体结构**：契约可将主体拆分为身份主体、意识来源、灵魂载体（Soul Gem）与身体执行器，伤害与死亡判定必须明确目标层级。
- **因果预算**：现实改写的规模受主体因果预算约束；超出预算将导致偏差、不完整或重大代价。
- **污染守恒**：净化是污染从主体向外部载体（Grief Seed）的转移过程，污染在全局世界中不凭空湮灭。

## 2. 游戏机制迁移结论

### 2.1 规则怪谈与未知异常（SCP 体系）
- **三层解耦**：客观异常机制、可能真假的信息记录（`Record`）与主体的理解信念（`Belief`）严格分离。主体可依照错误记录行动，客观异常依固有规则结算。
- **异常相位**：异常按固定步长在单行动结束后的异常相位统一推进，避免全局低效轮询。

### 2.2 规则编译与持续契约（Baba Is You / 跑团与桌游）
- **AST 编译**：规则文本经受控语法解析为 AST，普通规则影响 Soul 决策权重，仅言灵与客观机制可注册为 `RulePatch`。
- **持续契约（Covenant）**：契约作为独立 Entity 记录参与方、承诺、例外与违约惩罚。`ObligationListener` 在意图提交时核验，于行动后结算违约。

### 2.3 全局回合与仪式推进（Dominions / 密教模拟器）
- **单时间线调度**：所有主体与计划事件共用行动值时间线。到期时基于当前最新状态重新核验。
- **局部 Aspect 汇总**：借鉴《密教模拟器》的槽位与 Aspect 门槛机制，仅对明确投入槽位的合法对象进行原理求和，剔除其实时倒计时。

## 3. 群像职能与封闭舞台设计（《枪弹辩驳》体系）

### 3.1 人物职能生态
- **职业能力**：主职业提供高难度专属行动，副专业制造可交流、可质疑的知识重合。
- **主角位置**：侦探主角负责发现问题、请求专业行动并整合证据，不替代其他职业鉴定。
- **角色分工**：
  - **低信息调查视角**：主角推进调查，不预先掌握医学、机械、艺术或神秘学答案。
  - **分析协助**：稳定提供线索与推演，分担信息处理压力。
  - **价值扰乱者**：基于自洽且极端的价值体系行动，主动制造局势变数。
  - **社会黏合与后勤**：纪律、照护与技术保障群体维系与现实改变。

### 3.2 设施与空间演进
- **七类设施职能**：公共规则物、生存物资、专业设备、记录物、门禁枢纽、私人物品与治理权力物。
- **动态依赖**：区域开放改变资源类型、信息透明度、权限分布与人物相互依赖，推动博弈阶段演进。
