# 文学机制调研：爱好者百科第一轮

> 调研对象：`turn-and-reaction-model-zh.md` 中明确点名的《咒术回战》《诡秘之主》《魔法少女小圆》和《JOJO的奇妙冒险》。  
> 调研日期：2026-08-27。

本文使用爱好者百科替代对原作的大段摘录。百科仍然是二手材料：有明确章节、卷次或动画集数脚注的内容可以作为建模依据；缺少脚注的稳定归纳只能形成设计假设；角色状态表和社区讨论只用于发现关键词。Fanon Wiki、同人角色页和论坛猜测不进入事实层。

为了避免把百科编辑者的解释误写成原作规则，下文始终区分三件事：百科实际记载了什么，可以从中抽象出什么机制，以及这种机制对引擎意味着什么。

## 1. 《咒术回战》

本轮主要使用 [Jujutsu Kaisen Wiki](https://jujutsu-kaisen.fandom.com/wiki/Jujutsu_Kaisen_Wiki)。该百科的专题划分较细，许多条目带有漫画章节、卷次或动画集数脚注，适合研究束缚、领域、结界和自动反应。

### 1.1 束缚是规则交换

[Binding Vow](https://jujutsu-kaisen.fandom.com/wiki/Binding_Vow) 将束缚分为对自身的束缚和多人之间的契约。施加限制可以换取力量或特定效果。对自身的束缚被打破时，通常失去由束缚获得的收益；多人契约的违约后果则更不确定。

“公开术式”是很有代表性的例子。公开信息会增加自身风险，风险本身因此成为可以交换的代价。束缚也能改变结界参数，例如排除特定对象，或者用暴露结界源头换取更高耐久。

这说明束缚不能被简化为扣除资源。它更接近一项对规则的补丁，同时附带持续义务：

```text
声明约束
→ 核验声明者能否约束相关对象
→ 评估限制、风险和不可逆性
→ 生成对应增益或规则改写
→ 监听违约事件
→ 在违约时结算后果
```

引擎可以将其表达为 `RulePatch + Obligation`。一项束缚至少需要记录参与者、受限变量、受益变量、生效区间、撤销方式和违约后果。多人契约还需要允许后果暂时未知，等到违约发生时再求值。

信息状态也必须能被规则系统引用。如果公开能力原理可以成为代价，那么“谁知道什么”就不只是叙事记录，而是客观结算条件。

### 1.2 领域是局部规则环境

[Domain Expansion](https://jujutsu-kaisen.fandom.com/wiki/Domain_Expansion) 将领域描述为结界、内在领域与术式的组合。完整领域会把术式嵌入结界，并获得必中效果。旧式非致死领域主要强迫范围内的目标遵守术式规则，并不一定直接造成伤害。

领域展开需要手势或信号，也需要大量咒力。领域结束后，术式通常会暂时不稳定。两个领域重叠时，必中效果可能相互抵消，领域的精炼程度会影响冲突结果。三方同时展开甚至可能因为冲突因素过多而全部构筑失败。

[Barrier](https://jujutsu-kaisen.fandom.com/wiki/Barrier) 补充了结界的内部强度、外部强度、体积、构筑速度和目标识别等参数。一般领域从内部难以突破，外壳却可能被外部盟友击穿。这意味着“在作用域内生效”远远不足以描述领域。

更适合引擎的过程是：

```text
核验手势、能量和构筑时间
→ 创建空间作用域
→ 注册目标识别规则
→ 注入局部规则
→ 解决与其他作用域的重叠冲突
→ 领域结束
→ 施加术式熔断或冷却
```

“必中”应当覆盖命中判定规则，而不是直接产生伤害。这样，反领域技术可以取消必中属性，却不必抹除攻击本身。

作用域冲突至少需要支持覆盖、抵消、竞争和共同崩溃。多个领域同时展开时，它们应基于同一个初始世界版本求值，避免先提交者获得不合理优势。

### 1.3 自动反应仍然是普通行动

[Simple Domain](https://jujutsu-kaisen.fandom.com/wiki/Simple_Domain) 记载，简易领域可以写入条件和程序。新阴流能够自动拦截进入范围的对象。三轮霞的版本以双脚不离开原位为束缚，对进入约 2.21 米范围的目标自动拔刀。

这种自动反击仍可能被速度足够快的目标避开。因此，“自动”只表示系统在触发后生成反应，不表示反应必然成功：

```text
范围进入事件
→ 匹配预设反应
→ 生成反击意图
→ 核验姿态、速度、资源和目标状态
→ 正常解决命中与效果
```

这一结构可以直接用于异常反应子回合。QTE、NPC 预设反应和术式自动防御都只是意图的不同来源，不能绕过统一行动模型。

[Domain Amplification](https://jujutsu-kaisen.fandom.com/wiki/Domain_Amplification) 还展示了能力通道互斥：使用者以空的领域承接并中和接触到的术式，但通常不能同时发动自身的生得术式。这种限制不是资源不足，而是两种能力不能占用同一通道，应在能力模型中显式表达。

## 2. 《诡秘之主》

本轮主要使用 [Lord of the Mysteries Wiki](https://lordofthemysteries.fandom.com/wiki/Lord_of_Mysteries_Wiki)。该百科也收录《宿命之环》的信息，因此引用时必须核对条目所依据的作品和章节，不能把续作补充自动当成《诡秘之主》正文已经确立的规则。

### 2.1 尊名是带风险的语义地址

[Honorific Name](https://lordofthemysteries.fandom.com/wiki/Honorific_Name) 将尊名描述为指向高位存在的多段称谓。它可以用于祈祷、联络和仪式借力。序列 3 可以在一定范围内回应祈祷，序列 2 及以上通常可以在全球范围回应。

尊名的危险在于，它并不只是姓名。含糊的称谓可能同时指向多个共享权柄的存在；过于准确的称谓又可能直接引来不希望接触的目标。仅仅知晓某些高位存在的尊名，也可能造成污染。

因此，言灵寻址应当是语义约束匹配：

```text
解析称谓中的象征、权柄、身份和范围
→ 生成候选目标
→ 根据唯一性、距离、位格和屏蔽规则消歧
→ 建立联系，或产生误指、无响应、反噬和污染
```

查询结果可以为空、唯一或包含多个候选。多目标不是普通解析错误，而是一种需要进入结算的危险状态。目标拥有回应权限和响应范围，被准确寻址也不意味着必须满足请求。

危险知识还说明“形成理解”本身能够触发世界效果。认知系统在主体获得新信息时，需要区分听见、记住、理解和相信；不同规则可能监听不同阶段。

### 2.2 仪式是异步请求协议

[Ritualistic Magic](https://lordofthemysteries.fandom.com/wiki/Ritualistic_Magic) 将标准仪式咒文拆成祈求对象、请求恩典、具体诉求和象征材料增幅。仪式还常包含净化、祭坛、蜡烛和灵性之墙等准备。

[Tarot Club/Rituals](https://lordofthemysteries.fandom.com/wiki/Tarot_Club/Rituals) 显示，同一个目标可以允许特定人员采用简化仪式。简化成立的原因是目标授权或双方已经建立关系，而不是基础步骤从来没有作用。

仪式适合表达为包含寻址信息、请求内容、材料、环境和授权证明的请求对象。不同步骤承担的功能也要分开：有些是硬性前置条件，有些帮助寻址，有些提高成功率，还有些只负责隔离副作用。

被祈求者的响应不宜在发起仪式的同一动作里直接写死。仪式先建立通道并发出请求，目标是否响应、何时响应和如何响应，应作为目标主体的新意图进入后续因果批次。

简化仪式则应作为有限范围内的授权模板，而不是修改全世界的基础仪式规则。

### 2.3 污染会改变身份

[Beyonder Characteristics](https://lordofthemysteries.fandom.com/wiki/Beyonder_Characteristics) 记载，非凡特性可能携带历任持有者的精神烙印，也可能受到更高位存在的污染。烙印强度与原持有者的位阶、死亡时间、容纳时长和死亡时精神状态有关。

容纳带有烙印的特性可能导致身份解离。影响并非一次性伤害，而会逐渐改变主体的精神结构。净化也不是统一的“移除负面状态”：粉碎重组、净化和偷盗等方法各有适用范围，并且受到双方位格影响。

因此，污染需要记录来源、载体、传播方式、位格、强度、潜伏状态和身份影响。它可以改变记忆权重、偏好、人格边界和决策输入，而不只是降低生命或理智数值。

[Beyonders](https://lordofthemysteries.fandom.com/wiki/Beyonders) 对晋升、扮演法和仪式的描述也说明，风险通常是连续变化的。仪式可能降低失控概率，却不一定是决定“允许或禁止晋升”的布尔开关。

[Anchor](https://lordofthemysteries.fandom.com/wiki/Anchor) 则说明，锚在帮助高位者维持稳定的同时，也会以群体认知反向塑造目标。引擎可以把锚视为施加在身份分布上的外部约束：它降低身份崩溃的概率，但可能把主体推向信徒共同相信的形象。

## 3. 《魔法少女小圆》

本轮主要使用 [Puella Magi Wiki](https://wiki.puella-magi.net/) 和 [The Puella Magi Wiki](https://madoka.fandom.com/wiki/Puella_Magi_Wiki)。前者对动画集数、制作资料和系列衍生内容的索引更细，后者适合快速查找灵魂宝石、悲叹之种等专题。引用时需要区分电视动画、剧场版、《魔法纪录》、漫画和游戏；衍生作品可以补充案例，却不能自动证明电视动画已经确立同一条通则。

### 3.1 契约同时创建能力、义务与新身体结构

丘比提供的契约表面上很简单：实现一个愿望，少女则成为魔法少女并承担与魔女战斗的任务。但契约的实际效果还包括把签约者的灵魂从身体中抽出，封装进灵魂宝石。[Soul Gem](https://madoka.fandom.com/wiki/Soul_Gem) 记载，灵魂宝石既是灵魂载体，也是变身、施法、武器召唤和魔力感知的中心；它离身体过远时，身体会立即失去活动能力，宝石被破坏则意味着主体真正死亡。

由此可见，契约不是给既有角色附加一个职业，而是重构主体：

```text
签约前
主体、灵魂、意识、身体、生命条件基本重合

签约后
主体身份 → 仍指向原来的少女
灵魂载体 → 灵魂宝石
身体 → 可由灵魂远程驱动并用魔力修复的执行器
能力核心 → 灵魂宝石
死亡条件 → 灵魂宝石遭到不可恢复的破坏
```

引擎不能继续假定角色、身体和灵魂是一条不可拆分的记录。至少需要区分主体身份、意识来源、灵魂载体、身体执行器、感知节点和死亡判据。伤害效果也必须声明攻击的是身体、灵魂载体，还是二者之间的控制联系。

这个契约还暴露了“有效但不知情”的问题。丘比能够缔结客观有效的契约，却没有主动披露灵魂外置和最终魔女化等关键事实。因此，契约需要分别记录形式是否成立、各方是否有缔约权限、披露了哪些事实、主体理解了什么、欺骗是否影响效力，以及规则是否允许撤销。客观有效性与伦理正当性不能合并为一个布尔值。

### 3.2 愿望是受因果预算限制的现实改写

[Magic](https://wiki.puella-magi.net/Potential) 对系列案例的整理显示，魔法少女的个人能力通常由愿望的文字、意图或背景衍生。与时间重来有关的愿望产生时间操作能力；治疗他人的愿望可能产生治疗能力。衍生作品也说明，这种映射不总是字面对应，因此不能用固定关键词表直接生成能力。

愿望的规模受到“因果潜力”限制。[Glossary](https://wiki.puella-magi.net/Glossary) 将其概括为一个人成为多少命运联系焦点的程度。晓美焰重复回到过去，并不断把多条时间线的目标集中在鹿目圆身上，使圆积累了异常庞大的因果潜力。愿望于是不能只检查施愿者想要什么，还要核验其是否拥有承担该现实改写的因果预算。

```text
自然语言愿望
→ 解析字面内容、真实意图和背景对象
→ 估算被改写的对象、时间范围与因果影响
→ 核验签约者的因果潜力
→ 生成现实改写
→ 依据愿望形成个人能力与长期命运联系
```

这里的“预算不足”不必只有拒绝一种结果。衍生案例显示，超出潜力的愿望可能以高昂代价、不完整结果或偏离原意的形式实现。为了不把推测写成通则，引擎应让具体世界规则决定失败策略，而不是把某一种处理写死。

愿望形成的能力还可能受到主体后来如何看待愿望的影响。[Magic](https://wiki.puella-magi.net/Potential) 收录了主体因潜意识拒绝自己的愿望而失去相关能力的案例。这说明能力授权不仅来自过去发生过的契约，也可能持续依赖主体与该愿望之间的身份一致性。

### 3.3 污浊把资源消耗和精神崩溃汇入同一载体

灵魂宝石会因使用魔法而逐渐污浊。身体遭受重伤时，维持和修复身体也会增加魔力负担。绝望则能直接推动灵魂宝石向完全污染发展。

这三条路径最后进入同一个载体，但不应被误写成完全相同的数值来源。施法消耗可以直接计算；身体修复取决于伤势和能力；精神事件则必须经过主体的认知、价值观和既有创伤解释。同一个失败事件对不同角色未必造成同等污浊。

```text
外部事件
→ 主体感知
→ 主体解释事件对愿望、关系和自我的意义
→ 形成情绪与信念变化
→ 判断是否动摇维持主体的希望或身份
→ 必要时生成灵魂污浊
```

因此，精神伤害不应作为事件自带的固定伤害类型。事件只提供事实和刺激，污染量来自主体对事件的解释结果。

### 3.4 净化是转移，不是删除

魔女死亡后可能留下[悲叹之种](https://madoka.fandom.com/wiki/Grief_Seed)。它可以吸收灵魂宝石中的污浊，使魔法少女恢复继续活动的余地。但悲叹之种正是灵魂宝石完全污染后的形态；吸收足够污浊而未被处理时，它仍可能再次孕育魔女。

局部净化因此只是改变污染的归属：

```text
灵魂宝石中的污浊减少
＋ 悲叹之种中的污浊增加
＝ 世界中的污染没有凭空消失
```

这对所有治疗、净化和解除诅咒机制都很重要。效果必须说明负面状态是被销毁、转化、封印、转移到其他载体，还是暂时压制。若只是转移，事务系统应在同一个原子提交中同时减少源载体和增加目标载体，不能让中间状态被利用来复制或丢失污染。

悲叹之种同时也是稀缺生存资源。魔法少女为了净化自己必须猎杀魔女，而魔女又来自魔法少女的失败。系统因此形成稳定但不公平的资源循环。它能够长期运行，不代表参与者获得了公平交换。

### 3.5 魔女化是主体与局部世界的相变

灵魂宝石完全污浊后会变成悲叹之种，魔法少女则转化为魔女。这个过程不适合表达成“角色死亡，然后在原地生成怪物”。魔女的主题、行为、使魔和结界通常仍由原主体的愿望、人格、执念及绝望塑造。原来的精神结构没有消失，而是以扭曲形式外化为新主体和异常空间。

```text
愿望
＋ 人格和关系
＋ 最终导致绝望的解释
→ 魔女的身份主题
→ 行为规则
→ 结界环境
→ 使魔和攻击方式
```

相变应当作为跨越阈值后生成的一组原子效果：撤销原魔法少女能力，改变灵魂载体，替换主体行为模型，创建局部作用域，并把精神结构编译为结界规则。如果其中任何必要部分无法构造，整个相变批次都应失败，而不是留下半个魔女或无主结界。

这也提示了异常场景的生成方法。异常空间不必从随机规则表拼接，它可以由主体的愿望、记忆和崩溃原因生成。这样，场景规则既客观可执行，又保留叙事意义。

### 3.6 圆环之理是全局反应规则

[Law of Cycles](https://wiki.puella-magi.net/Law_of_Cycles) 记载，鹿目圆的愿望改写了所有时间线中魔法少女的结局：在灵魂宝石完全污染、即将转化为魔女时，圆环之理介入并吸收其绝望，从而阻止魔女诞生。

从引擎角度看，它不是简单删除“魔女”类型，而是注册了一条跨越时间和空间的高优先级反应：

```text
触发条件：任意适用时间线中的灵魂宝石即将完全污染
介入时点：魔女化效果提交之前
替代结果：吸收污浊，取消魔女化，将主体导向新的终止状态
作用范围：过去、现在、未来及多条时间线
```

新规则改变了相变的结局，却没有消灭世界中的一切诅咒和负面能量。这说明高位规则改写也要明确替换哪个因果分支、保留哪些守恒量，以及新世界如何重新达到稳定。它适合作为后期的全局规则测试，不应成为早期实现普通反应机制的捷径。

## 4. 《JOJO的奇妙冒险》

本轮主要使用 [JoJo's Bizarre Encyclopedia](https://jojowiki.com/)，其中 [Stand](https://jojowiki.com/Stand) 是替身体系的总入口。系列横跨多个部和不同世界线，替身通则又经常伴随明确例外，因此调研记录必须保留适用部数、具体替身、原作出处和例外类型。

### 4.1 替身把精神特征变成可交互实体

百科将替身描述为由使用者精神产生的能力实体。通常一名使用者只有一个替身，替身与使用者共享意识、感官或伤害，替身被彻底破坏也可能导致本体死亡。非替身使者通常不能看见或直接伤害替身。

这些是默认关系，不是不可违背的世界公理。物质同化型替身可以依附真实物体；自动型替身可能不向本体传递伤害；死后型替身能在使用者死亡后继续存在；某些替身还会更换或伤害自己的宿主。[Stand Types](https://jojowiki.com/Stand_Types) 对这些类型进行了归纳。

因此，替身不应被硬编码为角色的固定子对象。更合适的表达是以可覆写关系连接本体与能力实例：

```text
ownership：替身当前属于谁
control：谁能向替身提交意图
perception_link：双方共享哪些感知
damage_link：伤害如何在双方之间传播
lifecycle_link：一方死亡或失能时另一方怎样变化
visibility：哪些观察者能够感知替身
materiality：替身能与哪些对象发生碰撞
```

普通近距离替身可以使用一组默认值，自动型和同化型替身只覆写必要字段。这样既保留通则，也不会为了容纳例外不断破坏核心代码。

### 4.2 能力规则对使用者本人也可能是未知的

[Stand](https://jojowiki.com/Stand) 明确指出，使用者觉醒替身时并不天然知道能力的全部细节，需要通过练习和实际事件发现能力。有些能力直观，有些则要经过很长时间才发现隐藏性质。

这意味着能力的客观定义和主体认知必须彻底分开：

```text
客观能力：实际触发条件、范围、效果和例外
使用者模型：使用者认为自己的能力如何工作
观察者模型：敌人根据现象推导出的假设
公开说法：角色向他人描述或伪装出的规则
```

即使能力属于角色，角色的决策系统也只能读取使用者模型，不能直接读取客观规则。新的应用方式应通过训练、试验、他人说明或偶然事件进入认知层，再改变角色能够提交的意图。

### 4.3 射程交换的是控制品质，不只是伤害

替身通常存在有效射程。近距离替身常有较高力量、速度和精密度；直接控制型替身离本体越远，表现往往越弱。但该趋势不适用于所有替身，尤其不适用于自动型和与时间、空间相关的能力。

真正值得抽象的不是一条“射程与威力反比”公式，而是一组可交换属性：

```text
作用距离
控制精度
反馈信息
响应延迟
停止能力
目标选择能力
伤害回传风险
```

自动追踪型替身可以放弃精确控制和即时停止，换取远距离、持续行动与较低的本体暴露风险。直接控制型替身则保留精细操作和完整感知，但本体通常必须接近战场。

[Highway Star](https://jojowiki.com/Highway_Go_Go) 是典型案例。它通过诱饵房间取得目标的气味，然后以固定高速自动追踪并吸收目标生命力。自动状态使其能远离本体持续行动，但也让它机械地追随气味，因而能够被误导。对抗者不必在力量上摧毁替身，而可以利用其目标选择算法寻找本体。

### 4.4 自动能力是可被研究的算法

自动替身并不是拥有无限判断力的 NPC。它通常由有限触发条件、目标选择和持续规则驱动。规则越稳定，越能远距离独立工作，也越可能被敌人预测和利用。

[Notorious B.I.G](https://jojowiki.com/Notorious_Chase) 在本体死亡后才完整激活，会吸收能量并自动追逐附近移动最快的对象。它几乎无法通过直接攻击消灭，但“追逐最快目标”使行为完全可预测。角色最终不是击败它，而是让持续运动的海浪成为其长期目标。

这个案例说明，反制不必产生 `destroyed = true`。只要把异常引导进一个不会继续危害主要目标的稳定状态，也可以视为成功解决：

```text
不可摧毁异常
＋ 可预测目标选择器
＋ 持续存在的环境诱饵
→ 局部稳定封锁
```

引擎因此需要区分消灭、解除、封印、转移、误导和稳定隔离等任务结果。

### 4.5 智斗的核心是逐步识别最小规则

《JOJO》的战斗通常不从双方完整公开能力开始。角色先遭遇现象，再建立假设，通过低成本试探排除错误解释，最后找到触发条件或例外。适合引擎的认知循环是：

```text
观察异常现象
→ 生成一个或多个能力假设
→ 推导各假设可区分的预测
→ 选择风险可接受的试探
→ 获得新事件
→ 更新假设置信度
→ 找到可利用的条件或反例
```

系统不应直接给 NPC 一个“已识破能力”的标签，而应保存结构化假设。例如，角色可能知道攻击与影子有关，却不知道触发需要踩中影子；知道敌人能够回溯时间，却不知道回溯由谁获知秘密触发。部分正确的知识已经足以改变行动选择。

### 4.6 “败者食尘”展示了嵌套触发与时间回滚

[Bites the Dust](https://jojowiki.com/Bites_the_Dust) 被植入宿主体内后自动运行。当其他人通过宿主得知吉良吉影的秘密时，能力杀死知情者，并把时间回退到大约一小时前。回退后，之前被能力杀死的人仍可能在对应时点再次死亡。与此同时，替身被部署在宿主体内，使吉良无法正常召唤杀手皇后保护自己。

该能力至少包含四层规则：秘密传播事件、自动杀害、时间线回滚，以及回滚后保留的预定死亡。反制来自发现它的限制：宿主选择受限；吉良本人直接暴露身份并不以相同方式触发；部署期间吉良失去主要防身能力；吉良主动解除能力后，循环能够被打断。

这要求时间系统区分：

```text
世界状态回滚
主体记忆是否回滚
能力内部记录是否回滚
已注册的未来事件是否保留
触发源在新时间线中是否重新核验
```

普通事务回滚是撤销失败批次，不应等同于世界内的时间能力。后者会创建一个新的因果版本，并按照能力规则选择性继承记忆、预定事件和隐藏状态。

### 4.7 “监狱摇滚”展示了对认知容量的规则攻击

[Jail House Lock](https://jojowiki.com/Jail_House_Lock) 使目标只能保留三条新信息；获得第四条时，最早的一条会被遗忘。旧记忆仍然存在，因此它攻击的不是全部记忆，而是新信息工作集的容量。

空条徐伦的反制不是提高意志数值，而是改变信息编码方式。她利用二进制只包含零和一两种信息的特点，把复杂肖像编码为不超过容量限制的数据，再由替身将其输出成图像。她后来还迫使能力作用于守卫，使守卫忘记正在追踪的目标。

这对认知系统有两个直接启示。第一，记忆不能只有“知道或不知道”，还需要区分长期记忆、当前工作集、外部记录和重新识别。第二，规则限制的计数单位本身可以被策略性利用。“三条信息”中的一条如何划分，不应由字符串数量决定，而要由世界规则采用的语义分块方法决定。

### 4.8 对引擎的结论

《JOJO》最重要的贡献不是提供又一套能量体系，而是证明能力规则本身可以成为战场。一个能力可以在输出上近乎无敌，却因目标选择、触发条件、宿主关系、信息需求或环境依赖而被反制。

引擎若要产生这种智斗，必须保证客观能力能够稳定执行，主体只能依据自身认知行动，试探会产生可区分的证据，异常规则存在可观察的边界，而且环境对象能够参与反制。否则所谓智斗只会退化成系统临时宣布“角色想到了弱点”。
