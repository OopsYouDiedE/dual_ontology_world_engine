# 《异常感知学园》前五日剧情规则树

## 1. 设计范围

本稿设计禁闭开始后的前五天。它不是五日剧本，也不规定唯一场景顺序。日期只开放节点；节点是否发生，由此前实际事件、人物认知、在场者、规则与玩家行动决定。

前五天的目标是让人物通过共同生活留下第一批行为证据：谁尊重拒绝，谁履行承诺，谁会在证据不足时指控，谁愿意承担自己提出的办法。系统此后才能据此判断性格在具体处境中的反应。

固定事实只有：

- 十六人在生活院各自的住处醒来。
- 他们记得姓名、才能、入学前经历、性格和身体习惯，不记得校内经历与彼此旧关系。
- 才能只是本人自述，实际能力需要通过行动验证。
- 一日为 `200 AV`。天亮 `120 AV`，天黑 `80 AV`。
- 普通通路移动至少消耗 `20 AV`。
- 天黑后必须睡眠。正常人物不生成夜间日常行动。
- 第一日由广播公布夜禁。其他集合、分组、值日和公共规则都不是既定事实。

## 2. 性格规则必须来自剧情

人物设定在第一次选择时只提供低风险候选。实际选择发生后，才产生可供后续决策引用的行为依据。

一条依据只需记录：

```text
来源节点
当时刺激
行动者当时相信的事实
实际采取的动作
该动作适用的现场边界
```

例如，第一日鸣海澄在久世弦明确要求安静后停止说话，只能证明“鸣海在没有旁观压力时尊重过久世的一次明确拒绝”。第二日再遇到餐厅噪声时，久世可以因此先直接提出要求。它不能证明鸣海对所有人都体贴。

认知仍然有方向。旁观者只记录自己亲眼所见或相信的转述。后台掌握的真相不进入人物选择。

## 3. 总体规则树

```text
第 1 日：醒来与低风险初见
├─ 零散相遇 → 临时同行、礼貌分开或彼此错过
├─ 集中介绍成立 → 产生公开自述和缺席者
└─ 集中介绍不成立 → 信息分散到小组
        ↓
初次生活与探索
├─ 结伴、独行、留守、做饭、休息或拒绝参与
└─ 守约、越界、帮助、失误形成首批行为依据
        ↓
夜禁广播 → 及时返回并连续睡眠 80 AV

第 2 日：重复接触
├─ 早餐因实际召集而成立
├─ 零散进食，形成信息断层
└─ 前夜异常留下痕迹时，部分人先核实
        ↓
探索汇报或普通活动
├─ 产生可核实承诺
├─ 产生轻微摩擦种子
└─ 没有大事发生

第 3 日：检查已经存在的摩擦种子
├─ 共有物边界
├─ 公开纠正与难堪
├─ 配给与隐私
├─ 探索承诺与信息披露
└─ 无种子 → 继续普通日常
        ↓
第 4 日：同类刺激是否再次发生
├─ 条件完整 → 公开冲突、明确限制或关系回避
├─ 场合改变 → 私下核实或低强度交涉
└─ 条件被消除 → 节点永久取消
        ↓
第 5 日：后果
├─ 可见补救 → 有限合作
├─ 只有道歉 → 未结事件保留
├─ 拒绝继续接触 → 平行使用或第三方见证
└─ 从未升级 → 普通共同生活
```

四条路线都可以成为第五日的有效结果。系统不补造替代冲突。

## 4. 第一天节点池

### D1-N01 陌生房间醒来

**前置**：人物刚恢复意识，没有必须立即处理的伤势。

**刺激**：姓名标识存在，个人用品与记忆不连贯，门外偶有声音。

**候选**：检查房间、立即出门、隔门询问、等待、继续休息。真壁铸只有发现实际设备异常才检查设备；灰原朔只有发现身体异常才进行医疗判断；白峰局可以因信息不足继续躺着。这些选择都不生成道德判断。

**玩家改变**：多检查 `20 AV` 会获得更多环境事实，同时错过早期相遇；主动敲门会把对方的第一刺激改成“陌生人站在门外”。

**结算**：只形成关于环境和第一名接触者的低把握判断。没有承诺便不改变履约预期。

### D1-N02 走廊初遇

**前置**：二至三人在生活院相遇，没有即时危险。

**刺激**：双方都无法验证对方身份，只能观察措辞、距离和是否尊重拒绝。

**可能动作**：

- 鸣海澄可能主动填补沉默。若对方要求安静，是否停止成为行为依据。
- 久世弦可能只报姓名。别人继续追问时，可以离开，不必争论。
- 青栖绘可以观察而少说。别人替其解释沉默时，可以纠正、举起速写或结束交谈。
- 苍井砥面对突然靠近或危险物才要求拉开距离，不对空手陌生人进行搜查。
- 榊火澄只有看见口渴、发抖或衣着不整等实际需要时才先处理生活问题。
- 月见里鸢可以用含糊介绍试探盲信。被指出矛盾时，是补充、玩笑带过还是继续隐瞒，成为后续依据。

**分支**：临时同行、只交换姓名、礼貌分开、因误解产生轻微不快。拒绝同行不增加伤害预期。

**取消与变形**：广播打断时，未完成介绍保留为之后的闲聊种子；隔门交流时，双方不能获得外表与携带物的亲见信息。

### D1-N03 集中介绍是否成立

**前置**：至少六人在中央厅，有人提出确认姓名或人数，过半在场者愿意停留 `20 AV`。

**发生**：参与者只公开自己愿意说明的姓名、才能自述和失忆范围。有效发言者控制在二至五人，其余人可以简短应答、旁听、迟到、走神或离开。

**性格反应**：

- 御影章若提出记录，只能登记本人愿意公开的内容。扩大登记范围会给月见里鸢或其他重视边界者提供实际质疑理由。
- 冬城史会提醒“本人如此自述”不等于已经证实。
- 白峰局只在人数或说法明显对不上时需要开口。
- 鸣海澄可以递话，也可能把不愿发言者推上台；后者是否明确拒绝决定这是不是边界事件。
- 绯宫巡可以完整介绍，同时拒绝轻佻评价。公开表达完整不等于愿意私下接近。

**不发生**：无人提议、支持不足或有人先要求确认出口时，介绍拆成小组。缺席者之后只能通过本人补充或转述被认识。

**玩家改变**：主持方式决定“程序尊重边界”或“强迫公开”的第一批认知。玩家要求先探索会让 D1-N04 提前，但不会自动获得领导地位。

### D1-N04 自然探索与第一餐

**前置**：有人提出确认出口、食物、医疗条件或建筑边界。

**组队规则**：提议者邀请具体对象。每人依据疲劳、兴趣、刚形成的印象和风险判断选择同行、独行、留守或拒绝。禁止按才能平均分组。

**普通结果**：

- 有人只找到无关用品。
- 有人走到一半嫌远而返回。
- 有人留在后勤院准备食物。
- 有人没有汇报价值，只谈路线难走或房间难闻。
- 有人留下聊天、洗漱、休息或观察别人。

**行为证据**：

- 真壁铸面对实际故障才动手。方城础给出可见结构依据后，真壁是否停止，会成为二人之后处理风险的依据。
- 赤星砾看到未知残留物后，是否在缺少容器和通风时克制，决定旁观者如何判断其风险。
- 灰原朔检查诊疗所只证明其领域能力，不证明愿意公开病人信息。
- 青栖绘画下路线后是否愿意展示，由对请求者的初步认知决定。
- 榊火澄留下确认食材，是因为众人即将进食；已经有人可靠处理时，可以离开做别的事。

玩家可以作出 `40 AV` 内返回、共享发现或不碰私人物品的明确承诺。只有之后实际兑现或违反，才改变履约预期。

### D1-N05 第一餐与夜禁广播

**前置**：白天已经过去至少 `80 AV`，或探索者开始返回。

**固定世界事件**：广播公布天黑后必须返回住处并保持睡眠，公共区域活动属于违规。质疑不会暂停规则生效。

**生活反应**：有人先问浴室，有人抱怨没吃饱，有人忘记住处方向，有人给迟归者留食物，有人提前离席。没有找到食物时，人物必须在继续寻找和及时返回之间选择。

**规则反应**：御影章会询问意外滞留和急救是否仍算违规；苍井砥会提醒预留返程成本；月见里鸢可以检查文字与门锁边界，但没有更强动机时不会为证明性格而首夜违规；灰原朔可以询问急救例外，没有病患便不会夜间行动。

**分支**：

- 全员及时返回：迟归和夜间搜索节点取消。
- 白天返程估算错误：形成客观违规与动机分离的特殊节点。
- 玩家组织入夜前搜索：参与者支付移动成本；找到迟归者后夜间节点取消。

**结算**：正常人物从 `120` 到 `200 AV` 连续睡眠。夜间不播放轮流行动。

## 5. 第二天节点池

### D2-N01 早餐集合

**触发**：第一日有人明确承诺召集，并实际敲门、传话或准备食物；或者人物因饥饿和食物气味零散到达。

**分支**：

- 承诺被履行：早餐形成小型公共锚点。
- 无人召集：人物零散进食，消息不能自动同步。
- 召集者失约：早餐仍可能由别人促成，但失约只进入知情者认知。

**生活表现**：允许迟到、拿走食物、换座、没听点名、多睡、吃不惯和中途离席。久世弦因嘈杂独自进食不等于敌意；绯宫巡没有承诺准时时，迟到不算失约；苍井砥只追问答应到场却缺席的人。

### D2-N02 配给与生活边界

**前置**：至少四人取餐，库存尚未准确清点；有人多拿、替缺席者留份、要求登记或拒绝公开饮食需要。

**发生条件**：至少两人的处置动作不兼容，并使一方实际受阻。只有意见不同而无人受阻时，只是餐桌争论。

**具体反应**：

- 榊火澄先阻止明显浪费或大量取用。若没有库存数字，其他人可以合理质疑限制依据。
- 灰原朔主张只公开配餐所需信息，不公开诊断。榊此前尊重过隐私时，灰原更愿意私下说明。
- 御影章可以提出只试行一餐的办法和复议条件，不自动取得管理权。
- 月见里鸢会检查办法是否同样约束管理者。规则一致且允许复议时，可能嘴上讥讽但实际遵守。
- 白峰局只有看到库存数字后才提出分配。若方案要求别人少吃，自己是否接受同等限制会成为行为依据。
- 鸣海澄被私下提醒与被公开点名时，反应可以不同。

**取消**：清点证明库存充足后，长期配给冲突取消，只保留餐桌礼节与管理边界。玩家提前把特殊需要交给榊而不公开诊断，隐私冲突取消。

### D2-N03 探索汇报

**前置**：至少两组掌握不同区域的亲见信息，且存在会影响公共行动的事实。

**知识规则**：展示记录或带路验证形成较高把握；口头汇报只形成带来源 Claim；未在场者不自动知道。

**具体反应**：

- 雾岛律区分亲见、推测与转述。对已经守约的汇报者可以临时采信，仍保留复核。
- 冬城史面对残缺文字保留多种解释。别人允许其暂不下结论时，更可能展示原文。
- 青栖绘可以展示路线图而遮住私人速写。有人擅自翻页会产生边界事件。
- 方城础与真壁铸可以围绕“眼下能够通行”和“持续使用是否安全”产生事实层面的分歧。
- 赤星砾若第一日曾无防护取样，苍井砥或灰原朔才有剧情依据要求安全限制。
- 无责任、无兴趣的人可以中途离席，不需要轮流表态。

**玩家改变**：公开别人的发现会改变信息分布并可能产生被抢夺成果或泄露隐私的事件；要求现场复核需支付往返 AV；提前提供完整证据会取消隐瞒争议。

### D2-N04 无事发生的下午

当日没有紧迫公共问题时，剩余至少 `40 AV` 返回日常池：洗衣、洗澡、散步、阅读、下棋、吃剩饭、看别人活动、闲聊或独处。

已守约的同行者可以自然延续交谈；发生过轻微摩擦的人可以避开同桌、只谈事务或需要第三人在场。一次聊天只影响亲近意愿；兑现一项小承诺只影响相应履约预期。没有实质互动时，不更新关系。

入夜前所有人支付返程成本，随后连续睡眠 `80 AV`。

## 6. 第三天摩擦种子选择

第三日不指定冲突。系统从前两日实际形成的种子中，最多激活一条主要链。没有种子就继续普通日常。

### S-A 共有物边界

**所需前史**：某人在 D1-N04 或 D2-N02 使用、移动或承诺归还过具体共有物。

**现实刺激**：厨房钥匙、医药箱、提灯、工具盒或记录册不在约定位置；至少两人确实需要使用；发现者没有亲眼看见移动过程。

**反应依据**：

- 已见过移动者守约的人先询问。
- 已有越界记录且再次拒绝解释时，才提高限制行动的优先级。
- 物品影响吃饭或急救时，照顾倾向者先寻找替代，再追责。
- 习惯核实者区分接触、移动和拿走，阻止无证据定罪。

**取消**：玩家在公开询问前找到物品，指控节点取消，只保留归位协商。物品归属和使用办法已提前说明时，整条链失效。

### S-B 公开纠正

**所需前史**：某人已公开给出可检查说法或做法，另一人拥有相反的亲见事实。

**现实刺激**：路线安全、库存数量、设备状态或记录内容出现明确矛盾。

**反应依据**：纠正者根据此前关系选择公开指出、私下提醒或暂缓核实；被纠正者根据对方是否曾公平对待自己，选择核实、要求证据或把行为理解为羞辱。

**变形**：没有旁观者时删除公开难堪分支，只保留核实与拒绝。玩家提前核对并让当事人自行更正，公开节点取消。

### S-C 配给与隐私

**所需前史**：D2-N02 已出现特殊需要、留份或管理边界，但没有解决信息如何传递。

**现实刺激**：食物或药品出现实际短缺，同时有人不愿公开自身需要。

**反应依据**：榊火澄是否尊重过灰原朔的有限披露，决定灰原是否愿意私下提供信息；被公开催促进食的人此前如何理解榊的关心，决定其接受、回避或反击；白峰局的方案是否约束自己，决定旁观者是否认为其公平。

**取消**：玩家找到替代资源后，分配争夺取消；隐私问题只有在仍有人试图公开诊断时才保留。

### S-D 探索承诺与信息披露

**所需前史**：有人承诺返回、共享发现、不碰记录或替别人保密。

**现实刺激**：承诺逾期、共享内容缺失、私人页面被翻看，或者当事人认为信息已被他人抢先公开。

**反应依据**：先确认承诺是否明确、当事人是否知道期限、违背是否出于路线受阻。亲近对象可以获得私下解释机会，履约预期低的对象会被要求见证或复核。

**取消**：没有明确承诺便不能产生失约节点。玩家及时补传消息或阻止泄露后，对应冲突完全取消。

## 7. 第四天升级树

第三日种子只有同时满足下列条件才升级：

1. 已留下明确未结事件。
2. 同类刺激再次出现，或第一次刺激已造成实际损失。
3. 相关人物实际同场。
4. 当事人的质疑没有得到回答。
5. 当事人仍有退让以外的可执行选择。

条件完整时，节点可形成公开冲突、明确限制或关系回避。性格反应必须引用前一节点：

- 曾在低压力场合接受证据的人，第二次应先要求核实；只有对方重复失约或公开羞辱，才提高对抗强度。
- 曾尊重边界的人，在相似问题中先获得解释机会。
- 曾把玩笑当作逃避的人，面对同一人的玩笑会降低口头解释权重。
- 曾承担自己提出规则的人，更容易获得试行支持；选择性执行者会面对公开质疑。
- 先前被保护的人可以相信动机却反对手段，两项判断分别保存。

**场合变形**：参与者不足三人或玩家提前安排私下谈话时，公开面子压力删除，节点变为核实、交涉或离场。

**永久取消**：玩家消除重复刺激、澄清错误归因、修复物品或让规则不再限制当事人后，节点不再以更换人物和物品的方式补演。

## 8. 第五天后果树

### O-A 有限修复

**条件**：存在明确未结事件；至少一方愿意承担可观察成本；被修复方可以拒绝。

有效动作包括：公开更正超过证据的指控、把自己纳入同一规则、归还或修复物品、交出原本可以继续隐瞒的证据、完成低风险再合作。

结算只更新被验证维度。人物可以恢复工作合作，仍拒绝私下相处；可以接受物品归还，仍要求第三方见证。

### O-B 修复条件不足

只有口头道歉、劝和或“大家都是同伴”的要求时，不恢复关系。双方可以停止争吵，同时保留未结事件；也可以使用不同时间、第三方保管或每次见证的平行办法继续生活。

### O-C 错误认知被证据修正

新证据只修正收到并相信证据的人。公开指控者决定是否在相近见证范围内更正；被误解者可以接受事实纠正而不恢复亲近。实际受辱不会因真相出现而删除。

### O-D 普通收束

若前三日的摩擦被低成本解决，第五日不补造冲突。人物正常归还物品、准备餐食、整理公共区、短暂娱乐或各自休息。

该节点观察谁自然坐在一起、谁兑现小承诺、谁只谈事务、谁仍避开某人。允许没有数值变化。

## 9. 四条必须可运行的路线

1. **自然升级**：生活摩擦重复，第四日形成公开冲突，第五日出现有限修复机会。
2. **提前澄清**：玩家在第三日前解决事实问题，升级节点永久取消，第五日保持普通生活。
3. **改变现场**：玩家让公开纠正变成私下核实，旁观者没有获得相关认知，关系损害较小。
4. **传播错误信息**：玩家扩大不完整转述，冲突对象与知情范围改变；第五日只能通过证据纠错，不能自动复位。

四条路线的第五日认知关系必须不同。只改变台词或地点不算分支。

## 10. 行动值与日常比例

- 五日共有 `600 AV` 天亮时间，其中至少 `360 AV` 应用于进餐、洗漱、整理、散步、休息、找人、闲谈、阅读、娱乐和自愿帮忙。
- 单个普通节点通常消耗 `20 AV`；复杂争议最多连续消耗 `40 AV`。
- 移动与返程实际收费。不在场者不能免费加入会议或获得信息。
- 节点被取消后，释放的行动值返回日常池。
- 每晚统一结算 `80 AV` 睡眠。前五日默认路线没有夜间违规。
- 夜间违规若因白天未消除的急救、危险或滞留触发，必须留下痕迹，并在次日单独处理；玩家白天消除诱因后，该分支完全取消。

## 11. 验收条件

- 第一次性格反应只使用人物设定和眼前事实；之后的反应必须引用至少一个先前剧情节点。
- 每项引用写明当时刺激、所信事实、实际动作与适用边界。
- 每个特殊节点都有发生、变形和彻底取消条件。
- 至少一条路线在第五日结束时没有公开冲突。
- 节点取消后不生成相同功能的替代争执。
- 认知严格区分亲见、转述和推测，不向全员同步。
- 亲近意愿、履约预期和伤害预期可以向不同方向变化。
- 领域能力可信不扩展为人格可信。
- 玩家至少能改变一次信息分布、一次在场关系和一次物品或规则事实。
- 角色可以迟到、拒绝、走神、偷懒、闲聊、离席或什么也没发现。
- 不要求十六人在公共场景中轮流发言。
- 正常夜间只进行连续睡眠，不生成普通行动。
- 第五日状态来自实际节点，不由日期写入。
