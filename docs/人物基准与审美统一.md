# 人物基准与后续审美统一

2026-10-27 已确定 VRoid Studio 加 Blender 的三头身人物制作主路线，具体依据见[人物生成器选型](人物生成器选型.md)；但是新增人物尚未完成样角与正式 Godot 验收，以下旧候选记录均不代表当前采用状态。

用户最新确定采用 Q 版三维人物，当前筛选以完整蒙皮模型、统一的风格化头身比及 E 外观为依据；但是下述 MakeHuman 写实成人候选已排除，不作为角色基准，也未接入游戏。后续的实际合理比例指 Q 版风格内部一致、角色与家具接触合理；但是不意味着恢复写实成人头身比。以下候选检查作为选择过程记录保留。

实施顺序先完成地图、三维 Demo、家具预制件与完整蒙皮人物，再统一比例与时代审美；但是当前地图仍有旧贴片、Demo 仍是分镜预览，因此尚未进入全面审美验收。

用户明确要求人物保持完整网格与蒙皮变形，本轮已撤回分段关节人物、动作脚本及 16 个临时生成角色文件，恢复原 E 外观；但是原 E 人物也是暂存外观，不能作为完整蒙皮人物替换完成的证据。

Sol 已搜索 [Plewr 的完整绑定人物](https://plewr.itch.io/3d-rigged-character)、[MakeHuman](https://www.makehumancommunity.org/about/license.html)、[Blender 官方人物基础网格](https://download.blender.org/demo/asset-bundles/human-base-meshes/)与 [Innerscene 的 MakeHuman 派生底模](https://www.innerscene.com/tools/library/3d-parts/male-base-mesh-3d-person-rigged-a-pose-380e6d89)，主代理负责最终采用判断；但是候选列出不等于入库批准。

Innerscene 候选已下载至项目暂存目录并检查 GLB：4,498,248 字节、一个 163 骨蒙皮、全部七个材质图元含关节及权重属性、约 1.786 米高、共 109,064 三角面，SHA256 为 `d15a07e2b4cf1d08a3b91cb212a9a06a91438077f05a3f2a62f45351e8a71eb8`；但是文件不含动画，尚未检查弯曲变形、连续拓扑和服饰适配，也尚未作为正式人物采用。官方页面标为 CC0；但是当前面数更适合作为比例制作基准，游戏版本仍需优化和验证。

Plewr 官方列出免费的 CC0 `characterRIGGED.glb`，约 993 kB；但是本轮尚未取得该文件，不能对其拓扑或动画质量作出确认。[Quaternius 当前总许可](https://quaternius.com/license.html)为 2026-08-28 更新的 QAL，可用于游戏但限制独立素材再分发；但是具体旧包许可须按实际取得版本另行核验，不能统一写成 CC0。

后续审美依据现有设计案的架空 1900 年代皇家海外学园，以大宸近代改扩建、维多利亚工业细部与新艺术运动元素为背景，分别核对人物身高、头身比、家具座高、桌高、门窗及建筑净空；但是不能把十六世纪遗构与近代生活空间混成同一层装修。公共厅、宿舍、诊疗、后勤与人物私人陈设按用途和身份保留差异；但是具体家具和服装样式落地前仍须补齐同期地域资料与实物尺寸依据。
