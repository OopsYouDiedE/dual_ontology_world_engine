# 独创仪式因果契约与违约惩戒规范

## 商业领域现有技术局限

商业游戏中的制造、合成与仪式系统（如各类沙盒生存游戏的 Crafting Table、MMORPG 锻造系统）本质上是单向、即时且无状态的数据替换。玩家消耗原料物品列表，系统根据配方匹配成功后实例化目标物品，流程即刻终止。传统合成缺乏多实体协同维持的持续生命周期概念，也无法表达 仪式启动后必须持续维持祭品完整度与心智专注，一旦破坏将引发超自然反噬的因果网络。

---

## 本系统独创设计

本系统将合成行为从单纯的物品交换升格为建立具有持续生命周期的仪式因果契约（Causal Covenant），并在契约破裂时执行强制性因果反冲惩戒。

### 契约生命周期与多实体义务网络

通过 KotodamaFactory.CreateRecipe 装配的仪式配方在激活时生成独立的契约实体：
- 槽位绑定：契约将参与者实体（施法者、受术目标、媒介催化实体、祭品）动态绑定至指定的槽位规范（SlotSpec）。
- 履约义务（Obligation）：契约向参与者施加跨行动周期的行为义务。例如要求施法者在接下来的若干回合内持续处于特定专注状态，或要求环境保持特定源质平衡。
- 豁免例外（Exceptions）：预设解除义务责任的特定情境表达式。

### 违约侦测与创伤反冲管线

系统由言灵监督系统（KotodamaSystem）全局挂载审查机制：
1. 效果通报：当世界中发生任何效果（Effect）时，系统调用 Observe(effect) 审查当前所有活跃契约。
2. 违约判定：若效果破坏了契约规定的客观义务（如破坏了仪式维持物、擅自离开法阵），契约标记为已破坏状态（Breached）。
3. 惩戒反冲（Breach Reaction）：系统拒绝执行常规事务回滚，而是立即激活契约中预设的惩戒效果集（Breach Effects）。反冲效果直接作用于违约者的认知切面与身体切面，写入长效因果创伤、恶性情绪或不可逆生理异化。
