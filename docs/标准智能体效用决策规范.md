# 标准智能体效用决策技术规范

## 1. 概述

标准智能体效用决策系统（Utility AI）基于微观经济学效用理论与游戏决策建模架构（以 Dave Mark 的行为数学模型与《模拟人生》的动机体系为代表）。
该系统通过将智能体的内在生理/心理需求与外部环境状态映射为无量纲的效用标量，在海量候选行动中实现连续、平滑且自适应的情境决策。

## 2. 需求动机模型（Motives & Needs）

智能体持有若干连续的需求数值池（如饥饿度、精力值、社交渴求、安全感）：
* **数值区间**：每个动机设定统一基准区间 $[0, M_{\text{max}}]$（通常为 $[0, 100]$）。
* **持续时间衰减**：动机随离散时间或游戏刻度持续衰减：

$$\text{Motive}_{t} = \text{Motive}_{0} - \lambda \times \Delta t$$

* **交互补偿**：特定环境对象（如床铺、食物、书籍）对外发布其可满足的动机类型与恢复量。

## 3. 考虑因素与归一化（Considerations & Normalization）

决策管线在评估每一个候选行动时，分解为多个独立的考虑因素（Consideration）：
* **输入归一化**：将环境中的原始物理量 $x$（如剩余生命、距离、物品数量）通过上下界线性映射至 $[0, 1]$ 区间：

$$x_{\text{norm}} = \text{clamp}\left(\frac{x - x_{\text{min}}}{x_{\text{max}} - x_{\text{min}}},\, 0,\, 1\right)$$

* **语义统一**：所有输入数据转化为无量纲的标准化输入，确保跨维度评估的一致性。

## 4. 响应曲线模型（Response Curves）

归一化输入 $x \in [0, 1]$ 通过数学响应曲线转换为具体的单项效用得分 $u \in [0, 1]$：
* **线性曲线**：$u(x) = m(x - c) + k$
* **多项式/幂函数曲线**：$u(x) = m(x - c)^k + b$（用于表现随匮乏程度加剧而加速攀升的紧迫性）。
* **Logistic 曲线（S 型）**：

$$u(x) = \frac{1}{1 + e^{-k(x - x_0)}}$$

（用于表现临界阈值前后的剧烈态度转变）。
* **分段线性样条（Piecewise Linear）**：由策划配置若干关键控制点，中间线性插值生成。

## 5. 效用聚合算法（Utility Aggregation）

候选行动的最终综合效用 $U$ 采用带权乘法模型聚合，避免加法模型中低紧迫项虚假掩盖致命缺陷的问题：

$$U = \prod_{i=1}^{n} \left[ (1 - w_i) + w_i \times u_i \right]$$

其中 $w_i \in [0, 1]$ 为该考虑因素的权重，$u_i \in [0, 1]$ 为单项效用。
若某项关键条件完全不满足（$u_k = 0$ 且 $w_k = 1$），总效用直接归零，该行动被自然否决。

## 6. 分桶与决策惯性控制

### 6.1 优先级分桶（Bucketing）

行动候选按紧迫程度划分为若干分桶：
1. **危机桶（Critical Bucket）**：生命垂危、极度饥饿等生死攸关行为。只要该桶内存在可用行动，直接忽略次级分桶。
2. **常规动机桶（Standard Bucket）**：工作、社交、娱乐、休息等日常需求。
3. **空闲桶（Idle Bucket）**：游荡、观察、整理等无明确紧迫目标的低效用行为。

### 6.2 决策惯性与防震荡（Momentum & Hysteresis）

为防止智能体在两个效用相近的动作之间高频往复切换（Thrashing），系统引入惯性机制：
* **持续承诺奖励**：正在执行中的动作获得效用加成 $U_{\text{bonus}}$。
* **切换惩罚**：变更当前行动路线需扣除固定的切换阈值开销。
