# 独创双层分流规则裁决规范

## 商业领域现有技术局限

商业领域中的业务规则管理系统（BRMS，如 Drools、BPMN 决策流）或游戏 AI 行为树装饰节点（Decorators）均采用 单轨合规判定：
- 规则命中后，系统若判定其属于非法操作，则直接抛出异常或短路中断执行。
- 智能体只能在规则允许的安全空间内行动，无法模拟现实世界中明知故犯、两害相权取其轻或顶着道德与规则负罪感违抗戒律的人性化冲突。

---

## 本系统独创设计

本系统将产生式 AST 规则网络重构为主观心智决策层（心理规则压力加权）与客观世界法则层（硬性物理法则阻断）的双层分流裁决机制。

### 主观心智决策层：心理规则压力

在智能体心智评估阶段，产生式规则不充当硬性拦截器，而是通过 RuleSystem.Evaluate 转化为心理规则压力（RulePressure）：
- Mode.Require：若候选行为匹配要求，提供 $+100 + \text{priority}$ 的驱动奖励；若行为未满足要求，施加 $-80 - \text{priority}$ 的负罪压力。
- Mode.Forbid：若候选行为触犯禁止条件，施加 $-100 - \text{priority}$ 的抑制压力。
- Mode.Prefer：提供 $+50 + \text{priority}$ 的偏好加成。
- Mode.Permit：提供 $+20 + \text{priority}$ 的许可豁免。

最终意图决策通过代数叠加求解：

TotalScore = \sum \text{RulePressure} + \text{UtilityScore}

若违背禁令的行为能换取极其庞大的外部效用（如背叛誓言能挽救同伴生命），综合得分依然可能胜出。智能体得以做出顶着心理压力违背禁忌的选择，并在事后向情绪系统写入懊悔（Remorse）或内疚。

### 客观契约法则层：硬性物理法则阻断

当下沉至客观世界物理事务与言灵硬契约（KotodamaSystem.Allows 与 HardConstraint）时，系统切换至客观法则模式：
- 调用 RuleSystem.ObjectiveAllows 进行绝对合规性验证。
- 触犯客观禁止或未达成客观前提的行为，直接返回 alse 并触发 BlockedIntents++。
- 底层事务执行器立即拒绝该意图，杜绝物理不可能事件发生。
