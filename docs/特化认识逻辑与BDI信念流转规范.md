# 特化认识逻辑与BDI信念流转规范

## 商业智能体与行为决策系统背景

智能体心智架构在商业应用中主要分化为两大成熟体系：
- 工业级 BDI 平台（如 JACK Intelligent Agents、商业多智能体仿真中间件）：专注于复杂态势感知、目标管理与长期承诺维护。
- 商业游戏 AI 架构（如虚幻引擎的行为树黑板系统 Blackboard、GOAP 规划系统）：专注于高频反应式决策与轻量级环境认知上下文共享。

### 工业化架构标准

现代商业智能体系统普遍采用如下认知设计模式：
- 黑板与认知缓存（Blackboard / Sensory Cache）：环境观测通过感知传感器（Perception Components）采集后，直接以强类型键值对或事实对象写入角色私有黑板。
- 目标与计划库（Plans Library / Goal Arbiter）：BDI 系统的欲望（Desires）被建模为目标池，当满足触发条件时，规划器在预定义计划库中检索可行动作序列并转化为执行中的意图（Intentions）。
- 确定性直接写入：主流商业系统为了计算效率，通常在感知检测成功后直接将信息标记为主体认知（即默认观测即真实，或收到消息即采纳），缺少对认知消化的中间过程建模。

## 本系统特化设计

本系统的特化设计在于将商业黑板/BDI 的 直接断言机制，重构为主客观双重二元隔离与显式四阶段信念内化流水线。

### 四阶段认知内化流水线

外部感知或对话交流输入的信息不直接成为行动依据，信息流转严格经历四个阶段：

1. 接收阶段（Received）：
   智能体在感知视界内观测到客观事件或听取到对话断言，系统生成未解析的原始感知数据元。此时数据仅表示智能体感官上捕获到了信息，尚未解析为语义命题。
2. 理解阶段（Understood）：
   智能体调用自身语法语义解析器，将原始信号翻译为主体可解释的认识命题。若解析失败或存在歧义，状态流转中止于未理解状态。
3. 评估阶段（Evaluated）：
   智能体依据内部认知一致性、说话者信誉度与当前心理状态，对命题进行真值求值与可信度打分。
4. 采纳或拒绝（Accepted / Rejected）：
   - 采纳：若可信度高于采纳阈值，命题被持久化写入主体认知层信念集合，正式成为多步路径搜索与效用决策的事实依据。
   - 拒绝：若命题与牢固信念直接冲突或信誉度过低，命题被标记为驳回并记录怀疑标记，不进入决策输入集。

### 主客观二元拓扑隔离

系统在实体模型上划分客观世界树（Ontological Reality）与主观认识拓扑（Epistemic Graph）：
- 客观世界中的门禁状态、容器内物与节点连通性由物理实体真实持有。
- 智能体决策时严格只允许查询其本地采纳的信念拓扑，形成可能包含错误、过时信息的局部认识投影。
