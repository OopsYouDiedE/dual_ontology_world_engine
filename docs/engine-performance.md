# 会话决策与耗时记录

## 指标与范围

`DvSession` 为 CLI、Godot 共用的统计入口。统计使用 `Stopwatch` 单调时钟，分别记录同步引擎计算与整段现实游玩时间；不修改物理世界、人物心智、行动费用或规划输入。控制来源分为 `engine`、`human`、`llm`，仅该诊断标签随存档顶层 `performance_controller` 保存，累计数据从每次打开或恢复会话重新开始。

| 指标 | 字段 | 计算口径 |
| --- | --- | --- |
| 每游戏小时引擎秒数 | `seconds_per_game_hour` | 正式计算与提前准备的累计排他毫秒 ÷ 1000 ÷ 实际推进游戏小时 |
| 每游戏小时引擎决策数 | `engine_decisions_per_game_hour` | 正式引擎行动选择数 ÷ 实际推进游戏小时 |
| 每游戏小时外部控制者选择数 | `controller_decisions_per_game_hour` | 人类或大模型的正式行动选择数 ÷ 实际推进游戏小时 |
| 每游戏小时现实用时 | `elapsed_wall_seconds_per_game_hour` | 整段现实游玩毫秒 ÷ 1000 ÷ 实际推进游戏小时 |
| 人类／大模型每游戏小时用时 | `controller_seconds_per_game_hour` | 当前外部控制模式下的整段现实游玩秒数 ÷ 实际推进游戏小时；引擎自主模式为空 |
| 每现实游玩小时引擎决策数 | `engine_decisions_per_wall_hour` | 引擎正式行动选择数 ÷ 现实游玩小时 |
| 每引擎计算小时决策数 | `engine_decisions_per_compute_hour` | 引擎正式行动选择数 ÷ 累计引擎计算小时 |

游戏时间分母只取正式 Prepare、后台 Prepare、采用提前准备与 Complete 期间物理时钟的真实前进量，只在最外层操作计一次。读取地图、切换视角、等待输入、阅读正文、Godot 移动及动画本身不增加该分母。开发命令引起的时间跳跃单列。零推进时所有每游戏小时比率为空，终端显示“—”；不足一小时按实际覆盖分钟折算。

`engine_ms` 为同步计算的墙钟耗时，包含该段期间的操作系统调度和 GC，不是线程 CPU 时间或 Godot 帧率。`elapsed_wall_ms` 从开局或恢复完成计至宿主发起关闭，包含人类阅读、思考、大模型调用与网络、输入等待、现场执行、界面和引擎处理，不自动扣除离席、暂停和后台停留。人类／大模型的 `controller_wall_ms` 对应这段实际游玩时间，不能解释成纯思考或纯模型推理时间。关闭后的归档不继续累积现实游玩时长；活跃会话后续快照仍会包含操作者主动查看或导出报告所花的时间。

报告携带控制来源、审计方式、开发模式、主体数、.NET 版本与程序集 MVID。插桩具有开销，不同条件的数字应分别报告。

## 决策事件与控制来源

只计本次统计会话内新增、已经进入正式 `state.events` 的 `action_selected`。NPC 与自主主体计为 `engine`；外部控制主体依据显式配置计为 `human` 或 `llm`。UI 聚焦、取消、候选搜索节点、无候选的选策阶段和未采用的 PrepareAhead 分支不增加决策数。分支正式采用后，其新增选择事件只计一次。恢复存档从历史事件末尾开始采集；开发命令新增选择仅推进游标，不计入正式决策。

决策数描述已经形成的行动选择，不等同于成功执行次数。选择后因预算或现场条件被拒绝的行动，仍保留其真实选择；执行成功与失败继续由 `outcomes` 独立记录。`decisions` 表按主体与控制来源聚合，包含次数、每游戏小时比率、首末事件引用与游戏时刻。全局和小时表同时保留 `engine_decisions`、`human_decisions`、`llm_decisions`、`total_decisions`。

`player` 与 `human` 表示人类，`llm` 表示外部大模型，`ai` 表示引擎自主。人类和大模型仍走同一个底层 player 输入合同，标记不会改变行动资格或控制权。`--jsonl` 只选择协议格式。控制来源须在首次正式／预备／开发操作前确定；统计开始后不得改名混合不同来源。默认恢复沿用存档的标签，旧存档按实际 player_actor 推定 human 或 engine。

## 计算分类与嵌套

| category | 内容 | 是否计入引擎计算指标 |
| --- | --- | --- |
| engine | 正式 Prepare、后台准备、采用分支、Complete | 是 |
| speculation | PrepareAhead 实际计算，包含最终未采用的提前计算 | 是 |
| projection | 意图、快照、增量、观察者地图、选项、状态与正文投影 | 单列 |
| startup | 新会话初始化、存档恢复 | 单列 |
| persistence | 稳定存档、轨迹、会话关闭与序列化 | 单列 |
| development | 显式开发命令 | 单列 |

认知 `phase.cognition` 与选策 `phase.choice` 沿现有阶段边界记录真实主体。Prepare 等外层操作的 `total_ms` 包含子阶段，`self_ms` 扣除子阶段；分项相加只使用排他耗时。按操作／阶段／主体汇总次数、异常、未闭合阶段、均值、峰值、P95 上界和分配字节。操作调用次数与正式决策数分列，不能拿 Prepare 次数或 choice 阶段次数代替选择事件数。

P95 为固定直方图上界并由已观测峰值收紧，分配字节为当前托管线程累计分配。异常范围为 DV 调用与持久化异常；参数拒绝不意味着动作执行。未结束作用域不补成已完成样本。

## 小时表与原始记录

小时表按物理游戏时钟的绝对 60 分钟区间排列。计算耗时归该操作开始小时；决策归原事件游戏时刻；现实等待归当前已提交游戏时刻，推进期间仍归操作开始小时，推进完成后切换归属。实际前进分钟按跨小时边界拆分，不假定跨小时计算与等待均匀耗费。向后调时新建 epoch。每行保留覆盖分钟、整小时标记、各分类耗时、认知／选策／Prepare／Complete 等排他分项、各来源决策数和现实用时。阶段列是分类的拆分，不能重复相加。全局均值用累计分子除以累计覆盖时间，不平均各小时比率。

计算原始采样与决策引用各保留最近 8192 条；两类尾部环分别记录累计、保留与淘汰数。主体、小时和会话累计汇总不随尾部淘汰。正常计算过程不逐样本写磁盘，也不依赖性能页是否打开。

`dv-performance-v2` 导出五个文件：

| 后缀 | 内容 |
| --- | --- |
| `.md` | 中文定义、运行条件、决策、计算与小时报告 |
| `.hourly.csv` | 每游戏小时区间的覆盖、计算耗时、决策率及现实用时 |
| `.operations.csv` | 按分类、操作及主体的计算聚合 |
| `.decisions.csv` | 按主体与控制来源聚合的正式选择数、比率及事件引用 |
| `.dvlog` | 二进制计算尾部、决策引用尾部、完整聚合快照与 seal |

CSV 是派生聚合表，原始记录写二进制。各文件独占创建 partial，完整后原子改名；失败保留部分文件，独立尝试其他文件后报告错误。报告生成与写盘不计入该次快照。

## CLI 与回放

游戏时间下的固定页头显示引擎秒／游戏小时、引擎决策数／游戏小时、累计引擎秒数与推进分钟；人类或大模型模式增加对应现实用时／游戏小时。分页保留，窄屏换行。字段缺失显示“—”；人类及大模型的 AI 评分默认隐藏，可显式覆盖。

`--controller player|human|llm|ai` 设置来源。`perf` 展开当前汇总、主体决策和计算分项，`perf NEW_PREFIX` 同时导出五个文件。`--performance NEW_PREFIX` 指定退出报告前缀。CLI 正式会话退出自动导出；有 --trace 或 --save 时使用其旁边去扩展名加 `.performance` 的前缀，其余放在 `artifacts/performance/<UTC时间与会话标识>/engine`。

新交互记录保留 `controller_kind` 与当时的 `performance`，确认帧随实际结果更新摘要。回放的 `perf` 只读当前已播放帧，不创建统计会话、不把播放速度折算成历史耗时，也不导出新报告；旧记录缺失字段保持缺失。

## Godot 与桥接口

`PerformanceSummary()` 返回轻量摘要，`PerformanceSnapshot()` 返回完整汇总，`WritePerformanceReport(prefix)` 导出。`SetPerformanceController(kind)` 只设置诊断来源，须与实际 player_actor 兼容且在统计操作开始前调用；存档保留该标签。`StopPerformanceClock()` 幂等冻结现实游玩时长，不关闭会话或改变世界；Close 自动调用，Godot 在关闭记录前先冻结以排除归档等待。

GameEngine 公开摘要与快照接口。性能页继续保留 120 帧图，每 0.25 秒读取摘要，增加决策数与人类／大模型用时；离页只停止原有帧诊断，累计会话统计持续。退出写入 `user://dv-sessions/<会话>/engine-performance.*`，独立于完整审计开关，失败登记关闭清单。
