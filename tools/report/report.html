01 / 当前运行主链

以下主链按 Main、SessionBridge、RuntimeSession 与 NativeCli 源码核对。箭头表示委托；宿主回报通过独立完成接口进入 Core。

两组接口同时存在

正式 Godot 新局由 SessionBridge.Open → CharacterSessionDefinition.Create → RuntimeSession 建立；CLI 的 NativeCli 也持有 RuntimeSession。仓库还包含 DVKernel / DVSimulationKernel 的 object/列表形态函数和 DvSession 兼容实现。

当前主链的 HostCompleted 与旧 F_dvs_session_complete_commit 不应画成同一次直接调用。全局没有引用到的符号也不自动等于死代码。

数据、规则与表现

.dv 提供内容声明；C# 实现状态、规则、推理、调度与空间计算；GDScript 实例化 UI、角色与建筑，执行物理移动和动画；Python/HTML 提供 MCP 与作者工具；Shader 实现材质与视觉效果。

真实回执、运行顺序及动态多态必须在正式宿主验证。本次只分析与验证报告本身，没有启动游戏、注入状态或声称通过游戏门禁。
